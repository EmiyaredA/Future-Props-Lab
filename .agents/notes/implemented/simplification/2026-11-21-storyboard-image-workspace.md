# Agent Note: 分镜固定图像与属性区收紧

Status: implemented

当前制作类型规则由[分镜对应镜头视频](../bug-fix/2026-11-21-storyboard-video-production.md)取代；本篇保留先前决定，紧凑布局规则继续有效。

## Problem

分镜工作区用无文字图标切换图像与视频，镜头选择又优先打开视频，无法稳定表达分镜图编辑用途。
预览下方的容器间距与页签上下外边距叠加，属性区的大控件和单列空白挤占内容。

## Decision

按用户要求，分镜工作区只编辑图像节点，移除制作类型切换与视频关联入口。
纳入、关联、新建、镜头缩略图、画布选择和预演采用统一使用图像关联。
保留镜头文档中的旧视频关联与制作节点，不迁移或删除用户历史输出。
这取代了[参考素材格直接上传](../feature/2026-11-21-direct-reference-upload.md)中
分镜视频／图像切换保留为图标的决定，参考素材上传机制继续沿用。

详情页签取消额外上下外边距，分镜输出区采用 8px 内容间距、32px 页签和输入框。
属性表单弱化标签与操作按钮，景别、运镜、时长并排，对白与声音并排，窄屏回到单列。
剧本关联分镜面板统一为紧凑标题栏、选段引用、关联操作与整行可点击的编号列表，
摘要限制两行。没有当前场次时不将所有无来源镜头误判为关联镜头，显示选择场次提示。

## Alternatives considered

- 给类型按钮补文字：仍保留用户不需要的切换与两套制作上下文。
- 删除旧视频关联：会破坏既有项目，界面简化无需更改持久化协议。
- 只缩小字体：无法消除叠加间距，降低可读性。

## Consequences

仅关联视频的旧镜头需要关联或创建分镜图才能在分镜制作区编辑；原视频仍在文件和画布中。
保存、只读、失败重试和输出版本沿用既有机制，不变更 API 和数据库。
遵循[能力实现契约](../../../../docs/architecture/capability-contracts.md)与
[开发与验证流程](../../../../docs/operations/development-workflow.md)。
