# Agent Note: 分镜统一为紧凑列表

Status: implemented

## Problem

分镜侧栏保留卡片／表格切换，但工作区的紧凑样式将两种模式覆盖为相同布局，切换只有按钮状态变化。用户确认不需要这项显示切换。

## Decision

移除分镜显示方式按钮、组件内的模式状态和失效的两套布局样式，统一沿用当前紧凑缩略列表。场次筛选独占原工具行，保留搜索、新建、纳入、排序、选择及保存保护。

## Alternatives considered

恢复大图卡片与紧凑列表的差异：能修复切换，但增加用户明确不需要的展示分支。

## Consequences

画布与看板共用同一列表，不增加持久偏好或修改分镜数据。保留固定侧栏宽度和局部滚动。

## Verification

更新已有39镜浏览器回归，检查无显示切换、场次筛选可见、条目高度、末镜选择和局部滚动，覆盖明暗主题、桌面、矮窗口与手机。验收产物放在忽略的 `.local/storyboard-view-switch/`。
