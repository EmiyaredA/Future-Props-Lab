# Agent Note: 嵌入表格不再闪现保存按钮

Status: implemented

## Problem

笔记里的多维表格在单元格修改后会自动保存。未保存的短暂窗口里，工具栏下方会插入一颗「保存」按钮，保存完成后再拿掉。阅读中的表格因此上下跳动，看起来像表头临时拉出一个保存入口。

## Decision

嵌入表格只保留自动保存。单元格修改后约一秒写回源表，父笔记正文不因此变为待保存。保存失败、冲突和本机草稿仍用原有提示处理，不靠这颗按钮重试。独立打开的多维表格页面继续在标题旁显示保存状态，需要时可以立即保存。

## Alternatives considered

- **把按钮固定留在工具栏** — 自动保存已经覆盖正常修改，常驻按钮会让人以为必须再点一次。否掉。
- **独立表格页也去掉立即保存** — 那一页的状态就在标题旁，按钮不挤进表格。本次只处理嵌入块里的跳动。否掉。

## Consequences

- **收益**：编辑嵌入表格时，表名、搜索和新增记录那一行不再被保存按钮撑开。
- **代价与已知上限**：嵌入块没有「立刻保存」入口。离开页面前仍会提交未保存操作；失败时按提示处理。

## Verification

- `web/tests/features/thought-multitable.test.tsx` 在新增记录后的待保存窗口检查嵌入块没有「保存」按钮，独立表格页的标题旁仍保留该按钮；同文件其余 5 项通过。
- 使用指南写明单元格修改后约一秒自动保存，嵌入块不另放保存按钮。当时打开的文档页所在服务已不在监听，没有在那篇笔记里再点一次单元格。
