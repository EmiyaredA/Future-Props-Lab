# Agent Note: 视频提示词控制区合并单行

Status: implemented

## Problem

视频提示词的版本管理与模板／预览／复制仍分别占据一行，重复消耗编辑区高度。此前只约束渲染操作行不能解决用户标出的整个控制区。

## Decision

GenerationPromptField 接收现有版本 hook 的返回值，在同一工具栏内组合 PromptVersionControls 与渲染操作，紧凑和普通视频入口均使用该组合。版本 hook、草稿回调与保存时机不变，图片和音频继续使用原有独立版本控件。

以提示词容器实际宽度响应：中等宽度隐藏重复的版本说明和预览／复制文字，保留按钮无障碍名称及提示；窄区域缩短版本下拉与图标按钮的宽度，仍保留全部版本操作。所有控件不换行，极窄区域仅在工具栏内部横向滚动，下拉继续使用原有逃离裁切的弹层。

此约束取代[视频控件统一密度](2026-11-21-video-controls-unification.md)中窄屏版本管理自然换行的规则。

## Alternatives considered

- 只缩小两排间距：仍占两行，不符合本次整体单行要求。
- 隐藏部分版本操作：降低可发现性，采用名称省略与图标按钮缩窄，保留直接操作。

## Consequences

无新增 API 或持久状态。版本选择、模板选择、编辑／预览、复制原文及四项版本操作共用一个单行容器。键盘与读屏名称继续保留，版本完整名称通过下拉与原有 title 可读。

## Verification

- 生成、提示词版本和渲染组件回归验证版本操作及保存／生成语义。
- visual-prompt-rendering.spec.ts 检查八个控件在1440px／390px和明暗主题下同排；四种视频模式尺寸旅程继续回归。
- 隔离配置、截图和构建位于忽略的 `.local/prompt-controls-single-row/`。

54项相关组件测试和四项浏览器旅程通过；浏览器同时验证八个控件同排、互不重叠，长提示词下工具栏维持32px高度并可操作。类型、ESLint、Prettier、Agent Note及受保护文档检查通过。
