# Agent Note: 移除镜头属性中的关联设定

Status: implemented

## Problem

镜头属性的设定关联与生成编辑器中的参考素材入口重复，且关联已有视频后不会同步生成输入，用户无法从这里判断对制作的实际影响。

## Decision

按用户要求移除共享镜头属性中的关联设定区块，包括已关联列表、添加与移除操作、专用选择分支和样式。此决定替代[精简分镜属性](../feature/2026-11-22-h3-rich-references-and-shot-properties.md)中保留设定关联界面的决定。参考素材继续在生成编辑器管理。

## Alternatives considered

- 保留区块并补充说明：仍然重复占用镜头属性空间，用户明确要求移除。
- 同时删除历史关联字段：超出界面精简范围，会损失已有镜头信息。

## Consequences

画布、看板及只读入口共用的属性面板均移除此区块。已有 `card_ids` 随原分镜保存，首次准备制作节点时读取旧关联的兼容行为保留，不新增迁移或变更生成草稿。

## Verification

分镜现有测试覆盖属性精简、修改描述时完整保存旧关联、视频创建与关联、只读和白模关联；执行对应测试、ESLint、Prettier、Note 与产品文档保护检查。
