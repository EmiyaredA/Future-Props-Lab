# Agent Note: 内置验收模板收敛为动作迁移

Status: implemented

## Problem

视频、角色、连续性、音画、剧情和空白六种内置模板将同一创作用例拆散，用户难以直接判断该选哪套要求以及需要什么参考。

## Decision

内置模板列表仅提供“动作迁移”，使用独立 ID builtin:motion-transfer。要求包含输出规格、角色外观一致、动作与道具，以及仅用于视频的动作连贯与节奏。角色与姿态使用 AI 抽样辅助，连续动作和节奏必须人工完整播放核对。参考准备明确为角色基准图与原动作视频。

模板卡片使用单列展示并说明目标。Workspace 自存模板、搜索筛选、从空白开始仍沿用原用例。模板复制为独立项目文档，不修改已有草稿、发布标准、历史记录或已保存模板，不需要迁移数据库。

验收模型列表补充 slug 与 provider_kind，由服务端真实目录提供。选择框与列表项以供应商图标、模型名称、调用标识和供应商名称展示。通用 CustomSelect 增加可选渲染函数，继续拥有统一的焦点、键盘与浮层定位；验收功能只拥有模型卡片内容和样式。

## Alternatives considered

- 仅在前端隐藏旧模板：后端仍提供不再推荐的列表，其他消费者行为不一致，未采用。
- 把连续动作交给 AI 自动判断：现有抽帧证据不能验证整段节奏，保留人工确认。

## Consequences

新建标准只有一个内置起点；用户仍可编辑复制后的要求并保存自用模板。静态内置模板无持久引用，旧项目使用的完整标准不会随列表调整而改变。界面提示与官方指南同步反映抽样检查边界。

## Verification

后端 API 测试覆盖唯一内置模板、检查方式、参考位置以及已有项目标准和 Workspace 模板保留。组件测试覆盖默认选择、复制编辑、空白入口与筛选；隔离浏览器旅程覆盖唯一卡片、参考准备、窄屏与图片／视频验收复验闭环。
