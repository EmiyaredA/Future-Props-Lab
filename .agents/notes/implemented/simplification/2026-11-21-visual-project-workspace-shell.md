# Agent Note: 视觉项目统一工作区与紧凑导航

Status: implemented

## Problem

项目的画布、看板、剧本、分镜和白模使用不同顶栏与边栏。切换时入口换行、侧栏比例变化、镜头与搜索状态丢失，重复的位置文案进一步占用制作空间。

## Decision

尺寸与默认展开策略由后续[舒展布局与默认固定侧栏](2026-11-21-visual-workspace-comfort-and-pinned-navigation.md)调整，本文保留工作区层级和保存职责的历史依据。

项目只有工作台、剧本、白模预演三个一级工作区，统一使用固定 48px 顶栏与等宽入口。画布／看板只控制工作台的展示方式，文件、分镜、人设、场景、道具只属于工作台资源导航。删除重复的“工作台 · 画布”标题。此导航决定替代[此前的创作功能编排](2026-11-21-visual-project-creation-workspaces.md)，不改变其分镜与制作节点的数据归属。

三个工作区统一保留 48px 导航窄栏，内容列表默认收起，点击展开 240px 覆盖面板；桌面允许固定，窄屏仍覆盖展示。分镜列表复用原有文档控制器，画布选择镜头后定位其制作节点，看板使用同一份生成编辑器和输出属性，不增加第三种工作台页面。

项目壳显式持有当前工作区、工作台视图与镜头选择。工作台和剧本保留已挂载的页面内状态，隐藏工作区不注册离开保护。白模隐藏时释放三维宿主，保留编辑器文档与机位状态。统一顶栏委托当前编辑器原有的保存／离开规则；CAS 冲突与保存失败阻止切换并保留草稿。项目或账号变化时重新挂载，不把草稿写入浏览器持久存储。

## Alternatives considered

- 只统一按钮颜色：顶栏位置和两侧常驻宽面板仍会发生变化。
- 把分镜作为独立的第四工作区：用户要求分镜留在工作台，并保留画布／看板展示方式。
- 切换时卸载所有编辑器：会丢失场次、搜索与滚动位置。

## Consequences

一级导航不再承担工作台局部视图切换。各工作区仍拥有自己的编辑内容与保存规则，通过显式来源、镜头和场景标识联动；提示词、生成输入与输出版本继续由制作节点唯一维护。新导航没有新增后端接口、数据库迁移或项目 URL。

## Verification

工作区与看板组件测试覆盖键盘、数量、分别搜索、默认收起、固定与关闭。隔离浏览器旅程覆盖三个一级工作区、分镜保留两种视图、失败保存不离开、返回恢复选择与搜索、等宽入口及固定坐标、1440/1024/768/390 宽度和明暗主题。类型检查、相关静态检查及 Web 构建预算通过。可再生成的截图、日志和视觉对照报告位于被忽略的 `.local/project-workspace-ui/`。
