# Agent Note: 工坊首页合并业务操作与公共控件

Status: implemented

## Problem

工坊首页把公共控件、列表标题、搜索和筛选分成数行。演示工坊的宣传区与思绪工坊的重复标题进一步下推首屏内容。

## Decision

九个首页通过 `WorkshopAppChrome` 在同一个工具栏中组合标题、搜索或场次选择、业务操作与公共控件。网站和独立入口显式传入同一组公共控件，页面继续拥有业务状态和操作。宽屏单行显示，窄屏在栏内换行。只读首页复用栏位并保留原有只读操作。

这取代了[首批入口壳层](../architecture/2026-11-07-workshop-entry-shell.md)中由壳层额外绘制一整行公共顶栏的布局。

## Alternatives considered

考虑过仅把搜索移进业务标题行并保留公共控件独占一行。这能消除重复标题，但项目列表仍要为两行栏位留出高度。

## Consequences

首页移除宣传文案与封面上重复的操作提示。项目详情、表单流程、编辑器和账户权限由原功能继续维护。

## Verification

`web/e2e/workshop-entry-shell.spec.ts` 覆盖网站与独立 HTML 入口的标题去重、搜索和主操作位置、桌面单行、三种宽度的明暗主题和公共控件。知识库列表回归测试覆盖搜索、封面、卡片操作和回收站。
