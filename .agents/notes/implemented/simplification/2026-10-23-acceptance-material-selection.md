# Agent Note: 验收素材列表统一选择交互

Status: implemented

## Problem

参考素材的独立预览按钮和悬停浮窗占用操作空间，却不足以帮助查看图片细节与视频动作。验收节点采用另一套纯文字下拉列表，长名称和媒体类型不易辨认。

## Decision

按用户反馈移除参考素材的预览按钮、悬停浮窗及其状态、事件与样式，只保留可见行的鉴权缩略图、媒体格式、名称及绑定、替换和解除操作。该决定取代[原预览方案](../feature/2026-10-23-acceptance-reference-previews.md)中的放大预览交互。

验收节点选择复用参考素材行，以相同的内联滚动列表点击整行选择。当前节点通过按下状态标识；Escape 和取消关闭列表并返回触发按钮。无最终输出的节点仍可查看，音频和文本展示类型图标。节点切换仍重置版本页码，保留原有跨节点批量版本选择契约。

## Alternatives considered

- 扩大预览浮窗：用户明确要求移除，额外的播放与窗口交互不再保留。
- 继续使用纯文字节点下拉框：不能满足用户要求的统一素材列表交互。

## Consequences

参考绑定和输出版本的持久化、权限、发布快照与 API 均保持原契约。图片和视频缩略图继续使用 useApiBlobUrl 的可见性加载、中止及回收；不为音频、文本下载缩略图 Blob。不再通过参考列表播放视频或放大图片。

## Verification

组件测试覆盖参考选择、替换、解除、只读、失败恢复、资源释放，以及验收节点的选中状态、类型和键盘关闭。隔离浏览器旅程覆盖两种列表、长名称、明暗主题和窄屏。
