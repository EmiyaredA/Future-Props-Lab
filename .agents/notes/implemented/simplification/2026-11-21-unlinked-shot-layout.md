# Agent Note: 未关联分镜的镜头设计布局

Status: implemented

## Problem

没有图像关联的镜头在中间展示大块空白，全部属性堆在右侧，两个区域又重复提供创建和关联按钮。
用户无法从页面层级辨认镜头设计与画面制作的先后关系。

## Decision

未关联有效分镜图时，将原镜头表单放入中间的镜头设计卡片，右侧显示分镜图占位和唯一的制作／关联入口。
保留原表单输入、保存保护、只读状态与错误反馈；画布浮层复用同一内容。
创建图像后恢复现有生成编辑器与输出区的属性页签。已有图像的镜头仍按现有方式工作。
失效图像引用显示重新添加提示，旧视频引用不改动。

## Alternatives considered

- 只给右侧属性区增加边框：不能解决中间空白和重复入口。
- 自动为所有无图镜头创建节点：会无请求地改变项目数据，保留用户主动开始制作的行为。

## Consequences

未关联镜头可以直接完善设计，再从右侧开始制作。仅调整视图分配，不更改持久化协议或自动提交生成任务。
遵循[能力实现契约](../../../../docs/architecture/capability-contracts.md)和
[开发与验证流程](../../../../docs/operations/development-workflow.md)。

- 浏览器检查深浅主题、桌面及窄屏边界、画布浮层和开始制作后恢复图像编辑器。
