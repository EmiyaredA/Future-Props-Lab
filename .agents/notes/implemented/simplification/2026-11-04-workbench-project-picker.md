# Agent Note: 云控工作台直接选择项目

Status: implemented

## Problem

新建 Agent 会话之前，管理员需要在桌面设置中单独保存项目授权。选择项目与远程桌面设置是两项独立操作。

## Decision

工作台通过可信本机浏览器 Session 读取推荐目录、浏览四类本机入口，并校验粘贴路径。SQLite 按账号和规范绝对路径去重并保存最近使用时间。会话继续引用稳定项目 ID。旧 TOML 项目保留原 ID 和命令预设；公网 Agent 仅解析原有 TOML 项目。

## Alternatives considered

在桌面设置内继续保存项目会保留多余的配置步骤。浏览器原生目录句柄指向访问页面的设备，无法表达 FPL 所在 Mac 的绝对路径。

## Consequences

新项目不改写部署配置。工作台在会话创建和执行时重新校验根目录，失效时仍能读取历史。新增迁移不重写历史会话与部署设置。

## Verification

隔离 API 测试覆盖目录和账号边界、重复登记、目录移动、旧会话与新会话执行。浏览器回归覆盖三类目录选择入口、窄屏、最近项目与精简后的桌面设置。
