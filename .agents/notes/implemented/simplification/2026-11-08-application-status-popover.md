# Agent Note: 应用卡片状态详情浮层

Status: implemented

## Problem

应用卡片把状态详情展开在网格内，抬高整行卡片并移动其他应用。状态文字和详情也相距较远。

## Decision

状态文字是详情浮层的锚点。桌面可悬停，触屏可点按，键盘可用 Enter 打开。浮层复用现有视口定位，移开鼠标、点击外部或按 Escape 可以收起详情。

## Alternatives considered

在卡片内部预留固定高度仍会让每张卡片为不常看的内容留出空间。浮层可以就近展示检查时间与依赖。

## Consequences

详情显示期间应用卡片网格高度保持稳定。失败原因、依赖和上次检查时间都由状态浮层展示。

## Verification

应用服务状态单测核对悬停、键盘、依赖与失联反馈。Portal 浏览器验收核对状态浮层与卡片高度。
