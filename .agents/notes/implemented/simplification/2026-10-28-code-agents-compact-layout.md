# Agent Note: 编程智能体紧凑布局

Status: implemented

## Problem

编程智能体页面同时铺开各 CLI 的连接卡，重复的登录说明占据主要视野，授权表格与外部接入因此被推向页面下方。

## Decision

页面使用一个统一的设置面板：左侧为固定宽度智能体列表，右侧依次呈现所选连接的名称、版本、诊断信息、行内登录命令和账号授权矩阵，外部接入作为面板底栏。详情不再使用大卡片，登录说明和复制操作放在同一行，减少重复容器与留白。

列表同时展示所有智能体的名称和状态，选择只保存在页面内存中；目录刷新后保留有效选择，选项消失时回退到首项。切换智能体时重新挂载详情组件，复制反馈和详情展开状态归属于当前智能体。

列表、连接标题与授权表通过同一个 `AgentLogo` 组件复用 `web/public/providers/` 已登记来源和许可证的 Codex、Claude Code、OpenCode、DeepSeek Harness 与 Pi 标识，以品牌色展示。重新检测放在智能体列表底部；目录为空或加载失败时仍在页头保留检测入口。

授权矩阵继续展示全部智能体，并收紧单元格与区块间距。窄容器中设置面板改为上下布局，列表保持两列，授权表格保留局部横向滚动。

## Alternatives considered

- 仅缩小两张连接卡：保留了重复说明，对连接数量增长和视觉层级的改善有限。
- 列表与大连接卡并排，授权继续独占全宽：主要信息仍分散在多块大容器中，视觉体量没有明显降低。
- 把授权也收进所选智能体：降低跨智能体核对账号用途授权的效率，因此保留完整矩阵。

## Consequences

页面可同时扫描所有连接状态，详细信息需要选择对应智能体。选择过程不触发检测、授权保存或外部接入设置。
