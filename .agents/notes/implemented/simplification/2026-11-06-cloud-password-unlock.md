# Agent Note: 云控使用管理员密码解锁

Status: implemented

## Problem

在本机使用 Agent 工作台也必须先登记验证器。公网桌面首次连接还要依次输入管理员密码、动态验证码和 VNC 密码。

## Decision

本机和公网共用 Identity 的密码重验和用途授权接口。Agent 工作台按会话解锁 15 分钟。公网桌面授权随当前会话有效，本机桌面直接使用 VNC 密码。写入授权前在短事务内核对当前管理员会话与登录后的重验时间。

本决定取代[公网云控的密码重验与验证器](../architecture/2026-11-05-public-cloud-verification.md)中的验证器要求。

## Alternatives considered

只在本机省去验证码会保留公网登记和重设流程。扫码登记可省去手动复制密钥，但公网每次首次解锁仍需要验证码。

## Consequences

公网开关和账号白名单继续控制入口，桌面票据仍绑定账号、会话和入口。历史验证器数据保留在凭据迁移路径。兼容网站、独立服务和 Web 使用匹配的契约版本。

## Verification

隔离测试覆盖密码错误、重验时效、CSRF、管理员权限、用途隔离、并发授权、桌面重连与票据重放。浏览器测试覆盖错误密码反馈、密码解锁和 VNC 重连。
