# Agent Note: 视觉创作工坊项目列表不再区分状态

Status: implemented

## Problem

视觉创作工坊需要按名称找到并打开项目。草稿与已完成的分类占用工具栏和卡片空间，并让用户维护一个业务流程用不到的状态。

## Decision

视觉创作工坊将项目统一列出，移除状态筛选、标签和切换操作。项目卡片只接收列表需要的字段。官方认证独立于项目状态，继续使用现有标识。既有状态字段保留在数据和接口契约中。

## Alternatives considered

只移除筛选会留下卡片上的状态标签与修改操作。删除数据字段则涉及已有项目、快照和 API 调用方，超出了此次界面简化的范围。

## Consequences

原有项目都能通过同一个列表按名称查找，生成任务仍展示自己的运行状态。

## Verification

`web/e2e/applications-workshop.spec.ts` 覆盖新建项目与旧已完成项目同列、状态控件移除和项目名称搜索。
