# Agent Note: 移除工坊冗余项目状态标签

Status: implemented

## Problem

工坊列表仍通过公共项目卡片显示手动维护的“草稿 / 已完成”。Galgame 列表、概览及音频标注的角色来源选择器还使用同一标记，导演台重复显示固定的“预演”标签。这些信息不能说明实际任务进度或内容质量。

## Decision

公共 `ProjectLibraryCard` 不再接收和展示项目状态。Galgame 移除列表与概览的手动完成、恢复草稿按钮及其专用 mutation 和反馈，保留从工程检查结果计算的线路就绪提示。音频标注的角色来源选择器只展示工程名称；导演台移除固定预演标签。

官方作品标识、音频校对百分比、创作发布状态及后台任务状态继续由所属业务展示。此次只清理界面和相关客户端交互，现有 API、持久字段与快照格式保持兼容。

## Alternatives considered

- 逐个调用方隐藏标签：公共卡片仍会因为传入完整项目对象而再次显示历史状态，故直接移除公共卡片的状态展示契约。
- 连同数据库字段和 API 一并删除：需要独立迁移与旧快照兼容设计，超出本次界面清理范围。

## Consequences

各工坊不再要求用户额外维护项目完成标记；历史项目的编辑、重命名、搜索、导入导出与删除继续使用原接口和权限。实际进度和发布信息保留在各业务入口。

## Verification

Galgame 列表与概览现有测试覆盖移除状态控件后的重命名、搜索、删除、线路检查提示和编辑器入口。相关工坊组件测试、Web 类型检查、改动文件的 ESLint 和 Prettier 检查以及 Agent Note 与文档中心保护检查用于验证此次清理。
