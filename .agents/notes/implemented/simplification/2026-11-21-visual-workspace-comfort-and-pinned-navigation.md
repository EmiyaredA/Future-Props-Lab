# Agent Note: 视觉项目舒展布局与默认固定侧栏

Status: implemented

## Problem

统一项目壳的浮层侧栏遮挡制作内容，48px顶栏和压缩列表显得拥挤。资源创建按钮比例过大，画布节点操作图标又受到看板通用按钮内边距影响，嵌入后被挤小。

## Decision

以用户确认的整页图为视觉依据，三个工作区统一使用56px顶栏、56px导航栏、280px列表，桌面一级入口等宽112px、高36px。列表行至少56px、缩略图40px，编辑区20px留白。此尺寸与默认固定规则替代[此前默认收起的项目壳规则](2026-11-21-visual-project-workspace-shell.md)，保留其工作区层级与保存职责。

`useWorkspaceSidebarState` 统一管理视口至少1024px时的默认展开和固定，以及窄屏临时覆盖展开。固定列表通过布局占位；重复点击当前入口、点击外部和Escape均不关闭，显式关闭仍保留固定偏好。取消固定后支持外部点击与Escape关闭。跨断点清空临时展开，保留桌面偏好；刷新或进入新项目恢复默认。状态不写入浏览器持久存储或服务端。

编辑和输出按工作区域实际宽度排列：不足900px时上下滚动，避免固定侧栏后两列被挤窄。资源新建／上传独立使用32px按钮与13px文字，避免撑满列表。画布节点操作使用32px按钮、18px图标和零内边距，保留逆缩放补偿，工具栏与节点保留间隔；禁用、悬浮和键盘标签沿用原动作契约。

## Alternatives considered

- 仅扩大字体：浮层遮挡和可用内容宽度不足仍存在。
- 所有按钮统一放大：资源创建按钮比例过重，也不能修复节点工具栏的内边距冲突。
- 窄屏继续固定列表：会挤压编辑区域，无法满足手机操作。

## Consequences

工作台、剧本与白模共享侧栏状态规则和尺寸。隐藏工作区不参与浮层关闭和焦点恢复；选中镜头、各分类搜索、滚动、保存失败保护与逐镜白模行为继续保留。没有新增后端接口、数据库迁移或产品文档中心内容。

## Verification

组件测试覆盖默认固定、显式关闭、取消固定、外部与Escape关闭、跨断点恢复，以及窄屏初始收起。浏览器旅程覆盖三个工作区几何尺寸、保存失败保留草稿、分镜两种视图、节点工具栏缩放尺寸、1440/1280/1024/768/390px和明暗主题。相关回归、类型、静态检查、构建与截图证据保存在被忽略的 `.local/project-workspace-comfort/`。
