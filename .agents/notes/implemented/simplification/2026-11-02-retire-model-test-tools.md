# Agent Note: 移除 Mock 测试工具

Status: implemented

## Problem

独立测试工具目录及其在文字、实时语音测试中的 Mock 执行链路没有继续保留的产品价值，维护成本涉及管理页面、运行编排、持久表、事件协议、SDK 和文档。仅隐藏入口仍会保留可调用接口及失效的运行依赖。

## Decision

完整移除 Mock 测试工具管理、会话绑定、执行记录与文字/语音测试集成。新增 `0119_retire_model_test_tools`，依次删除调用记录、会话绑定、工具定义表；历史迁移保持原样。用户明确选择删除专用历史数据，并授权定向同步受保护文档中心及 SDK 文档生成映射。

普通模型测试继续使用单轮供应商流式路径。`llm/playground/recovery.py` 独立拥有服务启动时的未完成回复取消与会话 revision 更新，同一会话只更新一次；重复恢复不再次更新。模型调用日志中的既有工具快照保留，不改写历史日志。模型目录的 tools 能力声明、通用 Agent Harness、Amadeus 与集成中心的实际工具能力保持各自边界。

前端移除工具页面与导航，旧 URL 按未知路由回到首页；模型测试路由按路径段匹配，避免旧工具地址被文本测试前缀误识别。公开接口、Web 类型和 SDK 使用正式生成流程同步，删除不再生成的工具参考页。此前[模型中心视觉设计](../feature/2026-09-16-model-center-high-fidelity.md)中的工具专属页面随功能下线，其余模型中心视觉规则继续适用。

## Alternatives considered

- 只移除页面入口：旧接口、执行器及选择状态仍可使用，不能形成完整下线。
- 保留专用旧表：可避免删除数据，但留下无访问入口的永久存储；用户选择通过正式迁移一并删除。

## Consequences

- 移除工具配置、Mock 延迟与失败、工具步骤状态、实时工具事件及对应 SDK 资源，减少维护面。
- 三张专用表的数据在执行正式迁移后不可通过应用恢复；上线遵守停机、完整备份、核准迁移流程。本次只在隔离测试数据库应用迁移，不操作正式实例。
- 对话、消息、附件和模型调用日志继续保留；现有浏览器和 SDK 需要随新契约更新。
- 官方知识只更新仓库导入包，不覆盖管理员已经导入的笔记。文档保护检查会报告本次已授权变更，检查脚本保持原样。
