# Agent Note: 云控视图切换

Status: implemented

## Problem

远程桌面与 Agent 工作台并排时挤占彼此的操作空间。额外的面板收起按钮与布局选择重复。

## Decision

云控页头切换远程桌面和 Agent 工作台，选中的视图占满工作区。两套组件保持挂载，桌面隐藏时释放键鼠焦点，源码阅读在工作台内部打开。

## Alternatives considered

- 并排布局提供同时查看能力，但缩小了两个工具各自的操作区。

## Consequences

浏览器按 FPL 账号保存上次使用的视图，新账号默认打开远程桌面。

## Verification

组件测试核对默认视图、切换后保留工作台节点和按账号恢复。浏览器回归覆盖宽窄屏、桌面连接与键鼠释放、会话草稿及源码阅读。
