# Agent Note: 视觉项目视图、创作功能与分镜文档

Status: implemented

导航层级与布局的后续决定见[统一项目工作区](2026-11-21-visual-project-workspace-shell.md)，本文保留分镜数据归属与退休兼容的历史依据。

## Problem

画布／看板视图与剧本、白模预演混在同一导航层，画布缺少一致创作入口；节点检查器承担素材、生成、分类整理和自动验收。镜头设计缺少独立于制作节点的顺序、场次和规划信息。

## Decision

采用用户选定的工具栏编排：画布／看板为项目视图，文件／人设／场景／道具为项目模块，剧本／分镜／白模预演为创作功能。追加标注要求画布创作入口位于顶部中间，左侧文件按钮下补充三种设定入口。看板入口同样移入顶部，去掉可见的“创作功能”标签，让三个按钮直接前移；分组的无障碍名称保留。复用既有身份、Amadeus、主题、文件操作与输出版本。

分镜独立保存镜头顺序、描述、景别、运镜、规划时长、对白、声音、来源场次和设定关联。存储使用项目授权、短事务 CAS 和新增关联校验；已删除资源的既有引用保持可修复，剧本变更不自动覆写分镜。第一版仅手动编辑和批量纳入现有图像／视频节点，不自动拆剧本或检测镜头。

镜头卡引用制作节点，后者继续管理素材、生成和输出版本。新建制作节点先准备参考图和提示词草稿，再保存画布与分镜关联，不自动提交模型请求；已有制作节点设置不被分镜覆写。失败保留本页草稿，离开先保存。关闭创作工作区后再测量并定位画布，避免在隐藏 DOM 上计算视口。画布底部控制条保持在底部，避免与新创作入口重叠。窄屏生成检查器使用显式宿主脱离画布变换层，并保留关闭操作，防止编辑区被裁切。

分镜进入项目快照和独立历史迁移，追加网站 0136、Visual 0016 迁移。便携快照重映射制作节点并保留剧本来源；账号设定库不进入项目档案，关联解除并返回提示，目标账号重新选择。初次实现未执行正式迁移；后续用户授权后的迁移与恢复验证见[本机发布收尾](../bug-fix/2026-11-21-native-agent-admission-and-visual-release.md)。

节点编辑只显示生成内容，移除素材和自动验收页签及分类整理入口，人工通过独立保留。自动验收退出前端、公开 OpenAPI、SDK 和自动化目录，两种装配均不启动执行器。兼容网站显式将已退休路径送到受认证且按项目隔离的 410 处理器，不扩展公开目录；独立网关不再签发新操作授权。启动恢复按原账号幂等取消未完成检查，历史结果、证据与保留引用不清除；删除制作节点时保留被历史验收引用的输出。

## Alternatives considered

- 五种入口共用分段按钮：视图与功能不对等，用户明确否定。
- 将分镜属性写入媒体节点：节点复制、删除和生成会混入规划文档语义，无法独立排序和关联场次。
- 只隐藏自动验收入口：后台仍可能执行，因此同时关闭公开提交和执行器并取消未完成检查。
- 便携档案直接复用全局设定卡 ID：跨账号身份关联不可靠，因此解除并提示。

## Consequences

旧项目不会自动生成分镜，可批量纳入已有节点。规划时长与实际生成参数独立，生成前仍由用户选择模型和规格。历史验收存储、引用保护与快照代码保留，已移除功能的原旅程测试由退休、历史保留和新分镜测试替代。

工程契约及目录索引同步。初次实现未改写受保护产品文档。后续授权已同步生成的 Visual SDK 参考，并以独立文档提交保存；旧验收说明不在本次正文更新范围内。

## Verification

分镜测试覆盖 CAS、账号隔离、关联校验、已删除引用、快照重映射和追加迁移；独立服务测试覆盖相同协议、公开操作完整性及退休授权拒绝；退休测试覆盖 410、历史保留与按账号幂等取消。视觉工坊相关前端 201 项及后端、架构、契约 410 项回归通过。隔离浏览器检查画布工具位置、项目设定面板、镜头编辑保存、生成设置跳转、看板及窄屏布局；检查产物位于忽略的任务目录。
