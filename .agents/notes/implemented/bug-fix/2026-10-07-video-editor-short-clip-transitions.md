# Agent Note: 短定帧片段的转场时长约束

Status: implemented

## Problem

修复闪屏插入的定帧片段可能只有125001微秒。转场面板固定为接缝提交500000微秒，超过相邻片段长度，正式API拒绝整个批次后保存队列暂停。片段头尾入口与属性面板默认时长存在同类问题；输入框只设置HTML最大值，手动输入仍可提交越界时长。原保存提示隐藏后端拒绝原因。

## Decision

接缝新建时取默认时长、两个相邻片段长度与契约上限的最小值；片段头尾取该片段长度与契约上限。转场面板手动输入在提交前约束为有效整数微秒，并保留显示值和最大值的微秒精度。属性面板默认值随片段时长变化更新，启用时再次检查上限。

保存失败提示展示ApiError的具体原因，版本冲突保留专用提示。正式API仍严格拒绝过长转场，保存队列保留未保存操作并要求显式放弃，不自动重提或改写持久数据。

## Alternatives considered

- 放宽后端转场长度校验：短定帧不具备足够的画面区间，会改变预览与导出语义。
- 修改或删除定帧片段以容纳默认转场：改变用户时间线，超出本次修复。
- 只设置输入框max属性：手动输入不会自动裁剪，仍可提交无效批次。

## Consequences

短片段能够使用合法时长的转场，长片段默认仍为0.5秒。125001微秒的定帧接缝最长只有0.125001秒，效果节奏受真实片段长度限制。没有新增HTTP契约、迁移或跨模块职责。

## Verification

319项视频编辑器Web回归与97项相关后端测试通过。Web回归覆盖短定帧接缝、片段头尾、新建与手动输入、撤销快照以及属性面板片段长度变化。正式API隔离测试覆盖过长批次拒绝且快照不变、合法时长保存与撤销重做。失败提示测试覆盖业务校验、版本冲突与网络失败。正式数据库诊断只读，不对项目自动重提失败操作。
