# Agent Note: 闭眼睁眼导出遮罩不自相交

Status: implemented

## Problem

闭眼睁眼转场的预览 SVG 沿外框和眼睑曲线连续围合，但 Pillow 导出的下眼睑按左下、右下、左曲线端、右曲线端连接，形成自相交多边形。导出视频出现斜切黑块、边角漏光和闭合细缝。原测试只检查中心与上边缘，未覆盖下眼睑及真实编码结果。

## Decision

下眼睑在右下角后沿曲线从右到左返回，与上眼睑和预览 SVG 的边界顺序一致。开合时序、曲线、镜头切换、片段参数与音频规则保持原契约。

精确帧缓存增加共享合成器版本，浏览器精确帧 URL 的 renderVersion 同步递增；旧帧保留在原路径但不再命中。已生成的 MP4 保持固定结果，修复需要重新导出，不改写既有任务产物。

## Alternatives considered

- 修改开合时长或降低曲率：不能消除多边形自相交，也改变效果语义。
- 只改编辑器预览：预览路径原本正确，无法修复正式导出。

## Consequences

修复共享确定性合成器，覆盖片段接点、入场和离场的眼睑遮罩。精确帧首次访问使用新的缓存命名空间。没有数据库或公共 API schema 变化。

## Verification

- 七个开合比例和三种横竖/奇偶尺寸，逐列检查唯一连续、居中的可见区间，检查底部边角没有对角漏光。
- 真实 H.264 编码、解码后检查闭合帧全黑，闭合前为原镜头、张开后为新镜头，半开上下遮罩对称。
- 正式预览 API 在同 revision 下忽略旧采样与旧合成器缓存，不删除或改写旧文件。
- 本地合成对比图及两秒编码样片保存在已忽略的 .local/eyelid-fix/。
