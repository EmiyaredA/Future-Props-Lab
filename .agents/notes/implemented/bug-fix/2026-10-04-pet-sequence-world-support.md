# Agent Note: 完整桌宠序列的确认位移与世界支撑

Status: implemented

## Problem

原播放器按确认步相选择完整原帧，却没有接入宿主实际位移。同一帧停留期间窗口继续移动，承重脚随窗口滑动；八帧、每周期 60 DIP 的循环中，一个帧段会产生约 7.5 DIP 的漂移。渲染器还优先报告右行片段的循环距离，使左右或攀爬采用不同距离时步相不一致。人体原画不自然是另一问题，不能用统一画布或测试通过作为视觉通过证明。

## Decision

私有 SequenceInput 明确接收宿主已确认的有符号二维 travel、实际模型到 DIP 比例和已知方向。figure 使用已安装 SVG 的显示矩阵换算位移，按当前片段报告 stride；没有实际移动的事件或离线原帧检查保持兼容，不假装拥有世界支撑。

player 在有 distancePerCycle 的物理循环中登记真实支撑肢及世界位置。同一原帧内只平移整幅画面保持支撑；跨帧按照累计 duration 的循环距离核对原画支点，不拉长、旋转、缩放或重组肢体。至少一只共同支撑肢连接相邻帧，新支点建立后才释放旧点。登记超出 1 DIP、多个支点不能用一次完整画面平移满足、位移与步相矛盾、非法数值或支点缺失时停止并反馈。

计时的入口、停步和转角也校验支点，窗口等待期间同一原画支点不能漂移；物理能力检查提前拒绝缺少中间支点的入口／返回。正常 stop 保留最后确认 travel，退出桥完成实际绘制后才结束支撑；显式取消和比例变化结束旧周期。离地只允许已匹配完整桥的末帧与目标空中首帧相同且无支点，中段缺失仍拒绝。失败可以发生在宿主已经确认窗口移动之后；保留最后实际绘制帧时，仍用其世界支点补偿这次已确认位移，不选择错误新帧。figure 的前置失败与 player 的片段失败共用公开拒绝接口。新请求和退出恢复不追赶旧时钟。

## Alternatives considered

- 只用 i/帧数推进：忽略不同原帧时长，也不能锁住原帧停留期间的脚。
- 从步相反推窗口位移：无法区分方向、迟到回执、取消和实际移动失败；只消费已确认位移。
- 放宽登记容差或把错误图大幅平移到支点：掩盖原画错误，因此先校验原画相邻登记再计算补偿。
- 回到旧分件运动：用户已拒绝其扭曲及断缝，新素材继续以完整原画制作。

## Consequences

支撑锁定不改变资源包版本、持久配置、CAS、公共 API 或数据库。旧包和纯事件检查继续兼容；物理行走和攀爬需要真实支点及距离声明。

校验覆盖距离驱动循环、实际物理过渡的登记点及失败后的已绘支撑补偿。入口／出口仍以原画时间播放，实际窗口等待；对已登记点的校验不能证明画中手脚对应正确，也不能证明缺少的逐姿势停止原画自然。有限原帧保持支撑时，躯干仍可能呈离散节奏，必须以足够连续的完整原画解决。此次没有合格全套动作，不应用新正式资源，不把技术校准当作人体或 Electron 视觉验收。

## Verification

174 项相关测试及类型、局部 lint／格式通过，覆盖 player 与生产 figure 的同帧、跨帧、方向、三种比例、支点交接、取消、失败保留、当前片段距离、计时桥、stop 实际位移及离地终点。冻结与逐项结果保存在 `.local/desktop-pet/sequence-support-review/`。真实 Chrome 生产 Canvas 与实际 SVG 显示矩阵使用合成有色支点校准，检查实际绘制像素的世界位置；源码哈希、逐 tick 位移和结果保存在忽略的 `.local/desktop-pet/world-support-review/`。该校准不使用人体素材，不访问正式 App、数据库或模型。

候选 walk-right-v2 与 edit1 完整原帧逐张放大检查仍重复同一支撑腿，鞋底登记相差约 17–20 source px，拒绝。新 opposite-passing-v2 单张实现对侧支撑和向后屈膝，仍不等于完整步态。原图、prompt 和独立报告保留在 `.local/desktop-pet/four-edge-motion/full-frame-sequences/`；全部动作、服饰、四边和正式应用仍遵循[完整帧提案](../../proposed/bug-fix/2026-10-04-pet-whole-frame-motion.md)的独立视觉门禁。

第三版 atlas 以两种完整承重姿势为参考，05／06 的交换有改善；整组头高比参考小约 5%，03→04 腿身份接续仍未建立，拒绝。白底共同画幅 8 关键帧的 4 秒 30 fps 导出（120 输出帧、8 个不同原帧）及 10 fps 抽取是源图循环诊断，不是实际运行、30 个不同原帧或 Electron 录像；不授予正式更新资格。

最终冻结复核：九个文件 SHA 与实现者 source-freeze.json 保持一致。桌宠 Web 共 42 文件、630 测试通过；全仓库 lint、格式和 build（含 TypeScript）通过，契约／SDK、架构、LFS、导入包、文档保护与 Note 检查通过。独立实际播放器复核确认原 5 DIP 计时桥反例现在以 support-registration-mismatch 拒绝、保留支点漂移 0；77 项独立回归通过。实际 PetLocomotion.receipt→stop→figure 使用负屏坐标、sceneOffset 和不同名义／真实显示比例，41 个退出采样及迟到回执支撑漂移 0，stop 快照独立。最终报告保存于 `.local/desktop-pet/world-support-review/final-report.md` 与同目录独立复核记录。当前 Mac 锁屏导致真实 App 操作无法继续；全套隔离 Electron 视觉验收未执行，正式资源未更新，不以这些代码结果宣称动作已完成。
