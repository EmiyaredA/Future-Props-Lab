# Agent Note: 分阶段完整帧拒绝后的冻结恢复

Status: implemented

## Problem

完整帧播放器拒绝新动作或收到预检拒绝后，会冻结当前原画并重置普通播放时钟。但是分阶段爬行的 `distanceStage` 仍保留旧的静止阶段起始时间与位移相位原点。返回此前动作时，旧时间会跳过尚未完成的静止原画；重置后的宿主相位也会导致 `invalid-support-motion`，无法从已确认的阶段距离继续。

## Decision

取消、选择拒绝及预检拒绝共用播放器内部的冻结原语，同时清空普通时钟和阶段的时间／相位原点。保留实际帧索引、累计阶段距离与整幅位置；返回原请求时按当前时间、当前相位重新绑定原点。静止阶段重新计时，移动阶段只允许尚余的确认距离。原有支撑校验、拒绝反馈与同步呈现提交保持原契约。

## Alternatives considered

- 只清空普通时钟：不能冻结分阶段恢复，已有实际复现。
- 丢弃阶段并从动作第一帧开始：会替换当前已绘完整原画并丢失已确认距离。

## Consequences

分阶段循环与普通动作遵守相同的拒绝后冻结恢复规则。本修复不新增原画、放宽支撑容差或改变四边动作契约；代码回归不证明角色原画的承重与视觉自然度，也不授予失败候选正式安装资格。
