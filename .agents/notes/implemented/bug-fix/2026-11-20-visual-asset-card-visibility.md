# Agent Note: 视觉项目素材库展示设定卡分类

Status: implemented

## Problem

角色、场景和道具设定在项目文件视图中各有现存记录与独立用例，原来的二级设定卡入口让三类卡难以发现。只读资产页只装配了文件浏览器。

## Decision

- 项目素材页将文件、角色卡、场景卡和道具卡放在同一级页签。各卡片视图通过类型读取、筛选和创建，沿用原有存储与权限控制。
- 只读入口复用同一素材页和卡片页签，文件使用只读浏览器，卡片操作使用已有只读模式。画布素材抽屉提供在新标签页进入完整资产管理的链接。

## Alternatives considered

在原设置组旁补充说明。平铺后，用户无需先发现设定卡总入口即可打开具体分类。

## Consequences

旧项目仍可从文件中选图作为卡片采用图。没有设定记录的项目显示相应分类的空状态；用户可以新建卡片或从分集剧本提取。

## Verification

`web/e2e/visual-creative-workflow.spec.ts` 验证打开各类已提取的卡、利用键盘切换、画布管理链接和只读入口。
