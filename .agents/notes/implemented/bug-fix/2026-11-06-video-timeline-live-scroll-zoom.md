# Agent Note: 时间轴缩放读取当前滚动位置

Status: implemented

## Problem

滚动时间轴与改变缩放可以发生在同一次事件循环。浏览器已更新滚动容器，但 React 还没有收到滚动事件。使用保存中的滚动值计算缩放会让末端和播放头向左跳动。

## Decision

编辑器在缩放事件中直接读取时间轴滚动容器当前位置。时间轴继续负责应用并回报浏览器夹紧后的滚动值，持久化工作区偏好沿用现有逻辑。

## Alternatives considered

- 等待下一次滚动事件。缩放期间还可能发生下一次滚动，推迟计算会改变用户看到的锚点。

## Consequences

同一帧中的滚动与缩放共享实际视口位置。刷新恢复和最小缩放边界继续使用原有工作区偏好。

## Verification

Chromium 在同一次事件循环滚动到右边界并派发缩放事件，核对夹紧位置、持久化偏好以及下一次缩放的播放头位置。
