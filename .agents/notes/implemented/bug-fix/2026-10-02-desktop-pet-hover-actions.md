# Agent Note: 桌宠悬停操作的可点击路径

Status: implemented

## Problem

透明桌宠窗口仅在角色命中区域接收鼠标输入。角色与底部悬停按钮之间存在透明间隙；指针经过间隙时按钮立即消失，Electron 也恢复点击穿透，因此用户无法点击按钮。

## Decision

按钮显示期间，角色中央至窗口底部的狭窄区域保持可交互，作为指针通往按钮的路径。按钮自身始终属于命中区域。离开该路径、角色和按钮时恢复点击穿透。命中状态变化时才向 Electron 发送切换请求，避免每次鼠标移动都产生 IPC。

## Alternatives considered

- 持续让整个桌宠窗口接收点击：会挡住桌面上其他应用的透明区域。
- 把按钮移到角色轮廓内：会遮住角色，并限制可配置按钮的数量。

## Consequences

按钮显示时，角色中央的一条窄带也会接收点击；离开这条窄带后窗口继续透传鼠标。此规则对 Live2D 角色和 Coopanion 鲸鱼娘共用。

## Verification

隔离 Electron 烟测用 Playwright 鼠标事件从角色移动到「隐藏」按钮并点击，确认桌宠隐藏；移动到窗口角落确认按钮收起，再移回角色确认按钮重新出现。分别用鲸鱼娘和 Live2D 桌宠运行该烟测。
