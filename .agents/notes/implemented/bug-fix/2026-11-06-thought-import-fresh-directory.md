# Agent Note: 思绪工坊导入读取提交前的目录版本

Status: implemented

## Problem

新建文档后立即选择 Markdown，文件事件可能在目录查询刷新之前捕获旧知识库。即使导入按同一操作队列等待刷新，事件闭包仍会提交旧版本，造成知识库已更新的 409。

## Decision

工作台在选择文件时固定目标知识库 ID。Markdown 和 Markdown 内容包在本地解析、打包完毕后读取该库最新目录，再把版本交给原有导入接口。完整备份按原有流程创建副本。提交后发生的并发冲突仍由服务端版本检查处理。

## Alternatives considered

- 导入收到 409 后自动重试。冲突可能来自另一个设备的更新，直接重提会跳过已观察到的并发变化。
- 以闭包中的旧查询快照作为写入版本。队列能排序请求，无法更新已经捕获的对象。

## Consequences

Markdown 导入增加一次目录读取。读取发生在文件验证通过后，目标 ID 始终来自文件选择时所在的知识库。原子导入、素材归属和回执机制保持由服务端执行。

## Verification

Chromium 固定新建后的目录请求时序，在旧版本上复现导入失败。相同场景在修复后连续通过三次，覆盖导入、代码块、图片选择及响应式操作。
