# Agent Note: 官方发布的角色选项

Status: implemented

## Problem

账号角色归并后，官方发布仍把旧「超级管理员」和「管理员」都显示为同一个权限键。两个勾选项会同时变化。

## Decision

对话框只显示管理员与普通用户，选择官方发布时默认授权管理员编辑。沿用服务端角色去重和既有权限校验。

## Alternatives considered

- 保留两个旧标签。两项写入同一角色，保留会继续误导发布者。

## Consequences

当前显示与固定账号角色一致。已发布的文章继续使用原有授权与可见性。

## Verification

Chromium 使用真实的官方文档导入与发布接口，从「全部文档」打开发布设置，核对公开文章及持久化的单个管理员角色。
