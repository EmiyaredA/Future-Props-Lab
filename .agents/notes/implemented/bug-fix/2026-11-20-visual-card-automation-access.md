# Agent Note：设定卡 SDK 和 CLI 授权登记

Status: implemented

## Problem

设定卡已有账号级读写路由和生成的 SDK 方法，独立网关与兼容入口的自动化清单缺少这些路由及将项目采用图添加到总文件的接口。已绑定账号的 CLI 调用因此返回 `automation_operation_forbidden`。

## Decision

在共享自动化清单登记账号级查询、新建和按版本更新，以及现有项目下的读取方法。登记现有的项目素材复制接口，让自动化按同一账号将项目原件复制到总文件。沿用现有账号归属、凭据读写权限、图片检查和 revision 校验。候选图生成仍通过原有生成入口授权。

## Alternatives considered

通过网页逐张录入保留了既有权限，但大批量整理需要反复选择素材，也无法复用已有 SDK 的版本检查。

## Consequences

外部客户端可在已授权账号范围内维护通用设定卡，项目侧仍能读取同一份记录。部署更新授权清单即可启用这些方法。

## Verification

兼容网站的本机和远程入口校验操作发现、读写权限与过期 revision。视觉工坊测试校验账号隔离和项目引用。
