# Agent Note: Amadeus 对话删除确认居中显示

Status: implemented

## Problem

对话删除确认直接追加到历史列表末尾，随列表滚动且占用窄侧栏空间。长历史下确认内容远离触发入口，标题换行拥挤，列表仍可操作。

## Decision

AmadeusWindow 复用共享 ConfirmDialog，通过 Portal 在窗口中央显示删除标题与本地消息、会话文件的删除范围。侧栏仅选择目标对话，删除仍调用原有 conversationActions.remove 并沿用 revision 校验与冲突处理。提交期间禁用确认与关闭，失败信息在确认框内可见；取消、Esc 或遮罩关闭后恢复触发按钮焦点。独立 Amadeus 入口补齐确认框按钮样式，使用共享主题变量适配明暗模式。

历史行的重命名与删除图标在鼠标悬停或行内键盘聚焦时显示，常态下标题使用整行宽度。图标绝对定位，显示时为标题预留空间，行高保持稳定。隐藏图标不接收鼠标点击但保留键盘顺序；不支持悬停或使用粗指针的设备始终显示入口。删除使用垃圾桶图标。

## Alternatives considered

将确认框放到历史行旁边仍受窄侧栏与滚动裁切限制。单纯使用 fixed 定位只改善视觉位置，仍缺少模态语义和键盘焦点管理。复用共享确认组件使交互与其他删除入口一致。

## Consequences

确认不再影响历史列表布局。删除只由显式确认触发，提交失败保留目标供用户核对或取消，不自动重试。数据/API 契约保持原有实现。后续的 [历史行内重命名](2026-10-08-amadeus-inline-rename.md) 使用同一历史行操作区。

## Verification

组件测试覆盖 Portal 脱离侧栏、标题与说明关联、取消/Esc/遮罩关闭、焦点恢复、显式删除、提交期间禁止重复提交与关闭、失败提示及取消。共享确认组件测试与现有对话冲突测试继续覆盖其各自契约。

隔离 Electron 烟测在 400px 与 900px 窗口、明暗主题下验证中心位置、视口边界、长标题无横向溢出、焦点留在弹窗并在 Esc 后恢复；正式 API 创建的一次性测试对话在取消后保留、显式确认后删除。截图人工复核通过。

同一烟测覆盖历史行常态隐藏、不可指针点击、悬停显示、键盘聚焦显示与 Tab 顺序、移出后隐藏、显示前后行高不变，以及标题为操作图标让出空间。
