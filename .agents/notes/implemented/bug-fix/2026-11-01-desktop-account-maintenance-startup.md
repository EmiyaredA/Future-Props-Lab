# Agent Note: 桌面账号维护状态启动

Status: implemented

## Problem

账号归属升级将后端保留在文件维护状态，`/ready` 返回 503，后台任务不启动。桌面壳原先只接受 200，因此用户无法打开登录和管理员文件迁移页，升级停在桌面启动等待。

## Decision

后端就绪探针为此状态返回明确错误码 `account_storage_upgrade_required`，仍使用 503。桌面壳通过带私有启动凭据的探针，仅接受正常 200 或上述 503 错误码来打开界面；其他状态、无效 JSON、响应过长和请求失败继续阻止启动。

维护页仍要求现有账号登录、管理员身份及近期密码验证，经正式文件布局 API 迁移。桌面启动不执行文件用例，不绕过账号验证，也不启动普通任务。

## Alternatives considered

- 全部 503 都放行：会掩盖真实数据库或执行器故障。
- 将维护状态改为 200：会错误表示业务可用。
- 启动时直接迁移文件：绕过正式 API 的管理员确认与恢复反馈。

## Consequences

维护状态可进入应用并由管理员完成升级；监控仍能观察业务未就绪。正常服务与业务 API 的鉴权不改变。用户此次明确要求迁移并重启正式实例；正式 schema 升级使用已登记迁移，停机持锁备份后执行，不修改历史 SQL。
