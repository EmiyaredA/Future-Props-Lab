# Agent Note: 完整爬行原画区分停住换支点与确认位移发力

Status: implemented

## Problem

循环原画只按宿主累计位移推进时，手脚换支点的原画无法在窗口停住时播放；持续移动又使支撑与身体推进脱节。渲染反馈若只给剩余距离，控制器反复读取同一反馈可能重复领取移动额度，迟到回执还会覆盖新暂停原点。

## Decision

资源片段可选distanceAtFrame，长度为帧数加一、从零到distancePerCycle有限非递减。零距离阶段按完整帧durationMs计时，正距离阶段只消费真实确认位移，一次实际提交最多跨一个边界。纯distanceStages拥有校验与阶段采样，旧未声明包保持原距离步相。player.present的成功提交才发布预算，figure按真实CTM换成DIP；私有motionBudget携带owner epoch、剩余DIP与本次确认位移原点。控制器扣除后续确认位移并限制整个未确认目标，仍只有一个移动请求在途；手动输入优先。实际与试玩暂停、配置及环境变化经公开cancelPlayback取消阶段，旧回执沿既有代次规则拒绝，恢复重新等待活动间隔，附着休息不被零距离阶段冻结。

## Alternatives considered

只加durationMs但继续恒速移动会拖滑支点；用时钟伪造步相把未确认目标当作真实移动；每帧读取剩余额度都发新目标会超走。用工程支点或放宽1DIP约束替代原画也不成立。阶段契约保留真实确认和提交边界，不生成缺少的人体姿势。

## Consequences

可选字段位于原资源模型JSON，不新增公共REST、数据库schema或事件。后端校验所有服饰的相同素材闭包；旧包、既有帧/图集/JSON预算与支撑约束保持不变。新原画仍需足够密集的完整发力中间帧；一个大距离阶段不能制造平滑上移。数值测试不能作为自然人体或正式资源验收。

## Verification

63个Web桌宠测试文件1056项通过，其中新增34项覆盖合法/非法距离阶段、真实生产Figure安装提交、挂起解码、失败回滚、总目标预算、迟到确认、暂停代次与真实hook/虚拟恢复。后端494项通过，其中新增21项覆盖旧包、三服饰闭包、非法阶段和隔离API/CAS拒绝保留快照。合成30/60fps支撑漂移小于1e-9DIP，错误登记明确拒绝；该测试并非原生GPU或人物视觉证据。Web类型、scope lint/格式、Ruff、48架构测试、contracts及SDK检查通过。正式资源、持久配置、数据库和App未更新，完整人体及隔离Electron动态验收仍属于全动作提案。
