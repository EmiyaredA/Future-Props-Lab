# Agent Note: 用创意工坊的保存回执同步编辑状态

Status: implemented

## Problem

保存和发布会规范化服务端的草稿与作品内容。编辑器此前只更新保存的作品快照，导致
草稿仍和已保存快照不同。发布成功页的查看作品操作因此弹出未保存确认。

## Decision

加载、保存和发布使用相同的可编辑字段投影。成功响应同时更新保存基准和本次提交的
草稿。编辑器保存在请求发出后继续输入的内容，确认公开发布前要求预览草稿已保存。

## Alternatives considered

在成功页绕开导航守卫会掩盖真正未保存的编辑，也无法修正普通保存的状态。

## Consequences

发布成功后的查看作品直接打开作品详情。正常的未保存保护仍检查编辑和请求中的输入。
HTTP 请求、服务器修订号和安装回执继续使用既有契约。

## Verification

- 创意工坊与独立入口 8 项定向测试通过，覆盖保存请求期间继续编辑。
- 隔离兼容站的构建产物通过 2 项 Chromium 检查，含发布后跳转、安装与响应式入口。
