# Agent Note: Studio 切换时核对旧站来源和历史授权

Status: implemented

## Problem

从固定候选目录封存旧站时，网站配置的相对数据库路径可能解析到候选目录。旧站的
`code_agents` 设置也可能包含已停用工作台的合法授权，导致覆盖检查无法完成。

## Decision

封存命令通过 `--source-config-root` 显式指定相对数据库路径所属的旧站根目录。它仍要求
解析结果与待封存数据库一致，并保留原始配置字节。已登记的 `agent_workbench` 授权与旧工作台
历史一并封存在回滚快照中，覆盖检查继续拒绝无法识别的设置。

兼容站的 `profiles/codex-app-server/` 由 Host 使用。头像导出只登记账号头像，允许旧站保留这个
已知的真实目录。Identity 导入仍拒绝未登记路径，原账号头像继续校验文件归属及 SHA256。主机
目录及其凭据由完整快照保全，正式装配按 Host 状态恢复。

旧推理任务中的较长请求 ID 在历史导入时保留原值。公共提交仍遵守自己的长度限制。迁移工具记录经过
格式校验的错误码，避免把凭据、请求体或私人资源标识写入操作日志。

旧站缺失的已结束转录输入须逐条核准。对旧上传可保留任务、转录文字和输入元数据，由原有的
文件可用性状态报告输入不可用。旧素材库输入只在封存来源能确认同账号原件、字节数与摘要时
恢复，走 Models 维护导入接口。未核准的缺失、进行中的任务与归属不符仍阻止切换。

思绪工坊迁移游标沿用资源 ID 契约，保留旧记录中无连字符的 ID，原父子关系和素材引用继续校验。历史官方导入
回执保留含标点的原请求 ID，分页时使用与笔记编辑回执一致的十六进制编码。

旧剪辑分段结果缺少导入标记时，按同账号全部输出的实际范围重建回执。剪辑派生文件校验要求
每个登记文件存在，只识别命名与文件类型均符合旧预览生成规则的未登记缓存，缓存留在完整快照。旧 M4A 音频代理随登记文件按原格式和摘要恢复。旧片头、片尾转场只放宽历史回执的校验，原操作与版本保持。

Galgame 当前故事的素材引用必须全部出现在旧索引中。旧索引中额外保留的引用和历史快照一起
传给 Assets，仍逐项验证同账号、项目及原件归属。

## Alternatives considered

改写正式配置可以消除相对路径，但会改变旧站启动输入和恢复摘要。关闭覆盖检查会掩盖其他
未处理的设置。

## Consequences

使用固定候选目录执行封存时，操作单要传入正式站的项目根目录。工作台旧历史和旧授权可从
快照恢复，本机 Happier 继续使用自己的 Relay 和权限。

## Verification

隔离 SQLite 覆盖相对路径、错误根目录拒绝、配置字节保留、已知旧工作台授权归档和未知设置拒绝。
