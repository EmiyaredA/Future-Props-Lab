# Agent Note: 模板设计器确认一次后返回

Status: implemented

## Problem

模板设计器先弹出确认，然后调用带导航保护的返回入口，同一个未保存状态再次触发拦截。独立文档导航在用户确认后还会遇到设计器的原生离开提示。

## Decision

完整页面的返回按钮由已注册的导航保护发起确认，嵌入文稿内的模板编辑继续使用自身的确认框。浏览器卸载检查使用现有保护上下文的批准状态。

## Alternatives considered

- 在确认时清除脏状态。后续导航守卫仍可取消跳转，草稿需要保留原有保护。

## Consequences

已确认的文档导航直接返回模板库，未确认的浏览器离开操作继续受保护。嵌入编辑器使用原有的文稿内关闭动作。

## Verification

Chromium 用例从模板库打开新模板，经确认返回模板库。独立 Compose 旅程同时检查确认后没有原生卸载弹窗。
