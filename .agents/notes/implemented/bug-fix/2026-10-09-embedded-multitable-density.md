# Agent Note: 嵌入多维表格的密度与列宽

Status: implemented

## Problem

笔记里的多维表格视图把更换目标、工具栏和分组计数分成多层，窄栏里搜索和新增记录再折一行，长文本被单行截断。列宽拖动只挂在独立表格的字段配置回调上，嵌入视图没有列边界，读者无法把比较结果列拉宽。

## Decision

嵌入块把表名和「更换视图」放进工具栏同一行，分组计数不再使用整条底色。容器宽度低于 760px 时，嵌入工具栏仍保持一行，直到 640px 以下才让搜索占满宽度。

未写入 `column_widths` 的嵌入列按笔记内容宽度分配：名称列和选择、引用等短字段保持紧凑，其余文本列平分剩余宽度，单列不超过 640。文本单元格最多显示两行。已保存的列宽保持原值。

目标可编辑时，表头右缘 12px 可拖动列宽。拖动中只预览，松手或方向键才把宽度写入源视图配置；父笔记正文不因此产生修订。字段菜单、筛选、排序和分组仍只在独立表格提供。只读嵌入不显示列边界。

## Alternatives considered

- 把嵌入列宽存进父笔记节点会让一次列宽调整变成正文修订，和「嵌入编辑只更新源表」冲突。
- 只在本地保存阅读宽度无法让同一篇笔记的其他读者看到作者排好的列。
- 继续要求回到源表拖列宽，笔记栏和源表宽度不同，比较结果仍然被截断。

## Consequences

嵌入中的列宽调整会改变源视图，打开同一视图的独立表格也会使用新宽度。尚未手调的嵌入列和独立表格的默认列宽可以不同。字段结构、筛选和分组不能从嵌入块修改。

## Verification

`fittedColumnWidths` 覆盖比较表在 700px 内容宽度下的分配，以及已保存列宽不被重算。网格测试确认嵌入视图没有字段菜单，方向键加宽「比较结果」只调用列宽回调。工具栏测试确认嵌入态显示「更换视图」。
