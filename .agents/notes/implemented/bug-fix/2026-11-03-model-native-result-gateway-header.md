# Agent Note: 原生模型结果描述与网关身份头清理

Status: implemented

## Problem

原生模型 worker 上传结果时将字节描述放在 `X-Fpl-Output-Descriptor`。真实 Caddy 原生入口会先删除客户端所有 `X-Fpl-*` 身份头，再注入该服务的可信入口证明。结果描述被同时删除，上传返回 422，模型已经执行却一直无法提交结果。直接调用 ASGI 的测试未覆盖这次协议转换。

## Decision

结果描述使用用途明确的 `X-Model-Output-Descriptor`，上传端与接收端共同更新。网关继续删除全部外部 FPL 身份头；文件描述不取得身份或执行权限，接收端仍校验 worker、原任务租约、长度和内容摘要。工作进程重试原结果交付，不重新合成。

Models 镜像显式包含本地模型清单；镜像打包回归核对实际构建上下文中的清单字节，防止只复制 Python 源码而遗漏运行输入。

## Alternatives considered

- 在网关放开客户端 FPL 头：扩大身份边界，并使普通描述字段与可信入口证明混用。
- 上传失败后重新提交合成：无法区分已执行与未执行，产生重复副作用。
- 仅验证直接 ASGI 上传：不能发现真实网关的头清理行为。

## Consequences

原生上传遵守统一身份清理规则；测试传输模拟网关清除头后注入可信证明。正式切换仍需真实模型权重、全部服务和数据转移验收，合成执行不能替代真实 MLX 环境验收。

## Verification

原生租约、回执恢复和素材回存定向回归验证同一任务最多执行一次；镜像清单、网关及部署边界回归通过。实际容器和浏览器验收结果记录在独立服务迁移文档及 `.local/service-split/` 报告中。
