# Agent Note: 恢复供应商已接收但查询中断的生成任务

Status: implemented

## Problem

供应商已经接收任务并返回任务 ID 后，单次网络查询异常会把本地任务永久判为失败。没有结果 URL 时现有恢复入口不可用，重新生成可能重复计费。

## Decision

共享生成状态机只对已提交任务的只读轮询采用逐任务退避，间隔从 5 秒增长至最多 60 秒，保留远端 ID 和活动状态。提交阶段不重试；真实供应商失败保持终态。视觉创作工坊的现有恢复结果入口接受明确的历史网络查询失败，沿用原 ID 转回 pending；已取得结果 URL 的任务仍恢复保存。Web 和 SDK 复用同一业务入口，不增加路由、传输字段或迁移。恢复使用状态和 revision 条件更新，重复操作不创建任务。

## Alternatives considered

- 重新生成：可能重复计费，不能恢复已支付的结果。
- 直接修改持久数据库：绕过业务权限和状态机，不采用。
- 所有异常都持续重试：会掩盖真实供应商失败或提交结果不明，不采用。

## Consequences

连接故障会保持任务活动，并显示不包含地址或凭据的查询异常提示；恢复查询不会占用新的模型生成调用。未恢复的远端任务仍应计入调用方并发控制。退避计时保存在执行器内存，重启可继续查询同一远端 ID。

## Verification

确定性状态机与业务/API 测试覆盖网络退避、恢复后落盘、执行器重启、真实失败、提交中断和重复恢复。测试使用临时隔离数据与模拟供应商，不触发真实模型生成。
