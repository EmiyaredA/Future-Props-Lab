# Agent Note: 视觉画布添加菜单可收起

Status: implemented

## Problem

视觉画布左侧加号打开添加菜单后，重复点击加号不会收起菜单，点击菜单外部也不会关闭它。

## Decision

加号按钮在菜单关闭时打开菜单，在菜单打开时关闭菜单；菜单监听外部指针按下并关闭，同时通过 `aria-expanded` 暴露展开状态。菜单内部交互和 Escape 关闭行为保持原有处理。

## Alternatives considered

- **只增加 Escape 关闭提示** — 可键盘关闭，但无法解决用户点击加号或菜单外部时的预期操作。
- **把菜单改为独立弹层管理器** — 对单一画布菜单来说会扩大修改范围，现有局部状态已足够。

## Consequences

- **收益**：菜单可通过原加号、菜单外点击和 Escape 收起，按钮状态对辅助技术可见。
- **代价与已知上限**：外部指针按下会立即关闭菜单；需要跨组件复用时再抽取通用弹层行为。

## Verification

在视觉创作工坊画布中打开添加菜单，分别重复点击加号、点击菜单外区域并按 Escape，确认三种方式都能收起菜单；检查加号的 `aria-expanded` 随开合状态更新。
