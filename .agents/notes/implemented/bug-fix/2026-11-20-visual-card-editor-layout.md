# Agent Note：视觉设定卡编辑布局

Status: implemented

## Problem

设定图在长表单末尾，浏览一张卡时很难先看到采用图。场景卡与道具卡也使用这套编辑器，低高度窗口中保存需要滚动到底。

## Decision

角色、场景、道具使用同一个双栏编辑布局。采用图和候选图集中在左侧，名称与已确认的设定在右侧。剧本依据、素材和候选图生成使用可键盘展开的分组。底部操作栏位于滚动区外，窄屏按预览、设定、操作的顺序排列。

## Alternatives considered

只调小现有表单的字号和间距仍会把设定图放在编辑项之后，且候选图增加时保存按钮依然需要滚动。

## Consequences

设定库和项目素材页一起使用新布局。采用候选图后即刻预览，仍由现有保存流程提交。卡片内容、来源和图片引用继续通过现有 API 管理。

## Verification

`web/e2e/visual-card-editor.spec.ts` 覆盖三种卡的首屏、键盘展开、采用候选图与保存，以及深色窄屏的滚动和操作栏。
