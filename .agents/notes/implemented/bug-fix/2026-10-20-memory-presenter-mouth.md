# Agent Note: 记忆科普角色的小幅曲线嘴形

Status: implemented

## Problem

用户放大成片后指出嘴型奇怪。原渲染器把元音画成深色椭圆，A 的最大高度达到角色坐标 8，O 也偏竖长；独立舌头椭圆、偏橘的肤色遮罩与突然切换的宽度，进一步放大贴片感。此前音轨与停顿检查只能证明时间关系，不能证明口型自然。

## Decision

在原[日语视频制作链路](../process/2026-10-20-agent-memory-japanese-video.md)内增加纯函数嘴形模块。以实际角色双眼跨度校准嘴形尺度，使用稳定嘴角、浅上缘与轻微下颌开合的曲线轮廓；最大开口高度 2.58，最大宽度 6.7。下唇内部颜色裁剪在口腔路径中，不再叠加独立舌头椭圆。三套姿势的遮罩分别匹配脸部局部肤色。

音量开合做短窗平滑，元音参数按相邻时间插值；短元音的过渡窗口随音节时长缩短，避免下一个元音接入时跳变。闭唇辅音前后分别收放，实际停顿仍立即闭嘴。站姿、摊手与托腮使用同一嘴形函数、各自的固定面部锚点。修改仅作用于忽略目录内的制作程序和交付物，不修改桌宠或原角色素材包。

## Alternatives considered

仅缩小旧椭圆不能消除竖长比例、贴片色差与元音突变。重新生成整个人物会引入造型漂移，也无法直接解决时序，未采用。单纯跟随音量的一种嘴型会丢失元音和闭唇差异，因此保留音轨约束下的近似音节形状。

## Consequences

新增放大对照视频和实际时间轴取样页。修正版使用新 MP4 文件名，避免旧播放缓存误导；旧文件名保留更新后的兼容副本。声音、中文字幕和 anatomy 图解时间轴不变。嘴形仍是二维近似，不声称逐音素强制对齐或恢复原角色表演。
