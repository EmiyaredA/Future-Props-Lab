# Agent Note: 演示工坊粘贴使用当前浏览器选区

Status: implemented

## Problem

全选并复制文字后立即按方向键移动光标，再粘贴时，浏览器可能先派发粘贴事件，稍后才派发选区变化事件。浏览器交付正确的纯文本，但编辑器仍使用上一个全选范围，导致粘贴把原文替换成相同文本，用户看不到追加结果。

## Decision

文字编辑器在消费纯文本剪贴板时，将同一编辑区域内的浏览器选区映射到当前 ProseMirror 文档坐标。仅在选区确实变化时同步该选区，再交给现有的纯文本粘贴和历史流程。浏览器选区跨出当前编辑区域时沿用编辑器选区。

## Alternatives considered

- 等待浏览器事件或在测试中插入等待。用户输入仍可能重现这一事件顺序。
- 自行插入文本。现有粘贴流程还负责段落拆分、样式和撤销历史。

## Consequences

快速复制、移动光标和粘贴与鼠标调整选区使用相同的选区规则。粘贴仍使用纯文本，交由既有文稿历史记录。

## Verification

新增 Chromium 用例在同一事件循环内折叠浏览器选区并派发粘贴。修复前错误替换整段文本。修复后该用例及真实快捷键用例各连续通过 15 次，真实快捷键用例同时覆盖撤销、重做与保存重开。
