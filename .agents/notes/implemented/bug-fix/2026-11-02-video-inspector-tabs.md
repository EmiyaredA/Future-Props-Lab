# Agent Note: 视频节点素材与生成面板选中状态一致

Status: implemented

## Problem

视频节点通过“替换素材”或“选择视频素材”进入素材面板时，页签仍将“生成设置”标为选中，实际内容与选中状态不一致。既有完整浏览器旅程还在寻找视频节点不再使用的“AI 生成”页签，无法继续验证连线参考素材及后续导航。

## Decision

内嵌视频检查器明确提供“素材／生成设置／节点验收”三个现有内容面板入口，选中状态严格对应内部 tab 状态。“替换素材”继续进入素材面板，生成参数与连线参考仍由已有生成控制器处理。完整旅程改用视频节点自己的“生成设置”入口，并验证素材与生成切换后的选中状态及固定参考素材约束，不删除后续助手、刷新与导航检查。

## Alternatives considered

- 只更换测试文本：可以解除超时，但不能纠正真实界面的错误选中状态。
- 将“替换素材”直接改为打开生成器：改变替换行为并隐藏本地素材选择，不采用。

## Consequences

没有新业务面板、接口、模型执行或持久化契约。三个页签共用既有检查器状态，素材与生成可来回切换，未保存的生成草稿沿用原保存流程。测试使用隔离账号与确定性供应商模拟，不调用真实模型。

## Verification

23 项画布视频、节点与连线组件测试通过；视觉工坊完整浏览器旅程已通过，包含进入应用、创建与保存项目、刷新恢复、图片生成反馈、视频连线参考、助手操作、窄屏与返回导航。最终合并回归共 58 项组件测试、47 项架构测试和 8 条浏览器旅程通过；有效图片及类型筛选模拟下的完整工坊旅程再次通过。页签切换后通过“适配视图”验证控件完整可见。正式 build:studio、Web lint、format:check、Agent Note 与文档中心保护检查通过，结果保存在 `.local/home-redesign/`。
