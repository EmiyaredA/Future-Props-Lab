# Agent Note: Codex 历史里的用户补充与图片标记

Status: implemented

## Problem

Codex 可以在助手轮次中记录用户补充。工作台依据共享轮次将补充并入助手区块，并把带图消息的提示包装和本机路径当作用户正文。

## Decision

工作台按 Codex 原生角色与消息标识分组。采集器核对已知图片说明、正文分隔符和实际图片块的对应关系，提取正文并沿用现有附件标记。识别不了的格式保留原文。

## Alternatives considered

- 在 Web 上截取标题之后的所有文字会误删普通 Markdown，也会让搜索索引继续包含附件说明。

## Consequences

Codex 独立提升采集版本。既有投影分批回填，条目标识与排序位置保持稳定，空包装条目退出索引和会话视图。可下载附件继续由来源权限校验。

## Verification

隔离存储测试覆盖分批回填、正文和索引更新、分页、内嵌图片与未知格式。工作台测试覆盖同轮助手活动、独立用户气泡、图片标记及结构化问答回执。
