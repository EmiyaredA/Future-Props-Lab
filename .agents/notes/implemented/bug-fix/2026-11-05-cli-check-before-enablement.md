# Agent Note: 编程 CLI 启用前检测

Status: implemented

## Problem

连接未启用时，页面跳过安装和登录检测。即使 CLI 已安装，管理员也只能打开启用弹窗后才发现还需要登录。

## Decision

连接目录为有配置权限的本机管理员复用 CLI 安装和登录探测。通过检测的停用连接返回 `ready_to_enable`，启用和可用标志仍为 false。页面分别展示安装与登录结果，检测通过后开放管理员验证入口。

## Alternatives considered

- 只改页面提示会让管理员仍需通过启用操作发现缺少的前置条件。

## Consequences

启用操作仍核验管理员身份和最新的 CLI 状态。普通用户和公网访问保持原有的停用提示。

## Verification

- API 测试覆盖本机管理员、普通账号和公网管理员的可见范围，以及从未登录到待启用的转换。
- 组件测试覆盖已安装、未登录、待启用和管理员重验。
