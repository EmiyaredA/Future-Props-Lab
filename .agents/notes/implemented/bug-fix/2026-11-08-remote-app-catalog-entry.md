# Agent Note: 公网云控的添加应用入口

Status: implemented

## Problem

公网云控隐藏「添加应用」，已验证的管理员无从知道应用名单在哪里维护。即使允许列表为空，也需要能找到下一步。

## Decision

本机与已验证的公网云控均显示「添加应用」。本机打开现有应用选择表单；公网打开同名说明，指引管理员在 Mac 本机选择已安装应用、重验密码并保存。公网说明不请求已安装应用目录。

## Alternatives considered

- 继续隐藏按钮会把来源限制表现为功能缺失。
- 让公网直接编辑会改变应用名单的授权边界。

## Consequences

应用目录读取和名单写入仍由可信本机入口校验，保存使用近期密码验证和当前配置版本。已验证的远程浏览器通过现有列表刷新取得新标签。

## Verification

前端测试覆盖本机选择推荐及搜索应用、保存后标签更新、未验证公网入口，以及已验证公网入口在空名单时能打开说明且不读取主机目录。后端已有测试覆盖公网拒绝名单变更。
