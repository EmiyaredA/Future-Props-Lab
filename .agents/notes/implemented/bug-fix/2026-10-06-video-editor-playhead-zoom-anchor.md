# Agent Note: 时间轴缩放保持播放头位置

Status: implemented

## Problem

视频剪辑时间轴的缩放滑杆只更新每秒像素数，横向滚动位置保持原值。用户在较晚切点放大时，播放头和正在观察的区域会移出视窗。

## Decision

滑杆输入先限制缩放范围，再按播放头微秒时间计算滚动补偿：新滚动位置 = 旧滚动位置 + 播放头秒数 × 缩放差值。缩放和滚动在同一次界面更新中生效，播放时间与工程内容不变。

负滚动位置限制为零；时间轴在布局阶段应用滚动值，并把浏览器限制后的实际位置回传到工作区状态，供后续连续缩放和偏好保存使用。“适配宽度”继续显式回到起点。

## Alternatives considered

- 每次缩放把播放头移到视窗中央：能显示切点，但连续操作会改变用户观察位置。
- 保持滚动值不变：实现简单，但不能保留当前切点的屏幕位置。

## Consequences

- 播放头可见时，鼠标滑杆和键盘调整均保持其横向位置；缩放不进入撤销记录。
- 到达首尾滚动边界时无法维持原坐标，使用实际边界位置；播放头已在视窗外时仍按同一坐标规则补偿。
- 复用现有工作区偏好保存，不增加后端接口或持久化格式。
