# Agent Note: 局部框选分组成员

Status: implemented

## Problem

[原框选规则](../feature/2026-10-21-presentation-marquee-selection.md)要求框住完整分组。流程卡片和其他内容属于同一大组时，框住卡片却没有选中反馈，无法直接下移。

## Decision

框选优先保留完整包围的分组。框只覆盖一部分时，继续检查组内的子组和元素，仅选择完整落入框中的可见、未锁定对象。框选不更改分组关系或进入组内编辑；已有移动、连接跟随和历史沿用同一份元素选区。

## Alternatives considered

要求先进入分组会增加操作步骤；框到一部分就选中整组会一起移动框外的内容。

## Consequences

大组内的一行卡片可以直接框选，框外成员留在原位。完整组的选择和锁定规则保留，旋转对象仍按实际外界判断。

## Verification

组件测试覆盖完整组、嵌套子组和局部选择。隔离浏览器用例覆盖框选同一大组内的部分卡片、批量下移、撤销重做及保存。
