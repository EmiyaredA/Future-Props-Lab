# Agent Note: 下拉菜单保留键盘高亮

Status: implemented

## Problem

调用日志筛选的下拉菜单在鼠标停留于上次点击位置时重新打开。浏览器因布局变化派发悬停事件，可以在用户按下 Home 后把高亮移回原选项。接着按 Enter 会提交意外的选项。

## Decision

仅在指针移动时用指针位置更新高亮。菜单打开、滚动和焦点引起的悬停事件不参与高亮选择。触屏滚动不更新高亮，点击仍执行选择。

## Alternatives considered

- 在键盘操作后短时间屏蔽鼠标事件。固定时限会影响用户在两种输入方式之间切换，并继续依赖事件顺序。

## Consequences

键盘和指针都可以控制高亮。指针需要移动才会接管键盘选择，点击仍提交目标选项。

## Verification

Chromium 在菜单下方保留鼠标位置，按 Home 后重放悬停事件，再按 Enter。核对选中全部调用凭据且焦点返回触发按钮。
