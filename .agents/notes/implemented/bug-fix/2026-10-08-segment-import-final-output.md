# Agent Note: 分段导入登记默认最终输出

Status: implemented

## Problem

视频剪辑的分段导入直接保存素材引用和画布节点，没有创建节点输出历史。看板通过节点 asset_id 可以播放视频，但输出版本为 0、最终输出未设置，与普通上传的版本行为不一致。

## Decision

视觉工坊 outputs 包提供公开的 register_imported_output 入口，复用自身输出登记规则，来源沿用 uploaded，保持 HTTP 与数据库结构不变。分段交接先在目标画布取得 CAS 写锁，再在同一短事务内提交素材、项目引用、输出历史、节点和任务完成状态。每个片段默认建立 v1 并设为最终输出，登记键使用完整任务 ID 与节点 ID，重复登记不增加版本。文件准备在事务外执行，失败仍清理本次暂存文件。

旧节点通过当前 Workspace 的已完成分段任务确认目标项目、节点与原素材，仅对未改变素材且无历史、无最终输出的节点调用现有节点 outputs POST API。顺序使用最新 revision，冲突停止该项目，不重新编码、上传、提交模型或直接修补持久数据库。已有版本或用户选定的最终输出保留。

## Alternatives considered

前端仅把 asset_id 标成最终输出不能建立可查询、可引用的历史。再次上传会重复媒体文件。读取画布时隐式回填会使只读请求执行写入。新增迁移或裸 SQL 不适合修补运行期业务数据，因此复用正式 API。

## Consequences

新画布与已有画布的分段交接遵守同一版本规则，下游跟随最终输出获得明确的输出身份和 v1 快照。仅下载分段不创建画布历史，失败不留下部分节点或输出。公开登记入口要求调用者已验证项目和素材归属及媒体类型，并持有画布 CAS 写锁；它不独立提交事务。

## Verification

分段往返测试覆盖新建/已有画布、原节点保留、v1 历史与素材一致、重复请求与完成处理、稳定登记键及下游最终输出解析。复制失败、取消和第二个输出登记失败验证整体回滚与文件清理。隔离数据库构造旧导入形状，通过正式 API 验证旧素材复用、版本补齐、CAS 冲突无残留和跨 Workspace 拒绝。官方分段交付正文补充可验证的看板结果。

本次相关后端与架构测试 74 项、看板与技术文档 Web 测试 13 项通过，lint、格式检查、构建及文档中心保护检查通过。契约检查中的 OpenAPI、Web 类型和 SDK 生成物检查通过，既有三篇受保护 SDK 文档被报告过期，未重生成这些文件。Agent Note 校验通过；受沙箱 IPC 限制时直接使用 node --import tsx 运行相同校验脚本。

使用现有已授权桌面 SDK，通过正式 GET API 检查当前空间的已完成分段交接，四个目标项目共 50 条记录：39 个现存节点均已有最终输出，11 个节点已删除，没有需要补齐的候选，未执行任何真实数据写入。本地不含凭据的验收记录保存在被忽略的 .local/output/segment-final-output/legacy-scan.json。
