# Agent Note: 新建文档等待知识库目录

Status: implemented

## Problem

直接打开知识库时，顶部和目录的创建按钮可能先于目录数据出现。此时选择新建会读到尚未加载的知识库 ID 和修订号，导致普通文档及多维表格创建失败。

## Decision

目录数据到达前禁用两个创建入口。创建动作持有已加载的知识库值，并继续由服务端校验所属账号和预期修订。

## Alternatives considered

- 点击后等待目录再提交。用户切换知识库时会留下待执行动作，还需区分触发位置与当前目录。

## Consequences

界面加载完即可创建。目录请求失败时沿用既有的错误与重试提示。

## Verification

隔离 Chromium 延迟真实目录请求，验证两个入口均不可操作，释放请求后创建多维表格并核对回执及目标 URL。原有多表、三视图、正文、CSV 和备份浏览器用例同步通过。
