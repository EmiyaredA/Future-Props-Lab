# Agent Note: 迁移与文档测试恢复

Status: implemented

## Problem

思绪迁移的关联素材核验调用缺少显式清单端标记，社区与外部同步恢复遇到非空素材时提前失败。退役会话测试使用最后一版迁移之前作为历史起点，新版迁移加入后已越过被测边界。视频增强能力未同步 SDK 资源标签及模型类别断言。Web 测试缺少现有浏览器能力和媒体时钟 mock，并将无章节的文章根链接误判为无效。

## Decision

迁移脚本显式标明目标端，保留清单完整性、账号范围、错误上下文和摘要核验。退役测试按各所属服务的具体迁移 ID 建立历史库，随后通过真实迁移器升级到最新，继续验证未结算拒绝、事务回滚、私人资料及非退役成果保留；不改写迁移链。

SDK 参考补齐视频增强资源名称并从现有公开契约重新生成，模型目录断言保留完整集合检查并纳入已有类别。视觉项目指南补充会话与附件章节。此次产品文档更新由用户明确要求修复文档失败授权，提交时与代码及 Note 分开。

文章根链接校验目标文章，含章节链接继续校验章节；源码依据通过同一份显式迁移清单定位到真实文件，不豁免缺失路径。两个文档测试共用定位助手，延续[架构修复](../architecture/2026-11-16-storage-boundaries-and-editor-components.md)的源码归属约束。ResizeObserver 仅在独立入口测试中模拟并恢复，全局浏览器行为不变；标题测试补齐当前预览模块所需媒体时钟能力。

## Alternatives considered

- 删除视频增强类别或放宽类别集合检查会掩盖已有公开能力。
- 去掉迁移中的未结算保护、重建旧表或改写已登记 SQL 会改变数据恢复语义；历史起点错误属于测试夹具。
- 忽略失效源码依据或放宽所有章节断言不能证明链接正确；根链接和章节链接分别检查各自契约。
- 为 JSDOM 修改生产组件或关闭 Amadeus 组合会降低入口覆盖，浏览器能力应由测试环境提供。

## Consequences

修复思绪恢复脚本的调用缺陷，同步既有产品契约和测试环境。公开 API、数据 schema、账号归属与生产配置不变。本机数据均为隔离测试产物，没有部署或操作正式数据库。产品参考及说明文档形成独立补丁；工作区保护检查按设计提示独立提交，不修改或绕过保护脚本。
