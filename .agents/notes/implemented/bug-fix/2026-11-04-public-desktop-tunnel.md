# Agent Note: 公网远程桌面连接中断

Status: implemented

## Problem

公网就绪探针一次失败就终止 SSH 进程。网关短暂错误或构建切换时，健康的 SSH 转发也可能被主动关闭，切断已有桌面会话。浏览器未处理 Guacamole 隧道关闭，首帧前断线时仍会等到画面超时。

## Decision

HTTP 探针只更新公网可达状态并定期复查。SSH 子进程退出才触发自动重连，保留 OpenSSH 的连接超时、转发失败检查和保活机制。浏览器收到隧道关闭事件后立即清理桌面并提示重新连接。

公网连接未收到浏览器帧确认或上游不可用时，服务记录发送字符数、画面分块数、帧同步和保活计数。日志不包含画面、输入内容或认证信息。

公网实测吞吐约 20 KB/s，25 秒内可能传不完 Mac 的高分辨率首帧。公网协商额外允许 guacd 选择 WebP。持续接收图像数据时，浏览器从最近收到的图像数据起最多等待 25 秒，同时将整个连接尝试限制在 90 秒内。转接器从已收到的浏览器隧道 ping 节制地转发 guacd 保活，不刷新用户输入空闲计时。

实测 guacd 即使协商 WebP，也会为高纹理桌面选择 PNG 或生成体积较大的 WebP，并交错发送多个图像流。公网转接按帧暂存有界指令，压缩首帧和后续达到 64 KiB 的桌面图像更新，保持流编号、图块尺寸、透明度与绘制顺序。高纹理图块使用较低细节的预览。低于阈值的后续帧在同步时按原样转发，超过缓冲上限的帧立即透传。

## Alternatives considered

延长首帧等待时间无法恢复已经关闭的连接。累计探针失败次数再重启也可能因网关错误而中断仍在使用的 SSH 隧道。

## Consequences

公网不可达时，界面仍会报告探针失败。SSH 存活时不会为了 HTTP 探针失败重复重建转发，连接真正失效后仍由 SSH 保活与进程退出驱动重连。

## Verification

隔离测试覆盖探针短暂失败后复用同一 SSH 子进程、保活与用户输入计时隔离，以及按入口协商图像格式。浏览器测试覆盖首帧前及画面已显示时收到 WebSocket 关闭，以及持续传输下超过 25 秒才完成的 WebP 首帧。

实机 guacd 对 2940 × 1912 合成 VNC 桌面生成约 12.4 MB 首帧。压缩为约 0.82 MB 后，以实测公网吞吐 20,745 字节/秒回放至 Chrome，原始流超时，压缩流在第 40 秒呈现完整尺寸的桌面。该对照复用生产 guacd，但不使用私人 Mac 画面或凭据。

同一 guacd 的合成 VNC 点击实验在约 72 毫秒内生成后续更新，产生约 2.4 MB WebP 指令。公网转接将该更新压缩至约 0.18 MB，编码额外耗时约 0.21 秒。以 20,745 字节/秒回放，Chrome 在第 9 秒确认完成绘制，原始流在 30 秒内尚未绘制。
