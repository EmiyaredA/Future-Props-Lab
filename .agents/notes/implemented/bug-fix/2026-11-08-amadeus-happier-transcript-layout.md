# Agent Note: Amadeus 会话行与右侧详情

Status: implemented

## Problem

原工具组收起后完全隐藏工具行。查看详情只定位到某次运行，重复出现的助手标题也把连续的输出切割成独立卡片。会话文件预览遮住对话，难以与工具结果对照。

## Decision

按本地 Happier 固定提交 `a2c45c86804b` 的 `MessageView`、`ToolCallsGroupView` 和 `SessionDetailsPanel` 适配 Web。用户消息保留气泡和时间，助手正文平铺，每轮模型与用量集中到轮末。工具组保留最近三条预览，展开后按原序展示全部，逐条以运行和调用标识打开回执。宽屏在聊天旁展示工具或文件详情，窄屏使用面板内覆盖。文件继续由现有账号作用域的预览接口读取，仅当前会话和最新请求可更新预览。

## Alternatives considered

沿用全部收起的检查按钮会多一步展开操作，按运行打开统计也无法准确定位调用。整套原生面板依赖 Happier 的会话、设备和文件权限，FPL 使用自己的运行事件和会话文件。

## Consequences

完整消息和增量按运行内事件顺序归并。工具等交互边界分隔正文段，最终快照复用已显示段落，无法由事件还原的旧回复仍由保存的消息提供。输入框上方显示当前轮的思考、工具执行、输出或停止状态。

会话数据、工具授权和模型配置沿用现有契约。工具组展开状态仍以账号、会话及首条工具标识保存在当前浏览器标签。

## Verification

混合完整消息与多批增量的回归样例在视觉工坊画布分屏验证。运行结束前即可看到工具后的正文和输出状态，刷新后段落不重复，思考和工具的展开状态恢复。

用四条确定性工具调用核对最近三条、展开、逐条选择和回执。Chromium 验证宽屏会话文件和窄屏工具详情，并检查刷新后的展开状态。
