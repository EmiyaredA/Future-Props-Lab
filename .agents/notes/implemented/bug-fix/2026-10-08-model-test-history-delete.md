# Agent Note: 模型测试历史行悬停删除

Status: implemented

## Problem

模型测试只提供当前对话标题栏的删除按钮。清理旧对话必须先切换当前对话，破坏正在查看的上下文；历史列表需要与助手历史一致的悬停操作入口。

## Decision

历史行包含独立的选择按钮与垃圾桶按钮，避免嵌套按钮或由删除点击触发选择。鼠标悬停或键盘聚焦行内控件时显示垃圾桶，并为标题和时间预留空间；无悬停或粗指针设备始终显示。只显示图标不会改变行高。删除入口使用列表摘要中已有的 ID、标题与 revision 打开共享居中确认框，再调用既有正式删除 API。

删除成功立即从查询缓存移除目标，仅在删除当前对话时重选对话。删除其他历史记录保留当前选择和输入草稿。生成或上传期间禁用删除，提交期间禁止重复提交；失败在确认框中显示，保留目标且不自动重试。

## Alternatives considered

先加载并选中历史对话再删除会改变用户正在处理的上下文。嵌套操作按钮不满足 HTML 交互语义，也容易误触选择。仅依赖鼠标悬停会让键盘与触屏用户失去入口，因此保留聚焦显示和触屏常显。

## Consequences

列表中的选择和删除分开触发，标题常态下使用完整宽度。摘要 revision 过期时仍由后端拒绝删除，用户需刷新并重新核对，不静默覆盖。公共 API 与持久化格式保持原契约。

## Verification

组件测试覆盖删除确认与取消、不切换历史目标、未选中对话删除后保留当前选择和草稿、当前对话删除后选择剩余记录、版本错误在确认框内显示且记录保留。浏览器测试覆盖明暗主题下的常态隐藏、悬停与键盘聚焦显示、Tab 顺序、行高稳定、确认范围、删除指定 revision，以及触屏无需悬停可打开与取消确认。
