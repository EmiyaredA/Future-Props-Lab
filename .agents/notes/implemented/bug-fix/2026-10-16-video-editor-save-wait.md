# Agent Note: 视频编辑器保存等待可取消与超时反馈

Status: implemented

## Problem

视频编辑器把后台保存状态传给确认框的 pending 属性，导致离开等待中的取消、关闭及 Escape 全被禁用。时间线保存请求没有期限，响应停滞时保存队列持续 busy，用户无法回到编辑器查看，也无法进入未确认操作处理流程。

## Decision

离开保护只禁用保存期间的放弃操作，允许用户取消离开并返回编辑器。取消清除导航 continuation，不取消后台写入；后续成功不能触发已取消的导航。保持等待时仍在成功后继续导航，失败时仍要求明确放弃。

时间线操作 API 的单次请求使用 30 秒 AbortController 期限，完成或失败均清理定时器。超时映射为本地 save_confirmation_timeout 错误，沿用队列的未确认操作保留、停止后续提交和服务器快照刷新流程。取消响应不表示服务器回滚，因此不重试、不报告确定未落盘，也不绕过 revision 校验。

## Alternatives considered

- 仅开放关闭弹窗：能返回查看，但停滞请求仍让队列永久 busy，缺少后续恢复入口。
- 保存中允许放弃并离开：在途写入结果未知，可能丢失后续本地意图并造成误解，因此保留写入期间的放弃限制。
- 修改所有确认框的 pending 行为：会改变其他提交和删除操作的保护，改为仅调整此处调用语义。

## Consequences

后台保存不会独占弹窗交互。30 秒期限会把慢响应作为结果未确认处理，用户需要核对服务器快照后决定后续编辑；此阈值不影响上传或渲染请求。未确认操作仍仅保留在当前编辑器内存中。

## Verification

- 保存保护测试覆盖等待成功、按钮/关闭/Escape 取消、取消后禁止迟到导航、未保存关闭保护及等待失败后显式放弃。
- API 测试覆盖停滞响应中止、无自动重试、请求身份保持，以及成功和失败后的期限清理。
- 现有保存队列和错误反馈测试覆盖失败意图保留、后续提交暂停及项目生命周期隔离。
