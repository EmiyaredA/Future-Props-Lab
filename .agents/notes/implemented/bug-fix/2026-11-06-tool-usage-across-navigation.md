# Agent Note: 工具导航跨页面保留使用记录

Status: implemented

## Problem

独立工具站打开内置工具时会加载新文档。旧点击流程先请求跳转，再通过异步 mutation 发送使用记录。浏览器可能先卸载旧页，丢失最近使用记录和使用次数。

## Decision

先通过共用鉴权客户端发送允许跨导航继续的 POST，再打开内置工具。打开页面只依赖请求发出，确认仍由 mutation 处理。外链同步打开新标签页，继续遵守浏览器的弹窗规则。只读账号直接打开工具。使用次数的未知写入不自动重试。

## Alternatives considered

- 等服务端回执再打开内置工具。工具页进入速度会依赖记账服务的响应。
- 导航后由目标页记账。直接访问和刷新需要额外区分一次性来源，容易重复累加。

## Consequences

页面切换保留正在发送的会话请求。兼容网站继续使用原有的乐观更新、结果合并和失败提示，独立站返回工具列表时重新读取账号状态。

## Verification

浏览器回归延迟记账回执，检查请求发出时的页面、保活标记和目标页面就绪。独立 Compose 复查每次实际文档导航后的持久使用次数。
