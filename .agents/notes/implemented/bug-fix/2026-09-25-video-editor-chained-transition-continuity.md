# Agent Note: 连续接缝转场的画面时间连续性

Status: implemented

相关：[导出转场本地时间](./2026-09-22-video-editor-export-transition-local-time.md)

## Problem

一个片段同时有入场和出场接缝时，旧 evaluator 按保存顺序挑第一个关联转场，可能先正常绘制片段，再由后一个片段触发接缝而重复取帧。入场非闪白转场带来的半窗时间偏移只在普通绘制中保留，进入下一次转场时丢失。2 秒入场转场会让下次出场回退约 1 秒。预览存在相同的转场选择问题，还会漏掉已过时间线终点、仍应参与淡出的片段。媒体时间提前到片尾时直接跳过图层也会造成提前黑屏。

## Decision

后端和 Web 按当前时间选择活动接缝，已参与接缝的片段不重复绘制。所有取帧分支使用相同的入场半窗偏移，包含后续出场与闪白；媒体时间到片尾后定格，图层持续到时间线或活动接缝结束。片段边缘淡入淡出仍按时间线本地时间计算。

保留既有非闪白转场提前播放入场素材的语义，不改工程文档、源入点、播放速度或音频映射，也不改导出解码和连续编码策略。

## Alternatives considered

- 只修改解码器 seek：不能纠正 evaluator 已经请求了更早时间的问题。
- 只排序转场：一个片段仍有两个接缝，保存顺序不能替代活动窗口判断。
- 取消入场半窗偏移：会重新引入转场结束时回放已播内容的问题。

## Consequences

连续接缝不再因偏移丢失或重复取帧回跳，普通片尾不会因提前耗尽媒体范围而消失。沿用当前手柄不足时的定格语义；没有新增源片尾之外的读取或修改持久数据。多个接缝窗口相互重叠的混合策略不在本次改动范围内。

## Verification

- 后端连续三片段测试覆盖 crossfade、wipe、zoom、blur、flash，正反保存顺序、单帧单次取样、时间单调和片尾保留。
- Web 同场景验证出场后半段仍包含两个图层，入场时间连续且不提前消失。
- 临时生成带 B 帧、2 秒 GOP 的 H.264 素材，验证短 seek、超过 10 秒的 seek 和变速取帧；真实 30/60 FPS MP4 导出解码检查第二次转场边界的画面时间。
- 测试只使用临时素材与隔离数据库，不访问桌面正式数据。
- 转场、解码取消与真实视频回归共 32 项通过；视频编辑器 Web 25 个文件、192 项通过。改动文件 Ruff、Prettier、ESLint 和 Note/文档保护检查通过。
- 扩大后端与架构检查为 157 通过、20 失败；用 HEAD evaluator 在内存中复核，15 项波纹变速撤销与 5 项架构/文档/文件体量失败仍然存在。完整构建在既有 `vendor/pi/packages/agent/src/node.ts` 引用缺失的 `harness/env/nodejs.ts` 时阻断。本次不修改这些独立问题。
