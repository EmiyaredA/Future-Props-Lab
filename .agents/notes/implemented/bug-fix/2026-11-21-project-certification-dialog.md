# Agent Note: 官方标记弹窗与画布新增入口整理

Status: implemented

## Problem

官方标记弹窗在项目列表使用管理端的弹层组件，但组件未独立导入样式。
首次直接进入工坊时缺少可靠的遮罩和居中布局，旧页面样式还会让关闭按钮换行、操作按钮挤在左侧。
嵌入项目工作台的画布还显示一个与侧栏新建重复的悬浮加号。

## Decision

管理弹层自行导入拥有的样式，使用具名遮罩提供固定定位、可见视口约束与居中，避免依赖访问过其他页面。
官方标记使用局部紧凑样式：标题和关闭按钮同排，作品名称独立展示，明确动作按钮右对齐。
保存中统一锁定关闭、取消和确认；失败继续保留弹层供复核或重试，账号权限与 CAS 请求不变。
项目工作台去掉独立加号，保留侧栏创建和右键菜单；独立画布工具栏不受影响。
顶栏视图切换显式启用指针事件，避免画布透明工具层的样式加载顺序使按钮无法点击。

## Alternatives considered

- 仅为项目页复制管理端整套样式：继续依赖入口与 CSS 加载顺序，并扩大页面样式耦合。
- 删除所有新增入口：不符合用户仅删除画布顶部重复按钮的范围。

## Consequences

不改变认证权限、认证值或 API，不对真实作品执行认证操作。新增入口收敛到现有侧栏，创建、避让与保存机制不变。
遵循[开发与验证流程](../../../../docs/operations/development-workflow.md)的明暗、窄屏与键盘验证要求，
以及[能力实现契约](../../../../docs/architecture/capability-contracts.md)的工作台与账号隔离约束。

- 既有治理测试继续覆盖认证所需权限；画布节点与布局测试验证加号移除后侧栏新建、右键新增和避让。
