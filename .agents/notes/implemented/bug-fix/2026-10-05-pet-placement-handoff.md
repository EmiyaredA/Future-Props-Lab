# Agent Note: 桌宠最终放置保持画面世界位置

Status: implemented

## Problem

完整隔离 App 松手的同一原画帧，在最终宿主位置确认与 React 运动帧交接之间出现 20 DIP 一帧跳。稳定终点仅约 0.3 DIP 误差掩盖了中间故障；提前切待机会在移动前先出现相反偏移。仅调状态更新顺序或缩短回执延迟不能保证连续。

## Decision

私有渲染器控制接口按手势代次开始、提交或取消放置交接。开始记录实际已绘且按 0.1 DIP 取整的外层根位置，待最终位置确认期间按真实窗口屏幕原点变化补偿完整角色；确认该代次的非拎起输入被绘制流程消费后，在同一次交接中释放旧登记并恢复放下。不再次扣除旧 placementShift，不把人物模型缩放乘到屏幕位移。

轨迹 hook 持有代次与最终确认，运行页仅转发公开接口。WhaleRenderer 提供 window.screenX/Y 加宿主元素位置的真实 DIP 原点；当前 CTM 包含补偿，几何采样缓存随实际绘制失效。缺少真实原点的旧嵌入不启用此控制，不伪造零原点。新抓取、取消、捕获丢失、暂停、外部环境变化、资源 revision、尺寸变化和卸载释放旧交接；迟到回执不能提交新交接。缺失取消回执、最终确认、桥或几何时安全退出并报告原因。

## Alternatives considered

- 提前设置待机帧：会在宿主移动前向相反方向闪跳，未采用。
- flushSync 缩短 React 延迟：不能保证 IPC 移动与绘制原子，未作为正确性方案。
- 只看稳定终点：真实逐rAF已经证明掩盖中间故障，未采用。

## Consequences

只增加私有渲染器可选控制接口与 hook 的资源版本输入；不修改桌面 IPC、公共 API、数据库、素材或原有预览校验。此机制解决放置交接的世界位置登记，不修复原画人体比例、缺失动作、服饰断缝或支撑原画。原生系统合成帧与 DOM 世界登记分开验收；Mac 锁屏时不能将后者当作前者通过。未合格动作素材仍不得应用到正式资源。
