# Agent Note: 演示文稿导出进度与保存回执

Status: implemented

## Problem

PPTX 主按钮和导出菜单分别执行生成逻辑，主按钮仅显示短暂忙碌文字。Blob 下载没有保存回执，用户无法区分正在生成、取消保存、写入失败或文件已经落盘，也无法从应用找到输出位置。

## Decision

两个 PPTX 入口共用导出弹窗与正式版本快照、转换预检和导出 API。弹窗显示保存、检查、生成和文件保存阶段，进度条不虚构百分比。转换差异仍需确认，失败不自动重新提交。

桌面壳通过固定 IPC 接收有界的 PPTX、JSON 或文稿包字节和文件名，验证可信主窗口与参数后弹出原生另存为。路径只来自用户选择；先写同目录独占临时文件，再原子替换目标，成功后才返回完整路径和绑定当前窗口的定位回执。定位接口不接受任意文件路径，窗口销毁时清理回执。

取消或保存失败保留弹窗内生成的 Blob，可重新选择位置而不重新生成；关闭弹窗即释放引用。浏览器及旧桌面桥接只报告下载交接，位置由下载列表或保存窗口提供，不报告磁盘保存成功。图片与 PDF 保留原有渲染及打印流程。

## Alternatives considered

- 仅延长按钮忙碌文字：无法反映保存成功、取消或位置。
- 继续依赖 Electron 的下载对话框配置：渲染层仍无法取得实际保存回执，取消与写入失败也无法可靠反馈。
- 新增持久化导出任务和百分比接口：本次仅解决现有请求内导出的反馈与本地交付，不增加后台状态和迁移。

## Consequences

桌面原生另存为和文件定位需要应用 Electron 更新。文件生成阶段没有服务端逐页进度，因此使用不定量进度。原生保存桥接限制内容为 256 MiB，防止无限制 IPC 载荷；仅当前窗口最近一次成功导出可通过回执定位。

## Verification

- Web 演示相关 307 项测试通过，含 8 项新测试覆盖自动启动、生成与保存进度、重复点击、差异确认、版本冲突、取消重选、保存失败重试、路径和定位错误及浏览器下载交接。
- 桌面 51 项测试通过，含 5 项新测试使用仓库忽略目录中的隔离文件验证真实字节写入、取消、可信来源和参数边界、并发保存、原子替换失败清理和回执隔离。
- 两项专项浏览器旅程通过：真实 PPTX 下载与进度，及模拟桌面保存回执的取消重选、文件定位、明暗主题和窄屏显示。原生保存调用由桌面测试替换对话框返回值，再验证实际文件字节；未对正式数据执行原生另存为。
- Web 构建、Web／桌面 TypeScript 和 lint、桌面格式、改动文件格式、官方导入包同步、Note 与文档中心保护检查通过。
- 扩大的浏览器检查有 3 项既有失败：两个编辑器响应式横向溢出断言、一个只读文稿按钮定位歧义。全局 Web 格式检查另报 6 个未改动文件；本次保留这些路径，不以扩大修复范围消除失败。
