# Agent Note: 模型测试字号与语音合成布局统一

Status: implemented

## Problem

语音合成隐藏公共测试标题并覆盖页签样式，双栏布局与其他生成模式不一致。文字、面板和输入区留白偏大，窄屏需要长距离滚动才能切换文稿与结果。

## Decision

模型测试头部共用字号和触屏控件尺寸，各模式保留自有内容样式。语音合成使用已有生成测试网格与紧凑面板契约，桌面按历史、结果、参数排列；窄屏使用共用的测试结果、参数与资源、历史记录按钮。

草稿与任务状态仍由原控制器持有，切换面板不卸载文稿；提交成功和选择历史记录后显示结果面板。历史包含当前选中记录并标记选中状态。上传、播放、保存、账号归属和任务请求契约保持原行为。

## Alternatives considered

- 仅缩小独立双栏的字号仍保留与其他模式不同的导航和交互，因此采用已有三栏及面板切换。
- 全局缩放会影响其他页面和结果阅读，因此只调整模型测试所属样式，保留已有小字号。

## Consequences

紧凑面板 hook 显式提供设置当前面板的方法，业务调用方在提交和历史选择后控制展示；不增加隐含状态或跨功能依赖。此前加载动画改动保留，无 API、数据库和权限变更。

## Verification

通过相关组件测试及隔离浏览器验收，覆盖六模式、明暗主题、六种宽度、语音上传与播放、保存和面板切换草稿保留。截图及检查日志保存在 `.local/model-test-density/`。
