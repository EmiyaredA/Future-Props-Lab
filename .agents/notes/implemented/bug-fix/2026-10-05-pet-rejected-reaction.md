# Agent Note: 拒绝缺失反应前停止旧物理

Status: implemented

## Problem

完整帧缺少点击跳跃时，播放器保留正确画面，但事件先让旧引擎进入 crouch/air；外层根位置仍上移。此前实际隔离 App 的短点，宿主不移动、原帧不变，仍出现约 7.4 DIP 单次和 13.7 DIP 累计上移。仅暂停自主控制器不能阻止这条事件物理路径，聊天反应也能从另一入口进入。

## Decision

WhaleRenderer 在事件和聊天反应开始前按资源读取状态、已知动作的 own-key 和当前渲染模式检查能力；缺少已知动作是资源提示，未知 ID 或非法描述仍是错误。停用的版本 1 人物动作保持缺少资源的语义，无关节描述的原鲸鱼路径保持兼容。

公开 replaceRejectedReaction 不调用 act，停止旧反应速度和脉冲，并保留实际已安装、按原引擎精度取整的根位置。SequenceFigure 通过独立公开拒绝接口保留最后已绘完整帧、图集请求与播放位置；同名但不符合播放模式的图集不加载。时间、可用表情和完整事件 1800 毫秒恢复规则仍推进，不冻结整个引擎。

手动拎起、真实运动、最终放置交接和已有松手缓动优先，结束后按实际已绘位置重新保留，不跳回拒绝前的位置。下一次有效反应只清除拒绝状态；图集解码、接触登记和支撑失败仍优先反馈。取消不能静默把缺少资源变为成功。私有 renderer/figure 接口变化不新增数据库字段、宿主协议或公共 API。

## Alternatives considered

- 只暂停 locomotion：无法停止先进入的 crouch/air，实际复现否定。
- 伪造 hop 渲染模式或同名片段：会绕过实际能力或播放错误图集，未采用。
- 冻结整个时钟或所有根位置：会阻止表情到期、完整事件恢复和手动放置，未采用。
- 重建渲染器或恢复旧分件：破坏已绘画面与资源生命周期，不用于缺项恢复。

## Consequences

缺失反应保留现有画面并反馈原因，不能据此宣称新动作已完成。合法动作开始后的动态支撑失败仍由原严格播放器检查，本入口修复不替代该检查。完整帧中的五官仍来自完整原画，不叠加旧皮肤块。正式素材、持久数据与 App 未更新。
