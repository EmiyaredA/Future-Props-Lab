# Agent Note: 演示连接线键盘删除与历史

Status: implemented

## Problem

连接线有独立于普通元素的选区，画布删除快捷键只处理普通元素，导致选中连接线后无法用键盘删除。

## Decision

画布快捷键在已有连接线选中时复用属性面板的删除操作；输入控件继续保留自身键盘行为。删除通过文稿提交进入既有历史，并将焦点交还画布以支持立即撤销和重做。未提交的连接预览不视为可删除的已有连接。

## Alternatives considered

将连接线混入普通元素选区会改变现有选择和命令契约，超出本次修复范围。

## Consequences

Backspace 和 Delete 对已有连接线生效，Ctrl/Cmd+Z 与重做使用既有文稿历史；属性面板与键盘入口共用删除规则。

## Verification

演示编辑器组件测试覆盖两种删除键、输入框隔离、删除后的焦点、撤销与重做；连接面板测试覆盖面板删除和历史。
