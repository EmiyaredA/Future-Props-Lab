# Agent Note: 完整人物的头部点击与悬停按钮通路

Status: implemented

## Problem

可见像素命中修复后，弯腰人物的脸仍按宿主窗口高度判为身体。实际隔离 v2 短点脸触发 click，不能以鼠标命中通过代替摸头分类通过。另一处实际桥探针证明：从脸移到 alpha0 空白后，宿主仍收到 interactive=true；原按钮通路覆盖整个角色宿主至窗口底部，阻挡透明区域下的桌面。

## Decision

渲染器公开可选 classifyHit，结果为 head、body、null 或 undefined。完整序列先验证当前成功绘制原图的可见像素，再用已绘帧冠顶至下巴轴的有限椭圆分类。轴随完整帧平移和实际安装变换投影，不借用下一张未解码图或宿主矩形。null 是权威未命中；只有没有能力的 undefined 保留基础人物与 Live2D 原热区。编辑器鼠标沿用相同分类，键盘 detail=0 仍可试听。

interaction.ts 拥有实际按钮栏命中及纯 actionTrayPath。输入来自当前 client 指针、渲染器公开可见范围、已显示栏的实际矩形和最近真实像素命中点。实际栏包括按钮间隙，避免穿过间隙先收起栏；仅栏外通路才读取角色几何。栏须完全在角色上方或下方，相邻间隔不超过96 DIP；最近真实点须距对应角色边不超过8 DIP，并经当前公开 hitTest 复验仍可见。只连接该点横向8 DIP以内至实际栏的短通路，不填补头身其他透明区。没有栏／真实点／几何、非有限尺寸、相交布局或测量异常拒绝连接。运行页先检查实际按钮／状态及角色像素，按钮不伪造角色点；当前几何逐次校验，不保存旧窗口通路或引擎内部状态。

几何采样和动作栏 ref 均为当前实例的公开能力，不共享可变内部状态；失败后保留转发的鼠标移动入口，进入真实角色或按钮可重新恢复交互。没有配置写入、公共接口、数据库迁移、运动轨迹或原画像素变化。

## Alternatives considered

- 继续按宿主高度分头身：完整人物前弯时脸、靴子与长发的关系无法由同一个矩形上下切分表达。
- 扩大原圆或整窗悬停区域：重复接纳透明空白，实际桥探针已复现阻挡。
- 完全取消按钮通路：保留真实按钮命中，但经过角色至按钮间隙时栏会先收起；有限相邻通路保留可达性。

## Consequences

头部椭圆是外观交互区域，不能当作人体语义分割或严格骨骼边界。旧包及 Live2D 未实现该分类时保留原行为；无几何不扩大透明区域，实际按钮仍可被转发鼠标移动重新命中。上下短通路暂时接收交互，其外恢复穿透请求；不宣称系统级点击穿透已完成。

原 v2 face→click、桥探针失败与未知正式WAL变化保留在[前一修复](2026-10-06-pet-sequence-hit.md)，不重写历史失败。当前衣身完整的小幅悬挂候选仍不代表站姿进入、放下、四边支撑或全部服饰通过；不将未通过动作应用到正式资源。
