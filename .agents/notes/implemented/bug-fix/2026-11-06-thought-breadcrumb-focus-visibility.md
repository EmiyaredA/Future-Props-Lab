# Agent Note: 窄屏文档路径显示键盘焦点

Status: implemented

## Problem

窄屏路径栏会横向滚动。浏览器把焦点移到被裁切的父文档按钮时，路径栏有时停在原处。用户可以按回车打开父文档，但看不到已聚焦的按钮。

## Decision

私人文档路径栏收到焦点后，对照按钮和滚动容器的实际边界，只调整该容器的横向滚动。已有可见焦点保持原位。

## Alternatives considered

- 将路径项挤入可用宽度。层级较深时会压缩所有可点击标题。
- 调用全页滚动到焦点。可能同时改变编辑器纵向位置和已保存的阅读进度。

## Consequences

窄屏焦点沿原有 DOM 顺序移动。路径栏自身滚动，正文位置和当前文档保持不受影响。

## Verification

Chromium 验证父文档键盘导航、未保存保护和 390px 路径栏。在容器移到末端后抑制浏览器的默认焦点滚动，仍能看到获得焦点的起始按钮。
