# Agent Note: 知识库内外导航分离

Status: implemented

## Problem

思绪工坊的全局入口与当前知识库的搜索、视图和目录同时显示，重复的导航占用目录空间。普通知识库因传入全局入口而失去独立返回按钮；官方与社区正文也插入同一组全局导航。

## Decision

KnowledgeSidebar 仅在库外展示全局入口与“搜索与最近访问”。普通知识库内保持单一“我的知识库”返回按钮、库内搜索、视图和父子目录。官方与社区知识库只保留返回“知识社区”、库内搜索和目录。官方阅读页不再接收全局导航回调。

返回沿用现有页面导航和未保存保护。社区返回按钮经编辑器 guard 执行；原知识库返回经应用导航保护执行。弹窗、主题和目录数据生命周期保持既有行为。全局搜索从知识库列表打开，使用指南同步说明入口位置。

## Alternatives considered

- 缩小所有导航按钮：仍然同时混合全局与库内职责，目录空间不足。
- 将全局入口折叠进库内菜单：用户明确要求只在库外展示，因此保留单一返回入口。

## Consequences

进入知识库后需要先返回列表再切换全局栏目，目录得到更多可用空间。普通、只读、社区和官方入口使用相同导航层级。不改变文章 ID、URL、正文、权限、数据库或图形契约。

## Verification

- 侧栏组件回归覆盖可编辑与只读入口，验证库外全局导航、库内搜索与视图、键盘返回和回到库外后入口恢复。
- 隔离浏览器测试覆盖普通、社区与官方库在 390/768/1600 宽度、明暗主题和移动抽屉中的导航；刷新后用键盘返回并检查全局入口恢复。
- 社区编辑与普通笔记未保存返回继续显示保护弹窗，取消后保留正文。
- 运行相关组件、浏览器、构建、改动文件 lint/格式及文档保护检查。
