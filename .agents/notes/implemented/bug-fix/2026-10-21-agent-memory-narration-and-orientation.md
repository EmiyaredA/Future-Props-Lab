# Agent Note: 记忆科普的旁白一致性、叙事入口与阶段导览

Status: implemented

## Problem

用户指出第一集约 42 秒开始音色改变，播放时难以辨认当前项目和步骤，并且视频直接进入原理、缺少“为什么需要记忆”以及项目背景。这些问题不能只靠提高音量、加标题或识别通过解决。旧逐段缓存键只有模型名称、参考描述前缀与文本，没有校验参考录音的实际内容。

## Decision

延续 [四集制作通路](../process/2026-10-21-agent-memory-four-episode-production.md)，修订仍隔离在 `.local/research/agent-memory/anatomy-v4/series/`，旧旁白、字幕和成片保留在本任务的 previous-delivery 下。原 42.83 秒处确实是两个独立合成任务的拼接点；不能据此声称换过模型或参考。内部说话人特征显示该段是异常点，作为诊断线索，与用户听感报告一起处理。

新版离线读取已安装的 Qwen3-TTS 1.7B Base 权重，采用项目内原始日语参考，固定转录、参考 SHA256、模型 revision、运行实现 SHA256、语言与采样配置。进程中复用同一说话人向量和参考条件，缓存键包含实际配置与逐段种子覆盖。内部特征只用于标记偏离，不能认证听感或身份；不合格长开场保留并排除，后续将长开场拆为两段自然停顿的短录音。旧 SDK 音轨不混入新版。

开场先建立长期 Agent 合作的期待，再通过跨会话偏好与旧地址问题解释记忆管理。九个项目分别先交代维护组织或研究团队、目标和 GitHub 关注度，再进入机制。精确 API 快照与页面近似值分开记录，标注 2026-10-21 查询日期，Star 不作为能力排行。新增概念分镜只用于构图，文字、状态与动作仍通过连续 2D 场景实现。

导航由独立数据映射统一提供“集数 → 项目或主题 → 当前步骤”，视频与交互画面共用。播放器时间变化和主动跳转同步更新当前章节，导入阶段明确说明尚未进入项目。新音轨重新驱动字幕、口型与时间线，不将不同时长的新录音直接混入旧视频。

两个对齐进程曾共用一个临时音频窗口，导致 ASR 读到另一段的内容。窗口现按段落、窗口时间与进程命名，旧结果归档后重做；音轨本身没有被该问题修改。后续剧集压缩额外片头、片尾和段间空白，保留原句首句尾余量，不通过改音高或裁掉正文压缩时长。编码在临时位置完成双版本后发布，失败不会主动重提外部模型任务。

## Alternatives considered

统一响度只改变播放音量，不能修复音色漂移。只固定随机种子也不能保证每次克隆听感一致。继续沿用旧缓存缺乏参考条件证据；直接重封装新旁白会使字幕和口型错位。用静态标题页补齐开场不能代替问题引入和连续动画。不同项目 Star 或异条件评测成绩不适合构造性能榜单。

## Consequences

四集采用同一参考条件的日语合成讲解，仍使用 Q 版真由理案例和红莉栖讲解形象。正文增加开场与九个项目背景，阶段信息进入实际视频和本地交互页。研究与制作源码继续区分源码阅读、教学示意、实际运行验证和仍需人工听审的范围。产品 API、数据库、模型配置和现有工程依赖均不修改。

## Risks

零样本克隆仍可能发生语气变化、音色偏移或尾部退化，内部说话人特征和 ASR 均不能代替人工听审。缓存同一条件不等于输出质量保证。Star 随时间变化，页面近似值不可伪装成精确计数。制作源、时间线与发布的视频必须一同更新，不能把旧版验证摘要用于新版。
