# Agent Note: 视觉工坊内部导航保持当前网页

Status: implemented

## Problem

独立视觉入口的侧栏、画布与项目素材跳转调用 `location.assign`，每次重新加载 HTML、身份与助手上下文，
造成全屏闪烁和重复请求。直接替换为 History 导航又会绕过原先依赖 `beforeunload` 的剧本、预演离开检查。

## Decision

按 Studio 框架的 Web 装配边界，将浏览器机制放在 `app/routing/useApplicationNavigation.ts`。
入口提供路径归属，工坊内使用 History，跨应用加载目标文档。普通内部链接也走相同机制，
新窗口、修饰键和下载保留浏览器行为。懒加载边界放在视觉入口的内容区，侧栏与外层身份、助手保持挂载。

历史条目携带当前应用的索引；被编辑功能拦截的 Back/Forward 先恢复游标，确认后重放同一历史移动，
取消不新增条目或清除前进记录。导航成功通知已有助手来源订阅。

共享导航保护提供生命周期绑定的功能 Guard 注册。画布在保存中阻止放弃，错误和冲突要求用户确认；
剧本与白模复用已有保存后离开过程，失败留在编辑器展示原错误。项目 ID 改变时重新挂载项目组件。

## Alternatives considered

- 只隐藏全屏加载动画：不能避免文档重载与上下文重建。
- 将独立入口接到兼容网站的总路由：引入其他工坊注册与页面依赖，破坏独立装配边界。
- 拦截 Back 后新增当前路径：会丢弃原来的 Forward 记录。

## Consequences

工坊内部切页保留当前 Document 和账号上下文。实际页面数据仍按原权限与查询键读取。
跨应用导航、刷新与新窗口仍是文档导航；这项修改不改变服务路由或后端接口。

## Verification

- 平台导航回归覆盖内部切页、查询和 hash、Back/Forward、未保存拦截、链接手势和卸载授权隔离。
- 隔离 Playwright 旅程检查独立视觉入口没有新增 Document 请求、侧栏在切页时保留、项目画布和素材可达，
  并检查浏览器返回先保存剧本。可再生成的验收证据归 `.local/visual-navigation-20261121/`。
- 相关前端 45 个文件的 256 项回归、126 项架构测试通过。Chrome 旅程同时验证保存失败不离开编辑器、
  重试成功后正常离开，以及跨应用才加载新文档。类型、变更文件 ESLint/Prettier 与视觉独立入口构建通过。
