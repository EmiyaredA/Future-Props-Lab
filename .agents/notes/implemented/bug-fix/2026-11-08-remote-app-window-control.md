# Agent Note: 远程应用窗口与键鼠状态

Status: implemented

## Problem

默认连接可能选中 Chrome 的辅助采集面。窗口的阴影或采集留边会让视频内容与输入坐标所用的窗口边界错位。浏览器收到画面后直接显示已连接，目标窗口失焦和键鼠通道未打开时没有操作反馈。

## Decision

从 ScreenCaptureKit 列表优先使用能匹配辅助功能窗口的候选，把聚焦窗口排在第一位。采集不包含阴影，输出按同一窗口边界缩放。Web 画面限制在内容区内，保留等比适配与点位映射。

Host 发布目标窗口的键鼠就绪状态。Web 分别判断首帧、键鼠通道和目标窗口焦点。失焦时保留画面并暂停键鼠，用户可通过现有连接流程恢复目标窗口焦点。指针命中支持经 AX 父节点确认所属窗口。

## Alternatives considered

- 只调 Web 缩放会放大采集帧里已有的留边，且无法修复默认窗口选择。
- 在每次收到键鼠时自动抢占 Mac 前台会干扰本机操作，因此焦点恢复由用户触发。

## Consequences

站点和 Mac 辅助程序需一起更新才能显示主机焦点状态。更新签名后按云控指南复核屏幕录制和辅助功能授权。

## Verification

云控浏览器用例验证短屏和桌面的画面边界、等比点击坐标及键鼠状态。Mac 辅助程序通过编译和签名校验，真实键鼠验收需要新签名的隔离辅助程序获得 macOS 授权。
