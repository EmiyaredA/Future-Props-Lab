# Agent Note: Amadeus 历史行内重命名

Status: implemented

## Problem

历史对话的重命名在列表末尾展开独立表单，离目标对话较远。长列表里用户难以确认编辑的是哪一行，且表单挤占可视空间。

## Decision

重命名输入替换目标行的标题与悬停操作区。进入编辑自动聚焦并选中原名称；回车或勾选按钮保存，Esc 或取消按钮退出。输入最大 120 字，提交前去掉首尾空白，空名称不可提交，中文输入法选词回车不提交。失焦保留草稿，不隐式保存。

保存调用原有 conversationActions.rename，保留正式 API 的 revision 校验。保存期间禁用输入与重复提交；失败保留行内草稿并显示错误。发生冲突仍更新目标快照、保持草稿且不自动重试。历史搜索显式保留正在编辑的目标 ID，避免服务器刷新后的标题变化让编辑行消失。退出后焦点回到该行标题。

删除确认与悬停操作沿用 [居中删除确认决策](2026-10-08-amadeus-conversation-delete-dialog.md)，编辑时不另建列表底部表单。

## Alternatives considered

保留底部表单或改成独立模态框仍会让重命名脱离目标行。失焦自动提交使切换焦点也触发写入；采用明确的保存与取消，失败时让用户继续核对草稿。

## Consequences

正常编辑保持行高和列表位置，不切换所编辑的历史对话。只有一行处于编辑状态，其他行的重命名与删除在提交期间禁用。删除后的旧表单样式与深色覆盖规则移除。公共 API 与持久化格式保持原契约。

## Verification

组件测试覆盖输入属于原行、自动焦点与选中、回车保存与空白修剪、取消与焦点恢复、空名称及输入法回车保护、保存期间禁止重复提交、失败后草稿与错误保留，以及搜索保留编辑目标。既有实际用例测试覆盖冲突快照更新且不自动重提。

隔离 Electron 烟测在 400px 与 900px 窗口、明暗主题下核验编辑器位置、行高、无横向溢出与取消不写入，并通过正式 API 读取确认回车保存的名称。输入与两个固定宽度按钮采用网格排列；逐一聚焦时核验焦点描边仍在行内，且不与相邻控件重叠。
