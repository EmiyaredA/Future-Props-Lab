# Agent Note: 完整原帧保持固定显示方向与比例

Status: implemented

## Problem

完整帧使用统一画布和模型比例，但鼠标停到角色左侧时，core 的旧转向插值仍将外层横向比例由 +1 经零压到 −1。真实公开 pointerMove→step→SequenceFigure 连续100帧复现同一原图宽度从203.0848 DIP压到11.2128 DIP；下一次按住又恢复正向，源登记标记横跳95.199 DIP。统一图片外框或修正固定抓点不能消除这层显示坐标变化。

## Decision

私有 WhaleFigure 增加可选只读 groupFacing，用于原画显示基准，与请求运动朝向分开。Core 只接受确切 ±1；没有能力或非法返回沿用原逻辑。完整序列返回 +1，左右物理运动继续选择相应的完整原图片段，不做外层压窄或镜像。当前停用旧运动的版本 1 人物只有正面站姿、坐姿和表情，也仅对这个路径条件声明 +1；无 rig 人物、authored v2、旧鲸鱼与 Live2D 的策略不改变。

固定显示基准不新增转身能力，不跳过片段或支撑校验，不恢复旧分件动画。抓取仍通过[固定P0入口](2026-10-05-pet-held-pickup-entry.md)和原外层缓动分工；[加载错误恢复](2026-10-05-pet-sequence-asset-failure.md)、待机计时、换装、失败保留画面与隐藏表面释放沿用既有生命周期。只有四个生产文件与独立新测试增量修改；原未提交工作保留。

## Alternatives considered

- 对所有 figure 使用 abs(scale)：会破坏旧朝向语义，也没有表达原画与请求方向的职责差异。
- 将插值改成瞬时镜像：不会压瘪，但完整原画的抓点和已绘世界位置仍突然翻面。
- 所有人物禁用转向：会扩大到未复现的无 rig／authored v2路径，改变已支持的行为。
- 重新缩放每个动作画布：无法修复外层转向，还会隐藏素材比例错误。

## Consequences

显示基准只在内存中消费，不新增数据库、公共API、IPC、资源字段或CAS写入。缺少左右或转身原画仍准确反馈。修复外层压窄不证明新素材的头部、五官、骨段、世界支撑或自然动作一致；未通过视觉验收的候选不应用。相同完整帧仍会重复绘制，paint-key缓存未在本次实现，Chromium tile警告根因未确定。
