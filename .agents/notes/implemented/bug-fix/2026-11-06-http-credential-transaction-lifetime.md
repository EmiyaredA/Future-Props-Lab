# Agent Note: HTTP 凭据事务在业务处理前释放

Status: implemented

## Problem

HTTP 鉴权与业务请求共用一个数据库会话。读取凭据后，这个会话可以保持连接到响应结束。兼容站媒体预览另借素材连接，许多并发请求会各自先占用鉴权连接，随后等待素材查询，耗尽连接池。

## Decision

Identity HTTP 适配器注入凭据会话工厂。账号、Session、API Key 与活动时间更新在短会话内处理。关闭凭据会话后，将已核验身份写入请求，并将账号绑定到业务会话。

## Alternatives considered

- 扩大连接池。达到新容量时仍可能发生同样的互相等待。
- 对调用者的会话执行回滚。业务会话与凭据适配器的事务责任会混在一起。

## Consequences

鉴权不占用业务预览或流式发送期间的数据库连接。身份断言、账号归属和凭据活动更新继续沿用原有规则。
