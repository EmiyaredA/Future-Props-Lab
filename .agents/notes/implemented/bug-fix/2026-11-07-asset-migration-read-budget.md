# Agent Note: 素材迁移清单读取预算

Status: implemented

## Problem

完整素材清单会在发送响应前读取并计算所有原件的 SHA256。正式迁移的连接错误没有记录请求阶段，排查时无法区分清单计算、原件传输和回执读取。

## Decision

只为原件清单增加读取预算。连接断开时，同一只读清单可以重读一次。素材写入不会自动重试，仍以原有批次回执和源目标 SHA256 比对判定结果。连接错误记录阶段和异常类型。

## Alternatives considered

放宽所有请求的超时会让其他请求故障变得更难定位。跳过原件摘要核验会降低迁移可信度。

## Consequences

慢磁盘上的完整清单有更长的响应时间。连续连接错误和读取超时仍会中止迁移。错误输出不包含请求地址、账号标识或维护凭据。

## Verification

定向用例覆盖清单断连后重读、慢读取预算和超时诊断。隔离回归保留素材写入、读回和重复导入核验。
