# Agent Note: 完整原帧按实际步相收步与转向

Status: implemented

## Problem

旧完整序列每对 from/to 只提供一条平铺过渡。来源行走的不同原帧有不同承重脚及足底位置；把全部来源帧依次塞进通用停步桥，会在宿主停止后播放下一步的原画，从而正确触发支点登记拒绝。独立四帧实际播放器反例只有最后步相能完成停止，其余在 111 ms 拒绝；继续补静图或放宽支撑容差不能解决契约缺口。左右能力入口也未提前检查反向直接桥。

## Decision

私有 frameSequences 版本 1 过渡新增可选 branches，每项仅含 fromFrame 整数索引与 clip ID。新声明必须完整覆盖实际来源每一帧；引用独立非循环、无距离驱动的计时桥，首帧与对应来源图片和所有锚点相同，末帧与目标首帧相同。时长可以不同。后端、Web reader 与播放能力判断使用同一语义，未声明的旧平铺路径兼容。

sequences/transitions.ts 集中纯原帧身份、分支覆盖与直接选择规则；播放器与解码加载消费最后实际已绘片段和帧，不以新目标或旧来源推测当前身体。每个分支保留此前世界支撑、真实位移、失败冻结与取消约束。物理左右行走在启用前检查左右转向桥；途中打断入口同样需要实际过渡片段到新目标的直接资源，缺失时拒绝并保留当前画面，不自动跳回旧来源。

输入仍是授权 ZIP 内的原画与严格 JSON，展示素材继续由现有 Workspace 素材 API 加载，只有既有资源 CAS 保存持久化；本轮没有数据库 schema 或具名 OpenAPI/SDK shape 变化。接口出参原有 whaleModel raw dict 保持不变，不能因此省略资源格式和契约测试。

## Alternatives considered

- 把全部原帧塞进一条通用停步桥：实际反例证明固定宿主后支撑位置不同，既不自然也无法通过正确的世界支撑约束。
- 放宽登记容差或让支撑脚滑回待机：掩盖原画与真实步相不符，保留原 1 DIP 边界。
- 自动规划或镜像过渡：不能产生用户要求的完整自然原画，缺资源时明确保留实际画面。
- 给片段上限开豁免：没有实施。八帧左右行走及逐帧收步/转向的最小闭包可落在 64 片段内；更高帧数、全部四边和更多打断入口仍须在原图片/JSON预算内设计，不宣称全部素材可装。

## Consequences

新作者可明确提供每步相正确的收步姿态，避免运行时跳向一条与当前承重腿不符的通用尾巴。严格首尾注册和支点仍不能证明画中膝盖、比例或服饰自然，必须看实际原画及隔离运行录像；契约完成不表示正式角色包已具备新动画。

本轮图片使用内置 imagegen，原图/prompt/哈希与独立视觉复核保留在忽略的 full-frame-sequences/。短体型 atlas 的全身/头比例接近原站，但重复承重腿、裁格串发仍失败；不能应用失败素材。正式资源、配置、聊天及服饰状态没有本轮写入或覆盖。受保护文档中心未修改。
