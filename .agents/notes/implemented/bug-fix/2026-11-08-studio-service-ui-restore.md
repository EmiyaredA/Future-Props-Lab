# Agent Note: 恢复独立服务的旧版 Studio 界面

Status: implemented

## Problem

工具、集成、AI 能力和创意工坊分别发布浏览器程序。旧独立发布包使用单独的页头，模型页还另设一排导航。从门户进入这些页面时会丢失原来的界面和入口位置。

## Decision

五个浏览器入口沿用旧站的 Studio 壳层及功能页面。模型目录和编程智能体共用旧页头，模型测试和日志由 Studio 侧栏进入。键盘切换在目标页面恢复标签焦点。可读账号沿用 Studio 的助手入口，创意编辑器和集成表单由既有离开保护处理。

## Alternatives considered

回退 Portal 会影响云控和应用目录，四个区块仍会加载各自的独立前端。将它们合回兼容站会改变数据和权限边界。

## Consequences

五个程序继续以原服务和 URL 独立发布。模型测试、调用日志、集成管理和创意编辑的权限继续从当前账号读取。

## Verification

隔离浏览器对照旧站及独立前端的布局、导航和离开保护。发布时核对每个服务的程序清单、接口契约和本机、公网构建号。
