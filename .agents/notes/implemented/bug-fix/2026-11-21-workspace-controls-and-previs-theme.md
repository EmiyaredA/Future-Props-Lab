# Agent Note: 工作区控件、多集展开与白模编辑主题

Status: implemented

## Problem

分镜侧栏按钮层级与其他工作区不一致；剧本目录复用当前编辑集作为展开状态，只能展开一集。白模宿主仅映射部分 Element Plus 变量，产生浅底浅字，3D 天空和地面也不响应应用深色主题。

## Decision

- 三个工作区共用控件尺寸和状态外观，保持 56px 分类栏、280px 固定面板与原有保存保护。
- 画布／看板切换由统一顶栏提供，窄屏通过顶栏更多菜单访问，不在内容区重复占位。侧栏标题与固定／关闭操作为28px行，搜索、筛选和创建操作为32px行；分镜创建与纳入操作并排，其他目录复用相同间距。
- 分镜列表自身滚动，条目保持内容高度且不参与纵向压缩，避免多条数据被挤成边框；紧凑样式不能以缩小可读内容换取列表空间。
- 剧本目录独立维护展开集合和搜索。新建场按目标集 ID 更新，展开、搜索和选择不产生文档写入。
- Truman 宿主完整映射内嵌控件及具名弹层的主题；监听应用 `data-theme`，渲染器同时监听宿主主题变化。
- 深灰只属于编辑显示。编辑帧临时替换背景、地面并隐藏天空网格，使用 `finally` 恢复；机位预览与捕获相机始终渲染原场景，不修改序列化文档。
- 从剧本创建使用侧边面板，先保存原场景；候选与原编辑器轮流持有可见渲染宿主。取消恢复原场景，创建失败保留输入，窄屏禁用创建但保留草稿，离开工作区释放渲染宿主。

## Alternatives considered

- 将展开集与当前编辑集绑定：无法同时浏览多集，也会让跨集操作依赖隐式编辑上下文。
- 通过修改场景材质和天空实现深色：会改变导出和持久数据，超出编辑主题职责。
- 仅修改 React 宿主背景：无法覆盖 Vue 内的浮层、弹出菜单及 Three.js 天空网格。

## Consequences

不新增 API、数据库迁移或持久界面偏好。内嵌主题和交互锁定通过宿主参数传递；临时显示配色必须在所有失败路径恢复。仅隐藏视图按钮中的标签，不能隐藏同一工具行内下拉框的选中文字；主按钮 hover 显式维护前景与背景的对比度。参考素材的详情操作放在图片下方的独立网格行，清除旧列表的三列按钮布局，避免图标、编号和图片互相遮挡；工作台局部视图工具栏在窄屏换行。

## Verification

组件测试覆盖独立展开、搜索恢复、跨集新建、只读和保存失败；渲染辅助测试覆盖正常和异常时的背景、材质、天空恢复。隔离浏览器旅程覆盖控件文字、明暗与 hover 对比度、多尺寸工作区布局、创建保护和恢复，并比较固定场景在明暗主题下的捕获输出。39镜的列表回归先在旧样式复现约7px卡片，再验证明暗主题下桌面、矮窗口和手机宽度的完整卡片、局部滚动、末镜选择、顶栏切换和紧凑工具行。测试、截图和视觉对照报告位于忽略的 `.local/workspace-controls/`，不作为服务依赖。
