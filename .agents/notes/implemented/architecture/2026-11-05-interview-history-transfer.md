# Agent Note: 面试助手场次、任务和原件迁移

Status: implemented

## Problem

面试助手的准备记录和历史报告在数据库内，材料原件存于账号目录。服务拆分需要保留原账号、创建请求回执和场次指向的任务。旧任务可能在准备过程中停止。

## Decision

按场次、材料、准备任务和创建回执导入。保留历史执行者、请求标识、事件、结果和原始修订，验收后由正常启动流程中断尚未完成的旧任务。材料通过按账号、场次和材料 ID 授权的流式维护入口迁入，核对原尺寸、SHA256 及持久回执。已删除场次的创建回执保留原重试行为。

## Alternatives considered

复制整个旧运行目录会携带其他服务的数据。只复制数据库会丢失材料。迁移时重跑准备任务会启动未经用户重新确认的本机进程。

## Consequences

同一批次可在目标重启后继续。已交付报告通过原任务读取。未知材料、归属冲突、缺失文件或任务关系错误会阻止通过。临时执行目录随原封存快照保留。

## Verification
