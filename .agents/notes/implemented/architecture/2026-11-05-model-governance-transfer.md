# Agent Note: 模板同步历史和运行额度迁移

Status: implemented

## Problem

旧站模板同步记录包含管理员发起人、其他账号目标和加密模板快照。额度记录可能绑定 Models 自有任务、其他应用旧任务或已停止的同步请求。

## Decision

以原发起人传输模板同步任务及其目标记录，核对计划账号并验证快照密文。以原账号传输额度，核对历史任务归属。旧站仍占用额度的跨服务任务必须先结清，目标保留已结清的历史引用。Models 自有任务和同步请求继续由已有启动恢复处理。

## Alternatives considered

将目标账号当作任务所有者会分裂同一管理员批次。直接导入活跃跨服务额度会留下独立 Models 无法结清的占用。沿用旧授权会绕过签名来源检查。

## Consequences

缺失账号、错误密钥、归属冲突或未结清的跨服务额度会阻止验收。未获得新版签名授权的旧同步待处理项由执行器跳过，已完成的结果保留。

## Verification

`tests/test_model_governance_transfer.py` 验证加密快照、跨账号同步目标、旧跨服务额度拒绝、重启后的批次重放和启动恢复。
