# Agent Note: Amadeus 对话和运行历史迁移

Status: implemented

## Problem

对话和运行历史分布在六张表中。运行之间有自引用，排序可能先遇到续接后的运行。切换后需要保留事件、已回答问题、外部操作状态和中断时的部分回复。

## Decision

先导入六张表，再在事务内恢复续接边。校验账号、对话、响应消息、完整事件序列和运行图的无环性。批次结果与写入同时持久化。旧活动状态随历史迁入，由正常启动恢复流程把未完成的运行和操作转为中断或待核实。

## Alternatives considered

按创建时间猜测父运行会依赖不稳定的时间顺序。忽略续接边会破坏已保存的运行关系。重新调度旧运行可能重复未知外部操作。

## Consequences

目标重启后可以续跑并核对原回执。跨账号、损坏关系或缺失事件会阻止验收。会话文件另经文件迁移流程验收。

## Verification

`tests/test_amadeus_history_transfer.py` 使用真实维护监听器验证乱序 ID、循环拒绝、重启续跑、跨账号隔离、原事件序列和首次启动恢复。
