# Agent Note: Amadeus 临时工作区与任务客户端

Status: implemented

## Problem

关闭 CLI 内置工具与调整 cwd 不能证明宿主源码不可读。直接开放 Shell 又会把宿主账号的
文件、认证及网络权限交给生成代码。现有会话目录属于持久存储，不能作为任意脚本的工作目录。

## Decision

Amadeus 两种执行入口共用每轮独立的临时工作区和 macOS 内核文件策略。模型 CLI 保留
声明的业务工具，新增 Host 本地 `execute_workspace` 与 `save_workspace_file`，不向业务
HTTP 服务提供任意执行接口。CLI 工作目录不再使用调用者的持久会话目录。

模型 CLI 的认证配置使用独立临时副本；Pi/Harness 的扩展也复制到该轮私有目录。
程序、动态库和系统依赖按明确闭包开放，禁止放开整个主目录、Homebrew 或仓库。
脚本使用更严格的沙箱，只能读写当前工作区，不能读取 CLI 私有配置，不继承供应商或后端密钥。
脚本无直接网络权限，只能连接本轮授权 socket；关闭 Apple Events、Mach 查询和外部进程信息及信号访问。

独立 Python 运行环境从明确登记的 SDK 与依赖构建到运行根目录下 `agent-workspace/`，
不依赖后端 editable 环境或仓库路径。运行环境按源码摘要原子发布，任务不能修改它。
macOS dyld 需要读取根 vnode；策略只允许根目录本身，不递归授权。`/System/Volumes/Data`
不属于系统目录白名单，防止通过数据卷别名访问用户文件。

Python `task_client()` / `async_task_client()` 与 `fpl --task` 使用同一 SDK 资源方法，
将登记的 JSON 操作传给任务工具桥。业务读写仍由原有账号、权限、版本和参数审批规则裁决；
未登记接口与直接 HTTP 不可用。脚本写操作返回等待审批，不把提案包装成已完成响应。
本地执行最长 120 秒、输出上限 1 MiB、临时文件预算 512 MiB，退出、超时和取消清理进程与目录。
只有显式提案保存的 UTF-8 产物进入会话；首版不增加任意二进制持久化接口。

暂停/取消可能与插入指令的短写事务并发。指令投递循环在取消时等待已开始的领取、回执和尾部保存
完成，即使再次取消也不将写事务遗留给后续审批；不重试模型输入或业务写操作。

## Alternatives considered

- 仅靠提示词、cwd、CLI read-only：不能作为系统级文件边界。
- 直接打开 CLI 原生 Shell：执行器可能继承模型凭据和个人配置，不满足代码与认证分离。
- 容器或虚拟机：用户选择本机可信运行依赖例外，因此本次使用 macOS 沙箱。
- 给整个解释器虚拟环境或软件安装前缀开放读取：可能通过 editable 安装暴露应用源码，改用独立 SDK 运行环境。

## Consequences

首版仅支持 macOS；沙箱探针失败明确拒绝运行，不回退到普通进程。Python SDK 的任务模式
只提供现有任务桥能表达的 JSON 操作；附件与 Skill 通过受控工具读取，网站客户端行为保持独立。
真实 CLI 版本启动只能证明依赖闭包可启动，不能证明登录、供应商额度或所有模型能力可用。
临时认证副本不向个人 CLI 目录回写；长期登录刷新行为需要在真实登录验收中核对。

## Verification

`tests/host/test_amadeus_workspace.py` 使用实际内核沙箱验证工作区读写、源码和凭据拒读、
数据卷别名、符号链接、硬链接、直接网络拒绝、SDK/CLI、显式保存、超时、取消、输出限制和清理。
CLI 原生协议及业务权限/审批由现有确定性测试回归；不使用正式数据和真实供应商请求。
五种已安装 CLI 另以空临时配置运行 `--version` 检查真实程序依赖闭包，不证明真实登录与模型调用。
