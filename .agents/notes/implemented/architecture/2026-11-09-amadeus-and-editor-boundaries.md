# Agent Note: Amadeus 与编辑器职责边界

Status: implemented

## Problem

Amadeus 工具编排从 HTTP 模块读取目录，网站动作执行同时掌握 ORM 和外部执行器。
前端会话读取依赖控制器传入多组 setter 和 ref。视频剪辑和导演台入口混合交互、编辑规则与生命周期管理。

## Decision

独立装配注入操作目录和按账号绑定的工具端口。兼容网站用持久记录端口领取和结算动作，外部效果由装配绑定。
Amadeus 前端按会话、运行、附件和能力目录持有状态，通过快照和命令协作。
视频编辑命令从当前时间线生成，导演台帧调度和场景计算分别接收所需数据。

## Alternatives considered

统一网站和独立执行器需要统一两种取消和授权语义，会扩大此次改动范围。
按行数切分页面无法消除状态与生命周期的共享，因此按完整职责拆分。

## Consequences

使用替身记录、文件和执行端口可以独立验证编排。领取与结算各持有短事务，取消期间等待已开始的持久化操作结束。
前端选择版本决定是否接纳异步结果，帧调度随导演台生命周期释放。

## Verification

架构测试限制编排的依赖方向并验证导航唯一所有者。执行端口测试覆盖读取、提案及领取期间关闭。
前端回归覆盖会话切换、附件部分成功、轮询停止、字幕乱序与批量编辑撤销。
