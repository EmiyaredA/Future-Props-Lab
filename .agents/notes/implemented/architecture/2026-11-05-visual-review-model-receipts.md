# Agent Note: 独立视觉验收的模型回执与基础证据

Status: implemented

## Problem

视觉工坊需要以固定视觉模型评估冻结的节点输出。拆分后供应商配置和调用额度归 Models，视频原件归 Assets，解码归 Rendering。调用发出后断线可能丢失结果，重发会重复调用供应商。

## Decision

Models 以账号和验收运行 ID 唯一登记模型请求，提交前核对固定连接签名、证据摘要和额度。结果与调用日志在短事务内落盘。同一摘要重放返回原回执，进程中断留下的运行中调用恢复为结果未知。模型计划只返回模型标识与连接签名所需的公开字段。

原节点验收请求可为同一项目委派视频取样，和手动区间取样使用不同的 Rendering 路径。Rendering 从 Assets 读取精确版本原件，按旧取样策略返回解码时间点和摘要。原件与生成帧继续通过独立的引用准备和源事务回执协调。

## Alternatives considered

在 Visual 读取供应商凭据会绕过 Models 的模型可用性、调用额度和调用日志。自动重试未知供应商调用可能重复计费或产生冲突结果。

## Consequences

Models 需要显式应用 0018 迁移。Visual 的公开创建验收操作还需要接入验收执行流程。已知模型回执可以重取，未知调用由用户显式发起新验收。

## Verification

隔离的 Identity 与 Models 测试覆盖相同请求重放、摘要冲突和中断后的未知结果。真实视频测试覆盖区间取样、输出均匀取样、参考视频取样、原件元数据及授权边界。
