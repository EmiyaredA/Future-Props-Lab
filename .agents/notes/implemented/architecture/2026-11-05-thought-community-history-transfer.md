# Agent Note: 思绪工坊社区与官方导入历史迁移

Status: implemented

## Problem

独立 Thought 恢复文档和发布记录后，社区收藏、编辑者已上传的附件、旧官方链接和原导入请求回执仍需保留。社区附件属于文章账号，上传者可能是另一个账号。

## Decision

社区收藏由收藏者拥有。上传记录从文章推导归属，并保留原上传者。官方来源映射核验所属文章，原导入回执保留历史请求号、包摘要和结果。官方回执与收藏保留历史引用，即使用户随后删除了原文章或撤回了发布。引用恢复校验以同一计划核对上传对应的文章账号、原件及 SHA256。

## Alternatives considered

用当前发布关系筛选收藏会丢掉已撤回发布的历史。把附件按上传者归属会把文件交给错误的账号。给旧上传新增长期保留记录会改变未引用附件的生命周期。

## Consequences

恢复可分批提交和重复核对。没有明确归属的上传、跨账号文章引用和缺失的原件会使验收失败。旧官方导入请求仍可使用原回执，不会因升级后的包内容变化而再次导入。

## Verification

`tests/test_thought_cutover_transfer.py` 通过实际旧站 HTTP 创建社区编辑者、收藏、附件和官方导入回执，再验收迁入、旧站恢复、账号隔离和文件摘要。
