# Agent Note: Models 独立推理历史与原件迁移

Status: implemented

## Problem

旧站的独立推理记录引用目录、调用日志、输入素材和本机结果。元数据写入和原件传输可能分开中断，提交状态未知的任务也可能留在来源。

## Decision

先迁移任务，再迁移输入记录，按账号核验模型、日志和输入认领关系。流式维护接口以业务记录定位原件，用大小及 SHA256 验证后持久发布和记录回执。最终逐账号比对原件清单并核对回执。正常运行时继续用已有推理恢复逻辑处理提交中断。

## Alternatives considered

复制整棵推理目录会把暂存文件带入生产，并且无法验证文件与业务记录的归属。只迁移任务会让已有结果无法下载。

## Consequences

计划外账号、缺失记录、错误摘要和额外目标原件会阻止验收。封存来源保留已识别的中断暂存文件。其他 Models 数据仍需按归属逐项迁移。

## Verification

`tests/test_model_call_log_transfer.py` 验证隔离监听器上跨账号拒绝、原件摘要错误拒绝、先传一份文件后重启续跑、超过维护 JSON 上限的结果文件及未知提交恢复。
