# Agent Note: 两种网站装配共用演示执行器

Status: implemented

## Problem

兼容网站和独立服务分别持有几乎相同的演示执行逻辑，兼容版本把数据库工厂、调用计数、排空和日志存为模块全局变量。

## Decision

删除重复运行模块，两种装配均构造 `DemoRuntime`。配置读取由各自存储适配提供；兼容网站仍读取原有平台设置键，不迁移数据。模型与工具消费者显式接收当前实例的传输或执行回调。

Amadeus 的旧模型桥接接收日志会话工厂和传输回调。已返回 410 的 HTTP 入口保留请求验证和鉴权，移除其异常后的不可达调用代码。

## Alternatives considered

用转发函数保留旧模块会继续隐藏实例归属，也无法证明两个装配没有共享可变状态，因此直接更新消费者。

## Consequences

演示启停、排空、重初始化、安装及模型流格式保持原行为。跨应用模型与工具端口进一步归并仍在后续批次推进。

## Verification

演示治理、Amadeus、视觉助手、思绪流、独立工具与服务契约回归 67 通过、3 跳过。实例隔离与服务打包检查 26 通过。新增隔离测试验证实例之间不共享调用计数、日志和排空，取消后释放计数并完成排空。
