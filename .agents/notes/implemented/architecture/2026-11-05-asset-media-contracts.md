# Agent Note: 素材与媒体数据契约独立于执行实现

Status: implemented

## Problem

素材上传、文件描述、时间线和特效文档曾位于旧能力包。独立业务只需要数据类型，仍把旧包带入源码闭包；这也使后续归并素材存储和渲染执行器容易引入跨应用内部依赖。

## Decision

素材输入流、领域错误和文件协议归 `studio.contracts.asset_library`。媒体裁切、取帧、信息和角色动画数据归 `studio.contracts.media_rendering`。时间线及音频接缝结果归 Video Editor 契约，特效文档归 Motion Compositor 契约。两套装配使用同一份类型，旧定义删除，不保留转发。

流只表达文件名、内容类型和异步读取／关闭。接收 I/O 适配器负责关闭、内容校验和账号授权。包含本机路径的渲染计划仍留在实现内，不能因名称带 contracts 就提升为跨进程接口。

## Alternatives considered

- 保留旧包转发：会掩盖未迁完的依赖，使镜像继续包含旧目录。
- 将渲染器和素材存储一起作为公共包：会让只读描述的消费者加载实现，扩大替换范围。

## Consequences

公共协议字段、URL、存储格式和历史迁移保持不变。素材 ORM、文件操作及媒体执行器的所有权迁移仍在后续批次完成；这一批不代表完整架构迁移完成。
