# Agent Note: Amadeus 登记操作读取

Status: implemented

## Problem

Amadeus 独立部署后需要显示原有业务操作目录，并在保持浏览器账号归属和权限撤销语义的前提下读取其他服务的数据。

## Decision

操作目录由同一版本的 OpenAPI 和自动化白名单生成。读取请求用操作 ID 解析到登记服务和准确路径，Identity 校验原授权仍有效且具备目标权限，随后签发短期目标请求凭据。目标服务独立校验账号归属。请求限于登记的 GET，传输期间计数并按原契约返回业务错误。

## Alternatives considered

将浏览器凭据交给目标服务会让多个服务处理登录状态和入口信任。允许客户端指定目标地址会绕开已发布的操作登记。

## Consequences

Amadeus 读取仅携带限定到目标方法和路径的身份凭据，目标服务继续持有自己的数据。操作目录仍显示已登记的写入能力，执行写入由独立批准流程处理。

## Verification

定向隔离测试覆盖了目录过滤、未登记操作、读取通道拒绝写入、跨账号不可见和原 Session 撤销。
