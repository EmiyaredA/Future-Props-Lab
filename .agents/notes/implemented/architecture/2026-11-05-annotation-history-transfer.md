# Agent Note: 录音标注历史与音频引用迁移

Status: implemented

## Problem

录音标注的项目、文档、波形和编辑回执需要分批迁入。音频原件由 Assets 拥有，迁移后的项目必须保留原文件关系和原编辑结果。

## Decision

先导入项目，再导入文档、波形和 Annotation 分区的编辑回执。分别保留修订号和历史原始值，校验子记录归属和完整覆盖。Assets 在音频原件验收后重建项目引用，核验原账号、素材范围、媒体类型、大小上限和文件回执。

## Alternatives considered

只迁移项目会造成波形和文档缺失。只迁移文件无法恢复引用保护。重新计算波形会改变历史内容和版本。复制整张编辑回执表会导入其他服务的数据。

## Consequences

旧编辑请求重试可读回原结果。导入断开后可从已持久化批次继续。素材归属、文件回执和子记录缺失时阻止切换。

## Verification

`tests/test_annotation_transfer.py` 从隔离旧站创建项目、编辑、改名并写入波形。测试恢复旧站，并在实际维护监听器验证重启续跑、重复回执、错误账号和错误素材类型拒绝，以及音频 SHA256。
