# Agent Note: 节点验收与固定只读方案

Status: implemented

## Problem

项目标准与输出版本分离时，用户重复绑定节点已有素材和规格。自由模板及连接难以表达模型 API 与 Code Agent 不同的输入和报告边界；强制通过后采用混淆了质量记录与创作选择。

## Decision

视频节点持有带 CAS 的方案选择，只提供动作迁移模板和模型 API、Codex、Claude Code 三个固定方案。项目只读说明与汇总，连接由 TOML 指定并校验 Workspace、账号权限、模型能力或 CLI 状态。

生成输出冻结实际请求及输入快照，上传输出读取已保存设置。上下文指纹覆盖输入及独立定义版本，发起使用 revision、指纹和幂等 ID。API 逐项结果和 Agent 报告分别保留，人工结论与原始结果分开保存。验收不拦截采用，也不自动采用被检查版本。

共享 CLI 能力负责参数、事件、环境过滤、取消和父进程监督。视觉工坊拥有任务包、媒体 MCP 和报告转换，不依赖面试助手内部实现。Agent 只读取任务清单、证据图片和有界取样，不提供通用命令或 FPL 服务凭据。

## Alternatives considered

- 保留项目发布标准覆盖节点：仍需重复配置，生成版本依据有歧义。
- 强制 Agent 使用模型 API JSON：丢失报告、区间和附件语义。
- 新增动态模板和连接编辑器：超出固定定制方案边界。

## Consequences

追加 `0108_node_acceptance`，旧标准外键保留。每次执行内部标准版本只作为不可变定义，不发布项目标准。旧写接口返回 410；旧模板、标准、记录和导入结果只读保留，不自动转换或绑定。快照验收格式 2 兼容格式 1，固定连接在目标部署重新校验。

CLI 需管理员在应用外安装登录，默认连接为空。初检输出最多 12 帧，Agent 每次追加最多 12 帧、每任务 24 帧，总时限 15 分钟。取消、超时或进程中断终止子进程，恢复不重提。连续动作仍需人工完整播放确认。

## Verification

后端隔离数据库旅程覆盖资料快照、绑定 CAS、上下文冲突、幂等请求、人工结论、返修复验、证据、历史导入、取消恢复和独立采用。假 CLI 验证不同事件、结构化结果、环境隔离与进程取消。浏览器使用真实隔离项目、素材和绑定，模拟外部执行及审阅响应，覆盖模板、节点和汇总交互。真实付费调用不属于确定性测试的证明范围。

实现与配置见 [节点验收](../../../../docs/operations/node-acceptance.md)。本决策替代[此前项目标准方案](../feature/2026-10-22-visual-acceptance.md)，旧记录保留。
