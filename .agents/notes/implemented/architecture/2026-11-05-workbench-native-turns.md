# Agent Note: 独立工作台 Mac 立即轮次

Status: implemented

## Problem

独立 Agents 需要执行用户发起的项目轮次，同时保持账号、入口、审批、已保存对话与原生执行结果之间的对应关系。

## Decision

Agents 在同一事务登记轮次与 Mac 任务。浏览器授权只保留在进程内，运行期间定期向 Identity 复核。Mac worker 通过独立回环通道领取租约，启动前探测 CLI，随后复核实际配置和项目目录身份。文件和命令工具复用兼容站的安全路径及命令沙箱。审批绑定轮次、账号、项目、操作内容摘要和回执，已领取的审批无法再次执行。

## Alternatives considered

在容器直接运行本机 CLI 会失去可信 Mac 的连接和项目边界。把浏览器授权写入 SQLite 会使中断的历史任务携带可重用凭据。

## Consequences

持久回执丢失时保留未知状态，重启只确认原任务结果。工作台独立就绪还需新增的排队、插入指令和源码预览接口通过验收。

## Verification

隔离 HTTP 测试覆盖重复提交、跨账号和跨入口审批拒绝、文件写入及活动投影、实时撤权。兼容站和独立 Agents 的原有读取及架构检查同步复跑。
