# Agent Note: 网站动作与下载生命周期

Status: implemented

## Problem

视频时间线助手依靠模块级注册寻找数据库，Amadeus 活动执行句柄和视频下载任务也保存在全局容器中。网站关闭时没有等待这些操作结算。

## Decision

时间线适配显式接收会话工厂。Amadeus 装配创建 `ActionExecution`，注入时间线执行器并拥有活动句柄；关闭时取消并等待原有结算逻辑，非脚本动作仍以未知结果处理执行中断。

下载由 `VideoDownloads` 实例拥有任务与状态，注入下载器、依赖探测和素材入库适配。素材入库保持原事务。关闭后拒绝新任务，等待已接受的本机执行和入库完成后再关闭数据库；不以取消 Python 线程假装已停止外部写入。

## Alternatives considered

仅替换全局数据库引用无法解决共享任务容器及关闭顺序，因此同时明确生命周期归属。下载的原有进程内状态与持久任务迁移分开处理，避免改目录时擅自修改恢复协议。

## Consequences

公开操作与账号归属保持不变。API 模块导入不再注册视频执行器。下载任务沿用原进程内状态，应用重启不会恢复旧任务；持久下载与原生取消机制仍属于业务归并的后续工作。

## Verification

Amadeus 与视频编辑回归 39 通过、3 跳过。下载与边界修正后 22 通过。新增测试验证关闭等待入库、拒绝新任务、账号隔离及实例隔离。服务打包与其他相关检查 46 通过。
