# Agent Note: Visual 节点固定模型验收的源事务与恢复

Status: implemented

## Problem

节点验收需要冻结可见画布、验收方案和旧输出版本。取样与模型调用可在服务重启或网络中断时丢失回执。可见结果必须来自仍有效的账号和未取消的原运行。

## Decision

Visual 在写锁内重新核对画布、方案、输出和请求摘要，使用写锁外读取的工程素材投影。冻结定义、运行、素材引用、执行计划和初始 Assets 回执在同一事务写入。后台逐来源发布帧证据，回执与验收版本同步更新。通过 Identity 确认执行账号后，模型请求以同一验收 ID 和精确证据摘要交给 Models。收到模型结果后复核账号，并只更新正在执行的运行。

## Alternatives considered

在一次事务中持有跨服务取样和模型请求会长时间占用 SQLite 写锁。中断后从头执行会重复发布帧并可能重复调用模型。

## Consequences

Visual 需要应用 0009 迁移。固定模型路径可独立执行和恢复。Mac CLI 方案需要对应原生执行链路才能接受运行。

## Verification

隔离测试使用真实 MP4 和 FFmpeg，在输出证据回执丢失及 Models 结果回执丢失后分别重启 Visual，核对证据 ID、人工与自动判定、原模型结果及唯一调用。覆盖陈旧画布版本、相同请求重放和取消待执行运行。
