# Agent Note: 本机与公网共用前端构建

Status: implemented

## Problem

本机开发前端和云端静态快照分别更新，容易产生版本差异。每次发布都需要上传程序，并在两台机器上保留快照。

## Decision

共享模式由 `[website].web_root` 指向 `.local/studio-current/current` 启用。统一启动器监听前端输入并串行构建，校验清单后原子切换。两种入口在每个请求开始时读取同一指针，并持有共享文件锁直到读取结束。Caddy 通过既有隧道转发所有路径，公网探针核验实际服务实例与构建。

## Alternatives considered

直接把 Vite 转发到公网可以即时更新，但会向浏览器公开开发模块。分开发布云端静态资源可以让 Mac 离线时仍显示登录页，但需要同步两端版本。

## Consequences

构建期间仍提供当前页面。成功切换后提示刷新，旧构建经过短暂缓冲并释放请求后清理。公网页面可用性跟随 Mac 和隧道。本机管理权限仍依据实际监听端口。

## Verification

隔离测试覆盖两个入口同时切换、失败构建保留当前版本以及公网管理员的本机操作限制。
