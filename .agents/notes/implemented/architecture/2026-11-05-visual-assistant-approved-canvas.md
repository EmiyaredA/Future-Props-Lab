# Agent Note: Visual 助手批准后的画布写入

Status: implemented

## Problem

独立助手要在用户确认后执行画布编辑，同时继续经过素材准备与源事务。浏览器收到审批事件后可能立即提交决定。

## Decision

审批先登记，再发给监听方。只有已匹配账号、项目、对话、运行和审批的批准上下文进入工具处理器，原请求授权只存在于进程内。Visual 使用提案时的画布版本做 CAS，并将批准请求绑定到当前项目的 Assets 保留准备。

## Alternatives considered

使用发送消息的授权执行写入会混淆发起和审批。以审批时看到的较新版本执行会把旧提案套到更新过的画布。

## Consequences

旧版和独立助手沿用原审批事件和操作参数。过期提案返回当前版本，调用方可重新读取后提案。

## Verification

覆盖即时审批、批准时的真实画布写入、缺少审批授权和旧版本拒绝。
