# Agent Note: 媒体读取共用用例与可替换素材借用

Status: implemented

## Problem

兼容网站的裁切和格式查询直接查询素材 ORM、读取全局配置并重复媒体规则。独立 Rendering 拥有另一份实现。消费者无法替换素材来源，查询事务也容易延长到解码或探测阶段。

## Decision

`ReadMedia` 统一账号、素材种类及处理后授权规则，依赖素材借用、媒体执行器和授权三类接口。输入为账号、素材 ID 和已校验命令，输出为图片字节或媒体描述；用例不接收数据库 Session、HTTP Request 或路径。

Assets 的 `StoredMediaSources` 在自有短查询内核对账号，关闭查询后提供不可变描述与受限内容句柄。Rendering 的远端适配绑定已验证请求账号，下载并核验素材协议后借出相同接口。兼容网站与独立服务在各自装配入口注入这些组件，使用相同处理器；原网站重复实现删除。

I/O 适配器可以直接复用已借用文件，避免再次复制大文件；其他流实现通过有上限的临时文件适配。取消、异常和正常退出均释放句柄与临时输入。文件路径不进入业务端口。裁切不创建素材或改变原件 revision，处理后重新核验原请求身份，授权失效不返回已生成内容。

## Alternatives considered

- 仅迁移旧文件：保留了两份类型判断与错误规则，没有实现组件替换。
- 所有来源强制复制：简化了路径处理，但会给本地大媒体引入不必要的磁盘 I/O。
- 用例接收素材 ORM 或路径：使业务依赖数据库生命周期及宿主存储布局。

## Consequences

HTTP 操作、响应与错误结构不变。网站也执行处理后身份复核，并使用已有的有界图片解码器。借用句柄不可持久化或跨请求使用。缩略图、元数据预览和取帧尚待同样归并；本批不代表全部媒体或整体架构完成。

## Verification

- 同一裁切用例使用内存流、真实隔离 SQLite 和受控 HTTP 来源；覆盖缺失文件、账号不匹配、类型错误、授权撤销和取消释放。
- 真实网站 Session 经登录、上传、裁切成功后，在处理阶段通过正式退出 API 撤销，原请求返回 401；没有直接修改持久数据库。
- 流适配取消和超限清理、现有媒体回归、架构和网站装配检查通过。OpenAPI stale-check 无变化。
