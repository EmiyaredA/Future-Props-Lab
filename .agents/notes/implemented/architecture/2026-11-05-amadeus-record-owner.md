# Agent Note: Amadeus 独立记录服务

Status: implemented

## Problem

Amadeus 的对话与运行已经有按账号归属的持久规则，兼容站的执行连接和全局数据库装配仍绑定在同一个模块。

## Decision

将运行记录和中断结算提取为按显式会话执行的用例，兼容站单独绑定旧连接入口。独立 Amadeus 使用六张自有记录表，Identity 授权作为账号归属依据。旧站数据库的既有迁移保持有效。独立记录路由沿用原路径、操作 ID、修订错误和退役接口响应。

## Alternatives considered

把全站数据库挂载给 Amadeus 会混淆私有状态和其他所有者。另写一套对话、审批记录和运行历史规则会让两种入口在冲突和重启后出现不同结果。

## Consequences

Amadeus 增加 0001 迁移、独立镜像和 Compose 装配，纳入 Mac 启动预检。就绪仍取决于工作文件、跨服务工具、Mac CLI 和完整路由接通。

## Verification

79 项定向测试通过，1 项依赖主机条件的测试跳过。三容器隔离运行验证签名账号入口、退役协议状态和重启后的记录读回。存储测试核对了跨账号拒绝、旧修订冲突、部分回复与未知动作恢复。
