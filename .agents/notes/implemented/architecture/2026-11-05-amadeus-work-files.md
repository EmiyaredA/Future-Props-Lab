# Agent Note: Amadeus 独立工作文件

Status: implemented

## Problem

独立 Amadeus 必须用自己的账号文件目录实现导入、写入、清单和下载，支持原有文件大小与版本冲突语义。

## Decision

保持常规请求的有界读取。唯一的多段上传入口按协议允许的文件大小流式计数，再分块写入同目录暂存。创建用原子链接，覆盖操作在目录锁下按 SHA256 比较并落盘。服务内的对话锁协调删除和文件写入，账号路径、目录与文件描述符均验证归属。

## Alternatives considered

将多段上传和其他 JSON 请求设为同一个上限会截断现有导入范围。一次把整个上传和下载读到内存会扩大并发下的内存占用。

## Consequences

独立文件入口沿用原路径和操作 ID。文件始终落在 Amadeus 的服务目录，浏览器只能访问已校验的对话原件。

## Verification

75 项定向测试通过，1 项依赖主机条件的测试跳过。隔离用例覆盖 9 MiB 导入、文件摘要和长度、同名导入冲突、并发 SHA256 CAS、超限请求和暂存清理。
