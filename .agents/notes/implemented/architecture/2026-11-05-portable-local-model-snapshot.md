# Agent Note: 封存本机模型解释器链接

Status: implemented

## Problem

旧版 uv 创建的虚拟环境以绝对链接指向同一运行树内的打包解释器。源路径包含原运行目录，快照检查会拒绝，复制链接也会把恢复目录指回来源。

## Decision

只接受已知虚拟环境入口指向同版本运行树内打包解释器的绝对链接。计算对应相对路径并写入封存副本。封存清单核对相对链接和文件字节，原目录只读核对。

## Alternatives considered

允许任意绝对链接会让快照依赖源目录或外部文件。丢弃虚拟环境目录会使旧站快照不完整。

## Consequences

搬迁恢复目录仍能解析到其自身的打包解释器。失效链接、循环链接和外部链接继续拒绝。运行时环境和权重的可用性由 Mac worker 演练另行核验。

## Verification

`tests/test_website_legacy_snapshot.py` 核对原链接、封存相对链接、恢复解释器字节和外部链接拒绝，并在同一恢复包重启隔离旧站。
