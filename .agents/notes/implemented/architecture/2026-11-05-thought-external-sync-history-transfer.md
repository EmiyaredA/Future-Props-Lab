# Agent Note: 思绪工坊外部同步历史迁移

Status: implemented

## Problem

旧站的同步绑定、任务、远端步骤和素材在切换后仍需可核对。旧执行者快照不能替代独立服务的授权，正在运行或曾经核对后重新排队的任务可能已写入远端。

## Decision

保留原始标识、修订、执行者、远端快照和步骤。旧站排队及运行中的任务导出为待核对，原状态和说明保留在检查点。原文档已永久删除的排队任务仅在无远端执行证据时导出为失败。导入校验文档、绑定和步骤归属，以及待核对任务的目标一致性。单独核对迁入的 Integrations 连接和 Assets 原件。

## Alternatives considered

自动续跑会重新执行未知结果的远端写入。只复制绑定会丢失步骤、已知结果和人工核对入口。重建一个独立执行授权会扩大旧执行者的权限。

## Consequences

启动后可以查看待核对任务的远端状态，并通过已有业务入口显式结束任务。再次写入由新预览和新的授权开启。原站仍可从封存快照恢复。

## Verification

`tests/test_thought_sync_transfer.py` 使用旧数据库的隔离样本和实际维护监听器，验证重启重放、未知步骤、连接和素材读回、跨账号与目标不匹配拒绝，以及启动后核对与结束任务。
