# Agent Note: 全仓存储边界与编辑组件

Status: implemented

## Problem

兼容网站的跨应用 SQL 与文件适配仍混在业务包，模型额度反向依赖网站模型清单。部分架构检查保留旧命名空间和不完整扫描范围。音频编辑需要多个子组件共同维护草稿及历史，视频预览直接依赖 HTTP Request。两套文件修改实现和多个文档快照转换重复，编辑接口的重试返回语义未明确区分。

## Decision

兼容网站的跨表适配、组合事务、后台执行和相应协议组合按业务所有者迁入 `studio/assembly/website/<owner>/`。纯规则、自有实体与独立服务保持在应用。所有调用方硬切新归属，没有旧模块转发、全局注册表或默认查表回退。镜像闭包不扩大。素材上下文必须显式提供项目存在性查询。

Stories、Canvas 和 Audio 的 revision 命令共用纯读取/重放/校验/转换流程；原子 CAS、回执与取消回滚由所属存储适配实现。Video 保留独立的当前快照重试语义，并通过 `EditTimeline` 端口编排纯规则与 SQL 提交。FrameRequests 只接收脱离会话的时间线、素材描述及渲染端口；HTTP 与 SQLite 分别由适配器实现。Models 的额度决定只消费聚合事实。

音频草稿、编辑版本、dirty 与撤销历史由一个可订阅状态组件拥有。UI 和转录提交命令，保存确认不能覆盖后续编辑或服务器重载。异步转录核对实例范围和片段区间。播放使用独立能力协议。视觉生成的网络提交及反馈独立为 Hook，不以组件 props 定义执行端口。

文件目录规则和文档快照转换只保留一个实现；素材修改 CAS 由两套 API 共用。静态源码迁移清单仅供历史文档依据定位，不参与运行或提供旧代码别名。受保护产品文档未改写。

架构检查扫描真实路由、实体及所有应用的存储导入，包含相对、局部、类型和字面量动态形式；禁止元数据发现及应用反向加载网站组合。使用正反样例证明规则有效，不保留迁移豁免基线。

## Alternatives considered

- 仅更改目录名但保留应用到网站的反向导入，不能解除独立服务的打包耦合。
- 把共享数据库组合改成多次独立提交，会破坏现有项目、素材与回执的原子性。
- 让所有编辑接口返回历史快照需要改变视频 API 恢复契约，本次保留既有行为并明确差异。
- 在旧路径创建转发包或符号链接会掩盖源文件归属；使用静态文档定位清单保留可追溯性。

## Consequences

网站兼容实现的源码路径改变，应用核心可独立加载；数据库表、迁移 SQL、正式配置和公开协议未变。组合适配仍承担兼容数据库的事务协调，不能据此宣称所有历史业务编排均已纯函数化。新的组件端口和状态单元可使用内存实现替换。

## Verification

架构与独立服务打包回归 150 项通过，22 个独立服务的全部源码闭包检查通过。端口、音频、视频、素材与画布定向回归 153 项通过；新增编辑/渲染替换和视频重试回归通过。最终视频回归 15 项通过。

Web 全量 1960 项通过、5 项失败；5 项均在修改前 HEAD 隔离副本复现，涉及旧文档断言、ResizeObserver 和媒体时钟 mock。最后的状态、卸载保存保护及生成回归 37 项通过。真实浏览器 9 项通过，覆盖音频保存确认期间继续编辑、撤销重做和刷新恢复，以及文件预览、视频编辑、视觉生成先保存草稿。

后端全量 2964 项通过、7 项失败、4 项跳过。6 项失败在修改前 HEAD 复现：思绪迁移脚本缺少 peer 参数（2 项）、SDK 文档资源标签、模型目录断言及退役表迁移（2 项）。另 1 项迁移测试仅检查随机 UUID 排序的第一页而偶发漏掉目标回执；改为遍历全部分页，并单独复测完整迁移。上述原有功能失败未扩入本次架构修改。

lint、format、TypeScript、生产构建与 bundle 预算、服务所有权契约、Note 校验、受保护文档检查均通过。公开协议及 SDK 类型生成检查通过，SDK 文档生成检查仍因修改前已有的 4 篇受保护正文过期而失败，未重写正文。首次受沙箱监听限制的全量运行不计作最终通过证据。

本次记录的原有后端与 Web 失败由[迁移与文档测试恢复](../bug-fix/2026-11-16-migration-and-documentation-test-recovery.md)后续修复；最终后端和 Web 全量测试均通过。
