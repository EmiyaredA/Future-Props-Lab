# Agent Note: Visual 助手批准后的生成和结果发布

Status: implemented

## Problem

助手工具需在一次批准下保存生成记录和画布节点。供应商结果通常在批准请求结束后返回，发布前还需复核原账号授权和输出归属。

## Decision

Visual 冻结生成计划并经当前批准向 Identity 登记账号、项目、任务和计划摘要。Models 继续独立准备并执行任务。Visual 用提案时的画布修订在单一事务中保存执行决定、任务和节点。Identity 在结果发布时复核原凭据仍有效，并封存结果长度和 SHA256，然后只签发此次素材变更的保留权限。

## Alternatives considered

长期保存用户请求的认证断言会留下可再委派的凭据。使用更宽的服务身份直接上传会跳过原账号的权限复核。先创建占位节点再提交任务会留下无法恢复的半完成画布。

## Consequences

Identity 需要 0009 迁移。Visual 的批准生成决议只保存范围和摘要；原请求凭据只存在于当前请求内。结果发布沿用已有的 Assets 源事务和重试入口。

## Verification

隔离服务测试覆盖固定生成模型、画布版本冲突、重新加载执行器后的结果发布、原件下载摘要、供应商只调用一次和已封存结果的篡改拒绝。
