# Agent Note: Integrations 目录与凭据迁移

Status: implemented

## Problem

工具、MCP 服务和外部连接必须在服务拆分后保留原标识、所有者、版本和凭据。若目录复制成功但密钥不匹配，恢复后的调用会失败。

## Decision

Integrations 的回环维护入口传输原始加密字段，导入前以目标私有配置中的原密钥校验可读性。MCP 环境同时核对解密后的结构和键名清单。MCP 已发现工具继承已验证的服务账号，历史检查独立保留。目录写入和批次回执共用一个事务。

## Alternatives considered

- 解密并以明文传输会扩大凭据暴露范围。
- 不校验目标密钥会使错误延迟到实际调用后才暴露。

## Consequences

目标维护配置和源网站使用同一加密密钥。独立服务数据和维护回执归 Integrations，其他服务使用公开授权协议查询连接。Skill 文件使用单独的原件核验。

## Verification

隔离测试创建旧版目录并经实际回环维护入口迁移。测试验证错误密钥拒绝、重启续跑、完整密文解密、MCP 子记录归属及原有检查历史。镜像源码闭包与数据库归属检查覆盖新入口。
