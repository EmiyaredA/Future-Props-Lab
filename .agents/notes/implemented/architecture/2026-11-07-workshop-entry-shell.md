# Agent Note: 九款工坊首页共享公共顶栏

Status: implemented

## Problem

兼容网站和独立应用分别装配入口。工坊首页的外观、账户、文档中心和 Amadeus 分散在不同外壳，部分入口缺少助手宿主。思绪工坊还需要保留自己的可调整知识库侧栏和目录。

## Decision

工坊首页显式启用 `WorkshopShell` 的公共顶栏。顶栏复用 `StudioGlobalHeader` 的现有控件，按会话权限决定是否提供 Amadeus。思绪工坊通过内容插槽挂载同一顶栏，并在这个页面隐藏侧栏底部的重复主题开关。没有启用公共顶栏的编辑器和其他页面使用原来的外观入口。

独立入口继续拥有 URL、未保存拦截、更新提示和账号范围内的 Amadeus 宿主。只读首页沿用所属功能的只读页面。账户登录、后端接口和数据格式沿用当前契约。

## Alternatives considered

曾考虑统一到平台的 `StudioShell`。工坊需要自己的品牌、导航和沉浸式编辑器边界，思绪工坊还需要专用目录。共享顶栏并保留各自的导航职责能减少重复装配。

## Consequences

工坊首页的身份入口、主题和助手可使用同一套组件。独立入口的助手以当前账号挂载，窄屏关闭后在页面重新可交互时恢复触发控件焦点。登录前由现有身份门拦截。

## Verification

`web/e2e/workshop-entry-shell.spec.ts` 通过兼容网站和真实独立 HTML 入口验证九个首页，覆盖明暗主题、窄屏、菜单焦点、助手、退出和只读入口。浏览器测试连接隔离的兼容网站 API。

公共控件与业务标题合并后的入口布局见[工坊首页合并业务操作与公共控件](../simplification/2026-11-08-compact-workshop-toolbar.md)。
