# Agent Note: 编辑器生命周期与会话版本冲突边界

Status: implemented

## Problem

导演台曾改写全局事件注册方法来收集监听器，卸载时可能影响同页其他功能。Amadeus 的迟到读取会覆盖当前账号、Workspace 或会话内容；版本冲突缺少可供用户确认的当前快照。编辑器模型的类型、创建与校验职责混合，增加替换成本。

## Decision

导演台由编辑器实例持有 AbortSignal，持续监听器和桌面桥接订阅随实例释放，委托事件只处理编辑器根节点内的目标。Amadeus 的列表和详情读取按账号、Workspace 及选择顺序取消并核对；冲突返回期望版本、当前版本和会话摘要，前端保留输入并读取最新详情，写操作不自动重试。导演台的类型入口、常量、创建和校验分别命名；空间报告只依赖只读场景接口。架构门禁检查 TypeScript 实际发出的运行时导入环，类型引用仍由类型检查覆盖。

## Alternatives considered

- 改写全局事件注册方法：能集中收集监听器，但越过组件生命周期边界。
- 冲突时自动用新版本重发：减少交互，但会覆盖用户尚未确认的变化。
- 以文件行数平均拆分：能通过体量门禁，但无法形成可替换的职责边界。

## Consequences

- 编辑器卸载不取消其他功能的监听器；重新挂载不会保留旧委托处理器。
- 会话冲突需要用户检查新快照后再次提交；当前字段是会话摘要，完整消息由详情接口读取。
- 类型引用可以跨模块，运行时依赖仍保持无环；单独替换校验或创建模块无需改变数据形状。

## Verification

运行导演台事件生命周期、Amadeus 范围读取、并发 CAS、架构、契约及受影响工坊测试。
