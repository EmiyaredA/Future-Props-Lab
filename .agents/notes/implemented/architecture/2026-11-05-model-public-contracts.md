# Agent Note: 模型服务公开数据契约

Status: implemented

## Problem

模型目录、转录参数、执行进度和调用归因类型位于旧模型实现包中。部分类型校验还导入供应商实现或模型 ORM，使消费方仅加载协议时也进入业务实现。

## Decision

模型 HTTP 数据结构、转录结构、执行遥测和不可变调用归因归入 `studio/contracts/model_service/`。供应商默认地址及 ZEALMAN 地址归一化保持原规则，但由纯配置契约共享；本地模型语言列表直接读取纯配置定义。

调用归因契约移除未使用的记录修改方法，持久记录到快照的映射留在模型调用日志适配中。HTTP 归因依赖归装配模块，业务与契约不因读取调用者身份加载 HTTP 框架。

## Alternatives considered

保留旧类型转发包不能消除父包和内部实现依赖。复制供应商地址规则会造成验证与执行不同步，因此共享同一纯函数。

## Consequences

HTTP 形状、错误语义、供应商参数、身份归因与持久格式保持不变。模型执行和状态存储仍在后续业务归并批次迁移。

## Verification

调用归因、服务闭包及服务契约检查 60 通过；其纯契约检查发现的供应商反向依赖已拆除。后续边界、归因、转录、本地模型、ZEALMAN 和目录 HTTP 检查 54 通过。OpenAPI 与部署归属清单无变化，Ruff 通过。
