# Agent Note: Amadeus 记录归并与显式文件根目录

Status: implemented

## Problem

独立 Amadeus 仍从旧 console 包加载记录、审批和恢复规则。会话文件缺少根目录时读取
全局配置，网站与独立服务无法证明操作只落在自己的文件树。本机沙箱与模型日志也混在助手包。

## Decision

共享会话、消息、动作、提问、运行和恢复移入 `studio.apps.amadeus.storage`，协议归
`studio.contracts.amadeus`，对话提示归纯规则。网站执行适配归 `execution/website_*`。
模型调用和日志归 Model Service；调用必须显式提供加密器、传输解析和会话工厂。

所有会话文件和固定 Skill 读取要求显式根目录。网站生命周期、动作执行器与工具桥传入
已装配根目录，独立服务继续传入自有数据根。删除会话缺少文件配置时明确拒绝，不寻找全局服务。
Finder 与沙箱进程分别由 Host 文件操作和执行适配拥有；保留既有账号、符号链接、摘要 CAS、
脚本审批和超时清理规则。网站 Skill 加载入口补齐既有 Integrations 目录的显式装配调用。

## Alternatives considered

- 把旧包保留为转发层：无法消除目录双重归属，因此删除旧实现并同时更新消费者。
- 文件根目录可选并回退：会使独立实例意外访问网站数据，因此文件操作要求明确配置。
- 顺便统一两种执行协调：当前网站进程任务和独立租约有不同边界，留待用例端口批次验证。

## Consequences

原 `app.console.amadeus` 和路由文件删除；服务 ID、HTTP、表名、文件格式及历史迁移不变。
网站与独立入口共用记录规则，执行协调及其 SQL 事务仍需后续进一步解耦，整体提案未完成。
