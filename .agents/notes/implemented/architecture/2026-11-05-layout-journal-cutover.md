# Agent Note: 切换前核验旧素材布局升级记录

Status: implemented

## Problem

旧站完成一次性账号布局升级后仍保留记录及原件。覆盖检查把已完成记录视为待传数据，同时只验证快照的数据库和配置，无法发现回滚原件已被改动。

## Decision

覆盖检查在读出数据库前比对封存清单中的运行目录，逐文件检查摘要和权限，校验目录内相对链接。逐条确认升级记录已完成且目标路径归计划中的账号。已完成记录随封存数据库保留，报告仅输出计数。

## Alternatives considered

在独立 Assets 重放旧路径会再次引入一次性工作区布局。忽略记录则可能在旧布局尚未完成时切换。

## Consequences

存在未完成的记录、账号路径冲突或快照文件变动时，切换前验收失败。运行中的独立 Assets 仍按自有素材记录、文件摘要和持久回执核验。

## Verification

`tests/test_website_legacy_snapshot.py` 覆盖完成记录归档、失败记录、路径冲突、快照原件变动及隔离环境恢复旧站。
