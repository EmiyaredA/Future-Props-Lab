# Agent Note: 公网云控的密码重验与验证器

Status: implemented

## Problem

主线的公网仅桌面配置会直接使用登录和 VNC 密码。当前仓库指令要求公网远程桌面和工作台执行均经过账号授权、密码重验与 TOTP。

## Decision

公网仅桌面选项继续限制允许的功能范围。所有公网桌面首次握手均要求当前 Session 已在登录后单独重验密码，并有通过 TOTP 验证的桌面授权。公网启用前必须登记验证器。公开工作台解锁也要求当前 Session 的独立密码重验。连接和空闲重连继续使用 VNC 密码，注销或撤权后关闭连接。

## Alternatives considered

只在浏览器禁用按钮仍会留下直接调用接口的路径。仅检查登录时的密码时间不能证明后续的独立密码确认。

## Consequences

兼容站和独立 Identity 使用相同的云控规则。设置界面为公网仅桌面模式显示验证器要求。已有配置的公网开关保留，连接时执行新授权门禁。

## Verification

79 项后端定向测试通过。隔离 Chromium 云控规格 8 项通过，覆盖普通账号拒绝、设置、桌面与工作台入口和响应式布局。
