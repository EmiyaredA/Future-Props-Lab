# Agent Note: 视频剪辑项目与时间轴归属

Status: implemented

## Problem

视频剪辑的项目与时间轴是账号私人数据。兼容站在项目创建时建立素材目录，独立剪辑服务需要保留原项目及修订契约，并把素材目录交给 Assets。

## Decision

兼容站和独立剪辑服务共享项目、时间轴读取与 HTTP 路由。旧站通过项目布局适配器维护目录，独立服务在空项目创建时只提交项目和默认时间轴。独立镜像只装配这五项公开操作，启动逐项核对 OpenAPI。

## Alternatives considered

复制路由及时间轴读取会使旧文档规范化、错误和响应形状逐步分歧。共享 Assets 存储会绕过账号素材的专有边界。

## Consequences

独立服务可验证空项目、账号归属和修订持久性。时间轴写入、素材、剪辑交接和历史数据仍由就绪门禁跟踪。

## Verification

隔离测试覆盖跨账号 404、过期修订冲突、服务重启及镜像边界。兼容站剪辑回归继续覆盖原有目录生命周期。

独立时间轴编辑复用现有轨道和片段校验。Assets 的签名读取绑定项目、请求路径与原件 ID 集合，剪辑服务持有处理状态、任务关联和修订回执。素材边界测试使用隔离 Assets 与 Identity，覆盖不同项目和账号的原件拒绝以及类型不匹配。四容器额外验证缺失原件、CAS、编辑重放和重启。

独立项目创建与删除改由 Assets 的文件范围协议接收准备与确认。删除准备阻止新增原件，源提交与回执同事务落盘。文件仅在确认后清理，按账号和项目核对，保留其他项目素材。四容器与中断测试分别验证正常删除和回执恢复。

原件上传与复制经独立回执连接 Video 和 Assets。上传绑定长度与 SHA256，复制绑定源标识集合。Assets 只向对应账号和项目发布文件，Video 可重启后恢复同一回执并一次登记处理任务。仅确认过的文件进入剪辑素材列表。容器验收复用真实 Gateway 写入与引用。隔离传输故障覆盖远端已提交、HTTP 响应丢失和后续恢复。
