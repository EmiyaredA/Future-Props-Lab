# Agent Note: 视频剪辑项目与时间轴归属

Status: implemented

## Problem

视频剪辑的项目与时间轴是账号私人数据。兼容站在项目创建时建立素材目录，独立剪辑服务需要保留原项目及修订契约，并把素材目录交给 Assets。

## Decision

兼容站和独立剪辑服务共享项目、时间轴读取与 HTTP 路由。旧站通过项目布局适配器维护目录，独立服务在空项目创建时只提交项目和默认时间轴。独立镜像只装配这五项公开操作，启动逐项核对 OpenAPI。

## Alternatives considered

复制路由及时间轴读取会使旧文档规范化、错误和响应形状逐步分歧。共享 Assets 存储会绕过账号素材的专有边界。

## Consequences

独立服务可验证空项目、账号归属和修订持久性。时间轴写入、素材、剪辑交接和历史数据仍由就绪门禁跟踪。

## Verification

隔离测试覆盖跨账号 404、过期修订冲突、服务重启及镜像边界。兼容站剪辑回归继续覆盖原有目录生命周期。

独立时间轴编辑复用现有轨道和片段校验。Assets 的签名读取绑定项目、请求路径与原件 ID 集合，剪辑服务持有处理状态、任务关联和修订回执。素材边界测试使用隔离 Assets 与 Identity，覆盖不同项目和账号的原件拒绝以及类型不匹配。四容器额外验证缺失原件、CAS、编辑重放和重启。

独立项目创建与删除改由 Assets 的文件范围协议接收准备与确认。删除准备阻止新增原件，源提交与回执同事务落盘。文件仅在确认后清理，按账号和项目核对，保留其他项目素材。四容器与中断测试分别验证正常删除和回执恢复。

原件上传与复制经独立回执连接 Video 和 Assets。上传绑定长度与 SHA256，复制绑定源标识集合。Assets 只向对应账号和项目发布文件，Video 可重启后恢复同一回执并一次登记处理任务。仅确认过的文件进入剪辑素材列表。容器验收复用真实 Gateway 写入与引用。隔离传输故障覆盖远端已提交、HTTP 响应丢失和后续恢复。

确定性剪辑探测和派生文件生成由媒体渲染能力共享。Rendering 读取经过项目与账号绑定的原件，持有任务和派生文件。Video 只保存处理状态、探测结果与可恢复投递，使用独立的任务对等通道。兼容站继续使用同一生成逻辑。渲染完成后，Video 通过现有接口流式返回派生字节。项目删除后以持久投递清理派生文件。五容器和故障用例覆盖重启、丢回执、授权范围、代理重试及分段读取。

独立浏览器复用既有剪辑项目、任务与时间轴页面及只读入口。任务查询由兼容站和独立应用共享，权限仍基于项目和账号。页面版本与发布 API 摘要一起核验。五容器 Chromium 覆盖窄屏、桌面编辑、真实文字保存、任务查询和版本拒绝。

精确帧和文字图层由 Rendering 承接。Video 根据时间轴修订冻结文稿、转场及素材范围，原件从 Assets 按确切版本传输，服务在返回帧前复查账号授权。兼容站与 Rendering 共用 PNG 渲染和时间范围规则。验收覆盖文字、图片、版本冲突、缓存重放和生成后的权限撤销。

成片生成复用既有预检、帧编码和规格校验。Video 持久提交同一时间轴与原件摘要，Rendering 将输出封存后才请求 Assets 发布。恢复时先查原回执，Video 用同一事务登记媒体与终态。Assets 成片入口使用已有项目快照大小上限。五容器及故障测试覆盖实际编码、重启、发布回执丢失、分段下载与排队取消。

特效交接以原 Motion 项目、任务、成片格式、目标项目和请求摘要授权。Rendering 直接传递已完成的 MP4 或 ProRes 原件。Video 在一个源事务登记目标素材、处理任务、顶层时间轴片段和持久回执。新建目标先以草稿登记文件范围，远端明确拒绝时保留空草稿供账号复核或删除。六容器与丢回执故障测试覆盖原字节、现有和新建目标、恢复及源项目删除。

音频候选分析经版本校验后交给 Rendering，精确绑定源文件摘要、片段范围与当前账号。兼容站和独立执行器共用原解码和排序逻辑。五容器及隔离测试验证候选、参考波形、重复结果和旧修订拒绝。

剪辑项目工程包保留兼容清单、原件筛选及项目来源。Assets 以独立归档凭据对每个文件暂存、封存并确认，源决定持久化后才发布副本并重映射全部时间轴与素材编排引用。文件暂存后重新校验 SHA256。五容器与故障测试验证旧格式、未使用成片排除、素材 ID 映射和丢确认恢复。

打开剪辑项目文件夹仅接受可信本机入口的浏览器 Session。Identity 将本机证明委托给绑定同一项目的 Assets 目录准备和 Tools 原生调用。Assets 校验文件范围和路径后创建固定目录，Mac worker 使用独立回环原生队列与持久回执执行系统打开。五容器及故障测试验证本机路径、跨账号与公网拒绝、符号链接拒绝和回执重放。

素材名称由 Assets 保存，默认效果和素材修订由 Video 保存。改名准备仅保留该账号与项目中的确切原件。Video 同事务提交修订、效果与决定，确认后才返回改名成功。丢失准备响应时恢复并释放准备，丢失确认时重放原决定。四容器及故障测试核对旧版本、两服务重启、名称、效果和原件 SHA256。

原件删除及已结束成片删除先取得 Assets 保留回执。删除准备禁止同一文件获得新保留，已保留的文件拒绝删除。成片路径还核对原始渲染任务发布回执。Video 用本地短事务校验时间轴与任务修订，提交素材移除、素材编排、任务状态及结果，再由 Assets 结算和持久清理。并发保存经写锁复查文件。五容器 Chromium 与竞态测试覆盖已引用素材、旧成片修订、移除后的下载、派生资源和确认重放。

剪辑片段合并使用原有选段、应用与撤销规则。Video 持久保存确切原件摘要及合并范围，Rendering 编码、校验透明 ProRes 4444 并同时封存代理。成片在 Assets 发布后，Rendering 用一个事务登记结果和代理，Video 再完成任务。五容器 Chromium 核对格式、帧数、代理与缩略图、请求重放、应用、撤销和取消。

素材烘焙继续校验原件修订、处理状态及有效抠像参数。Video 记录原件摘要和任务，Rendering 用兼容站共享算法生成透明 PNG 或 1080p MP4，Assets 按封存摘要发布。Video 在确认后保存处理结果并把副本安排在源素材旁。五容器 Chromium 验证两种产物、透明像素、重复提交、编排与服务重启。

仅导出文件的分段任务共享原选段、编码预设和文件名规则。Rendering 封存整组 MP4 后发送带摘要的顺序清单。Assets 校验所有字节后原子登记整批和回执，ZIP 读取使用同一账号及任务的不可变清单，写入 ZIP 时重新计算每项摘要。大型 ZIP 暂存于 Assets 自有卷，启动清理中断文件。五容器 Chromium 与故障用例验证编码、Range、取消、重启、重放与整批回滚。

分段交接先冻结当前画布修订或新项目标识。Rendering 把素材封存到 Assets 的不可见批次。Visual 确认目标并在本地持久保留画布写入权，Video 记录提交或回收决定后再推进。Assets 在同一事务发布文件、Visual 归属和素材保留，Visual 同事务登记节点、输出历史和接收回执。旧修订、撤销及不完整上传触发精确回收。六容器 Chromium 和故障测试核对现有及新建画布、摘要、响应丢失、并发画布保存和源项目删除。
