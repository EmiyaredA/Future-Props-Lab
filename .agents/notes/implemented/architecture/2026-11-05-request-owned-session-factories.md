# Agent Note: 事件流与治理的会话工厂

Status: implemented

## Problem

后台 Runner 显式化后，额度、模板同步、工作台订阅和视觉助手仍直接打开全局数据库。两个装配无法明确绑定各自的日志、回执与取消结算。

## Decision

这些组件接收装配提供的会话工厂。治理用例将额度领取和释放绑定到同一工厂；模板预检的每个账号读取仍使用独立短会话。工作台订阅在读取快照后释放连接再发送，事件流由装配显式注册。

视觉助手将工厂传给工具绑定器、结算和事件回执；删除只为绑定全局工厂而存在的两个转发函数。请求结束或取消时仍在独立短事务记录原有终态，不改变账号绑定与审批校验。

## Alternatives considered

- 从已有请求 Session 推断全局工厂会隐含连接归属，也不适用于请求结束后的结算。
- 用 ContextVar 替代全局变量仍把执行依赖藏在上下文中，取消及后台恢复难以核对。

## Consequences

公开接口、SSE 内容和持久格式不变。ORM 仍限制在已有适配实现，本批不把显式会话工厂等同于完整业务存储端口。

## Verification

额度、模板、账号归属、Amadeus 恢复、视觉助手工具及工作台回归 96 通过、3 跳过。Ruff 检查通过，未访问正式数据。
