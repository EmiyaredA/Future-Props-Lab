# Agent Note: 独立工作台队列、指令和源码预览

Status: implemented

## Problem

兼容网站已经提供工作台排队、运行中插入指令和活动源码预览。独立 Agents 需要使用相同公共路由和权限边界接手这些能力。

## Decision

Agents 持有账号队列与轮次。推进队首前检查浏览器会话、可信入口和当前云控授权，在同一事务登记运行和原生任务。重启和失败暂停尚未执行的队列，恢复从新的授权会话开始。插入指令绑定当前 Mac 租约，发送前持久登记摘要，丢失回执时只保留未知状态。源码预览从已保存的活动取得相对路径，Mac 复核项目根后读取正文，Agents 将正文留在当前请求内，任务只保存摘要。

## Alternatives considered

让 Mac 持有队列会把用户会话和业务状态分散在两个进程。将源码放入持久原生回执会产生额外的项目文件副本。

## Consequences

Agents 就绪需要采集协调器、两个原生执行入口和轮次维护循环健康。浏览器通过当前轮次及队列修订读取变化。

## Verification

隔离协议测试覆盖已登记的公开路由、队列删除和恢复、插入指令只交付一次、已授权活动的源码及摘要回执。兼容站工作台、云控和独立 Agents 的既有入口同步复跑。
