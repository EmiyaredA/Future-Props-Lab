# Agent Note: Integrations 自有运行时、固定执行意图与外部步骤回执

Status: implemented

## Problem

Integration Center 的工具、MCP、Skills 和外部连接已有各自用例，但 HTTP 装配隐含创建旧数据库客户端，演示工具通过运行时模块加载单体数据库。思绪工坊的飞书同步直接读取连接 ORM 和凭据；拆成两个数据库后不能继续沿用。工具验证原本使用 Models 的实例总额度，也不能在拆分时静默取消。

文件与数据库提交之间还存在恢复风险：Skills 创建、增版或删除在提交成功但回复丢失时，旧异常清理可能删除已提交文件或恢复已经删除的数据。外部写入的超时不等于远端未执行，重新投递会重复追加正文或覆盖远端修改。

## Decision

- `fpl_integrations` 装配全部既有公共工具、MCP、Skills 和外部连接接口，自有数据库仅登记这些表及执行回执。账号是外部不透明 ID，外部连接不再保留到 Identity 的 ORM 外键；单体历史 SQL 不改写。独立入口只执行已核准迁移，服务锁、配置路径、公共操作清单和页面契约同时验证。
- HTTP 通过 `IntegrationBindings` 显式取得所属客户端与 Skills 存储。单体和 Amadeus 的旧兼容入口显式提供演示工具端口，普通生产 HTTP 不能自行加载旧演示运行时或数据库。
- Identity 接受当前原请求的固定 `IntegrationScope`，校验原 Session/API Key 后只持久保存内部 Actor 引用、具体资源及输入摘要。Integrations 与 Thought 保存不含执行权限的意图 UUID；每次出站执行持续复核原授权。源 JWT 仅在当前请求和授权交换中使用，不新增 JWT 持久化。
- 原有 `example_tools` 安装由 Models 保留目录 CAS，Integrations 在同一事务创建三项固定工具和安装回执。Models 保存不含凭据的协调记录；回复丢失先读取已接受回执，恢复后才落盘成功审计，不盲目再次安装。演示调用同样通过固定验证意图回到 Models 自有运行时。
- Models 的自有 `integration_capacity` 回执保留工具/MCP 验证原有共享额度。固定目标短期签名只能申请或结算同一已接受验证意图；取消或响应未知不会在重启时释放未确认占用。已确认结束的结算在退出登录后仍可完成，但不能重新授权执行。
- 飞书凭据只由 Integrations 解密。Thought 前台读取通过绑定原文章请求、连接和输入摘要的私有委托；后台读写通过固定意图及步骤签名。不可变正文、初始远端快照和图片的文件名/MIME/大小/内容摘要绑定提交意图。服务端验证 append 图结构、远端内容、图片块映射、上传 token 和删除前缀，而不是信任调用方给出的任意写入参数。
- 每个任务的 append、delete 和每图片块的 upload/replace 分别只有一个动作回执。确认结果可以重读；未知结果不重新调用供应商。写后读取并核验结构与版本观察。明确核对结束保存独立关闭栅栏，旧排队步骤无法随后执行；正常完成自动关闭该文档任务。
- 原生 stdio MCP 由自有 `native_mcp` 持久租约与回执编排，经仅回环可达、同时校验入口证明与 worker 凭据的 HTTP 通道交给 Mac。租约仅包含账号、意图、连接 revision、固定工具名与输入/启动摘要，不包含环境凭据或主机路径；执行前从当前连接短暂读取启动配置，并持续复核原 Identity 授权。Mac 本机只执行明确登记的完整 command/arguments 组合，环境变量键也须登记；不继承个人 HOME、PATH 或当前工作目录，MCP 的 stderr 不进入持久日志。环境值只在受认证响应及进程内存中出现，返回结构在回执落盘前脱敏。
- Mac 在动作开始前保存执行意图，结果持久化后只重试同一回执交付；已经租出的任务与中断结果从不重新排队。撤权会取消正在等待的 MCP 会话，未知执行保留额度；仅有明确终态回执才允许原验证额度结算。浏览器独立入口保留四类集成页面、资源深链接、只读权限和未保存导航保护。
- Skills 在数据库提交开始后保留文件，删除在数据库明确提交后才移动/清理目录。服务启动在接收请求前根据自有数据库快照核对版本，恢复旧暂存删除并清理未提交孤儿，拒绝链接和账号目录冲突。大文件上传阶段不持有写事务。

## Alternatives considered

- 跨库读取连接或账号表：破坏服务归属，也使账号撤权和连接 revision 检查分散到调用方。
- 在后台继续保存原 JWT：新增可复用凭据保留，且不能替代当前账号状态检查。使用 Identity 自有内部引用和目的固定的短期目标签名。
- 供应商超时后重新发送：无法区分远端未执行与回复丢失。保存未知回执，后续只能读取或明确核对结束。
- 只保存 step UUID：调用方仍可为同一 append 换一个 UUID 重发，因此动作键和任务共同唯一。
- 直接比较两次 `feishu_tree`：临时 block UUID 每次不同。先将完整图规范化比较，再用实际提交的临时 ID 验证远端映射。

## Consequences

独立服务不持有其他服务数据库或主机目录，网络和凭据边界可以由源码闭包与容器挂载检查验证。外部步骤和文件提交的未知结果保留现场，恢复不会自动产生新的远端写入。

本批尚未代表全部部署已切换。原生 stdio MCP 的真实子进程、租约与丢回复回执验收已通过；九容器部署和浏览器整体验收仍由集成批次执行。验证请求的未知额度目前没有既有公共核对入口，不能把内部回执当作已经提供的用户管理能力。父任务统一决定公开核对契约和最终发布门禁。正式数据、真实供应商与持久配置未读写。

## Verification

- 独立与兼容 Integration HTTP、Skills、CAS、Identity 固定意图及 Models 迁移：27 项定向回归通过。
- 实际私有 ASGI 与确定性 Feishu HTTP：完整正文/图片/删除、动作幂等、响应丢失不重放、明确结束栅栏与静默撤权中止，3 项通过。
- 三个隔离实际 ASGI 服务使用真实 Identity 签名：治理启用、演示安装后丢回复、Models 回执恢复、同操作重放、正式工具验证、共享额度结算和中央审计全部通过。
- 实际 Identity → Models：验证额度幂等申请、错误路径拒绝、重启保持未确认占用和退出登录后只能结算。
- Skills 创建、增版、删除分别注入提交后回复丢失，已提交版本可读且启动恢复按确认的数据库状态处理文件。
- 新进程验证 Integrations 装配不加载单体数据库、Console、Models ORM、Assets ORM 或工坊模块；全部公共契约与聚合 OpenAPI 比较一致。

- 原生 MCP 定向测试覆盖真实 stdio 发现、回执响应丢失后重启交付且执行次数为 1、错误账号/输入/本机启动配置与环境键拒绝、撤权不重派、取消持久化未知结果，以及正式 HTTP 验证绑定和共享额度结算。
- 独立 Integrations 页面测试保留 MCP 资源深链接、只读权限和未知页面恢复；`scripts/website/integrations_docker_checks.py` 提供隔离九容器与浏览器验收，不使用正式数据或真实供应商。
