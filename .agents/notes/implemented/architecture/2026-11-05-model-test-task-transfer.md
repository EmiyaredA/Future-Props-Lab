# Agent Note: 模型测试生成与转录历史迁移

Status: implemented

## Problem

模型测试生成任务的结果与输入参考文件由 Models 持有。转录任务的输入与生成参考素材共用目录。旧任务可能保留外部素材引用或处于提交状态未知的阶段。

## Decision

按账号迁移生成任务、参考素材和转录任务，核对目录、调用日志和任务归属。校验生成请求中每项参考素材的账号、任务、角色和类型。共享目录以两个数据集的并集确定原件清单，和生成结果一起逐文件验收回执。仍引用旧站 Assets 的任务必须经隔离旧站正式回填接口转换。启动时继续执行已有恢复流程。

## Alternatives considered

按任务类别独立枚举共享目录会把另一类原件视为多余文件。让新 Models 读取旧 Assets 路径会破坏服务边界。

## Consequences

关联缺失、账号冲突或文件未校验时无法通过迁移验收。提交状态未知的任务保留失败历史和日志，旧站原始快照可用于恢复。

## Verification

`tests/test_model_playground_transfer.py` 覆盖生成引用缺失、共享目录文件清单、超过 JSON 上限的生成结果、重复导入和中断任务恢复。
