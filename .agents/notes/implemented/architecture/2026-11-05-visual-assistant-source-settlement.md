# Agent Note: Visual 助手的源事务与恢复结算

Status: implemented

## Problem

助手发起需要同时准备素材保留、模型额度和对话记录。任一服务重启都可能发生在模型或对话已登记而响应丢失之后。

## Decision

Visual 用原画布和对话版本保护消息提交，保存不含请求令牌的源运行及结算决议。Models 在开通调用时冻结非秘密的凭据归因字段。恢复时仅结算专用服务签名可匹配原账号、运行和追踪标识，返还唯一日志回执。准备或结算期间保留对话和项目根记录。

## Alternatives considered

持久保存可用于再委派的请求令牌会扩大凭据暴露。让 Models 直接修复 Visual 的待定消息会跨越对话归属。

## Consequences

Visual 需要 0010 迁移，Models 需要 0020 迁移。两服务分别只读挂载结算专用凭据。公开助手流仍需要接入工具与审批。

## Verification

隔离测试覆盖陈旧版本、真实附件内容、Visual 重启、无签名和不匹配运行的拒绝，以及原浏览器会话结束后的结算恢复。
