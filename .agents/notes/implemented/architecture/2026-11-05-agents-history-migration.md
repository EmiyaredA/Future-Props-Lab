# Agent Note: 独立 Agents 历史迁移

Status: implemented

## Problem

旧站 Workbench 的项目、对话、原生历史及同步进度存放在兼容数据库。独立 Agents 需要可校验和可续跑的历史导入，同时避免切换后重派旧任务。

## Decision

回环维护端口从只读封存快照导出九个账号数据集。按父记录优先导入，核验账号和父子关系，将精确批次回执与记录写入同一事务。旧活动轮次导出为已中断，待执行队列暂停并清除旧会话绑定，遗留采集请求终止。历史条目以原有文本和身份重建搜索索引。

## Alternatives considered

复制整库会带入无关业务、旧授权和可重派任务。复制旧搜索虚表会保留过期或缺失的索引行。

## Consequences

账号 ID、会话 ID、历史条目、游标和修订保留。原生会话的引用仍指向同一 Mac 上的已登记来源。维护客户端核对每个数据集的记录数和批次摘要，并比较由源历史条目计算的索引摘要。

## Verification

独立维护进程测试覆盖中途停止、续跑、重复导入、跨账号拒绝、队列暂停、活动审批转未知和 FTS 逐条摘要。
