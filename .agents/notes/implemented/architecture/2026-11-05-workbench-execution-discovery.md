# Agent Note: 独立工作台项目发现

Status: implemented

## Problem

独立工作台需要从可信 Mac 枚举允许访问的项目和 CLI，并让当前账号在独立数据库中登记本机项目及创建对话。

## Decision

Agents 保存项目和对话归属。Mac worker 使用专用原生凭据从回环入口领取范围固定的目录与连接检查任务。Agents 在派发、领取后的授权检查及返回结果前复核 Identity。短期浏览器断言只保留在请求进程内。公网仅获得 TOML 对当前账号开放的项目投影。本机注册目录经过 Mac 校验，对话创建在提交前复核当前账号的项目绑定。

## Alternatives considered

容器直读 Mac 项目或挂载整份配置会扩大目录、连接凭据及其他本机设置的可见范围。只在派发时验证身份会使已撤销请求继续取得结果。

## Consequences

回环 worker 与采集器使用独立凭据。服务重启会关闭旧发现任务，客户端可发起新的只读检查。工作台对话执行仍由独立的就绪门禁跟踪。

## Verification

隔离测试覆盖身份和入口隔离、项目登记及创建、失效授权和 Mac 结果的范围校验。Agents 镜像通过源码闭包构建。
