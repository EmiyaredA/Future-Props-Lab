# Agent Note: 剪辑与特效历史记录和素材范围迁移

Status: implemented

## Problem

Video 与 Motion 的历史文稿、编辑回执、素材元数据和任务需要保留原 ID、账号、修订和时间。独立 Assets 需要恢复账号和项目文件范围才能服务这些数据。

## Decision

两个应用复用受控维护传输，按原项目归属验证根记录及子记录。每个批次以源提交、账号、游标和摘要绑定，事务同时写入原记录及回执。Assets 已完成原件逐文件摘要校验后，再对每个项目核对素材 ID、版本和大小的集合摘要并重建范围。

## Alternatives considered

工程包适合复制与交接，会重新分配部分 ID。正式迁移使用账号范围的原记录批次，以保留编辑回执和任务指向的历史标识。

## Consequences

项目、文稿和编辑回执进入来源覆盖清单。Motion 成片和 Video 派生文件由 Rendering 维护入口读取并核验。Video 的历史成片与分段下载关系仍由迁移门禁跟踪。两种服务的正式就绪条件继续包含完整历史核验。

## Verification

在真实兼容站生成合成账号、剪辑和特效工程、素材与编辑。完整停写并封存来源后启动六个回环维护进程，验证范围过早导入被拒绝、重复批次结果相同、两个原件摘要一致。恢复独立快照并用原账号会话读取两个文稿和原始字节。


Rendering 每个文件以长度与 SHA256 接收，确认全部文件后才恢复历史任务绑定，不重新运行旧渲染。隔离演练用兼容站实际生成 MP4、透明 PNG 序列与剪辑缩略图，注入不完整上传并重试。独立服务经原鉴权 URL 读回相同字节并验证 206 分段读取。仍在运行的旧非媒体任务会阻止制品迁移。
