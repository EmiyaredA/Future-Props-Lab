# Agent Note: 主机能力复核的显式装配

Status: implemented

## Problem

面试准备与远程桌面复核直接访问全局数据库；面试 HTTP 又通过 Session 元信息寻找回调，无法看出执行器属于哪个应用实例。

## Decision

面试执行器状态适配显式接收配置和会话工厂，Runner 接收状态查询回调。兼容网站与独立服务在应用状态登记各自的适配；HTTP 只调用装配提供的回调，Session 元信息不再保存这一业务服务。

远程桌面桥接接收会话工厂与配置读取器。每次复核仍重新读取授权和空闲超时，配置读取器保留现有热更新语义。

## Alternatives considered

保留可选全局工厂回退会让测试遗漏装配缺口，因此这些依赖均为必填。

## Consequences

账号校验、取消、迟到结果保护及远程桌面协议不变。面试其余存储与文件适配的分层仍属于后续业务迁移。

## Verification

面试准备、独立面试服务、云控和架构边界回归 53 通过、1 个真实 CLI 测试按原有显式启用条件跳过。远程桌面使用临时回环协议桩。Ruff 检查通过。
