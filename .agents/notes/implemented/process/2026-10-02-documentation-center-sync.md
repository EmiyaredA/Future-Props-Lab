# Agent Note: 按实际应用入口同步产品文档中心

Status: implemented

## Problem

新增工坊、桌面助手和创意发布能力没有完整的使用指南。覆盖脚本按固定目录枚举，遗漏思绪与演示工坊；旧实现路径使内容校验失败，SDK 参考仍把桌面 Session 专属操作描述成通用 API Key 操作。

## Decision

按用户明确要求维护产品正文，保留既有文章标识和阅读器。新工坊复用应用上下文目录；桌面与助手、创意工坊复用平台基础分类。覆盖脚本发现全部使用正文，要求登记实际入口与存在的核验依据，内容测试对照应用注册表和覆盖清单防止遗漏。

SDK 文档从现有契约生成，补齐中文模块名称并按桌面、浏览器 Session、配对通道和公开只读入口记录鉴权差异，不修改公共业务契约。配图使用隔离数据和正式业务 API，来源与哈希保留于既有清单。

## Alternatives considered

- 只增加介绍页：不能修正失效操作步骤，也不能发现新增应用在覆盖清单中遗漏。
- 全量改写阅读器：当前目录、搜索和链接机制可复用，改版会扩大与内容同步无关的范围。
- 手写生成参考：后续契约检查会覆盖手工修改，继续以生成器维护唯一真源。

## Consequences

使用指南能够从实际应用入口找到，覆盖清单不再静默遗漏未登记的使用正文。新增分类仍需登记入口与核验依据；截图只说明实际捕获的状态，不证明外部模型效果。

本次是产品文档更新，不是工程决策整理。文档保护脚本保持原样，会报告本轮已授权的文档变更；Note 不复制产品指南。

## Verification

文档内容和渲染检查验证文章标识、锚点、链接、来源、图片与应用覆盖。SDK 文档检查核对生成物，独立测试覆盖新模块名称及桌面专属鉴权说明。最终执行结果在 `docs/operations/documentation-acceptance.md` 记录。
