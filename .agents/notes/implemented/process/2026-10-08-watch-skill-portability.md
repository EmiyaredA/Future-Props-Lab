# Agent Note: watch Skill 宿主通用化

Status: implemented

## Problem

watch 的工具白名单、报告指令和请求标识绑定某一代码 Agent。其他宿主即使能运行 Python、查看图片和读取文本，也可能缺少同名工具；文本读取成功还可能被误认为已取得视觉证据。

## Decision

watch 的中文指南按命令执行、文件读取、图片查看、用户交流和网络访问等实际能力描述流程。移除特定工具白名单与斜杠调用假设，说明远端路径、执行环境、能力缺失和有限证据的处理。凭据优先由宿主安全配置提供；安装、保存凭据及外部传输遵循已有授权。

脚本保留下载、抽帧、转写和引擎参数，只将 watch.py 的文档与报告提示改为宿主通用表述，将 whisper.py 的自定义 User-Agent 去除产品标识；SOURCE.md 记录这两处上游适配。应用经已授权 SDK 追加新版本、切换默认版本，将 Codex 标签替换为通用 Agent，保留其他标签与启停状态。

前一版中文化见 [watch 中文维护](2026-10-08-watch-skill-chinese.md)。

## Alternatives considered

- **仅去除正文中的工具名称**：报告和请求仍保留宿主绑定，无法完整表达通用性。
- **重新实现下载与转写后端**：与宿主适配目标无关，扩大维护和验证范围。

## Consequences

各类具备相应能力的助手可复用同一脚本协议；能力不足时限定回答证据范围，不承诺任意宿主均能运行。上游脚本不再全部逐字相同，来源记录明确维护差异。历史应用版本保留，上传不安装依赖或执行分析任务。
