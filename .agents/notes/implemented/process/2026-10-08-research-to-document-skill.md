# Agent Note: 调研到文档 Skill 初版

Status: implemented

呈现与存档方式的后续调整见 [普通笔记与多维表格组织](2026-10-08-research-native-notes-and-tables.md)。

## Problem

产品使用与技术／论文调研缺少统一的问题、证据和结论记录，聊天中的阶段产物难以监督、续做和复核。用户希望在 Codex／类似 Agent 中发起，在思绪工坊保留过程与文档，并先审阅呈现方案。

## Decision

官方自动化 Skill 包新增 `research-to-document` 叶子。Skill 复用宿主搜索与读取能力，按产品和技术两种模式成文；Q/S/E/C 稳定 ID 连接问题、来源、证据与结论，检查点保存阶段、未决问题和下一步。模板和存档约定位于叶子目录，标准库校验器只读检查关系与状态，不访问网络或数据库，不证明证据真实。

思绪工坊存档复用已有正式 CLI/SDK 操作、revision 和回读，跨文档保存逐项确认，失败保留 pending。新增内容不改变业务 API、schema 或应用内 AI 写作入口，不提供后台运行服务。项目总览、来源台账和报告审阅的静态可点击原型仅位于已忽略的 `.local/research-workbench-preview/`，使用虚构材料展示拟议呈现方式；专用 UI 尚未集成到产品。

## Alternatives considered

- **立即增加独立调研 App**：流程尚未通过实际任务打磨，会提前承担运行系统与界面维护成本。
- **只写一份成文提示词**：无法维护可恢复状态，难以发现引用断链或区分文档声明和实测。
- **保存逐字执行日志**：监督成本高，缺少面向问题与证据的导航。

## Consequences

Skill 允许单独安装或随官方包发现；个人 Codex skills 目录通过同名符号链接发现仓库叶子，保持唯一维护源。正常执行不修改仓库源码。存档适配仍由 Agent 按运行中的正式契约操作，当前交付没有实测真实 App 存档。结构校验允许披露未决问题的完成状态，拒绝未读来源支撑证据、无实验产物的实测标记、已回答问题无已核对结论和未确认目标的 synced 状态。后续改善应来自真实调研任务。

## Verification

Skill Creator quick_validate 与官方包结构校验通过；`tests/test_research_skill.py` 在无公共 conftest 的隔离运行中 13 项通过，覆盖来源读取、实测产物、断链、完成时未决问题披露、存档状态和畸形输入。Ruff 检查与格式检查通过。共享测试入口在首次运行时因并行工作中的迁移模块未就绪无法加载，没有为此改动其他任务文件。

本地原型经独立临时 Chrome 渲染，生成三个主要页面和深色、手机预览；检查引用跳转、筛选、搜索、意见本地保存、Markdown 导出、主题切换与 390／768／1024 宽度无根级横向溢出，未连接真实 App。产物与验证记录保存到 `.local/research-workbench-preview/`，不进入受保护的文档中心。
