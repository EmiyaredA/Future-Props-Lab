# Agent Note: 记忆系统四集动画的可复核制作通路

Status: implemented

## Problem

用户批准连续二维时间动画，要求制作完整四集，随后指定案例人物改为 Q 版真由理，并保留红莉栖日语旁白。短预演不能代表完整交付；长片还需要固定源码、分镜、真实音轨时间和图形状态之间一致。

## Decision

在已忽略的 `.local/research/agent-memory/anatomy-v4/series/` 独立制作，保留旧版本，不改变产品接口、数据库或产品依赖。56 段日中脚本按四集组织，每段关联固定源码证据。按用户要求先生成项目和比较场景概念，再以原生 SVG 和确定性时间模型实现动作，不以概念图充当整段动画背景。真由理使用独立透明姿态与行走图集；红莉栖沿用清晰嘴部轮廓，口型读取实际音轨能量与日语音节近似时间。

本地 1.7B TTS 通过正式 SDK 提交，每个任务重新上传参考输入；供应商输入素材具有单任务认领生命周期，不能跨任务复用已认领的素材。明确拒绝且未创建任务的 `asset_in_use` 可以准备新输入；提交结果不明时停止并核查，不能自动重复提交。脚本文本、模型及参考版本共同确定缓存键。

实际句子时长驱动字幕和动画节拍。渲染在完整 30fps 时间网格比较状态，运动帧逐帧输出，完全相同的相邻状态只渲染一次，编码时按原始帧数保持；不会通过降低动画采样率冒充 30fps。4K 主片生成后再编码 1080p 版本，分别检查嘴部与字幕。渲染缓存包含场景、角色、资源与依赖版本；跨版本复用已审查帧需要显式参数，不默认沿用旧图片。

长静止段的 concat sentinel 不能被输出时长条件提前丢弃，封装按精确视频帧数结束；补渲染帧先统一编号位数。角色图集与红莉栖纹理在 Remotion 中显式等待加载，独立交互页不调用依赖 Composition 的预加载组件。整集旁白使用两遍响度整理，目标 -19 LUFS、真峰值上限 -1.5 dBTP；保留样本数与原语音包络，核对词语时间无偏移。

## Alternatives considered

持续使用同一本书或机械装置无法解释各项目真实职责；用户已明确拒绝。直接把概念生图铺成幻灯片不能表达时间和状态变化。对每个相同静止帧重复进行浏览器截图只增加制作成本，逐帧状态相等后复用保留了原时间网格。

## Consequences

四集双分辨率视频、独立音轨与字幕、交互 HTML、22 页研究 PDF、研究 HTML 和制作源码均实际生成。56 段旁白、370 条字幕共 2524.57 秒；12 张机制与综合场景概念用于构图和动作设计，最终文字与状态由代码控制。未知能力、未运行上游和未复跑基准单独说明。旧样片保持在原位置，新版统一入口为 `.local/research/agent-memory/anatomy-v4/series/output/index.html`。

## Risks

生成概念可能偏离指定案例或写出错误标签，最终事实、坐标和文字由已核实的场景代码控制，偏离的草稿不作为证据。ASR 查漏与对齐不能替代母语听审。缓存键对应实际文本及音轨；参考素材、凭据和模型权重不随可复现源码包分发。口型属于真实音频包络和日语元音／闭口时间驱动的近似表演，不宣称专门捕捉的口型。

## Verification

九个 checkout HEAD 与固定清单一致；字幕顺序、音轨 SHA、全部段落的证据、时间边界、教学 PPR 权重和 774 个可见停顿帧闭嘴检查通过。四集 4K／1080p 共八个最终编码完整解码、帧数和章节一致，无黑帧区间；导出 168 张章节与转场帧并检查代表性机制，分别放大检查实际 4K 和 1080p 嘴部。响度整理后 56 段交叉相关的时间偏移均为零。四集在本地 HTML 中实际播放并能跳到末尾。390px／1280px 明暗、键盘、4× 和减少动态检查通过，22 页 PDF 全部渲染并逐页检查，源码与音轨 ZIP 完整性通过。

Agent Note 树、格式和归档封印检查通过。文档中心保护检查提示任务开始前已有的两处 SDK 文档未提交改动；本任务未修改这些受保护路径，也未覆盖用户改动。产品 API、数据库及现有产品依赖未修改。
