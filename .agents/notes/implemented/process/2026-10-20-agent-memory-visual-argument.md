# Agent Note: 记忆系统科普视频的二维卡通原理样片

Status: implemented

## Problem

用户指出旧版全程活页书与知识内容脱节。新版机械装置概念增加了理解隐喻的负担，随后三格对话／图谱信息图又退化为 PPT。问题在于画面没有承担原理讲解，不能通过提高分辨率或换一套装饰解决。

## Decision

保留四集、日语 1.7B 红莉栖配音、中文字幕、按镜头需要出场的角色与双分辨率交付目标。用户进一步指定二维卡通风格，停止机械外壳、三格图文和发光立体图谱路线。阅读公开 Vibe 视频制作项目的实际源码与示例后，以约 69.3 秒的 Graphiti 时间机制样片验证视觉方法；四集正片仍未完成。

镜头以输入、状态、条件变化与结果为契约，同一事实、关系或证据跨镜头保留身份。时间筛选必须实际改变有效关系，图传播的强弱与段落排序必须来自同一个教学模型。生图确定单镜头构图、关键状态和可运动图层，不把信息图静帧的缩放当成机制动画。用户最新指示优先于 anatomy 默认的机械隐喻要求。

## Alternatives considered

继续为各系统设计机械装置会增加一层映射。改成图文分栏仍把解释负担留给文字。直接安装参考项目全部技能会引入不适用的供应商、审批和多代理流程，因此只读其源码和制作记录，选择适合本题的视觉方法。

## Consequences

在已忽略任务目录保存参考项目固定 commit、阅读文件、实际抽样范围与来源链接。二维关键帧由生图确定方向，小林、住处、报告和带日期的记忆由原生 SVG 独立绘制；HTML 与 Remotion 共用确定性教学模型。人物只搬家一次，查询日期改变选择的关系而不改变人物位置。红莉栖在引入与边界说明时出场，实际 WAV 能量与近似音节驱动口型；嘴部使用输出像素轮廓并缩小肤色遮罩。源码包包含可直接播放的样片及提示词，排除模型、凭据与原始参考录音。

2026-10-21 根据实际观看反馈简化时间呈现：相似的横轴和交叉连线不能直观区分有效期与报告到达时间，故删除这些轨道和查询射线。住址记录直接标注起止日期，以边框和勾选显示查询匹配；问题日期按三个讲解状态切换，避免闪过无关日期。迟到报告展开时，背景退淡，分别标出描述日期与收到日期，再回到原记忆。报告收到时间表示该来源的到达，并不声称等同于去重后关系的创建时间。手动查询直接展示匹配记录，避免报告特写遮住结果；继续复用原始音频、字幕与口型。

该日期简化实验随后收到“动画仍要体现时间变化”的反馈，未成为获认可的后续视觉规范。该方向停止继续导出，后续采用 [单一事实时间带与历史回看预演](2026-10-21-agent-memory-time-motion.md)。已实现的二维状态模型与验证记录仍保留。

## Risks

公开示例可能只证明技术流程或视觉风格，不能证明机制正确；抽样画面无法替代完整音视频验收。教学状态模型必须明确标识，避免把示意动画描述为上游项目的真实运行。图像先行也可能再次退化成静态信息图，因此动态因果需要单独验证。
