# Agent Note: 从封存账号生成迁移计划

Status: implemented

## Problem

整站转移需要统一的计划标识、来源摘要和账号集合。手工填写账号清单可能遗漏停用账号或误用另一份快照。中断后换用新计划会改变确定性批次标识。

## Decision

从完整校验过的封存来源生成独占计划文件。账号清单从已封存数据库的只读连接取得。临时文件写入并同步后用独占链接发布，已有文件始终保留。整站来源检查再次比对计划与全部封存账号。

## Alternatives considered

手工录入与在线账号分页结果都可能遗漏账号，且在线清单与停机时点不一定一致。

## Consequences

计划含短期维护凭据，保留在快照外的本机 0600 文件。公开输出只显示计划路径、运行标识、源版本与账号数量。续跑沿用原计划。

## Verification

真实隔离快照和旧站回滚测试使用该入口生成计划，验证摘要错误、账号缺漏和计划覆盖均被拒绝。随后使用同一计划导入并读回记录。
