# Agent Note: 记忆系统科普视频的日语讲解与中文证据层

Status: implemented

## Problem

用户指出早期图文脱节、讲解生硬，并确认跨语言音色克隆的中文开头发音异常。随后明确改为日语讲解，保留中文字幕，使用项目内红莉栖角色、1B 以上语音模型和 anatomy 图解。

## Decision

制作工具和交付物仅位于已忽略的 `.local/research/agent-memory/anatomy-v3/`。使用正式 App 安装、启用并加入目录的 Qwen3-TTS 1.7B Base，正式 SDK 读取用户指定参考音频并逐章生成日语，不修改产品模型接口或数据库。中文研究稿与人工日语译稿逐句配对；本地日语 ASR 仅提供时间与审核线索，中文字幕不取自自动翻译。96 个日语机制短语驱动与交互页面共用的确定性图形状态。

实际 WAV 的 60 Hz 能量决定开口和停顿闭嘴，日语读音转换得到的元音与闭唇形状补充二维口型。待机、讲解、思考、提示边界与收尾等六类动作保持完整人物姿势，避免旧分件抬臂接缝。旧中文实验与未完成编码保留为实验记录，不混入日语交付物。

## Alternatives considered

继续用中文中间参考能改善部分中文发音，但用户已选择日语。仅替换音轨会使字幕、口型和图解触发脱节，因此一并重建。逐词识别结果直接充当字幕会引入专名错误，不采用；语音先加速以适配原时间轴也不采用。

## Risks

ASR 内容相似度与语言识别不能证明发音绝对正确，也不能验证音色身份。识别词内部均分音节的口型是近似，不声称恢复真实表演。固定源码阅读和教学机制动画不等于部署上游系统或重新运行论文基准。语音模型许可证不替代原角色素材许可。

## Consequences

24 章日语旁白均由 1.7B 生成，中文字幕和图解触发点按实际音轨对齐。日语较原中文长，因此缩短章节间纯静音，不加速语音，完整视频保持在 12–18 分钟内。独立源码包包含冻结研究证据、生成器和模型任务元数据，不包含权重、凭据或原始角色录音。

## Verification

正式 API 回读 24 个任务确认实际模型为 1.7B；111 个自动语言窗口均为日语，逐章 ASR 无达到审查阈值的连续缺句。时间轴包含 178 条中文译文字幕和 96 个机制触发点。32,363 帧角色状态均确定、有限，音量停顿处闭嘴；六类动作均出现。交互图解 192 个明暗状态、390px、键盘、减少动态与 4 倍细节通过。最终 MP4 为 1078.784 秒、1920×1080、30fps、H.264/AAC，24 章，音视频长度匹配，全片无检测到的黑帧；实际编码抽查覆盖全部章节 48 帧与全部转场 69 帧。研究 PDF 更新为最终制作方式并逐页检查 21 页。验证记录位于任务目录；自动语音检查仍不等于逐音素人工听审。保留仓库原有未提交改动。
