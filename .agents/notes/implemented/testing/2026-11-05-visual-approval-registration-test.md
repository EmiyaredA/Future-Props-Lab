# Agent Note: 同步视觉审批回归的等待登记

Status: implemented

## Problem

语音 WebSocket 回归会退出共享测试应用的 lifespan，关闭这个应用的审批协调器。
随后运行的视觉审批测试借用同一实例，导致有效审批无法登记。该用例验证页面修订号
和提案修订号分别承担的职责，过期行为由专门的审批生命周期测试验证。

## Decision

视觉审批测试使用单独的审批协调器，通过登记回调等待操作可审批，再发送带有不同
修订号的请求。失败时清理等待任务。

## Alternatives considered

单纯增大等待期限仍需要猜测等待任务是否已登记。显式回调建立测试与实际登记状态的同步。

## Consequences

运行时审批期限和行为保持当前契约。HTTP 回归继续覆盖审批按提案修订号结算及重复请求
返回 404。

## Verification

视觉助手 HTTP、独立助手流、审批生命周期和画布工具的 13 项定向用例通过。

增加语音 WebSocket 用例先运行的顺序复现。隔离协调器后，语音、视觉助手、独立助手流、审批生命周期和画布工具的 25 项测试通过。
