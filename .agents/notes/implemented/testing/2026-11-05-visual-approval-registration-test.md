# Agent Note: 同步视觉审批回归的等待登记

Status: implemented

## Problem

并行执行镜像构建和全量回归时，视觉画布审批测试返回 404。该用例仅等待一轮调度，
并设置一秒审批期限。该测试要验证审批携带的页面修订号无法覆盖提案修订号，
过期行为由专门的审批生命周期测试验证。

## Decision

审批 HTTP 回归通过 broker 的登记回调等待操作可审批，再发送带有不同修订号的请求。
给这段跨 HTTP 与 SQLite 的验证十秒完成时间，并在断言失败时清理等待任务。

## Alternatives considered

单纯增大等待期限仍需要猜测等待任务是否已登记。显式回调建立测试与实际登记状态的同步。

## Consequences

运行时审批期限和行为保持当前契约。HTTP 回归继续覆盖审批按提案修订号结算及重复请求
返回 404。

## Verification

视觉助手 HTTP、独立助手流、审批生命周期和画布工具的 13 项定向用例通过。
