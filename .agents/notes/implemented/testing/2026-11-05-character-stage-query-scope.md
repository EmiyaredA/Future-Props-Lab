# Agent Note: 角色舞台测试查询范围

Status: implemented

## Problem

Galgame 角色舞台测试重复从整个编辑器查询按钮，jsdom 为不相关面板计算可访问名称与样式，导致 15/20 秒门禁波动。单条位置编辑测试的诊断记录中，样式计算累计约 10.8 秒、全页面角色查询累计约 8.4 秒。

## Decision

将角色按钮查询限定到当前角色工作区，继续使用角色与可访问名称匹配。跨面板导航及挂载到外部的确认弹窗保持各自查询范围。每次查询重新取得当前面板，避免切换页面后复用已卸载节点。

## Alternatives considered

- 提高超时不会减少反复扫描无关 DOM 的开销。
- 跳过可访问名称检查或模拟计算样式会削弱交互验证。

## Consequences

生产组件和测试断言不变，保留原有超时配置。本次范围收敛已使全部七项测试通过，不为减少单条用例时长重复创建测试场景。

## Verification

角色舞台文件 7 项通过，耗时约 38 秒；原超时的位置编辑、独立方案及表情详情分别约 9.2、8.6、12.6 秒。诊断日志位于忽略的本地架构验收目录，诊断包装未保留在测试源码中。
