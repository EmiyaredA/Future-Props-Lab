# Agent Note: Galgame 编辑器测试的查询边界

Status: implemented

## Problem

Galgame 编辑器集成测试在并发验收时会超时。角色舞台和演出测试的 CPU 采样中，按角色查询分别消耗约 18 和 20 秒，React 渲染约 3 秒。首次进入资源面板还要等待测试运行器转换懒加载模块。

## Decision

测试按当前的舞台设置、表情呈现、场景或时间轴面板查询控件，保留可访问名称断言。测试准备阶段预载真实模块，编辑器仍由原有懒加载入口渲染。测试继续等待实际的保存回执和交互结果。

## Alternatives considered

- 延长用例等待上限会保留重复扫描的成本，冷加载与交互断言仍共享时间预算。
- 在生产代码中提前加载编辑器面板会改变实际浏览器下载和加载边界。

## Consequences

测试依赖明确的编辑器面板范围，浮层仍从它的实际挂载位置查询。静态构建的浏览器测试继续覆盖完整样式和首次加载。

## Verification

使用原有超时运行角色舞台、舞台与声音、编辑菜单、媒体、脚本和素材编辑用例。
