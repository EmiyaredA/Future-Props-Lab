# Agent Note: 模型安装和语音接入的浏览器入口

Status: implemented

## Problem

旧 Chromium 用例从业务站安装本地模型。当前安装命令属于本机管理中台，业务账号只接入已安装的模型。

## Decision

管理浏览器用例使用确定性响应覆盖安装、取消和重试，并核对请求使用当前修订。业务站用例从已安装状态开始，检查显式接入后，通过手机参数面板执行语音合成并下载结果。布局用例检查业务站对本机安装入口的提示。

## Alternatives considered

- 在同一个页面模拟全部操作。业务入口已经没有安装控件，模拟这一行为会丢失权限边界的覆盖。

## Consequences

两个入口分别覆盖自己的操作和界面。测试使用模拟模型响应，可在无模型权重的隔离环境运行。

## Verification

管理入口 8 项 Chromium 用例通过。业务端的已安装模型接入、语音结果下载和响应式布局用例通过定向复测。
