# Agent Note: 画布媒体浏览器夹具响应缩略图请求

Status: implemented

## Problem

画布预览走认证缩略图接口，浏览器夹具只对原件接口提供图片。缩略图请求误收到文件列表
JSON，导致原图比例与边界断言无法取得可解码图片。

## Decision

通用视觉工坊夹具在缩略图和原件路径都返回图片。完整预览用例为三种指定素材同时提供
两个路径的同尺寸图片，继续检查媒体比例、对齐和历史切换。

## Alternatives considered

将断言改为只检查弹窗是否可见，会漏掉图片没有成功解码的情况。

## Consequences

产品的素材读取方式保持现有契约，浏览器测试仍按每个素材的像素尺寸和视口边界验收。

## Verification

隔离兼容站的固定构建通过画布图片预览的 8 项 Chromium 用例。
