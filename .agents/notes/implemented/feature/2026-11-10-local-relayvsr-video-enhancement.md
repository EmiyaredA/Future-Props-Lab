# Agent Note: 本地 RelayVSR 视频增强

Status: implemented

## Problem

桌面本地模型需要处理超过单次显存预算的影片，逐段交付并支持暂停与恢复，同时保持原片音画时间。

## Decision

Models 保存镜头切点、固定分段和已发布段数。Metal 子进程通过受控 RGB 帧文件处理有界窗口，单任务复用模型上下文。
原片等比缩放与增强预览使用相同范围。每个片段通过校验后发布，整片用片段的视频轨和源音轨合成。
运行时入口按主机验收证据启用，模型权重和输入输出分别由部署及账号持有。

## Alternatives considered

整片一次推理的缓存随时长增长。每段单独启动运行时会重复加载大模型。

## Consequences

任务恢复粒度为已发布片段。首版支持 SDR 恒定帧率 MP4 和 MOV。Metal 进程使用互斥锁，父进程崩溃后主动退出。

## Verification

隔离测试覆盖分段、检查点、暂停和续跑，以及实际 FFmpeg 帧数和音轨校验。实机验收另记录峰值和对比视频。
