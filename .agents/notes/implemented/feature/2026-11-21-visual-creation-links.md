# Agent Note: 剧本选段、制作节点与逐镜白模联动

Status: implemented

## Problem

分镜规划属性挤占实际提示词和模型输入，剧本、设定库与白模缺少可修复关联。若直接保存整份白模为镜头结果，会让共享布景被镜头走位覆盖。

## Decision

分镜复用节点生成编辑器；属性与输出版本按需切换。剧本来源扩展为版本、原文摘录和浏览器 UTF-16 偏移；唯一原文可在前文编辑后重新定位，失效时保留摘录并显式核对。关联更新不改生成提示词或实际输入。

新增项目自有 `creation_links` CAS 文档：场景卡绑定本项目完整 3D 舞台，角色/道具卡绑定稳定对象 ID。账号共用卡片不保存项目关系。镜头在分镜文档中保存舞台版本、机位及允许的对象位姿/动作覆盖；共享结构变更从镜头入口拒绝并指引切换范围。共享舞台更新后刷新实际修订，旧镜头保存因版本冲突而保留草稿。

预演采用先捕获、预览，再确认同媒体新增/替换。上传复用请求标识、文件摘要和确定性节点 ID；上传成功但设置保存失败时重试只保存设置。实际能力和参考数量验证通过后更新制作草稿，不自动生成。替换按原输入位置保持顺序和别名，解除已被替换的设定快照关联。

追加 Visual 0017 与网站 0137，旧记录不改写。独立历史迁移保留完整绑定。便携快照保留舞台顺序 ID 对照、重映射逐镜引用；账号设定卡及其绑定解除并提示。最终统一项目壳由并行的控件一致性任务整合，此处不覆盖其公共导航变更。

## Alternatives considered

- 将舞台 ID 写入共用场景卡：不同项目之间会互相覆盖，改为项目自有关系。
- 每镜复制完整舞台：结构修改无法共享且数据冗余，改为共享舞台加允许字段覆盖。
- 白模导出立即生成：无法让用户核对实际输入，因此采用和生成分两步。

## Consequences

关联和实际生成输入分开；修改关系不会隐式改变已保存制作。失效历史引用保持可修复。新增关系表需要走显式迁移，不能由前端创建。镜头模式拒绝结构改动，需切换共享舞台编辑。

## Verification

隔离 API 验证项目/账号权限、CAS、UTF-16 选区、舞台版本冲突、便携快照重映射和旧文档兼容。独立历史迁移与回滚验证绑定记录；前端验证原位置替换、能力上限及共享几何隔离。浏览器使用本轮独立测试库检查剧本选段、分镜编辑、场景关联和白模入口，不调用付费模型。
