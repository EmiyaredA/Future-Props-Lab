# Agent Note: 点击集名按块查看和排序分镜

Status: implemented

## Problem

点击剧本目录的集名仍然打开首个分镜，无法按整集顺序组织已有分镜。此前将用户的一次性内容整理请求实现成标题拆分按钮，增加了用户不需要的流程；第一镜还夹杂整集说明和重复标题。

## Decision

集名选择进入整集视图，单镜选择保留正文编辑器。整集按本集 `scenes` 顺序展示分镜块，以编号和连接箭头表示先后；明确关联的制作节点提供当前输出缩略图和制作入口。拖动手柄与上下移动只改本集分镜顺序，沿用剧本草稿、revision 保存、失败重试及离开保护。进入制作前先完成原有保存流程。只读入口保留查看，隐藏排序操作。

本决定替代[剧本标题拆分方案](2026-11-22-script-shots.md)中的通用整理流程。移除该按钮、提示、自动拆分保存规则及其专用代码，正文按原样保存。用户已将目标项目分成八镜；本次通过现有浏览器编辑器清理并保存八镜正文，去除重复标题以及第一镜中的集名、基调和人物节奏说明，保留镜头动作、对白和声音。不增加内容清理工具或设置项。

## Alternatives considered

- 点击集名继续定位首镜：不能满足用户按整集查看和排列的需求。
- 新建独立编排文档或同步修改制作文档顺序：引入两份顺序和额外写入，当前直接使用已有剧本分镜数组即可。
- 保留通用拆分入口：用户明确要求直接完成一次性内容整理，并移除此入口。

## Consequences

不增加 API、持久字段或数据库迁移。整集顺序由剧本持有，同一剧本条目关联的多个制作保留其原有顺序；未关联和未产出分镜保留占位。整集块展示已有输出并通向原制作区，沿用其视频预览和生成流程。项目内切换集和单镜不丢失未提交正文，保存失败保留排序草稿。本机验收产物位于忽略的 `.local/script-shots/sequence-results/`。
