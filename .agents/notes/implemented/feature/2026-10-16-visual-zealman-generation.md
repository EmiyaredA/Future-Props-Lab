# Agent Note: 视觉创作工坊接入 ZEALMAN 视频工作流

Status: implemented

## Problem

模型测试已接入 U06、U17，但工坊仍只接受原有视频协议。看板生成器位于窗口底部时，模型列表固定向下展开，选项落到窗口外。

## Decision

- 工坊通过现有模型目录返回工作流能力；模型 ID、项目素材、画布 CAS 和输出归档沿用原入口。两个工作流支持文生视频与全能参考，不承诺首尾帧约束。
- `llm/schemas/workflow_video.py` 拥有共用参数契约；供应商适配器统一校验参考数量、参数、时长与音频搭配规则。工坊额外校验项目/Workspace 素材权限、格式和总大小。默认种子在任务创建时生成并写入快照，恢复沿用该快照。
- 工坊 runner 使用同源上传与工作流副本提交，状态转换继续由 GenerationTaskDriver 编排。提交中断失败，恢复只轮询原任务；等待超过 60 分钟失败。
- 图片与视频模型选择统一使用 CustomSelect 的顶层 popover，自适应可见区域、滚动和窗口尺寸，保留键盘选择与焦点返回。
- 新增迁移 `0092_visual_zealman_video` 扩展工坊任务协议约束，既有记录、索引与外键保持不变。共享视频请求允许省略供应商不支持的选项，原有视频供应商在调用边界保持原默认值。

## Alternatives considered

- 只加入模型列表：素材提交与参数仍无法运行，不满足生成闭环。
- 仅把菜单改成绝对定位向上展开：仍受滚动容器裁切，窗口较小时也可能越界。
- 修改已有迁移：已有桌面数据库校验和会漂移，因此追加版本。

## Consequences

工作流参数随草稿和任务保存；切换模型时重置工作流参数，原首尾帧转为普通图片参考并提示。U06 不接受视频参考，两个工作流固定联合输出音频，不展示原有水印、清晰度与生成音频开关。独立推理目录的供应商支持范围保持原有边界。

## Verification

隔离迁移测试验证记录、索引、外键与级联删除；API/runner 测试覆盖双工作流无密钥提交、参考顺序、实际种子快照、参数拒绝、结果落盘、恢复不重提和超时。组件测试覆盖工坊能力控件、参数保存、提交形状与键盘选择，浏览器测试检查窗口底部图片/视频菜单边界和草稿保存后提交。
