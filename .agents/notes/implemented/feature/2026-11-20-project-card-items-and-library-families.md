# Agent Note: 项目独立设定项与设定库归组

Status: implemented

## Problem

项目中需要引用和移除具体造型，主卡与变体折成一项增加了操作歧义；账号设定库将所有变体平铺又使同一设定分散。三类设定缺少一致排序入口，短名称变体在添加选择器中难以按所属设定找到。

## Decision

项目侧栏严格按 project_card_ids 显示独立行，三类卡的主卡与变体拥有各自的查看、引用、来源和移除操作。只添加用户选中的 ID，不隐式收录父卡；已有项目数据不批量重写。

独立项的名称在展示层分为主体名与变体小标签：按已核验父关系解析主体，只移除完整主体前缀，不拆分主体自身的分隔符。三类卡共用淡杏橙标签与主题配色，长内容省略并通过悬浮或聚焦提示完整名称；原始 title、搜索、卡片 ID 和引用保持原契约。

账号设定库按 parent_id 归为设定组，主图和变体分别打开自己的卡片；人设、场景、道具共用族计算、组卡和高清横向条带。解析父关系支持多层、缺失父卡和循环终止，不按名称合并数据。归档筛选按单卡生效，活跃变体保留归档父卡的文字上下文；搜索主卡呈现全组，搜索具体变体呈现匹配项。

各项目的三类标题和卡库当前类别提供按名称排序。使用中文数字自然顺序，主卡优先、变体相邻；偏好仅按账号、项目/卡库和类别保存在浏览器，存储失败时仍可本次排序。搜索不改变排序作用范围，不修改卡片或项目持久内容。

项目详情内创建变体复用账号创建接口，再显式回调加入当前项目；收录失败保留创建结果并展示重试添加，不重建卡片。提交期间编辑和关闭沿用 busy 限制。添加选择器每次打开刷新卡库，按卡片 ID 标记已添加，不封锁整个设定族；关键词包含所属设定，短名称的其他变体仍可找到。

该决定取代[横排变体 Note](2026-11-20-visual-variant-filmstrip-and-dialog-dismiss.md)和[高清滚动 Note](../bug-fix/2026-11-20-visual-variant-scroll-preview.md)中的项目侧栏呈现；高清预览、局部滚动和弹窗关闭约束继续适用于设定库。

## Alternatives considered

同一套合并展示不能同时适合项目引用与全账号管理。拆开卡片数据或重建变体会改变已有引用，因此只调整呈现和明确收录集合。排序没有引入后端排名字段，避免把浏览偏好变成素材内容修改。

## Consequences

卡片身份、采用图、历史输出与账号范围保持原契约，HTTP API 和数据库无需迁移。board/DesignCardRow 拥有项目行；creative/CardLibraryGroups、VariantStrip、cardFamilies 拥有库内展示与族规则，项目不反向成为卡库依赖。AssetCards 将创建与收录重试交给 useCardCreation，仍持有编辑器。原生 dialog 的外侧关闭、焦点恢复和未保存确认沿用现有实现。

## Verification

单元测试覆盖三类归组与独立身份、多层变体、归档父卡、搜索、自然排序、偏好隔离和收录失败复用已建卡。隔离浏览器覆盖三类连续追加同族变体、只添加所选项、单项移除、创建与收录重试、卡库归组、排序刷新、高清条带、键盘和明暗窄屏编辑器。

实际项目选择器按红莉栖搜索得到 24 张卡，其中 6 张已添加、18 张仍可选；仅查看列表，没有为验收添加真实项目素材。实际侧栏和库内截图位于被忽略的 `.local/card-layout/`。
