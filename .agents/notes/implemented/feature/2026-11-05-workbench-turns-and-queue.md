# Agent Note: Agent 工作台轮次阅读与待执行队列

Status: implemented

## Problem

原端工具调用和输出分别渲染为聊天消息，掩盖正文和用户输入之间的轮次关系。工作台执行会话在忙时无法接收后续请求。

## Decision

历史适配层保留原生关联，Web 在同一轮次内显示正文和可展开的活动摘要。旧阅读副本即时分组，授权来源重读时补齐关联。分页以序号和原生身份稳定排序。

工作台在 SQLite 持久化待执行消息，使用现有单活跃轮约束和项目授权。正常完成后队列继续，停止、失败、重启和授权失效会暂停待执行消息。Codex 与 Pi 使用原生协议确认轮内指令，确认回执与队列分离。

## Alternatives considered

按时间距离匹配工具结果与调用会错配并行调用。浏览器内排队在刷新或关闭时会丢失，多个标签页也无法共享顺序。停止当前任务并重新提交会破坏工具审批与结果的因果关系。

## Consequences

只读同步与工作台执行使用独立的权限边界。提交和调度重验 Session、入口、项目和解锁。客户端可区分已接收、被拒绝与结果未知，未知状态保留原回执。

## Verification

隔离测试覆盖原生格式、历史分页、轮内工具折叠、队列顺序和停止恢复，以及 CLI 指令确认。
