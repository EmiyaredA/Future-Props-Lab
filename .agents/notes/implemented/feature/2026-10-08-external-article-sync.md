# Agent Note: 外部连接与飞书文章同步

Status: implemented

## Problem

用户需要将思绪工坊文章维护为一份可在飞书阅读的副本。凭据管理、文章生命周期和外部写入恢复具有不同职责；未来接入其他平台时不能让适配器依赖文章内部 ORM。整篇替换还必须防止过期预览、重复提交与不确定写入导致数据损失。

## Decision

集成中心的外部连接管理 Workspace 加密凭据与鉴权；思绪工坊的 external_sync 拥有目标绑定、纯内容投影、快照和持久任务。治理模块提供操作者权限回调，任务监督器调用该回调，不持有请求上下文。新迁移 0088_external_article_sync（文件 r0088_external_article_sync.py）追加连接、绑定、任务、步骤和任务素材引用表。

目标是已有飞书 docx 文档；绑定全局唯一，活跃任务以部分唯一索引串行。预览固定本地与远端快照，提交重新读取并校验。任务先追加、上传图片和核验，再删除旧正文；每个步骤保存请求 ID 和确认结果。远端 revision/client_token 是观测版本与请求标识，不当作未验证的 CAS 保证。

未知结果进入 needs_review；重启不重放外部写入。只有没有 pending 步骤且远端与已确认快照一致才可以恢复，恢复前重新校验当前操作者。人工结束可以在连接停用或凭据轮换后释放任务，但不删除远端现场。绑定、复制和备份拥有不同生命周期，新副本不继承绑定。

运行中与待核对任务阻止文章永久删除；可进入回收站并恢复后处理，防止任务失去界面入口而永久占用目标。此删除守卫是 external_sync 的公开契约，Notes 不读取其内部任务模型。

外部连接和同步界面使用本地飞书 SVG 标识（来源：<https://github.com/flathub/cn.feishu.Feishu/blob/master/cn.feishu.Feishu.svg>），由共享 FeishuMark 展示品牌身份，不依赖外网加载。配置引导与凭据表单分区，弹窗关闭按钮固定尺寸，页脚保持可操作；连接卡片、预览对照、同步历史和风险确认沿用应用主题。状态文案区分本地版本已同步与预览发现的飞书修改，避免把本地版本相等误表述为远端也一致；重新打开侧栏主动读取任务状态，不沿用全局查询缓存的短期新鲜期。

外部连接页的空态与未绑定文章的同步入口使用中性连接图标和平台无关文案；具体连接卡片、平台配置及已绑定目标展示对应平台品牌。首版仅开放已实现的飞书连接，不添加可操作的未来平台占位入口。

## Alternatives considered

- **首页入口**：配置放集成中心、操作放文章顶部，避免给首页增加仅管理员使用的动作。
- **清空后重建**：改为先追加并核验，部分失败时保留原正文；代价是同步中短暂同时出现两份内容。
- **自动重放或依赖版本参数**：跨多个请求无法保证原子性，未知结果须人工核对，不能用模拟服务证明真实飞书去重语义。

## Consequences

首版仅开放管理员和拥有者、飞书自建应用、已有 docx、手动单向同步。正文支持常用格式、图片与普通表格；复杂节点显示位置并阻断，转换差异明确提示。单篇上限 1,000 个飞书块。Secret 不回传，素材引用保护任务执行期的本地文件。知识库 `/wiki/` 链接作为 docx 定位符的解析见 [飞书知识库文档链接](../bug-fix/2026-10-09-feishu-wiki-document-link.md)。

受保护的产品文档中心保持原样，API 参考更新在 docs/reference/api.md，使用流程进入官方知识库导入来源。SDK 生成方法与 OpenAPI 保持一致；包含旧文档中心正文再生成的聚合检查须单独记录其限制。未提供真实飞书凭据，真实首次替换、再次同步、外部修改暂停和版本去重语义验收尚未完成。
