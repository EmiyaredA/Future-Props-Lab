# Agent Note: 思绪文档历史与附件使用独立引用保护

Status: implemented

## Problem

文档历史需要可回看，公共文件清理又不能误删仍被历史引用的素材。

## Decision

文档历史由思绪工坊拥有，历史附件使用独立引用并参与文件删除保护；文档永久删除时才级联释放历史引用。

## Alternatives considered

- **只保存当前正文** — 存储少，但历史无法可靠重现。
- **每个历史版本复制独立文件** — 恢复直观，但会产生重复资产。

## Consequences

- **收益**：历史可读且文件生命周期仍有单一引用保护。
- **代价与上限**：历史不会自动过期，永久删除必须正确释放引用。
