# Agent Note: 视频剪辑书页翻页转场

Status: implemented

## Problem

视频剪辑现有转场不能呈现纸页从边角卷起、露出下一画面的效果。只在浏览器使用 CSS 翻转会使精确停帧、预渲染和导出与实时预览不一致。

## Decision

时间线的接缝与片段头尾转场增加 `page-curl`，复用现有方向、微秒时长、缓动和原子编辑操作。方向仅接受左右，默认向左、800ms、缓入缓出；短片段使用既有时长上限。转场库与检查器共享可用方向，切换自上下方向的效果时重置为左。

`media_rendering/local/page_curl.py` 与 Web 的 `pageCurlCanvas.ts` 使用相同的归一化倾斜圆柱、逆向采样、纸背着色和局部投影公式。后端仅对卷曲及投影区域分配采样数组；Web 复用已解码、裁切、抠像及定时效果处理后的画面。翻转素材时反转卷曲局部方向，使画布上的左右含义保持稳定。源 Alpha 控制纸背和投影，不给透明素材填充不透明纸张。

接缝先合成下一片段，再卷起上一片段；重排仅发生在所属轨道内。片段入场反向展开，出场卷走，露出下层轨道或背景。接缝卷曲优先于同一片段同时存在的头尾卷曲，其他已有头尾效果继续沿用现有组合规则。采样和接缝窗口复用既有规则，不改变音频及时间线总长。

后端精确帧和预渲染身份分别提升合成器版本和预渲染版本。公共契约由现有生成命令更新；不增加数据库字段或迁移。

浏览器与编码成片对照暴露了已有顺序解码器的片尾越界：接缝把时间钳制为 `durationUs - 1` 时，按整帧推进可能读到切点后的源帧。首次进入此保持位置时重新定位到包含该微秒的源 PTS，随后复用保持帧，避免逐帧重开解码器。

## Alternatives considered

- CSS 三维整页旋转：实现较短，但不满足已确认的卷曲纸页效果，也不能复用到后端帧求值。
- 仅提供接缝转场：无法满足片段头尾卷入与卷出的已确认用法。
- 导出依赖浏览器录屏：偏离现有固定帧网格和无浏览器后端渲染契约。

## Consequences

首版只开放方向、时长和缓动，纸背、卷曲半径和阴影使用固定配方。卷曲逐帧执行，导出增加局部像素采样开销；实时预览沿用现有有界画布与代理视频。新增能力仍通过所属项目的时间线 CAS、账号隔离和素材端口工作。

## Verification

后端确定性测试覆盖左右镜像、透明度、起止边界、纸背、阴影、层序、非法方向，以及公开 API 的短片段、撤销重做和工程包往返。Web 测试覆盖转场目录、默认值、方向切换、头尾进度、接缝层序与像素性质。浏览器旅程分别验收左右翻页的实时预览、精确帧和编码导出；运行证据存入被忽略的 `.local/page-curl/`。

- 视频剪辑与相关媒体采样、连续性及取消回归共 409 项通过；架构检查 47 项通过。
- 核心转场 Web 测试 45 项通过。扩展回归 404 项中 403 项通过，空隙面板已有异步状态断言出现一次时序失败，该文件单独重跑 8 项全部通过。
- 甩镜、漏光及左右翻页共 4 条 Chromium 旅程通过；追加的左翻页旅程同时验证 720p 预渲染缓存与精确帧一致。
- 正式构建、修改范围的 Ruff、ESLint、格式和类型检查、Agent Note 与产品文档保护检查通过。OpenAPI、Web/SDK 生成契约及服务归属检查通过。
- 完整 `contracts:check` 在 SDK 文档检查处报告仓库已有的 10 篇参考正文和 coverage 过期；只读比较确认本次 OpenAPI 更新不改变任何 SDK 文档生成内容，保留受保护正文。
