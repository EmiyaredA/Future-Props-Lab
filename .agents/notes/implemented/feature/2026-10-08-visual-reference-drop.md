# Agent Note: 视觉工作台参考素材拖入

Status: implemented

## Problem

看板左侧项目素材无法拖入生成器参考框，用户必须重复打开素材选择菜单。已有素材库拖拽只会在画布创建节点，不能用于选择生成输入。

## Decision

素材树中有媒体文件的节点通过已有自定义 MIME 传递当前 asset ID、类型及来源项目，空节点和文本节点不可拖拽。`useProjectReferenceDrop` 依据已加载的当前项目文件验证类型、项目归属、重复及包含连线输入的数量；不信任拖拽标题和类型作为文件事实。生成参考框沿用原 onChange 与草稿保存路径，全能参考栏在捕获阶段按文件类型路由到图片、视频或音频列表，内部图片排序继续使用独立 text/plain 拖拽。

拖入引用当前文件，与跟随最终输出的任务连线有不同生命周期。拖入不会选择来源节点、修改连线或提交模型任务。单选帧可替换已有手动参考；禁用框和数量不足均保留草稿，拖入不额外显示状态文案。当前节点通过显式 excludedAssetIds 排除自身文件，素材选择菜单共用该限制；旧草稿中的自身引用在加载完成后移除。后端输入解析在合并手动参考与上游输入之后拒绝当前节点自身素材，防止绕过界面提交。跨项目或公共库素材先通过现有选择菜单导入，不在拖入过程中新增导入事务。

## Alternatives considered

- 通过输入连线引用来源节点：会跟随最终输出变化，与拖入固定参考框的含义不同，并改变生成模式。
- 仅在各类型图标上接收：无法覆盖全能参考栏空白区域，容易在错误类型图标上误放；统一参考栏使用媒体类型路由。

## Consequences

拖入接收端只使用显式项目与可用文件快照，无新增持久字段、API 或迁移；生成请求引用自身时返回 422/self_asset_reference。文件加载完成前或素材失效后拒绝添加，用户可以重新拖入。图片排序、键盘选择与上传菜单继续独立工作。官方工作流指南说明固定文件参考与任务输出引用的区别。
