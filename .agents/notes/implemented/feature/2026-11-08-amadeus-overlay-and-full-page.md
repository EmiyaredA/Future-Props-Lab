# Agent Note: Amadeus 右侧弹窗和新标签页

Status: implemented

## Problem

部分 Studio 顶栏会直接跳到 Amadeus，离开正在看的文件或应用。需要在当前页面继续工作时也能打开对话，并按需切到完整工作区。

## Decision

Studio 顶栏和工坊入口默认打开同一个页面内弹窗。宽屏固定在右侧，窄屏占满视口。视口至少 1100 像素时可以从 Amadeus 顶栏切换分屏，让原页面和会话并排。切换布局复用同一个会话组件，保留未发送的输入。独立服务公共壳提供弹窗，避免文件页等入口各自选择导航行为。两种布局都可以打开全视口的 `/amadeus` 新标签页，并携带当前已保存的会话 ID；数据仍走[独立 Amadeus](../architecture/2026-11-08-amadeus-cross-workshop-workspace.md)。

文件服务随独立前端构建发布 Amadeus 头像和许可文件。Vite 开发服务器扫描独立 HTML 入口，避免首次从文件页加载弹窗时重新优化依赖并混用两份 React 运行时。

## Alternatives considered

直接跳转会离开当前工作。默认分屏会缩小工坊编辑器和文件列表的可用空间，因此把分屏留作宽屏下的主动选择。

## Consequences

关闭面板时焦点回到入口，下次从弹窗打开。分屏时缩窄窗口会临时回到弹窗，窗口重新变宽后恢复分屏。选取页面控件时临时隐藏面板，保留当前会话界面及输入。原标签页保留在原路由，新标签页加载已保存的会话。

宽屏的默认打开方式后来改为[默认分屏](2026-11-08-amadeus-default-split.md)。

## Verification

浏览器用例检查文件页在三种布局间切换、分屏时原页面仍可见、宽窄屏回退、保留草稿、输入区控件未越界、键盘关闭，以及工坊侧栏生成当前会话链接。
