# Agent Note: 演示文稿刷新恢复当前页

Status: implemented

## Problem

刷新演示编辑器会返回第一页，长文稿的当前工作位置丢失。

## Decision

在浏览器标签页的 sessionStorage 中按文稿 ID 记录当前幻灯片 ID。打开时仅在当前文稿包含该 ID 时恢复，否则显示第一页；存储不可用时正常编辑。页面重排不改变恢复目标，撤销等导航也更新记录。初次显示时将选中的缩略图滚入列表视野。

## Alternatives considered

使用页码无法适应幻灯片重排；写入服务端会把临时浏览位置混入文稿数据并影响其他会话。

## Consequences

恢复位置属于当前浏览器标签页，不修改文稿或其历史；其他标签页可以独立浏览。关闭标签页后浏览器不保证保留该位置。

## Verification

编辑器组件测试覆盖重新挂载、页面重排、文稿隔离、失效页面及存储异常。
