# Agent Note: MiniMax H3 提示词渲染适配器

Status: implemented

## Problem

视频提示词编辑器将 H3 的结构字段、参考标签、镜头和对白显示为连续纯文本，长提示词不便阅读。直接改造可编辑 DOM 会增加光标、素材引用和版本切换的风险。

## Decision

展示层通过适配器注册表解释原文，首期提供 minimax-h3，覆盖基础音画三字段和全参考六字段。独有的行首字段触发自动识别，用户可手选普通文本或 H3；通用 summary 和声音字段不能单独触发识别。段落按原顺序解释，前置说明、未知内容和不完整结构保留。解析结果保留原始 heading 和 token，连接后与输入逐字一致；对白中的字段和镜头标记不触发分段。

视频画布、看板与普通生成面板共用 GenerationPromptField；图片与音频入口保持原状。预览通过 React 文本节点展示中文段落名称、原始字段名和标签，不解析任意 HTML、不推断 H3 标签与素材的绑定。预览只在显示时收起块首尾空白，模板识别和编辑／复制操作保持一行。原文编辑复用 GenerationPromptEditor，输入过程中不会自动切走，失焦保存和生成前保存屏障沿用原流程。

模板与显示方式是当前编辑器的临时状态，按项目／节点身份隔离；切换文字版本保留显示选择并刷新内容。预览和模板切换不改写 prompt，不增加 API、持久字段或迁移。复制操作读取当前原文并反馈失败，不复制中文标题或样式内容。

GenerationPromptEditor 的 normalizeReferencesOnLoad 默认保持原行为，展示包装层显式关闭该选项；进入原文模式时只显示解析后的素材块，不因旧素材别名规范化而改写草稿，用户实际编辑仍经过既有引用投影。

## Alternatives considered

- 在 contentEditable 内直接重建结构化样式：与已有素材块、选区及输入法处理耦合，首期采用预览和原文编辑切换。
- 绑定当前模型选择模板：同一模型允许普通文字，按提示词结构识别并允许手动选择更贴合实际内容。
- 为版本持久化渲染模板：新增跨端契约与迁移，当前展示需求只需会话状态。

## Consequences

新增模板只需提供相同解析契约并注册，不修改生成控制器。所有预览输入都作为文本处理；不完整内容可编辑修复，不阻止现有生成行为。当前支持字段式纯文本，不解释 JSON 包装或执行提示词中的指令。本次遵循能力实现契约的提示词／版本约束、目录索引的 generation 归属及开发与验证流程的隔离测试和主题／可访问性要求。

后续[多模态引用与分镜属性](2026-11-22-h3-rich-references-and-shot-properties.md)按用户要求细化展示：预览省略已识别的对齐前言及主描述字段名，引用通过明确的素材槽位解析，原文编辑、复制和生成仍完整保留源串。

后续[H3 适配器直接编辑](2026-11-22-h3-adapter-direct-editing.md)替代按钮切换模式，增加独立标题兼容、原文事务及行尾光标映射。
