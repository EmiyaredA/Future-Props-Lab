# Agent Note: 云控面板独立折叠

Status: implemented

## Problem

云控的固定布局持续占用横向空间。阅读长会话、文件或操作远程桌面时，用户需要临时将空间让给当前面板，并能恢复原布局。

## Decision

顶部按钮在三种布局中控制面板可见性。浏览器按账号和布局保存收起的面板标识，页面至少显示一栏。容器宽度决定同时显示的面板数，响应式切换优先显示用户刚选中的面板。

面板隐藏时保留组件实例和文件阅读容器。远程桌面沿用失去可见性时的输入释放规则，自动锁定继续约束连接。会话中的文件入口自动展开阅读栏，关闭文件重新显示会话栏并恢复触发链接焦点。

## Alternatives considered

在原栏保留窄条会为每个收起面板持续占用横向空间。移除组件会清除草稿和阅读状态，也会中断远程桌面连接。

## Consequences

布局偏好保存在当前浏览器。远程桌面和正在进行的会话在折叠期间继续遵循各自的连接与授权规则。

## Verification

云控与文件阅读的隔离浏览器旅程覆盖键盘操作、比例与布局偏好恢复、响应式切换、草稿和连接保留，以及文件重新展开与焦点恢复。
