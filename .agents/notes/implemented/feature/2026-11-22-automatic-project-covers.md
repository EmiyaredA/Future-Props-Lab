# Agent Note: 项目卡片自动展示真实内容

Status: implemented

## Problem

项目列表的固定背景无法区分项目内容，用户只能反复阅读标题或进入工程。不同工坊保存的内容形态不同，统一随机选素材会展示无关文件，直接在列表挂载编辑器又会启动播放、保存和大量渲染。

## Decision

各工坊在现有账号范围的项目列表响应中提供可空的轻量 `ProjectPreview`，描述类型、内容版本和取材位置。通用传输形状归 `runtime/project_preview.py`，内容选择归各应用；兼容网站的 Visual 和 Galgame 项目装配复用相同选择器。描述不写数据库、不推进项目或文档 revision，也不改排序时间。

视觉封面只取仍存在节点的当前采用输出，按输出时间稳定排序，忽略旧版本和已移除节点。查询只投影当前输出必要字段，不加载历史输入快照。剪辑、特效和 Galgame 使用既有真实合成帧；Galgame 的精确帧 POST 是既有只读操作，不创建导出。导演台按需加载自己的单次渲染入口，使用保存场景的摄影机与生产渲染引擎，结束后释放宿主、模型和 WebGL 资源，不挂载编辑器或写回工程。

演示复用第一页预览。思绪保留手动封面优先，自动读取最近的未删除文档首张正文图片或摘要，手动图片无法读取时退回自动内容。表格通过 SQLite JSON 投影最多六行五列已保存显示值，不计算公式、不向列表进程加载整个工作簿。音频使用最多 96 个真实波形区间及已有转写，没有波形时不伪造数据。空内容和失效来源保留可识别的回退。

项目卡片统一横向封面并适度收紧密度，保留操作。预览区不显示纯装饰的文件／图片类型图标，文字直接展示摘要，空内容使用简短文字。接近视口才读取媒体；普通媒体最多四路、复杂渲染单路，队列由 QueryClient 生命周期持有。会话缓存按账号、工坊、项目和源版本区分，最多保留 64 个闲置预览，退出账号随 QueryClient 清理。Object URL 随组件释放；离开视口取消未完成读取，离开列表取消排队和渲染。返回列表与窗口聚焦重新读取预览描述。

## Alternatives considered

- 只为视觉工坊随机取文件库第一张图片：不能保证与节点当前成果相关，也无法满足其他工坊。
- 调用生图模型设计封面：用户已明确更正为使用真实内容，不调用 AI 生图。
- 列表直接加载全部工程并挂载编辑器：增加请求、GPU 和内存占用，可能触发播放与保存。
- 持久化一份独立封面并回填旧库：增加迁移和一致性状态；当前派生描述与既有预览接口已能覆盖旧项目。

## Consequences

不新增持久表或迁移，不上传新封面，不调用付费模型。较复杂工程首次渲染晚于列表信息展示；渲染器不可用或资源失效时回退，不阻塞打开项目。Web、SDK 和服务契约同步可空响应字段，既有请求形状不变。思绪指南来源及导入包同步说明自动封面，已有用户笔记不回写。

## Verification

隔离后端回归覆盖实际列表投影、当前采用输出、删除节点、跨账号读取、工作簿大数据的有界投影和读取不改变 revision。前端覆盖媒体回退、Object URL 回收、视口懒加载与取消、真实波形和单元格、渲染队列，以及原有列表操作。浏览器覆盖九类工坊的明暗主题和窄屏，并实际运行导演台场景渲染；Galgame 检查只读取精确帧而不创建导出。证据放在忽略的 `.local/project-covers/`。
