# Agent Note: 看板紧凑生成状态

Status: implemented

## Problem

视频任务提交后，右侧仅显示暂无输出，持续提示提交成功也不能说明当前是否仍在执行。预览方案中的阶段流程和历史中间帧占用过多高度，已有输出与当前生成状态也需要区分。

## Decision

项目看板继续通过现有任务及图片批次查询轮询。`generationActivityModel` 按节点关联选择最新活动任务，将阶段、真实进度及创建时间归一为显式展示数据；输出历史接收该查询快照，不持久化界面计时或动画状态。生成按钮接收活动状态，禁止同一节点在运行期间重复提交。

任务状态或结果变化继续失效画布与输出查询。画布持久化边界忽略已知 revision 及更旧的轮询快照，避免迟到的读取覆盖待保存草稿、回退自身成功保存的版本或误报冲突；真正较新的远端版本仍保留原有 CAS 冲突保护。

主预览下方仅显示紧凑状态行和细进度条，包含转圈、当前阶段、已用时及任务入口。未知进度使用不定值动画，不虚构百分比；100% 但尚未完成时显示正在保存输出。节点标题、素材树、状态分组、任务列表和生成按钮复用同一转圈图标，并尊重减少动态效果设置。

当前公共任务契约没有中间帧。无输出时显示等待生成画面，已有输出仍通过版本徽标明确标识并可继续预览；不将参考素材当作实时生成结果，也不增加阶段流程和历史缩略图画廊。完成或失败后随轮询结果结束运行状态，输出历史仍按原有最终版本与手动预览规则更新。

## Alternatives considered

- 展示三阶段流程及最近三张中间帧：增加高度，且当前 API 无真实中间帧可消费。
- 随时间增长估算百分比：没有供应商事实支持，使用不定值动画表达等待。
- 用生成期间占位界面替换旧输出：会阻碍已有版本核对，保留独立版本预览。

## Consequences

不新增 API、迁移或供应商调用。真实中间帧仍需将来通过供应商适配边界和公共任务契约提供。计时从创建时刻计算，包含排队时间；页面每秒更新显示并在卸载后清理定时器。

## Verification

- 45 项相关组件测试通过，覆盖未知／有效进度、计时、终态清理、节点隔离、三类生成器及旧输出保留。
- 画布持久化测试覆盖同版本／旧版本轮询不覆盖编辑与成功保存，以及较新版本仍触发冲突。
- 2 条隔离浏览器旅程通过，覆盖紧凑布局、明暗主题、窄屏、转圈、减少动态效果、终态恢复及 30 节点下的输出版本操作；不提交真实模型任务。
- Web lint、接口契约、官方知识库导入包与文档中心保护检查通过。全量格式检查的两处原有问题位于未修改的 `web/src/docs/styles-components.css` 和 `web/src/features/thought-workshop/official/content/thought-workshop/help.md`，本次修改文件格式通过。
