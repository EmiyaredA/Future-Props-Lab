# Agent Note: 原生模板画布与显式正文套版

Status: implemented

## Problem

静态模板预览与数值配置不能表达正文默认布局、分组和直接操作，示例图文在预览代码中导致保存与创建结果不同。全局模板更新和正文移动也需要不同的生命周期。

## Decision

共享原生元素契约独立于文稿与模板，v2 模板保存全局场景、五种页型固定场景、正文默认场景及显式动态文字关联。v5 文稿保存正文对象到模板默认对象的关联。既有模板继续按 v1 解析，只有明确升级才转换槽位；不推断旧正文。

模板设计器复用文稿 SlideCanvas、场景选择、几何与吸附，手势在提交时形成一次历史记录。编辑状态经定义保存进入 CAS 模板 API，渲染层只展开固定场景，不把默认正文注入已有页面。新页明确克隆默认场景并重映射所有对象关系。

正文套版使用独立的 layout 预览／应用动作，显式指定页面和一一对应对象，双 revision 与预览摘要固定输入。默认只转移几何，文字样式是独立选项；保留正文、素材、裁剪、备注和未映射对象。v5 保存防止旧客户端降级；新增迁移仅增加持久格式降级保护，不改变旧数据和 r0111。

## Alternatives considered

- 另建简化拖动坐标系统：会产生吸附、分组与缩放行为差异。
- 保存后自动重排所有正文：破坏已有交付和局部排版。
- 根据位置和字号匹配对象：不能保证正文与素材语义，因此只接受明确关联。

## Consequences

- 原生画布多选、分组、缩放、旋转、撤销、数值联动及五页型保存重开。
- 固定层与正文默认层影响范围清楚，动态文字来源不可被示例文字替换。
- CAS、选页套版、未匹配和越界诊断、素材保护、跨空间原生包与可编辑导出。
- 390／768／1440／1920 明暗主题及相关测试、契约、SDK、架构和文档检查。

## Verification

- 复用 SlideCanvas、选择／分组、布局吸附与原生连接调节。模板画布支持方向键、手势取消、撤销重做、原生复制粘贴与数值同步；手势只在结束时提交一次。跨影响范围的分组和连接在编辑边界拒绝，不保存无效引用。
- v2 原生场景与 v5 对象关联通过共享样例核对 Web／Python 的文本、坐标、旋转、隐藏规则与分组。新页与预览读取同一份持久默认正文，旧模板不猜测正文。
- 179 项演示后端测试通过，1 项跳过；299 项组件测试通过。完整 Chromium 旅程通过两种缩放拖动、缩放手柄、旋转、分组、键盘、保存重开、Logo、全稿覆盖、指定页套版、示例保存及复用；检查明暗主题与 390／768／1440／1920。
- 契约和 SDK 检查通过。全仓 lint／格式仍受既存视频下载文件问题影响；架构仅有 home、tools 的既存跨功能私有导入失败。SDK 参考随公共契约生成，受保护文档检查要求与 Agent Note 分开提交，不绕过该检查。
- r0112 在临时数据库验证后定稿；2026-10-25 正常退出正式 App、持双锁完整备份并校验，再经正式 runner 应用。备份为 Future Props Lab Development Backup 20261025-192320-_94ukv83；App 和 SDK 已恢复。迁移与重启前后均通知用户指定任务，未修改 r0111。
- 通过正式 SDK 更新当前模板与 24 页合并稿；正文以可编辑流程、比较和原生产物重排。三份源稿 revision 保持 65／220／91。原稿完整文案与来源保留在备注，比较／流程／密集页先生成完整视觉参考。素材、预览、迁移回执、导出及逐页验收位于忽略的 .local/presentation-template-canvas/。
- 当前模板 revision 3、合并稿 revision 14。正式原生包经隔离 API 预览和导入验证，素材重映射且清除源模板关联；24 页实际 PPTX 渲染与画布分别核验，窄节点与文本高度问题按具体对象修正。

## Risks

模板正文默认布局只影响新页，已有正文必须明确映射并预览；全稿固定层覆盖不修改正文。模板库主题变更会同步仍使用主题值的原生原型，独立配色与字体保留。保护文档需要独立提交，不能为了全仓门禁回滚必要的 SDK 参考或修改保护脚本。
