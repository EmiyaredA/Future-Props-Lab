# Agent Note: 知识社区与统一文档布局

Status: implemented

## Problem

官方文档与个人笔记的导航和正文布局分离，零散按钮占据阅读空间。Workspace 权限不能表达只发布选定文章、允许其他空间账号编辑该文章而不开放私人目录的需求。复制正文会产生两个更新来源，开放普通文件 API 又会泄露源空间素材。

## Decision

思绪工坊的 `publication/` 拥有发布记录、逐篇访问规则、成员角色和账号收藏，追加迁移 0082，正文仍由原 ThoughtNote 拥有。社区接口只接受浏览器 Session 和 CSRF 校验；首版不登记 SDK 具名操作或 Agent 白名单。SDK 继续生成 HTTP 数据类型，生成器跳过社区操作集合。

社区用例在独立数据库会话中校验发布与授权，再显式绑定源 Workspace。读事务形成一致快照；保存和授权使用短 BEGIN IMMEDIATE 事务重新校验，避免撤销与保存竞态。Notes 用例拥有正文 CAS、校验、历史与素材引用事务。上传在无写事务期间处理文件，再重新校验并登记文章上传；未提交素材只有上传者在这篇可编辑文章中可读。

目录、计数、搜索、反向引用和导出只投影可读的当前文章；隐藏父文档的子文章提升至可见顶层。素材只开放正文实际引用和明确发布封面。源 Workspace 权限继续有效，逐篇角色不成为空间成员身份。回收站同步撤回，恢复不自动发布；历史仍仅在原空间开放。

Web 的 DocumentAccess 显式适配保存、上传、素材、引用、剪贴板和导出，复用侧栏、正文、大纲与编辑器。社区缓存、草稿与阅读位置按账号和发布资源隔离；普通笔记存储键保留。403/404 停止保存且保留本机草稿，409 由用户处理，不自动覆盖。官方 Markdown 保持原受控渲染器，93 篇静态正文保留 URL、ID、阅读偏好和图形复制。

导航集中为我的知识库、知识社区、我的收藏和我的发布。搜索与最近访问收进侧栏，模板进入新建菜单，导出、备份、复制、发布进入对应更多菜单。发布与授权长表单单独滚动，固定标题和操作区；插入菜单限定在视口内，阅读态隐藏格式工具栏。

## Alternatives considered

- 复制公开正文：两个真源不能保证保存即时同步，还会重复维护历史和素材。
- 放宽普通笔记与文件接口：破坏 Workspace 边界，无法限制私人目录和素材。
- 只由前端隐藏未授权文章：接口仍泄露标题、计数、历史和文件。
- 社区专用编辑器：编辑契约、恢复与布局会分叉。

## Consequences

整机数据库备份保留发布配置；普通知识库内容备份不包含授权，导入内容不自动发布。首版不开放匿名访问、互联网托管、评论、热度、历史或实时协同。上传期间授权变化可能留下未引用托管文件，但不会扩大读取权限。迁移定稿与浏览器验收使用隔离数据，正式数据尚未迁移。

社区 OpenAPI 增加全局 schema，保护文档中心的生成检查可能提示过期。按仓库保护规则保留原文档中心，通过 [API 说明](../../../../docs/reference/knowledge-community.md) 和知识库官方指南覆盖社区行为，不重新生成保护正文。
