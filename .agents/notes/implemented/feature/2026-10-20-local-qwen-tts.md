# Agent Note: 可选本地 Qwen 音色克隆

Status: implemented

## Problem

模型目录有语音合成分类，但没有本地模型安装与独立 TTS 调用闭环。默认发布 MLX 与权重会增加包体和依赖负担，共享主机资源与空间私有录音需要不同边界。

## Decision

本地模型是部署级资源，固定清单由应用发布；安装、取消、启停、卸载由平台管理员浏览器会话执行。独立 Python/MLX 通过私有管道工作，主应用不依赖 MLX；启动和升级不下载模型。空间显式接入供应商，调用复用独立推理任务和素材接口，录音、结果、日志保持 Workspace 隔离。安装记录与操作回执使用新增迁移；提交中断不自动重新合成。

## Alternatives considered

- 自行部署 HTTP 服务：不满足应用内安装和运行管理需求。
- 主进程直接加载 MLX：污染冻结后端依赖，并使模型故障影响主应用。
- 首版加入多种 TTS 和训练：扩大环境与许可矩阵，延后调用闭环。

## Consequences

首版支持 Apple Silicon macOS 15+，提供两种 Base bf16 模型。权重与环境是可再下载缓存。模型串行推理，空闲五分钟释放；停止和卸载由平台管理。本地供应商无需 API Key，云端凭证要求保持不变。

## Verification

确定性测试覆盖固定清单、零隐式下载、管理角色、安装取消与恢复、续传校验、目录 CAS、无 Key 合成、WAV 结果、日志与卸载后可用性。真实运行验收只安装 0.6B，1.7B 不作为已实测结果。

实机验收已在 M5 / 32 GB Mac 完成：正式数据停机备份并应用迁移后，通过应用安装 0.6B、接入当前空间；默认模型与备份快照一致，1.7B 未安装。官方示例录音经统一任务 API 合成中文 4.32 秒、英文 4.88 秒 WAV，生成阶段分别约 10.25 / 5.70 秒，MLX 峰值约 6.56 GB；播放与保存到文件库成功。显式 WAV 格式修复了无扩展名素材键写入失败，并补回归用例。

正式冻结后端在排除开发 Python/uv 的 PATH 下通过首次启动、重启零下载检查；隔离按需安装未复制推理环境，缓存档案与权重重新校验后创建环境并通过模型加载自检。App 清单无 safetensors、MLX 库或推理环境，仅携带固定清单、依赖锁和独立 worker。原生系统保存框未完成自动化验收；浏览器下载事件与正式 WAV 内容接口分别验证。全仓测试存在其他模块失败，不能把相关测试通过表述为全仓门禁全绿。
