# Agent Note: 视频剪辑工坊旋转模糊转场

Status: implemented

## Problem

现有效果库缺少围绕素材中心旋转并产生角向拖影的转场，单独改变清晰度无法表达这种运动。

## Decision

共享时间线转场类型新增 `spin-blur`，沿用接缝和片段头尾操作、时长、缓动、权限、CAS 与撤销契约。无需数据库迁移。离场使用正角度，入场使用负角度，随可见度恢复到零；九个均匀角向采样围绕 45° 最大旋转、24° 最大拖影展开，每个样本按宽高比放大以覆盖素材边界。

导出与精确帧由共享 media_rendering 的 Pillow 实现负责，使用预乘透明度避免透明素材出现黑边。Web Canvas 使用同一采样公式；视频只处理现有播放器已经定位的帧，先移除代理黑边再采样，保持抠像、源时间和播放器生命周期不变。图片和文字复用已加载图像，不重复解码视频。接缝旋转优先于同时存在的片段头尾旋转；其他接缝效果仍可叠加片段旋转。

## Alternatives considered

- CSS 旋转加高斯模糊：成本较低，但不能产生角向运动拖影。
- 多个视频元素叠加：可以近似采样，但重复解码并引入多个播放器之间的帧同步问题。

## Consequences

效果在“模糊”分类可搜索，支持三个作用位置和现有参数。Web 采样限制到 960 像素宽，导出保留输出分辨率；两端插值存在像素级差异。采样会放大并裁掉部分边缘，以免旋转时露出透明角。只影响画面，不自动修改音频。
