# Agent Note: 面试助手模拟版接入应用中心

Status: implemented

后续准备与持久化范围由[真实 Codex 资料准备](./2026-10-22-interview-codex-preparation.md)替代；本篇保留初版模拟实现的决策背景，应用注册、主题与练习保护继续适用。

## Problem

独立原型能够走通面试流程，但没有注册为 FPL 应用，无法从应用中心搜索、筛选和访问，也没有复用真实的主题、导航保护与账号 / Workspace 生命周期。

## Decision

面试助手作为效率协作应用注册在 `/apps/interview-assistant`，使用现有 WorkshopShell、CustomSelect、ConfirmDialog 和 Radix Dialog。功能代码归属独立前端 feature，不依赖其他 App 实现。原型的布局和示例素材迁入 TypeScript，所有 CSS 受功能根选择器约束，面试深色仅作用于局部区域。

输入、准备结果、对话记录和复盘只保存在 reducer 状态中。准备任务固定输入快照，并通过尝试序号拒绝取消或重试后的旧回调。提交回答、结束、暂停、计时和重练都通过明确动作转换。重练的候选 session 仅在确认开始后应用，取消不改写原复盘。

页面按账号与 Workspace 标识挂载，离开应用和切换 Workspace 使用现有导航保护；刷新清空内存并使用 beforeunload 提示。PDF / DOCX 不执行解析，TXT / Markdown 的异步读取带版本校验，防止旧文件覆盖新输入。反馈、时间点与导出只引用实际提交的回答；零回答不产生虚构反馈。

模拟版没有后端 API、数据库、模型调用、检索、外部 Agent 进程或媒体采集。本机朗读只使用可用的本地中文语音，否则回到文字提问。候选人素材是生成的虚构图片，通过 Git LFS 管理。

## Alternatives considered

- 在应用卡片中跳转独立原型：不能复用正式导航、主题与会话隔离，还会依赖额外的开发服务器。
- 同步接入后端存档与真实模型：超出用户确认的首版模拟范围，也会扩大数据与架构边界。
- 原样复制原型的全局样式与弹窗：存在污染其他应用、焦点管理和明暗主题不一致的问题。

## Consequences

应用中心的搜索、分类、能力标签与最近访问自然包含新应用。工作区成员可以体验纯本地模拟，不新增持久写入权限；公开 Workspace 访问仍由应用现有鉴权入口阻断。

后续真实能力需单独定义正式 API、权限、任务和媒体契约。模拟的目录约定不构成工程层权限控制，当前界面明确区分该边界。

## Verification

- 数据与 reducer 测试覆盖自定义 JD / 简历、输入快照、旧任务回调、暂停、提前结束、报告引用与空回答。
- 页面测试覆盖应用发现、完整练习、取消重练、账号 / Workspace 重新挂载、离开保护，以及本地文件读取竞态。
- 浏览器旅程覆盖应用中心入口、真实输入引用、Markdown 下载、离开确认和 390 / 768 / 1600 像素明暗主题适配。
- 质量与浏览器验收产物保存在被忽略的 `.local/interview-assistant/`，不操作正式数据目录。
