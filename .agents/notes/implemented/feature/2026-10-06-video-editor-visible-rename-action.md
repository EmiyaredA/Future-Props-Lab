# Agent Note: 直接可见的素材重命名入口

Status: implemented

## Problem

用户无法从素材列表直接找到重命名；文件夹图标的整理菜单缺少改名语义，需要解释才能完成操作。

## Decision

素材行右侧常驻“铅笔 + 重命名”按钮，一次点击打开现有改名弹窗。按钮包含完整素材名称的无障碍标签，只读时禁用；文字与图标同时可见，不依赖悬停。整理菜单保留原入口。

此决定调整 [最初的素材重命名设计](2026-10-06-video-editor-asset-rename.md) 中仅使用整理菜单的选择。弹窗、版本冲突与正式 PATCH API 沿用原实现，输入、保存和持久化数据流不变。

## Alternatives considered

- 只显示铅笔图标：占用空间较少，但用户仍需猜测或悬停；采用文字说明。
- 继续只通过整理菜单进入：名称占用空间更少，但用户反馈证明入口难找。

## Consequences

素材名称可用宽度减少约 56 像素，仍通过现有局部省略与可收缩布局适配窄面板；按钮独立于预览与添加动作，取消后焦点返回直接入口。

## Verification

- `web/tests/video-editor-assets.test.tsx` 从直接按钮进入所有改名保存、失败、取消和冲突用例，验证无需打开整理菜单与只读禁用。
- Web 定向 lint、格式检查、构建；官方指南与导入包保持一致。
