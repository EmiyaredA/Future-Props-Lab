# Agent Note: 云控桌面登录与本机设置

Status: implemented

## Problem

云控需要在网页内直接连接并操作 Mac。配置流程应让管理员在本机选择项目和 CLI，并按实际桌面操作设定空闲锁定。

## Decision

浏览器向同源接口提交当次 VNC 密码。后端用一次性凭证将密码短暂交给 guacd，以真实输入计时并释放已按下的键鼠。公网桌面验证绑定 FPL Session，Agent 的短时执行授权独立。可信本机管理员使用 revision 保存受限 TOML 字段。编程智能体页负责共享 CLI 连接。启用连接检测安装、版本与登录，并沿用云控设置的配置锁。有效账号可在自己有权访问的功能中使用已启用的 CLI。历史用途授权记录不参与运行时决策。云控工作台直接读取共享连接，桌面与工作台入口继续要求管理员。

浏览器桌面点击在 pointerdown 时聚焦远程键盘输入，再阻止 mousedown 的默认焦点切换。按键仍通过 Guacamole 转发，焦点离开时释放已按下的键鼠。桌面底部显示键盘接管状态。

部署端可显式开启 `public_desktop_vnc_only`。默认继续使用密码重验和动态验证码。启用该模式并打开公网开关后，桌面验证使用现有 FPL 管理员 Session、账号白名单及 VNC 密码。Agent 执行只走本机入口，公网桌面继续校验来源、一次性凭证及 Session 撤销。

Guacamole 首次同步只表示协议连接成功。浏览器等待该次绘制队列刷新并确认桌面画布已输出像素，再开放键鼠。整次连接最多等待 25 秒，超时释放连接并在左栏提供重试。透明空画布与有效的黑色桌面用透明度区分。

## Alternatives considered

配置文件长期保存 VNC 密码会增加部署步骤。浏览器独立定时不能在失联时中断远程会话。整页重连弹窗会打断 Agent 输入。

## Consequences

首次使用依赖本机屏幕共享与回环 guacd。真实桌面控制与公网启用需要完成单独的部署验收。

## Verification

隔离测试验证会话验证、凭证、防越界、空闲和浏览器重连。实机验收按云控参考文档执行。

浏览器回归用例从画面点击开始，校验焦点、缩放点位、按下与抬起的键盘帧、合成提交和 Shift + Esc 释放。

隔离测试覆盖两种公网策略、无动态验证码的桌面设置保存、Agent 执行隔离、跨来源拒绝和注销断开。

连接回归覆盖普通账号默认可用、自有任务边界、管理员远控入口以及本机启用接口。公网入口拒绝启用本机 CLI。
