# Agent Note: 统一新画布与嵌入白模编辑器

Status: implemented

## Problem

画布可记住旧版视口，导致用户在同一工坊看到两套画布入口。进入白模场景时会替换项目顶栏，场景新建页的文字和控件也比其他工作区大。

## Decision

所有视觉项目使用 Vue Flow 视口，原节点、连线、历史和视口数据继续由画布控制器读取。此决策更新 [Toonflow 与白模接入](2026-11-20-toonflow-previs.md) 中的画布回切选项。

白模清单和编辑器共用项目顶栏及左侧列表。新建页采用工坊控件尺寸，三维编辑器使用下方区域内的独立窗口。窄屏在同一窗口提供既有的只读预演。

项目导航、场景切换及关闭复用同一离开检查。先处理正在运行的编辑器操作和未完成的素材回填，再保存场景。保存失败保留当前编辑器及草稿，保存成功刷新场景列表。

## Alternatives considered

- 保留双画布入口会让浏览器旧偏好继续覆盖用户当前选择。
- 打开覆盖页面的独立编辑器会遮住项目导航和场景列表。

## Consequences

已有画布和白模场景可直接打开，无需转换存储。工具和播放预览使用嵌入窗口的可用空间。

## Verification

组件测试检查新画布的节点和缩放行为。隔离浏览器旅程验证旧偏好、嵌入边界、窄屏预演、素材回填及顶栏离开时的保存失败与重试。本机用现有 201 节点项目和已保存白模场景核对工作区。
