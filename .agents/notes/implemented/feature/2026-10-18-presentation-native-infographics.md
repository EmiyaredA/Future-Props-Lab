# Agent Note: 演示工坊可编辑信息图与视觉重建

Status: implemented

## Problem

演示工坊缺少参考图对照、持久化分组和节点关系，Agent 插入流程图后无法统一编辑、复制和导出绑定端点的连接线。将信息图压成整张图片无法满足文字可改、节点可移动和组可解组的交付要求。

## Decision

文稿版本 2 保留现有元素结构，按页追加 groups、connections、reference 和 infographics。组只保存成员与父级，连接显式绑定元素和四侧端口；手动坐标与布局折点是持久化真源，不保存第三方编辑器状态。分组循环、重复归属、非法端点和来源引用在 Pydantic 契约层统一拒绝。旧版输入先规范化，0096_presentation_scene 迁移只补缺省字段和版本，不改已有 revision、内容、顺序和坐标。

输入从编辑器的受控 AntV 模板或原生片段 JSON 进入。五类模板按需加载，步骤、时间线和对比图转换真实浏览器 SVG 几何，层级与关系图转换语义节点和关系；所有关键文字必须完整转换。复杂装饰是独立 SVG，经现有素材预览 API 校验后才能应用，上传沿用文件库入口和 Workspace 权限。失败不替换画布；源码重新应用先预览，整次替换进入既有撤销栈。上传过程中失败可能留下未被文稿引用的文件库素材，重试不自动提交文稿。

ELK 分组布局在用户触发时运行于独立 Worker，采用固定侧端口及直角路由；布局完成后终止 Worker，越界或不能完整转译的路由拒绝应用。预编译 GWT 引擎是单个独立懒加载资源，预算上限 1600 KiB；其余脚本保持 500 KiB，AntV 的结构、交互和字体度量按职责分块。构建预算只读产物。

场景编辑复用已有文稿保存、草稿、历史、权限和批量操作；fragment 的插入、更新和删除由正式 API 原子校验，沿用 CAS 和幂等回执。复制完整重映射对象 ID，删除节点清理边，解组把成员交还父级。参考图复用托管素材引用保护，只在编辑器显示，不进入放映、缩略图或 PPTX。页面检查只定位文字溢出、旋转后越界、缺失素材、断开连接和设备字体替代，不自动改写内容。

统一导出先创建对象映射，再写入原生连接绑定和嵌套组。自定义节点显式声明四侧连接位；旋转和翻转后的连接几何与端口索引保持一致。普通文本保留原生文字，复杂装饰继续经过已有 SVG 媒体导出边界。

## Alternatives considered

- 直接插入整张信息图：失去文字、节点与关系的独立编辑能力。
- 嵌入独立 AntV 编辑器或后端 Node 渲染服务：增加第二套状态、权限与保存链路，首轮只保留生成来源和前端转换。
- 同时接入 Mermaid、D2、ECharts：扩大未验证输入范围；首轮使用 AntV 白名单，后续适配仍输出同一原生契约。
- 在主线程执行 ELK：大图会阻塞编辑，采用按需独立 Worker 并保存计算后的原生坐标。

## Consequences

自动 OCR、背景修复和整页自动重建仍不属于首轮。转换只开放五个验证模板与 template/data 语法，复杂关键结构不能降级为图片。参考图隐藏不解除素材引用。源码重新应用替换该信息图及其关联边，手动调整可通过撤销恢复。大图超过页面布局容量时要求拆页，不自动缩字号。

迁移先在临时数据库验证；本次未对正式桌面数据库应用迁移，也未启动正式数据热加载。功能由当前编辑器入口消费，不新增产品路由。

## Verification

测试覆盖版本迁移、跨 Workspace 参考图、引用删除保护、循环组、非法连接、原生片段原子替换、CAS 与批次回执、页面复制的完整 ID 重映射和 DrawingML 组、端点绑定及自定义连接位。组件测试覆盖组内编辑语义、锁定成员、正交布局、复制删除和只读控件。

浏览器隔离旅程覆盖五类信息图、源码重新应用、中文编辑、组内选择、参考图并排及叠加、三阶段视觉稿原生重建、双分组关系布局、复制删除、撤销重做、保存重开和统一导出。验收产物只保存在 .local/presentation-scene/。

契约、SDK、官方知识库种子、架构、格式、lint、构建与文档保护检查同时执行。实际 Microsoft PowerPoint 中移动节点与解组仍需要目标软件验收；本机未安装该软件，自动化不宣称替代此项。

最终验证：相关后端与迁移测试 68 项通过、组件测试 30 项通过，生产构建的浏览器旅程 4 条通过；lint、构建预算、契约/SDK、官方知识库种子与文档保护检查通过。旧迁移测试明确截止到目标 migration，并补齐升级历史断言，避免新增迁移改变旧测试的建库基线。

全量回归记录保存在 .local/presentation-scene/：后端首次完整运行 1822 项通过，旧迁移测试修正并复测后，剩余既有失败包括桌面 Agent 清单缺少三个技能文件读取入口、视觉工坊 generation_draft 旧断言缺少 workflow_parameters；首页 HomeHeroPet 的跨 feature 内部导入也是现存架构违规。Web 全量 302 个文件、2579 个断言通过，但思绪工坊恢复测试留下 ReadingPosition 和 MermaidDiagram 两个异步 mock 异常。全仓格式检查另发现未改动的受保护文档中心 CSS 和思绪工坊 help.md 格式问题；本次修改范围格式检查通过，不改写这些无关路径。
