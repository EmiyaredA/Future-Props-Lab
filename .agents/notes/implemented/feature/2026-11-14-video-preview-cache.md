# Agent Note: 视频剪辑手动预渲染缓存

Status: implemented

## Problem

多轨画面、画中画、文字和密集切镜要求浏览器重复定位视频及逐层合成，已有素材代理不能消除这部分开销。

## Decision

节目监视器提供手动整线预渲染，固定使用保持项目帧率的 720p H.264/AAC。预渲染复用确定性共享渲染器与现有任务/dispatch，结果是派生缓存，不是素材或正式成片。兼容网站增加 `0129_video_preview_renders` 迁移，仅扩展任务类型约束；独立服务现有任务表支持该类型，无需改写历史迁移。

缓存身份绑定账号、项目、已保存 revision、素材摘要及渲染器版本。保存队列提供等待全部提交完成的屏障，保留失败操作时拒绝提交。播放只在起播时选择缓存，使用单个播放器的媒体时钟驱动时间线，缓冲不推进播放头；暂停继续走原编辑与精确帧路径。素材版本或未保存编辑使缓存停用，加载失败在当前位置退回实时预览。

清理先标记任务退役，再由持久执行器回收文件。独立服务保留只含预览标记的终态 dispatch，以便源项目删除后仍能按原账号回收渲染端文件；失败回收继续重试。新缓存完成后退役旧完成缓存。媒体读取核验账号与当前快照，支持 Range，后台生成与发布复核权限。

兼容网站的编码暂存与成品都位于项目派生目录，重启恢复只回收当前任务的残留暂存，项目删除一并回收。文件删除等待实际 I/O 结束；清理失败保留退役记录并轮转重试，不阻塞正常导出通道。

## Alternatives considered

- **继续只使用素材代理**：代理减少单素材解码成本，无法消除多层合成和跳剪定位。
- **自动后台或分段增量预渲染**：降低手工操作或失效成本，但需要额外调度和区间依赖契约；首版采用用户确认的手动整线策略。
- **把预览作为正式导出素材**：可以直接复用发布链路，但产生冗余素材、引用和工程包体积。

## Consequences

重复播放绕过逐层解码、画面合成和独立音轨同步。首次需要等待生成；任意时间线 revision 变化后整体失效。每项目保留一份完成缓存和一项新的有效预渲染，退役文件异步回收。缓存可删除、可重建，不参与正式导出。

Web 证据在 `web/tests/features/video-editor-preview-cache.test.tsx`、`video-editor-save-queue.test.ts` 和 `web/e2e/video-editor-preview-cache.spec.ts`；浏览器样片包含密集切镜、转场、画中画、文字和音频，比较缓存前后的播放器数量与播放指标。

## Deployment

2026-11-14 部署到现有独立服务，只替换 Video、Rendering、Identity、Gateway 及匹配的 Video 前端；保留生产已有的其他契约和功能。前端构建为 `bec46a130dc18db4e436`。四个服务的已登记迁移均为最新，无需执行数据库迁移；兼容网站的 0129 不适用于此部署。

切换使用 Agent 空闲门禁，备份范围仅包含受影响配置与停止后的 Video/Rendering 数据库，验证 SHA-256、SQLite 完整性、外键和迁移账本。失败候选自动回退。镜像打包保留目录执行权限，完整替换带清单的静态目录，服务版本标识使用 20 位摘要；发布前以生产 UID 验证导入、应用装配、清单和资源哈希，并通过临时网关实测新增路由。

最终本机与公网 `/ready`、Video 构建标识、静态资源哈希和新增接口未登录鉴权均通过；任务入口恢复为 accepting，其他服务容器未重建。发布回执保存在 `.local/video-preview/deploy/receipt.json`。线上未替用户项目提交预渲染，实际播放验收仍以本节前述隔离浏览器样片为依据。

## Packaged permission regression

首次上线的 Identity 包含新增权限，Video 的最小部署包遗漏同一份共享权限表。未登录请求在 Identity 返回 401，掩盖了登录后 Video 再次检查权限时返回 `unmapped_account_operation` 的问题。源码集成测试共享最新权限模块，不能单独证明每个部署镜像都包含该版本。

Video 启动时逐项核验其公开操作的账号权限，缺失登记直接拒绝启动。补丁只更新 Video 的权限表与启动检查，不修改账号权限、数据库或前端。五种预渲染操作分别有启动拒绝回归测试；最终镜像还使用一次性测试公钥、隔离数据库与签名 Session 请求验证查询、提交、取消、清理和跨账号 404。发布验证同时检查运行容器内的权限清单，不能仅依赖未登录响应。修复发布证据保存在 `.local/video-preview/deploy/permission-fix/`。
