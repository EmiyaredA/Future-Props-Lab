# Agent Note: 演示工坊原生代码高亮

Status: implemented

## Problem

幻灯片技术示例使用等宽单色文字，缺少语法结构。只在浏览器使用 CSS 高亮会在 PPTX 导出后丢失，截图高亮又会失去文字编辑能力。

## Decision

演示工坊复用现有 lowlight 依赖，通过独立纯转换函数把语法树转换为现有 PresentationParagraph / PresentationRun。每个物理行是一个段落，语法颜色解析成显式十六进制值，等宽字体、字号与行距沿用既有契约。文本经 React 原生文本节点渲染，不插入代码 HTML，也不在放映和导出时重新运行解析。

代码高亮弹窗只在单个未锁定文本框、非文字编辑状态开放，按需加载解析器与预览。用户明确选择语言及适合现有底色的文字配色，检查源码与预览后一次 patch 更新段落，复用草稿、撤销、保存与 CAS。背景、尺寸、分组和连接保持原样。未知语言按纯文本处理；过大输入明确拒绝，不截断源码。运行期修改文稿仍通过正式 API，不直写持久数据库。

工具栏另有“代码块”插入入口，使用同一预览和转换器。codeBlock.ts 按内容生成原生背景、语言标签、分隔线与代码文字，以普通分组作为整体块，不创建第二套渲染或导出状态。超出页面高度或保守字宽预算时拒绝插入并提示调整，不裁切或静默缩字。弹窗通过 Portal 渲染到页面根，避免移动端格式面板隐藏时连带隐藏对话框。

## Alternatives considered

- 使用截图或 SVG 代码图片：无法继续修改源码文字。
- 仅使用高亮 CSS：无法通过现有原生 PPTX 导出保存语法颜色。
- 新建代码元素与持久化语言契约：引入迁移、两套编辑状态和渲染分支；当前复用原生富文本满足明确应用高亮的用例。

## Consequences

无需新增依赖、schema、路由或迁移。语言与配色不作为独立代码状态持久化；普通文字编辑后需再次应用高亮。源码空格、换行、空行和尾部换行保持，CRLF 归一为 LF。高亮不自动缩字号或重排页面，长行与设备字体仍通过页面检查和导出验收核对。

## Verification

组件测试覆盖 JSON、Python、HTML 的颜色、跨行 token、未知语言、空行、中文、编辑器往返、长度限制、安全文本渲染、预览应用与取消。导出测试检查原生 DrawingML 段落、等宽字体和逐 run 颜色，不包含代码截图。真实文稿仅通过配对 SDK 读取、CAS 更新与导出验收。
