# Agent Note: 剧本与预演工作区的信息密度及统一参考入口

Status: implemented

## Problem

剧本名称、场次、排序操作占用多行，预演解析面板留白过多但缺少可核对的信息。舞台顶部重复显示标题、绑定及返回操作；桌面更多菜单重复已有入口。空文生视频节点还要求先切换生成方式才能上传参考，节点标题区域也有额外留白。

## Decision

- 剧本元数据在桌面同排，排序收进菜单，窄屏保留明确标签与操作名称。保存、提取和转预演集中在同一工具行。
- 预演创建面板展示真实解析状态、四项统计、角色道具、机位、对白和待核对动作；较长明细折叠，输入与按钮紧凑排列。样式归独立组件 CSS，避免跨文件覆盖。
- 舞台名称、绑定和采用控件移入场景侧栏设置，通过显式 DOM 容器 portal 复用原编辑器控件与回调，不复制草稿或保存状态。原宿主关闭入口继续执行离开保护。
- 场景标题旁的添加菜单统一收纳“新建空白场景”和“从剧本创建”，列表只显示场景资源。菜单复用既有键盘与关闭行为，两项均经过原有离开保护；取消剧本创建后回到添加按钮。
- 桌面更多菜单只保留未重复的操作，窄屏继续提供被隐藏的重命名、主题与工作台视图操作。
- 支持参考输入的模型在无既有引用的文生视频状态直接展示对应上传格。成功新增素材才同步切换全能参考并保存引用；取消、失败及不兼容既有引用继续使用原修复规则。类型顺序沿用[直接上传决策](2026-11-21-direct-reference-upload.md)。
- 看板节点标题缩减上下内边距及操作高度，桌面标题、类型、状态和通过开关同行；外侧横向边距及两栏间隔均为 8px，避免编辑器内边距叠加。窄屏允许整体分行，状态组内部保持对齐。
- 图像生成工作台为参考图增加紧凑标题行，展开操作随标题放置；提示词使用明确编辑边界与同一行版本管理，模型、比例、数量和生成按钮统一为 32px。样式归 `generation/image-workbench.css`，通过图像工作台作用域保持画布生成器布局和业务回调不变。

图像工作台的独立输入行移除及最终边距按用户选定稿由
[图像生成区统一参考入口与边距](../simplification/2026-11-21-image-composer-reference-surface.md)
继续约束，原草稿、版本和生成提交机制保留。

## Alternatives considered

- 仅压缩预演面板空白：仍缺少解析依据，无法快速核对候选，因此增加来自现有解析结果的统计与明细。
- 删除舞台顶部控件及其能力：会失去改名、绑定和采用入口，因此复用原控件移至侧栏。
- 显示上传格时立即切换模式：用户只是查看或取消选择也会改变草稿，因此切换只在新增素材成功时发生。

## Consequences

展示密度和默认上传路径改变，生成提交、场景创建、权限、CAS 保存及离开保护仍由现有组件负责。新增媒体后会显式成为参考生成；纯文生模型继续遵循发布能力。异常反馈保留，解析输入变更会使旧候选失效。
