# Agent Note: 项目验收参考素材列表与放大预览

Status: implemented

后续变更：用户要求移除放大预览；当前交互见[验收素材列表统一选择交互](../simplification/2026-10-23-acceptance-material-selection.md)。缩略图与素材格式继续保留。

## Problem

纯文字下拉框无法辨认相近名称的角色、场景与镜头素材，绑定前也无法确认图片细节或视频动作。用户需要通过缩略图、媒体格式和预览识别实际素材。

## Decision

项目验收拥有独立的参考素材列表，保持 ReferenceMaterials 的输入和固定素材 ID 契约。列表按素材 ID 去重，展示 64×40 缩略图、两行名称和图片／视频格式，点击素材行绑定；已绑定参考仍可预览、替换或解除，最多六个。

每行仅在进入可见区域时通过 useApiBlobUrl 加载受鉴权保护的素材，同一行的缩略图与放大预览共用 Object URL。该 hook 附带可选 MIME 类型元数据，格式依据实际响应而非节点标题；失败时保留媒体类型和明确的不可读取提示。离开可见区域或关闭列表时中止请求、释放 URL，不新增缓存或公共 HTTP 契约。

编辑器统一维护一个活动预览，鼠标停留 250ms 打开，离开后延迟 140ms 关闭以允许跨越浮层间隙。自绘 popover 避开滚动裁剪并在窗口边缘换边、限宽。视频只在放大浮层中静音循环播放，关闭即暂停；自动播放被拒绝后提供播放按钮。独立预览按钮供键盘和触屏使用，打开后聚焦关闭按钮，Escape、外部点击或关闭按钮退出并恢复触发焦点。预览不触发素材绑定。

## Alternatives considered

- 扩展通用 CustomSelect：包含预览按钮的素材行有独立操作语义，强塞入单选 listbox 会改变其他使用方及其键盘契约。
- 打开时加载全部素材并为浮层重新请求：大项目会同时下载很多视频且产生重复 Object URL；按可见行加载和复用 URL 能限制资源占用。
- 根据名称后缀判断格式：节点可任意改名，实际 Blob MIME 类型才是可信格式来源。

## Consequences

绑定、草稿和发布快照保持原有契约。列表新增预览入口与媒体格式，更新官方指南和导入包；不引入后端接口或迁移。现有文件接口返回完整 Blob，因此可见视频仍需加载完整文件，后续若要优化大视频传输，应由文件能力提供独立的缩略图或范围读取契约。
