# Agent Note: Amadeus 会话回放与项目分组

Status: implemented

## Problem

Portal 的旧构建在重开会话时仍使用旧式工具清单。部分旧运行包含重复的最终快照或时间不齐的事件，历史回放会丢失回复与工具之间的顺序。日期分组也无法反映对话涉及的项目。

## Decision

Web 共用实时与历史时间线。运行事件以序号为准，已保存正文不足以由事件还原时仍保留原文。已完成写入与已回答提问以紧凑摘要显示，完整资料可展开。会话列表在账号范围内从最新运行提取最小项目摘要和运行状态，项目归组不需要重写已有会话。

## Alternatives considered

把整轮最终文本始终放在工具之后会丢失前后回复的关系。逐个读取历史对话以分组会增加请求和事件读取开销。

## Consequences

旧会话缺少结构化项目快照时归入「未关联项目」。已保存的业务状态、引用和审批权限继续决定用户能执行的动作。正式构建按独立版本切换流程另行发布。

## Verification

后端用隔离账号验证列表摘要和跨账号访问。Web 测试覆盖回复快照、旧记录和会话切换，浏览器旅程使用视觉画布验证审批续跑和重开前后的回放。
