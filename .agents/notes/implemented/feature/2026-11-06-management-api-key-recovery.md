# Agent Note: 管理 API 密钥再次复制

Status: implemented

## Problem

用户关闭首次签发提示后，已在客户端使用的管理 API 密钥无法在账号设置中再次复制。

## Decision

Identity 在签发事务内保存加密副本，认证继续验证哈希。网站和独立服务共用取回入口，以浏览器 Session、CSRF、近期密码验证、账号归属和密钥有效状态授权。每次成功取回记录审计事件，撤销删除加密副本。前端只在当前弹窗保留取回的明文。

密钥列表按行显示身份、权限、有效期和状态。有效且可取回的密钥直接提供复制入口，续期、撤销和删除由同一行的更多菜单进入对应确认流程。

## Alternatives considered

- 只保留首次签发提示，刷新后仍需更换客户端密钥。
- 允许登记现有密钥，增加明文提交入口和客户端操作步骤。

## Consequences

加密副本随账号凭据迁移，服务切换须保留部署加密配置。历史哈希可以继续认证，但无法恢复明文。

## Verification

账号 API、独立 Identity 场景与凭据迁移测试验证取回授权和历史兼容。账号页面的浏览器测试覆盖密码重验、复制和清除明文。
