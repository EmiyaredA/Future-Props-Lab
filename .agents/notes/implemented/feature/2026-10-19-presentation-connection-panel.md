# Agent Note: 演示工坊连接线浮动调节

Status: implemented

## Problem

连接设置使用遮罩弹窗，修改时遮挡画布且需要再次应用，难以对照连线效果。旧设置将任何字段修改都视为重新布线，修改文字也会丢失自动布局路径；选中连线增加真实描边宽度，无法准确查看粗细。

## Decision

连接调节使用画布滚动层之外的浮动面板，支持标题拖动、键盘方向键移动与可视边界限幅。面板复用自绘下拉与选色器，常用外观设置直接展示，端点按需展开。位置与折叠状态只属于当前编辑会话，不保存到文稿或本地存储。

SceneTools 拥有当前连接身份、新建预览和修改入口。已有连接读取当前文稿，经 changeSlide 与 draft.commit 更新，沿用历史合并、保存队列和 revision 冲突处理。新建预览仅作为 SlideCanvas 的单独渲染输入，不能进入节点变换快照；点击创建后才提交。删除、撤销导致连接消失时关闭面板，不把失效选择当成新建请求。

connectionEditing 统一计算初始端点、验证可连接节点，并且只在端点、端口或线型发生实际变化时清空 waypoints。外观修改保持路径；选中效果使用额外高亮路径，真实描边保持原宽度。关系文字的输入法组合阶段接入现有草稿组合状态，防止保存半成品。

## Alternatives considered

- 右侧属性栏：画布始终无遮挡，但用户明确选择可拖动的小浮动块。
- 保留应用按钮的小弹窗：仍需要反复提交，不能满足实时调节。
- 同时增加端点拖拽：用户选择先通过面板调节，当前不增加连接几何编辑手势。

## Consequences

关闭面板保留已有修改，新建预览关闭即取消；修改可撤销，面板不锁定画布焦点。Esc 先交由下拉或选色器处理，再关闭面板回到画布。面板内普通键盘操作不穿透画布快捷键。窄屏限制面板尺寸并只滚动内容，标题和关闭入口保持可达。

不新增公共 API、持久字段或迁移。官方使用指南、技术正文与图形、阅读简介和管理员主动导入包同步维护；不改写受保护文档中心，不访问正式运行数据。
