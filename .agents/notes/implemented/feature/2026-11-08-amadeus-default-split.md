# Agent Note: Amadeus 默认分屏

Status: implemented

## Problem

在宽屏上通过 Studio 或工坊入口打开 Amadeus 时，右侧弹窗会盖住正在查看的内容。

## Decision

将[页面内弹窗的原默认值](2026-11-08-amadeus-overlay-and-full-page.md)改为宽屏分屏。视口至少 1100 CSS 像素时，每次重新打开都从分屏开始。窄屏使用现有的浮层布局。

## Alternatives considered

沿用上次关闭时的布局会让每次打开的结果取决于之前的操作。本次采用可预期的默认值。

## Consequences

同一面板内仍可切换分屏和右侧弹窗，也可在新标签页打开完整工作区。缩窄视口后使用浮层，重新变宽时恢复当前选择的宽屏布局。

分屏使用可拖动的分隔线。方向键微调，双击恢复默认宽度。左右两侧分别至少保留 600 和 400 CSS 像素。调整结果保留在当前页面，临时使用浮层或关闭助手后再次分屏会恢复调整值。

## Verification

独立文件页的 Playwright 用例检查默认分屏、键盘切换、关闭后重开、窄屏回退和草稿保留。工坊用例检查窄屏项目搜索和跨工坊多选。

浏览器用例还检查拖动实时改变列宽、键盘宽度边界、恢复默认及重新打开后的宽度保留。
