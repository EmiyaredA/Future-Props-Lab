# Agent Note: H3 多模态提示词展示与精简分镜属性

Status: implemented

## Problem

提示词预览重复显示首尾帧对齐前言和主字段名，却未呈现真实素材缩略图。分镜属性同时展示多套与实际生成草稿分离的参数表单及重复视频，剧本与白模输出关联反而不清楚。

## Decision

以用户最后确认的局部效果图为范围，保留现有三栏布局、工具栏、参考素材输入和输出历史。主提示词从镜头正文开始，仅在展示层省略已识别的对齐前言和主描述标题；编辑、复制、保存和提交仍使用完整原文。此规则细化并替代[初版渲染](2026-11-21-h3-prompt-rendering.md)中预览必显示所有前言的决定。

格式来自应用内登记的 h3-prompt-writing 基础与全参考指南。展示任务类型、主体、素材引用、保留关系、镜号、时间、说话人、语言、对白、运镜、画面文字及转场／截断。所有内容作为文本或明确组件渲染，不执行提示词中的 HTML。

素材引用接收调用方提供的实际输入槽位，不依赖文件元数据到达顺序，缺失槽位保留标签。主体显示定义中的多个来源，不以主体编号绑定图片；视频与音频独立编号，不推断视频自带音轨。图片和视频使用缩略图，音频使用类型图标；完整视频与音频仅在打开弹层时读取，关闭释放播放组件。弹层支持键盘、Escape、外部点击和焦点恢复。

正文使用小节标题和行内标签，主体显示定义中的简短名称和实际来源缩略图，镜号、任务及保留关系用可读标签呈现。渲染预览和原文编辑均允许 `@` 选择已有图像、视频、音频、主体、说话人及插入对白。预览维护显式的原文偏移，选取后只插入原有 H3 协议标记并走现有草稿保存；原文编辑中的引用块复制、剪切和投影保留其规范源串，不以显示名称替代协议标记。取消选择不修改正文。模板菜单仅调整当前控件的行距和边框，不改其他下拉样式。

按用户追加反馈，预览标题及行内标签统一 22px 高度，正文行高统一 28px，小节间距 20px，标题下留 8px。各镜头与普通段落共用正文间距，非对白中的空白行仅在显示层收拢，仍保留每段的原文偏移；对白字句及原始换行不改写。不同标签、换行和旧工作台按钮的最小高度不再撑大个别行。

分镜保留名称、描述、剧本与设定关联，移除景别、运镜、规划时长、对白和声音表单及重复视频预览。旧字段随原快照保存。白模关联选择当前项目场景并保存版本，按既有发布标签筛选真实输出；查看输出与打开预演经过原保存保护。切换到不同场景清除旧机位覆盖，不自动写入生成输入或提交任务。

## Alternatives considered

- 删除 H3 预览、只显示文本：用户明确要求保留并扩展格式化展示。
- 从已加载素材数组直接按编号取文件：异步加载与失效文件会使编号错位。
- 删除存储中的旧镜头字段：超出精简界面的范围，也会破坏历史信息。
- 用静态灰模图表示所有关联：无法证明实际导出存在，使用已发布输出节点的真实素材。

## Consequences

不新增 API、数据库字段或迁移，不改生成参数和任务提交规则。原文仍可访问被省略的前言与字段名。白模发布标签只用于当前项目内展示，场景不存在或输出未发布时给出明确反馈，不伪造缩略图。

后续[H3 适配器直接编辑](2026-11-22-h3-adapter-direct-editing.md)按追加要求替代编辑／预览切换，调整正文为 24px 行高及 12px 小节间距，说明收进工具栏信息提示。

后续[按标记显示](../simplification/2026-11-22-h3-literal-labels.md)按用户要求替代主体命名与来源缩略图：主体只显示编号，媒体缩略图仅出现在各自图片、视频、音频标记上，不为主体挑选代表素材。

## Verification

单元测试覆盖原文逐字符重组、显示省略、全部语义类型、素材槽位及异步缺失、播放与焦点恢复、原文引用块复制及 `@` 原位插入、旧字段保存、只读与白模关联。浏览器验证与构建证据位于忽略的 `.local/h3-rich-rendering/`。
