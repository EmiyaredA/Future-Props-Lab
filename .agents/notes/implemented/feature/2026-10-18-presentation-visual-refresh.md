# Agent Note: 演示工坊视觉层级与单页换肤

Status: implemented

## Problem

编辑器的场景操作单独占据一排，压缩画布空间；模板、信息图和面板缺少统一视觉。直接通过 CSS 覆盖页面颜色会导致编辑、放映与 PPTX 不一致，自动改旧稿还会破坏已有品牌色和警示含义。

## Decision

编辑器保留项目栏与单排工具栏。场景工具返回显式动作描述与独立弹窗，工具栏消费动作，次要操作进入支持键盘的“更多”菜单。控件状态继续由场景功能拥有，不复制分组、布局与权限规则。窄屏工具栏局部横向滚动，保留全部命令。

新建模板与五类信息图共用蓝青色板，生成时写入原生样式。AntV 的主题文字属性在布局后覆盖，不用于改变标题字号；转换器为标题保留独立原生区域，图形区域按单独的页面框缩放，避免标题挤压或遮挡节点。现有文稿不自动更新，渲染器不覆盖持久化颜色。单页换肤使用纯函数收集可修改颜色并构造新页面，内置色确定性映射，未知颜色默认保留，用户可以逐项指定。目标色为固定点，重复应用默认方案无变化。

预览替换表只在弹窗内，取消不提交草稿；应用作为一次操作进入现有撤销/重做与 CAS 保存。保留字号、内容、几何、分组、连接身份、来源与媒体，仅修改背景和未锁定原生对象的颜色，以及圆角矩形的圆角。连接到锁定对象的边同样保留。只读或裁剪时不可打开换肤，应用前结束文字编辑。无新增 API、数据库字段或迁移。

## Alternatives considered

- 全局 CSS 换肤：无法同步 PPTX，且无法保留逐页数据。
- 打开旧稿自动替换颜色：无法让用户保护警示色与品牌色。
- 自动整理旧页布局：需要判断文本语义与版式，超出本次确定性样式更新。

## Consequences

换肤不改变栅格图或 SVG，也不修复溢出和字体替代。重新应用信息图源码仍按既有契约替换该信息图的手动调整。界面主题只控制编辑器外壳，幻灯片始终按文稿数据呈现。官方指南和旁置技术图同步维护，受保护文档中心保持原样。

## Verification

组件与数据测试覆盖预览取消、手动替换、锁定和素材保护、数据不变式、重复应用与一次撤销重做、菜单键盘及权限。隔离浏览器旅程检查明暗主题、窄屏、真实截图、保存重开、五类信息图与 PPTX 导出。验收产物位于被忽略的 `.local/presentation-ui/`，不接触正式桌面数据。

最终验证：106 项组件与官方内容测试通过；76 项相关后端测试通过，另行启用的百页导出测量也通过。生产构建的 28 条浏览器旅程通过，其中五类信息图在修正时间线圆点断言后单独复测。截图验收发现并修复了标题重叠及 AntV 背景矩形遮住原生连接线的问题，回归覆盖独立标题区域、连接数量与背景排除。

构建、类型、lint、契约/SDK、官方导入包、Note 与文档保护检查通过。Note 脚本通过 `node --import tsx` 执行，避开沙箱禁止的 tsx CLI IPC。全仓格式检查仍有两个既有失败：受保护的 `web/src/docs/styles-components.css` 与无关的思绪工坊 help.md；本次范围格式检查通过。PPTX 验收核对原生文本、颜色、组与连接结构，不代替实际 Microsoft PowerPoint 的字体和显示验收。
