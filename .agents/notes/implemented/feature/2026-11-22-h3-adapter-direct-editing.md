# Agent Note: H3 前端适配器直接编辑与历史格式兼容

Status: implemented

## Problem

已有 H3 提示词使用独立字段标题且不带冒号，旧识别规则将整段回退为普通文本；带时长的 `[Shot 1, first 4.600s]` 也无法解释。只读预览要求额外点击编辑按钮，粘贴后不能即时保持格式化展示，行尾缺少稳定的光标位置，说明文字与小节间距还占据了正文空间。

## Decision

MiniMax H3 仍作为可选择或自动识别的提示词适配器接入。纯解析器与前端视图分开注册，前端注册项拥有自己的编辑器、引用选项及说明；通用字段只分派选中的适配器，普通文本沿用既有编辑器，不改模型参数、供应商协议或后台生成过程。此决定替代[初版预览](2026-11-21-h3-prompt-rendering.md)以及[富引用展示](2026-11-22-h3-rich-references-and-shot-properties.md)中的编辑／预览切换。

解析器接收带冒号字段和不带冒号的独立字段行，支持 CRLF 和混用标题，完整保留 heading 及 token 源串。标题仅在行首识别，不把句内字段名或对白中的文字当作结构。镜头标签兼容括号内时长注释，展示镜号和原注释，不推断或修正生成时长。格式依据应用内 h3-prompt-writing 的基础三段与全参考六段；宽容展示历史变体不代表改写 skill 的规范输出。

H3 前端直接编辑渲染正文。输入、选区替换、纯文本粘贴、原子引用删除及中文输入通过原文偏移完成事务，React 展示标签不用于序列化。标题、素材和协议标记使用明确边界，普通正文与对白文字可以直接修改。复制部分文字读取对应源片段，全选及工具栏复制包含完整原文；粘贴按当前模板重渲染，只读入剪贴板纯文本。长度限制使用原始协议串，撤销／重做保留源快照，清空文本时保持当前编辑会话的适配器和撤销历史，外部版本变更清除本地历史。

每行末尾提供零宽光标锚点，不进入保存文本；点击最后可见文字之后跳过隐藏的协议结束标记。新换行需要编辑时提供对应的可定位空行，不将源串空白写入样式标签。展示正文行高 24px、行内标签 22px、小节间距 12px、正文上方 8px。工具栏信息图标通过 hover 或键盘焦点展示适配器说明，正文不再常驻说明段落。`@` 菜单有真实搜索输入，中文输入法不直接写入正文。

## Alternatives considered

- 要求用户给所有标题补冒号：会强迫用户重写已有内容，展示层可以安全兼容。
- 点击正文后切回原文、失焦后才渲染：仍然无法在格式化正文中直接编辑和立即预览粘贴结果。
- 将渲染 DOM 的 textContent 保存回提示词：会丢失隐藏标题、协议标记和图片编号，中文显示标签也会污染生成输入。
- 把 H3 编辑能力放入所有模型的通用编辑器：超出适配器边界，增加其他格式的耦合。

## Consequences

不增加 API、数据库或模型请求字段。H3 编辑器持有短期选区和撤销状态，调用方仍持有原文、版本及保存失败恢复；生成继续经过原保存屏障。可以切换普通文本编辑完整字段。源串 offset 使用 UTF-16，与 DOM 选区一致，字符删除通过 grapheme 分段避免拆开 emoji。渲染及粘贴中的 HTML 只作为文字处理，不执行内容中的指令。

[隐藏结构边界修复](../bug-fix/2026-11-22-h3-source-boundaries.md)进一步约束删除与跨段替换，避免碰到字段名和对白包装；[按标记显示](../simplification/2026-11-22-h3-literal-labels.md)移除主体名称及代表素材推导。

## Verification

组件测试覆盖无冒号六段与基础三段、CRLF、对白隔离、逐字重组、带时长镜号、直接替换与复制、模板粘贴、中文输入与取消、清空后的撤销和长度限制；同时回归普通生成、版本、引用及分镜保存。隔离浏览器验证明暗主题、1440px／390px、原位输入、粘贴重渲染、信息提示、行尾点击与协议原文保存。证据和构建日志位于 `.local/h3-rich-rendering/`，不调用生成供应商。
