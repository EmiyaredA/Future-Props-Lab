# Agent Note: 演示工坊连接拖拽与沿边端点

Status: implemented

## Problem

连接只能通过设置面板调整，无法直接拖动走线避开内容。四边中点无法表达 panel 边缘偏上的连接位置；移动节点会清空手调路径。用户要求端点可沿边缘任选位置，并明确拖动不能改变直线或折线的类型。

## Decision

在[连接线浮动调节](2026-10-19-presentation-connection-panel.md)基础上扩展画布几何编辑；原面板保持外观与层级职责。

connectionGeometry 拥有旋转端点、边缘投影、路径化简与节点跟随。ConnectionHandles 仅显示画布编辑覆盖层，useConnectionDrag 保存可取消的起始快照与预览，松手才提交一次草稿。四边连续投影按屏幕 16px 吸附，接近中点 5px 时吸附正中；重叠内容不屏蔽背板边缘，分组内背板仍是独立的连接目标。端点保存元素 ID、边和 0–1 的沿边比例，跟随尺寸和旋转；不持久化分组选择或画布运行状态。

直线中点拖动沿两端当前绑定边投影调整比例，碰到边角后限幅，始终保留直线。折线支持线段垂直移动和拐点联动，保留端点绑定。只有面板线型按钮切换类型；重置走线只清空路径。端点未命中有效对象时恢复原状，禁止连接普通线条或另一端的同一节点。

updateScene 在预览和提交中保留内部路径并调整端部，两端等量平移时整条路径平移。后端 connection_routes 消费相同 JSON 测试向量，operations 在整批完成后调整路径，显式路径更新优先。路径整理保留有意折返，拒绝坐标越界或超过 32 个路径点，不写入部分结果。

新字段 source_offset 与 target_offset 缺省 0.5。追加迁移 0100，仅补缺失值，保留既有比例、顺序、路径、revision 和更新时间；迁移先在临时数据库验证定稿，再登记。ORM 继续使用既有文稿 JSON，无新表或列。OpenAPI、Web 与独立 SDK 契约同步生成，受保护文档中心不变；官方指南、技术图形和导入包同步更新。

PPTX 对非中点连接或手调折线路径使用可编辑自由形状，保留准确外观；中点普通连接继续使用原生端点绑定。此选择延续现有 PowerPoint 自由路径兼容性边界，不把自定义路径写进连接对象。

## Alternatives considered

- 仅提供四边中点：实现较小，但无法连接 panel 左侧的任意位置，用户明确要求连续位置。
- 拖动直线后切换折线：早期方案如此，用户明确要求拖动保留原类型，改为投影移动两端位置。
- 自由路径导出后仍绑定 PowerPoint 节点：用户选择工坊内跟随、导出保留外观，保留既有兼容策略。

## Consequences

Escape、指针取消、捕获丢失、切页、权限变化和窗口失焦取消未提交预览；撤销优先取消手势。键盘沿边调整比例，Shift 加速，垂直于边的方向键切换连接点。缩放期间手柄保持屏幕尺寸，拖动暂停手势缩放。编辑覆盖层不进入缩略图、放映或导出。

正式桌面需按已有停机备份与迁移流程升级，开发热加载不代办正式迁移；本次只使用临时测试数据库，不修改正式运行数据。

## Verification

前后端共用节点平移、旋转、缩放、非中点、自动路径与历史非正交路径向量。浏览器旅程验证折线段和拐点、直线不变型、panel 非中点吸附、分组移动、缩放滚动、键盘精调、无效落点、取消、一次撤销重做与保存重开。迁移测试验证幂等和既有比例保留；PPTX 测试核对偏移端点的准确坐标及现有原生绑定。

12 条隔离 Chrome 旅程通过，包含现有连接面板、层级、分组、信息图与明暗窄屏回归；新旅程同时断言无页面运行错误。Web lint、类型、生产构建、公共契约与 SDK、官方导入包、改动文件格式、Agent Note 和文档中心保护检查通过。Note 校验使用 `node --import tsx` 执行同一脚本，避免 sandbox 禁止 tsx CLI 的 IPC 监听。

全库架构检查保留一项既有失败：HEAD 的 HomeHeroPet 从桌宠 feature 内部入口导入。全 Web 格式检查的三个既有失败位于受保护的 docs/styles-components.css、无关的思绪工坊 help.md 和 presentation-lists.test.tsx；均已核对 HEAD，保持原样。

验收文件位于忽略目录 `.local/connection-drag/`，浏览器使用独立临时数据库和登录状态；不访问正式桌面数据。
