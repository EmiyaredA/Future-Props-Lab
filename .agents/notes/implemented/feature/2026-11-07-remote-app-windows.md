# Agent Note: 云控按应用窗口远控

Status: implemented

## Problem

整屏共享增加画面传输范围，公网交互延迟也妨碍日常操作。部署管理员需要从已安装应用中明确选择可远控范围。

## Decision

兼容网站通过可信本机和近期密码重验管理 TOML 名单。WebRTC 握手票据按账号、浏览器会话和入口绑定，网站定时复核授权并关闭失效的 Host 连接。Mac 辅助程序以应用自身身份启动，通过私有 Unix socket 与 Pion 交换数据，让 macOS 将录屏和辅助功能权限归给该应用。辅助程序按窗口采集画面，使用硬件 H.264 编码，按窗口和进程核对输入。公网可使用自托管 TURN。

## Alternatives considered

在 VNC 画面上加应用快捷入口仍传整屏。Wisp 的逐窗口体验与 RelayRemote 的浏览器传输可分别参考，FPL 需要接入自己的管理员会话与本机配置流程。

## Consequences

此功能依赖登录且解锁的 Mac、屏幕录制和辅助功能权限。应用沿用该 Mac 账号的权限。生产切换由配置显式启用，要求先完成 Chrome、文本编辑与公网延迟验收。

独立 Remote 保留远程应用 HTTP 契约及已禁用时的响应。预检拒绝在开启远程应用或 Happier 网站接入时接管业务入口。

## Verification

自动化覆盖名单修改与冲突、浏览器会话隔离、撤权、切换应用及公网权限。Mac 原生采集验证
Chrome 与文本编辑，浏览器回环验证 H.264 首帧及中文输入。Chrome 接收端使用低缓冲目标后，
文本编辑的 20 次输入到画面变化采样中，P50 为 79 ms，P95 为 110 ms。
本机正式站验证了管理员密码重验、读取已安装应用和保存 TextEdit 名单。站点使用安装在用户
`~/Applications` 的签名应用。使用真实管理员会话连接 TextEdit 后，浏览器收到 864×720 画面，
从浏览器发送的验收文本出现在宿主文稿中，断开时视频源和画面清空。公网入口关闭时返回 503，
公网直连与 TURN 按云控参考文档验收。
