# Agent Note: 视觉画布编组与项目常用设定

Status: implemented

## Problem

二维画布的临时多选无法随项目保存。看板曾把人设、场景作为普通上传分类，项目使用的参考图与账号设定卡缺少明确关联。

## Decision

画布版本化文档保存编组与项目常用设定卡 ID。编组保留成员的世界坐标，使用同一画布写入和撤销路径。看板常用设定通过账号设定卡引入，镜头记录当前采用的项目素材和卡片版本。旧素材由用户选择关联，节点 ID 和输出历史继续可用。

## Alternatives considered

自动为旧分类建全局卡会增加未整理记录，也可能合并用户希望分别管理的变体。由用户逐项关联。

## Consequences

编组采用单层，沿用节点连线和输出类型。项目快照重建编组成员并保存已用参考图。导入后的账号卡片由当前用户手动关联。

## Verification

覆盖画布版本冲突、旧客户端写入、保留分类的服务端约束、快照编组往返，以及隔离 Chromium 上的打组、拖动、刷新、解组、撤销和常用设定收录。
