# Agent Note: 甩镜模糊与漏光扫过转场

Status: implemented

## Problem

转场库缺少原片常见的方向甩镜与黄绿色漏光。径向模糊、角向旋转和单色闪白无法表达这两种效果；仅增加面板卡片会使播放预览与实际导出不一致。

## Decision

新增 `whip-pan` 与 `light-leak` 两个画面转场类型，复用接缝、片段头尾和 revision/CAS 操作，不增加接口或迁移。目录定义独立维护名称、分类、搜索词与默认时长，属性检查器复用名称。新建时甩镜 0.4 秒、漏光 0.5 秒，两者默认向左与两端平滑。

共享 media_rendering 拥有确定性配方。甩镜在预乘透明度空间混合九点方向采样，延展边界像素；漏光按画布比例生成黄绿光晕和白色亮核，在节目合成后滤色并保留透明度。Web 图片、文字和视频代理使用对应的方向采样，漏光在节目层仅绘制一次。精确帧缓存的合成器版本递增。

本次只增加产品能力，不修改用户正式时间轴。测试通过隔离数据库和正式 API 创建工程。保留已有片段合并等未提交改动，文档中心保护路径不重新生成；OpenAPI、Web 类型和 SDK 采用定向生成命令，SDK 文档仅执行只读 stale-check。

## Alternatives considered

- 复用径向模糊或闪白：没有方向位移或有色移动光带，与参考效果不同。
- 保存外部转场叠加视频：引入资产生命周期与缩放依赖，无法独立调整方向和时长。
- 只做浏览器滤镜：不能保证精确停帧、透明合并和正式导出使用同一效果。

## Consequences

旧时间轴契约保持兼容，新增枚举需要升级客户端契约。甩镜每帧增加九次采样；实时代理画布宽度上限沿用 960 像素。漏光颜色和两种效果强度使用固定配方，暂不增加独立颜色或强度控件。原视频已有同类效果时，用户主动应用会叠加。

## Verification

后端相关回归 151 项通过，覆盖四方向、三种作用位置、短片段边界、原子保存、撤销重做、工程快照、透明度和重复渲染。Web 相关回归 92 项通过，覆盖分类搜索、默认参数、方向编辑和预览进度。两个浏览器旅程均通过，在隔离工程核对明暗主题、键盘操作、代理裁边、精确帧与编码导出，检查起点、中点和终点；产物统一保存在 `.local/transition-effects/`。切点定位采用片段键盘选择，避免时间尺 33333 微秒网格落在切点前导致比较不同镜头。

Web lint、类型检查、契约 stale-check 与构建通过。全仓库 lint / 格式检查受已有视频下载模块报错阻断；架构检查已有跨功能内部导入违规，本次保留这些无关改动。文档中心保护路径按开始时的内容摘要核对，本次没有修改。
