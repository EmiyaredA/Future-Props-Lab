# Agent Note: 剪辑工坊跨轨片段边吸附

Status: implemented

## Problem

时间轴「吸附」只把移动中的片段贴到**同一目标轨**上其他片段的左右边（外加时间轴 0 与终点）。用户在视觉轨对齐混合轨/音频轨上的入出点时，必须肉眼估齐，跨轨对齐成本高。

## Decision

`snapClipPosition` 收集**全部轨道**上非移动片段的左右边作为吸附目标；左/右对齐语义、8px 阈值、精确 seam（不强制帧网格）、绿线 `guideUs` 与开关持久化均不变。拖拽、落素材、裁剪继续共用该函数。`targetTrackId` 仍由调用方传入，仅用于放置校验，不再限制吸附目标轨。

不吸附播放头；同轨与跨轨共用同一阈值，不做同轨优先加权。

## Alternatives considered

- **仅同轨吸附（旧行为）** — 实现更简单，但无法满足跨轨入出点对齐；绿线已是全画布竖线，限制扫描轨没有交互收益。
- **同轨更小阈值 / 跨轨更大阈值** — 额外旋钮，当前 8px 与帧下限已够用；优先保持单一规则。
- **增加播放头吸附** — 与本次跨轨边对齐无关，留给后续需求。

## Consequences

- **收益**：任意轨上的片段边都可成为对齐参考；现有吸附开关与绿线无需改 UI 结构。
- **代价**：目标边更多时，近距离多候选仍取最近边；落点轨重叠校验不变，吸附后仍可能因同轨冲突不可放置。
