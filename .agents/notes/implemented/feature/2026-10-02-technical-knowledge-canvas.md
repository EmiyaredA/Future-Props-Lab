# Agent Note: 技术原理知识库与笔记画板

Status: implemented

## Problem

产品操作指南无法解释模块、状态和数据如何协作；个人笔记的 Mermaid 源码图也不能表达可拖动的信息图。技术说明需要与源码同步，图形需要可复用、可离线交付，并保持官方内容只读和现有租户、保存与历史边界。

## Decision

第十二个官方库提供十二篇平台原理和十篇应用原理，每篇包含 Mermaid 与版本化信息图。文章、稳定目录和图形文件随应用构建；搜索读取说明和图内标签。官方阅读和个人笔记使用同一 SVG 与 Mermaid 展示组件，原始 HTML 禁用，Mermaid 保持严格模式。只有具备内容写权限的用户能显式创建个人图形副本，来源链接保留官方文章位置。

个人画板是既有第二版笔记中的原子 canvas 节点，独立 CanvasScene 使用 sceneVersion 1。场景只记录绝对坐标、允许的形状、固定图标、文字、样式、连线和托管图片 ID。React Flow 只处理交互，不持久化其选择、测量或视口状态。一次完成的拖动或属性变更进入现有自动保存、CAS 和撤销历史；选择和缩放不更新正文。斜杠菜单的替换和节点插入合为一个事务，防止 React NodeView 刷新时旧受控值覆盖新节点。

后端在既有正式 API 内校验场景、素材归属和版本并发，搜索与历史均追踪画板内容。备份重映射所有历史图片引用；Markdown 使用 fpl-canvas 代码块和资源路径，导入重新上传并映射。HTML、SVG 与 PNG 使用固定白名单图形；前后端共享约定的坐标、连线、文字折行和明暗文字对比规则。剪贴板跨素材范围复制需要携带图片字节并重映射，不信任外部素材 ID。

## Alternatives considered

仅加入更多 Mermaid 模板无法支持用户要求的视觉排版。直接持久化 React Flow 运行状态会将保存格式绑定编辑器内部实现。将官方图形存入用户项目会引入同步和只读保护的额外状态，因此内置内容保持静态，复制只产生个人记录。

## Consequences

不增加数据库表、迁移或 HTTP 路由。React Flow 开源核心为懒加载编辑依赖；产品工具栏和属性面板使用项目组件。画板最多一千元素和两千连线，文字与坐标有明确上限；暂不支持自由画笔、嵌套分组、实时协作或 Mermaid 与画板互转。普通 Markdown 阅读器不能渲染专用画板，完整备份保留全部编辑信息。服务端 Markdown 转换继续限制二十万字符；前端离线 HTML 将 Mermaid 渲染为 SVG，服务端 HTML 的既有 Mermaid 源码回退保持不变。

正文和图形随实现更新；维护说明位于 AGENTS.md 与项目目录索引。原文档中心受保护路径不迁移、不重写。

## Verification

内容测试验证十二库、八十四篇正文、技术库二十二篇及四十四幅图的有效引用、唯一 ID、源码入口和图内搜索。相关组件测试验证场景校验、剪贴板、原子插入、HTML 与 Markdown 往返及历史位置。

后端一百零一项思绪工坊与 SDK 测试通过，覆盖保存、搜索、CAS、历史、备份、图片重映射、注入转义、损坏导入原子性和跨 Workspace 拒绝。浏览器验证官方图复制、只读、全部技术图渲染、画板编辑保存和导出，使用隔离数据；诊断产物保存在忽略的 .local/technical-knowledge/。

最终后端全量 946 项通过、2 项跳过，相关 Web 组件 94 项通过，架构 64 项通过。全仓 lint、格式、API/SDK 契约、Agent Note 与受保护文档检查通过；Web 与 desktop 模式构建通过。七条官方/技术库浏览器旅程通过；再以桌面 Web 产物运行六条技术库旅程，全部通过，覆盖阻断外网后的二十二篇图文、500 保存失败、真实 409 冲突与另存副本、未保存导航保护，以及 150 节点和 149 连线的连续输入/拖动/保存重开。

Web 全量 1122 项通过、2 项超时，失败位于未修改的 Galgame 场景菜单及角色预设测试；局部复跑仍有超时。未为通过本任务门禁修改这些模块或扩大测试超时。

收尾复验通过方向键移动、Delete 删除、撤销、Shift 多选和坐标持久化；暗色控件悬停保持对比度。官方 Markdown 的图块 renderer 独立保持稳定，弹窗打开不重建图块，取消后恢复原按钮焦点并保留阅读缩放。
