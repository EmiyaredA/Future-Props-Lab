# Agent Note: 同步时把多维表格写成普通表格

Status: implemented

## Problem

文章同步遇到嵌入的多维表格时整篇被阻断，预览只显示「暂不支持多维表」。同一篇文章里的普通表格样式差异只是提示，却和这条阻断排在一起，读者无法判断能不能继续同步。

## Decision

预览先用多维表格的静态导出把当前视图展开成标题和普通表格，再交给原有的飞书投影。筛选后的可见列和记录进入这份快照；填色、编组和列宽不写入飞书。源表之后的修改要重新预览并同步。无法访问或已删除的视图变成说明文字，不再阻断其余正文。画板、Mermaid、公式、附件和文档导航仍然阻断。左侧预览渲染这份快照的标题、段落、列表和表格，而不是把正文挤成一段纯文本。此决定补充 [外部连接与飞书文章同步](../feature/2026-10-08-external-article-sync.md)。

## Alternatives considered

- **继续阻断并要求删掉嵌入块**：其余正文可以同步，但调研笔记里的比较表正是要交给飞书阅读的内容。
- **在飞书创建多维表格**：同步目标仍是已有 docx，首版没有创建或维护飞书多维表格的契约。

## Consequences

- **收益**：含嵌入视图的文章可以同步，预览能看到将写入飞书的表格文字。
- **代价与已知上限**：飞书得到的是普通表格快照，不是可筛选的多维表格。人员格仍使用用户 ID，附件只保留数量说明。单篇飞书块超过 1,000 时仍需拆分文章。

## Verification

隔离测试创建一张带记录的多维表格，把它嵌入普通文章后预览同步。预览没有「暂不支持多维表」阻断，本地文本包含记录值，并提示这是当前视图的普通表格。
