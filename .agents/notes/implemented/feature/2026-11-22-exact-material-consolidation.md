# Agent Note: 精确素材身份与可恢复去重

Status: implemented

## Problem

项目导入副本改变素材 ID 并清除卡片关联，导致已有角色、场景、道具归属无法在输入中显示；重复原文件也占用存储。直接按名称猜测归属或删除 ID 会损坏创作引用与历史。

## Decision

按照 Studio 框架、能力实现契约、文件暂存与数据库事务及生产部署规则，将文件哈希与去重账本归 Assets，显式卡片反查及冻结历史清单归 Visual。仅在同一已验证账号内以完整原文件 SHA-256、字节大小与媒体种类核验相同内容；归属来自已保存的卡片关系，有冲突则不显示。

公开 API 固定操作 ID、项目范围与版本，先准备并保护保留原件，再 CAS 迁移当前引用，最后显式选择可删除成员。文件删除前保存元数据，恢复使用新存储键；维护脚本的恢复记录原子写入持久 `.runtime/`。历史输出、任务输入、冲突的槽位与别名保留。设定卡语音纳入设定页，关联页展示实际绑定图片与模型。

## Alternatives considered

- **名称或视觉相似度匹配** — 会把不同资源归并，无法支持用户要求的不推断原则。
- **直接数据库修复或先删除副本** — 绕过所属服务、引用保护与 CAS，失败后不可可靠恢复。

## Consequences

- **收益**：导入副本可以追溯真实归属，安全副本减少存储，清理中断可重试。
- **代价与已知上限**：首次哈希需要读取原文件；历史使用或引用冲突使部分副本必须保留。保留原件和操作账本是恢复依赖。

## Verification

Assets 的精确内容、账号隔离、引用保护、并发准备、故障重试和恢复测试；纯引用替换冲突测试；输入标签回归测试；隔离设定卡端到端、契约生成和类型构建检查。正式整理仅通过公开 SDK 执行并保存实际报告。
