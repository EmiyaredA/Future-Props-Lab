# Agent Note: 连线文字画布缩放与位置数值编辑

Status: implemented

## Problem

连线文字已有拖动与字号字段，但缺少直接缩放的画布入口和精确位置输入。密集流程图中，用户不易发现文字的独立调节方式。

## Decision

选中连线标签后，在右下角显示字号缩放把手。拖动按页面缩放比例换算位移，调整既有 `label_font_size`，并重算沿线锚点与偏移，使标签左上角在文字换行时保持原位。命中区保持屏幕上的 24px，不随画布缩小而难以操作。

连接属性补充文字水平、垂直偏移，数值相对沿线锚点，缺省偏移延续原值。把手支持键盘调节及 Home/End 字号上下限，普通标签方向键继续用于移动。编辑复用草稿、保存、撤销及取消机制，拖动预览不落库，结束只提交一步；只读与放映不显示把手。

本次扩展[标签绑定](2026-11-14-presentation-connection-labels.md)与[字号契约](2026-11-14-presentation-connection-sizing.md)的编辑入口，不增加 API、数据库或导出字段。PPTX 继续按原字号与位置规则输出原生文本。

## Alternatives considered

- 独立文字框宽高字段：与字号和换行重复表达大小，额外扩大保存与导出契约。
- 只保留侧栏字号：不能提供直接画布调节体验。

## Consequences

标签继续归连接所有，调整不改变节点、端点或路径。文本最大换行宽度保持原规则，大小通过字号与自动排版表达，不引入独立横向拉伸。

## Verification

27 项组件测试通过，覆盖缩放位移换算、换行时固定左上角、字号边界、只读与取消、键盘缩放和撤销重做、单轴偏移保留另一轴。隔离 Chromium 旅程通过，验证真实缩放、位置输入、保存重开、路线不变及放映无编辑把手。TypeScript 与相关 ESLint 检查通过。
