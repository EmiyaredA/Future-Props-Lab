# Agent Note: 视觉看板复用应用素材和编辑项目名称

Status: implemented

## Problem

看板的素材上传只能从设备选择文件，应用中已有的素材无法直接放进指定分类和分组。看板顶部的项目名称也无法直接编辑。

## Decision

看板复用素材选择器，从总文件、本项目和其他视觉项目读取图片、视频和音频。总文件走已有项目引用，其他项目走已有跨项目导入。本项目直接使用素材 ID。看板以一次画布版本校验保存新增节点，服务端登记首个输出版本。项目名称复用画布的重命名请求与查询缓存。

总文件沿用文件库的目录层级。每一级显示直属文件夹和可用素材，搜索限定在当前目录，跨目录浏览保留已选文件。

## Alternatives considered

先下载到本机再上传会重复传输文件。另建素材选择器会重复维护来源、筛选和预览逻辑。

## Consequences

外部素材入库后才保存画布。若画布保存失败，当前弹窗重试复用已导入的素材和节点 ID。看板通过文件缩略图预览候选视频。

## Verification

浏览器回归覆盖三个素材来源、总文件的嵌套目录与跨目录多选、分类分组、首个输出版本、刷新恢复，以及项目标题的保存和取消。
