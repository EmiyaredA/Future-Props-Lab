# Agent Note: 桌宠编辑器即时预览与内存桌面联动

Status: implemented

## Problem

编辑器选择事件和修改动作、表情后仍显示待机，用户无法分辨未配置、素材不支持与预览失效。独立桌宠只读取已保存配置，无法检查草稿效果。红莉栖正面长腿直接套用鲸鱼短腿的旋转角度，走动及结束过渡出现交叉步。

## Decision

中央舞台与预览控制器按职责拆出。统一 runtime、inspect、event 三种模式；自动调整保持表情、有限动作演示一次、持续姿态保留，手动完整事件沿用时长和待机恢复。台词调整显示正在编辑的句子，只有手动播放轮换台词与提示音。不存在事件保留内置默认反应，明确 null 不回退；公开 replaceReaction 结束旧动作，避免忙碌状态拒绝新选择。渲染实例按角色结构及素材地址变化更新，菜单及纯配置变化复用实例。人物未实现表情保留中文名称并禁用。

桌面联动默认关闭，仅匹配已打开的项目可启用。私有协议限定展示配置与素材 ID，宿主校验可信主窗口、账号、Workspace 和项目，单一所有者拥有带项目 revision、会话和递增序号的有界租约。桌宠通过现有授权 API 校验固定结构、素材及版本，不接受桥传入的结构或地址。草稿只在内存覆盖；保存继续使用现有 CAS。关闭、导航、刷新、崩溃、身份变化和超时释放，聊天暂停并保留最新草稿；正常走动和主动台词不覆盖联动。运行会话的临时档位与外观保持独立。

人物步态使用真实引擎相位投影，左右腿小角度摆动并交替抬脚，站立过渡也限制角度，保持脚部左右顺序。保留素材、表情种类与鲸鱼姿态；承接[窄窗口走动修复](../bug-fix/2026-10-03-desktop-pet-roaming.md)。

## Alternatives considered

- 每次草稿变化重建渲染器：导致贴图加载、动作重置及菜单闪烁。
- 自动保存草稿或使用公共 REST 保存临时配置：混淆持久与预览生命周期，破坏 CAS 与多窗口编辑。
- 桌面桥传递角色结构或素材地址：扩大权限边界，无法依赖现有项目授权验证。
- 人物直接保留鲸鱼大腿角度：短腿视觉适配不能表达正面长腿的步幅。

## Consequences

不新增数据库迁移或公共接口。租约心跳仅传输展示配置，通信中断后自动恢复；授权快照校验失败时联动结束并提示原因，中间舞台继续可用。资源不变时配置更新保留动画实例。人物前后步幅通过二维投影表达，未新增角色素材。

## Verification

组件覆盖事件选择、属性调整、重复播放、持续表情、清除、待机、快速切换、台词编辑和菜单不重播。真实分层引擎覆盖忙碌替换、持续姿态与完整 walk/run 周期脚距；Live2D 使用实际参数与形变求值验证触发起点和恢复。桌面测试覆盖所有者、账号与空间、项目、乱序、版本、聊天、导航／崩溃和超时。隔离 Electron 使用本地红莉栖包验证草稿、保存、恢复与聊天暂停，并导出真实动画明暗验收图。测试不调用真实供应商模型。
