# Agent Note: 思绪工坊完整功能补齐

Status: implemented

## Problem

知识库缺少超过百条结果的分页入口和刷新后的草稿恢复，画板交互与静态连线不一致。引用、检索、模板、个人阅读状态与整库交付需要贯通内容、历史、素材和权限。

## Decision

沿用 Tiptap、React Flow、FastAPI 与单进程 SQLite，分可靠性、引用检索、内容复用、历史交付四批扩展已有切片。引用解析、搜索、模板、原子复制、命名标记、个人偏好和一致导出快照归属 thought_workshop/knowledge_tools；路由只适配协议，租户和账号只取 Principal。

列表以 40 条分页，查询变化重置页，结果按 ID 去重。本机草稿以账号、Workspace、文档和标签页隔离，IndexedDB 通过复合索引读取，未完成标题输入也保留。保存只按已发送时间清理本标签页草稿，晚到编辑重新基于已确认修订号落盘；409、网络失败和存储失败均保留内容。恢复检查完成前不挂载编辑器，避免只读扩展初始化竞态。账号与 Workspace 变化重建编辑状态。

模板是 Workspace 独立快照，素材具有独立引用保护。复制同时锁定源库、各文档和目标库的 CAS 条件，原子创建新 ID，内部引用重映射，外部引用保留。复制弹窗在来源快照和目标目录加载完成前禁止提交，取消仍可用；冲突只刷新信息，等待用户重新确认。命名快照只标记不可变历史；还原仍追加历史。正文 version 3 接收 version 2，画板 sceneVersion 2 接收 version 1；前后端使用同样的端点、路径、文字与实际内容边界。模板默认新分组插入，替换整板显式确认。

个人筛选和阅读状态只属于当前账号与 Workspace，不推进正文 revision，不参与备份。官方文章正文继续静态只读，本轮明确要求的个人阅读位置通过偏好接口同步；章节锚点和搜索定位优先。该行为扩展了[此前官方阅读任务](2026-10-03-official-knowledge-reading.md)中零偏好请求的范围，未新增官方正文存储或编辑接口。切换账号、Workspace 或文章时，不将新 DOM 或新身份写入旧阅读记录。

备份 version 6 保留历史、模板、标记与托管素材，导入先整体校验，再重映射文档、历史与素材；包外引用带警告降级为文字。整库 HTML 使用 SQLite 显式只读事务取得一致清单，浏览器按同一清单打包图片、附件、离线 SVG/MathML、相对引用及目录。新增 migration 0080 只在隔离数据库验证；正式数据未迁移。

并行 E2E 可显式指定 FPL_E2E_AUTH_STATE，与数据库、端口和输出一并隔离，避免共享登录快照覆盖。静态验收使用任务独立构建目录及 preview --outDir，避免其他构建清空共享 dist。图片设置初始聚焦在布局阶段完成，不通过延迟回调抢占后续字段。选区测试同时等待浏览器选区和编辑器选区，自动保存旅程等待实际 PUT 回执。目录菜单定位可见后再聚焦，消费 Escape 并还原触发器焦点；菜单与抽屉分层关闭。目录旅程等待新文档路由与标题加载，使用唯一知识库名称，并验证正文区域局部滚动。

## Alternatives considered

直接接入 Trilium 或 Docmost 会改变现有编辑、权限、部署和存储边界；引入协作或检索服务增加单机维护成本。只补前端不能覆盖 SDK、恢复与备份，因此采用现有栈内扩展。模板引用原文会破坏独立性；个人偏好进入知识库备份会造成跨账号混入，均不采用。

## Consequences

新增公共 API 必须同步权限、OpenAPI、SDK 和适用的桌面 Agent 清单；内容格式变更需要维护 Markdown、HTML、剪贴板和旧备份转换。模板属于整个 Workspace，仅全量备份包含模板，单库备份包含该库历史和命名标记。SQLite 搜索继续使用转义字符串匹配，中文标签通过 json_each 检索；不新增搜索服务。大规模库导出仍在浏览器生成 ZIP，有同现有便携导出一致的资源与内存边界。
