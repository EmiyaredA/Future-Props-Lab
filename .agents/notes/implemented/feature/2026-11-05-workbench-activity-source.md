# Agent Note: 工作台轮内活动与受限源码预览

Status: implemented

## Problem

工具活动只保留通用名称，正文里的搜索、问答和文件行为难以定位。受管执行的项目权限与原端阅读副本的来源权限彼此独立。

## Decision

工作台参考 Happier 的连续活动分组与稳定行身份，使用 FPL 现有 Web 组件。五种原生适配器从已识别字段提取活动语义，保留原生顺序与工具标识。执行活动使用现有 JSON 持久化槽，附带顺序和可显示详情。仅在成功的受管文件调用后记录可预览的文件引用。文件读取沿用当前账号、云控解锁、项目绑定和描述符路径检查。

## Alternatives considered

整套导入 Happier UI 会引入 React Native、Expo 和另一套同步状态。按聊天里的路径文本打开文件会把展示数据变成未授权的文件请求。源码预览以持久调用标识查找受管引用。

## Consequences

原端副本在授权来源重读后补齐显示字段。历史附件沿用原有边界。源码面板展示当前项目文本及可明确匹配的审批差异。现有队列、原生插入与审批流程继续提供执行控制。

## Verification

隔离测试覆盖五种适配、结构化问答、活动顺序、源文件授权、符号链接、解锁过期和浏览器源码定位。演示入口使用独立账号、配置、数据库和合成执行器。
