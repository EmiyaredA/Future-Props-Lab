# Agent Note: 视频剪辑素材原文件下载

Status: implemented

## Problem

左侧素材列表缺少直接下载入口，用户必须离开编辑器或重新导出才能取得已导入的源文件。

## Decision

素材行提供常驻下载图标，视频、图片与音频共用现有 `/v1/files/{asset_id}/download` 接口，通过平台下载客户端保留认证与错误处理。服务端校验 Workspace 和文件读取权限，并按当前显示名与原始扩展名提供下载文件名；响应缺少文件名时回退到移除路径分隔符的原始文件名。

每行独立管理请求状态，进行中禁用重复点击，失败显示行内原因且允许再次点击重试。原文件下载不依赖代理解析状态、时间线保存或编辑开关，不写入工程，也不重新渲染。较窄面板将改名入口缩为带无障碍名称的铅笔图标，最窄尺寸将按钮换到下一行，保留名称和全部操作。

## Alternatives considered

- 仅在整理菜单提供下载：用户请求左侧片段下载，常驻图标使入口更容易找到。
- 直接导航文件链接：不能保持统一的请求错误反馈，采用与现有分段下载相同的下载客户端和 Blob 保存工具。
- 新增剪辑下载 API：本需求针对素材列表中的原文件，既有文件接口已经提供权限、文件名与媒体内容，无需新增契约。

## Consequences

下载的是完整原素材，时间线裁切、变速、字幕和效果不进入该文件；剪辑输出继续由完整渲染或分段导出承担。下载过程中 Blob 占用与文件大小对应的浏览器内存，与现有分段下载行为一致。接口保持不变，不新增持久状态。

## Verification

- 素材下载组件测试覆盖视频、图片、音频、原文件请求、响应文件名、回退名称、重复点击保护、失败重试、只读和代理失败状态，以及 Object URL 回收。
- 素材列表、下载组件与 API 下载回归共 38 项测试通过；独立浏览器验证 200/250/320px 面板、键盘下载、失败重试、进行中禁用、保存文件名与文件内容。
- 定向 lint／format、Vite 生产打包与预算、官方导入包 stale-check、Agent Note 和文档中心保护检查通过。
- 完整 Web build 的 TypeScript 步骤仍被既有 `web/src/features/thought-workshop/tableColumnResize.ts:466` 的 attributes 返回值类型错误阻止；下载相关代码和测试没有新增类型错误。
