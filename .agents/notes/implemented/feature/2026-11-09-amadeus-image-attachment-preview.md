# Agent Note: Amadeus 会话媒体附件

Status: implemented

## Problem

用户需要在发送前和回看消息时确认图片与视频的内容。Agent 获得的图片文件名也需要能指向当前会话的原件。

## Decision

草稿与消息按当前会话和导入文件名读取可见媒体。缩略图、视频封面与弹窗共用鉴权读取生成的 Blob URL。
Codex 通过本轮工具权限读取引用图片，并在首个请求发送图像输入。其他 Agent 的提示词明确给出会话附件读取工具。

## Alternatives considered

把图片内容编码进引用会增加草稿、运行和消息体积。界面与 Agent 按需读取已上传原件。

## Consequences

会话切换或移除附件时中止读取并释放 Blob URL。媒体解码失败时显示预览不可用。Agent 的图片读取有解码尺寸和
单图输出上限，较大的图片在内存中缩放。Codex 的首轮内联输入受总大小限制，其他图片仍可用会话文件工具读取。

## Verification

浏览器回归用真实 PNG、MP4 和文本验证发送、放大、播放、键盘焦点和刷新恢复。隔离的 Codex 协议回归验证上传
的大图变成可解码的图像输入，图片字节不写入运行记录。
