# Agent Note: 桌宠轻伴随聊天与接触阴影

Status: implemented

## Problem

动画循环把桌宠地面阴影恢复为高不透明度，呈现硬边底座。模型回复同时出现在角色气泡和聊天窗，长文本只传递尾部片段。模型选项占用日常对话空间，展示方式没有个人偏好。

## Decision

接触阴影由分层角色引擎统一计算，使用径向渐变、最高 0.12 不透明度、与尺寸一致的脚底范围；离地渐隐，拖起隐藏。角色聊天 IPC 只驱动思考和说话，文本由一个伴随窗口持有。

伴随窗口在气泡和对话布局间调整大小，不卸载会话或重发模型请求。气泡保留回复开头最多 120 个 Unicode 字符，优先以完整句子结束，并提供完整历史展开入口。模型与主动台词收进设置；聊天展示独立于预设事件气泡开关。生成中可展开收回，持久模式选择在空闲时保存。

presentationMode 属于用户、Workspace 和桌宠的个人会话，沿用聊天 CAS。新增迁移为已有会话设置 dialogue；应用创建新会话明确使用 bubble。旧 PATCH 省略字段保留值，不重置主动台词或模型。生成、清空和设置共享既有 revision 规则。

Electron 只接受该聊天窗可信主 frame 发出的布局枚举及布尔命中状态，保持隔离 preload。透明空白穿透，控件可点击；窗口跟随角色及屏幕工作区，左右换侧同步气泡尾部。

## Alternatives considered

- 仅改 SVG opacity：动画引擎仍会覆盖，不能解决根因。
- 额外生成摘要：增加请求、费用和内容差异；直接保留原文开头。
- 新建窗口切换展示：销毁流式请求和草稿；同窗布局保留生命周期。
- 浏览器本地保存偏好：缺少服务端隔离与 CAS；使用个人会话正式持久化。

## Consequences

新增 schema 迁移及生成契约，需要先隔离验证再正式停机备份迁移。关闭聊天仍取消请求，展开收回不会取消。已有会话继续默认对话；红莉栖经正式设置入口选择气泡。角色原画和 ZIP 不变。

## Verification

后端覆盖迁移保留消息、旧客户端省略字段、枚举校验、revision 冲突和个人隔离。Web 覆盖长文展开、流式期间展开收回、偏好恢复及失败不重试。Electron 覆盖私有 IPC、尺寸及换侧；隔离烟测使用本地 demo 模型检查明暗气泡与对话、重新加载及 DS／人物渲染。

窗口关闭时提前保存 WebContents ID，closed 回调不再读取已销毁的 BrowserWindow；新建 Studio 的 IPC 不返回不可克隆的窗口对象。编译回调测试和隔离 Electron 验收覆盖这两处主进程错误。
