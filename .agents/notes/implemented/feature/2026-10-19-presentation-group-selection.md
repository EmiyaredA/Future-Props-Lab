# Agent Note: PPT 组合内逐层选择

Status: implemented

## Problem

画布点击组内对象始终扩展为整组选区，用户必须通过“更多 → 进入分组”才能调整成员。直接在按下时进入组内会改变拖动的操作对象，文字双击还可能绕过组合层级。

## Decision

`scene/selection.ts` 用命中元素、当前选区、分组层级与多选修饰键计算按下时的选择及候选下钻。只有选区恰好等于一个完整分组时才产生候选；画布松手且屏幕位移不超过 4px 时请求进入一层。拖动、缩放、旋转维持按下时的选区，取消事件和 Escape 丢弃预览与候选。

`useSceneTools` 唯一维护绑定页面 ID 的组内层级，画布通过显式回调请求层级和选区变更。界面显示当前分组与可键盘操作的退出按钮。Escape 依次处理拖动、文字编辑、返回父组及页面选区；退出父级时选中刚退出的组合。空白点击退出全部层级，组外点击按页面层级选择。切页或组消失立即使层级失效，后续撤销恢复分组不恢复旧层级。

文字双击使用首击前的选择状态判断：未分组文字保留直接双击编辑，组内文字需要已单独选中。用于下钻的快速双击只改变选择，不进入文字编辑。多选修饰键不下钻，锁定成员可选择但不能写入，只读页面不开放组内编辑。

## Alternatives considered

- 双击进入组合：用户明确选择再次单击进入，双击保留为文字编辑入口。
- 指针按下时立即下钻：会把准备移动整组的拖动变为成员拖动，改在松手确认。
- 直接解组后编辑：破坏组合结构与 PPTX 语义，不符合局部修改需求。

## Consequences

层级、按下快照和点击判断只保存在编辑器内存，不进入文稿、撤销栈、API 或数据库，无迁移。实际几何和文字变化复用已有草稿与保存链路。移动端保留现有轻编辑边界，单击下钻与退出可用，不新增画布拖动。

操作指南、故障处理、技术正文、旁置图形、阅读简介及官方导入包同步反映当前行为；已有导入笔记不自动覆盖。所有浏览器验收使用 `.local/presentation-group-selection/` 下的隔离数据库与产物，未操作正式桌面数据。

TypeScript、Web lint、生产构建及资源预算、契约/SDK、官方知识库导入包生成与检查、文档中心保护检查通过。Agent Note 校验通过 Node 的 tsx import 入口运行，避免沙箱禁止 CLI 临时 IPC。本次修改文件格式检查通过；Web 全仓格式检查报告范围外文件问题，保留不改，记录在 `.local/presentation-group-selection/format.log`。
