# Agent Note: 演示工坊公式模板与一致预览

Status: implemented

## Problem

公式入口藏在更多菜单，输入只能手写 LaTeX；KaTeX 预览与 MathJax 成品可能支持不同语法，固定对象框也让字号变化被等比适配抵消。

## Decision

工具栏与更多菜单共用现有对象编辑会话。`objects/formula/` 拥有独立模板弹窗、选区插入、预置替换、预览与几何计算；保留 v3 公式源码、颜色、字号和受管素材引用，不改变 API 或数据库。

预览与提交共用本地 MathJax SVG。输入停止 200ms 后渲染，以输入快照隔离旧结果；仅当前成功预览可提交，上传同一份 SVG，再通过原会话提交一次历史。关闭、卸载和失去编辑权限后迟到结果不改文稿。模板和弹窗草稿不持久化。

新对象采用自然尺寸并适应页面，已有对象从旧公式自然尺寸与对象框恢复等比缩放；编辑保留位置与旋转，字号变化参与新尺寸计算。双击编辑复用画布现有单选、分组和锁定边界。

## Alternatives considered

- 嵌入 PPTist 的 Vue 编辑器会引入第二份 UI 状态；使用现有 React 会话。
- MathLive 可提供结构化输入，但当前模板与源码需求不需要新增依赖。
- 保留两套渲染器无法保证预览即成品；统一使用已有 MathJax。

## Consequences

公式仍是独立对象，不提供行内数学编辑。PPTX 保留 SVG、PNG 兼容图和源码元数据，不能作为 PowerPoint 原生公式编辑。长公式或小页面会等比缩小；失败上传保留弹窗输入供用户重试，不自动提交。

## Verification

组件覆盖模板选区、异步竞态、语法错误恢复、上传重试、取消、权限撤销及字号几何。隔离浏览器旅程覆盖插入、双击、撤销重做、保存重开、放映、PPTX 矢量与源码，以及明暗主题、窄屏、低高度和键盘焦点。验收产物保存在已忽略的 `.local/formula-editor/`；不使用正式数据。
