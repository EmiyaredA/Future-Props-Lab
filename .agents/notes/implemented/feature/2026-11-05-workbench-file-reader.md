# Agent Note: 云控并排文件阅读与工具详情

Status: implemented

## Problem

原端历史的工具详情强制折行并叠加缩进，长脚本占满会话。现有源码预览只支持 FPL 执行会话，历史文件路径无法点击，云控桌面占据大部分阅读空间。

## Decision

命令、脚本与输出使用带复制和换行控制的代码块，保持原始文本，hover 只覆盖摘要按钮。参考 Happier 的会话与详情分离交互，云控显式提供桌面、两栏阅读与三栏布局；工作台通过显式容器属性渲染阅读器，独立工作台保留自己的阅读区域。

历史文件请求以账号所属会话为入口，将持久 cwd 与已授权项目精确匹配，再通过现有 descriptor-relative 文件读取执行校验。同步来源不授予项目文件权限。本机项目登记不扩大公网授权；读前后检查云控解锁与项目绑定。只持久化布局偏好，不保存阅读目标或正文。

文件阅读器按扩展名选择已安装的 Lowlight 语法，先解析完整文档，再将 token 分配到原始行，保证跨行注释和字符串不失真。与命令块共用高亮入口和主题颜色；未知类型、超限内容或解析失败退回纯文本，使用 React 文本节点渲染，不执行源码 HTML。

## Alternatives considered

直接把日志中的绝对路径交给文件读取会绕过项目授权。仅显示日志输出不能满足阅读当前文件的需求。把阅读器塞在原本狭窄的聊天列中会继续挤压命令展示，因此云控提供独立文件列。

## Consequences

不新增数据库迁移和文件写入能力。当前兼容网站增加原端会话文件读取接口；独立服务的正式切换仍归原服务化任务。私密配置、隐藏路径、链接和过大文本沿用既有项目规则拒绝。命令路径识别只用于导航提示，最终授权与校验在服务端。

## Verification

后端测试覆盖账号隔离、项目授权、路径越界、私密文件、链接、非文本、大小限制与解锁过期。组件测试覆盖参数解码、链接过滤、复制、换行、行定位、取消过时读取与焦点恢复。浏览器旅程覆盖双主题、两栏／三栏、窄屏与关闭后焦点恢复。

高亮回归覆盖跨行注释、空行和原文保真、未知类型回退、HTML 字面量安全展示、行定位与差异切换；浏览器在明暗主题下验证关键字颜色区别于正文。
