# Agent Note：设定组全部关联图片总览

Status: implemented

## Problem

设定库外层只显示主卡和各变体的采用图。已经关联为候选或参考的完整人设图无法从外层辨认，容易误认为漏绑；打开主卡详情也不能一次查看整个角色的不同造型。

## Decision

三类设定组提供全部图片入口及变体图片数，总览按主卡和变体显示采用图、保存的候选图及已完成候选任务结果。只依据显式素材与任务 ID 汇总，不按名称或外观推断。单卡和组总数按素材 ID 去重，同图跨卡保留各自关联，父图只由所属卡片展示。

总览使用搜索前的完整设定组，并沿用归档显示范围。候选任务查询只在打开总览时建立，进行中的任务继续轮询；关闭后撤销观察并通过 AbortSignal 取消无其他观察者的请求。尚未读取的任务结果以图片数后的加号提示，已经缓存的完成结果继续参与数量统计。图片按可见区域加载，单图失败和候选任务读取失败分别重试。

总览及大图使用原生模态弹窗，支持关闭遮罩、Escape 和焦点恢复。进入设定卡详情先关闭总览，再复用原有编辑流程。图片总览不提供采用或解绑操作，也不执行导入、建卡或保存。

## Alternatives considered

把截图中的图片直接设为采用图会覆盖已有选择。只加强单张卡详情仍需要逐个打开变体。列表预读全部候选任务会为未打开的设定组产生批量请求，因此保留显式按需读取。

## Consequences

不增加服务器接口、数据迁移或持久状态；复用现有账号范围卡片、任务和受认证文件接口。只读用户可查看全部图片。卡片成员和图片数量随当前账号快照更新，已归档的主卡仅作为未归档变体的上下文保留，不因此暴露被过滤的主卡图片。

契约依据为[能力实现契约](../../../../docs/architecture/capability-contracts.md#models-与视觉工坊)的账号卡片、归组和图片总览条款；职责见[目录索引](../../../../docs/architecture/project-layout.md#兼容网站与组件端口)，验证沿用[开发与验证流程](../../../../docs/operations/development-workflow.md#验证矩阵)。

## Verification

单元测试覆盖采用图优先、素材 ID 去重、跨卡关联、父图排除、完成与未完成任务、三类设定组、搜索和归档范围、只读查看、图片失败重试、任务失败重试及焦点恢复。隔离 Playwright 用例覆盖总览、大图与原图、返回正确变体、明暗主题及窄屏，并对比操作前后的卡片快照、检查浏览期间的写请求。

相关单元测试 17 项及隔离 Chromium 旅程通过；截图复核桌面明暗主题和 320/390 像素窄屏。只读盘点核对截图中的 13 张原始素材均可由对应角色组的汇总规则定位，4 张采用图与 9 张参考图保持原关联。ESLint、格式、Vite Studio 打包、体积预算和 Agent Note／文档中心保护检查通过。全量类型检查受既有未提交的 `referenceContentLinks.ts` 使用未生成接口阻塞，报错不在本次总览代码；该文件保留原状。诊断和隔离验收产物位于 `.local/card-family-gallery/`。
