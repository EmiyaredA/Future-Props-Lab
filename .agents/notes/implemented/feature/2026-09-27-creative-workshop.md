# Agent Note: 创意工坊公开版本与安全安装

Status: implemented

## Problem

Workspace 内的工具 API、MCP 和 Skill 只能在集成中心分别维护。用户无法把可复用能力公开给同一部署的其他账号，也无法将数项能力连同使用建议作为方案分发。直接复制集成记录会把私有凭据或本机命令带到其他 Workspace，并使后续更新的归属不清楚。

## Decision

创意工坊使用 Workspace 与作者隔离的可编辑草稿、面向登录用户的公开不可变版本、方案包对能力版本的固定引用，以及目标 Workspace 的安装记录。公开版本只从白名单字段构造；封面重新编码，Skill ZIP 沿用已有路径与规模校验，发布前检查常见私有文件和凭据特征。方案包至少引用一项已公开的独立能力，不嵌套方案包。所引版本撤回时，方案包仍可展示但不允许新安装。

安装预检先查依赖、重复版本和目标名称冲突；确认后在同一数据库事务中写入所有目标集成与安装记录，并补偿删除已复制的 Skill 文件。工具 API 和 HTTP MCP 的凭据为空且默认禁用；Skill 默认禁用；stdio MCP 先登记待配置，目标 Workspace 管理员提交本机命令后在集成中心校验并启用。发布者的新版本不自动改变安装副本。

## Alternatives considered

- **直接共享原 Workspace 的集成记录**：会突破现有租户隔离，也会暴露凭据和本机环境。
- **安装时始终跟随最新发布版本**：会让目标 Workspace 配置在无人确认时变化。
- **首版执行方案编排**：需要独立的运行授权、错误恢复与审计，当前需求仅要求能力集合和建议步骤。

## Consequences

- **收益**：同一部署内的账号可发现公开能力并复制到自己的 Workspace；草稿和现有集成保持私有，重复安装可识别，撤回不破坏既有副本。
- **代价与已知上限**：发布的 Skill 内容只检查常见凭据格式，作者仍须检查自定义文件中的敏感信息。stdio MCP 安装后需要管理员提供、校验并启用本机命令；方案包不自动运行。

## Verification

- 临时 SQLite 迁移与后端用例验证草稿隔离、跨 Workspace 浏览、秘密字段排除、固定版本、stdio 待配置、撤回、重复安装及失败回滚。
- Web 组件与路由测试覆盖广场搜索、草稿到发布和导航顺序；Chromium 流程覆盖保存草稿、发布、详情、预检与安装。
- OpenAPI、Web 类型和 Python SDK 由同一接口生成；运行仓库契约、格式、质量与构建检查。
