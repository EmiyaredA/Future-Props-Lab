# Agent Note: 连线标签字号与箭头大小按连接保存

Status: implemented

## Problem

同页主流程与密集细节图使用相同的 16px 标签和箭头标记，细节文字会压过节点正文，短线上的箭头也显得过大。缩小整页会同时损失正文可读性，减细线条又会改变线身的视觉权重。

## Decision

在连接上增加可选 `label_font_size` 与 `arrow_size`。缺省延续原 16px 字号和中号箭头，旧文稿不批量回写。字号范围为 6–72，箭头提供小、中、大三个预设；右侧连接属性分别控制，不改变节点、端点、路径或位置偏移。

标签布局、输入框和 PPTX 按字号同步计算宽度、行高及文字大小，底垫仍保持原内边距。Web 小号箭头标记尺寸为原来一半，使用 viewBox 保留完整三角形；PPTX 使用 DrawingML 的 sm / med / lg 原生箭头大小，保留可编辑性。

本决策扩展[连线文字绑定](2026-11-14-presentation-connection-labels.md)的固定样式方案；不引入完整富文本样式面板。

## Alternatives considered

- 全局调小默认值：会改变其他已排版的页面。
- 仅减细线条：不能独立控制箭头与文字比例。
- 整页栅格化修改：失去用户要求的原生编辑能力。

## Consequences

结构增加向后兼容的可选字段，无新增路由、表或数据库迁移。浏览器箭头按 SVG 标记缩放，PPTX 使用其原生离散尺寸，验收检查两者实际视觉，而不承诺像素完全相同。

## Verification

共享几何向量增加小字号多行标签；验证非法字号、旧缺省值和三个原生箭头预设。浏览器覆盖调整、保存、重开和放映，交付页核对细节标签与节点的层级。
