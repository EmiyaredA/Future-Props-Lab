# Agent Note: 视频剪辑工坊闭眼睁眼转场

Status: implemented

## Problem

视频剪辑工坊现有转场以淡化、擦除、缩放和模糊为主，没有模拟角色闭眼再睁眼的场景连接效果。

## Decision

在共享时间线转场契约中加入 `eyelid` 类型。接缝使用转场前半合拢、闭合点切换素材、后半睁开的进度；片段入场与退场复用相同的开合进度。预览用画布顶层 SVG 弧形眼睑遮罩，成片渲染用 Pillow 在合成画面顶层绘制匹配的黑色曲线遮罩。

## Alternatives considered

- **复用黑场转场** — 实现简单，但没有上下眼睑的弧形开口，也无法表达闭眼动作。
- **直接裁切视频图层** — 可用单层裁切表达开合，但多轨画面和叠加层会让闭合遮罩不再覆盖整个画布。

## Consequences

- **收益**：效果支持接缝、片段入场和退场，预览和导出共用同一缓动进度语义。
- **代价与已知上限**：眼睑以黑色遮罩表达，不绘制角色肤色、睫毛或眼线；若未来需要主题化外观，应扩展效果外观契约。

## Verification

运行视频转场后端测试、预览转场与转场面板 Web 测试，以及 `npm run contracts:check`、`npm run sdk:check`、`npm run verify-notes`。
