# Agent Note: 知识库列表窄卡片

Status: implemented

后续设计见 [知识库复用工坊项目卡片](2026-11-07-knowledge-library-workshop-cards.md)。

## Problem

「我的知识库」的大幅默认封面占用阅读空间，进入知识库和更多操作在每张卡片底部并列显示。

## Decision

个人库列表使用窄卡片。按内容区宽度自动换列，宽屏最多五列。标题放进封面，正文显示三行简介及文档数和更新日期。卡片是一个键盘可达的进入入口，右上角独立的菜单复用知识库操作及焦点规则。

## Alternatives considered

保留共享项目卡片并压缩封面可以增加密度，但无法直接提供同一张卡片内分离的进入入口与悬浮菜单。私人列表的组件集中承载这两种操作。

## Consequences

同一知识库以持久 ID 选择默认封面色，搜索和排序后色彩保持一致。已上传的封面通过原有鉴权预览加载。文档数和日期直接读取知识库列表响应。

## Verification

`web/e2e/thought-library-layout.spec.ts` 检查五列布局、窄屏换列、明暗主题、标题与简介截断、菜单键盘焦点和库首页导航。
