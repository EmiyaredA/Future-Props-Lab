# Agent Note: 演示文稿列表预览

Status: implemented

后续调整见 [文稿封面直接打开与显式预览](../bug-fix/2026-10-19-presentation-card-entry.md)：封面恢复直接打开，预览改为独立按钮，移除悬停预览。下文保留原决策背景。

## Problem

基础版式缩略图较小，点击即进入新建流程；已有文稿封面不能查看后续页面，用户需要打开编辑器才能判断内容。

## Decision

版式与已有文稿共用预览卡片，延迟 350ms 悬停显示最多前三页，点击打开完整页面弹窗。单页基础版式按真实数据预览，不扩充模板内容；空白卡片保持直接新建。弹窗中的“使用此版式”进入原有命名流程，“打开文稿”进入原有编辑入口，标题继续支持直接打开。预览只使用现有鉴权 API 与页面渲染器，不持久化预览状态。

已有文稿按需订阅 owner query key，只有悬停或弹窗打开时读取完整文稿，复用十秒缓存并传递 AbortSignal；关闭且没有其他订阅者时取消请求。错误提供重试，不重试写操作。Radix 管理浮层碰撞、弹窗焦点约束及 Escape，关闭恢复卡片焦点时抑制悬停层重开；转入新建时把焦点交给命名弹窗。缩略图沿用 SlidePreview 的可见区域延迟渲染。其缩放画布绝对定位，避免 1280×720 内部内容参与外部缩略图的固有尺寸计算；横向缩略图按钮显式允许收缩。

## Alternatives considered

- 仅放大封面：无法检查多页文稿后续内容。
- 首页获取所有完整文稿：增加不必要的网络、图片和渲染负担。
- 把基础版式改成多页模板：改变现有新建内容，超出预览行为需要。

## Consequences

封面点击改为预览，直接编辑可点击文稿名称。只读用户可以预览，但没有新建入口。完整页面、缩略图和悬停预览共用真实幻灯片内容，明暗主题仅影响预览外壳。当前后端没有页面范围读取接口，因此悬停多页文稿仍需读取该文稿完整 JSON，但只渲染前三页。

## Verification

组件测试覆盖版式确认后创建、延迟按需读取前三页、逐页浏览、末页边界键盘操作、失败重试、关闭取消请求和恢复焦点。浏览器旅程覆盖基础版式预览、多页文稿、明暗主题与 390/768/1600 宽度，实际截图核对完整画布与控件可见。63 项演示相关组件测试及 2 项浏览器旅程通过；lint、格式、Note、文档保护与知识库导入包检查通过。Web 全量构建被范围外已有的 `tableColumnResize.ts:466` EditorState attributes 类型错误阻塞。
