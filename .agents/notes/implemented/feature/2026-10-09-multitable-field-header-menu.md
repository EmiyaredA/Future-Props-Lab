# Agent Note: 多维表格列头菜单

Status: implemented

## Problem

表格列头直接打开完整字段表单，列操作和字段配置叠在同一次点击里。隐藏、排序、分组和删除都要离开当前列，表头本身也缺少可发现的操作入口。

## Decision

可编辑的独立表格中，列头先打开分组菜单。修改字段仍进入原字段浮层，锚点是列头按钮，焦点和预览确认保持不变。向左或向右插入一个文本字段「新字段」，名称列左侧不能插入，满 50 个字段时不能再插入。隐藏、升序、降序和分组只改当前视图：排序把该字段放到首位并保留其余排序。按此字段筛选只打开现有筛选页。删除名称列被禁用；字段被看板或日历占用时沿用原提示；其余字段确认后走原字段保存、历史和恢复。只读页面和正文嵌入不提供这个菜单。

菜单和网格密度使用现有主题色。不提供整列填色、复制字段、字段描述、变更提醒、字段编组或冻结到某列。

与 [表头字段配置与显示格式](2026-10-04-multitable-field-config.md) 的关系：字段浮层、显示格式和转换预览仍由该决定约束，只是入口改为菜单中的「修改字段」。

## Alternatives considered

- 继续点击列头直接打开字段表单：少一次点击，但列操作仍然藏在工具栏和全表字段弹窗里。
- 按飞书补齐填色、复制、编组和冻结：这些没有现成的视图或字段契约，会把视觉调整扩成新的数据结构。

## Consequences

- **收益**：列上的展示操作和字段结构编辑分开，已有保存队列、CAS 和历史恢复继续生效。
- **代价与已知上限**：插入会顺延后续字段位置；自定义列顺序的视图会把新字段插到锚点旁边。名称列仍然固定在可见网格左侧。菜单不改变单元格编辑、嵌入权限或全表字段弹窗。

## Verification

- `web/tests/thought-multitable-grid.test.tsx` 覆盖键盘打开菜单、修改字段、名称列不可删除或向左插入、隐藏、升序、筛选入口，以及插入、排序保留和看板占用删除的纯函数。
- 浏览器核对独立多维表格的列头菜单、表头、标签和工具栏。正文嵌入不出现字段菜单。
