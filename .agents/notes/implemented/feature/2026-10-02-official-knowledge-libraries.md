# Agent Note: 思绪工坊内置官方知识库

Status: implemented

## Problem

思绪工坊只展示用户文档项目，缺少在同一阅读入口中访问完整产品指南的方式。官方内容需要对所有可阅读账号保持只读，并随应用版本更新，不能被用户备份、导入或回收站操作改变。

## Decision

官方专区展示一个通用库与十个应用库。通用库提供平台操作和应用总览，详细教程只放入对应应用库。正文重新编写为知识库版中文 Markdown，清单维护稳定 ID、分组和排序，作为后续主要使用指南。原文档中心保持原有职责和保护规则。

官方库使用功能内静态资源和独立阅读路由，不伪装成持久化 KnowledgeBase。Vite 把全部正文打包为可懒加载资源，页面使用现有 Markdown 依赖并禁用原始 HTML。搜索首次需要时加载当前库文章，查询键由思绪工坊维护。所有角色通过 content.read 门槛共用阅读组件，卡片导航继续经过应用未保存保护。

## Alternatives considered

复用旧文档中心正文无法满足用户要求另写并维护知识库版的意图。将官方项目写入每个 Workspace 会引入同步、删除保护、权限与备份兼容问题，且这些系统内容不需要运行期写入。仅给旧编辑器隐藏按钮仍会留下写接口与持久状态，不能表达内置内容的生命周期。

## Consequences

无需数据库迁移或新增公共 API。普通用户同名项目不具有官方身份，官方正文不能经业务写入口修改。桌面阅读只需要本机静态资源；外部模型与服务仍需连接。Web 浏览器首次加载仍需要访问部署，未实现离线站点缓存。

新增应用或修改用户行为时需同步更新清单与正文。官方内容不进入个人备份、回收站和编辑历史。工程包与最终媒体的差别在各应用指南中明确说明。

## Verification

内容与组件测试 10 项通过：十一库、62 篇正文、应用覆盖、内部链接、独立路由、正文搜索、错误重试、安全渲染和缺失文章。架构测试 48 项、API/SDK 契约检查、Agent Note 三项校验和文档中心保护检查通过；本次修改的 ESLint 与 Prettier 检查通过。

独立 Vite desktop 构建通过，清单中的 62 篇 Markdown 均生成可本地懒加载资源。使用该构建产物与隔离数据库运行的六条浏览器旅程通过，覆盖管理员与只读入口、无官方业务请求、未保存保护、刷新及大纲定位、浏览器返回、390/768/1600 宽度和明暗主题。阻断外部网络后仍能打开未读文章并刷新。个人文档的保存、备份导入、图片/公式/图表离线导出和版本冲突流程同时通过。额外回归官方/个人同名库的回收站隔离和恢复。

全仓门禁仍存在本次范围外的失败：后端全量测试 875 通过、19 失败、18 错误、4 跳过（桌面启动环境、已有操作登记/迁移断言、附件校验与剪辑 ripple）；Web 全量 1089 通过、5 失败（文件管理、旧 HTML 覆盖清单、剪辑测试）。全仓 Python/Web lint、Python 格式和 TypeScript 检查也有既存报错。标准 build 被四个既有品牌资产的清单校验值不匹配阻止；标准 dev 的 Amadeus 预构建缺少 vendor harness 源文件，因此浏览器验收使用独立 Vite 启动。上述失败未通过重写无关代码、资产或受保护文档规避。诊断日志与截图保存在忽略的 `.local/official-knowledge/`。
