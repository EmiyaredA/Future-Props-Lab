# Agent Note: 复合片段内部的定时视觉效果

Status: implemented

## Problem

已有转场只能应用于两片接缝或单片头尾。完整复合生成视频的内部切镜无法定位补光、甩镜或相机闪光；为了加效果分割或变速又会改变用户要求保留的复合片段。

## Decision

`VideoEditorClip.timedEffects` 保存片段局部微秒区间、效果类型、方向、缓动和原始进度阶段。只允许图片与视频使用六种单片视觉效果，不引入双片混合或音频处理。通过既有 `updateClip` 原子操作及 revision CAS 保存，旧工程默认空列表，不增加表、列或持久数据转换，因此不需要数据库迁移。

共享渲染与浏览器预览在素材取样后、图层几何变换前按数组顺序处理效果。完整阶段的脉冲前后归零，裁剪与分割保留相位交集，变速同比缩放区间。一个工程帧及更短的闪白按阶段中点取样，确保单帧闪光不会因采到零强度起点而消失。精确帧合成器版本递增以失效旧缓存。

## Alternatives considered

- 分割完整复合视频再使用接缝转场：会破坏用户要求的单个复合片段，且可能引入额外源帧取样。
- 把全部效果烘焙成新素材：增加渲染和版本负担，也失去每条效果的撤销及参数编辑。
- 让接缝转场接受任意时间点：双片源句柄语义与单片脉冲不同，容易误播或重复取样，因此保持两种契约独立。

## Consequences

效果只影响当前媒体图层，字幕标注和原声轨保持独立。默认进度 0–1 自然消退；截取进度允许在切镜处直接结束漏光。合并视频先烘焙各原片效果，替换片段从空效果列表开始，撤销恢复原可编辑效果。素材抠像烘焙只处理素材级默认抠像参数，不复制时间线片段效果。

## Verification

后端测试覆盖六种效果的有效区间、重复 ID 与非法范围、旧工程默认、裁剪及分割相位、变速时间映射、公开 API CAS/撤销/重做/重读、合并后不重复叠加，以及真实编码导出的单帧闪光。相关既有转场、短片段、甩镜/漏光、速度、裁剪与连续解码测试一起运行。契约通过独立 OpenAPI、Web 类型和 Python SDK 生成入口更新，受保护的文档中心生成器不执行写入。
