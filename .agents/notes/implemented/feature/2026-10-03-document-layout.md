# Agent Note: 知识库目录与通用正文编排

Status: implemented

## Problem

官方首页的分组卡片只能由专用组件生成，用户笔记无法制作相同版式。官方侧栏的分组与普通笔记的父子目录存在两套导航。公开引用可能携带旧标题，在撤回后继续显示不应公开的目标信息。

## Decision

目录仅表达父子文档。普通、社区和官方侧栏复用 KnowledgeTree，官方文章按既定顺序作为根文档，不创建分组文章。分组说明保留在自由编排的首页正文，93 篇静态文章、ID、旧 URL、阅读偏好保持。

思绪工坊 document-layout 子域拥有通用卡片、卡片组、动态目录、代码工具栏、提示块标题与正文样式。Markdown 和富文本保留各自解析器，共用展示组件。官方首页由静态清单生成与编辑器同样的块结构；官方正文保持只读，用户通过斜杠菜单或内置知识库首页模板制作相同版式。

正文 JSON 新增 documentCard、cardGrid、documentDirectory 白名单；卡片仅持有目标标识和展示配置，不缓存目标标题与简介。提示块增加标题与 tip 类型。纯校验归属后端 schemas/navigation.py，不改变数据库或 CanvasScene 契约。保存、历史、模板、复制和备份继续通过现有笔记用例。

DocumentAccess 显式提供引用和可见目录适配，NavigationScope 显式绑定知识库和导航守卫。普通使用 Workspace 目录，社区只使用逐篇校验后的发布目录，官方解析静态清单。卡片引用按每文档 100 项批量解析，查询按账号、Workspace 与访问命名空间隔离。撤回或授权失效后展示不可访问状态，隐藏目标标题、简介和链接。动态目录和导出只消费该访问适配器或已过滤的导出快照。

引用索引包含卡片和目录父文档。完整备份与历史保留节点结构，导入映射内部引用；跨访问范围粘贴清除私人目标和父文档引用。HTML 保留卡片排列，Markdown 转换为可读标题、说明和链接，并提示排版变化。标题查询失败时，内联引用也不回退到缓存的私人标题。

## Alternatives considered

- 新建目录分组：引入第二套目录实体，不能与现有移动、删除和权限保持一致。
- 为用户另建官方版式编辑器：保存、恢复、图形与导出会形成平行契约。
- 把目标标题写入卡片：改名不同步，撤回后仍泄露旧元信息。

## Consequences

旧正文不需要批量转换，不新增迁移。官方首页的受控静态块渲染器与富文本 NodeView 分别接入相同卡片组件。当前目录限定为所绑定知识库；社区目录不能直接查询源 Workspace。菜单与权限变化继续保持编辑器和图形实例，不重置画板视口。正式数据没有被用于验收。
