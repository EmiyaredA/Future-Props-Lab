# Agent Note: 剧本目录删除与项目确认弹窗

Status: implemented

## Problem

剧本目录能够新建集和场次，却没有删除入口。白模预演场景删除调用浏览器默认确认框，外观与项目不一致，失败后也缺少留在确认上下文重试的反馈。

## Decision

- 集与场次各自在目录行右侧常驻显示独立垃圾桶按钮，使用具名无障碍标签，不触发条目选择或折叠。只读时隐藏，保存中禁用。
- 复用项目 `ConfirmDialog`。整集确认显示真实的全部场次数，不受目录搜索过滤影响；取消及 Escape 不修改草稿。剧本载入服务器版本也使用该组件。
- 删除更新现有剧本草稿，点击保存或执行既有离开保护时通过原 revision CAS 提交。保留其他未保存编辑，失败保留删除结果供重试。当前条目删除后选择下一项，末尾回退上一项；允许空集和空剧本，并将焦点移至可继续编辑或创建的控件。
- 已有分镜及素材不随剧本删除，保留既有失效来源可修复契约。
- 白模删除继续使用已有 API、revision 和当前场景删除限制。确认期间防重入，失败在项目弹窗内显示错误并允许重试；取消恢复原按钮焦点。

## Alternatives considered

- 删除按钮只在悬停时显示：入口难发现，因此使用常驻图标。
- 剧本确认后立即提交整个文档：会连带保存其他未完成编辑，因此沿用显式保存草稿的既有行为，并在确认文案说明。
- 为删除新增后端接口：现有剧本文档更新支持移除集与场次，复用其账号隔离与 CAS 即可。

## Consequences

整集删除包括搜索暂时隐藏的场次，确认文案据完整文档说明范围。关联分镜可能保留失效来源，但其镜头、生成节点及输出不丢失。没有新增数据库写入路径或存储结构。

## Verification

- 定向组件测试 31 项通过，覆盖确认取消、空集与空剧本、邻近选择、搜索过滤下删除整集、保留未保存编辑、保存失败重试、只读限制和预演删除防重入。
- 浏览器旅程 1 项通过，在隔离测试项目核对桌面／窄屏及明暗主题的删除按钮与项目弹窗，覆盖剧本保存失败恢复、预演删除失败恢复和未出现浏览器默认确认框。
- 改动范围 ESLint、Prettier、Agent Note 与产品文档保护检查通过。全量 TypeScript 检查受同时进行的设定卡 `voice_asset_id`、`facts` 与 `proposed_design` 契约／测试改动阻塞；本次修改文件未报告类型错误，未改写其他任务的契约。
