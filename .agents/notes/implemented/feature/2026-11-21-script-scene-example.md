# Agent Note: 新建场次预填剧本示例

Status: implemented

## Problem

新建场次只有空字段提示，用户难以了解场景信息、动作和对白的写法，也无法直接试用需要正文的提取设定与白模预演入口。

## Decision

按照用户要求，在剧本目录新建场次时预填咖啡馆夜景、两名人物、道具动作和逐行对白的短示例。
示例是新场次的可编辑草稿，走现有保存及离开保护，不自动提交，也不调用模型。
已有场次不回填；用户修改或清空后不自动恢复示例。新建集仍保留原有空目录行为。

## Alternatives considered

- 仅更换占位文本：不能使用户直接试用依赖真实正文的操作。
- 每次遇到空正文自动填充：会覆盖用户主动清空的内容，因此仅在新建场次时初始化。

## Consequences

新增场次的初始正文不再为空，用户可改写或清空后保存。既有剧本、只读入口、账号隔离及保存契约不变。
遵循[能力实现契约](../../../../docs/architecture/capability-contracts.md)和
[开发与验证流程](../../../../docs/operations/development-workflow.md)。

## Verification

- 组件回归覆盖跨集新建场的示例、原草稿保留、首次场次初始化、清空后保存失败与重试。
- 浏览器验证新建后的场景信息和正文可见，提取设定及转白模预演按钮可用。
- 相关组件回归共 24 个用例、TypeScript、ESLint、Vite 构建及包体预算通过；Agent Note 与文档中心保护检查通过。
