# Agent Note: 审批、刷新与独立前端切换中的 Amadeus 会话

Status: implemented

## Problem

审批成功后的通用整页刷新卸载助手，未发送文本和附件引用也随之丢失。独立 App 原先的前端随镜像更新，旧页面可能无法加载按需资源。

## Decision

审批后以服务端回执为准，按资源与项目通知编辑器刷新。视觉画布和视频时间线使用各自的查询和版本检查；其他页面给出新标签页链接。连接中断时重新读回执。助手按账号、App 与标签页保存显示状态和草稿。粘贴文件与文件按钮共用串行导入，文本保持浏览器的原生粘贴。

独立 App 使用经验证的版本目录和原子构建指针。后端切换使用已安装的 Agent 任务入口保护，在暂停后确认在途请求和持久任务为空，再执行切换。

## Alternatives considered

整页重载会卸载对话并破坏编辑器本地状态。统一强制刷新旧前端会中断已有工作。给所有编辑器做相同的数据覆盖逻辑会绕过各自的保存与版本处理。

## Consequences

旧构建由单独的维护操作回收。尚未提供安全局部刷新的页面保留原有内容，用户可以在新标签页查看最新数据。首次安装任务入口保护需要已有流量的空闲窗口。

## Verification

隔离 Chrome 使用真实视觉画布和附件接口，模拟执行响应断开后读回执；核对同一文档更新、原会话续跑请求、草稿和附件刷新恢复。ASGI 集成测试覆盖两套独立构建、旧资源和兼容写入、回退、空闲门禁及暂停时读回执。独立前端浏览器探针保持视觉与视频的旧标签页打开，切换实际构建后读取原资源并提交兼容的模拟续跑请求。正式环境未切换。
