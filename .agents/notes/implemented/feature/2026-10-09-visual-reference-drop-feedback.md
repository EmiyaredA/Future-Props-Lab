# Agent Note: 参考素材拖入结果提示

Status: implemented

## Problem

把项目素材拖入生成参考框后，成功只体现为缩略图变化，拒绝则没有任何变化。重复、自身、满额、类型不符、未导入或参考框不可用时，用户无法判断这次放下是成功还是被拒绝。

## Decision

`useProjectReferenceDrop` 在每次识别到的素材拖放结束后发布一条结果：成功写明已添加或已替换的当前项目文件名，失败写明拒绝原因。文案使用已校验的项目文件名，不使用拖拽载荷里的标题。图片、视频与音频的紧凑生成器把该结果集中显示在参考框附近；未接入集中显示的参考框在自身下方显示同一提示。提示约 6 秒后消失，也可手动关闭。提示不写入草稿，不改变连线、导入或提交。

这补充了 [视觉工作台参考素材拖入](./2026-10-08-visual-reference-drop.md) 中“不额外显示状态文案”的部分。校验、去重、数量限制和自身素材排除保持不变。

## Alternatives considered

- 只在失败时提示：成功时缩略图确实会变化，但参考栏较窄时新增缩略图不容易被注意到，成功同样需要一句确认。
- 复用生成提交的通知：提交错误和拖放结果会互相覆盖，用户可能丢掉还需要处理的提交失败。

## Consequences

- **收益**：每次放下都能确认是否进入当前草稿，以及被拒绝的具体原因。
- **代价与已知上限**：提示是瞬时界面状态，刷新后不保留。文件列表尚未加载时，失败原因是素材未准备好，而不是更细的来源说明。

## Verification

- `web/tests/features/visual-reference-drop.test.tsx` 覆盖添加成功、重复、满额、错误类型、缺失、跨项目、无效载荷、自身素材和禁用框的提示文案，并继续核对草稿未被错误修改。
