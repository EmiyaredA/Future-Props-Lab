# Agent Note: 看板节点操作入口与下载

Status: implemented

## Problem

看板项目素材树的节点行只支持选择与拖入，单节点删除藏在工作台顶部菜单中，用户难以发现节点操作，也无法从该菜单下载当前内容。

## Decision

每个节点行常驻三个点按钮，和工作台顶部共用 NodeManagementMenu，提供下载、重命名、分类与标签、删除节点。选择按钮与菜单按钮为同级元素，菜单操作不触发选择或素材拖拽。分类与标签显式选中目标节点并展开其工作台整理区域；重命名与删除依靠节点 ID 定位目标。

重命名使用已有输入弹窗并调用 controller 的 patchNode，删除使用已有确认弹窗并调用 removeNode。确认框说明原文件保留及下游引用约束，controller 继续负责引用保护、连线清理、撤销与自动保存。菜单与展开状态不持久化，没有新字段或 API。

媒体下载使用已有 Session 鉴权的文件下载 API，下载当前绑定素材并由服务端保留原文件扩展名；文本下载当前正文为 TXT。无内容或下载进行中禁用下载项，键盘导航跳过禁用项。失败展示错误，成功释放 Object URL，不调用生成或保存接口。

## Alternatives considered

- 只在悬停时展示省略号：触屏及未悬停时无法发现操作。
- 常驻管理文字按钮：用户明确选择三个点，通过背景、边框与选中反馈增强可发现性。
- 每行直接删除按钮：占用空间并增加误触，菜单与命名确认更合适。

## Consequences

列表保持原有宽度，长标题继续截断并提供完整标题提示。菜单沿用键盘导航与 Escape 返回焦点，按钮提供独立节点名称标签。官方工作流同步说明入口和可验证结果，节点操作保持现有权限与保存契约。

## Verification

- 看板组件测试验证非选中节点重命名、删除取消与确认、分类展开及菜单键盘操作。
- 下载单元测试验证鉴权入口、原扩展名、文本导出、空内容、失败与 Object URL 回收。
- 浏览器用例覆盖明暗主题、窄屏操作、下载字节、下游引用保护与保存后刷新，使用隔离测试数据库。
