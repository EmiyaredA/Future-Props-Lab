# Agent Note: 首页应用与 AI 能力展示

Status: implemented

## Problem

首页三个等权大卡片占据主要区域，应用图标与模型能力需要跳转后才能发现，辅助入口缺少分类承接。

## Decision

正式首页保留窄侧栏、顶部栏、明暗主题与单一欢迎角色，内容沿既有 Studio 滚动容器展开。App 注入正式应用注册表；首页只维护四组展示归类，不跨层导入 app。文件夹改编 React Bits matte 几何，保留来源和许可证，使用按钮、CSS 过渡与显式展开状态；Esc 关闭并恢复触发器焦点。

模式与文件类型通过 URL 查询参数传递。AppRoute 显式携带查询参数，前进后退与刷新保留参数；文件页校验类型白名单，测试台复用目录模型选择，无可用模型时明确反馈，不执行模型。

文件、工具、集成独立折叠。文件预览和上传使用现有文件 API 与 owner query key，成功后失效同一文件库缓存；批量部分失败仅重试失败项。权限由 App 当前账号上下文传入，主机工具只在本机管理员入口出现。

## Alternatives considered

- 延续独立预览：用户明确改为直接更新应用。
- 完整复制 Folder WebGL／拖放：超出首页需求且增加渲染与维护成本，采用 matte 结构与克制 CSS 过渡。
- 模拟文件与模型状态：正式首页使用账号文件和通用能力说明，不伪造统计或供应商状态。

## Consequences

首页增加一次复用缓存的文件库查询。应用数量与图片来自正式目录，辅助跳转使用原有路由。上传创建真实私人文件，测试只在隔离环境或 mock 中执行。业务接口、数据库契约与原独立预览不变。

## Verification

组件测试覆盖键盘展开、Esc 焦点恢复、独立折叠、模式与分类参数、权限、上传部分失败重试和缓存失效。浏览器旅程检查固定导航、滚动、明暗主题、减少动态效果和 1440、1280、390 宽度；运行类型检查、构建和质量门禁。具体结果与截图记录于 `.local/home-redesign/` 验收产物。

后续收尾补齐了[视频检查器页签状态](../bug-fix/2026-11-02-video-inspector-tabs.md)与完整工坊旅程。最终相关 58 项组件、47 项架构、8 条浏览器旅程及正式构建全部通过。
