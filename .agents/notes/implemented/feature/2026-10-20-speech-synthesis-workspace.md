# Agent Note: 语音合成工作区

Status: implemented

## Problem

语音测试把文稿、语言、参考录音与对应文字垂直展开，生成结果位于表单下方。
用户需要反复滚动才能比较输入与输出，默认音频控件和原始任务状态也缺乏一致的反馈。

## Decision

采用用户选择的第二张视觉方案：桌面左侧编辑配音文稿与参考音色，右侧展示当前模型的生成记录；
内容宽度不足 900px 时上下排列，保留现有应用壳、模型选择与能力切换。
共用测试页头在标签横向溢出时仅滚动标签容器，使当前模式在切换或调整窗口后保持可见。
语言使用自绘选择器和中文名称；参考录音集中展示文件状态与替换入口，对应文字可扩大编辑。

页面显式向草稿 Hook 传递模型、参数和权限。Hook 校验输入，串行执行上传、替换和提交，
替换新输入成功后才清理旧输入；清理失败保留可用的新输入。提交通过原推理 API 创建任务，
成功回执先进入 owner Query 缓存，再独立刷新。刷新失败不抹去提交成功反馈，不自动重放请求。
输入归属任务后不能复用，成功提交清空参考录音但保留文字；失败保留全部输入。
组件以账号和 Workspace 为草稿边界，旧请求不得在身份变更后填入新缓存。

结果组件持有单个音频元素，通过共用鉴权 Blob Hook 读取和回收音频。
自绘播放、暂停与定位控件展示真实时长和播放位置，不合成示意波形；历史选择替换播放器。
下载和保存复用现有 API，保存请求期间阻止重复点击并校验内容写入权限。

## Alternatives considered

- **继续纵向表单**：实现简单，但长文稿会把结果推到首屏外。
- **结果抽屉**：节省空间，但输入输出对照需要反复开关，窄屏焦点管理也更复杂。
- **新增音色参数和波形**：现有接口没有语速、情感或波形数据，不提供无法兑现的控制。

## Consequences

- 不增加路由、后端行为、数据库或公开契约；样式仅影响语音合成区域。
- 草稿不持久化，身份切换清空；任务历史继续由服务端持久化并每两秒刷新。
- 不下载真实模型、不调用真实供应商，播放验收使用确定性 PCM WAV。
- 官方指南和导入包同步，工程职责索引更新；受保护文档中心及 SDK 生成物不改写。
- 截图与验收报告保存在忽略的 `.local/ui-speech-redesign/`。

## Verification

- 组件覆盖提交成功及失败、刷新失败、替换清理失败、输入限制、重复提交、身份切换、播放定位、保存权限与历史筛选。
- 浏览器覆盖真实音频元素播放、暂停、键盘定位、下载、保存和再次生成输入要求。
- 浏览器同时断言进度控件无输入框边框、内边距或填充背景，下载按钮无链接下划线，防止全局表单样式再次渗入。
- 390、768、1600 宽度及明暗主题使用隔离账号、临时数据库和确定性响应检查布局。
