# Agent Note: 桌宠角色台词与账号私有文字聊天

Status: implemented

## Problem

桌宠只有单句气泡，作者无法为不同触发事件准备多种表达，也无法让使用者在不混入角色工程的情况下保存私人文字对话。桌面透明窗口需要独立的可输入区域，且身份切换和关闭必须中断正在生成的回复。

## Decision

桌宠项目配置版本升至 2：六种事件各持有最多八句台词，旧 `bubble` 在读取时转成一条 `lines`；人设只保存角色简介、性格、说话方式和开场白。每个账号、Workspace、桌宠的模型选择、主动台词开关、会话 revision 和消息由 `r0079_desktop_pet_chat` 的聊天表保存。请求 ID 另存防重放记录，清空消息后仍不能重复调用模型。聊天读写从服务端身份确定租户，设置、清空与发送按 revision CAS；同一会话一次只生成一轮。模型通过 LLM 公共文字入口解析和流式输出，提示词使用当前人设与最近十二轮，调用日志标识为 `desktop_pet_chat`。

桌宠窗口提供聊天按钮，Electron 在当前屏幕可用区域内创建跟随桌宠的独立小窗。小窗关闭、桌宠隐藏、身份改变和应用退出时销毁小窗并取消浏览器请求。待机台词以随机 3–6 分钟定时触发，不访问模型。

## Alternatives considered

- 将模型和聊天记录写入角色配置：会把私人数据混入未来可能发布的角色快照，也会让不同账号共享记录。
- 在透明桌宠窗口内直接输入：文字区域会扩大鼠标命中范围，妨碍桌面点击穿透。
- 使用模型测试会话：会把产品对话与测试数据的生命周期、权限和日志语义混在一起。

## Consequences

作者编辑的台词和人设可随角色配置保存，私人模型选择与历史独立保留；桌面小窗仅在 macOS 应用中打开。首版没有语音、长期记忆或电脑操作。取消和失败的本轮消息标记为中断，不自动重发。
