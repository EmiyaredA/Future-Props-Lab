# Agent Note: 视频参考素材整合与图片级追踪对象

Status: implemented

## Problem

视频看板重复展示输入列表和生成参考缩略图。追踪对象只是一段逗号分隔文本，看不到每个目标对应哪张参考图。旧图片排序把连线当前文件写入普通参考列表，上游最终输出更新后可能仍携带旧图。

## Decision

视频生成共用一个紧凑参考区，缩略图下编辑目标，来源与固定版本收进详情。中文常用选项映射为英文调用值，自定义目标继续使用英文。草稿通过素材或连线身份保存目标和图片顺序，Visual 在解析实际输出后组装既有供应商参数。固定、跟随、文本上下文及未就绪引用均保留管理入口。

旧任务在目标数量与已解析图片数量一致时顺序关联，数量不同保留旧参数并由用户分配。旧客户端省略新增字段时保留已存内容。图片排序继续同步全部提示词版本的 Picture 编号。连线加载期间不自动清空持久顺序或提示词别名。

## Alternatives considered

只压缩原有两块 UI 仍保留重复信息。仅按数组下标绑定目标会在重排、删除和上游换图时错配。改变供应商协议会超出本次需求，因此继续发送英文逗号分隔目标。

## Consequences

新增字段位于既有画布 JSON，不需要数据库迁移。复制与快照导入同步映射素材和连线身份。模型不支持追踪时保留草稿绑定但不发送目标参数。浏览器预览通过公共文件与输出接口读取，账号范围和 CAS 规则沿用现有边界。

## Verification

确定性检查覆盖目标校验、旧客户端保存、来源换图、请求排序、复制与解除引用。隔离 Chromium 验收覆盖旧目标关联、对象编辑、固定版本详情、重排、刷新恢复及明暗主题窄屏布局。生成请求使用测试适配，不发起真实付费模型调用。

参考区与页签分隔线之间保留 12px 顶部间距，控件沿同一行对齐，缩略图不另套素材卡背景。主题截图在调色板切换期间禁用过渡，避免将中间灰色误当作最终控件外观。窄屏验收检查工具栏对齐和左右留白。
