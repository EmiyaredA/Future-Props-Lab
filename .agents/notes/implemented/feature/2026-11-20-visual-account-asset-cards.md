# Agent Note: 视觉设定卡归账号共用

Status: implemented

## Problem

可重复使用的角色、场景和道具需要跨项目查看与编辑。旧设定卡依附项目，一个账号会维护多份重复记录。

## Decision

- 账号是卡的归属和版本校验范围。旧项目 API 连接同一套卡，独立设定库无需先建项目。剧本来源保留原项目和场次版本。
- Assets 通过短期委托核验确切文件 ID 与账号。采用图片和关联模型时，编辑器可将项目私有原件副本存入总文件。以卡图为生成参考时，当前项目建立引用或复制；白模放置共享 GLB 时保存当前项目副本。
- 候选生成沿用项目任务队列，并在任务入队事务中关联同一张通用卡。项目快照保存项目剧情和预演，旧项目归档时的卡片可以导入。
- 迁移延续既有卡 ID、修订和数据。删除项目之前核对仍保留的项目文件引用，防止共享卡丢失原件。

## Alternatives considered

跨项目复用时复制整张卡。独立副本会让同一设计各处修改后难以同步。

## Consequences

查看或编辑通用设定不需要项目。候选图生成任务仍需要选择归档项目。已经被卡保存的采用图可以跨项目复用。

## Verification

独立服务资产授权、账号隔离、旧卡迁移和项目快照回归由 `tests/apps/visual_workshop/` 覆盖。Chromium 从左侧设定库创建卡，并在项目素材页查到同一张卡。
