# Agent Note: 演示工坊模板与示例

Status: implemented

## Problem

重复页面对象无法表达全稿标题、页码与章节目录，修改样式容易遗漏；单页版式不能替代可复用的文稿模板。模板设计需要明确区分规范、文稿快照、文稿覆盖与正文。

## Decision

在演示工坊内增加当前 Workspace 的模板与完整示例资源，以 v4 文稿保存模板快照、文稿覆盖、稳定章节身份与页面语义。纯模板解析层生成临时独立对象，正文编辑不回写解析结果。模板保存不自动影响已有文稿，绑定预览同时固定文稿和模板 revision，应用时校验预览摘要并保留正文、素材、备注及覆盖；解绑实体化当前模板外观。

模板、示例和原生包引用均使用受管素材及引用删除保护。目录按章节首次出场排序并同步起始页，容量不足需要显式续页；不完整目录不能静态导出。首次转换旧稿仅接受明确的文字对象映射，旧客户端不能降级覆盖新版数据。迁移 r0111 仅追加四张资源和引用表，不回写旧文稿。

## Alternatives considered

- 每页复制模板元素：不能集中修改，缺乏明确内容来源。
- 打开时自动跟随最新模板：历史交付会静默变化。
- 根据字号识别旧标题：可能误删正文，因此使用显式映射。
- 将模板内容锁定为大图：无法满足原生文字和形状编辑要求。

## Consequences

Web 与后端各自维护纯解析器，使用共享样例核对文字、几何、字体、配色、目录和页码。所有渲染入口消费解析结果；原生包保留模板快照，PPTX 展开为可编辑对象。模板层不参与普通画布选择与删除。模板应用纳入原文稿历史，首次绑定后的撤销也使用 v4 保存，避免触发降级保护。

可绑定文稿正文保持每页 200 个元素预算；解绑物化时允许 v4 无绑定页保留最多 300 个对象，避免正文达到上限时无法保留模板外观。全局设置与模板库保存使用独立生命周期，不共享可变内部状态。模板设计器以独立路由承载工作室，不嵌套在工坊侧栏内；临时内置素材仅用于预览，经正式上传后才进入模板及示例资源。

## Risks

模板覆盖是显式替换字段，必须保留文稿的有意覆盖；跨空间导入不得保留不可访问的源资源关联。新增迁移已在正式数据应用，后续数据库演进只能追加迁移，不能改写 r0111。
