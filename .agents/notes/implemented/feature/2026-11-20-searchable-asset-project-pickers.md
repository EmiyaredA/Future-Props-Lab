# Agent Note：文件与项目的可搜索选择弹窗

Status: implemented

## Problem

设定卡的采用图下拉只列根目录素材。素材和项目增多后，用户难以从长列表找到目标，也无法从同一入口搜索子文件夹中的图片。

## Decision

采用图、3D 模型和归属项目通过可搜索弹窗选择。设定素材查询复用受账号和项目权限保护的目录及文件接口，结果标出来源和路径。点选并确认只修改卡片草稿，保存时继续按素材来源复用共享文件或导入项目副本。画布素材、验收参考、设定卡引用和跨项目来源，以及演示和 Galgame 中直接选择媒体文件的入口沿用同一交互。

## Alternatives considered

给原下拉增加过滤框无法展示足够的缩略图与文件路径，也无法覆盖采用图已有的子文件夹缺口。

## Consequences

长列表可以按关键字缩小范围。关闭选择弹窗时返回触发控件，嵌套弹窗的 Escape 只关闭当前选择层。已有文件引用以及任务归属继续由各入口的原契约管理。

## Verification

浏览器用例验证子文件夹搜索、保存项目图片的共享副本、切换来源、归属项目和嵌套选择器的焦点。验收参考用例继续验证素材格式、去重和图片加载。
