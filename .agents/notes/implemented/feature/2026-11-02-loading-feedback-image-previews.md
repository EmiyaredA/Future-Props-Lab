# Agent Note: 全站加载反馈与图片派生预览

Status: implemented

## Problem

网站的路由、列表和编辑器等待状态只有分散文字，用户无法区分网络传输、模块初始化和服务器处理。
应用图标以几十像素显示却下载数 MB 原图，正文和素材选择器也存在预先读取完整图片的入口。

## Decision

共享 UI 提供整页、区域、行内加载与自绘进度条。150ms 后出现动画，行内按钮名称立即可访问；
10 秒后显示耗时，减少动态效果关闭循环。已知总量才显示百分比，不以轮询次数或计时伪造进度。
功能控制器持有每次传输状态，通过参数传给 UI，不建立全局请求列表或持久化网络状态。

API 以响应流计量接收，以原始 FormData 和 XHR 计量上传；保留 OpenAPI 序列化、Cookie/CSRF、
错误映射和取消。压缩 Content-Length 与解压字节不同口径时不计算比例；SSE 不视为有限下载。
上传字节完成后仍显示服务器处理，业务成功才结束；失败不自动提交。鉴权 Blob 路径改变即隐藏旧 URL，
过期回调不得更新新资源，卸载释放 Object URL。

公开静态图像离线生成摘要命名的 WebP 与尺寸清单，并加入 LFS；构建验证源、清单和 30 KB 图标预算。
托管图片复用有界解码、两个线程、原子落盘与账号预览目录，扩展 128/320/640/1280 尺寸。
已有头像、封面、社区和模型测试图片读取增加可选 size，未提供时仍返回原资源，无 schema 迁移。
SVG 保持安全矢量，动图预览取首帧；精确裁剪、播放纹理、原图预览和正式导出仍使用原始文件。

社区缩略图先验证当前发布、正文引用和逐篇权限，再在源账号上下文读取；派生缓存不授予访问权。
图像请求按可见性延迟，显示尺寸不进入文档和画布。失败不静默回退为大文件，选择按钮内不再嵌套操作按钮。

## Alternatives considered

- 所有区域都展示完整网络面板：占用列表、按钮空间，故采用分层规格。
- 全局猴子补丁拦截 fetch：混合不同资源和生命周期，故采用显式请求回调及功能控制器。
- 先小图再自动读取原图：最终流量不降，故由展示尺寸及明确原图操作决定。
- 用缩略图替换工程素材：会降低裁剪和导出质量，故派生只用于预览。

## Consequences

- 不新增数据库迁移，不访问正式数据库、配置或供应商；旧图片首次读取时通过正式 API 派生。
- 无法测量的模块初始化、缓存读取和服务器处理使用不定进度；速度仅表示当前资源传输速度。
- 新接口参数同步 OpenAPI、SDK 和参考文档。用户于 2026-11-02 明确批准四份生成参考文档的最小更新，
  仅增加 size 参数、扩展尺寸枚举与 SVG 响应说明；其余受保护路径保持不变。批准差异保留于
  `.local/loading-feedback/sdk-docs.patch`。官方文件指南、种子包、接口参考和目录索引同步维护。
- 入口清单与兼容边界见 `docs/reference/loading-and-images.md`；所有临时截图、日志和隔离库位于 `.local/loading-feedback/`。

- 后端最终相关回归 86 项通过，覆盖四种尺寸、方向、透明度、并发原子生成、头像、SVG、跨账号和社区缓存撤权。

  相对原图请求流量下降超过 90%；截图已人工查看，检查内容区加载与手机布局。

- 构建、lint、全量格式检查、LFS fsck 与官方种子包校验通过。SDK 方法、OpenAPI、Web 类型和 SDK 文档一致性检查通过。
- 文档中心变更范围核验仅包含用户批准的四份参考文档，内容与预先提供的差异完全一致；不放宽全局保护规则。
