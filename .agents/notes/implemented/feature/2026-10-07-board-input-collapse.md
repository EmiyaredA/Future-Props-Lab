# Agent Note: 看板输入素材默认折叠

Status: implemented

## Problem

看板节点引用较多时，默认展开的输入素材列表占据编辑区高度，提示词编辑区域过小，需要滚动才能继续写作。

## Decision

输入素材默认折叠，标题保留引用数量和可通过键盘操作的展开按钮。引用任务输出入口保持可见，打开选择器时同步展开输入区域。折叠状态只属于当前工作台组件，不修改节点、连线或画布文档；切换节点后重新使用默认状态。折叠时不请求引用版本或挂载素材预览。

看板图片与视频提示词区域的最小高度从 180px 增至 280px，并随视口高度增长；展开编辑提供更大的高度。样式限定在看板工作台内。

浏览器验收发现画布空格快捷键即使未开始平移，也会拦截 keyup，阻止按钮的空格激活。仅在快捷键确实启动平移时消费 keyup，保证折叠按钮和其他按钮保留标准键盘行为。

## Alternatives considered

- 隐藏引用数量与添加入口：不便核对输入或添加引用，保留紧凑标题栏。
- 持久化折叠状态：当前需求是默认显示行为，使用组件局部状态即可。

## Consequences

提示词有更多编辑空间，引用详情按需展开。现有引用绑定、保存和生成行为继续使用原用例。

## Verification

组件回归覆盖默认折叠、键盘展开、添加入口和折叠不修改引用；浏览器验收检查提示词实际高度、明暗主题与窄屏。
