# Agent Note: 面试资料准备接入本机 Codex

Status: implemented

## Problem

原面试助手的准备进度和来源均为模拟，无法形成可恢复、可追溯的真实资料。外部 Agent 若共享仓库或应用数据目录，会扩大材料、凭据和跨账号数据的读取范围。

## Decision

面试助手自有后端场次、不可变输入、任务与资料版本，原件通过正式 API 上传并按账号与 Workspace 私有保存。后台执行器串行运行本机 Codex CLI，只白名单继承模型连接，并关闭 Shell、用户插件、额外 MCP、记忆及子代理。独立文档 MCP 提供任务内的只读材料和草稿读写，结构化交付由应用验收。进程看护覆盖父进程退出和超时。

任务输入不包含当前聊天、仓库代码、FPL 凭据或其他场次。JSONL 事件驱动真实进度，版本化交付包含原文、来源、知识、问题蓝图与评价依据。实际读取回执、搜索事件和引用自洽是完成条件，Schema 通过不称为事实核实。只有当前任务成功才能替换有效资料，取消、失败和旧回调保留原版本。文字练习固定使用已验收资料，评分与音视频仍为模拟。

此决定替代[初版模拟范围](../../implemented/feature/2026-10-22-interview-assistant-app.md)中的准备与材料仅内存保存约束，其应用注册、主题与导航部分继续适用。

## Alternatives considered

- 直接启动带全部用户工具的 Codex：集成更少，但隐式扩大文件、连接与凭据上下文。
- 完整 app-server 会话系统：适合后续交互式 Agent，目前准备任务只需有界执行、事件与一次交付。
- Agent 直接写持久数据库：省去回收接口，但无法统一校验、权限、CAS 和版本切换。

## Consequences

- 原件读取、真实搜索、交付与实际问题选择形成闭环；无法读取时不伪装完成。
- 后端／浏览器测试覆盖隔离、取消、重试、中断、恢复与版本保护。
- 迁移只在隔离测试数据库验证；正式后端不自动重启或迁移。

## Verification

- 后端、SDK、迁移与配置测试覆盖文件解析、回执、CAS、旧结果拒收、真实子进程事件与取消终止。
- 八个浏览器场景覆盖原件提交、进度、恢复、来源、导出、补充材料、版本保留、问题蓝图及三种宽度明暗主题。
- 显式真实联网测试用虚构 DOCX 完成 CLI 读取、搜索和交付；隔离预览再经生成 SDK 提交任务并保存六个来源、六道候选题和三题首轮顺序。
- 独立 PyInstaller 工具二进制完成 stdio MCP 握手、三工具清单、原件读取与路径拒绝烟测。
- OpenAPI／SDK 契约检查通过。全仓架构和质量检查的既有跨 feature 引用、视频下载 lint／格式问题不在本次改动范围。
