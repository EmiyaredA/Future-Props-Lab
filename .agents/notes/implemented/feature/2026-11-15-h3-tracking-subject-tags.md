# Agent Note: H3 追踪对象标签与 main 集成

Status: implemented

## Problem

截图对应的 H3 人物替换功能已部署，但主工作区没有对应源码；追踪对象以单行文本框呈现，
标题、输入与说明缺乏层次，多对象不易区分。

## Decision

按用户要求，将 `472f1678` 的 H3 功能以三方合并方式整合到当前 main 工作区，保留已有的
工程整理与 UI 未提交改动，重新生成 OpenAPI、Web、SDK 及归属清单。

模型测试与视觉工坊共用 `VideoSubjectControl`。界面以可移除标签呈现，支持 Enter、逗号、
批量粘贴与退格删除，沿用原有英文名称校验和逗号分隔字符串契约。输入中的文字立即同步父组件，
确认只改变呈现方式，避免未失焦或直接提交时遗漏。外部节点／草稿变化替换编辑状态。

视频参数表单由 `ModelVideoParameters` 持有，数值参数校验归已有 `videoCapabilities`，
避免功能整合令旧控制器及页面超过源码体量门禁。不改运行服务或用户数据。

## Alternatives considered

- 仅给原文本框加样式：仍然无法区分及逐个删除对象。
- 标签使用数组持久化：会扩大既有 API 和草稿格式变更，不符合这次界面任务范围。
- 直接覆盖为部署候选源码：可能覆盖 main 上已有的架构与用户改动。

## Consequences

标签继续保存为原参数字符串，旧草稿可以直接恢复；非法输入保留并显示错误。
新样式使用应用主题变量，窄屏自然换行，图标按钮有可访问名称。
主工作区的源码集成不等于发布，当前部署构建保持原状。
