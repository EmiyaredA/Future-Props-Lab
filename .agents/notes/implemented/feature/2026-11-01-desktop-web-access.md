# Agent Note: 桌面本地与公网访问及轻量加载

Status: implemented

## Problem

独立启动的 Web 服务和 LaunchAgent 隧道缺少应用内状态及停止边界。公网首屏提前加载编辑器、公式和 3D，原始媒体预览与缺少压缩缓存进一步增加流量。

## Decision

`capabilities/web_access/` 持有复用现有 ASGI 应用的附加回环监听器和 SSH 子进程；附加监听器关闭 lifespan。运行开关仅在内存，每次启动默认关闭，停止公网先撤销接入再取消重连，退出和崩溃清理所属进程组。连接就绪同时验证 SSH 进程及带实例标识的 HTTPS 探针，握手有启动宽限，指纹、授权和远端端口失败提供受控原因。

头像菜单仅桌面管理员显示访问面板，使用有效 Session、CSRF、近期密码验证及配置 CAS。原生文件选择和配置领取还要求独立宿主凭据与绑定当前 Session 的一次性票据。密钥只保存于受限目录，前端仅得到文件标识和 SSH 指纹。配置交接处理所有窗口的未保存保护，持数据锁停机备份完整 runtime/backend、校验后原子发布 TOML，再启动同一业务运行时。旧 LaunchAgent 接管保存恢复资料并停用自动启动。

登录后的业务入口与桌面宿主动态导入，Web 首页动画主动开启。文件列表和画布按可见区域请求账号鉴权缩略图，原始视频只主动播放时读取；生成限制两个并发，HTTP 取消仍保留工作线程名额。登录权限轮询在隐藏标签页暂停。

Studio 产物带构建标识、SHA256 清单和预压缩文件。相邻 remote-control 项目拥有 Caddy/SSH 模板和发布器，上传前白名单过滤，远端再验证、串行原子切换并保留前两个版本。私人数据不参与发布，API/素材/SSE 禁止共享缓存，开启公网先比较云端构建。Caddy 用 route 固定缓存头优先级。

构建隔离显式 React/Query 与重型依赖；导演台资源分包包含资源模块之间的依赖路径，避免聚合分包引入环，保留底层 vendor 独立。构建预算增加静态分包环检测，未提高既有体积上限。清理已无 markup 的 Galgame 选择器并合并等价作用域，修复旧 CSS 超限。历史迁移测试按具名 0116 边界截断，避免新增 0117 后误把新迁移当作旧空间布局；不改写任何历史 SQL。

## Alternatives considered

- 独立业务后端：重复数据库及后台执行器生命周期，不采用。
- 继续 LaunchAgent 自动重连：App 停止开关无法成为连接的唯一控制者，不采用。
- App 保存服务器管理员密钥并自动发布：扩大权限，采用显式管理员发布命令。
- 共享静态包隐式合并依赖：会将 3D 等重新带回登录入口；改用显式分包与依赖路径闭包，配合静态环门禁。

## Consequences

本机和公网共用账号与数据，Mac 离线时业务不可用。云端程序资源可独立读取；其缓存和 App 转发统计互相独立，面板统计请求正文，非 TLS 线速流量。保存配置的完整核验随素材体量增加耗时，备份与密钥仅留本机。

正式数据更新使用持锁全量快照与已登记迁移入口，保留原有文件、配置与源码修改；本次一并应用工作区已有的 0117 Agent 工作台迁移，访问功能自身不增加迁移。云端已切换静态托管，当前正式数据开发应用已更新；每次启动保持本地与公网访问关闭。旧 LaunchAgent 已经由管理员近期验证和原生配置交接完成接管，保留恢复信息并停用自动启动。随后检测到同期正在移除两个工坊并调整头像、构建和契约，用户选择等待这些修改完成后统一验收发布；当前公网保持关闭，不把首次门禁结果冒充合并后版本的结果。
