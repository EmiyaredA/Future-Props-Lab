# Agent Note: 视觉画布批量复制粘贴

Status: implemented

## Problem

画布支持框选、多选移动和删除，但复制仅读取单选 ID，多选时无法复制。
单节点复制直接保留生成任务关联，并且节点与连线若分别保存会产生中间不完整图和两次撤销。

## Decision

`canvasClipboard.ts` 从选中节点及选区内部连线建立深拷贝快照，复用断线引用清理逻辑移除外部连线带入的参考。
`useCanvasClipboard.ts` 统一节点按钮、选区工具栏、右键菜单和键盘入口，仅在当前项目画布生命周期内保存快照。

粘贴生成新的节点和连线 ID，保留正文、素材及生成草稿，解除生成任务和批次关联；不创建生成任务或复制素材文件。
选区左上角对齐鼠标位置，坐标按当前视口转换，无鼠标位置时使用视口中心；同一落点连续粘贴逐次偏移 32 个画布单位。
数量、坐标或未解决保存冲突阻止整组插入，失败不产生历史记录。

整组节点和连线调用现有快照提交入口，形成一次 CAS 保存和一次撤销记录。保存失败保留草稿，冲突沿用版本选择，均不自动重做粘贴。
框选及节点拖动把焦点交还画布；输入框、富文本后代和弹窗内的复制粘贴仍属于各自编辑器。
多选工具栏展示通用复制操作，宫格合成条件及状态仍由合成模块拥有。

## Alternatives considered

- **只复制节点**：实现简单，但无法复制用户安排好的生成关系；因此保留内部连线并重映射端点。
- **保留全部相关连线**：可以继续引用原图，但会意外连接选区外节点；此次仅保留内部连线。
- **系统剪贴板或跨项目复制**：可扩大复制范围，但需要新增格式及素材、任务归属规则；此次按用户选择限定当前画布。
- **保留原任务关联**：沿用旧单节点行为，但副本可能继续接收原任务结果；副本解除任务及批次关联，生成由用户主动提交。

## Consequences

- 四种节点及内部连线按相对布局复制，修改原节点或副本不会修改剪贴板快照。
- 最大节点数、连线数和坐标边界沿用后端现有约束，不增加公共契约或迁移。
- 剪贴板在刷新或离开画布后失效。没有已保存素材的在途任务副本仅保留生成草稿。
- 现有单节点复制也解除任务关联，并移除选区外连线带入的参考，与批量行为一致。
