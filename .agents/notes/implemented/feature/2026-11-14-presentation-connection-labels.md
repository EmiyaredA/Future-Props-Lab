# Agent Note: 演示工坊连线文字绑定与前景渲染

Status: implemented

## Problem

连接已保存关系文字，但位置固定且画布与 PPTX 的排版不同。用独立文本模拟标签时，移动节点或调整路径会使文字与连接脱离，其他线条也会遮挡文字。

## Decision

关系文字继续由连接的 `label` 拥有。可选 `label_position` 和 `label_offset` 表达路径长度比例与页面坐标偏移；缺省保持旧标签的路径中点上方位置，不批量修改历史文稿。

Web 和后端导出器分别拥有纯几何实现，以同一组测试向量核对路径锚点、换行和外框。固定 16px 字号、20px 行高及 240px 最大外框宽度，标签背景采用页面底色。所有标签在连线与内容之上绘制，避免后绘制的线再次盖字；编辑手柄仍在标签之上。PPTX 使用原生文本框，保留编辑性，但不承诺 PowerPoint 重新路由时自动绑定文字。

就地输入与标签拖动由独立手势控制器持有临时状态。输入确认或拖动完成通过现有草稿提交，取消、切页、权限变化和文稿变更丢弃临时状态；拖动标签不解除端点绑定，不改变路径。

## Alternatives considered

- 独立文本元素：无法随连接更新，重复产生错位。
- 仅给现有 SVG 文字描边：不能阻止后绘制的连接盖字，也不能解决导出位置不一致。
- 完整文字格式面板和自动避障：超出本次已选范围，保留固定可预测的标签样式和手动定位。

## Consequences

后续的字号与箭头预设扩展见[连线大小](2026-11-14-presentation-connection-sizing.md)；旧缺省值保持兼容。

连接结构增加两个向后兼容的可选字段，无新路由或数据库表。标签前景层是原有连接层级的明确例外；标签与节点冲突时由用户拖动调整，不自动重排节点。前后端几何规则须同步维护共享测试向量。

## Verification

共享向量覆盖直线、竖线、折线、多行、长中文、零长度与空标签。前端交互检查覆盖缩放拖动、取消、中文输入、撤销重做；PPTX 检查原生文本、底垫及前景顺序。浏览器验收另检查保存重开与放映。
