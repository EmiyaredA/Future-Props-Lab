# Agent Note: 视觉验收四页的密度与证据审阅

Status: implemented

## Problem

验收界面的标题、主题切换和表单间距占用过多空间。模板与自定义模板混排，结果选择区重复出现，视频对比使用两套原生控制，用户难以在同一视口核对证据、问题和操作。

## Decision

沿用工坊主题，在验收作用域统一 14px 正文、13px 辅助文字、20px 标题及 34px 控件。模板、标准、审阅分别拥有样式；页头和主题切换不改变其他页面。模板筛选与分栏状态仅属于前端，持久化仍遵循[版本验收与候选输出](2026-10-22-visual-acceptance.md)的契约。

内置模板使用紧凑卡片，自定义模板使用真实 Workspace 表格。媒体范围来自实际条目，不根据模板名称猜测。界面不补造接口缺失的更新时间、参考版本或执行信息。

视频控制由验收模块拥有：新版为时间主轴，旧版静音并在较短时长结束后停留末帧。播放结果来自媒体事件与 Promise，失败提示用户，不把按钮点击当作播放成功。实际取样帧与参考素材分区，问题位置使用证据时间。图片区域按真实画幅定位。

人工判断草稿按条目保留，查询刷新不覆盖编辑。原问题按条目 ID 关联，只有新版经过人工确认通过才标记已解决；原始检查与人工记录继续分开呈现。返修草稿复用当前工作台已知的草稿身份，经现有 GET/PUT 接口读取和编辑，没有身份时显式生成新草稿，不假装读取既有草稿。

## Alternatives considered

- 仅缩小全部字号：难读，且无法解决重复控制与信息分组，未采用。
- 修改共享主题组件以压缩所有页面：影响不相关页面，改为验收作用域样式。
- 为预览里的更新时间新增后端字段：本轮是 UI 与审阅交互改造，省略没有真实数据来源的列。

## Consequences

桌面常用内容与主操作在一屏内可见，长内容保留局部滚动。窄屏以列表、预览和详情切换，同一组件实例保留编辑状态。不新增数据库、API、SDK 操作或桌面 Agent 权限。

## Verification

组件测试覆盖模板筛选、分段键盘操作、参考替换与解除、判断草稿、模型不可用、失败重试、只读、播放失败与短片同步。隔离浏览器使用合成图片及短视频验证取样、草稿、复验与最终采用，并保存明暗和多宽度截图；生产数据与付费供应商均不参与测试。实际质量门禁结果保存在 `.local/acceptance/` 的诊断报告中。
