# Agent Note: DeepSeek 官方连接与供应商品牌图标

Status: implemented

## Problem

模型服务只能通过通用 OpenAI 兼容配置连接 DeepSeek，已有同名模型实际归属 SenseAudio 网关。
用户缺少官方服务入口和正确模型预设；供应商白名单也会使独立类型无法进入测试、推理与工坊。
本地 Qwen 使用芯片占位图，无法辨认品牌。

## Decision

- 官方连接使用 `deepseek` 类型，默认地址在请求校验时补齐，凭据、CAS 与租户权限沿用现有目录用例。
- 兼容协议与 DeepSeek 请求选项由 providers 拥有；诊断、流式调用、Agent 和复现显式关闭思考，避免隐含供应商上下文进入公共契约。
- UI 提供 Flash 与 V4 Pro 预设，分别声明实际能力，保留手动模型 ID。不自动播种官方连接或转换已有网关。
- 新迁移仅扩展供应商类型约束，完整保留原表数据、索引与引用；只在临时数据库验证迁移。
- Agent 用量事件表达单轮最新快照。工具测试失败与取消结算部分输出和按轮累计的用量，异常不会被补成成功或触发重提。
- Qwen 与 DeepSeek 使用本地品牌 SVG，来源及 MIT 许可随素材保存。

## Alternatives considered

- 仅添加 OpenAI 配置捷径：不能可靠区分供应商默认参数，也无法独立筛选日志。
- 首版提供深度思考：需要新增思考设置、展示和工具历史上下文契约，超出本次已选范围。

## Consequences

新增 ProviderKind 对外可见，OpenAPI、Web 与 SDK 生成契约同步更新。
升级前需要完成新增迁移；正式桌面开发仍经停机备份及手动应用，不通过热加载直接迁移真实数据库。
已有模型、默认用途和模板记录不因新增供应商而自动变化。

## Verification

确定性测试覆盖官方和代理地址、关闭思考、鉴权、流式文本与图像、工具后续轮次、断流、失败、取消、日志、模板、CAS、租户隔离和迁移完整性。
前端检查协议选择、预设能力、可编辑模型 ID 和本地图标；隔离浏览器检查明暗主题及窄屏。
本次专项后端验收 87 项通过、3 项因既有平台条件跳过；模型目录前端验收 23 项通过，浏览器 390/1440 宽度与明暗主题共 4 项通过。构建、契约、知识库导入包、Agent Note 与改动文件 lint/格式检查通过。
契约生成器仅为 SDK 模型参考的两处供应商枚举补入 `deepseek`；文档保护检查会提示该受保护文件变化，未修改保护脚本或重写其余文档中心内容。全仓测试及 lint/格式检查仍存在本次范围以外的失败，保留原有未提交改动。
真实 DeepSeek 网络调用需要专用凭据，未用真实模型请求替代模拟测试。
