# Agent Note: 桌宠自然关节姿态与接触衔接

Status: implemented

## Problem

正面人物整条腿摆动会出现交叉步和滑脚，单纯缩放正面头部会让攀爬变成扁平拼接。按住期间直立悬挂不表达腰部受力；松手直接恢复站姿锚点会产生可见跳变。鲸鱼的短骨段不能直接使用人物接触高度。

## Decision

沿用单一运动控制器和宿主位置回执。私有运动帧携带阶段、进度、尺寸对应步长、确认位移和接触起点；`phases.ts` 管理支撑时序，`articulation.ts` 维护模型空间的接触点、双骨段求解、重心与平滑关节。支撑脚和手补偿宿主位移，自由肢体屈伸；全局呼吸与翻转缩放不能破坏物理接触坐标。三段四肢维持统一遮挡顺序，骨段不拉长。

人物资源包可选 `motionRig.version=1`，固定肩肘腕、髋膝踝父子树，支持 UV 原画分段、关节补画、腰颈锚点和独立侧向头部。后端验证有限数值、骨长、引用与固定父关系，仍拒绝脚本。旧人物包保留原路径。鲸鱼适配由 `whaleRig.ts` 拥有，以其原画与体型生成内部关节描述，坐姿保留原素材。服饰、表情与运动不共享可变内部状态。

拎起从当前抓点平滑转到资源包腰部锚点，上身弓腰、屈膝、手臂下垂，头部独立平衡；静止摆动衰减。松手平滑恢复原有运行锚点，窗口仍停在放置位置，不立即滑翔。试玩增加左右走路与落地，所有演示继续使用同一姿态引擎；联动只演示姿态。

完整 VPet 参考仓库只放在被忽略的 `.local/references/VPet/`，记录 commit `332933432a93b6daac90186d67be2356e71e75ff`。左右行走、攀爬、下降及静态／动态拎起逐帧参考开始、循环、结束阶段。发布包不包含其动画或代码；新补画通过内置 imagegen 生成，保留原角色站姿、坐姿和并行任务的三套服饰源文件。

## Alternatives considered

- 两条完整腿做正弦摆动：不能控制膝盖和世界支撑点。
- 压窄正面头像模拟侧面：实际抽帧发现头部比例失真，改用独立侧向头部分件及原表情单眼。
- 只用固定的脚尖属性测试：无法发现 IK 够不到目标导致的滑脚；使用真实变形器坐标及实际显示比例。
- 将鲸鱼和人物使用同一固定接触高度：鲸鱼短腿超出骨长，按骨长和步长约束目标。
- 使用 VPet 原始图像：角色造型和独立动画授权不适合本资源包，仅用于本地对照。

## Consequences

资源更新仍走既有完整 ZIP 校验和 CAS，不新增数据库 schema、公共运动路由或自动保存。所有姿态、接触、计时和联动草稿只在内存。侧向头部、三段肢体及关节补画扩大包体，资源画布必须包含悬挂长发范围；角色渲染实例与贴图不因菜单或草稿变化重建。
