# Agent Note: 角色原声参考与设定字段精简

Status: implemented

## Problem

通用角色卡只有图片与模型引用，无法保存日语原声供试听和创作参考；服饰、童年和 Q 版变体也没有对应语音。剧本依据与待确认设计占据角色详情，并会从提取、搜索、候选提示词与旧快照重新进入使用流程。用户明确要求彻底删除这两个字段和已存内容。

## Decision

角色卡以可空 `voice_asset_id` 保存受账号与媒体类型校验的音频引用，沿用素材描述端口、`media_projects` 和短事务 CAS。创建变体时仅在请求未提供语音字段时复制父卡当前引用；显式空值与以后独立更换均被保留，父卡并发变更导致重新创建而非复制过时语音。编辑、只读详情均提供播放器和读取／解码失败后的重试；共享原件不随解除绑定删除。

两套公开接口移除 `facts`、`proposed_design`。兼容网站 `0138_visual_card_voice` 与独立 Visual `0018_visual_card_voice` 通过新增登记迁移删除历史 JSON 键并推进受影响卡片 revision，既有迁移与账本不改写。旧记录读取和旧快照导入丢弃退役字段，引用图片、音频和模型分别核验，原有剧本来源关联保持可用。

原声优先使用原作官网角色试听；新增角色使用标注明确的日语原作台词、带角色名字幕的广播剧或游戏片段，Amadeus 使用自身台词。实际来源、裁切时间和摘要保存在本机正式清单。内容绑定工具通过公开 SDK 校验账号及完整家族、摘要核对、逐卡保存与读回确认；确定性文件名和持久回执支持不确定提交后的恢复，单独保存修改前卡片以便经 API 恢复。

## Alternatives considered

- 只隐藏表单：保留了用户要求删除的数据及隐式提示词输入。
- 所有变体动态跟随父卡：父卡更换会隐式改动已编辑的变体。
- 给每张变体重新上传一份录音：重复占用素材，且无法证明重试不重复上传。
- 给所有角色复制红莉栖音频：不能满足不同角色的真实声音对应关系。

## Consequences

角色语音是录音参考，不创建语音合成音色或提交生成任务。主卡与现有变体显式绑定，新变体复制一次；归组保留原有独立音频。来源文件进入正式素材库，诊断、下载与截图仅放在忽略的 `.local/steins-voices/`，正式清单、回执与恢复资料保存在 `.runtime/steins-voices/20261122/`。这些路径不构成服务依赖，凭据与原声不提交 Git。

## Verification

后端和内容工具的相关 17 项测试覆盖账号隔离、音频类型、CAS、变体复制、显式清空、迁移、旧快照、完整家族及不确定保存重试。角色相关前端回归与播放器读取／解码重试测试通过；隔离 Chromium 的三个角色卡旅程验证上传、保存、刷新、窄屏、选择素材及字段消失。

实际独立 Visual 迁移经离线备份、隔离副本和逐卡数据对照执行，130 张卡片的退役键清零。首轮重启遇到端口释放延迟后已恢复旧库与服务；重试在启动前等待端口释放，完成迁移并恢复 Agent 准入。18 份音频绑定至 18 张主卡与 74 张变体，92 张逐卡读回与音频摘要核验通过，38 张无关卡保持不变，重复执行不新增文件或推进 revision。

当前执行端不支持音频输入，未进行主观音质听审；说话人通过官方映射、片段归属、字幕和游戏名牌核实，音频通过解码与实际浏览器播放验证。来源与验收限制随本机验证报告保留。
