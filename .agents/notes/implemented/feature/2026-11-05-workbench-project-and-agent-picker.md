# Agent Note: 工作台目录树与 Agent 选择

Status: implemented

## Problem

原目录浏览逐级替换列表，选项目时容易失去位置。Agent 列表只显示文字，并将占位提示当作选项展示。

## Decision

本机目录用嵌套列表展示，每个展开按钮按需请求该分支。目录名负责选中，页脚展示路径并等待确认。展开、选中和粘贴路径各有独立反馈。目录检查和登记使用现有接口，查询按账号和目录缓存。Agent 选择复用编程智能体图标，沿用共享下拉菜单的键盘操作。

## Alternatives considered

保留逐级列表并增加路径导航能够改善定位，但仍需离开当前列表才能对照同级目录。一次获取整棵树会增加磁盘读取和响应体积。

## Consequences

可以同时展开多个目录，收起分支后仍可确认已选路径。目录登记继续由服务端检查最终提交路径。项目快捷列表和绝对路径入口保留。

## Verification

云控浏览器用例覆盖键盘展开与选中、收起后保留选择、确认登记、粘贴路径错误与恢复，以及 Agent 图标和键盘选择。
