# Agent Note: 参考缩略图移除与素材拖入

Status: implemented

## Problem

全能参考区通过样式隐藏了缩略图的移除按钮，用户需要打开详情菜单才能取消引用。参考框已有项目媒体拖入协议，但不接受本地文件，分镜与设定卡列表也未提供相应拖拽数据，造成同一素材在不同入口的操作不一致。

## Decision

- 全能参考恢复右上角移除按钮，在悬停与键盘聚焦时显示并暂时让出分类标签位置。按钮和详情菜单使用同一移除回调，调用方拥有连线解除权限，不删除原文件。
- 保留现有项目媒体拖拽协议，分镜提供已产出视频，缺少视频时提供分镜图片；设定卡额外传递卡片 ID，并在目标侧读取账号可访问的当前卡片，复用既有采用图解析与导入。
- 共享参考拖入逻辑通过文件 API 处理本地上传、文件库和跨项目导入，按媒体类型写入原草稿。异步结果在关联前重新检查容量；批量逐项结算，保留成功项并汇总失败，不自动重试写操作或触发生成。
- 以项目和目标节点识别当前关联上下文。目标变化或组件卸载后，迟到文件保留在上传项目中，不回填到新镜头。

## Alternatives considered

仅取消隐藏样式可以恢复手动素材的按钮，但无法解除连线引用。为各入口分别实现上传和拖拽会重复数量校验及失败恢复，因此在共享参考拖入逻辑中扩展既有协议。

## Consequences

分镜内部排序仍保留，拖入参考框时不切换当前镜头或修改来源素材。上传或导入已经完成但用户已离开的文件仍留在项目文件库，可由用户后续选取。图片与首尾帧入口保持单类参考限制，原按钮与选择器保留键盘和无法拖拽时的入口。

## Verification

定向 Vitest 覆盖混合批量上传、数量上限、部分失败、文件库及跨项目导入、切换镜头后的迟到结果、只读限制和设定卡版本绑定。Playwright 使用隔离账号、配置与数据库检查悬停及聚焦、位置与分类标签避让、移除保存、设定卡与文件拖入、本地上传、分镜拖入及刷新恢复。类型检查、定向 ESLint 与格式检查核验消费端契约。
