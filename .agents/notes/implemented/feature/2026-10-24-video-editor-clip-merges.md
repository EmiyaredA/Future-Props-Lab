# Agent Note: 连续视频片段合并

Status: implemented

## Problem

用户需要把时间线上多个连续视频片段变成一个可整体编辑的片段。简单扩展源区间无法支持不同素材、变速、抠像和关键帧；后台渲染直接覆盖时间线会丢失期间发生的编辑。

## Decision

同一画面轨或混合轨的 2～100 个连续视频片段通过独立 clip_merge 任务生成透明 ProRes 4444 MOV，并准备透明代理。共享媒体渲染能力提供显式透明模式，默认成片导出不变。任务冻结选择、设置、轨道、相关转场、边界邻片和素材版本；生成完成只发布项目素材。

前端当前会话通过 applyClipMerge 操作和时间线 CAS 保存队列原子替换，undoClipMerge 从服务端任务快照恢复原片段及转场。内部转场烘焙，外部转场改接新片段；重做复用生成结果。离开页面或重启不自动应用。关联片段先解除关联，跨轨、空隙、重叠及纯音频不在第一版范围。

追加 r0110_video_editor_clip_merges 迁移扩展任务类型约束，不修改既有迁移。新端点登记 Workspace 权限并生成 OpenAPI 与 SDK，桌面 Agent 通道保持默认拒绝。

## Alternatives considered

- 复合片段：需要新增嵌套编辑模型，用户选择生成独立视频。
- 仅恢复同一素材切分：无法覆盖不同源视频，用户选择支持不同源素材。
- 普通 MP4 烘焙：会丢失透明度并遮挡下层画面，内部素材使用透明 MOV，最终交付仍使用既有视频导出。

## Consequences

生成增加磁盘和编码成本，透明 MOV 通常比 MP4 大；失败、取消或冲突不会替换原片段，已生成且未应用的视频可以保留为项目素材。输出、代理和任务完成在文件准备后的短事务中发布；取消与完成通过条件更新避免相互覆盖。

## Verification

自动化覆盖选择约束、快照冲突、内外转场与撤销重做；30/60 FPS 真实 FFmpeg 任务验证透明通道、画幅、帧数、时长、音轨和代理就绪。迁移在临时数据库验证旧任务与外键、索引保留。Web 组件与浏览器旅程覆盖入口、进度、取消、替换和刷新。
