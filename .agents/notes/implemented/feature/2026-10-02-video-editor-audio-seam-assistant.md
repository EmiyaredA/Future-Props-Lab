# Agent Note: 视频剪辑工坊相似音频接点辅助

Status: implemented

## Problem

音频素材已有整段波形图片和交叉淡化，但时间线片段不显示实际源区间的波形。剪掉音乐中段后，用户难以找到节奏和音色接近的接入点，也无法在提交前比较与预听。

## Decision

音频 Clip 按源起点、时长和播放速度裁取已有波形图片。选中同轨相邻音频片段后，通过只读候选 API 对同一已就绪音频素材的整段可用源范围做本地分析；候选位置必须容得下 B 的完整源时长。FFmpeg 解码为单声道 PCM，NumPy 提取响度包络、频带能量和频谱变化，以固定相似度阈值过滤静音及明显不相关的区域，再筛选并间隔化前三个候选。候选仅供比较和预听，不写入时间线。

确认后使用单个 `alignAudioSeam` 时间线操作设置 B 的源起点，保持 B 的播放时长，将其移至 A 末端形成交叉淡化，并整体移动同轨后续片段及其关联组。现有 revision CAS、最终文档校验和原子事务负责并发与失败恢复，Web 保存原片段与转场快照供撤销。A/B 本身若仍与画面链接，要求先分离，避免无声的视听失同步。无需数据库迁移或持久分析缓存。

## Alternatives considered

- 只比较波形图片：图片分辨率不足以可靠评估节奏与音色，因此只用于轨道显示。
- 分析完成即自动应用：候选无法保证音乐语义和乐句完整，保留试听与明确提交。
- 每个后续片段单独提交：大工程会超过操作批次上限，也会产生部分提交，因此使用专用原子操作。

## Consequences

- 首次分析需解码源文件，30 分钟以上的素材会明确拒绝；不调用外部服务。
- 首版只针对同源音乐；不同歌曲、语音及循环片段继续使用手动剪辑。
- 提交可能移动关联的后续画面片段；锁轨、负时间或非法视觉重叠使整次操作失败。
