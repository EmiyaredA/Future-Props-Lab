# Agent Note: 桌宠连续动作素材与整帧提取

Status: proposed

## Problem

完整角色图集反复生成相同的领先手脚，逐张修改又带来体型漂移。上一任务已累计大量拒绝候选，局部静态检查没有收成可交付的四边循环。总目标继续见[完整帧提案](../bug-fix/2026-10-04-pet-whole-frame-motion.md)。

## Proposal

不沿拒绝原画继续递归修改。锁定较好早期完整姿势，尝试以连续视频生成完整动作，再提取完整 RGBA 帧；仍只绘制整个人物，不恢复肢体拼接。视频请求通过已配置模型的正式推理 API 和独立 Python SDK 提交，先保存请求意图和唯一 request_id；不自动重提供应商任务。首尾相同画面使用分别上传的输入记录，遵守接口的素材 ID 唯一规则。

临时原图、请求、诊断和导出全部保存在已确认忽略的 `.local/desktop-pet/animation-finish-2026-10-06/`。完整图集按真实人物间隙提取，不能假设生图遵守等分网格。统一画布内只做整幅平移和透明填充；源角色不缩放、不拼贴、不补造动作。

## Alternatives considered

- 继续八格图集与单张相反步相修改：本轮仍重复同侧领先，不能作为完整循环。
- 恢复分件运动：用户明确要求完整角色序列帧。
- 把录像帧率、合法元数据或代码测试作为视觉完成证明：不能证明原画换手换腿、身体尺度或实际支撑。

## Acceptance criteria

生成服务有可用额度且允许所需角色内容；检查连续动作、首尾、完整服饰和透明提取，再按现有契约检查人物尺度、支撑、入口和转角。展示用锚点占位不能用于正式资源。当前三条视频请求均失败，不能安装或声称整套完成。

## Risks

供应商内容限制和额度阻止连续动作生成；本地落地预览尚未通过头部尺度、真实支撑和跨动作验证。不得以占位锚点导入正式桌宠，也不得自动重复提交失败任务。

## Verification

本轮内置生图共返回11幅：重复步相候选拒绝，保留六幅滑翔落地原画预览与三张绿幕输入。右爬和顶部悬挂被视频供应商以输出版权限制拒绝，底部爬行返回使用限制／余额不足，未自动重提。首次任务创建因首尾重复素材ID返回422，确认无任务后按独立输入记录修正；该次未认领输入已通过正式API删除。
