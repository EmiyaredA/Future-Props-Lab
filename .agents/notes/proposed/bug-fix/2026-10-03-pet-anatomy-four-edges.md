# Agent Note: 桌宠人体姿势与四边贴附修复

Status: proposed

## Problem

上一轮关节动作存在人体扭曲：站姿切片旋转与反向颈部补偿不能表达弯腰悬挂，侧头与正面躯干不一致，脚步和服饰接缝不自然。旧数值测试甚至要求大幅翻折，不能代表视觉质量。手动松手清空运动状态，边缘仅左右两种，不能主动贴附四边。

## Proposal

使用对应姿势的新原画、可选独立头部及上段／下段／掌靴刚性分件，保留连续蒙皮兼容路径和受限关节，保留原站姿、表情、坐姿。资源以可选 motionRig v2 登记姿势素材、关节限制、接触区域及面部映射，旧包不冒充四边支持。

单一运动控制器在最终手动放置确认、放下反应结束后重新测量接触平面，近边进入平滑贴附。左右攀爬、顶部悬挂横移、底部低姿爬行、角落转边共享运动帧，步相仅由宿主回执驱动。暂停取消旧轨迹，保存仍用原 CAS，不新增 schema 或公共运动 API。

拎起期间以鼠标抓取点为优先，允许悬挂身体暂时伸出工作区；松手后用已缓存的放下姿态几何进行最终边界确认。宿主可扩展透明窗口，渲染原点固定在初始画布内，避免窗口 resize 改变人物位置。私有回执携带 sceneOffset 补偿 macOS 原生菜单栏位置限制，控制器按宿主确认的实际渲染原点计算位移。

动作五官可映射到已登记的透明素材并使用露出面部的遮挡多边形。独立头与分段引用由后端验证唯一引用、body 父级、有限颈点和互斥引用；通过完整专属校验的 motionRig v2 人物及鲸鱼包最多 128 分件，其他包仍是 80，ZIP 与图像预算不变。鲸鱼六姿势登记固定头发、鳍尾和裙摆层，原生眼球／虹膜／睫毛／眼睑曲线保留，面部以非退化且非镜像的有限 affine 投影，不套用人物七种五官协议。腕踝与掌／鞋底接触点分开登记，连续蒙皮将整个远端素材绑定到接触朝向，支撑开始前为后续行程保留可达空间。

## Alternatives considered

- 继续调旧切片旋转角：素材轮廓和支撑关系仍错误。
- 只验证骨长和传入属性：不能发现实际人物轮廓扭曲。
- 用窗口矩形判定边缘：透明空白和不同姿势使位置错误。

## Acceptance criteria

每轮动作版本录制真实引擎及隔离桌宠正常速度视频，循环至少 10 fps 抽帧，过渡逐帧检查。人体、接缝、支撑、抓取、按钮必须视觉通过，支撑漂移不得超过 1 DIP。候选失败不得更新正式资源。不调用真实聊天模型，保留并行任务工作。

## Risks

新素材仍需通过真实桌宠逐帧验收；仅提供资源描述及数值通过不能证明人体和服饰自然。未经视觉验收不得更新正式资源或重启应用。四边不同姿势的可见范围、接触平面与宿主约束必须一起校验，不能以窗口矩形替代角色边界。

经用户授权使用多 Agent，分别进行真实帧独立审查、步态数值诊断和质量门禁。步态鞋底释放的角度断点曾造成单帧 6.3 DIP／27°跳变，连续末端角已修复。后腿摆动起点由任意横向偏移产生不可达，改用真实 contact−ankle 偏移、零端点导数抬脚和非支撑腿可达裕度；60 fps 不可达 5→0，膝角最大单帧变化 20.56°→8.33°，稳定支撑漂移接近数值零。这些数值不是视觉通过证据。原站姿颈腰与骨长作为统一比例基准，候选原画和校准包只保存在忽略的 `.local/desktop-pet/four-edge-motion/`。

### 双手下垂与完整表面复核

- 用户明确拎腰姿态的双手应向下垂；顶部抓边图不作为拎腰资源。`heldRecovery.ts` 保留新完整原画的静止肩肘腕与膝踝角度，不再强制竖直手臂、固定 18／22 度屈膝或 20 度靴子旋转；只叠加有界拖动惯性，重抓与恢复继续沿用实际同姿势快照。
- 新 `held-v3` 的近侧肩腕约 39 model，双手、手指向下。`held-v4` 虹膜上移约 2.55 model，但头高、腰位及嘴位也改变，不能沿用第 3 版登记，未用它替换资源。原第 3 版正常图／无五官图采用未修改像素，绘制时统一移动五官 3 model；实际眨眼和各表情仍未验收。
- 首次新完整拎腰 GPU 诊断发现不透明衣袖／短裤边界的细白缝。`poseSkin.ts` 为完整 held 的有限惯性保留连接的源表面，肩胯边缘与相邻肢体影响采用渐变及归一化；大幅接触动作继续分区编译，不宣称因此修好行走或攀爬。原画、UV 与骨段长度保持不变。新增真实 rig 顶点测试覆盖 30／60 fps 的连续表面及正面积；最初硬边权重触发面积门槛失败，渐变修正后通过。
- `.local/desktop-pet/four-edge-motion/held-connected-recording-feathered/` 保存新的正常速度 GPU 录像及全部 358 个编码源帧；这是 partial local model 的生产 `humanFigure` 渲染诊断，未通过桌面宿主，也不覆盖放下跨姿态、三服饰或鲸鱼验收。第一个 partitioned 诊断录像被同路径后续录制覆盖，不能宣称保留原始失败录像；`held-partitioned-reproduction/` 明确标记为独立复现，不伪称原片。
