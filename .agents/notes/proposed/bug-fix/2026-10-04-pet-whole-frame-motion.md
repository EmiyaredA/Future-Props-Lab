# Agent Note: 桌宠完整序列与统一人物比例

Status: proposed

## Problem

用户再次明确拒绝不协调的运动拼接，并要求不同动作及序列帧比例一致。旧侧身、正面、拎腰视图分别按图片外框登记会改变头身关系；单独满足骨长或支点数值不代表真实绘制自然。静态登记后的新肘膝素材仍出现衣料截面、袖口和靴口接缝。

## Proposal

依据用户最新指示，新运动改用完整角色序列帧，停止继续用肢体分件制作运动姿势。此前[人体与四边提案](2026-10-03-pet-anatomy-four-edges.md)保留历史及兼容接口；本提案取代其新运动素材制作路径，不改写旧提案。原站姿、坐姿、表情、换装及 CAS 数据继续保留；完整帧尚未具备完整表情变体，不能宣称其动态五官已支持。

可选私有 `frameSequences` namespace 登记固定画布、固定模型框、唯一等比 scale、原始 PNG 图集和局部抓点／足底／头部／支点。所有动作共用这些单位，逐帧头部欧氏标尺限制在参考 ±2%，前后端拒绝独立缩放、非等比布局和实际 PNG 越界，不自动修正原画。描述合法仍需看实际画面，元数据不能证明身体比例、膝盖方向和服饰正确。

纯播放器按实际渲染时钟或宿主确认步相选原帧，跨动作必须提供与实际当前帧、目标首帧一致的完整过渡。缺入口、停止、转向或快速重抓原画时保留已绘帧并反馈失败，不镜像、拉伸、透明叠影或退回被拒绝的旧运动素材。画布适配只做完整原画绘制及全局锚点平移；初次动作先真实绘制 idle，再报告入口进度。加载失败不提交未经校验图集，旧请求失效回调不污染最新选择。几何测量优先读取当前有效画布，缺少可用边姿势不宣称四边支持。

所有服饰共用原图尺寸和时间布局；首套素材走 `tex/`，其余走 `schemes/{id}/tex/`，仍通过原授权素材 API 加载和 existing CAS 替换。无数据库 schema、公共运动 API 或事件扩展。兼容 `restTransform` 静态登记继续保留，但不再用于新运动候选；后端及人物入口拒绝 JSON 内部 mesh，避免合法上传后 GPU 创建失败。

单一控制器的已落地修复继续使用：贴附起始 tick 只发布意图，等待实际入口播放；顶部／底部折返同时更新姿势朝向；休息 7 秒采用计时 epsilon，边缘距离阈值不放宽；旧放置回执等待期间仍允许新的 150 毫秒按住进入悬挂，新取消代次阻止迟到回执重新附着。

## Alternatives considered

- 继续微调分件角与静态 cap：实际 GPU 零姿势仍有肩肘和膝靴断缝，用户要求弃用。
- 生成一张 16 帧 atlas 即视为完整步态：首张重复同一支撑腿，后排越过帧边界，明确拒绝。
- 按每帧外框 fit 相同高度：会让抬手／屈膝后的头身忽大忽小，格式禁止。
- 只用属性与数值测试验收：只能证明传递和统一尺度，不能证明人体自然。

## Acceptance criteria

三服饰和鲸鱼所有动作、四边与转角仍需真实隔离 Electron 30 fps 正常速度录像和逐源帧检查。稳定支点漂移不得超过 1 DIP。每批完整原图检查头身、承重、膝踝、颈肩腰、五官及遮挡；缺失或失败素材不能安装正式包。全部通过后才 CAS 更新及受控重启。浏览器渲染诊断必须标明不是 Electron 或完整步态验收。

## Risks

固定画布只消除播放缩放，不能阻止生成原画重绘眼睛、支撑腿或衣料。新完整帧的表情变体、世界支点和完整过渡仍需实现和验收；本提案不授予失败候选正式发布资格。保留用户与并行任务的未提交改动。

### 完整帧比例实际绘制与最终门禁

最终相关 Web 桌宠 39 文件 542 项、后端桌宠 332 项、桌面私有桥／录制 29 项、架构 48 项通过。全 Web 类型及完整构建、全仓 lint／format、契约与 SDK、LFS 指针／生产／fsck、官方导入包检查及文档保护通过。Notes 的 npm/tsx CLI 最初因沙箱禁止临时 Unix Socket 失败，改用相同校验脚本的 `node --import tsx` 运行，树／格式 159 项及归档封印均通过；第一次新提案缺 Risks 段已补齐，原失败日志保留。不是全仓全部单元或 E2E 验收。

新 `capabilities.ts` 与舞台逐动作判断实际 clip、入口／返回及支撑，不因完整帧字段存在就解禁所有动作；普通 walk/run 与物理方向共用映射，stand 回 idle，未知包不回退旧运动。几何只测当前有效画布，部分接触登记以实际可见轮廓补齐宿主所需四边字段，但不宣称缺失的支撑能力。帧间尺寸、失败图集缓存、旧 decode 代次和隐藏画布误读均有生产入口测试。

真实 Chrome 生产画布的最终比例诊断保存于 `sequence-renderer-checks/run-2026-10-04T05-47-18-373Z/`：144 个实际录像帧、4.767785 秒、30 fps，289 个实际 RAF tick，48 张 10 fps 抽帧。两幅完整原画以相同 1182×1330 画布及 0.19984586693 单一比例绘制，Canvas 不透明像素／alpha 与原 PNG 相同；原图头部细节有重绘，不声称像素锁死。该诊断只是两个已拒绝静图的比例播放，并非完整步态、实际 Electron 或世界支点通过。三次诊断的旧命名／稀疏 tick／源码采集问题已保留 limitation；最终 onLoad 源码 hash 与执行 bundle 独立保存。

passing-v3 降低膝位但失去后折，拒绝；带独立骨架导引的 v4（SHA 0d51c10b695f4888c02cc98c88570baf5adc1b78d82fbe02e093f473792563ae）后折方向改善，膝位与鞋视角及近远遮挡仍错误，拒绝。四张完整 passing 候选都未应用。此批停止重复盲生；完整自然步态、其他姿势／服饰／鲸鱼、动态表情变体和世界支点仍须继续完成，不把固定画布当作全目标完成。源码最终快照与逐项日志在 `quality-sequences/`，没有正式 CAS 更新或 App 重启。
