# Agent Note: 思绪工坊完整功能补齐

Status: proposed

## Problem

知识库缺少超过百条结果的分页入口和刷新后的草稿恢复，画板交互与静态连线不一致。引用、检索、模板、个人阅读状态与整库交付需要贯通内容、历史、素材和权限。

## Proposal

按可靠性、引用检索、内容复用、历史交付四批扩展现有切片。浏览器草稿以账号、Workspace、文档和标签页隔离；业务资源仍由正式 API、SQLite 事务与 CAS 管理。模板是 Workspace 独立快照；个人筛选和阅读记录属于当前账号。新增正文和画板版本保留旧格式读取，备份重映射内容与素材引用。官方正文继续静态只读。

## Alternatives considered

直接接入 Trilium 或 Docmost 会改变现有编辑、权限、部署和存储边界；引入协作或检索服务增加单机维护成本。只补前端不能覆盖 SDK、恢复与备份，因此采用现有栈内扩展。

## Acceptance criteria

分页、断网草稿、跨租户隔离、引用重映射、模板复制原子性、CAS、历史比较、前后端画板几何及离线导出有自动化回归。新迁移先验证临时数据库，不接触正式运行数据。同步官方指南、API/SDK、目录职责和权限登记。
