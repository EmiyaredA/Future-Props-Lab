LiveKit 指标的矩阵落点

LiveKit 原始字段主表指标矩阵位置核验说明
transcription_delay转写延迟（Transcription Delay，TD）听觉理解 × 语音链路层官方 User messages / EOU 字段。
end_of_turn_delay轮次结束判定延迟（End-of-Turn Delay，EOTD）对话交互 × 语音链路层官方 User messages 字段。
end_of_utterance_delay语句结束延迟（End-of-Utterance Delay，EOUD）对话交互 × 语音链路层官方 EOU metrics 字段，并包含 transcription delay。
on_user_turn_completed_delay用户轮次完成回调延迟（On-User-Turn-Completed Delay，OUTCD）对话交互 × Agent 任务层官方 User messages / EOU 字段。
ttft；llm_node_ttft首 Token 延迟（Time to First Token，TTFT）工程运行 × 组件层、语音链路层前者为 LLM metrics，后者只在 STT-LLM-TTS pipeline 中填充。
ttfb；tts_node_ttfb首字节延迟（Time to First Byte，TTFB）工程运行 × 组件层、语音链路层前者为 TTS metrics，后者为流水线 Assistant messages 字段。
playback_latency播放延迟（Playback Latency，PL）对话交互 × 语音链路层官方播放起点观测，不能直接等价于用户听感起点。
e2e_latency端到端延迟（End-to-End Latency，E2E Latency）对话交互 × 语音链路层官方 Measure conversation latency 直接给出。
model_usage模型用量（Model Usage，MU）工程运行 × 组件层官方 Session usage 的累计 provider/model 用量列表。

四、结论与使用边界

结论类型本报告的处理方式
来源直接出现保留原文英文名称、缩写、符号或官方字段，并给出具体章节、附录或字段标题。
部分对应列出来源实际出现的相邻指标或评测环节，说明当前指标增加的本地条件。
本文工程扩展保留飞书主表名称，但不声称英文全称或缩写是论文原生指标；实施时需冻结分母、事件边界和阈值。
未找到同名定义只能说“参考了该来源的能力方向”，不能写成“来源定义了该指标”。
