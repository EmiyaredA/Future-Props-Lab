# Live2D 工坊：原生角色工程

入口为 `/apps/live2d-workshop`。项目页沿用 Studio 暖色主题，完整编辑器使用深色主题；浏览器和桌面窗口共用页面。应用图标统一使用 `web/public/brand/live2d-workshop-mark.png`，来源见 `docs/assets/live2d-workshop-avatar.md`。

## 制作流程

1. 新建角色，导入多张透明 PNG 或 RGB 8 位 PSD。空项目导入 PSD 时采用原画布尺寸，并同步设置头像与舞台相机位；PNG 默认居中。图层名称、分组路径、坐标、顺序、可见性和透明度保存到部件。可处理的栅格遮罩烘焙进 PNG。已有工程重导入 PSD 时按分组路径与图层名匹配；同画布、尺寸和坐标的图层可替换像素，保留部件 ID、网格和绑定。几何变化、重复路径或超限先报告并阻止覆盖。
2. 模型页通过可折叠对象树查看 PSD 分组和变形器父子关系，并编辑部件位置、大小、顺序、透明度和单部件遮罩。图层可临时独显，选中图层可叠加透明轮廓检查。画布支持平移、缩放、适配和定位选中对象；新导入的透明 PNG 按有绘画像素的网格单元生成网格，已有图层可主动重建；顶点可拖动或用方向键移动，双击添加点。拓扑重建清除当前部件的蒙皮与参数绑定前需要确认，撤销可恢复。
3. 创建旋转或曲面变形器、父子骨骼与逐顶点蒙皮；父级选择会拒绝循环挂载。绑定页支持骨骼权重热图、画笔与逐顶点数值；画笔保持每顶点最多四根、权重归一化。骨骼静态试调只改变画布预览，不写入工程或动画。参数及真实数值明确标注最小、默认、最大和中间关键形。编辑网格、格点或旋转/缩放只改变当前参数关键形，基础位置等字段回到模型页修改。新增关键形从当前参数的插值形态初始化，求值时其他参数保持默认，避免把当前预览中的复合效果写入该参数。
4. 动画页保存表情参数预设，创建动作轨道并记录时间关键帧。可拖动、复制、删除关键帧并调整值、插值及循环范围。先应用表情值，再由动作的同名轨道覆盖；无轨道的参数保留表情值。可设置 Cubism 参数 ID 映射，导入/导出参数级 `.motion3.json` 与 `.exp3.json`，并为 Amadeus 七种执行状态绑定原生动作和表情。导入预检显示缺失参数、超范围数据与近似采样；模型和部件轨道拒绝导入。删除预设会清除相关状态引用。
5. 保存后可导出 `.fpllive2d` 工程继续编辑，或选择表情与动作组合导出透明 PNG 序列 ZIP。每组独立目录，并附 `manifest.json`。导出页从后端读取所选表情、动作和帧的实际预览，可选择完整画布、居中方形或可拖动/缩放的自定义裁切。输出尺寸默认锁定裁切宽高比，也可显式解锁；默认帧范围跟随动作时长，并显示每个组合及预计帧数。另可导出 Cubism 素材交接 ZIP，含 RGB 8 位分层 PSD、逐层 PNG 和可映射的参数动画 JSON；Cubism Editor 中仍需重新建网格、参数并生成 `.moc3`。

侧面板支持拖动调整宽度和顶栏按钮收起。编辑器支持撤销/重做、保存快捷键及未保存离开保护；CAS 冲突保留本地修改，支持先下载本地文档备份再重新读取。编辑中的引用和素材不会被自动覆盖。

## 格式与求值

原生文档 `schemaVersion: 3` 包含画布、部件、三角网格/UV、变形器、骨骼/蒙皮、头像与舞台相机位、待机映射、参数绑定、表情、动作、`stateBindings` 和 `cubismParameterIds`，独立于数据库 `revision`。v1/v2 数据在读取时适配为 v3，下次正常保存写回 v3；旧 `.fpllive2d` 仍可导入，新导出包清单版本为 3。数据库无需迁移。旋转围绕枢轴；曲面使用规则格点分片双线性插值。每个参数按关键形值分段线性插值，并减去该参数默认值处的形态，再增量叠加到目标默认形态。完成参数叠加后，从子到父依次应用变形器或骨骼蒙皮。前后端共享 `tests/fixtures/live2d-evaluation.json` 验证数值。

## 红莉栖分层与绑定验收草案

`scripts/build_amadeus_rig_draft.py` 根据已选定原画、去表情底画和补绘的遮挡底画，在 `.local/output/live2d-rig-review/` 输出逐层透明 PNG、RGB 分层 PSD、无正式动作的 v3 工程包，以及中性、闭眼、头部侧倾和身体/手臂试姿态的头像 48px、76px 与半身舞台图。`scripts/check_amadeus_rig_draft.py` 检查包解析、骨骼权重、素材引用与中性像素还原。草案可以通过现有工程导入接口创建可编辑项目；本阶段不替换随应用提供的内置只读案例或 Amadeus 运行头像。用户检查图层和关节效果后，才制作七种状态动画并替换运行工程。

当前草案的头部侧倾预览在领口和长发交界仍有细碎接缝；这属于绑定审阅尚未通过的可见问题，不能据此把草案升级为内置运行模型。半身相机位取景至原画腰部边界之前，以免骨骼试调时露出原始画布裁断处。

`.fpllive2d` 为 ZIP，包含格式/版本清单、文档、所引用 PNG 和缩略图；导入重新分配素材 ID，保留部件、绑定及动画。拒绝目录穿越、绝对路径、符号链接、重复条目、额外文件、未知版本和缺失素材。限制解压后总大小 256 MiB。

PSD 解析在 Worker 内运行，限制 128 MiB、4096 边长、128 图层及 6400 万解码像素。PSB、非 RGB8、调整/文字/智能对象图层、图层效果、矢量遮罩、剪贴及非普通混合模式均停止导入并报告。分组遮罩、分组透明度和带羽化/密度/相对坐标的遮罩要求先栅格化，避免静默改变画面。

## 持久化与 API

业务归 `backend/app/apps/live2d_workshop/`，纯文档/参数与 Pillow 渲染归 `capabilities/media_rendering/live2d/`，Web 归 `features/live2d-workshop/`。迁移 `r0071_live2d_workshop` 新增项目、素材和导出任务表，根资源直接记录 Workspace。运行文件在对应 Workspace 的 `applications/live2d-workshop/projects/<id>/{assets,exports}/`，使用既有项目文件事务。

`/v1/live2d-workshop` 的项目、文档、素材、工程包、预览、预检和任务操作全部登记 `content.read`/`content.write` 权限。新增清理不再被当前文档引用的素材的 DELETE 操作，必须携带 `expectedRevision`；仍被引用的素材拒绝删除。清理在同一事务内递增项目 revision 并返回最新项目快照，避免并发保存重新引用已删除素材。公共类型由 OpenAPI 生成，Python SDK 通过 `client.live2d_workshop` 访问。写入与删除携带 `expectedRevision`，冲突返回 409 及当前快照；外空间 ID 返回 404。预览、预检和导出都绑定明确的已保存 revision；存在未保存编辑时前端停止发起，后端对 revision 漂移返回冲突。桌面 Agent 白名单没有自动放开新增业务操作。

导出任务固定创建时已保存文档，并在任务结果中记录 revision、表情/动作组合、尺寸、帧率、帧范围和裁切设置；同一 requestId 参数相同返回原任务，不同参数拒绝。前端只轮询活动任务，失败时展示服务端原因。渲染逐帧检查取消，完成前再次原子检查取消状态；取消后不会发布 ZIP。应用中断后的 running 任务变为 failed，不自动重新执行。删除操作先取消活动导出再删除；服务端拒绝删除仍有活动任务的项目。

## 范围与验证

本版不是 Cubism 编译器，不提供 CMO3、MOC3、视频、物理模拟、贴图集、复杂混合、多参数联合修正或外部实时输入。Cubism 交接只覆盖素材与参数动画文件，不接入 SDK/Core。制作用完整画布，方形仅为输出裁切。受支持 PSD 的最终外观仍需用户预览确认。

- `tests/test_live2d_workshop.py`：几何与透明边缘、非法引用/拓扑、临时迁移、项目 CAS、素材隔离、工程包往返、分组序列、任务取消和中断恢复。
- `tests/test_live2d_permissions.py`：真实会话权限与跨 Workspace 隔离。
- `web/tests/live2d-model.test.ts`：共享数值夹具、表达式/动作优先级、网格与嵌套变形。
- `web/e2e/live2d-workshop.spec.ts`：真实浏览器 PNG/PSD 导入、层级树、关键形和时间线、保存重开、裁切预览、PNG 下载、错误报告、窄窗口与画布像素检查；冷缓存首次载入 PSD Worker 也不会触发中途整页重载。

自动化只使用临时数据库和确定性素材，不调用真实供应商、不迁移正式桌面数据。
