# 能力实现契约

## 表格工坊

表格工坊通过独立 `spreadsheet` 服务保存版本化工作簿，账号来自 Identity 签名上下文，所有读写和原件下载执行账号隔离。快照更新与批量单元格操作共用 CAS 和事务回执；导入原件先安全落盘再提交引用，未知提交保留文件供恢复核对。公式计算在浏览器进行，自动化写入后的缓存显式标为待算。限制、转换支持范围和独立发布要求见[表格工坊工程说明](../reference/spreadsheet-workshop.md)。

修改下列能力时，先定位所属应用及装配，再查对应条款。跨应用规则见[Studio 框架契约](studio-framework.md)，代码位置见[项目目录索引](project-layout.md)。

## 编辑器导航

独立入口的工坊内切页使用共享 History 控制器，编辑器通过导航 Guard 或显式状态端口声明离开条件。
保存中、批处理和导出尚未结束时不得绕过现有保护；错误与冲突保留当前草稿，放弃须由用户确认。
导演台的命令式编辑器只向 React 壳报告 dirty/busy 状态，不拥有浏览器路由。项目 ID 改变时重新挂载项目编辑器。

## 音频标注

- 音频标注文档编辑由 `EditDocument` 执行版本判断与纯转换，`DocumentEdits` 在一个事务内提交
  CAS 与回执；并发失败复查原请求回执，取消回滚。HTTP 层只映射领域错误。
- 音频标注创建与导入由 `CreateProject` 共用用例执行，时长、说话人和片段转换规则归 `rules/`。
  创建输入端口只借出已授权描述和转录快照，路径与媒体探测留在适配器；`storage/projects.py`
  原子提交项目、文档、波形及引用投递，借用范围覆盖提交结果，未知提交不得自动重建项目。
- 音频标注删除用例只删除指定版本的任务及引用，保留源音频；存储在写入时再次执行 CAS。
  已保存片段导出与识别通过 `SavedAudio` 的快照、裁切、识别端口执行，业务不访问存储私有属性。
  媒体适配器在 I/O 前释放读取事务并负责临时文件；识别结果只返回候选，不代替编辑 CAS。
- 兼容网站的音频跨表来源装配归 `assembly/website/annotation_sources.py` 与 `annotation_imports.py`。
  转录私有原件先校验、探测及暂存字节，再将素材与标注加入同一短事务；取消须等复制停止后清理。
  提交确认丢失时按持久素材记录核对，不能把已提交文件当作失败副本删除。
- `TranscribeSegment` 统一裁决音频项目归属与可识别范围，范围存储返回脱离 ORM 的快照并释放事务。
  网站与独立执行器只负责模型调用适配；网站跨表连接归装配，Models 的转录解密器必须显式注入。

## Amadeus

- CLI 的持久会话文件与每轮临时工作区分离。两种执行入口通过同一 Host 适配执行系统沙箱，
  不支持沙箱时拒绝运行。生成脚本只能读写本轮工作区，运行依赖只读开放，不能获得模型认证或后端凭据。
  任务 SDK/CLI 只连接运行绑定 socket，由原有业务工具复核权限并提出写入审批，不能绕开 Plan 限制。
  临时目录只保存可清理内容；产物需显式保存到会话，独立工具运行环境归正式运行根目录。

- Codex 原生生图由 Amadeus 每轮快照显式开启，默认开启，Plan 与账号写权限在两套执行入口复核。
  原生图片项通过独立原件交付端口保存到账号会话 `outputs`；完成事件只能由原件保存用例产生。
  原件不可变、同一运行与图片项的交付幂等，上传确认丢失先读取回执，不重新生图。
  会话消息保留文件引用，运行事件维护图片与文字的顺序，纯图片回复和重启恢复遵守同一规则。

- 独立 CLI 工具只消费运行快照及记录、文件、目录和操作端口。运行账号在装配时绑定；提案与暂停同一事务提交。
  操作目录由当前装配提供，独立服务读取已安装契约，源码运行时使用生成契约，兼容网站使用本实例的 OpenAPI。
- 兼容网站先校验账号、权限、批准摘要和运行状态，再以 CAS 领取动作。执行效果在领取事务结束后运行，
  独立短事务结算。取消和关闭等待已开始的状态提交；网站脚本停止记为取消，无法确认的其他执行记为结果未知。
- 前端会话模块唯一接纳会话及历史快照。附件和审批异步结果按账号和选择版本校验，运行模块按账号持有活动运行，
  只有当前会话接纳对应的运行快照。退出时取消读取和轮询，服务端已接受的写入通过持久回执核对。
- 草稿和已发送消息的图片、视频通过当前会话的鉴权文件路径读取。接近可视区或主动打开预览时读取，缩略图与弹窗
  共用临时 Blob URL。移除草稿附件或切换会话时释放 URL。消息仅持久化文件引用。
- 会话附件通过运行绑定的 `read_file` 工具读取。Codex 将本轮显式引用的图片随首个请求发送，其他 Agent 通过
  同一工具按需读取。图片工具限制解码尺寸与返回体积，在内存中缩放大图，保留导入原件。
- 运行中补充以请求 ID、内容摘要和会话 revision 原子保存消息及指令。执行端先领取一次投递，再回传绑定运行、
  租约与正文摘要的回执。Codex/Pi 原生追加；Claude、OpenCode、Harness 在原 CLI 会话确认中断后续接。
  停止、暂停和恢复将未投递指令标为未送达、未确认投递标为未知，不自动重发；未知和未送达消息不进入后续运行提示。
  补充的文件和项目引用重新校验，不改变当前运行的模式、能力、权限或审批。

## 文件与项目工坊

- 文件格式表归 `studio/contracts/asset_library/file_types.py`；字节检测、完整文件校验、SVG
  安全规范化、摘要及归档编解码归 `studio/runtime/files/`。目录暂存机制不决定应用布局，
  `runtime/database/project_files.py` 通过创建／删除布局接口执行原有事务补偿。
  导演台使用自有 `storage/file_paths.py`，两套装配显式提供存储，不继承素材库布局或读取全局配置。

- 演示工坊的项目、模板、编辑回执和导入使用当前装配提供的账号范围项目适配。素材读取、留存
  与导入显式注入，Session 仅持有账号与事务上下文。两套入口保留各自的素材交付和事务边界。
- 特效制作的 HTTP 装配与网站渲染 Runner 显式构造账号范围的项目适配。素材元数据与文件布局
  端口由两套装配提供，导出、快照和编辑共享其账号与事务上下文。
- 视频剪辑的项目布局和时间轴素材端口由装配按账号与操作显式传入。网站助手和特效交接也使用
  装配绑定的端口，布局变更、片段任务和编辑回执沿用原有事务及恢复规则。字幕导入与素材批量插入共用时间线编辑队列；
  文件解析晚于取消或项目切换时丢弃结果。

- 视频剪辑手动预渲染冻结已保存时间线及素材摘要，固定生成保持项目帧率的 720p 合成预览。
  缓存绑定账号、项目、revision、素材摘要与渲染器版本，不登记为用户素材或普通成片。
  播放入口只在开始播放时选择有效缓存，并关闭逐层画面与音频；缓存播放器驱动时间轴，缓冲时播放头等待。
  未保存编辑立即停用缓存，暂停编辑仍使用原预览与精确帧；加载失败在当前位置恢复实时预览。
  清理和替换先持久标记任务退役，再由所属执行器回收文件；独立服务的 dispatch 在源项目删除后保留清理回执。
  私人缓存媒体读取重新验证账号、项目与快照身份，支持 HTTP Range；后台执行及发布前复核账号授权。

- 视频剪辑书页翻页 `page-curl` 在接缝和片段头尾复用方向、时长与缓动，仅接受左右方向。
  浏览器和后端使用相同归一化卷曲、纸背、投影及透明度规则；接缝仅重排所属轨道的前后片段。
  精确停帧、预渲染和导出复用后端帧求值，合成配方变化同步提升相关缓存版本。

- 视频成片编码仅保留当前画面及接缝两侧需要的片段解码器和图片缓存；每帧打开新源前回收已结束的源，
  并固定 FFmpeg 编解码及滤镜线程上限。解码、编码及音频合成的异常退出不得被静默保持帧掩盖。
  失败回执提供阶段、可采取的恢复动作及任务编号，系统强制终止提示可能内存不足；底层诊断只记入服务日志，
  不向用户返回源路径、上游正文或凭据。取消继续等待子进程退出并关闭管道后清理暂存。

- Story 总校验保持纯函数分层：身份/角色、素材、国际化、时间轴、流程与表现层规则归属
  `apps/galgame_workshop/schemas/story_validation.py`；Pydantic Story 入口只负责迁移适配和统一调用。

- 视频时间线操作的回执记录请求输入与提交 revision；相同请求不重复写入，并返回当前时间线快照。
  后续编辑可能使响应 revision 高于原操作 revision。相同请求 ID 更改输入沿用既有错误响应。
  客户端遇到确认超时先核对持久状态，不把返回快照误认为原操作的历史文档。
- 音频、故事与画布编辑继续返回相同请求原来的结果；纯 revision 命令机制不合并不同重试语义。

## Models 与视觉工坊

- Visual 画布与看板通过同一持久化命令选择服务器或本地冲突版本；恢复先处理旧保存队列，再统一更新 revision、草稿、元数据、错误及历史。展示组件不得直接写持久化 ref。剧本和设定卡用例只接收账号范围存储与具名素材描述端口，SQL、CAS 和回执提交归存储适配。
- 画布轮询快照与保存回包共享单调的版本裁决；旧回包不得替换较新的冲突快照，也不得将未解决冲突显示为已保存。存在冲突时保留本地草稿，服务器或本地恢复均使用最新已知版本。
- Visual 的参考输入规则由 Models 发布能力描述；供应商判断只在 Models 适配边界发生。选择元数据的参考能力不进入冻结任务计划，保留既有计划摘要、准备/激活/中止决议及重启恢复语义。

- 模型目录的凭据读写、诊断、默认项冲突快照及演示安装使用装配提供的 `CatalogCipher`。
  凭据能力不得回退到旧全局帮助函数。解密与密钥提示统一通过注入的 `studio/runtime/secrets.py` 实例处理。

- 视觉验收、Galgame 转录与思绪写作显式注入解密能力；构造器不接收整个
  应用状态容器。网站思绪写作的跨库连接归 `assembly/website/thought_writing.py`，业务只消费写作端口。
- 文本推理、模型测试 SSE 与实时语音 WS 的解密器由 HTTP/WS 装配显式传入；语音来源校验
  使用当前应用的 CORS 配置。实时语音父包保持轻量，调用方导入具体目录或会话组件。

- 生成 Driver、转录 Runner 和工坊模型适配显式接收解密器；Models Runner 必须接收配置，
  不允许默认全局配置回退。

- Models 的视觉生成提交、执行、结果读取与清理各自接收会话、文件、授权及传输依赖，
  不持有应用状态容器或借用另一组件的生命周期。文件布局归 `storage/visual_generation_files.py`，
  批次身份和摘要读取归 `storage/visual_generation_batches.py`；结果读取不依赖 Runner 实例。
- 生成结果下载逐跳验证无凭证的 HTTPS 公网地址，并固定连接到已验证 IP，保留原 Host、TLS SNI 与证书校验。
  系统 DNS 返回代理虚拟地址段时，仅对非本地域名通过固定公网 HTTPS DNS 端点核验真实 A/AAAA；
  私网、回环、链路本地、混合私网答案及无法核验的解析继续拒绝。此恢复不重新提交供应商任务。
- Models 的独立目录和推理 Runner 显式接收原生就绪端口，独立结果删除要求清理端口已装配。
  兼容网站沿用本机就绪校验。Session 不承担原生能力选择。
- Models 全包禁止读取进程全局配置；测试台、转录与独立推理的文件根目录和上传策略必须显式传入。
  HTTP 适配从当前应用装配获取配置，推理文件布局由 `InferenceStorage` 实例持有；不提供默认根目录函数。
- 视觉工坊全包禁止读取进程全局配置；网站生成与验收使用当前应用注入的配置和素材存储。独立视觉服务继续通过跨服务端口取得能力。
- 视频草稿按素材或连线身份保存追踪对象及参考图片顺序。生成时由 Visual 在输出解析后组装英文目标串，Models 仍只消费既有工作流参数。固定版本与跟随最终输出共用解析规则；浏览器不得在连线尚未解析时清空已保存的顺序或提示词别名。
- 视频提示词通过展示适配器自动识别或手选模板，首期支持 MiniMax H3 基础三段和全参考六段格式，字段标题兼容独立行与冒号形式，镜头标签保留括号内时间注释；普通文本或未识别内容保留原文编辑。模板下拉仅选择自动识别或具体渲染模板，普通文本／渲染展示由工具栏独立开关切换，切换及版本更新保留当前模板与显示方式。模板与显示方式仅为当前编辑器会话状态，适配器前端支持直接编辑和按模板粘贴重渲染，查看和复制不写入草稿；显式 `@` 插入通过原文偏移保存规范引用，保存与生成仍使用当前版本原文。渲染省略已识别的首尾帧对齐前言和主描述标题，未识别文本仍按原顺序展示；非对白多余空白行仅在预览收拢，原文编辑、复制、保存和生成保留全部内容。图片、视频和音频标签按调用方提供的实际输入槽位匹配，未加载或失效槽位不顺移；主体只显示类型和编号，不提取名称、不绑定代表图片或视频；定义保留原文。只有明确协议标记参与标签展示，任务类型与保留关系保留原值，普通句子不推断成运镜、画面文字或说话人，也不从视频推断音轨。正文删除和部分替换保留隐藏字段、必要换行与对白包装，全选仍可替换整篇。对白／歌词保留原字句，任务类型、参考保留关系、说话人、语言、时间、运镜和转场／截断标记提供安全样式；版本选择及管理、模板和显示切换／说明／复制操作合并为单行，窄区域省略版本名并使用带无障碍标签的图标操作，极窄区域使用局部横向滚动。
- Amadeus 持有对话和操作审批；视觉工坊提供项目上下文、元素引用及提交前保存，并以画布 CAS 应用批量操作。旧 Visual 审批来源只用于验证既有生成任务成果发布。
- 白模场景归视觉项目，使用独立 revision 和场景格式版本。场景引用内置素材或已核验的项目 GLB，使用受认证的素材 ID 读取 GLB。随项目快照复制时重映射文件引用，项目删除时清理。兼容网站与独立视觉服务共用账号隔离和 CAS 契约。
- 分集剧本和通用设定卡各自保存 revision。设定卡归账号，剧本来源记录项目、场次 ID 和所用版本。候选生成在选定项目的生成任务提交事务内绑定通用卡和请求回执。采用图与父卡图独立记录，项目页引用时通过素材库验证并加入本项目。新项目快照仅保存项目内容，导入旧快照可恢复其中保存的设定卡。
- 设定卡候选区展示当前采用图、已保存候选及已完成候选任务结果，当前选择标记为“已选中”，只读入口同样可见。更换选择不移除原图、不重排已有候选，仍由用户显式保存；载入服务器版本恢复服务端集合。服务端在账号范围的 CAS 保存上下文将被替换或清空的旧采用图保留为候选，并保留其素材项目归属；保留后超过 80 张时拒绝本次写入，不截断图片。项目素材入库后的已知 ID 映射同步到候选，任务原件与入库副本仅在文件内容身份服务明确核验一致后合并展示。
- 角色卡通过可空的 `voice_asset_id` 引用账号可访问的音频，保存时校验媒体类型并维护素材项目归属。新建变体省略语音时复制父卡当前语音，显式空值保持无绑定；父卡以后更换语音不覆盖已有变体。编辑与只读入口均可试听及重试，解除绑定不删除共享文件。设定卡仅保留确认的 `design`，`facts`、`proposed_design` 不再属于公开契约；登记迁移清除历史值并推进受影响卡片 revision，旧快照导入时丢弃两字段。
- 设定卡归组是独立的账号级 CAS 操作，保留卡片 ID、采用图、候选和来源。主卡与全部所选变体须同类且有效，修改带子卡的卡片须显式提供全部子卡，归组后扁平挂在无父卡的主卡下。看板固定提供人设、场景、道具三类入口，已关联旧节点通过卡片访问来源，原有输出和连线继续保留。
- 设定组的全部关联图片总览按主卡和变体展示采用图、已保存候选图及已完成候选任务结果；单卡按素材 ID 去重，组总数也按素材 ID 去重，跨卡关联仍分别展示。总览不受列表搜索词限制，归档范围沿用显示已归档开关；父图不重复计入变体。候选任务只在总览打开时读取及轮询，未读取结果的数量以加号提示；关闭停止轮询并取消无其他观察者的请求。预览、重试及进入卡片详情均不写入图片绑定，只读入口同样可查看。
- 工作台项目资源通过文件、分镜、人设、场景、道具纵向入口切换，同一时刻只展示一类列表。三个工作区统一使用56px顶栏、56px导航栏和280px列表；视口至少1024px时默认展开并固定列表，通过布局占位让出编辑区。固定列表只通过显式关闭收起，取消固定后支持点击外部或Escape关闭；窄屏默认收起并覆盖展开，临时展开不改变桌面偏好。刷新或进入新项目恢复默认固定。搜索按视图分别保留，导航数量来自未筛选的项目节点或项目引用的设定卡，不包含其他项目的卡片。页签切换不修改节点选择、持久化数据或任务状态，旧分类素材继续在文件页可访问。
- 预演回填复用项目节点上传。每个文件携带来源场景、来源 revision、可选镜号和内容摘要。每个文件单独确认和重试，回执按账号和项目作用域保存。删除或复制场景后，已交付素材仍保留原始来源版本。

- 模型模板同步、运行额度和演示配置属于 `studio/apps/model_service/`；兼容网站按已登记设置键
  读写原表，不转移存储归属。演示执行组件不依赖账号治理或模型目录，由装配注入配置读取。

- 独立模型任务归 `studio/apps/model_service/inference/`。备份要求见[生产部署](../operations/production-deployment.md)，
  供应商提交中断的处理见[共享执行与文件机制](studio-framework.md#共享执行与文件机制)。

- 项目的一级工作区为工作台、剧本、白模预演，固定顶栏入口等宽同位。画布／看板仅属于工作台内部展示方式，切换位于统一顶栏，窄屏从顶栏更多菜单访问；内容区不重复占位。分镜选择保留该方式并定位或编辑关联制作节点。工作区切换委托当前编辑器保存／离开规则，失败保留草稿；项目内保留选择、搜索和滚动状态，隐藏的白模释放渲染宿主。侧栏使用紧凑标题和32px操作行，分镜统一为紧凑缩略列表，不提供卡片／表格显示切换；条目保留内容高度并在列表内滚动。节点检查器直接编辑生成设置，不再提供素材、分类整理或自动验收页签。人工 `approved` 标记与输出版本契约保留。
- 剧本按“集 → 分镜”组织，集目录的展开集合与当前编辑集／分镜独立；跨集新建分镜显式指定目标集，目录筛选不修改业务文档。展开与搜索只在当前项目工作区会话保留。
- 剧本目录每集、每个分镜右侧提供删除按钮，只读时隐藏、保存时禁用；项目确认弹窗说明整集删除包含全部分镜。确认仅更新当前剧本草稿，沿用 revision 保存、失败重试和离开保护，不删除关联分镜或素材。删除当前条目后选择邻近条目，最后一个分镜或一集允许为空。预演场景删除同样使用项目确认弹窗，失败在弹窗内保留重试入口，执行中防止重复提交。
- 剧本新建分镜预填可编辑的场景信息、景别、运镜、时长、动作、对白和声音示例，只写入新分镜草稿，不回填已有分镜；修改、清空、保存失败与离开保护沿用剧本原规则。新建集仍由用户显式添加分镜。
- 剧本关联分镜面板使用紧凑选段操作与整行镜头入口；镜头摘要限制两行，点击仍经过当前剧本保存保护。无当前场次时不显示无来源镜头为关联结果。
- 白模宿主将应用主题映射到内嵌控件及弹层。深灰背景、地面和天空隐藏仅在编辑帧渲染时临时使用，异常时同样恢复；机位预览、采用和导出保留场景原有材质、背景与灯光。主题切换不写入场景 revision。
- 从剧本创建预演先经过原场景的保存保护，桌面以侧边面板显示，候选预览与原场景共用可见视口区域；取消恢复原场景，失败保留输入，成功打开新场景。隐藏工作区释放渲染宿主，窄屏保留创建草稿并限制创建。
- 预演场景标题旁的“添加”菜单统一提供新建空白场景与从剧本创建；场景列表只展示已有场景。两种创建方式均保留保存保护与只读／窄屏限制，取消剧本创建后焦点回到添加按钮。
- 剧本预演面板集中展示解析状态、角色／道具／对白／镜头统计和可折叠明细；解析与试排不自动创建场景。场景名称、绑定及采用控件收进场景侧栏设置，仍由原编辑器持有草稿、保存和离开保护。桌面顶栏更多菜单不重复项目标题与主题入口，窄屏保留对应操作。
- 画布与看板共用参考素材上传格，主操作直接打开对应图片、视频或音频文件选择；项目、文件库、设定卡来源保留次级入口。入口遵循模型支持范围、引用数量、只读与上传中状态，取消不写入，失败保留草稿并允许重试；上传不自动提交生成任务。全能参考区按图片、视频、音频排列，每类素材末尾各保留一个对应类型上传格，已有不兼容引用保持可修复。
- 生成参考区只选择当前项目文件、分镜已有媒体输出和已收录的设定卡；公共库与其他项目先经项目素材管理显式导入或收录，参考区不直接提供外部来源入口。选择器、拖拽、画布新关联和生成前均检查项目范围，分类标签仅消费当前项目卡。历史未收录或失效关联保留并提示修复，允许保存其他草稿，修复前不能生成。
- 参考区点击或拖入新图片先选择人设／场景／道具分类与名称，取消不上传；批量逐图分类并可应用到全部。图片上传后由项目登记操作在短事务内完成独立主卡创建、采用图与项目收录，并使用项目保存队列串行处理 revision。登记按核验的内容身份复用当前项目同类卡，多个匹配须明确选择，不覆盖采用图或自动生成变体；账号其他卡不自动收录。现有 Visual 操作回执同时支持请求重放和并发内容登记，不依赖新的持久表。视频、音频只收录到项目文件。
- 全能参考按媒体类型分流，图片及首尾帧入口保留自身类型限制。逐项检查重复、数量、只读与自身引用，部分上传或登记失败保留成功项与已上传文件，提供沿用请求身份的重试；切换镜头或离开后不将迟到结果绑定给新镜头。缩略图右上角移除按钮在悬停或键盘聚焦时显示，复用详情菜单流程，必要时解除当前输入连线，不删除来源文件或设定卡。
- 素材缩略图右上角的角色、场景、道具标签只读取显式设定卡引用、素材 ID 精确匹配的项目节点设定绑定、已解析连线源的设定卡绑定或素材 ID 精确匹配的采用图。手动选入素材同样读取项目节点绑定，不要求存在输入连线。显式关联优先，不按文件名、提示词、图像内容或编号推断；关联缺失、不可读或跨类型冲突时不显示分类。三类使用不同底色和相同尺寸，避让左上编号及移除操作；展示不改写引用、设定卡或生成参数。
- 视频文生、图生、首尾帧与全能参考共用紧凑参考工具栏的尺寸与内边距；模式、引用、版本和提示词显示控件使用一致的32px高度、12px字号及圆角。素材格保持64px，类型／首尾帧标签位于格子下方；非全能模式的任务输出和既有上下文从工具栏“引用”菜单访问，不单独占用内容行，不改变原有绑定和保存规则。
- 图像生成工作台以参考图片、提示词及参数栏组成单一编辑区，不显示独立的输入素材／引用任务输出行。原有上游连线继续参与输入解析，连线编辑保留在画布；文本节点沿用输入引用编辑。生成区内部左右留 12px、参数栏下留 8px，参考图与提示词、参数栏之间采用紧凑间距。
- 支持全能参考的模型在无既有引用的文生视频状态也展示对应上传格；成功新增素材时才将模式与引用一起保存为全能参考。打开或取消文件选择不切换模式，纯文生模型不展示其不支持的输入。
- `storyboard/` 独立持久化项目镜头文档和 revision；写入以 `expected_revision` 执行短事务 CAS，并验证新增制作节点、剧本场次与项目设定卡关联。已删除资源的既有引用保持可修复；剧本变更不自动覆写镜头设计。镜头卡仅引用制作节点，输出版本由原节点维护。新建制作节点先准备参考图和提示词草稿，再保存画布及分镜关联，不自动提交生成任务。
- 分镜的制作对象为“镜头视频”，工作区固定编辑 `video_node_id` 对应的视频生成节点，不提供图像／视频切换。纳入与关联仅接受当前项目的视频节点，避免将同一视频重复分配给不同分镜；新建分镜和剧本选段新建镜头准备独立视频节点，不自动提交生成任务。画布选择、缩略预览、输出历史和白模参考回填均以视频关联为准；仅有图片的旧镜头保留原图片字段，补建视频时将其已有图片输出作为生成参考，不改写已有视频草稿。生成时长仍由视频模型参数约束，规划时长独立保留。
- 镜头属性保留名称、分镜描述与来源剧本，移除独立的关联设定区块及其选择弹窗；生成参考素材在生成编辑器管理。景别、运镜、规划时长、对白、声音的独立表单及重复视频预览同样不展示；已有字段和设定关联随原镜头快照保留，旧关联仍可用于首次创建制作节点时准备参考图。白模关联按项目选择场景并记录 revision，仅展示该场景版本已发布的真实图像／视频输出，查看输出和打开预演经过当前分镜保存保护。更换场景显式重置该镜头的旧机位覆盖，保持其他字段和生成草稿。
- 未关联有效镜头视频时，镜头设计表单显示在制作区，右侧只保留一个制作／关联入口；画布中的未关联镜头面板沿用同一内容，缺失或类型不符的关联也允许修复。关联视频后恢复生成编辑器与输出详情页签，不重复渲染表单或创建操作。只读入口仅展示镜头内容，创建失败与关联保存失败沿用原有草稿恢复规则。剧本选段创建失败后重用已准备的镜头与视频标识，避免重试重复创建。
- 分镜随项目快照和独立历史迁移转移。便携快照重映射制作节点并保留来源剧本版本；账号设定库关联在导入时解除并返回明确提示，目标账号重新选择。自动验收不再列入公开 OpenAPI、SDK 或自动化目录；旧网站接口返回 410，独立网关拒绝为已移除操作签发新授权。两种装配不启动验收执行器；启动恢复只在原账号范围取消未完成检查，保留历史记录及证据。

## 项目列表自动预览

- 具备项目列表的工坊自动展示真实内容，不调用生图模型。视觉从仍存在节点的当前采用输出选图；剪辑、特效、Galgame 复用真实合成帧；导演台复用保存场景的生产渲染；演示保留第一页预览；思绪使用手动封面或最近文档图片／摘要；表格仅投影最多六行五列保存值；音频仅展示已有波形与转写。
- 预览描述与源内容版本关联，不写业务数据或推进 revision、更新时间。所属应用校验账号并选择来源，通用展示不读取其他应用存储。媒体接近视口才加载，普通读取最多四路、复杂渲染单路，离开取消并释放资源。会话缓存按账号、工坊、项目及版本区分，退出账号清理；旧项目无需回填或重新保存。

## 集成中心、创作工坊、工具导航与面试

### 剧本、分镜与白模关联

点击剧本目录集名进入整集视图，按本集剧本顺序展示分镜块与明确关联的制作缩略图。拖动手柄或上下移动只更新本集分镜数组，沿用剧本 revision 保存、失败重试和离开保护；不改写制作文档的镜头顺序。块内可打开单镜正文或经保存保护进入对应制作，只读入口隐藏排序控件。正文按原样保存，不提供按镜头标题自动拆分或整理控件；现有项目的拆分与内容清理由用户授权后直接通过应用完成。

分镜制作区直接编辑既有制作节点的实际提示词、输入素材和输出版本。设定关联不自动成为生成输入，剧本修改也不自动覆写制作草稿。来源选段保存原文、UTF-16 起止偏移和剧本修订号；定位优先核对范围，其次查找唯一相同原文，失效时保留摘录并由用户核对。

项目 `creation-links` 用 CAS 将场景卡绑定到本项目 3D 舞台，并将角色/道具卡绑定到稳定对象 ID；账号设定卡本体不保存项目舞台关系。逐镜 `previs` 仅保存机位、走位、动作覆盖与舞台版本，修改结构/素材需进入共享舞台。新关联校验账号、项目和资源类型，既有失效关联保留供修复。

预演帧/片段先预览，再新增或按原位置替换当前制作节点的同媒体输入；复用导出请求凭据、摘要和上传节点 ID，失败重试不重复上传，替换保留引用顺序和提示词。根据当前模型真实能力检查格式和输入数量，确认后仍需手动发起生成。便携项目重映射舞台 ID 并保留镜头覆盖，账号卡片绑定解除并提示重新选择；独立历史迁移保存完整关联文档。

### 素材内容身份与去重

Assets 通过 `/v1/files/content-identities` 返回当前账号内完整原文件 SHA-256、大小和媒体种类完全相同的素材 ID，哈希读取检查文件状态变化。Visual 的 `/v1/visual-workshop/asset-card-links` 仅返回设定卡采用图、节点和草稿明确保存的卡片关联；输入标签优先显式关联，副本只从验证相同的原件恢复归属，冲突不显示。

`/v1/file-library/content-audits` 固定账号、请求 ID 和项目范围；prepare/clean/restore 使用操作版本 CAS。清理仅处理明确选择的成员，再检查素材版本、内容和现有引用保护。删除先持久记录旧元数据并保护原件，再移除冗余文件；失败重试使用相同操作。恢复使用旧 ID 与新存储键，避免旧清理路径影响恢复。`scripts/maintenance/visual_material_dedupe.py` 通过公开 SDK 迁移当前引用，保留历史输出和任务，冲突时停止或恢复；恢复日志必须在 `.runtime/`，不允许 `.local/` 成为恢复依赖。
