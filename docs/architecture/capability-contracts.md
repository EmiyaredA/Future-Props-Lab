# 能力实现契约

## 表格工坊

表格工坊通过独立 `spreadsheet` 服务保存版本化工作簿，账号来自 Identity 签名上下文，所有读写和原件下载执行账号隔离。快照更新与批量单元格操作共用 CAS 和事务回执；导入原件先安全落盘再提交引用，未知提交保留文件供恢复核对。公式计算在浏览器进行，自动化写入后的缓存显式标为待算。限制、转换支持范围和独立发布要求见[表格工坊工程说明](../reference/spreadsheet-workshop.md)。

修改下列能力时，先定位所属应用及装配，再查对应条款。跨应用规则见[Studio 框架契约](studio-framework.md)，代码位置见[项目目录索引](project-layout.md)。

## 音频标注

- 音频标注文档编辑由 `EditDocument` 执行版本判断与纯转换，`DocumentEdits` 在一个事务内提交
  CAS 与回执；并发失败复查原请求回执，取消回滚。HTTP 层只映射领域错误。
- 音频标注创建与导入由 `CreateProject` 共用用例执行，时长、说话人和片段转换规则归 `rules/`。
  创建输入端口只借出已授权描述和转录快照，路径与媒体探测留在适配器；`storage/projects.py`
  原子提交项目、文档、波形及引用投递，借用范围覆盖提交结果，未知提交不得自动重建项目。
- 音频标注删除用例只删除指定版本的任务及引用，保留源音频；存储在写入时再次执行 CAS。
  已保存片段导出与识别通过 `SavedAudio` 的快照、裁切、识别端口执行，业务不访问存储私有属性。
  媒体适配器在 I/O 前释放读取事务并负责临时文件；识别结果只返回候选，不代替编辑 CAS。
- 兼容网站的音频跨表来源装配归 `assembly/website/annotation_sources.py` 与 `annotation_imports.py`。
  转录私有原件先校验、探测及暂存字节，再将素材与标注加入同一短事务；取消须等复制停止后清理。
  提交确认丢失时按持久素材记录核对，不能把已提交文件当作失败副本删除。
- `TranscribeSegment` 统一裁决音频项目归属与可识别范围，范围存储返回脱离 ORM 的快照并释放事务。
  网站与独立执行器只负责模型调用适配；网站跨表连接归装配，Models 的转录解密器必须显式注入。

## Amadeus

- CLI 的持久会话文件与每轮临时工作区分离。两种执行入口通过同一 Host 适配执行系统沙箱，
  不支持沙箱时拒绝运行。生成脚本只能读写本轮工作区，运行依赖只读开放，不能获得模型认证或后端凭据。
  任务 SDK/CLI 只连接运行绑定 socket，由原有业务工具复核权限并提出写入审批，不能绕开 Plan 限制。
  临时目录只保存可清理内容；产物需显式保存到会话，独立工具运行环境归正式运行根目录。

- Codex 原生生图由 Amadeus 每轮快照显式开启，默认开启，Plan 与账号写权限在两套执行入口复核。
  原生图片项通过独立原件交付端口保存到账号会话 `outputs`；完成事件只能由原件保存用例产生。
  原件不可变、同一运行与图片项的交付幂等，上传确认丢失先读取回执，不重新生图。
  会话消息保留文件引用，运行事件维护图片与文字的顺序，纯图片回复和重启恢复遵守同一规则。

- 独立 CLI 工具只消费运行快照及记录、文件、目录和操作端口。运行账号在装配时绑定；提案与暂停同一事务提交。
  操作目录由当前装配提供，独立服务读取已安装契约，源码运行时使用生成契约，兼容网站使用本实例的 OpenAPI。
- 兼容网站先校验账号、权限、批准摘要和运行状态，再以 CAS 领取动作。执行效果在领取事务结束后运行，
  独立短事务结算。取消和关闭等待已开始的状态提交；网站脚本停止记为取消，无法确认的其他执行记为结果未知。
- 前端会话模块唯一接纳会话及历史快照。附件和审批异步结果按账号和选择版本校验，运行模块按账号持有活动运行，
  只有当前会话接纳对应的运行快照。退出时取消读取和轮询，服务端已接受的写入通过持久回执核对。
- 草稿和已发送消息的图片、视频通过当前会话的鉴权文件路径读取。接近可视区或主动打开预览时读取，缩略图与弹窗
  共用临时 Blob URL。移除草稿附件或切换会话时释放 URL。消息仅持久化文件引用。
- 会话附件通过运行绑定的 `read_file` 工具读取。Codex 将本轮显式引用的图片随首个请求发送，其他 Agent 通过
  同一工具按需读取。图片工具限制解码尺寸与返回体积，在内存中缩放大图，保留导入原件。
- 运行中补充以请求 ID、内容摘要和会话 revision 原子保存消息及指令。执行端先领取一次投递，再回传绑定运行、
  租约与正文摘要的回执。Codex/Pi 原生追加；Claude、OpenCode、Harness 在原 CLI 会话确认中断后续接。
  停止、暂停和恢复将未投递指令标为未送达、未确认投递标为未知，不自动重发；未知和未送达消息不进入后续运行提示。
  补充的文件和项目引用重新校验，不改变当前运行的模式、能力、权限或审批。

## 文件与项目工坊

- 文件格式表归 `studio/contracts/asset_library/file_types.py`；字节检测、完整文件校验、SVG
  安全规范化、摘要及归档编解码归 `studio/runtime/files/`。目录暂存机制不决定应用布局，
  `runtime/database/project_files.py` 通过创建／删除布局接口执行原有事务补偿。
  导演台使用自有 `storage/file_paths.py`，两套装配显式提供存储，不继承素材库布局或读取全局配置。

- 演示工坊的项目、模板、编辑回执和导入使用当前装配提供的账号范围项目适配。素材读取、留存
  与导入显式注入，Session 仅持有账号与事务上下文。两套入口保留各自的素材交付和事务边界。
- 特效制作的 HTTP 装配与网站渲染 Runner 显式构造账号范围的项目适配。素材元数据与文件布局
  端口由两套装配提供，导出、快照和编辑共享其账号与事务上下文。
- 视频剪辑的项目布局和时间轴素材端口由装配按账号与操作显式传入。网站助手和特效交接也使用
  装配绑定的端口，布局变更、片段任务和编辑回执沿用原有事务及恢复规则。字幕导入与素材批量插入共用时间线编辑队列；
  文件解析晚于取消或项目切换时丢弃结果。

- 视频剪辑手动预渲染冻结已保存时间线及素材摘要，固定生成保持项目帧率的 720p 合成预览。
  缓存绑定账号、项目、revision、素材摘要与渲染器版本，不登记为用户素材或普通成片。
  播放入口只在开始播放时选择有效缓存，并关闭逐层画面与音频；缓存播放器驱动时间轴，缓冲时播放头等待。
  未保存编辑立即停用缓存，暂停编辑仍使用原预览与精确帧；加载失败在当前位置恢复实时预览。
  清理和替换先持久标记任务退役，再由所属执行器回收文件；独立服务的 dispatch 在源项目删除后保留清理回执。
  私人缓存媒体读取重新验证账号、项目与快照身份，支持 HTTP Range；后台执行及发布前复核账号授权。

- 视频剪辑书页翻页 `page-curl` 在接缝和片段头尾复用方向、时长与缓动，仅接受左右方向。
  浏览器和后端使用相同归一化卷曲、纸背、投影及透明度规则；接缝仅重排所属轨道的前后片段。
  精确停帧、预渲染和导出复用后端帧求值，合成配方变化同步提升相关缓存版本。

- 视频成片编码仅保留当前画面及接缝两侧需要的片段解码器和图片缓存；每帧打开新源前回收已结束的源，
  并固定 FFmpeg 编解码及滤镜线程上限。解码、编码及音频合成的异常退出不得被静默保持帧掩盖。
  失败回执提供阶段、可采取的恢复动作及任务编号，系统强制终止提示可能内存不足；底层诊断只记入服务日志，
  不向用户返回源路径、上游正文或凭据。取消继续等待子进程退出并关闭管道后清理暂存。

- Story 总校验保持纯函数分层：身份/角色、素材、国际化、时间轴、流程与表现层规则归属
  `apps/galgame_workshop/schemas/story_validation.py`；Pydantic Story 入口只负责迁移适配和统一调用。

- 视频时间线操作的回执记录请求输入与提交 revision；相同请求不重复写入，并返回当前时间线快照。
  后续编辑可能使响应 revision 高于原操作 revision。相同请求 ID 更改输入沿用既有错误响应。
  客户端遇到确认超时先核对持久状态，不把返回快照误认为原操作的历史文档。
- 音频、故事与画布编辑继续返回相同请求原来的结果；纯 revision 命令机制不合并不同重试语义。

## Models 与视觉工坊

- Visual 画布与看板通过同一持久化命令选择服务器或本地冲突版本；恢复先处理旧保存队列，再统一更新 revision、草稿、元数据、错误及历史。展示组件不得直接写持久化 ref。剧本和设定卡用例只接收账号范围存储与具名素材描述端口，SQL、CAS 和回执提交归存储适配。
- 画布轮询快照与保存回包共享单调的版本裁决；旧回包不得替换较新的冲突快照，也不得将未解决冲突显示为已保存。存在冲突时保留本地草稿，服务器或本地恢复均使用最新已知版本。
- Visual 的参考输入规则由 Models 发布能力描述；供应商判断只在 Models 适配边界发生。选择元数据的参考能力不进入冻结任务计划，保留既有计划摘要、准备/激活/中止决议及重启恢复语义。

- 模型目录的凭据读写、诊断、默认项冲突快照及演示安装使用装配提供的 `CatalogCipher`。
  凭据能力不得回退到旧全局帮助函数。解密与密钥提示统一通过注入的 `studio/runtime/secrets.py` 实例处理。

- 视觉验收、Galgame 转录与思绪写作显式注入解密能力；构造器不接收整个
  应用状态容器。网站思绪写作的跨库连接归 `assembly/website/thought_writing.py`，业务只消费写作端口。
- 文本推理、模型测试 SSE 与实时语音 WS 的解密器由 HTTP/WS 装配显式传入；语音来源校验
  使用当前应用的 CORS 配置。实时语音父包保持轻量，调用方导入具体目录或会话组件。

- 生成 Driver、转录 Runner 和工坊模型适配显式接收解密器；Models Runner 必须接收配置，
  不允许默认全局配置回退。

- Models 的视觉生成提交、执行、结果读取与清理各自接收会话、文件、授权及传输依赖，
  不持有应用状态容器或借用另一组件的生命周期。文件布局归 `storage/visual_generation_files.py`，
  批次身份和摘要读取归 `storage/visual_generation_batches.py`；结果读取不依赖 Runner 实例。
- 生成结果下载逐跳验证无凭证的 HTTPS 公网地址，并固定连接到已验证 IP，保留原 Host、TLS SNI 与证书校验。
  系统 DNS 返回代理虚拟地址段时，仅对非本地域名通过固定公网 HTTPS DNS 端点核验真实 A/AAAA；
  私网、回环、链路本地、混合私网答案及无法核验的解析继续拒绝。此恢复不重新提交供应商任务。
- Models 的独立目录和推理 Runner 显式接收原生就绪端口，独立结果删除要求清理端口已装配。
  兼容网站沿用本机就绪校验。Session 不承担原生能力选择。
- Models 全包禁止读取进程全局配置；测试台、转录与独立推理的文件根目录和上传策略必须显式传入。
  HTTP 适配从当前应用装配获取配置，推理文件布局由 `InferenceStorage` 实例持有；不提供默认根目录函数。
- 视觉工坊全包禁止读取进程全局配置；网站生成与验收使用当前应用注入的配置和素材存储。独立视觉服务继续通过跨服务端口取得能力。
- 视频草稿按素材或连线身份保存追踪对象及参考图片顺序。生成时由 Visual 在输出解析后组装英文目标串，Models 仍只消费既有工作流参数。固定版本与跟随最终输出共用解析规则；浏览器不得在连线尚未解析时清空已保存的顺序或提示词别名。
- Amadeus 持有对话和操作审批；视觉工坊提供项目上下文、元素引用及提交前保存，并以画布 CAS 应用批量操作。旧 Visual 审批来源只用于验证既有生成任务成果发布。
- 白模场景归视觉项目，使用独立 revision 和场景格式版本。场景引用内置素材或已核验的项目 GLB，使用受认证的素材 ID 读取 GLB。随项目快照复制时重映射文件引用，项目删除时清理。兼容网站与独立视觉服务共用账号隔离和 CAS 契约。
- 分集剧本和通用设定卡各自保存 revision。设定卡归账号，剧本来源记录项目、场次 ID 和所用版本。候选生成在选定项目的生成任务提交事务内绑定通用卡和请求回执。采用图与父卡图独立记录，项目页引用时通过素材库验证并加入本项目。新项目快照仅保存项目内容，导入旧快照可恢复其中保存的设定卡。
- 设定卡归组是独立的账号级 CAS 操作，保留卡片 ID、采用图、候选和来源。主卡与全部所选变体须同类且有效，修改带子卡的卡片须显式提供全部子卡，归组后扁平挂在无父卡的主卡下。看板固定提供人设、场景、道具三类入口，已关联旧节点通过卡片访问来源，原有输出和连线继续保留。
- 预演回填复用项目节点上传。每个文件携带来源场景、来源 revision、可选镜号和内容摘要。每个文件单独确认和重试，回执按账号和项目作用域保存。删除或复制场景后，已交付素材仍保留原始来源版本。

- 模型模板同步、运行额度和演示配置属于 `studio/apps/model_service/`；兼容网站按已登记设置键
  读写原表，不转移存储归属。演示执行组件不依赖账号治理或模型目录，由装配注入配置读取。

- 独立模型任务归 `studio/apps/model_service/inference/`。备份要求见[生产部署](../operations/production-deployment.md)，
  供应商提交中断的处理见[共享执行与文件机制](studio-framework.md#共享执行与文件机制)。

## 思绪工坊

- 私人知识库、社区发布及授权见[知识社区](../reference/knowledge-community.md)，官方文章与图形见[官方知识库写作](../operations/official-knowledge-writing.md)。

- 思绪工坊禁止读取进程全局配置；网站上传、备份、导入及社区素材由协议装配显式传入当前配置。
  旧站素材元数据适配器接收文件存储，读取前仍复核账号、版本及文件状态；不得自行选取数据根目录。
  素材及 Identity 目录端口经请求装配或源账号适配器提供，禁止通过数据库 Session 查找。
- 思绪归档导入和独立社区的文档及表格编辑显式传入本次准备的素材视图。授权或写入失败时沿用
  引用协调器的回滚规则，封存后的写入校验只使用已验证的快照。
- 思绪外部同步的提交与核对显式接收素材、暂存、授权和执行接口，不接收 HTTP Request 或应用状态容器。
  同步输入暂存只消费已授权素材端口；未知提交保留暂存供恢复核对。阻塞文件 I/O 使用
  `runtime/tasks/blocking_io.py` 等待真实操作停止后传播取消，避免清理与后台写入竞争。

## 集成中心、创作工坊、工具导航与面试

- 集成中心目录、外部连接与 Skill 操作共用 `studio/apps/integrations/` 实现，依赖由网站和
  独立装配显式提供；不得在目录构造器回退读取全局配置、创建默认加密器或查找全局客户端。
  公共 DTO 和 MCP 能力协议归 `studio/contracts/integrations/`，密钥加密机制归 `runtime/secrets.py`。
- 工具导航收藏和使用次数通过 `studio/apps/tools/use_cases/navigation.py` 的显式存储与时钟端口执行。
  存储每操作持有短事务，不向 HTTP 或业务传递会话；次数增量的未知提交不能自动重试。
- 创作工坊的发布过滤在 `studio/apps/creative_workshop/rules/publication.py` 保持纯函数；
  作者目录、来源、归档和文件设置通过 `CreativeResources` 显式传入，不写入 Session 服务定位表。
  安装用例调用注入端口，兼容网站跨表存储与独立投递分别由装配选择；不得回退读取全局配置。

- 面试材料与执行输入目录由装配显式传入，不从 Session 服务定位表读取。材料上传进入提交阶段后，
  确认丢失或取消不能删除可能已被记录引用的原件；重新读取快照核对结果，场次删除统一回收私人副本。
