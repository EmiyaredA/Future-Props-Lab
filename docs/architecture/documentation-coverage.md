## 核验口径

- 每行的入口对应实际功能模块；依据列区分实现文件与测试文件，不表示每篇都独立运行了端到端测试。

- 配置态图片不表示已调用模型。文本连接诊断使用本机确定性响应；图片失败状态使用本机返回的无图片响应，未调用付费供应商。
- 实时语音未执行真实麦克风通话；外部模型生成质量、外部 MCP 服务与第三方网站账号功能不在本次联网验收范围内。
