生成提示统一要求柔和棚拍光、圆角实体、细腻阴影、干净的蓝白与珊瑚配色，避免文字、Logo、水印和界面整图。插画与背景独立于正文及模板槽位，不以整张截图代替页面。

设计器与模板库使用应用自带静态图作预览。保存模板只上传实际引用的背景素材；用户主动导入示例包时，四张图去重上传至当前 Workspace 托管素材，再重映射模板和文稿中的引用。已有素材 ID 不重复上传，素材失败会中止资源保存。原生包和导出沿用正式素材引用规则。
