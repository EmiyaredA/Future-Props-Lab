## 实现与验证

入口是素材区的“添加文字”。文字使用最上层视觉轨，可编辑内容和样式、拖动或输入坐标、
调整时间，支持撤销重做。固定中文字体与透明文字排版归入共享渲染模块，播放预览和最终导出共用排版。
现有文档通过可选 `textStyle` 向后兼容，未改写运行中的项目或数据库表结构。

2026-09-12 验证结果：

- 后端视频剪辑、共享渲染、Galgame 视频和自动化导出相关测试：125 项通过。
- 前端视频剪辑相关测试：110 项通过。
- Chromium 端到端流程通过：添加中文与英文多行字幕、字号与背景、拖动、Esc 取消、撤销重做、
  锁定轨道、调整时长、刷新恢复、正式导出和手机属性面板。明暗主题均检查颜色控件可读性。
- 导出 H.264 视频首帧与后端精确帧的字幕区域像素平均误差约 0.38/255，低于测试阈值 5/255；
  单元测试另覆盖显示起止帧、透明背景、描边、对齐和中文换行。
- `lint`、生产构建、OpenAPI/SDK stale-check、修改文件格式检查、`git diff --check`、
  生产 LFS 资产检查和 `git lfs fsck` 通过。

全仓检查并非全部通过，以下问题位于本次文字功能未修改的代码或已有素材中：

- 账号导航样式覆盖应用壳选择器；视觉工坊历史测试文件超过 1200 行。
- 旧演示 CG 数量与清单不符；文档中心已有截图校验值与登记值不符。
- 项目快照测试期望值缺少已有的 `grid_output` / `grid_size` 字段。
- 文档导航的三个测试仍断言旧标题或旧搜索结果。
- 思绪工坊 `KnowledgeDocumentResults.tsx` 未通过现有格式检查。

这些问题保留原状。运行 `npm test` 时后端失败会阻止 Web 测试启动，因此 Web 全量测试另行运行；
其结果为 798 项通过、上述文档相关 4 项失败。后端全量检查发现的字体搬迁引用遗漏已修复，
并通过包含该路径的 125 项定向回归。
