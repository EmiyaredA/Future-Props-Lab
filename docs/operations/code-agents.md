# 编程智能体接入

从“AI 能力 → 模型与智能体”进入，在页头切换到“编程智能体”，管理本机 Codex、Claude Code 检测和当前 Workspace 的使用授权。Amadeus 保留原形象与窗口，新对话由官方 CLI 执行；旧 Pi 对话只读保留。

“模型服务”保留模型目录、接入管理、本地模型与默认模型用途；“编程智能体”显示本机连接状态和按用途授权。两个视图沿用原地址 `/model-service` 与 `/code-agents`，支持直接访问与浏览器前进后退。切换视图不会自动检测、保存或提交模型任务。

## 部署连接

在实际部署的 `backend/config.toml` 配置：

```toml
[code_agents]
codex_enabled = true
codex_executable = ""
claude_enabled = true
claude_executable = ""
```

空路径启用自动发现；显式路径优先。安装和登录在终端完成，页面“重新检测”仅检查连接，不提交模型任务。默认连接关闭。桌面配置变更遵循停机快照和手动应用更新流程，不在页面热修改。

Codex 最低版本为 0.163.0，Claude Code 最低版本为 2.1.259。实际版本必须支持页面所需的受限参数。模型发现来自 CLI；没有可发现目录时使用“CLI 默认模型”。模型认证、额度与计费属于本机 CLI 的登录账号。

## 账号授权

1. 管理员选择当前 Workspace 中的有效账号。
2. 按 Agent 和用途授权 Amadeus、视觉验收或面试准备；面试准备仅支持 Codex。
3. 保存后，授权记录 revision 增加；其他窗口的旧 revision 返回冲突并要求重新读取。
4. 撤销后，后续任务及工具调用重新校验授权。

旧视觉验收、面试配置按原账号及用途兼容。首次编辑某个用途会接管该用途，保留其他账号原有有效授权；接管后不回退旧授权。旧 Codex 路径不一致且未指定统一路径时，连接卡片显示冲突，由管理员显式配置，不自动选择。

## Amadeus 与外部客户端

Amadeus 运行由后端持有，关闭或刷新窗口不重复提交任务。每次运行保存 Agent、模型、消息与上下文快照；切换 Agent 新建会话。任务最长 15 分钟，退出应用或进程异常后保留已保存文本并标记中断，不自动重试模型请求或写操作。

CLI 只获得已声明的 FPL 工具；项目写入、集成调用和会话文件写入先生成参数绑定审批。Plan 模式拒绝写工具。工具不暴露数据库、任意本机文件或通用 Shell。会话产物须显式导入目标工坊才成为项目素材。

外部客户端使用随桌面 App 打包的独立 `fpl`：先展开“外部客户端接入”的配置，再开启本地接入，确认显示“已开启”，再运行 `fpl --profile codex connect --name Codex`，核对配对码后批准。默认只读，读写须显式申请；Claude Code 使用独立 profile。配置 stdio MCP 命令为 `fpl --profile codex mcp serve`。命令不可被 PATH 找到时，使用 App 中 `Contents/Resources/fpl/fpl` 的绝对路径。

MCP 提供 operations、call、open；call 的显式 files 参数可上传文件，小文件下载返回 Base64，大文件使用 `fpl call --output`。权限沿用配对账号、Workspace、API Key scope 和业务白名单；账号设置的 API 密钥列表可撤销客户端。此连接不限制外部客户端自身已有的本机权限。

连接卡片的“连接详情”可查看可执行文件路径。状态区分未启用、未安装、未登录、版本不支持、检测失败与未授权；“已连接”不代表已获准用于全部用途。授权表按账号显示 Amadeus、视觉验收和面试准备权限；Claude Code 不支持面试准备。保存期间暂时禁用账号和开关，冲突后载入最新授权并要求重新核对，不自动重提。

外部接入默认收起。桌面版从 Electron 读取真实状态，浏览器仅显示“需要桌面版”，仍可展开查看和复制配置；展开、复制或切换视图都不会开启接入。
