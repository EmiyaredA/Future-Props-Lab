# 本地与公网访问

Mac 后台服务统一管理热加载前端与后端，本机入口固定 `http://127.0.0.1:3000`，后端固定 `127.0.0.1:9001`。用户级 LaunchAgent 在登录后运行，与 `npm start` / `npm run dev` 使用同一启动器；关闭浏览器不影响服务和后台任务。现有账号、数据与模型保存在项目 `.runtime/`，私人凭据位于 `backend/config.toml` 与 `backend/web-access/credentials/`。

## 操作与结果

1. 在 Mac 本机入口使用管理员登录，从头像菜单打开「本地与公网访问」。其他入口不显示该菜单。
2. 核对公网来源及状态，点击「检查连接」。显示 ready 表示此进程与网关探针一致；错误信息需先处理再继续。
3. 部署转发网关与专用 SSH 凭据后可「开启公网」；从另一设备访问原 HTTPS 域名并登录，同一账号应看到相同作品。
4. 「关闭公网」停止隧道及重连，本机服务和已提交后台任务继续运行。公网管理员不能调用这些控制 API。

网关资料通过停机备份后的 TOML 配置维护，不把私钥或管理员密码放进网页。专用密钥只允许指定远端回环转发；必须使用已核验 known_hosts，不能关闭指纹校验。旧 LaunchAgent 隧道保持停用，避免两套重连管理器竞争。

## 构建与发布

本机和公网均读取 `[website].web_root` 指向的 `.local/studio-current/current`。统一启动器监听前端源文件并串行构建。通过逐文件 SHA256 清单校验后，两边同时切换。已打开的页面提示刷新，构建失败时继续使用上一次成功的构建。

公网回环监听默认 28081，复用本机业务进程。云端 Caddy 通过隧道转发页面、静态资源和 API。Mac 离线时公网页面也不可用。Host、Origin、CSRF、账号权限均校验；Cookie 按公网 HTTPS 设置 Secure。主机管理依据真实监听入口判定，伪造转发头或本机 Host 不会获得权限。

公网就绪检查失败时会更新状态并重新检查，仍在运行的 SSH 隧道继续承载已建立的连接。SSH 进程退出后由后台重连。

## 自动化与故障恢复

CLI、SDK、MCP 在本机通过网站地址和 Management API Key 访问；浏览器中创建并安全输入密钥，使用独立 profile。`fpl open` 返回归属校验后的网站链接，不切换现有编辑页。关闭或刷新 Amadeus 后可重新读取后台运行状态，未知写入和模型提交不自动重试。

服务日志在 `.runtime/logs/`。更新、配置变更及数据恢复遵守[生产部署](../operations/production-deployment.md)的停机快照流程。

## 多服务管理入口

独立服务模式将访问控制迁入管理端：管理来源、回环端口和 SSH 隧道与业务来源分离；公网只允许治理操作，本机 worker 执行启停、日志与隧道控制。以上单体入口在正式切换前保留为恢复契约，新模式不复用其数据库或进程内公网控制。完整配置与操作见[独立管理服务](management-service.md)。
