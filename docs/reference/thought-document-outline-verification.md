# 思绪工坊文档大纲验收

## 实现范围

- 普通文档编辑、知识库首页阅读、只读成员阅读共用 `RichEditor` 内部的大纲；历史对比不接入。
- 从当前 Tiptap 文档提取非空 H1–H6，保留重复标题，以节点位置定位；跳级标题按最近较浅层级缩进。
- 左侧留白达到 212px 时常驻，宽度为留白减 32px、最大 220px；不足时使用自绘浮层。正文水平位置和宽度不变，窄屏入口预留 44px 高度。
- 收起偏好仅在当前页面会话内存保留；自动窄屏降级不会覆盖。浮层支持外部点击、Escape、焦点循环及恢复。
- 编辑、删除、撤销重做与文档切换更新标题列表；组合输入结束后更新。滚动跟踪章节并避让工具栏与窄屏入口。
- 目录跳转及临时展开折叠内容只改变界面状态，不写正文、锚点、revision 或数据库；不涉及新增 API、迁移与生成契约。

## 运行中白屏修复

开发过程曾出现同名不同扩展名的组件与辅助模块，macOS 不区分大小写的文件系统令运行中的 Vite 保留了旧解析结果。辅助模块改名后，已有桌面服务仍把 `RichEditor` 的组件导入指向已删除的 `documentOutline.ts`；该请求回退为 HTML，导致模块无法加载。

组件导入现已显式指定 `DocumentOutline.tsx`，辅助模块独立为 `outlineHeadings.ts`。已从运行中的桌面开发服务器回读确认两个导入均指向正确模块，并通过类型和静态检查。修复未重启后端或改动正式数据。
