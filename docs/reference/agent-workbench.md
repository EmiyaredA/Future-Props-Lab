# Agent 工作台

在日常网站使用「云控 → Agent 工作台」。管理员在 Studio HTTPS 入口登录并验证密码，再通过 Happier 原生设备密钥创建或恢复账号。Happier 管理会话、审批、文件面板和终端。首次配对需要管理员确认，恢复密钥由管理员自己保管。

旧的 `/agents` 与 `/apps/agent-workbench` 链接进入云控的 Agent 页签。旧 FPL 聊天和原生采集记录按部署指南封存。独立 Compose 的云控提供远程桌面。

启用配置、Runner 项目挂载、验收和恢复流程见 [Happier 部署与切换](../operations/happier.md)。
