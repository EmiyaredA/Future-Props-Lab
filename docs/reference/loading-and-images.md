# 加载反馈与图片预览

浏览器使用统一的整页、区域、行内加载组件。读取资源与服务器执行任务分别拥有状态；网络传输完成不表示上传处理、模型生成或导出已经成功。

## 数据流与测量

`platform/api/transfer.ts` 定义每次请求独立的方向、阶段、已传输字节、可选总量与速度。文件上传的 serializer 通过 `createUploadTransfer` 保留原始 FormData，XHR 复用 Cookie、CSRF、AbortSignal 和 OpenAPI 的错误映射，不重新解析或复制文件。上传阶段依次为 `transferring → processing → completed`；失败由原功能显示错误，读写均不因此自动重试。

响应流按消费速度计量，不克隆整个响应。已解压字节不能除以压缩的 Content-Length；此时只展示大小和速度，不计算百分比。SSE 不进入有限文件传输计量，轮询保留业务任务进度。无可靠总量、模块初始化、图片解码与服务端等待均使用不定进度条。

`useTransferProgress` 归具体操作组件或控制器拥有。并发回执不能清除另一次操作的状态；卸载后忽略回调。`useApiBlobUrl` 保留取消、过期请求防护与 Object URL 释放，路径改变后不显示上一份图片。计量不进入数据库、浏览器存储或账号配置。

动画延迟 150ms 出现；行内按钮名称立即可访问。超过 10 秒显示等待时间，保持已有内容及关闭、取消、重试能力。减少动态效果设置关闭循环动画。

## 图片接口

| 已有 GET 接口 | 可选参数 | 行为 |
| --- | --- | --- |
| `/v1/files/{asset_id}/thumbnail` | `size=128/320/640/1280`，默认 320 | 当前账号的 WebP 派生图；SVG 保留原始安全矢量 |
| `/v1/account/profile/avatar` | 同上，省略返回原资源 | 当前 Session 的头像 |
| `/v1/creative-workshop/items/{item_id}/cover` | 同上 | 沿用草稿或当前发布版本的权限 |
| `/v1/creative-workshop/releases/{release_id}/cover` | 同上 | 沿用版本可见性 |
| `/v1/thought-workshop/community/publications/{publication_id}/cover` | 同上 | 验证发布及文章可见性后读取封面 |
| `/v1/thought-workshop/community/publications/{publication_id}/assets/{asset_id}/content` | 同上；保留 `note_id` | 只允许当前可读正文引用或合法编辑上传的素材 |
| `/v1/model-test/conversations/{conversation_id}/attachments/{attachment_id}/content` | 同上 | 当前账号会话的图片附件 |
| `/v1/model-test/generation-tasks/{task_id}/content` | 同上 | 图片结果缩略图；视频不接受图片尺寸 |

可选尺寸只影响读取；既有内容、下载、裁剪和导出原图接口保持原始资源。派生图经过方向纠正、保持比例且不放大、保留透明度；动画图片使用首帧。解码上限 4000 万像素，最多两个并发线程，写入先落临时文件再原子替换。HTTP 取消后等待解码线程结束才释放槽位。

派生缓存位于已授权源账号的 `previews/`，按资源版本和尺寸区分。创作封面在已有账号封面目录按不可变源文件名派生。缓存不能授予访问权；每次请求重新执行原有归属、发布和逐篇权限检查，返回 `private, no-store`，不进入公共缓存。

## 入口清单

| 入口 | 加载反馈 | 图片读取策略 |
| --- | --- | --- |
| 网站启动、登录检查、路由和编辑器懒加载 | 初始 HTML 动画及共享整页/区域组件 | 应用、导航、最近访问图标使用小尺寸 WebP |
| 查询列表、搜索、分页、设置和确认弹窗 | 区域/行内反馈；错误保留重试；已有数据继续可见 | 屏外托管图片延迟请求；头像 128 像素 |
| 文件库、视觉工坊看板、生成任务、素材选择器 | 上传/下载字节、速度、服务端处理；预览反馈 | 列表 320/640，详细预览至多 1280 |
| 思绪工坊正文、社区、封面、画板及附件 | 正文/模块加载；每文件队列进度；附件下载进度 | 授权适配器保持原链接语义；正文按显示宽度选 640/1280 |
| 演示工坊、Galgame、录音标注、模型测试、视频剪辑 | 区域加载、上传下载及真实任务阶段/百分比 | 列表小图；像素编辑、原图预览、正式渲染和导出使用原图 |
| 原生媒体播放、逐帧画面、波形、Live2D/3D 纹理 | 沿用播放/解码与渲染生命周期 | 不把缩略图写入工程或替换精确渲染输入 |
| 受保护文档中心、外部图片 | 已复用的共享 UI 生效；不重写受保护正文 | 不代理任意外链，不改写现有文档资产 |

缩略图失败显示错误，不自动回退为大图。可交互预览提供重试与查看原图；作为选择按钮的装饰图片由父按钮承接操作，避免嵌套按钮。图片比例、素材 ID、原始大小、裁剪百分比和工程内容不因预览尺寸改变。

## 静态资产与验证

`npm run images:generate` 通过既有 Pillow 与本地 Prettier 生成品牌图标 64/128/256 及模板图片 320/640/1280 WebP。文件名包含源 SHA-256 摘要，派生图纳入 Git LFS；`npm run images:check` 验证内容、清单、过期文件和图标 30 KB 上限，根构建调用该检查。

前端组件测试覆盖未知/压缩总量、取消、上传处理、延迟、可访问名称、失败与按需原图；后端隔离测试覆盖尺寸、透明度、方向、并发和撤权。浏览器验收覆盖明暗主题、390/1280 宽度、弱网路由占位、实际 WebP 请求和图标流量。临时测试产物位于 `.local/loading-feedback/`，不读取或更新正式数据。
