# 视觉创作工坊：看板与节点输出

画布与看板使用同一项目文档、节点 ID 和输入连线。看板的项目素材树按主分类与可选分组整理，默认人设、场景和分镜，可增加自定义分类。文本、图像、音频与视频是节点类型，用途标签独立保存。

`PUT /v1/visual-workshop/projects/{project_id}/canvas` 是整份画板替换，必须显式提交 `nodes` 与 `expected_revision`；缺少 `nodes` 返回 422，不更新 revision、节点、连线或输出历史。只改分类时也应先读取最新画板，再携带原 `nodes`、`edges` 和新 `categories` 提交。显式 `nodes: []` 表示删除全部节点，不能用来占位。

## 看板展示与整理入口

项目素材栏把新建和上传放在顶部，分类管理菜单提供分组与分类编辑；空分类默认收起，没有自定义分组时直接列出素材。工作台的「整理」入口编辑分类、分组和标签，节点更多菜单提供删除操作。提示词、常用参数与生成操作集中在编辑区，当前预览和最终输出以独立标记展示；横向版本条只选择预览，「设为最终输出」才更新最终版本。历史预览在同一项目页切换画布和看板后保留。

状态分组按状态分配空间：待准备和可生成使用紧凑卡，生成中突出进度，已完成突出结果；失败原因可展开，点击「调整并重试」进入对应工作台。桌面编辑与结果区分别滚动，窄屏素材栏改为抽屉。所有菜单支持键盘操作，不改变输出、引用或生成规则。

## 提示词版本

图像、视频与音频节点的 `generation_draft` 增加 `prompt_versions` 和 `active_prompt_version_id`。列表包含 1–20 项 `{id, name, prompt}`：ID 在同节点内唯一且最多 64 字符，名称非空且最多 120 字符，每版文字最多 6000 字符，可为空。当前版本 ID 必须存在；原 `prompt` 字段必须等于当前版本文字。不合法的请求返回 422。

版本通过原 `PUT /v1/visual-workshop/projects/{project_id}/canvas` 或 `/canvas/operations` 保存，仍要求 `expected_revision`，沿用 Workspace 与编辑权限校验。两个版本字段必须同时提供；均省略时视作旧客户端更新，已有节点保留其他版本并更新当前版本，新草稿初始化为 v1。显式版本列表可增删、改名或切换，不能为空。

界面的新增创建空白版本，复制保留当前文字，编辑自动保存；模型、参考素材和参数共用。切换、重命名与删除立即排队保存，生成前等待保存队列完成。参考图片排序对全部版本同步重编号 `<Picture n>`，避免非当前版本指向错误图片。已提交任务保留实际请求文字，后续版本编辑不改变任务记录。节点复制与项目包保留版本集合和当前选择；提示词版本独立于输出历史。

## 输出版本与最终输出

每次上传到已有节点、显式保存文本或成功生成都新增一个服务器维护的版本并成为最终输出。历史预览不修改最终输出；用户可另行选择旧版本作为最终输出。开始生成和失败不清空已有结果。版本列表分页，不靠前端轮询覆盖素材。来源为 `uploaded` 的版本卡片提供「删除」，确认后可删除最终版或历史版；删除最终版时在同一画布 CAS 事务内选取剩余编号最大的版本作为最终输出，没有剩余版本则清空节点的最终输出与素材引用。保留版本计数器，后续新增版本不复用已删除编号。被固定引用的版本仍返回 409 `output_in_use`，须先解除引用；其他来源的最终版仍需先切换最终输出。删除版本不删除媒体文件，也不改写已有任务的输入快照。

普通媒体上传使用 `POST /v1/visual-workshop/projects/{project_id}/node-uploads`，multipart 字段为 `file`、`expected_revision` 和可选 `x`、`y`、`category_id`、`group`。省略分类时进入未分类；分组必须属于目标分类。无效目标返回 422，过期 revision 返回 409；校验在文件落盘前执行。文件、节点分类、v1 与文档 CAS 原子保存。已有节点使用 `POST .../nodes/{node_id}/output-uploads`，上传类型必须与节点一致；视频节点额外接受 `.gif`，按完整单次动画转换为无声 H.264 MP4 后登记视频版本，保留逐帧停留时长（含末帧），不展开 GIF 循环次数。透明区域合成为黑底，奇数尺寸只向右／下补齐至偶数，不缩放原画。图片节点继续保存原始 GIF。

GIF 原文件与转换结果分别受现有上传大小限制；画布最长边不超过 8192、总像素不超过 16777216，转换最多 120 秒。无效文件／尺寸或转换超时返回 422，大小超限返回 413，缺少 FFmpeg 返回 503。临时文件与编码进程在失败或取消时清理；转换先于数据库写入，结束后通过既有 CAS 再次竞争 revision，冲突返回 409，不留下素材或输出版本。API/SDK 的 multipart 字段及响应形状不变。

看板点击「上传素材」展开上传位置选择，默认带入当前节点的分类与分组，可改选或选「未分类」。分类菜单的「上传到此分类」预选该分类，再选择可选分组并点击「选择文件」，支持多文件使用同一目标。上传过程中禁止更改目标或重复选择文件；目标在其他窗口变更时需重新选择或处理版本冲突，不自动改放到其他分类。

| 方法   | 项目内路径                                                   | 内容                                                       |
| ------ | ------------------------------------------------------------ | ---------------------------------------------------------- |
| GET    | `/nodes/{node_id}/outputs?page=1&page_size=20`               | 分页历史（版本降序）                                       |
| GET    | `/nodes/{node_id}/outputs/{output_id}`                       | 具体版本及提交输入快照                                     |
| POST   | `/nodes/{node_id}/outputs`                                   | `expected_revision` 与文本 `text`，或已托管素材 `asset_id` |
| PUT    | `/nodes/{node_id}/final-output`                              | `expected_revision`、`output_id`；选择最终版本             |
| DELETE | `/nodes/{node_id}/outputs/{output_id}?expected_revision=...` | 删除未被固定引用的历史版或人工上传的最终版                 |

上述路径均以 `/v1/visual-workshop/projects/{project_id}` 为前缀。写入要求当前画布 revision；冲突返回 409 与当前快照，不静默覆盖。读写使用视觉工坊固定权限并按 Principal 的 Workspace 校验；跨 Workspace 返回不存在。

生成记录与批次列表支持 `current_nodes=true`（须提供 `project_id`）。仅返回节点当前关联记录和仍在运行的记录；看板使用此投影，避免分页读取全部历史。普通历史列表保持原含义。

## 引用与生成

连线保存 `source_node_id`、`target_node_id`、`binding`（`final` 或 `fixed`）、`purpose`（`reference`、`context`、`first_frame` 或 `last_frame`）及固定模式的 `output_id`。禁止自引用与依赖环；固定版本必须属于上游节点。没有输出的节点不能在看板新选为输入。旧画布占位连线保持兼容，提交时等待上游输出。

跟随绑定在每次提交时解析当时的最终版本；固定绑定始终使用选定版本。文本作为提示词上下文，媒体按目标模型能力校验。提交记录中的 `input_snapshot` 保存具体节点、版本和素材；上游更新不改写在途请求，不自动重生成下游。已有结果与当前输入不一致时工作台提示使用了旧版本。删除被引用节点需先解除引用，删除节点保留媒体文件。

图片请求增加有序 `reference_asset_ids`，保留旧单图 `reference_asset_id`。两者合并并去重，保留首次出现顺序。SenseAudio 最多 1 张；方舟 `volcengine_image` 首批支持 `doubao-seedream-4-5-251128`，最多 14 张 PNG/JPEG/WebP，使用原生数组并关闭组图，每次返回一张。模型选项公开数量、格式、尺寸、种子支持和提示词上限；不截断、不换模型。方舟密钥在模型中心配置。同步结果先持久化下载地址，再由共享任务驱动落盘和归档；提交中断安全失败，恢复不重提供应商请求。

## 兼容与备份

`r0086_visual_node_outputs` 只回填可靠归属的完成记录和节点当前输出，保留节点、布局、连线与原 revision。无法证明归属的旧文件仍保留，通过素材导入或版本 API 显式关联。`r0087_volcengine_images` 扩展供应商约束，保留原任务与模型凭证。

`r0089_visual_prompt_versions` 将已有三类媒体生成草稿补为提示词 v1，不改写草稿参数或任务请求。无草稿节点首次编辑时初始化；旧项目包在导入校验时归一化。

快照包含分类、分组、所有输出历史、最终版本和固定引用；导入重新映射节点、连线、输出与素材 ID，保留版本编号、来源和时间。调用记录标识作为来源审计保留，不重建供应商任务。旧快照当前素材恢复为 legacy v1。

验收使用隔离数据库和模拟供应商；不调用付费模型。后台登记与用户编辑并发、重复完成、CAS、Workspace、迁移及快照由自动化测试验证。验收产物位于已忽略的 `.local/task-board/`。
