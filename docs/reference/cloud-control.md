# 云控

管理员在「云控」并排操作 Mac 桌面和 Agent 工作台。拖动分隔条或用方向键调整宽度。窄屏顶部可切换面板。两栏各自保留会话。

## 本机启用

1. 在目标 Mac 开启屏幕共享并设置独立 VNC 密码。复用本地 RustDesk 工程 `deploy/mac-browser-remote` 的带认证补丁 guacd 镜像，容器端口仅映射到 `127.0.0.1:4822`。默认由容器通过 `host.docker.internal:5900` 连接同一台 Mac。
2. 从可信本机入口登录管理员账号，打开「云控设置」。输入 FPL 管理员密码，检查两项服务状态并启用云控。
3. 左栏点击「连接桌面」，输入刚才设置的 VNC 密码。点击远程画面或其中的输入框，底部显示「键盘已接管」后即可打字。遇到 macOS 锁屏时，在远程画面里输入 Mac 用户的登录密码。用 Shift + Esc 归还键盘焦点。按需使用「适应窗口」和「全屏」。
4. 从工具条的「自动锁定」选择 15、30、60 分钟或自定义 5–120 分钟，默认 30 分钟。连续闲置后画面清空，再次输入 VNC 密码即可重连。右栏会话与草稿独立保留。

连接建立后，左栏显示「等待画面」，直到浏览器绘制出首帧才显示「已连接」。连接或画面等待超时后，左栏会显示原因和「重新连接」入口。等待期间可以取消连接。

在本机右栏点击「选择项目」，选择推荐目录或最近项目。点「选择其他目录」可以浏览 Mac 的项目、桌面、文稿和下载文件夹，也可以粘贴绝对路径。确认后，项目名称出现在工作台。选过的目录按账号记在「最近项目」中。

在本机「AI 能力 → 编程智能体」启用需要的 CLI 连接。选好项目和 CLI 后发送消息。已有会话继续使用创建时的目录。若目录已移动或删除，可查看会话历史，并从新会话选择可用目录。

## 公网与验收

1. 先在本机登记 TOTP 验证器，并实测桌面键鼠、中文输入、缩放点位和超时重连。对 FPL 的 HTTPS 入口核验同源 WebSocket 升级，再从本机「云控设置」允许公网连接。
2. 外网每次登录 FPL 后，首次连接桌面需要密码重验与 TOTP。同一 FPL Session 内，桌面空闲重连只需输入 VNC 密码。注销、撤权和重置验证器会断开已连接桌面。
3. 从另一台设备实际操作 Mac 并验证断线重连。已开放公网 Agent 的部署仅能使用旧 TOML 配置项目。从本机工作台选目录并新建对话，再续聊并验证审批。遇到公网验收失败时，从本机关掉公网云控。

部署端可以显式启用 `public_desktop_vnc_only`。此模式下，从本机确认实控后，在「云控设置」打开公网桌面。公网已授权管理员登录 FPL 后，直接输入 VNC 密码连接和重连。Agent 执行仍通过本机入口。

## 接口

- `GET /v1/cloud-control/status` 返回可用性、桌面授权、Agent 解锁期限和账号空闲偏好。
- `POST /v1/cloud-control/desktop/connect` 通过请求体接收本次 VNC 密码，设置短时一次性握手 Cookie。浏览器以 `guacamole` 子协议连接同源 `/v1/cloud-control/desktop/socket`。密码在后端内存中短暂使用。
- `PUT /v1/cloud-control/desktop/idle` 使用 revision 保存空闲时限。桌面空闲只由实际转发的键鼠事件刷新。
- `/v1/cloud-control/settings` 用于可信本机的桌面设置。写操作要求近期密码重验，配置保存通过文件 revision 检查并发。
- `GET /v1/agent-workbench/execution/directories` 在可信本机浏览 Mac 目录。省略 `parent` 时返回导航入口，传入后返回直接子目录。
- `POST /v1/agent-workbench/execution/projects` 接受本机目录 `root`，校验后返回稳定的账号项目 ID。推荐目录和最近项目通过本机 `GET /v1/agent-workbench/execution/catalog` 返回。
- `POST /v1/code-agents/{agent_id}/enable` 仅向通过近期密码重验的本机管理员开放。它检测指定 CLI 的安装、版本和登录，再保存共享连接的启用项与可执行路径。
- `/v1/cloud-control/totp/enroll` 与 `/totp/confirm` 用于本机登记或重设验证码。`/totp/verify` 按请求用途分别验证桌面 Session 或 Agent 短时授权。

正式启用前在隔离环境验证迁移，并按既有流程停机备份、迁移和发布匹配构建。旧部署文件中的 VNC 密码可在本机保存设置时清理。
