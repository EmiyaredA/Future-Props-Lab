# Galgame 工坊：常见问题与能力边界

## 章节或分支走不到

检查入口章、章内入口、启用顺序和分支条件。Branch、If 与 Call Fragment 执行目标后回到调用位置。用工程检查定位不可达片段与循环，再试玩实际路线。

## 角色没有出现或素材缺失

检查 Block 引用的稳定角色与素材 ID、时间范围、可见性和舞台位置。不要仅核对名字；同名条目可能不是同一个身份。

## 配音重复或时间不对

主音轨剧情以完整音频为时间基准，不同时重复播放逐句配音。核对当前语言、声音来源和时间轴，再生成或导出。

## 修改后旧视频没变化

导出任务冻结提交时的 Story。修改后保存并重新预览，再明确提交新导出。已有下载文件不会自动更新。

## 导出失败

先看素材失效、路线循环、预览版本、磁盘空间与输出参数。失败后修正再手动提交，不以反复重试绕过校验。

Galgame 适合叙事和舞台演出；它不是通用实时多人游戏引擎。最终视频是确定路线的画面交付，无法恢复互动分支和完整工程。
