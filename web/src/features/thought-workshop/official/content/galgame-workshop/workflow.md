# Galgame 工坊：主要操作流程

## 章节、分支与变量

维护章节顺序和启用状态，确定每章入口 Fragment。用 Branch、If 或 Call Fragment 执行目标片段，这些调用完成后会回到调用位置，不等同于永久跳走。

先建立变量，再配置条件与分支。用叙事地图检查因果链、不可达内容和循环，双击定位回剧本。每条关键线路都实际试玩，不能只看图谱连接。

## 角色与舞台

登记角色、场景、CG 和媒体，在 Block 中引用。调整舞台位置、立绘、镜头、对话框及声音时，确认当前 Fragment 和选中对象。

个性化集中管理对话框底图、颜色、字体、聚焦、口型与 UI；设置中管理画布和角色默认位置。默认配置和某段演出的覆盖参数需分别检查。

## 时间轴和配音

有精确时间轴的片段按时间安排画面和声音，播放核对关键时刻。主音轨剧情以完整音频为时间基准，不重复叠加逐句配音。

模型配音前检查文字、角色和声音设置，生成后试听并校对。语言版本维护对应文本和媒体，不假设修改一种语言会自动修正全部语言。

## 工程检查

把试玩与校验结合：检查入口、素材、变量、线路和结局，然后查看完整演出。发现错误返回实际位置修正；完成工程后修改故事会恢复草稿状态，需再次验收。
