# Galgame 工坊：功能概览与快速开始

想制作一段有角色对白、场景和选择的短故事，先让最短线路从入口走到结束。本篇带你建立一个可试玩工程，再逐步增加分支、配音和精确时间轴。

## 开始前

确认当前 Workspace 与内容写权限，准备一段简短对白或旁白；素材可以后续逐步补充。需要模型配音或识别时，另行确认对应模型与使用权限。

一个工程对应一部故事，先记住三个层次：

| 名称     | 用途                           | 例子                             |
| -------- | ------------------------------ | -------------------------------- |
| 章节     | 组织故事顺序与入口             | 第一章“初次见面”                 |
| Fragment | 可进入或调用的剧情片段         | “开场”“询问”“告别”               |
| Block    | 一次对白、演出、媒体或逻辑动作 | 角色说一句话、改变舞台或判断条件 |

## 制作最小可玩故事

1. 新建工程，打开概览并进入编辑器。
2. 确认入口章节及其入口 Fragment，先把开场写在这条实际入口上。
3. 配置需要的角色或场景，在片段中加入一段对白或旁白。
4. 暂时不加复杂分支，打开“试玩”，检查故事能开始、文本能推进、片段能结束。
5. 打开“工程检查”，阅读入口、资源和路线反馈，回到对应位置修正。
6. 保存成功后重新试玩，确认当前版本仍然连通。

**完成标志：** 从正式入口能完整走到预期结束，关键对白和舞台出现，没有未处理的路线或素材错误。

> [!TIP]
> 先完成一条短线路，再加一个分支。大量场景图、角色条目或台词并不能证明故事流程已经可玩。

## 入口和资源身份

工程有明确入口章，入口不能被删除或禁用。角色、场景、CG 和变量用稳定 ID 关联，Block 引用这些身份；重命名不等于替换引用。

若同名角色在舞台上表现不同，检查实际引用条目。若新增片段走不到，检查它是否从入口或已执行逻辑连接，而不是只确认列表里存在。

## 下一步怎样扩展

基本线路通过后，再逐项加入变量、分支、配音、多语言和时间轴。每增加一种变化，就试玩相关线路并运行检查。需要交付普通视频时，再选择一条确定路线导出；视频不保留互动选择能力。

试玩和工程检查帮助发现问题，不会自动替你补全断路或判断叙事质量。完成前仍需检查角色、字幕、声音与结局是否符合创作意图。
