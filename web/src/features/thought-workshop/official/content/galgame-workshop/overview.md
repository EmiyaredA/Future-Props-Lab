# Galgame 工坊：功能概览与快速开始

一个 Galgame 工程对应一部故事。章节组织顺序，Fragment 表示可调用剧情片段，Block 描述对白、舞台演出、媒体与逻辑。

## 最小可玩故事

1. 新建工程并打开概览，进入编辑器。
2. 在入口章节的入口 Fragment 加入场景和一段对白或旁白。
3. 配置说话角色与必要素材，先不引入复杂分支。
4. 打开试玩，检查开始、文本推进和章节结束。
5. 运行工程检查，修正断路和素材错误，再保存。

最小线路验证后再增加分支、变量、配音和精确时间轴。空有多张场景图片不能证明故事流程可玩。

## 入口与身份

工程有明确入口章；入口不能删除或禁用。角色、场景、CG 和变量有稳定 ID，演出 Block 引用这些身份。

编辑需要当前空间写权限，模型配音或识别需要相应模型和授权。试玩和工程检查用于验收叙事，不自动补全断路。
