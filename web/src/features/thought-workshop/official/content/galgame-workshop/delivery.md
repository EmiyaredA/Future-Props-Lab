# Galgame 工坊：导入导出与交付

要继续编辑故事，应交付工程与素材；要给普通观众播放，应导出一条确定路线的视频。本篇带你完成路线选择、试片和正式输出，避免把互动工程与成片混为一谈。

## 导出前准备

保存当前 Story，试玩目标线路并运行工程检查。确认角色、场景、字幕、声音和结局正确，所需媒体能够读取。路线校验失败时先回编辑器修复，不靠反复提交绕过。

## 导出一条路线视频

1. 点击“导出视频”，选择完整路线或选中的片段。
2. 完整路线遇到分支时逐项选择，核对最终结局与预计时长。
3. 选择输出预设：720p30、1080p30 或 1080p60。
4. 提交后在导出记录查看阶段；需要停止时使用取消，并等待任务到达安全结束状态。
5. 完成后下载视频，检查开头、分支展示、字幕、声音和结尾。

**完成标志：** 下载文件独立播放正常，路线与选择一致，内容不包含编辑器界面或鼠标。

> [!NOTE]
> 视频是一条已选定路线的输出，包含舞台演出、字幕与分支展示，不保留观众可操作的分支。需要互动内容的后续编辑时，还要保留工程。

## 先用快速试片检查局部

带时间轴的当前片段可以导出指定范围。默认从播放头向后取 10 秒；播放头位于末尾时取最后 10 秒。也可选 5、10、30 秒等快捷范围，单次最长 5 分钟。

试片会恢复起点之前的场景与声音状态，预热部分不进入输出。适合检查某个动作、字幕或声音切点，不必每次重渲染整条长路线。

## 工程与素材导入

继续编辑使用工程快照或正式项目包流程，并保留需要的媒体。导入素材时核对目标类型与归属，稳定 ID 由正式入口管理；手工拼装跨账号文件引用不能代替完整包。

导入后重新执行工程检查和试听，确认接收环境中的文件、字体或声音没有缺失。

## 交给视频剪辑继续制作

需要进一步剪辑时使用明确的视频剪辑交接流程，核对目标工程及其素材副本。后续 Story 修改不会自动更新已交接内容，需重新确认并交付。

直接路线视频导出使用公共渲染能力，不要求先建立剪辑工程。只有真正需要多轨后期时，再进入视频剪辑工坊。

## 任务失败后

先查看素材、路线循环、版本、磁盘或输出参数等明确原因；修复并保存后再手动提交。已完成的视频优先从原记录下载，旧下载文件不会自动更新成新 Story。
