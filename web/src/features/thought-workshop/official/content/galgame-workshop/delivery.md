# Galgame 工坊：导入导出与交付

## 工程与媒体

继续编辑应使用工程快照或项目包流程，保留所需素材。交付普通视频则使用“导出视频”；只有视频无法恢复角色、分支和故事数据。

导入素材时确认目标类型和归属，稳定 ID 由正式入口管理。不要把手工拼装的跨空间文件引用当作完整备份。

## 导出路线视频

1. 保存并试玩目标线路，检查声音、画面和结局。
2. 点击“导出视频”，选择完整路线或选中的片段。
3. 完整路线遇到分支时逐项选择，确认结局与预计时长。
4. 选输出预设，提交后在导出记录检查阶段、取消或下载。

支持 720p30、1080p30 与 1080p60。成片只含舞台演出、字幕和分支展示，不含编辑器或鼠标。

## 快速试片

带时间轴的当前片段可导出指定范围，默认播放头后 10 秒；末尾取最后 10 秒。可选 5、10、30 秒等快捷范围，单次最长 5 分钟。

任务恢复起点之前的场景和声音状态，预热部分不会进入输出。正式导出直接使用公共渲染能力，不要求先建立剪辑工程。

## 明确交接

需要进一步剪辑时使用编辑器提供的视频剪辑交接流程，检查目标工程及素材副本。后续 Story 变化不会自动改变已交接内容，需重新确认并交付。
