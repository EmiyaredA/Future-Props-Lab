# Live2D：参数绑定、网格与动作

## 先理解它解决什么问题

二维角色动画通过分层图片、网格和参数把静态素材变成可变形的角色。参数关键形描述某个参数值对应的形状，动作随时间驱动参数，最终状态决定每层的网格、变换和可见性。

**贯穿实例：** 头部左右转动可以由一个参数的左右极值与中间关键形描述。测试动作时应同时检查极值、默认姿态和组合参数，避免只在单一预览位置看起来正常。

## 实现与设计取舍

原生工程保存绑定与素材，Cubism 运行资源有独立的导入和兼容边界。公共渲染能力按文档求值。工程包用于继续编辑，PNG 序列用于画面交付，素材交接包用于在外部编辑器继续绑定；这些格式不能互相冒充。

## 异常、验证与当前边界

转换 Cubism 时物理、复杂遮罩或多参数联动可能无法精确对应。素材交接包不会生成 moc3 或 cmo3。角色完整性要检查默认姿态、参数范围、图层顺序与极端动作，预览成功不等于所有导出目标都一致。
