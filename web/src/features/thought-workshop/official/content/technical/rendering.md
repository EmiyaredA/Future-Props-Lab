# 时间线与媒体渲染：从状态到帧

## 先理解它解决什么问题

时间线描述在某个时刻应当出现什么，不直接等于一段视频。渲染器先求值片段、速度、转场、图层和声音，再按输出时间采样并编码。浏览器预览与最终导出需要遵守同一份语义。

**贯穿实例：** 一个素材片段以两倍速播放时，输出第 2 秒对应的源时间不再是第 2 秒。转场边界又会让相邻片段在同一时刻共同参与画面。

## 实现与设计取舍

确定性画面求值与媒体渲染由共享能力拥有，避免不同 App 私自实现不同含义的同一效果。Galgame 直接导出调用公开渲染能力，不依赖视频编辑器内部模块；跨工坊项目交接是另一个明确用例。

## 异常、验证与当前边界

预检要识别缺失素材、不支持效果和无效区间。验证不仅比较文件是否存在，还应检查起止帧、片段接缝、速度变化和音画对应。复杂工程消耗时间与内存，失败时保留工程和明确错误，不把部分文件当作完整成片。
