# Agent 工作台：查看文件与继续会话

Happier 原生会话管理回复、审批和项目文件浏览。

## 操作与核验

1. 在会话里确认机器和项目路径，在文件面板打开项目文件。核对面板显示的路径与当前项目一致。
2. 刷新或重新进入 Happier，从列表打开同一个会话。看到已有消息后再发送新消息，确认新回复追加到该会话。
