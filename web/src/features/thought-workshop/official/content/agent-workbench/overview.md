# Agent 工作台：阅读现有会话

本篇说明管理员如何使用云控中的 Agent 工作台，核对实际操作、保存状态和账号边界。普通用户不能访问工作台，管理员也不能读取其他账号的副本。

## 操作与核验

在 FPL 网站以管理员账号打开「云控」。左侧是远程桌面，右侧是 Agent 工作台。
点击右侧「会话历史」，可以查看 FPL 发起的会话和已同步的 Codex、Claude Code、OpenCode、DeepSeek Harness 或 Pi 记录。点击「管理来源」进入来源设置。

在本机「云控设置」验证管理员密码并启用云控。在本机「AI 能力 → 编程智能体」启用要使用的 CLI。首次在工作台发送消息时，按界面提示验证密码和动态验证码。右侧点击「新会话」，选择项目目录和可用 CLI，发送一条消息。看到用户消息与 Agent 回复后，可以在同一个会话里继续发消息。若 Agent 请求写入文件，先核对预览，再批准或拒绝本次操作。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 保存与能力边界

来源只有经原生标记核验才显示 APP 或 CLI；没有可靠证据显示来源待确认。工作台不是云端 ChatGPT 聊天列表，也不要求历史来源具备 CLI 执行授权。

> [!NOTE]
> 本机与公网浏览器访问同一部署时使用相同账号隔离规则。新的来源绑定只能在运行 FPL 的 Mac 上，经后端确认的本机网站入口执行；公开地址不会扩大账号权限。

## 独立访问与权限变化

工作台入口为 `/agents`。当前网站先提供兼容入口，独立服务随服务化任务完成验收后切换。管理员降级或账号停用后，页面和事件流停止访问，采集停止；已有来源、阅读副本与检查点保留，恢复管理员资格后按现有规则继续。来源发现与新绑定仍仅允许本机网站入口。
