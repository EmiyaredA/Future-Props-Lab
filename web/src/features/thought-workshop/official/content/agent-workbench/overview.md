# Agent 工作台：阅读现有会话

本篇说明管理员如何使用云控中的 Agent 工作台，核对实际操作、保存状态和账号边界。普通用户不能访问工作台，管理员也不能读取其他账号的副本。

## 操作与核验

在 FPL 网站以管理员账号打开「云控」，从页头切换到「Agent 工作台」。工作台占满内容区，切回远程桌面后仍可继续使用已打开的会话。

已启用 Happier 的部署在工作台显示其原生 Web。完成 FPL 密码重验后，首次点击 Happier 的 FPL 登录按钮。宽屏打开会话时，左侧是会话列表，中间是对话，右侧默认打开文件面板。窄屏使用 Happier 自带的面板切换。要查阅以前的 FPL 会话，从 `/agents` 打开原有历史。

以下是 FPL 历史和原有工作台的操作。

点击「会话历史」，可以查看 FPL 发起的会话和已同步的 Codex、Claude Code、OpenCode、DeepSeek Harness 或 Pi 记录。点击「管理来源」进入来源设置。

打开已同步的 Codex 会话时，可以在用户气泡里核对同一轮中追加的消息。带图消息正文下的附件标记对应原端记录中的图片。

在本机「云控设置」验证管理员密码并启用云控。在本机「AI 能力 → 编程智能体」启用要使用的 CLI。首次在工作台发送消息时，点击「验证并解锁」并输入 FPL 管理员密码。解锁后可在 15 分钟内发起 Agent 操作。

1. 在工作台点击「新会话」和「选择项目」。本机入口可以直接选择最近、推荐或已配置的项目，也可以点击「选择其他目录」。点箭头展开目录，点目录名后核对「已选目录」的路径，再点「使用此目录」。也可以粘贴绝对路径并点「使用粘贴的路径」。确认后，工作台顶部显示项目名称。
2. 打开「选择 Agent」，按应用图标和名称找到可用的 CLI。选中后，顶部显示 Agent 的图标和名称。
3. 发送一条消息。看到用户消息与 Agent 回复后，可以在同一个会话里继续发消息。若 Agent 请求写入文件，先核对预览，再批准或拒绝本次操作。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 阅读命令与文件

1. 展开回复中的操作摘要，再展开命令。命令和输出各自滚动；工具栏可复制全文、开启或关闭自动换行。Shell 显示命令正文，编排多个工具的脚本显示为 JavaScript。
2. 点击文件操作中的路径、回复中的文件链接，或命令下方识别出的文件路径。文件栏会自动展开，显示文件名、当前磁盘内容和行号。TypeScript、JavaScript、Python、Shell、JSON 等常见代码按文件类型高亮，跨行注释与字符串保留连续语义。带行号的链接会标记对应行。按 Escape 或点关闭按钮返回会话。

历史来源授权与项目文件授权独立。若提示项目未授权，请先在本机新会话的项目选择器中选择该目录；公网需要管理员配置对应项目授权。阅读文件还需要云控验证解锁。文件阅读显示当前磁盘文本，不是 Agent 当时读到的历史版本；已删除文件、链接、私密配置、二进制和过大的文件会显示不可读提示。

## 保存与能力边界

来源只有经原生标记核验才显示 APP 或 CLI；没有可靠证据显示来源待确认。工作台不是云端 ChatGPT 聊天列表，也不要求历史来源具备 CLI 执行授权。

> [!NOTE]
> 本机与公网浏览器访问同一部署时使用相同账号隔离规则。新的来源绑定只能在运行 FPL 的 Mac 上，经后端确认的本机网站入口执行；公开地址不会扩大账号权限。

## 独立访问与权限变化

工作台入口为 `/agents`。当前网站先提供兼容入口，独立服务随服务化任务完成验收后切换。管理员降级或账号停用后，页面和事件流停止访问，采集停止；已有来源、阅读副本与检查点保留，恢复管理员资格后按现有规则继续。来源发现与新绑定仍仅允许本机网站入口。
