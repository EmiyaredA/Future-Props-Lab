# Agent 工作台：打开 Happier 工作台

日常网站的云控通过 Happier 管理编程会话。指定管理员需要 FPL 密码解锁和 Happier 设备密钥。

## 操作与核验

1. 从 Studio HTTPS 入口登录，在「云控 → Agent 工作台」点击「解锁 Agent 工作台」并验证管理员密码。成功后会加载 Happier 页面。
2. 首次使用 Happier 时创建账号或用恢复密钥登录。登录后应看到会话列表。宽屏默认展开文件面板，窄屏使用 Happier 的面板导航。
3. 切到远程桌面再切回工作台，打开的会话仍在。解锁到期后，重新验证 FPL 密码再进入。
