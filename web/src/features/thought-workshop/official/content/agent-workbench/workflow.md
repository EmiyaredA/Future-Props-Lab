# Agent 工作台：配对并开始会话

使用经过管理员批准配对的 Runner，选择授权项目和已经配置的 CLI。

## 操作与核验

1. 在隔离 Runner 执行 `happier auth login`，在已登录的 Happier 页面确认配对。机器出现在新建会话的选择器中后，可以开始会话。
2. 选择在线机器、项目目录和 Codex，发送一条测试消息。确认 Happier 收到流式输出，再继续操作。
3. 遇到审批请求时核对项目路径和操作内容。批准或拒绝后，以会话中显示的审批结果为准。
