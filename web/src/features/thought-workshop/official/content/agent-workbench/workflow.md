# Agent 工作台：绑定与持续同步

本篇说明管理员如何使用云控中的 Agent 工作台，核对实际操作、保存状态和账号边界。普通用户不能访问工作台，管理员也不能读取其他账号的副本。

## 操作与核验

在运行 FPL 的 Mac 上，通过本机网站入口打开「来源」，选择已检测目录或填写实际会话目录的绝对路径。核对工具和路径，确认当前账号保存阅读副本，点击绑定并开始同步。返回会话并在原工具产生一条完整新记录，应看到最后同步时间与正文更新。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 保存与能力边界

上翻会保留阅读位置，出现新内容后使用「有新内容」回到底部。Pi 分支分别选择；暂停跟随仅影响当前阅读视图，后台和原 Agent 继续运行。原端历史底部显示「只读 · 自动同步」。展开回复内的活动摘要可以核对调用和输出。要从 FPL 发起新的 CLI 会话，请回到「云控」右栏，点击「新会话」。

在 Mac 本机打开「AI 能力 → 编程智能体」，选中要使用的 CLI，点击「启用 CLI 连接」并验证 FPL 管理员密码。看到「已连接」后，回到本机云控右栏，点击「选择项目」。可从推荐目录或最近项目直接选择，也可点「选择其他目录」浏览 Mac 或粘贴绝对路径。项目名称显示在右栏后，选一个可用 CLI 并发送消息，确认会话出现在历史中。再次新建会话时，可在「最近项目」找到刚选的目录。

Agent 回复时，输入下一条消息并选择「加入队列」，应看到它出现在输入框上方的「待执行」列表。Codex 或 Pi 就绪时，也可选择「插入本轮」，收到确认后会在当前回复中看到指令。当前轮失败、被停止或服务重启后，先核对上一轮结果，再解锁并点「继续队列」。

展开 Agent 回复中的活动摘要，可以查看搜索、文件、命令和可用的原端问答。FPL 执行会话读取文件成功后，可点击文件名检查当前源码。有行号的操作会定位对应行，关联的已批准差异可通过「显示更改」查看。

> [!NOTE]
> 本机与公网浏览器访问同一部署时使用相同账号隔离规则。新的来源绑定只能在运行 FPL 的 Mac 上，经后端确认的本机网站入口执行；公开地址不会扩大账号权限。
