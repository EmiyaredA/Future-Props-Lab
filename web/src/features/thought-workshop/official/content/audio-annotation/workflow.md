# 录音标注工坊：主要操作流程

## 定位与切分

用波形、播放头和列表选片段，先试听完整句子再调整边界。切分后分别核对两段文本，不以视觉间隙代替听觉判断。

“紧接上一段”调整当前开始边界，“紧接下一段”调整结束边界，另一侧时间与文本保持。片段需处于录音范围；多人真实重叠时不应为消除图形重叠破坏时间。

## 说话人与情绪

为人物建立清晰名称，一个片段可选择多位说话人，按选择顺序显示。情绪按片段内的人分别标注：先选择绑定对象，再选预设或自定义情绪。

移除片段说话人会移除对应情绪绑定。选择情绪不等于完成文本校对，两者分别维护。

## 情绪词库

情绪管理可建立自定义名称与颜色，内置预设只读。名称最多 40 字符，项目最多 64 项，不区分大小写去重。重命名同步已有对应标注；删除词条只移出词库，保留已有标注文案。

## 文本与语言

按自己的转写规范整理口头语、标点与语言版本。模型识别或外部文本导入后，逐段试听时间和人物，检查空文本、未指定说话人及未校对项，再决定交付。
