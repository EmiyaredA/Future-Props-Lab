# 录音标注工坊：导入导出与交付

## 项目 JSON

点击“导出标注”选择“项目 JSON”，用于完整标注草稿和继续编辑。文件记录工程、说话人、片段和源媒体元信息，时间以毫秒表示；录音二进制不在 JSON 中。

交接时同时发送对应音频。接收方从项目列表“导入项目”恢复，选择实际音频并核对时长与片段时间。

## SRT 字幕

导出前每段需有说话人和非空正文。按钮禁用时，弹窗显示遗漏数量；逐项补齐后再导出。

输出使用“说话人：内容”，多人按选择顺序显示，时间来自已保存的片段边界。用字幕播放器或剪辑器与原录音一起检查，不会自动重排时间。

SRT 不保留完整情绪、词库、版本与校对信息。正式交付字幕时仍建议另存项目 JSON。

## 外部文本与识别

按导入入口提供的格式组织外部文本，预览匹配结果后再应用。语音识别结果需逐段校对人物、正文和时间戳，不能只看总文本是否通顺。

## 验收

检查开头、结尾、重叠发言和紧邻片段。重新导入一份备份可验证数据完整；验收使用隔离副本，避免覆盖当前工作。
