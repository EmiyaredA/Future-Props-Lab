# 录音标注工坊：导入导出与交付

将标注交给下一位校对者，应保留人物、情绪和校对状态；将字幕交给剪辑师，则需要可播放的时间码与正文。先确定接收方用途，本节分别说明项目 JSON、SRT 和外部文本回填的实际流程。

## 选择项目 JSON 或 SRT

| 文件      | 保留的信息                                                 | 使用条件                                                   |
| --------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 项目 JSON | 工程、说话人、片段、情绪、语言和校对信息，以及源媒体元信息 | 可以保留未完成草稿；恢复时另选对应录音                     |
| SRT 字幕  | 已保存片段时间与“说话人：内容”                             | 每段需要说话人和非空正文；不保留完整情绪词库与项目编辑信息 |

> [!NOTE]
> 项目 JSON 不包含录音字节。完整交接应同时提供对应音频；只有 SRT 也不能恢复全部标注数据。

## 交接可继续编辑的项目

1. 确认保存完成，打开“导出标注”并选择“项目 JSON”。
2. 同时整理对应音频，核对文件时长和实际开头。
3. 接收方从项目列表“导入项目”读取 JSON，再选择对应录音并导入打开。
4. 抽查开头、结尾、多人重叠和紧邻片段，确认人物顺序、正文和时间没有错位。

若导入的是识别结果 JSON，先阅读导入窗口关于过短片段处理的提示，再核对剩余片段；不要把项目恢复与识别结果导入视为完全相同的数据来源。

## 导出可用字幕

打开导出弹窗，查看 SRT 按钮旁的遗漏数量。逐段补齐说话人或正文后再导出；“已校对”标记不能填补空文本。

SRT 使用“说话人：内容”，多人按选择顺序显示，时间来自片段边界。将字幕与原录音一同加载到播放器或剪辑器，检查字幕出现和消失时刻，尤其是句首、句尾与重叠发言。

## 回填外部修订文本

“导入文本 JSON”用于将修订后的情绪、原文、附加语言和校对状态带回已有项目。片段 ID、时间与说话人必须完全一致；不通过此入口改变分段结构。先在外部保留原始 JSON，再粘贴修订结果，检查校验提示后应用。

> [!TIP]
> 正式字幕交付时另存项目 JSON。后续需要修改人物、情绪或重新校对时，项目比 SRT 更适合作为起点。
