# 录音标注工坊：功能概览与快速开始

录音标注工坊围绕源录音管理片段、说话人、文本、语言、情绪和校对状态，输出可继续编辑的项目 JSON 或 SRT 字幕。

## 建立第一份标注

1. 从应用中心创建任务，填写名称并上传或选择当前空间可用音频。
2. 确认文件名、时长和可播放状态，进入编辑器。
3. 试听一整句话，用波形和播放头建立片段，调整起止边界。
4. 建立说话人，为片段填写人物和文本，再标注情绪与校对状态。
5. 保存后导出项目 JSON；需要字幕时补齐说话人与正文再导出 SRT。

例如双人访谈先用“主持人”“来宾”区分人物，逐句试听后再统一修订姓名。不要只根据波形高度判断发言边界。

## 模型与权限

手工标注无需模型，编辑需要空间写权限。语音识别还需要可用转写模型及其输入格式支持；能在浏览器播放不等于能提交给任意模型。
