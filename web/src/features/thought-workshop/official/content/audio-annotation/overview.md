# 录音标注工坊：功能概览与快速开始

把一段双人访谈整理成可交接的标注，需要同时保留时间、人物和说话内容。录音标注工坊围绕原始录音管理这些信息；完成本节后，你会得到能继续编辑的项目 JSON，并知道还需要补齐什么才能输出 SRT 字幕。

## 准备一段可核对的录音

编辑需要当前 Workspace 的内容写权限。可以上传新录音，也可以从当前空间文件库选择音频。手工标注不要求模型；语音识别另需可用转写模型及受支持的输入格式。

先试听开头，确认文件与预期访谈一致，记录时长。相同名称的剪辑版与原版可能时间轴不同，不要在开始标注后随意互换。

## 建立第一份标注

1. 打开录音标注工坊，点击“新建任务”，填写名称，选择文件库音频或“上传新录音”，再“创建并打开”。
2. 确认音频可播放、时长正确，试听一整句话后用波形和播放头建立片段。
3. 调整片段起止位置，重新播放边界附近，确保句首句尾没有被截断。
4. 创建“主持人”和“来宾”等说话人，为片段选择实际发言者并填写正文。先用清楚的临时名称，确认人物一致后再统一修订。
5. 按需要补充逐人情绪、附加语言与校对状态。逐段试听后再标记校对，不把模型输出自动视为完成稿。
6. 确认保存后点击“导出标注”，先导出“项目 JSON”。字幕交付前再补齐每段说话人与正文，输出 SRT。

> [!TIP]
> 先完整做完三到五个片段，确认自己的分段、人物命名与文本规范，再处理整段录音。波形空隙只帮助定位，真正的句子边界仍需试听。

## 什么样才算完成

重新播放时，选中的片段应对应正确句子；正文、人物和实际音频相符。重新打开任务后信息应仍在。项目 JSON 用来保留工作稿，SRT 用来给播放器或剪辑器显示字幕，两者不能互相替代全部信息。

> [!NOTE]
> 项目 JSON 不嵌入录音字节。交接或恢复时还需要对应音频，不能只留下 JSON。
