# 录音标注工坊：常见问题与能力边界

## SRT 按钮不能点击

检查缺少说话人或正文的片段数量。项目 JSON 允许保留未完成草稿，SRT 要求字幕内容完整。仅标成已校对不能填补空文本。

## 多人同时说话怎么标

一个片段选择多位实际发言者，按所需显示顺序排列。情绪分别绑定到片段中的人物，不把旁观者加入名单。

## JSON 导入后没有音频

项目 JSON 不包含录音字节。恢复时选择对应音频，核对时长和开头。相同文件名不能证明是同一音轨。

## 紧接操作改变了哪里

紧接上一段只改开始边界，紧接下一段只改结束边界。操作后循环试听，确认没有吞掉句首句尾，也没有破坏真实多人重叠。

## 能播放却不能识别

浏览器与供应商对格式、文件大小和时长的要求不同。检查所选识别模型的输入约束，必要时使用正式裁切或格式处理后再提交。

录音标注不自动保证转写正确，也不是实时共同编辑系统。最终交付需要人工试听与校对。
