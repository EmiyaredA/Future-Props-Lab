# 录音标注工坊：保存与素材管理

标注做到一半需要换人接手时，最重要的是把当前片段结构与原录音一起保留下来。项目 JSON 可以保存未完成草稿，SRT 则面向字幕显示；本节说明怎样留下能继续工作的材料，以及删除任务实际会影响什么。

## 保存当前标注

修改片段、说话人、情绪或正文后观察保存状态，离开前确认完成。版本冲突时保留当前草稿并核对服务器版本，不反复提交旧数据。

需要阶段备份时点击“导出标注”并选择“项目 JSON”。即使还有空正文或未指定说话人，也可以保存工作稿；这些遗漏可能阻止 SRT 导出，但不应阻止你保留当前进度。

## 原录音与 JSON 要成对保留

工程引用当前账号的音频；JSON 记录源文件元信息和标注数据，时间以毫秒表达，并不内嵌录音二进制。

1. 导出项目 JSON，并保留对应录音文件。
2. 在交接说明里写清这是原始录音还是剪辑版本，核对总时长与开头内容。
3. 接收方通过“导入项目”选择 JSON 和对应音频。
4. 重新试听开头、结尾与几个中间片段，确认时间码仍落在同一句话上。

> [!WARNING]
> 不要仅凭文件名相同替换源录音。剪掉几秒开头或改变音频长度，会让后续时间码整体失去对应关系。

## 哪些信息属于项目

多人发言顺序、逐人情绪、语言正文、校对状态与自定义情绪词库都是标注数据。颜色帮助识别人物或情绪，改变颜色不代表修改了正文。

外部文本回填不是新建时间轴：专门入口要求片段 ID、时间和说话人一致。若需要重切片段，应在编辑器操作并再次导出新的项目版本。

## 删除与恢复

删除任务会清理标注、说话人和波形数据，源录音仍保留在文件库。删除前导出 JSON 并保留录音；需要恢复时使用正式导入入口创建可检查的项目，不直接修改存储文件。

> [!TIP]
> 重新识别前先保存或导出当前工作。识别结果仍需校对，不应把一次模型结果当作已人工验收稿的等价替代。
