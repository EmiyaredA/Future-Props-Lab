# 录音标注工坊：保存与素材管理

## 保存标注

编辑片段、说话人与文本后观察保存状态，离开前确认完成。版本冲突时保留当前草稿，核对服务器版本后再处理，不重复提交旧数据。

中途交接可以导出项目 JSON，即使仍缺少说话人或文本也能保留草稿。SRT 的完整性要求更高，不适合代替工作中备份。

## 源录音

工程引用当前空间音频，JSON 保存源文件元信息，不嵌入录音字节。交接时同时保留音频，并确认接收方选择的是同一段录音。

更换不同剪辑长度的音频会影响全部时间码。不要仅因为文件名一样就认为时轴一致。

## 标注信息

多人顺序、逐人情绪、语言文本、校对状态和自定义情绪词库属于项目数据。颜色是辅助辨识，修改颜色不改变情绪文字。

## 删除与恢复

删除任务会清理标注、说话人和波形数据，源录音仍保留在文件库。删除前导出项目 JSON 并保留对应音频；恢复通过正式导入入口，不直接修改数据库。

识别失败先查看模型和输入要求。已有标注不应因重新识别而未经确认被覆盖，先保存当前工作。
