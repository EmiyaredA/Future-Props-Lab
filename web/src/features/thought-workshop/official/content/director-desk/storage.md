# 导演台：保存与素材管理

## 保存工程

顶部保存将当前戏段、对象、镜头与资源引用写入工程。等待成功后再离开或导出。版本冲突时保留本地内容并核对最新版本，不反复覆盖。

`.director` 工程包用于继续编辑，预演视频不包含可恢复的场景结构。

## 资源归属

模型、贴图和视频由工程管理。通过正式导入和保存入口写入资源，不能手工替换目录里的文件来修改作品。

编辑器内的资源状态与服务器保存可能不同。上传、解析或保存失败时查看明确提示，修正后再验收工程，不仅看当前内存中的预览。

## 戏段与动作

复制或切换戏段后核对当前对象和播放时间。可复用动作保存在动作库，场景中的实际使用仍要检查角色和时长。

对象可见性影响镜头，资产或对象筛选只帮助定位。导出前检查完整参与集合，避免在局部检查状态下遗漏对象。

## Agent 操作

外部 Agent 的场景工具需要对应编辑器已打开并完成加载。关闭页面可能使调用失败；恢复后先读取工程状态，不自动重复写入或导出。
