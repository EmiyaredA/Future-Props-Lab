# 导演台：保存与素材管理

一段预演不仅是一段视频，还包括场景对象、戏段、镜头轨道与工程资源。需要继续调整演员路线或替换道具时，应保留这些结构；本节帮助你确认保存完成，并在资源或版本异常时保留当前工作。

## 保存可继续编辑的工程

点击顶部“保存”，将当前戏段、对象、镜头与资源引用写入工程。等待成功再离开或导出。发生版本冲突时先保留本地内容并核对当前版本，不反复覆盖提交。

`.director` 工程包用于导入、导出与继续编辑。阶段性交接时应检查接收环境能重新打开对象和轨道，而不只是播放视频。

> [!NOTE]
> 预演视频保留画面，不包含可恢复的场景结构。重要预演建议同时保留工程包和已验收的视频。

## 工程资源怎样准备

模型、贴图和视频通过正式导入入口进入工程，再通过保存管理引用。不要手工替换资源目录里的同名文件，文件路径相同不等于工程已经接受了新资源。

1. 导入资源后等待解析与加载完成，检查是否显示明确错误。
2. 把资源用于正确对象，核对尺寸、材质或表面媒体映射。
3. 保存工程，重新打开或重新检查加载结果。
4. 从摄影机画面播放问题区间，确认资源在实际拍摄中可用。

当前内存里的预览可能早于服务器保存。上传、解析或保存失败时，先处理提示，不要仅凭“画面还能看见”判断所有材料已保存。

## 戏段与动作复用

复制或切换戏段后，重新核对当前对象和播放时间。动作库保存可复用动作，场景中的实际使用仍需检查演员适配与时长。对象筛选帮助定位，但筛选结果不是导出参与对象的完整清单。

## 外部 Agent 与编辑器状态

外部 Agent 的场景工具需要对应工程编辑器已打开并完成加载。关闭页面后调用可能失败；恢复连接时先读取工程状态和已有任务，再决定下一步，不自动重复写入或导出。

> [!TIP]
> 大幅改戏段或替换主要模型前先导出工程包，并记下验收机位与时间点。恢复时用同样的机位与时间检查，更容易发现差异。
