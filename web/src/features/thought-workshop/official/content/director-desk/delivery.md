# 导演台：导入导出与交付

## 可编辑工程

用 `.director` 包导入、导出工程。导入后检查模型、贴图、视频、戏段和镜头，等待资源加载后播放。只交付视频无法恢复对象与动画轨道。

## 输出预演

先保存，确认当前戏段、摄影机、时长、尺寸和帧率，再按导出面板提供的选项输出。检查起止帧、运动中点、对象可见性与遮挡。

预演用于评估构图和节奏，不替代最终美术制作。低精度交互预览与完整精度输出可能不同，验收要看下载文件。

## 外部 Agent

导演台没有编辑器内专属聊天助手。外部 Agent 可通过本地 `fpl` 或 Python SDK 读取工程、资源与动作库，场景工具在已打开的编辑器中执行。

```sh
fpl open director PROJECT_ID
```

将占位 ID 替换为当前空间的真实工程 ID。等待页面加载后再查询场景、检查几何或执行修改。

同一工程由最近打开的编辑器接收场景操作。没有打开页面时不会在后台假装修改或排队等待。只读授权不能执行修改、导出或取消任务；写入还需最新版本。

连接中断先核对工程和任务状态，明确决定是否重新执行，避免重复创建或导出。
