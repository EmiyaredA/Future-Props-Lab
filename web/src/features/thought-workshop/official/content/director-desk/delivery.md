# 导演台：导入导出与交付

给拍摄团队看节奏与构图，可以输出预演；给另一位制作者继续改镜头，应交付 `.director` 工程。本节将两种交付分开，并说明外部 Agent 如何进入已经打开的编辑器工作。

## 交接可编辑工程

通过正式入口导出 `.director` 包，接收方导入后等待资源加载。检查模型、贴图、表面视频、戏段和摄影机，再播放关键区间。若素材还在加载，先处理提示，不用一张空白预览判断整个工程失效。

> [!NOTE]
> 只交付预演视频无法恢复场景对象、演员走位或摄影机轨道。需要后续修改时应同时交付工程包。

## 输出可检查的预演

1. 保存当前工程，确认当前戏段和用于拍摄的摄影机。
2. 核对时长、输出尺寸和帧率，再按导出面板实际提供的选项提交。
3. 完成后打开下载文件，检查起止帧、运动中点、机位切换、对象可见性与前景遮挡。
4. 对使用表面视频的镜头，核对完整精度结果。降低纹理质量的交互预览不等于最终输出质量。

预演用于评估空间、构图和节奏，不替代最终美术制作。验收应以下载的输出为准，同时保留对应工程版本便于复改。

## 用外部 Agent 操作场景

导演台没有编辑器内专属聊天助手。外部 Agent 可通过本地 `fpl` 或 Python SDK 读取工程、资源和动作库；需要在场景中执行的工具由已打开编辑器接收。

```sh
fpl open director PROJECT_ID
```

把 `PROJECT_ID` 替换为当前空间的真实工程 ID，等待编辑器加载完成后，再查询场景或执行修改。同一工程由最近打开的编辑器接收场景操作；页面未打开时不会在后台假装执行或排队等候。

> [!WARNING]
> 只读授权不能执行修改、导出或取消任务。写入还需要最新版本；连接中断后先核对工程和任务状态，避免重复创建或重复导出。

## 交付完成检查

让接收方打开工程并定位到约定的戏段、时间和机位；视频则至少检查开头、结尾及运动最复杂的区间。这样分别验证“能继续编辑”和“能正确观看”两个目标。
