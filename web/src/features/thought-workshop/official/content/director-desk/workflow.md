# 导演台：主要操作流程

一个“演员走向桌边，摄影机缓慢推进”的镜头包含对象位置、表演时间和取景三个部分。按本节先搭景、再安排演员、最后调整机位，可以看清每一步对最终画面的影响。

## 整理场景与对象

在资产区按分类、收藏或最近使用查找资源，使用列表或宫格浏览。在对象列表中按类型、楼层等筛选，为演员、摄影机和关键道具设置容易辨认的名称。

先用宽视野查看整体，再调整具体对象的位置、旋转和尺寸。每次编辑前核对当前戏段、选中对象与播放时间，避免把同名对象或另一戏段改错。

> [!WARNING]
> 对象“隐藏”会影响拍摄和导出，不只是折叠列表。临时隐藏前景检查布景后，导出前要恢复所有需要入镜的对象。

## 安排演员动作和走位

1. 选择演员，将播放头移到动作开始时间，检查脚与地面的关系。
2. 在动作、走位等对应区域设置起点、朝向和可用动作，并记录需要的关键帧。
3. 移到结束时间设置终点，再播放整个区间，检查途中是否穿过道具、离地或突然转向。
4. 使用动作库或用户动作复用表演后，重新检查时长、方向和角色适配。动作存在并不代表适合每个演员。

先做清晰的单段运动，再叠加复杂动作。若演员在原地看起来正确，但行走中异常，应优先检查中间过程而不是只改终点。

## 从摄影机画面调整取景

选择正式机位，查看摄影机画面后调整位置、朝向和可用镜头参数。使用“K 位置”等对应入口记录运镜，再检查起点、中点、终点和机位切换时刻。

并排视图适合同时核对空间与取景。演员和摄影机都运动时，通过实际播放确认人物是否出画、被前景遮挡，以及切换是否发生在预期时刻。

## 表面媒体和预览精度

给对象表面使用工程媒体时，分别检查映射、裁切、偏移、重复与播放范围。同一源素材可以复用，但每个对象保留自己的参数。

> [!TIP]
> 降低视频纹理预览精度可以让交互更顺畅；判断最终清晰度时仍要看完整精度输出，不要把实时预览模糊直接当作素材丢失。
