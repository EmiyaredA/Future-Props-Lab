# 导演台：常见问题与能力边界

预演异常常发生在“看到的视图”和“实际拍摄的机位”不一致，或编辑了错误戏段与时间。先按现象定位入口，再用完整播放验证；不要通过同时改动所有对象来碰运气。

## 排查表

| 现象                           | 常见原因                                  | 处理与成功标志                                                 |
| ------------------------------ | ----------------------------------------- | -------------------------------------------------------------- |
| 布景看着正确，摄影机画面却不对 | 观察视图与正式机位不同                    | 选择摄影机并查看其画面，用并排视图核对构图和关键帧             |
| 演员穿过道具或脚离地           | 位置、朝向、动作适配或地面关系不合适      | 从起点到终点完整播放，检查中点与转向，逐段修正路线             |
| 对象没有出现在输出里           | 戏段、摄影机、时间或对象可见性不正确      | 恢复临时隐藏对象，检查完整参与集合和正式机位                   |
| 换动作后方向或时长不对         | 新动作不完全适配当前演员与镜头            | 重新核对持续时间、朝向和地面关系，不直接沿用旧验收结果         |
| 表面视频看起来模糊             | 交互预览纹理精度降低，或源媒体/映射有问题 | 先查源文件与映射，再比较完整精度导出                           |
| Agent 提示没有编辑器           | 对应工程页面未打开或尚未加载              | 打开当前账号的正确工程，等待完成；同项目由最近打开的编辑器接收 |
| 工程预览存在但重新打开缺资源   | 上传、解析或保存未完成                    | 回看错误提示，经正式入口重新处理并保存，再验证加载             |

> [!TIP]
> 排查顺序可以固定为“当前戏段 → 当前时间 → 选中对象 → 正式摄影机”。这四项比反复调整镜头参数更容易解释画面差异。

## 操作中断或版本冲突

先保留本地内容，核对服务器当前版本或已有导出任务。恢复连接后先读取状态，不自动重复写入和导出；已经完成的输出优先下载并核对。

如果只是当前观察角度混乱，切回明确的布景视图或摄影机画面再继续。不要用删除工程、手工替换资源文件来修复视图问题。

> [!WARNING]
> 隐藏对象会影响拍摄和导出。临时检查后必须恢复需要入镜的对象；筛选对象列表并不代表其余对象已被验证。

## 当前能力边界

导演台用于三维预演，不是最终离线美术渲染器。工程包与视频承担不同交付目标；外部场景自动化需要已打开的编辑器，不能把关闭页面后的调用失败理解为已在后台执行。
