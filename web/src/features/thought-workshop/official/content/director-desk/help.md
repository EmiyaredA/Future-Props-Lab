# 导演台：常见问题与能力边界

## 观察视图正确，镜头却不对

观察视图与摄影机不同。选择正式机位，从摄影机画面检查构图和关键帧；并排视图可同时核对空间与拍摄结果。

## 演员穿模或脚离地

检查对象位置、动作适配、朝向和地面关系，播放整段运动。默认动作不能保证适配每个角色和场景，应逐段修正走位。

## 对象没有进入输出

检查当前戏段、摄影机、时间和可见性。隐藏会影响成片，临时隐藏用于布景检查后应恢复。筛选列表不代表已检查全部对象。

## 表面视频模糊

交互预览可能降低纹理精度。先检查源媒体和映射，再核对完整精度输出；不要只依据实时预览判断素材丢失。

## Agent 提示没有编辑器

先打开对应工程并等待加载，确认正在操作当前空间的正确项目。同项目最近打开的编辑器接收工具操作，关闭页面后调用可能失败。

本应用是三维预演工具，不是最终离线美术渲染器。保存工程与输出视频承担不同交付目的，重要预演应同时保留两者。
