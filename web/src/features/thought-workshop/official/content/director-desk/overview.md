# 导演台：功能概览与快速开始

导演台用于三维预演，安排场景、演员动作、走位和摄影机，检查空间与镜头节奏。搭景运镜不需要生成模型，编辑需要空间写权限。

## 建立第一段预演

1. 点击“新建预演”，确认当前戏段和时间轴时长。
2. 用默认演员、舞台和摄影机熟悉操作，再从资产加入地面、建筑或道具。
3. 在俯视或布景视图检查对象位置、朝向和尺寸。
4. 添加或选择摄影机，用并排视图同时观察布景和实际拍摄画面。
5. 为演员设置动作和走位，为摄影机记录位置关键帧，播放后保存。

例如先做演员从门口走到桌边的一段预演：确认路线和遮挡，再加入跟随镜头，逐个检查而不是同时改所有对象。

## 视图与戏段

观察视图帮助编辑空间，摄影机画面用于验收镜头。戏段组织不同片段，复制或切换后先确认当前戏段与时间。
