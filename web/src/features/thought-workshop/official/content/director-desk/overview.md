# 导演台：功能概览与快速开始

拍摄前想确认演员从门口走到桌边是否会被前景挡住，可以先在导演台搭建一段三维预演。这里把场景、演员走位和摄影机放到同一时间轴中；完成本节后，你会有一个已保存、可播放的短戏段，并能从正式机位判断构图。

## 开始前确认

编辑需要当前账号的内容写权限，搭景与运镜不要求配置生成模型。先确定一个简单动作和一个机位，例如“演员进门、走到桌边、停下”。首次练习可使用默认演员、舞台与摄影机，减少资源问题对学习操作的干扰。

## 建立一段可检查的预演

1. 打开导演台，点击“新建预演”。先确认顶部当前戏段、时间轴总时长和播放时间。
2. 使用默认场景，或从左侧“资产”加入地面、建筑与道具。用“俯视”或布景视图确认门口和桌子的空间关系。
3. 选中演员，在对象列表核对名称，再调整位置、朝向和尺寸；不要误把道具当作演员修改。
4. 选择现有摄影机或“添加摄影机”。切到“并排”，一边看布景，一边看摄影机画面。
5. 在对应时间安排演员动作与走位，为摄影机记录必要的位置关键帧。先检查固定机位下的路线，再考虑加入运镜。
6. 从头播放，检查停留、遮挡和出画情况；点击顶部“保存”，等待成功，再决定是否导出预演。

> [!NOTE]
> 普通观察视图用来布景，摄影机画面用来核对拍摄结果。移动观察视角不会自动修改正式机位。

## 完成后应该看到什么

演员应从正确起点到达终点，中途不穿过桌子、脚不明显离地，摄影机能在需要的时刻看见人物。重新打开工程后，戏段、对象与镜头仍应存在；只下载一个视频不能保留这些编辑结构。

> [!TIP]
> 一次只增加一种变化。先验证演员路线，再增加摄影机运动，最后加入复杂前景或表面视频，能更快定位遮挡问题。
