# 演示工坊：保存与素材管理

## 保存与撤销

停止修改约一秒后自动保存，也可点击保存或按 Ctrl/Cmd+S。观察保存状态后再离开。文字、元素和页面操作参与本次编辑的撤销与重做；最多保留 100 步，重新打开不保留撤销历史。

保存失败会保留草稿并允许重试。版本冲突时，选择载入服务器版本或另存副本；先确认自己的修改是否已妥善保留，系统不会静默覆盖。

站内离开会先尝试保存；刷新或关闭浏览器依赖未保存提醒，不应以刷新代替保存。

## 图片归属

文稿引用当前空间的公共文件。删除图片元素或文稿不会自动删除公共源图片；有业务引用时文件管理会阻止删除。

替换图片前先确认新图尺寸与方向，替换后复查裁剪、旋转和透明度。派生的裁剪显示不改写源文件。需要移交作品时导出文稿，而不是把素材 ID 发给另一个空间使用。

## 界面偏好

右侧面板可拖动调宽、双击还原，也可聚焦边缘后用方向键调整。画布缩放和面板宽度是编辑视图状态，不改变 PPTX 的页面坐标。

验收时同时检查当前页面、保存版本和最后导出的文件。导出成功不代表之后的新修改已经进入旧下载文件。
