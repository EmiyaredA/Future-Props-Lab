# 演示工坊：保存与素材管理

排版完成后，需要确认修改已经写入服务器，而不是只停留在当前窗口。本篇说明保存状态、版本冲突、撤销范围、每页图像归档和公共素材引用，让文稿在重新打开与交付时保持一致。

## 保存当前修改

1. 完成文字输入、拖动或裁剪操作，停止修改约一秒，观察自动保存。
2. 需要明确触发时，点击保存或按 Ctrl/Cmd+S。
3. 等待页面显示保存成功，再切换项目、关闭窗口或导出。
4. 重要版本可返回项目列表后重新打开，核对关键页面和图片。

**完成标志：** 当前内容显示已保存，并且重新打开后仍能看到刚才的修改。

站内离开会先尝试保存；刷新或关闭浏览器依赖未保存提醒。提醒出现时处理当前草稿，不把刷新当成修复保存失败的方法。

## 撤销与重做能恢复什么

文字与格式、文稿名称、演示者备注、元素增删与排列、分组与连接线、页面增删与排序、背景、图片替换与裁剪、图像版本引用都按同一操作顺序撤销与重做，最多保留 **100 步**。切页、自动保存和手动保存不会清空历史；关闭、刷新或重新打开文稿后清空，载入服务器版本也会清空。

1. 修改名称、备注或元素后，点击顶部“撤销”，或按 **Ctrl+Z / Cmd+Z**。光标停在名称、备注、画布文字或属性输入框中也使用同一顺序。
2. 点击“重做”，或按 **Ctrl+Shift+Z / Cmd+Shift+Z** 恢复；也支持 **Ctrl+Y**。
3. 连续输入同一字段会合并，停顿约 800 毫秒、离开字段或切换对象后开始新的一步。拖拽、缩放、旋转与滑杆的一次手势整体恢复；中文输入法组合期间暂不执行文稿撤销。
4. 跨页回退会切换到受影响页面。恢复页面删除时，左侧缩略图与页面内容一并恢复；撤销后再修改会清空原重做分支。

**完成标志：** 画面与输入框立即显示恢复结果；保存后再次打开，内容与最后一次撤销或重做的结果一致。没有可恢复操作时，对应按钮禁用。

拖拽尚未松手时，首次撤销只取消这次预览。裁剪预览仍先确认或取消，确认后可整体撤销。弹窗中的未提交源码、搜索与预览草稿保留本地输入撤销，不回退背后的文稿；即时修改文稿的参考图设置与选色器使用文稿历史。放映、媒体预览与只读模式不执行文稿撤销。撤销图片或图像版本修改只恢复文稿引用，不删除公共源文件。

因此，撤销适合修正眼前操作；需要长期保留一个可交付版本时，保留对应文稿和导出文件，不能把撤销栈当作版本备份。

## 保存失败或版本冲突

| 状态                 | 你可以做什么               | 先确认什么                 |
| -------------------- | -------------------------- | -------------------------- |
| 保存失败             | 保留草稿，按页面反馈重试   | 网络及具体错误是否已解决   |
| 版本冲突             | 载入服务器版本，或另存副本 | 本地修改是否还需要保留     |
| 离开时仍有未保存内容 | 留在编辑器完成处理         | 是否真的收到了保存成功反馈 |

> [!WARNING]
> 载入服务器版本前先确认本地内容的保留方式。系统不会静默合并所有修改，连续重复提交旧版本也不会解决冲突。

## 模板快照与示例

文稿保存正在使用的模板快照、文稿全局覆盖与稳定章节信息。修改模板库里的配置不会自动改动已有文稿，必须预览并确认应用。模板更新、解除绑定和文稿样式修改均进入文稿撤销历史；撤销后作为新的 revision 保存，不回退服务器版本。

模板与示例的素材也受到引用保护。删除库中模板不会移除已绑定文稿的快照；示例是完整独立快照，不依赖源稿继续存在。模板设计器离开时有未保存保护，冲突后应保留本地修改或明确重新载入服务器版本，不反复覆盖旧 revision。

## 图片与源文件

文稿引用当前账号的公共文件，包括背景填充、图片、公式 SVG、视频、音频与封面。所有实际引用均受归属校验与删除保护。删除图片元素或文稿，不会自动删除公共源图片；有业务引用时，文件管理会阻止删除文件。

裁剪只影响文稿中的显示，不改写原图。替换图片后，重新核对方向、裁剪、旋转与透明度。跨账号交接应提供文稿交付文件，不是把旧素材 ID 发给接收方。

## 为每页归档生成图

先生成整页图像、再制作可编辑幻灯片时，可为每页保留一张图像版本。需要文稿编辑权限，图片来自当前账号的公共文件库。

1. 在左侧选择目标幻灯片，打开右侧“页面”面板。
2. 在“图像版本”区域点击“添加图像版本”，从文件库选择图片，或切换到“上传图片”选择原始生成图。
3. 核对归档缩略图；点击缩略图预览完整原图，“下载图像”保留原始图片文件。
4. 等待显示“已保存”，重新打开文稿并选择这一页，确认图像版本仍在。

**完成标志：** 这一页显示对应的归档图，其他页的图像版本和可编辑内容保持原样。

每页保留一张图像版本。“更换图像版本”替换当前关联；“移除图像版本”只解除关联，原文件仍保留在文件库。复制页面会一并保留图像关联，删除页面或文稿不会删除原文件。仍被文稿引用的图像不能从文件管理中删除。

图像版本不自动生成，也不参与放映或 PPTX 导出；需要重建时并排或透明对照的图片，使用独立的“参考图”。只读用户可以预览、下载已经归档的图像。

上传失败时原关联保持不变，可按提示重试。上传过程中关闭选择器或切换页面，不会把迟到的上传结果关联到另一页；已经上传的文件可能留在文件库，可再次选择。

## 哪些设置只是视图

右侧面板宽度和画布缩放不改变幻灯片页面坐标。面板可拖动调宽、双击还原，聚焦边缘后还可用方向键调整。

在另一设备看到不同缩放或面板宽度，不代表排版变化。要判断作品是否正确，看页面内容、保存版本和放映结果。

## 导出前核对

完成裁剪或取消临时状态 → 等待保存 → 放映检查 → 导出。导出后的文件是当次结果，随后对文稿的新修改不会自动进入旧下载文件。

## 信息图、连接与参考图的保存

文稿版本 3 保存原生元素、分组成员、连接端点与信息图来源，不保存第三方编辑器运行状态。旧版文稿通过登记迁移补齐新字段，已有内容、顺序和 revision 不变。

参考图同样引用当前账号的公共文件库素材，并参与引用删除保护。移除参考图只解除文稿引用，不删除文件。保存后重新打开文稿，应能恢复参考图的显示方式、透明度和显示开关。

Agent 可以通过已有项目和批量编辑 API 写入同一原生场景。批量操作支持 group、connection、infographic 与 fragment；片段根组、元素与关联边必须完整有效，写入仍要求 expected_revision 和 request_id。不能通过更换 revision 静默覆盖其他窗口修改。
