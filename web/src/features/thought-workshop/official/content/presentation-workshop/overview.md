# 演示工坊：功能概览与快速开始

要做一份三页产品介绍，可以先完成封面、说明页和结束页。本篇带你从新建文稿走到放映检查，得到一份已保存、能继续编辑的演示文稿。

## 开始前

确认当前 Workspace 与内容写权限。准备标题、一段说明和可选图片即可，手工排版不需要配置模型。新文稿默认 **16:9** 页面，也支持调整页面尺寸。模板尺寸需要与文稿一致。

只读成员可以浏览、放映和导出已有文稿，但不能修改元素。精细拖动与裁剪建议使用桌面；窄屏可以做文字、备注等轻编辑。

## 直接打开文稿与按需预览

侧栏“我的文稿”负责创建和管理文稿；“模板与示例”分别展示可编辑的全稿模板与完整示例。模板定义字体、标题、目录、页码、背景和固定 Logo，示例提供基于模板完成的整份内容。选择“使用模板”或“基于示例新建”并填写名称，即可创建独立文稿，不修改源模板或示例。首次使用可显式“导入技术汇报入门包”，向当前空间加入无品牌模板与五页示例。

在“我的文稿”中点击封面或文稿名称，直接进入文稿。需要先查看内容时，点击封面右下角的“预览”，在弹窗中用上一页、下一页、方向键或底部缩略图查看全部页面。按 Escape 或点击“关闭预览”返回列表，焦点回到“预览”按钮；也可以在弹窗中点击“打开文稿”进入文稿。只读成员同样可以打开和预览已有文稿。

**完成标志：** 点击文稿封面直接进入文稿；只有点击“预览”才显示所选文稿和页码，翻页后画面随之变化。预览加载失败时点击“重试”；预览本身不会新建或修改文稿。

## 制作第一份文稿

1. 从应用中心进入演示工坊，点击“新建演示文稿”，使用便于查找的名称，例如“产品介绍初稿”。
2. 在封面或所选版式中，点击文本框选中，再双击进入文字编辑，替换标题与副标题。
3. 点击“新建幻灯片”添加空白页，或打开旁边的“新幻灯片版式”，选标题正文、图文双栏等合适版式。
4. 在第二页放入一段核心说明，需要图片时通过图片入口上传或从当前空间文件库选择。
5. 增加结束页，写清下一步或联系方式；在左侧核对页面顺序。
6. 等待保存完成，再打开“放映”，用方向键逐页检查，按 Escape 返回编辑。

**完成标志：** 三页顺序正确、文字没有明显溢出、图片显示正确；返回列表重新打开后内容仍在。

> [!TIP]
> 版式中的文字、图形和图片是普通元素，可以继续修改。先利用版式建立结构，再调整细节，比从空白页同时处理所有元素更容易检查。

## 界面各区域负责什么

| 区域         | 主要用途                   | 开始时先做什么           |
| ------------ | -------------------------- | ------------------------ |
| 左侧页面列表 | 选择、排序、复制与删除页面 | 确认当前选中哪一页       |
| 中央画布     | 选择与移动元素、编辑文字   | 点击选中，双击编辑文字   |
| 右侧“元素”   | 修改选中对象属性           | 先确认对象再改参数       |
| 右侧“页面”   | 设置页面背景等             | 没选中对象时核对页面设置 |
| 底部         | 备注、缩放、适应页面       | 调整视图，不改变页面尺寸 |

## 第一次遇到问题

点了文字却无法输入时，确认已经双击进入编辑，而不是仅选中框。拖不动元素时检查是否锁定。离开时出现未保存提示，先处理保存或冲突，不用刷新代替保存。

需要交付时，继续阅读导出指南：放映用于检查，PPTX 才是可交给接收方打开的文件。
