# 演示工坊：功能概览与快速开始

演示工坊用于制作固定 16:9 文稿，排版文字、图片与图形，进行放映并导出可继续编辑的 PPTX。作品属于当前 Workspace，普通排版不需要模型。

## 制作第一份文稿

1. 从应用中心进入演示工坊，点击“新建演示文稿”并命名。
2. 从封面开始，或选空白、标题正文、图文双栏等入口。
3. 点击文本框选择，双击进入文字编辑，替换标题和说明。
4. 点击“新建幻灯片”加空白页，旁边版式菜单可创建其他版式。
5. 等待保存完成，打开“放映”检查，再导出 PPTX。

例如三页产品介绍可使用封面、图文双栏和结束页。版式中的内容都是普通元素，允许继续修改，不是固定图片。

## 界面与权限

左侧管理页面，中间编辑画布，右侧“元素”和“页面”分别设置选中对象与页面背景。底部提供备注、缩放与适应页面。

只读成员可以浏览、放映和导出已有文稿，不能修改元素。手机适合轻编辑和调整顺序，精细排版在桌面完成。
