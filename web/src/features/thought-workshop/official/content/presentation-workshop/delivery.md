# 演示工坊：导入导出与交付

要把文稿交给别人放映或继续编辑，先在应用内验收，再导出 PPTX。本篇帮助你选择 PPTX、文稿包或静态图片，预览已有文件的转换结果并创建新文稿。

## 模板与目录交付检查

导出前检查章节标题、页标题和小页码是否与画布一致。目录由章节自动生成，溢出时先添加续页，否则不允许导出不完整的静态内容。标题、页码与固定内容在 PPTX 中展开为可编辑文字、形状和图片，模板规则本身不作为 PowerPoint 母版恢复。

原生 `.fplppt` 包保留模板快照、文稿覆盖、页面语义与全部引用素材。跨空间导入会重新映射素材并解除不可访问的源模板关联；普通 PPTX 导入保留转换后的外观，不会假装恢复工坊模板绑定。

## 导出前准备

确认文稿保存成功，所有图片都能读取，当前没有尚未确认的裁剪操作。提前了解接收方使用的演示软件和可用字体，便于发现换行差异。

## 先做放映检查

1. 点击“放映”从第一页开始，或选择“从当前页放映”检查局部。
2. 用方向键逐页查看标题、正文、图片边缘、层级和留白。
3. 特别检查刚替换图片或修改字号的页面。
4. 按 Escape 退出，修正问题后再保存。

备注和编辑控件不会进入放映画面。编辑器里能看到一个文本框，不代表放映时没有溢出或被其他元素遮挡。

## 导出与验收 PPTX

1. 点击“导出 PPTX”，等待保存；出现差异报告时先阅读，点击“确认转换差异”后导出。
2. 在目标演示软件中打开下载文件。
3. 逐页核对字体、换行、图片比例、备注及可编辑元素。
4. 有差异时回原文稿调整，保存后重新导出。
5. 交接 PPTX，同时保留应用中的原文稿供后续修改。

圆点和编号列表导出为可编辑的原生列表。核对连续编号是否递增、普通段落分隔后是否从 1 重新开始，以及长行是否保持悬挂缩进；每个文本框独立计数。

**完成标志：** 接收环境能打开文件，关键页面内容和排版正确，需要编辑的文字、形状和图片仍可分别选中。

> [!NOTE]
> PPTX 不嵌入字体。接收设备缺字体或排版引擎不同，可能发生字体替换与换行变化。交付前使用接收环境检查，必要时换用双方可用的字体。

## 当前导入与容量范围

| 内容       | 当前支持情况                               |
| ---------- | ------------------------------------------ |
| 图片       | 上传或从当前空间文件库选择                 |
| 自包含 SVG | 先预检再插入；最大 2 MiB、3000 节点        |
| 已有 PPTX  | 预检、逐页预览与差异报告，确认后创建新文稿 |
| 文稿 JSON  | 当前空间结构复用；不携带素材               |
| `.fplppt`  | ZIP 文稿包，携带实际引用素材并重新登记身份 |
| 文稿页数   | 最多 100 页                                |
| 单页元素   | 最多 200 个                                |

文字、形状和图片尽量保持独立，原生形状及 SVG 尽量保留矢量；SVG 还附 PNG 兼容图。SVG 中的滤镜、动画、外部资源不属于当前支持范围。

## 导入一份已有文件

1. 返回文稿列表，点击“导入文稿”，选择 `.pptx`、`.json` 或 `.fplppt` 文件。
2. 等待预检，切换预览页面，对照源文件检查文字、图片、形状、表格和图表。预检不创建项目或文件库素材。
3. 阅读转换报告。母版装饰、未知形状、主题字体、复杂路径、图表外观或原文件动画可能需要重新设置；报告会标出页与对象。
4. 有差异时勾选确认，再点击创建。取消预览可直接关闭；创建期间等待结果，失败时检查项目列表再手动重试。
5. 打开新文稿，检查关键对象是否仍可编辑，保存后重新打开。

**完成标志：** 列表出现新的文稿，原项目没有被覆盖。跨 Workspace 导入文稿包后，图片和媒体属于接收空间，使用新的素材与页面身份。

当前不读取 PPTist JSON 或 `.pptist` 文件，也不会将不支持的整页自动转换为图片。文件最大 100 MiB，展开后的包同样受总量和条目限制；JSON 最大 8 MiB。

## 选择交付格式

| 目标                         | “导出选项”中的格式 | 核对结果                                       |
| ---------------------------- | ------------------ | ---------------------------------------------- |
| 在工坊继续制作，或跨空间交接 | 可编辑文稿包       | 包含文稿、清单、引用素材、公式源码与动画       |
| 在同一空间保存结构           | JSON               | 不含素材文件；其他空间不能直接使用旧素材 ID    |
| 在 PowerPoint 中编辑         | PPTX               | 常用对象可编辑；动画为静态内容，批注留在文稿包 |
| 发送页面图像                 | PNG / JPEG         | 可选当前页或全部页，多页下载 ZIP               |
| 固定页面版式                 | PDF                | 打印窗口选择保存 PDF；检查页数与页面方向       |

图片和打印复用页面渲染器，等待字体与素材；动画输出静态状态，视频使用封面。图片滤镜在 PPTX 中写入像素，原图和可调整滤镜仍在文稿包。公式保留 SVG 与兼容图片，表格和八类图表保留原生编辑对象。

## 导出受阻时

素材缺失先恢复或替换素材；SVG 超限先简化源文件；图片总量或单图像素超限按错误提示缩小输入。导出繁忙时稍后手动重试，不连续点击产生重复请求。

最终 PPTX 用于交付，应用中的原文稿用于继续制作；只有一张页面截图无法恢复独立元素。

## 信息图导出检查

信息图使用演示工坊现有“导出 PPTX”入口。原生文字和基础形状保留为 PowerPoint 对象，连接线及关系文字遵循页面中设置的前后顺序。连续叠放的分组保留原生层级；若组内成员与组外对象交错叠放，PPTX 会展开该组以保留遮挡顺序，应用中的分组不变。两端位于边缘中点的直线和没有显式拐点的折线保留原生连接及端点关联；带显式拐点的折线，以及端点位于边缘非中点的连接，导出为可编辑自由曲线，保留路径、箭头和标签，但移动节点后不会自动跟随，需要单独调整路径。复杂装饰继续使用独立 SVG 或图片。参考图不导出。

交付前在接收工具中修改一段文字、移动一个矩形节点、解组并选择成员，再单独替换一张素材。检查普通连接是否跟随节点、自由曲线的拐点是否与原稿一致，以及字体和换行是否符合预期。文件应直接打开，无需修复，各页内容完整；不能只凭文件结构校验判断实际编辑效果。

**完成标志：** 接收方能够修改关键结构，参考图没有混入演示内容，下载的是保存最新版本后重新导出的文件。
