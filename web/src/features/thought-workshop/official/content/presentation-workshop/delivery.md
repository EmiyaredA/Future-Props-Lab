# 演示工坊：导入导出与交付

## 放映检查

点击“放映”从第一页开始，或选择“从当前页放映”。方向键翻页，Escape 退出。逐页检查文字溢出、图片比例、层级与留白，备注和编辑控件不会进入放映画面。

## 导出 PPTX

1. 确认当前修改已保存；裁剪尚未确认时先完成或取消。
2. 点击“导出 PPTX”，等待保存和导出完成。
3. 在目标演示软件中检查全部页面、字体、图片和备注。
4. 交接可编辑 PPTX，并保留应用中的原文稿用于后续修改。

文字、图形和图片保持独立。原生形状与 SVG 尽量保留矢量，SVG 另附 PNG 兼容图。导出不嵌入字体，接收设备缺字体时会替换，可能影响换行。

## 导入与容量

目前支持图片和受限自包含 SVG 素材导入，不支持把已有 PPTX 导入成文稿。自定义 SVG 最大 2 MiB、3000 节点；超限先在矢量软件简化。

文稿最多 100 页，每页最多 200 个元素。导出图片有总量与单图像素限制，超限会返回明确错误。遇到导出繁忙稍后手动重试；素材缺失先恢复或替换，不反复点击导出。
