# 演示工坊：常见问题与能力边界

## 图片为何仍被裁切

图片按比例填满框。把四边裁剪清零只是恢复完整原图参与填充，不同比例的图片框仍会隐藏部分边缘。想完整展示原图，调整框比例并检查预览。

## 为什么修改没有作用

先检查元素是否锁定、是否选中正确对象，以及是否正在编辑文字。整框格式和文字选区格式范围不同。多个元素显示混合状态时，核对实际选区后再改。

## 导出后字体或换行变化

PPTX 不嵌入字体。接收端缺字体或排版引擎不同可能产生变化；在实际交付环境打开，必要时换用共同可用字体并重新导出。

## 保存冲突怎么处理

不要连续覆盖提交。先保留本地内容，比较服务器版本，选择载入或另存副本。导出前解决冲突，避免误交付旧稿。

## 当前边界

不提供 PPTX 导入、AI 生成文稿、图表、表格、页面动画或多人实时协作。可以使用文字、图形和图片完成版式；复杂表格或图表可准备外部素材后导入，但不会成为可编辑表格对象。

手机可选择文本后编辑、填写备注和调整页面顺序；桌面拖动裁剪与精细操作不应按手机界面推断。
