# 演示工坊：常见问题与能力边界

文稿看起来不对时，先判断问题出在编辑选区、图片填充、保存状态，还是接收软件。保留当前文稿，按下面顺序处理，避免通过反复重建页面掩盖原因。

## 开始排查前

确认当前 Workspace、文稿和页面；记录问题只出现在编辑器、放映还是导出的 PPTX。修改前先查看保存状态，有未保存内容时先保留草稿。

## 按现象处理

| 现象                     | 可能原因                     | 处理步骤                                                       |
| ------------------------ | ---------------------------- | -------------------------------------------------------------- |
| 清零裁剪后图片仍缺边缘   | 图片按比例填满不同比例的框   | 查看原图，调整图片框比例，再核对填充结果                       |
| 修改字号影响了整框       | 只选中框，未进入文字编辑     | 双击文本，选择需要的文字后再设置                               |
| 点击时总是选中整组       | 当前仍在组合外层             | 选中整组后再单击目标，嵌套组合逐层点击；单独选中文字后双击编辑 |
| 文字格式按钮显示混合状态 | 选区中含不同格式或多个元素   | 确认选中范围，再统一所需属性                                   |
| 元素无法拖动或删除       | 元素锁定，或焦点仍在文字编辑 | 退出文字编辑，检查并解锁正确元素                               |
| 替换图片后构图改变       | 替换保留外观但重置裁剪       | 重新进入裁剪并检查比例与位置                                   |
| PPTX 字体或换行变了      | 接收方缺字体或排版引擎不同   | 在交付软件核对，换共同字体后重导                               |
| 保存提示冲突             | 服务器版本已更新             | 保留本地内容，选择载入服务器版本或另存副本                     |
| SVG 无法插入             | 文件含不支持内容或超出限制   | 转换文字为路径，移除外部资源并简化文件                         |
| 备注在放映中看不到       | 备注不是放映画面元素         | 需要观众看到的内容放到页面文本框                               |

## 修复后怎样确认

1. 在编辑器重新选择目标元素，确认属性已改变。
2. 等待保存完成，放映检查相关页面及相邻页。
3. 若问题涉及交付，再导出新 PPTX，并在目标软件打开。
4. 不再使用修复前的旧下载文件作验收。

> [!TIP]
> 一次只调整一种原因，例如先修字体，再修图片比例。这样能确定是哪一步解决了问题。

## 当前能力边界

支持文字、图片、形状、受限 SVG、页面管理、备注、放映和 PPTX 导出，也支持五类信息图代码转换、分组、节点连接、自动布局和参考图对照。转换结果在原画布编辑，由工坊统一导出；复杂装饰可能保留为 SVG，不能因此逐路径编辑。

当前不提供 PPTX 导入、应用内 AI 生图、OCR 自动重建、背景擦除、原生图表、表格、页面动画或多人实时协作。信息图首轮支持模板与 data，不支持自定义设计、主题和外部图标资源；可以转换后在工坊调整样式和插入托管素材。字体仍使用已有字体选项，缺失时检查会提示替代。

复杂表格或图表可以先在外部准备成图片或兼容矢量素材，再插入文稿；它们不会因此成为应用内可逐格编辑的表格对象。

手机适合选择并编辑文字、填写备注和调整页面顺序。精细拖动、旋转与裁剪建议在桌面完成，不必把移动端界面缩到难以操作。

## 更新后旧文稿为什么没有变色？

新配色只用于新建模板和新生成的信息图。已有页面到“页面 → 应用蓝青风格”预览后手动应用；默认保留未知颜色，图片和 SVG 不会被重新着色。取消不修改页面，应用后可以撤销。找不到连接、分组、参考图或检查页面时，打开工具栏“更多”。
