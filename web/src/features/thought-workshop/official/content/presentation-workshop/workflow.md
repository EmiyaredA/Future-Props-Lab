# 演示工坊：主要操作流程

本篇以“把一页图文介绍排整齐”为例，说明选中、编辑、裁剪与对齐的顺序。开始前打开可编辑文稿，并准备一段文字和一张图片。

## 用模板统一整份文稿

1. 打开“模板与示例 → 新建模板”，填写名称。在左侧切换封面、目录、章节过渡、内容页和结束页。缩略图序号位于画面外，中央画布显示当前页型的真实布局。
2. 单击对象后拖动位置、拖动边框手柄缩放，拖动旋转手柄调整角度；右侧坐标、大小和旋转数值同步变化。Shift 多选或在空白处框选，工具栏提供编组、解组、连接、对齐与等距分布。方向键微调 1 像素，Shift + 方向键微调 10 像素，Escape 取消当前手势；撤销一次可还原整次拖动。
3. “新增对象影响范围”选择全局固定、页型固定或正文默认，再添加文字、形状、图片／Logo。选中后右侧说明影响范围；全局固定对象可勾选适用页型。章节签的底板、文字与装饰可编为一组移动。
4. 动态章节、页标题、页码和目录的文案来自文稿。设计器调整其位置、字体、颜色和显示开关，不用示例文字替换真实数据。删除动态对象只隐藏槽位，可在对象列表选中后恢复显示。单击画布空白处配置背景、全局字体、强调色及编号规则；默认页码 14 号，封面隐藏但仍计数。
5. 保存模板后返回列表“使用模板”。新页复制对应页型的默认正文，固定层由模板解析。既有页面正文不会自动跟着模板布局移动。文稿中“文稿模板 → 编辑模板布局”只改当前稿的覆盖设置，应用后可整体撤销；不会保存到库中模板。
6. “文稿模板”设置当前页标题、页型与章节。章节改名、重排、增删后，章节标题、目录与起始页同步更新；目录容量不足时添加目录续页，不会自动缩小字号或截断。模板固定层不能在普通画布误删，双击动态标题进入内容设置。

**完成标志：** 保存重开后五种页型的真实对象、分组和动态关联仍在；改变一次全局样式后，适用页面保持一致，正文与备注保留。

## 更换或更新模板

旧稿首次绑定需在“文稿模板”中逐页确认标题文字对象、页标题、章节及页型。只有勾选的文字会转换成模板标题；分组或关联连线尚未解除时，会提示先处理关联。未选择的正文不会自动删除或移动。

保存模板不会静默改变已有文稿。选择模板后“预览模板更新”或“预览套用模板”，核对变化、受影响页和正文重叠提示，再确认应用；若文稿或模板版本已变化，需要重新预览。更换模板不调整正文位置，标题与正文冲突需要人工调整。解除绑定前同样预览，确认后模板内容变成普通可编辑对象。

需要改变已有正文时，在“正文版式 · 预览后应用到指定页”选择页面和目标页型，逐一将正文对象映射到同类型默认对象。未映射内容保持原样，不插入示例文案。默认只调整位置、尺寸、旋转和翻转；“同时同步文字样式”默认关闭。预览列出移动对象、未匹配内容、重叠及越界，确认后一次应用、一次撤销。文稿或目标模板 revision 变化后必须重新预览。

**完成标志：** 绑定显示所用模板版本；更新后正文、素材、备注与文稿覆盖仍在。源模板删除后，文稿依靠快照继续打开与导出。通过“另存为示例”保存完整快照，再在模板库“基于示例新建”得到独立文稿。

## 先确认格式会作用在哪里

1. 单击文本框只选中整个元素；此时格式操作影响整框。
2. 双击进入文字编辑，再选择一段文字；此时格式作用于文字选区或后续输入。
3. 用悬浮工具栏设置常用格式，精确位置、尺寸、旋转等参数到右侧“元素”面板调整。
4. 多选出现混合状态时，先核对选区，再统一设置。

**完成标志：** 只有预期对象或文字范围发生变化。若改字号后整框都变了，先检查是否真正进入文字编辑。

## 框选多个元素

1. 从幻灯片内部空白处或页面外的灰色留白处按住鼠标拖动，用选框完整包围需要操作的元素；反向拖动也可以。
2. 背景形状或图片覆盖了空白位置时，先点工具栏“框选”，再从画布任意位置拖动。松手后自动回到普通选择，可抓住所选元素一起移动；按住 Shift、Ctrl 或 ⌘ 拉框会追加到原选区。
3. 分组按完整对象判断，选框需要包围其全部可见范围；进入分组后用“框选”只选择该组内对象。旋转元素按旋转后的范围判断，隐藏元素不单独作为框选命中目标，分组中的隐藏成员沿用整组选择；锁定对象和含锁定成员的组合需要先解锁。
4. 按 Escape 取消本次框选并恢复原选区。窗口失焦、指针取消和拖动中撤销也取消预览。只读文稿没有框选编辑工具；窄屏可点“框选”后用触控拖动，普通触控滚动保持原行为。

**完成标志：** 两个目标对象出现同一个选择范围，右侧显示多个元素；拖动其中一个时一起移动，一次撤销恢复位置。框选本身不改变文稿内容、不触发保存、不增加撤销步骤。放大并滚动画布后框选仍对应相同对象。

## 将正文设为列表

1. 单击文本框，在右侧“元素”面板的“列表类型”选择“项目符号”或“编号列表”；文字悬浮工具栏也提供同名选项。整框选择会修改全部段落。
2. 只改部分内容时，双击文字，将光标放在目标段落或选择多个段落，再切换列表类型；跨段落类型不一致时控件显示“混合”。选择“无列表”恢复普通段落。
3. 按 Enter 新建下一项；在空项再按 Enter 退出列表。Shift+Enter 在当前项内换行，不增加编号。
4. 保存后重新打开，并在放映与导出的 PPTX 中核对圆点、编号和换行。

**完成标志：** 连续编号从 1 递增，普通段落或项目符号分隔后的新编号段从 1 开始；长行换行后正文保持悬挂缩进。PPTX 中保留可编辑的原生列表。目前支持单层圆点与十进制编号。

## 排列元素

1. 拖动元素靠近其他对象的边缘或中心，确认出现对齐线并吸附；同一行或列的对象间距接近一致时，会显示两段等距线和间距数值。吸附距离按屏幕像素计算，放大后仍可精细操作。
2. 拖动八方向手柄调整大小，靠近参考对象的边缘、宽度或高度时，检查对齐线或“同宽／同高”提示。图片与矢量图保持比例，Shift 可约束普通对象比例；不相容的宽高目标不会同时吸附。圆形手柄用于旋转，Shift 约束旋转步长。
3. 按住 Alt 临时关闭吸附，辅助线立即消失；松开后继续拖动恢复吸附。按 Escape 取消本次拖动或缩放。输入精确数值和方向键微调不触发吸附。
4. Shift 点击或框选多个对象，在右侧“元素”面板或悬浮栏“对齐”菜单执行对齐、分布或统一尺寸。分布至少需要三个对象，统一尺寸至少需要两个。
5. 统一宽度、高度或宽高以首个选中对象为基准，右侧显示其名称与尺寸；框选按文稿对象顺序确定基准。取消选择基准后，剩余选区的首个对象成为新基准。统一尺寸保留对象中心、旋转和文字字号；图片与矢量图统一宽度或高度时等比缩放，统一宽高会改变比例时按钮禁用并说明原因。

未进入分组时，整个分组作为一个对象排列和吸附，内部间距随整组尺寸变化；进入组内后只参考同级对象与当前组边界。多选对齐以所选范围为边界，单选对齐当前页面或分组边界。含图片、矢量图或旋转成员的分组优先等比缩放。锁定对象可作为参考，但选区含锁定成员时需要先解锁才能执行排列命令。

**完成标志：** 图文边缘、间距或尺寸达到预期；整组对齐不会把成员堆叠在一起。一次手势或排列命令可以一次撤销，保存并重新打开后位置与尺寸保持一致。辅助线仅在编辑时显示，不进入放映或 PPTX。

## 放大查看页面细节

1. 把鼠标放在中间画布要查看的位置，捏合触控板，或按住 Ctrl／⌘ 滚动滚轮。页面围绕鼠标位置连续缩放，底部显示实际比例，手动范围为 25%–200%。
2. 也可用底部加减按钮或滑条调整，每步 5%；这些控件以可视区域中心缩放。放大后用双指滑动、普通滚轮或画布滚动条查看其他位置。
3. 点击底部“适应页面”，确认整页重新居中显示；调整窗口、侧栏或展开备注后，适应模式会重新计算比例。

**完成标志：** 小字和图形细节随画布放大，顶部工具栏和左右面板尺寸保持原样。只读文稿也可缩放。拖动、旋转、框选及图片裁剪期间暂停手势缩放，结束后再调整。缩放不改变元素坐标，不触发保存或撤销；重新打开文稿默认适应页面。

## 插入和编辑数学公式

1. 点击工具栏“公式”，或“更多 → 插入公式”。弹窗左侧提供分数、上下标、根号、求和、积分和矩阵模板，右侧显示预览与 LaTeX 输入。新建公式默认是 `E = mc^2`。
2. 将光标放在需要的位置再点结构模板；若先选择文字，模板会使用选中文字。点击“余弦相似度”会替换整条公式，不会立即修改画布。
3. 输入完成后等待预览更新，调整颜色和 6–240 范围内的字号。预览成功后点击“插入公式”；已有公式使用“应用修改”。空公式和语法错误不能提交，上传失败会保留输入供重试。
4. 单击选中公式后可移动、缩放和旋转；双击未锁定公式，或在右侧“元素”面板点击“编辑内容与数据”，可重新编辑。分组中的公式先进入组内选中。取消只放弃弹窗草稿，整次应用可以一次撤销。
5. 保存并重新打开，核对源码、颜色、字号和位置；放映检查显示，导出 PPTX 后检查公式清晰度。修改字号会按已有缩放比例调整公式框；新公式超出页面时等比缩小。

**完成标志：** 画布、放映与导出的公式形状一致，重新编辑时仍可读取 LaTeX。PPTX 中公式以矢量图和兼容图片保存，可在工坊导回后继续编辑；PowerPoint 中不能使用原生公式编辑器修改。只读文稿和锁定公式不能修改。

## 给代码添加语法高亮

新建代码块时，点击工具栏“代码块”，输入代码、选择语言、字号和浅底或深底配色，预览后点击“插入代码块”。新块包含背景、语言标签与代码文字，默认编为一组；可整体移动，进入分组后单独修改代码或外观。超出页面容量时先换行、减小字号或拆块，工坊不会截断代码。

1. 结束文字编辑，单击选中代码文本框，在右侧“元素”面板点击“代码高亮”。只读文稿和锁定元素不可应用。
2. 选择 JSON、YAML、Python、HTML 等对应语言，核对代码内容。按代码所在区域的底色选择浅底或深底文字配色；此操作不更换背景。
3. 在“高亮预览”核对关键字、属性、字符串、数字和注释的颜色，点击“应用高亮”。取消会保留原文本，应用后的整次修改可撤销。
4. 检查文本框高度和长行是否越界，保存后放映或导出 PPTX 核对。超出 12000 字或 150 行的代码需要拆成多个文本框。

**完成标志：** 代码仍可双击编辑，导出 PPTX 后保留分段颜色与等宽字体。高亮保留为文字格式；继续修改代码后，需要再次应用高亮以更新语法颜色。行号和终端边框可使用独立文本与形状制作。

## 放入并裁剪图片

1. 上传图片或从当前账号文件库选择，确认选中的是图片框。
2. 打开裁剪，选择自由、原比例或常用比例，拖动图片与手柄调整可见范围。
3. 用原图预览核对完整内容，按 Enter 完成；不满意时按 Escape 取消。
4. 退出裁剪后检查图片框位置、比例和周围留白。

更换图片会保留框的位置与外观，但重置裁剪，因此替换后要再次检查。

> [!NOTE]
> 图片等比填满图片框。四边裁剪清零，表示完整原图参与填充；如果框与原图比例不同，部分边缘仍可能被遮住。想完整显示原图时，先调整框比例。

## 使用图标和 SVG

图标面板支持搜索，单色矢量可以改色。导入自定义 SVG 时先看预检，再确认插入。素材需自包含，文字建议先转路径；滤镜、动画与外部资源不支持。

SVG 预检失败时回原矢量工具简化，不要反复导入同一个不兼容文件。

## 按视觉稿重建信息图

1. 从工具栏“更多”打开“参考图”，从文件库选择或上传页面视觉稿。选择“并排对照”或“透明叠加”，按需调整透明度。
2. 打开“信息图”，选择步骤、时间线、对比、层级或关系图，修改 AntV 源码中的 data，也可以切换到工坊场景 JSON。
3. 点击“预览转换结果”，检查文字、节点和连接。复杂装饰会明确标为独立 SVG；不支持的模板或关键内容转换失败时不能应用。
4. 点击“应用到当前页”。在原画布调整原生文字、形状与图片：第一次单击选中整个信息图，再单击目标逐层进入分组，直到选中需要修改的对象。
5. 需要改变生成数据时，选择完整信息图，打开“编辑信息图源码”，先预览再“应用更新”。这会替换该信息图的手动调整，可用一次撤销恢复。

**完成标志：** 文字能够直接编辑，节点能单独选中，保存并重新打开后布局不变。参考图仅用于对照，不会进入放映或 PPTX。此功能不执行 OCR，也不会自动识别或擦除视觉稿中的文字。

## 编组、节点连接与自动布局

连接、编组、自动布局、参考图与检查页面统一位于工具栏“更多”菜单。多选两个以上未锁定元素，点击“编组”；选择完整分组后可以解组或进入分组。点击“退出分组”返回上级。复制完整信息图会同时复制组、连接与来源，删除节点会移除关联连接。

1. 单击组合内任意对象，确认选区包围整组；再单击目标进入下一层。嵌套组合需要继续逐层点击，画布上方会显示当前分组名称。
2. 选中单个对象后，调整位置或属性；文字需在单独选中后双击编辑。用于进入分组的快速双击只改变选择，不直接输入文字。
3. 拖动操作当前选区：整组选中时移动整组，成员选中时只移动该成员。缩放、旋转手柄不会进入分组；Shift、Command、Ctrl 多选也不会进入。
4. 点击画布上方的“退出分组”，或在画布上按 Escape，返回上一级并选中刚退出的组合。文字编辑中的 Escape 先结束文字编辑，拖动中的 Escape 先取消拖动。
5. 点击画布空白退出全部分组并清空选择；点击当前组外对象回到顶层选择。锁定成员可以选中，但不可修改。

**完成标志：** 单独移动一个成员后，其余成员位置不变；退出分组仍可移动整组。仅切换选择不触发文稿保存，重新打开从页面层级开始。

1. 点击“连接节点”，在右侧“元素”面板选择起点、终点和四侧端口；也可选择“自由端点”，输入 X、Y 坐标。画布实时显示预览，点击“创建连接”加入文稿；关闭面板会取消尚未创建的预览。
2. 点击已有连线，在面板调整直线／折线、箭头、颜色、粗细或关系文字，画布立即更新，无需再次点击应用。面板的“层级”支持“置于顶层”“上移一层”“下移一层”“置于底层”，可让连线穿到形状、文字前方或后方，也可调整连线之间的顺序；到达顶层或底层时，对应按钮禁用。新连接创建后可调节层级。起终点设置位于“连接端点”折叠区，不能连接同一个节点。
3. 选中连接后，属性固定在右侧“元素”面板，不遮挡画布。颜色、粗细、关系文字、层级与端点设置在同一处调整；窄屏通过“格式”面板访问，内容可滚动。
4. 关闭面板保留已有连接的修改；撤销／重做可恢复调整。Escape 先关闭下拉或选色器，再关闭面板并回到画布。点击画布空白、选择元素或切页也会关闭面板。
5. 选中已有连线，拖动端点圆形手柄到目标元素的边缘；高亮边框与实心吸附点表示将要连接的位置。四条边都支持任意位置，例如“填充后的页面”panel 左边缘的上方，不限于中点。panel 与标题、正文编为一组时，仍可直接连接其背板边缘；连接目标是背板元素。松手处没有吸附目标时，端点留在该自由坐标；不会绑定到另一端的同一节点。靠近边缘中点 5 屏幕像素时会吸附到正中。
6. 折线显示拐点和线段中点手柄：水平段上下移、竖直段左右移，拖动拐点联动相邻走线，两端保持连接。按住 Shift 拖动线身限定水平或垂直方向。自由端点靠近另一端的同一水平线／垂直线（8 屏幕像素内）自动对齐，节点边缘绑定优先。拖动线身可让整条线自由移动：两端脱离节点，折点随线一起平移；直线的中点手柄也用于整线移动。直线始终是直线。拖拽不会改变线型，只有面板“直线／折线”按钮会切换类型。
7. 聚焦端点手柄后，沿边方向键每次移动 1%，Shift 每次移动 10%；垂直于边的方向键切换连接点。折线手柄方向键每次调整 1 个文稿像素，Shift 调整 10 个。自由端点与线身可用方向键每次移动 1 像素、Shift 每次 10 像素；已绑定端点仍按边缘精调。也可展开“连接端点”，输入自由端点 X、Y 或“沿边位置（%）”精调；左右边从上到下计数，上下边从左到右计数。
8. 移动、缩放或旋转节点时，端点按边缘上的相对位置跟随，手调路径保留内部走线并调整端部；两端等量移动时路径整体平移。修改端点、端口或线型会重新计算路径；仅改外观保留路径。“重置走线”清除手调路径，恢复自动连接。
9. 一次拖拽只产生一步撤销；Escape、指针取消或切页会取消尚未松手的预览。拖动时按撤销只取消当前预览。路径超出坐标或 32 个路径点限制时提示简化路径，不提交无效结果。

点击“自动布局”明确重新排列有连接的节点；布局不在打开菜单或重新进入页面时运行。超出页面可用区域会保留原布局并提示拆页，锁定节点需先解锁。

**完成标志：** 拖动线身后两端与折点等量平移，保存重开位置不变，一次撤销恢复原来的绑定和走线。连接设置只出现在“元素”面板。将端点接到 panel 左侧 20% 处，保存重开后仍在该位置；移动或缩放 panel 后端点保持相同比例。拖动一个节点后关系仍连接正确，撤销能恢复整次操作，复制后的连接只引用新对象。将一条连线置顶后，重叠处显示在元素上方；保存重开及放映仍保留该顺序。层级调整不会重算连线路径。

## 给当前页应用蓝青风格

新建版式与五类信息图使用统一的蓝青色板。更新应用不会自动改变旧文稿；已有页面可以手动换肤。

1. 结束文字编辑或图片裁剪，在右侧选择“页面”，点击“应用蓝青风格”。窄屏先切换“文字与格式”面板。
2. 核对当前页预览及“颜色替换”：内置颜色自动匹配，其他颜色默认保留。可逐项选择替换色，警示色与品牌色需要特别核对。
3. 点击“取消”关闭时，页面不产生修改。确认后点击“应用到当前页”，整次操作可用一次撤销恢复，也可重做。
4. 等待“已保存”，重新打开页面，再放映或导出检查。

**完成标志：** 配色和圆角变化，文字、字号、位置、层级与连接关系保持原样。锁定元素及其关联连接、图片、SVG、参考图和归档图像不会换肤。只读或裁剪期间不可应用。换肤不自动重排内容，也不解决文字溢出。

## 整理页面与检查

左侧页面可以拖动排序，也可通过上移、下移、复制或删除操作整理，至少保留一页。备注会保存到文稿，但不在放映画面显示。

放映时逐页检查，尤其看修改后的换行、图片边缘和重叠层级。缩放只改变编辑视图，不改变 PPTX 页面坐标。

“检查页面”会列出文字溢出、越界、素材失败、连接缺失和当前设备字体替代问题，点击条目定位对象。修改后点击“重新检查”；检查不会自动缩小字号或改写文案，目标 PowerPoint 中的显示仍需单独核对。

## 键盘操作

选中元素后按 Alt+F10 进入悬浮工具栏，使用方向键和 Enter 操作。Escape 按当前状态关闭菜单、取消拖动、退出文字编辑、返回上一级分组，或在页面层级清空选区；操作前留意当前焦点。

## 紧凑工作区与页面设计

左侧缩略图切页，中间工具栏插入对象，右侧按“页面、元素、图层、动画、批注”分类。标签支持左右方向键切换；画布右键打开编辑菜单，菜单中显示快捷键。

1. 无选区时打开“页面”，设置分节名称和背景类型，在“页面尺寸”选择预设或输入宽高；网格与标尺只辅助当前视图。
2. 按 Ctrl/Cmd 或 Shift 点击缩略图选择多页，再用页列表的批量按钮复制、移动或删除。批量修改可一次撤销。
3. 打开“图层”，修改名称、显示、锁定和顺序。隐藏后画布、缩略图、放映和 PPTX 不再显示该元素，源对象仍保留。
4. 点击“查找”或 Ctrl/Cmd+F 搜索文字与备注；替换跳过锁定元素，全部替换整体进入历史。

通过“更多 → 提取当前页版式／提取当前页风格”保留本次会话的模板快照；“插入提取的版式”复用元素排布，新建页面沿用已提取风格。跨项目长期复用时保留原模板页并导出文稿包，导入后可重新提取。

**完成标志：** 页面尺寸改变后画布保持对应比例，保存重开仍保留分节、背景及隐藏状态；缩放、网格、标尺和选区不改变保存内容。

## 插入和编辑新对象

1. 在“更多”选择“插入表格”“插入图表”“插入公式”“插入视频”或“插入音频”。
2. 在弹窗调整内容与预览，点击“应用”插入；公式使用“插入公式”或“应用修改”。取消不会修改页面。桌面上的图表与表格左侧显示预览，右侧编辑数据和样式；窄窗口自动上下排列。长数据在表格内滚动，底部操作按钮保持可见。双击对象或使用元素面板的编辑内容入口重新打开。
3. 表格可选择单元格，Shift 选择矩形范围后合并；行列操作会拆分现有合并。图表提供柱、条、折线、面积、散点、饼、环、雷达，散点横坐标必须为数字。
4. 公式支持模板与选区插入，预览成功后将同一份 SVG 上传到当前账号，具体见“插入和编辑数学公式”；音视频从当前账号文件库选择，可设置视频封面、自动播放与循环。
5. 文字和形状的“高级外观与文字”提供高亮、删除线、上下标、缩进、段间距、竖排、内边距和阴影；图片提供滤镜、着色与形状裁剪。

**完成标志：** 保存重开后，对象内容和样式一致，图表数据与公式源码仍可修改。浏览器限制自动播放时，在放映页面点击播放。

## 放映与演讲者工具

在“动画”中为选中元素添加效果，设置顺序、时长与单击／同时／上一动画之后触发。编辑、缩略图与静态导出不运行动画。

1. 从头或从当前页放映，右方向键推进动画步骤和页面；左方向键回退。
2. 打开“备注与计时”查看当前备注、下一页和已用时；“总览”提供缩略图跳转，“自动”启用定时推进。
3. 点击“打开观众窗口”，将新窗口移至投影屏。浏览器需允许弹出窗口；桌面版使用应用的受控演示窗口。
4. 选择激光笔、画笔、荧光笔、箭头、矩形或橡皮擦，必要时切换黑板。标注属于当前放映，不写入文稿。
5. Escape 退出。退出登录、切换账号或结束演示会终止窗口同步与媒体。

**完成标志：** 观众窗口同步当前页面、动画步骤及临时标注，演讲者备注只在主窗口显示。
