# 演示工坊：主要操作流程

本篇以“把一页图文介绍排整齐”为例，说明选中、编辑、裁剪与对齐的顺序。开始前打开可编辑文稿，并准备一段文字和一张图片。

## 先确认格式会作用在哪里

1. 单击文本框只选中整个元素；此时格式操作影响整框。
2. 双击进入文字编辑，再选择一段文字；此时格式作用于文字选区或后续输入。
3. 用悬浮工具栏设置常用格式，精确位置、尺寸、旋转等参数到右侧“元素”面板调整。
4. 多选出现混合状态时，先核对选区，再统一设置。

**完成标志：** 只有预期对象或文字范围发生变化。若改字号后整框都变了，先检查是否真正进入文字编辑。

## 排列元素

拖动元素移动，用边缘手柄缩放、圆形手柄旋转。Shift 用于约束比例或旋转步长，Alt 可临时关闭吸附。

把图文排成两列时：先大致放置 → Shift 点击或框选多个元素 → 执行对齐或分布 → 检查层级 → 再微调间距。锁定元素需要先解锁，才可以移动或删除。

## 放入并裁剪图片

1. 上传图片或从当前空间文件库选择，确认选中的是图片框。
2. 打开裁剪，选择自由、原比例或常用比例，拖动图片与手柄调整可见范围。
3. 用原图预览核对完整内容，按 Enter 完成；不满意时按 Escape 取消。
4. 退出裁剪后检查图片框位置、比例和周围留白。

更换图片会保留框的位置与外观，但重置裁剪，因此替换后要再次检查。

> [!NOTE]
> 图片等比填满图片框。四边裁剪清零，表示完整原图参与填充；如果框与原图比例不同，部分边缘仍可能被遮住。想完整显示原图时，先调整框比例。

## 使用图标和 SVG

图标面板支持搜索，单色矢量可以改色。导入自定义 SVG 时先看预检，再确认插入。素材需自包含，文字建议先转路径；滤镜、动画与外部资源不支持。

SVG 预检失败时回原矢量工具简化，不要反复导入同一个不兼容文件。

## 整理页面与检查

左侧页面可以拖动排序，也可通过上移、下移、复制或删除操作整理，至少保留一页。备注会保存到文稿，但不在放映画面显示。

放映时逐页检查，尤其看修改后的换行、图片边缘和重叠层级。缩放只改变编辑视图，不改变 PPTX 页面坐标。

## 键盘操作

选中元素后按 Alt+F10 进入悬浮工具栏，使用方向键和 Enter 操作。Escape 用于关闭菜单、退出文字编辑或清空选区；操作前留意当前焦点，避免误以为已经结束全部编辑状态。
