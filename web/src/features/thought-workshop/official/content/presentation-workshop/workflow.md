# 演示工坊：主要操作流程

## 文字与元素

用顶部入口插入文本、形状或图片。选中元素后，悬浮工具栏提供常用格式，右侧面板提供位置、尺寸、旋转和其他精细参数。

编辑文本时，格式作用于文字选区或后续输入；没有进入文本编辑时，格式作用于整个文本框。多种格式同时选中会显示混合状态，操作前确认范围。

拖动元素移动，使用边缘手柄缩放、圆形手柄旋转。Shift 约束比例或旋转步长，Alt 临时关闭吸附。Shift 点击或框选多个元素后，可对齐、分布和调整层级。锁定元素需先解锁才可移动或删除。

## 图片、图标与 SVG

图片可以上传或从当前空间文件库选择。更换图片保留框的位置与外观，但重置裁剪；原图预览用于检查完整素材。

裁剪时拖动图片和手柄，选择自由、原比例或常用比例，Enter 完成、Escape 取消。四边百分比调整原图可见范围，图片仍等比填满图片框。重置裁剪不保证原图所有边缘都能进入不同比例的框。

图标面板支持搜索，单色矢量可改色。自定义 SVG 先预检再确认插入；应自包含，文字先转路径，滤镜、动画和外部资源不支持。

## 页面、备注与键盘

左侧页面可拖动排序，也能上移、下移、复制或删除，至少保留一页。备注保存到文稿，但放映不显示。缩放只影响视图。

选中元素按 Alt+F10 进入悬浮栏，用方向键和 Enter 操作。Escape 依次关闭菜单、退出文字编辑和清空选区。
