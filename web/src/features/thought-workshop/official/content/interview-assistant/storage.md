# 面试助手：材料和练习分别保存

本篇说明面试助手的实际操作、可验证结果和数据边界，帮助你在当前账号中完成操作后确认保存状态。

## 操作与核验

房间、只读上传材料、准备任务及结构化资料由后端按当前账号持久化；内容更新使用版本校验，不覆盖其他窗口保存的新版本。查看历史时先确认当前房间和任务标识。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 保存与能力边界

练习回答和文字规则复盘只在当前页面保留，刷新或离开前需要导出所需报告。页面中的音视频状态不代表真实通话录制。要删除房间请通过正式界面或 API，不直接删素材目录、修改 SQLite 或合并其他账号的数据。

> [!NOTE]
> 本机应用与公网浏览器访问同一部署时使用相同账号隔离规则。来源绑定等桌面私有能力只能在已验证的桌面传输中执行；公开地址不会扩大账号权限。
