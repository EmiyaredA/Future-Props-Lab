# 面试助手：连接、失败和模拟边界

本篇说明面试助手的实际操作、可验证结果和数据边界，帮助你在当前账号中完成操作后确认保存状态。

## 操作与核验

连接不可用时在「模型与智能体 → 编程智能体」核对本机 Codex 路径、登录和面试用途授权，再点击重新检查。来源检索失败或材料不完整时应查看任务说明，补全材料后手动重新准备。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 保存与能力边界

应用不代替真实面试官，复盘为文字规则反馈，音视频为示意。外部检索结果可能过期，核验日期、来源和版本后再使用。已提交任务中断后不会自动重放；禁止通过改数据库或复用他人任务 ID 绕过失败和账号检查。

> [!NOTE]
> 本机应用与公网浏览器访问同一部署时使用相同账号隔离规则。来源绑定等桌面私有能力只能在已验证的桌面传输中执行；公开地址不会扩大账号权限。
