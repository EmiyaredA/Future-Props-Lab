# 面试助手：导出结构化资料和报告

本篇说明面试助手的实际操作、可验证结果和数据边界，帮助你在当前账号中完成操作后确认保存状态。

## 操作与核验

准备完成后可下载 Markdown 或 JSON 资料，核对岗位、来源与题目内容。Markdown 便于阅读，JSON 保留结构化字段；下载文件不改变本场准备任务，也不代表已保存后续练习回答。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 保存与能力边界

完成文字练习后先查看复盘，再导出需要保留的报告。转发前检查 JD、简历、经历和来源中的个人信息，接收者不会因此得到账号内房间权限；如果浏览器下载失败，保留当前页面，手动重新操作，不重复提交准备任务。

> [!NOTE]
> 本机应用与公网浏览器访问同一部署时使用相同账号隔离规则。来源绑定等桌面私有能力只能在已验证的桌面传输中执行；公开地址不会扩大账号权限。
