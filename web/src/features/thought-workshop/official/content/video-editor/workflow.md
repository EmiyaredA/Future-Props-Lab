# 视频剪辑工坊：主要操作流程

本篇以“两个镜头加字幕与声音”为例，说明时间线编辑、批量操作和预览检查。开始前已有可编辑工程和能读取的素材，先确认当前选中的片段。

## 把素材放到正确轨道

1. 双击素材，放入兼容轨道。
2. 移动片段确定开始时间，裁切头尾保留需要的范围；需要拆开时分割，再删除不需要部分。
3. 在右侧检查器调整位置、尺寸、裁剪、速度、透明度或声音等适用参数。
4. 把播放头放到片段前后，检查切点和相邻镜头。
5. 等待保存后再做精确帧或导出检查。

**完成标志：** 时间线位置和源入点正确，片段变化没有误影响其他选中内容，声音与画面仍同步。

## 多选、复制和批量修改

框选或组合选择后可整组移动，保留相对时间。跨轨操作仍会检查类型、重叠和锁定条件。

Ctrl/Cmd+C 复制，Ctrl/Cmd+V 在播放头附近粘贴。副本不继承原关联组，所以复制音画组合后应重新检查相对起点、源入点、变速和同步。

批量检查器可暂存属性，再一次应用。提交前核对选中数量与适用片段；不要只看其中一个片段就确认全部修改正确。

> [!NOTE]
> 片段剪贴板只在当前工程会话使用，不用于跨项目交接。副本是新的时间线身份，不等于原音画关联仍然存在。

## 导入字幕

1. 从“添加文字 → 导入字幕文件”选择 SRT、VTT 或 ASS。
2. 阅读有效条数与警告，确认文件被正确识别。
3. 选择保留原始时间码，或让首条字幕对齐当前播放头。
4. 导入后在独立视觉轨检查首条、中间和末条字幕。
5. 按需逐条编辑文本与样式，再播放核对声音。

ASS 的高级样式不会原样保留，会统一成编辑器字幕样式。时间不对时先核对导入方式，不立刻修改全部字幕。

## 声音与画面效果

音频片段调整音量和可用淡入淡出，试听真实重叠区。抠像、变速和转场在对应片段参数中设置，改完用精确帧或短输出检查边缘与衔接，尤其不要只凭缩略图验收。

## 调整工作区但不改变作品

时间线横向滚动时轨道名称固定，名称栏与片段区垂直同步。拖动面板分隔线调整空间，双击可恢复。滚动、缩放和面板布局帮助观察，不修改片段时间或进入撤销记录。

最后检查整段首尾、每个切点和效果变化处，再进入导出预检。
