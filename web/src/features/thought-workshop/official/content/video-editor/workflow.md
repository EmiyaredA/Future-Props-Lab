# 视频剪辑工坊：主要操作流程

## 轨道和片段

双击素材放入兼容轨道，移动、裁切、分割和删除片段。先检查选中项，再调整位置、大小、裁剪、速度、透明度和声音等可用参数。改变片段不会重写源文件。

播放头定位时间，滚动和缩放用于浏览。轨道名称栏与片段区垂直同步，横向滚动时名称固定。面板分隔线可拖动，双击恢复；布局不是剪辑内容。

## 多选与复制

框选或组合选择后整组移动，保持相对时间。跨轨仍检查类型、重叠和锁定。Ctrl/Cmd+C 复制、Ctrl/Cmd+V 在播放头附近粘贴；新片段不继承原关联组，需重新检查音画同步。

批量检查器可暂存属性后一次应用，提交前核对选中数量与适用片段。剪贴板只用于当前工程会话，不用于跨项目交接。

## 字幕、声音与效果

“添加文字 → 导入字幕文件”支持 SRT、VTT、ASS。先查看有效条数和警告，选择保留时间码或首条对齐播放头。字幕放入独立视觉轨，每条可编辑；ASS 高级样式统一为编辑器字幕样式。

音频片段调整音量和可用淡入淡出，试听实际重叠。需要抠像、变速或转场时，在对应片段参数里设置，再用精确帧和输出检查边缘、衔接与节奏。

## 预览验收

浏览器代理用于流畅播放，精确帧使用保存版本核对最终像素。检查首尾、切点和效果变化处，不能只检查播放头当前位置。
