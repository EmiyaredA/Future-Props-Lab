# 视频剪辑工坊：常见问题与能力边界

## 代理失败还能导出吗

代理用于交互预览，正式渲染依赖原素材。先检查原文件与解析状态，再重试代理；是否能导出由正式预检决定，不以缩略图是否出现判断。

## 字幕时间偏移

导入时可能选择了首条对齐播放头。核对原始时间码、当前播放头和导入选项，再决定移动字幕轨或重新导入。ASS 高级样式不会原样保留。

## 复制片段后音画不同步

副本生成新身份且不继承原关联组。检查复制选区是否包含所有相关片段，以及相对起点、变速和源入点。当前会话剪贴板不能用于跨工程复制。

## 画面或声音没有进入输出

检查轨道隐藏与静音、片段起止范围、图层顺序和导出范围。代理预览与精确帧用途不同，关键位置用精确帧核对。

## 为什么预检阻止导出

常见原因是素材缺失、范围非法、版本过期或编码环境不满足。处理明确原因后重新预检，不通过重复提交跳过检查。

本应用做确定性剪辑与渲染；模型生成在模型测试或视觉工坊完成。MP4 是最终媒体，不能作为可继续编辑工程的替代品。
