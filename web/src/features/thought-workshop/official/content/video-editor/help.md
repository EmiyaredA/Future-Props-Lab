# 视频剪辑工坊：常见问题与能力边界

出现画面、声音或导出问题时，先分清源素材、时间线、保存状态和任务结果。本篇按常见现象给出处理步骤，修复后再用精确帧或短输出验证。

## 排查前记录

确认工程、当前选中片段、播放头位置、导出范围与保存状态。对照原媒体、交互预览和输出文件，判断问题从哪一步开始出现。

## 按现象处理

| 现象                   | 可能原因                             | 处理步骤                                               |
| ---------------------- | ------------------------------------ | ------------------------------------------------------ |
| 代理生成失败           | 派生缓存或解码处理异常               | 先检查原文件与解析状态，再重试代理；正式导出以预检判断 |
| 字幕整体偏移           | 导入时选择首条对齐播放头             | 核对原始时间码和导入选项，再调整位置或重导             |
| ASS 外观变化           | 高级样式未原样保留                   | 使用编辑器字幕样式重新检查关键字幕                     |
| 复制后音画不同步       | 选区不全、源入点变化或关联组未继承   | 检查全部相关片段的起点、变速和源入点                   |
| 画面或声音没进入输出   | 隐藏、静音、图层顺序或范围错误       | 核对轨道与片段区间，再用精确帧和试听验收               |
| 分段导出没有抠像效果   | 分段输出原始视频片段                 | 改用“导出视频”输出时间线合成效果                       |
| 预检阻止导出           | 缺素材、非法范围、版本或编码环境问题 | 处理明确原因后重做预检                                 |
| 保存后续操作暂停       | 网络失败或版本冲突                   | 打开“查看未保存操作”，核对后明确处理，不自动重放       |
| 下载不到已完成结果     | 下载或连接问题                       | 查询原任务并优先重新下载                               |
| 换浏览器后面板位置不同 | 布局偏好保存在原浏览器               | 调整视图，不要重建时间线                               |
| 甩镜或漏光叠加过强     | 原素材已包含同类效果                 | 在转场面板删除新增转场或缩短时长，再对照源素材和精确帧 |

## 处理未保存操作

编辑器仅在内存中保留未确认操作。先查看具体列表并记下要重做的修改，再决定是否放弃；放弃后以服务器快照重新编辑。

> [!WARNING]
> 刷新或关闭窗口不是重试保存。它可能让未确认的本地操作丢失。导出前必须先解决保存问题，否则精确预览和任务会使用已经保存的版本。

## 修复后怎样验收

1. 确认原素材可读取，修复对应片段或参数。
2. 等待保存成功。
3. 检查首尾、切点、字幕变化和效果边缘。
4. 运行预检，必要时导出短范围验证。
5. 下载新结果独立播放，不再用旧文件判断修复效果。

## 当前能力边界

视频剪辑工坊负责确定性剪辑与渲染。模型生成在模型测试或视觉创作工坊中完成，连通模型并不会自动替时间线补充素材。

MP4 是最终媒体，不是可编辑工程备份；当前会话剪贴板也不能用于跨工程迁移。需要继续编辑时使用工程快照与正式项目包，保留完整媒体。

## 合并按钮为何不能完成操作

第一版只合并同一画面轨或混合轨上首尾连续的 2～100 个视频片段。先解除音画关联、解锁轨道并等待源素材就绪；跨轨、纯音频、间隙和重叠暂不支持。生成期间编辑原片段或相关设置时，替换会停止，生成素材仍可使用。合并输出使用带透明通道的 MOV，体积通常大于普通 MP4；最终交付可继续使用项目“导出视频”。
