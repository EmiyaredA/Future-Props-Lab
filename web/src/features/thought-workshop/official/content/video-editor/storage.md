# 视频剪辑工坊：保存与素材管理

剪辑操作按顺序保存，每一笔依赖上一笔成功版本。本篇说明如何确认时间线已保存，出现失败时保留哪些信息，以及素材、代理和渲染结果分别在哪里发挥作用。

## 确认当前操作已保存

1. 完成移动、裁切、属性修改或撤销重做后，观察保存状态。
2. 等待“已自动保存”，再进行精确帧预览或导出。
3. 重要修改重新打开工程时，核对片段位置、属性与声音。
4. 切换项目或关闭窗口前，处理所有未保存提示。

**完成标志：** 编辑器确认保存成功，服务器快照与当前时间线一致。刷新不代替保存，也不保证保留本次撤销栈。

离开时若显示“正在保存”，可以点击“留在编辑器”、关闭按钮或按 Escape 返回查看；保存会继续。取消离开后，保存完成也不会自动切走。等待弹窗保持打开时，保存成功会继续原先的离开操作。

## 失败后处理未保存操作

冲突、网络失败或单次保存超过 30 秒未收到结果会暂停后续提交。超时表示结果未确认，服务器可能已经保存。点击“查看未保存操作”，阅读未确认操作和重新获取的服务器快照；明确选择“放弃未保存操作”后，再按当前服务器版本重新编辑。

这些操作只保留在当前编辑器内存，系统不会自动重放。切换项目先处理未保存内容；刷新或关闭窗口触发离开提醒。

> [!WARNING]
> 在决定放弃前，先记下仍需重做的剪切、移动或参数。关闭页面可能丢失尚未确认的本地操作，不要以刷新尝试“重试全部”。

## 原素材、代理与文件夹

| 内容               | 作用           | 管理方式                                 |
| ------------------ | -------------- | ---------------------------------------- |
| 原始媒体           | 正式渲染依据   | 保持可读取，删除前移除时间线引用         |
| 缩略图、代理、波形 | 交互预览和定位 | 派生缓存可重建，代理失败可重试           |
| 素材文件夹         | 工程内分类     | 删除文件夹把素材移到未分类，不删除源文件 |
| 跨项目导入内容     | 本工程独立副本 | 来源后续变化不会自动同步                 |

素材区支持本地上传，以及从当前空间文件管理、视觉或 Galgame 项目导入。导入后确认媒体解析状态，再引用到时间线。

## 重命名素材

1. 点击素材行右侧的铅笔“重命名”按钮。视频、图片和音频使用同一入口；“整理素材”菜单中也保留“重命名”。
2. 在“素材名称”输入新名称，点击“保存名称”，也可按 Enter 保存；空白名称无法保存，最多 255 个字符。
3. 保存成功后核对素材列表和素材监视器中的名称，重新打开工程确认名称仍保留。原始文件名与时间轴引用保持不变，已有片段的独立名称不随素材改名。
4. 保存失败时弹窗保留输入并显示原因；若提示素材已被修改，先取消并重新打开重命名，核对最新名称后再保存。保存前可按 Escape 取消。

**完成标志：** 素材显示新名称，原有片段仍可预览，默认抠像设置保持原值。

## 下载原素材

1. 在左侧素材列表找到视频、图片或音频，点击该行右侧的下载图标（“下载原素材”）。
2. 下载期间图标显示忙碌状态，等待下载开始后再操作；文件使用当前素材名称和原始扩展名。
3. 下载失败时，素材行下方显示原因。检查网络、权限或原文件是否存在后，再点击下载重试。

**完成标志：** 下载目录出现可打开的原素材文件。下载保存完整源文件，不包含时间线裁切、变速、字幕或抠像效果，也不使用预览代理；要输出剪辑结果，使用“导出视频”或“分段导出”。代理仍在处理或生成失败时，也可以尝试下载已上传的原文件。只读或暂时禁止编辑时仍可下载，文件接口会校验当前空间与读取权限。

## 视图状态不等于工程内容

面板大小与滚动位置按工程保存在当前浏览器。改变布局不修改时间线、不占用撤销记录。换浏览器后布局不同，不说明片段或参数丢失。

## 渲染任务使用固定快照

提交渲染时固定时间线和资源版本。之后继续编辑不会改变运行中的任务，离开页面后可从任务列表查看进度。取消要等待安全阶段结束。

下载失败时先查已完成记录并重新下载，不立即渲染相同内容。原文件缺失时先恢复资源，再重新预检和提交。要长期继续编辑，保存工程快照；MP4 不包含完整多轨结构。
