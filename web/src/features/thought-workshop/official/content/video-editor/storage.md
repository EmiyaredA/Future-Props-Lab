# 视频剪辑工坊：保存与素材管理

## 工程版本

时间线编辑、撤销与重做按操作顺序保存，每次使用上一笔成功保存的 revision。等待“已自动保存”后再精确预览或导出。

冲突或网络失败会暂停后续提交。点击“查看未保存操作”核对，确认放弃这些操作后，再按服务器快照重新编辑；系统不会自动重放未确认保存的操作。操作仅保留在当前编辑器内存中。切换项目会先处理未保存操作；关闭窗口或刷新会触发离开提醒。

撤销、重做用于编辑过程；刷新不代替保存，也不保证保留本次撤销栈。

## 素材与代理

素材区可上传本地媒体，也可从当前空间文件管理、视觉或 Galgame 项目导入独立副本。文件夹用于分类；删除文件夹会把素材移到未分类，而非删除源文件。

原始媒体是正式渲染依据。缩略图、代理和波形是可重建的派生缓存，代理失败可重试。删除素材前需移除全部时间线引用。

## 布局状态

面板大小、滚动位置按工程保存在当前浏览器，调整不修改时间线、不占用撤销记录。换浏览器后布局不同不代表工程内容丢失。

## 渲染快照

提交渲染时固定时间线和资源版本，之后继续编辑不会改变该任务。离开页面可从任务列表继续查看；取消需要等待安全阶段结束。

结果下载失败先查询已完成任务，不重新渲染相同内容。素材原文件缺失时先修复资源，再提交新任务。
