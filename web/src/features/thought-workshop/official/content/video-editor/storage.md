# 视频剪辑工坊：保存与素材管理

剪辑操作按顺序保存，每一笔依赖上一笔成功版本。本篇说明如何确认时间线已保存，出现失败时保留哪些信息，以及素材、代理和渲染结果分别在哪里发挥作用。

## 确认当前操作已保存

1. 完成移动、裁切、属性修改或撤销重做后，观察保存状态。
2. 等待“已自动保存”，再进行精确帧预览或导出。
3. 重要修改重新打开工程时，核对片段位置、属性与声音。
4. 切换项目或关闭窗口前，处理所有未保存提示。

**完成标志：** 编辑器确认保存成功，服务器快照与当前时间线一致。刷新不代替保存，也不保证保留本次撤销栈。

## 失败后处理未保存操作

冲突或网络失败会暂停后续提交。点击“查看未保存操作”，阅读未确认操作和服务器快照；明确选择“放弃未保存操作”后，再按当前服务器版本重新编辑。

这些操作只保留在当前编辑器内存，系统不会自动重放。切换项目先处理未保存内容；刷新或关闭窗口触发离开提醒。

> [!WARNING]
> 在决定放弃前，先记下仍需重做的剪切、移动或参数。关闭页面可能丢失尚未确认的本地操作，不要以刷新尝试“重试全部”。

## 原素材、代理与文件夹

| 内容               | 作用           | 管理方式                                 |
| ------------------ | -------------- | ---------------------------------------- |
| 原始媒体           | 正式渲染依据   | 保持可读取，删除前移除时间线引用         |
| 缩略图、代理、波形 | 交互预览和定位 | 派生缓存可重建，代理失败可重试           |
| 素材文件夹         | 工程内分类     | 删除文件夹把素材移到未分类，不删除源文件 |
| 跨项目导入内容     | 本工程独立副本 | 来源后续变化不会自动同步                 |

素材区支持本地上传，以及从当前空间文件管理、视觉或 Galgame 项目导入。导入后确认媒体解析状态，再引用到时间线。

## 视图状态不等于工程内容

面板大小与滚动位置按工程保存在当前浏览器。改变布局不修改时间线、不占用撤销记录。换浏览器后布局不同，不说明片段或参数丢失。

## 渲染任务使用固定快照

提交渲染时固定时间线和资源版本。之后继续编辑不会改变运行中的任务，离开页面后可从任务列表查看进度。取消要等待安全阶段结束。

下载失败时先查已完成记录并重新下载，不立即渲染相同内容。原文件缺失时先恢复资源，再重新预检和提交。要长期继续编辑，保存工程快照；MP4 不包含完整多轨结构。
