# 视频剪辑工坊：导入导出与交付

## 导入内容

本地媒体从素材区上传；其他应用内容通过导入快照复制到本工程。字幕文件先预检再确定时间对齐方式。工程包用于完整项目交接，单个素材不是工程备份。

来源后续变化不会同步覆盖目标副本，需要主动重新导入并检查时间线引用。

## 导出 MP4

1. 播放检查完整范围，确认隐藏、静音和空白区符合预期。
2. 等待保存完成，点击“导出视频”。
3. 选择 720p30、1080p30 或 1080p60，设置起止范围。
4. 执行预检，处理缺失素材、非法范围、版本过期、磁盘或编码能力问题。
5. 预检通过后提交，在任务记录下载完成的 MP4。

正式输出使用原素材与固定快照，不通过浏览器录屏交付。下载后检查画面尺寸、时长、字幕、声音和切点。

## 工程与片段

需要继续编辑时同时保留工程快照，不能从 MP4 恢复多轨结构。单独片段导出与完整时间线渲染范围不同，操作前检查当前选区。

需要把剪辑片段交给视觉工坊时，使用明确的片段交接入口。特效工坊发送来的普通或透明镜头则在目标轨道核对叠放与声音。

## 失败恢复

先看任务原因，修正资源或参数后手动提交。已有完成记录优先下载；取消中或提交中断的记录先查状态，不自动重试写入。
