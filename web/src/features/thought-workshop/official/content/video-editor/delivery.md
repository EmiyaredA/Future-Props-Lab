# 视频剪辑工坊：导入导出与交付

交付前先决定：需要最终成片、原始分段，还是可继续编辑的工程。本篇带你预检并导出 MP4，也说明分段导出和跨应用交接的区别。

## 导出前准备

播放完整目标范围，检查轨道隐藏与静音、空白区、字幕及声音。等待“已自动保存”，确认原素材可读取。正在处理未保存操作时先完成处理，再导出。

## 导出完整时间线 MP4

1. 点击“导出视频”。
2. 选择 720p30、1080p30 或 1080p60，并设置起止范围。
3. 点击“运行预检”，阅读“输出画面预检”及反馈。
4. 处理缺失素材、非法范围、版本过期、磁盘或编码能力问题，再重新预检。
5. 预检通过后提交，在任务记录中等待完成并下载 MP4。
6. 独立打开文件，检查尺寸、时长、首尾、字幕、声音和切点。

**完成标志：** 下载视频包含预期时间线效果，能在接收设备正常播放，且没有误导出隐藏轨道或多余空白范围。

> [!NOTE]
> 正式输出使用原素材与提交时固定快照，不是浏览器录屏。提交后继续编辑，不会改变已经运行的导出任务。

## 分清三种交付

| 交付方式         | 用途                   | 重要区别                             |
| ---------------- | ---------------------- | ------------------------------------ |
| “导出视频”       | 输出最终时间线画面     | 包含对应时间线合成与效果             |
| “分段导出”       | 按视频片段输出原始片段 | 不包含抠像、背景合成等时间线画面效果 |
| 工程快照或项目包 | 保留多轨结构继续编辑   | 需保留工程内容及媒体资源             |

分段导出可以只下载文件，也可以使用明确入口导出并导入视觉工坊。需要抠像或背景效果时使用“导出视频”，不要用原始分段结果验收时间线效果。

选择导入视觉工坊时，先核对目标画布，再等待分段任务完成。打开目标项目的看板并选择导入的视频节点，应能播放片段，看到“输出版本 1”和“最终输出 v1”。每个片段自动保留一个输出版本并设为最终输出，下游节点可通过“引用任务输出”跟随该版本；无需再次上传视频或手动设置。只下载文件不会创建画布节点或输出版本。

## 导入媒体与字幕

本地媒体从素材区上传；其他项目内容通过正式快照导入复制到本工程。字幕先预检，再选择保留时间码或首条对齐播放头。导入后检查资源、时间与样式。

来源变化不会同步覆盖目标副本。需要更新时重新导入并检查时间线引用，避免以同名文件判断它已经替换。

## 跨应用交接检查

剪辑片段交给视觉工坊时，核对目标画布与新素材；特效工坊送来的普通或透明镜头，在目标轨道检查叠放、透明部分和声音。每次交接都检查目标副本，不假设它持续跟随来源。

## 失败后恢复

先阅读任务原因，修复资源或参数后手动提交。已有完成记录优先下载；取消中或提交中断先查状态。最终 MP4 不能恢复完整时间线，重要项目同时保存可编辑工程。
