# 视频剪辑工坊：功能概览与快速开始

视频剪辑工坊把视频、图片、音频、文字和字幕组织到多轨时间线，提供交互预览、精确帧检查与后台成片渲染。编辑需要当前 Workspace 写权限。

## 完成第一段剪辑

1. 从应用中心新建剪辑工程，打开编辑器。
2. 在左侧素材区上传视频或图片，等待媒体解析和代理准备。
3. 双击素材加入兼容轨道，在时间线上调整起点和长度。
4. 加入音频或文字，播放检查画面、声音和时长。
5. 等待保存完成，点击“导出视频”，先预检再提交完整渲染。

先用短素材做完整闭环，再增加轨道和长视频。预览流畅不代表原始媒体已满足导出条件。

## 工作区

左侧整理素材，中间查看画面，下方组织轨道，右侧修改当前选中片段。源素材与时间线片段不同：同一媒体可多次引用，每个片段有自己的入点、出点与外观。

多轨声音和镜头排列在本应用完成；独立二维特效可先在特效工坊制作，再明确交接成片媒体。
