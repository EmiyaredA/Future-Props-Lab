# 视频剪辑工坊：功能概览与快速开始

想把几个镜头、字幕和声音做成一条短片，可以先用一段短素材完成整个流程。本篇带你从入轨到导出预检，建立“编辑、保存、验收、渲染”的基本顺序。

## 开始前

确认当前账号与内容写权限，准备一段短视频或一张图片，以及可选音频。手工剪辑不需要先调用生成模型；首次使用不必直接导入整套长视频。

## 完成第一段剪辑

1. 从应用中心新建剪辑工程，打开编辑器。
2. 在左侧素材区上传媒体，等待解析并观察代理准备情况。
3. 双击素材，将它放入兼容轨道；检查片段在时间线上的起点和长度。
4. 增加音频或文字，移动播放头并播放，检查画面、声音和整体时长。
5. 等待保存成功，点击“导出视频”，先运行预检。
6. 处理预检提示后提交渲染，完成时下载并打开 MP4。

**完成标志：** 项目能重新打开，下载文件正常播放，首尾、文字与声音符合预期。

> [!TIP]
> 先让十几秒素材完整走通，再增加轨道和长视频。这样能分别确认媒体解析、时间线编辑和输出环境。

## 认识工作区

| 区域       | 负责什么               | 操作前检查             |
| ---------- | ---------------------- | ---------------------- |
| 左侧素材区 | 上传与整理源媒体       | 资源是否解析完成       |
| 中央画面   | 预览当前时间位置       | 当前播放头和显示模式   |
| 下方时间线 | 片段、轨道、顺序与时长 | 选中项和兼容轨道       |
| 右侧检查器 | 当前片段的属性         | 修改会影响哪些选中片段 |

源素材和时间线片段是两回事。同一个视频可以多次引用，每个片段有自己的入点、出点和外观；剪短片段不会改写原始文件。

## 预览与正式输出

代理用于流畅交互，精确帧用于检查保存版本的最终像素，正式渲染使用原素材和固定快照。预览流畅不代表所有导出条件已满足；最终以预检和实际下载文件验收。

分割后检查接点时，从切点前开始播放，观察画面是否连续、声音是否正常。同素材且源时间连续的分割共用视频解码器；跳剪或换素材仍需等待目标帧定位。暂停后若显示“画面更新中…”，等提示消失再核对精确画面。若卡顿持续，先确认素材代理已经就绪，并记录出现问题的接点时间；不要用重复分割或刷新尝试加速。

## 应用之间怎样配合

视觉创作工坊负责生成素材，特效制作工坊负责独立二维动画和透明镜头。将完成媒体通过正式导入或交接放入本工程后，再安排镜头、字幕与声音。

遇到保存失败先处理未保存操作，遇到素材缺失先修复原文件；不要把反复渲染当作保存或素材恢复手段。
