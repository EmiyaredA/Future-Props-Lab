# 特效制作工坊：常见问题与能力边界

预览或下载结果不符合预期时，先定位是图层、时间、格式还是交接环节的问题。下面的处理顺序以保留可编辑工程为前提，目标是修正最小范围并重新验证，而不是反复导出整个项目。

## 按现象排查

| 现象                         | 常见原因                                       | 处理与成功标志                                                        |
| ---------------------------- | ---------------------------------------------- | --------------------------------------------------------------------- |
| 导出没有声音                 | 特效工坊输出的是无声镜头                       | 在视频剪辑工坊添加音轨；最终成片中再检查声音                          |
| MOV 看起来有黑色或实色背景   | 播放器不显示 Alpha，或工程里仍有背景层         | 在支持 Alpha 的合成画面上叠放，检查全画布图层；透明区域应露出下层画面 |
| 动画提前停止或不出现         | 图层持续时间不够，或关键帧位置超出有效局部时间 | 核对开始帧、时长和关键帧，从图层进入到退出播放一次                    |
| 遮罩在中间帧折叠、跳动       | 路径关键帧控制点或手柄变化过大                 | 暂停动画检查静态轮廓，再逐段修正；中间帧也应保持预期轮廓              |
| 导出还是旧画面               | 下载了旧任务，或修改发生在提交之后             | 保存后提交新的任务，核对范围再下载；任务不会实时追随草稿              |
| 剪辑里的镜头没有随源工程更新 | 交接复制了已完成媒体                           | 重新导出并明确发送到目标，检查新增镜头后自行调整时间轴                |

> [!WARNING]
> 保存冲突时不要反复覆盖。保留当前草稿，核对服务器版本后再处理；导出文件不能替代可编辑工程备份。

## 缩小问题范围

1. 选中异常图层，在静态帧确认素材、可见性和叠放正确。
2. 检查局部时间与图层时长，再逐项恢复属性动画和遮罩。
3. 保存后只导出问题区间，用相同时间点比较预览与结果。
4. 已有成功任务时优先下载该结果；失败任务先处理明确原因，再决定重新提交。

## 当前边界

本应用负责二维镜头内部的合成，不负责音频编排；MOV 和 PNG 序列的透明输出也不会自动移除背景素材。工程包保留结构，最终媒体保留画面，两类文件承担不同用途。
