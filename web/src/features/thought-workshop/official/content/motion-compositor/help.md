# 特效制作工坊：常见问题与能力边界

## 为什么导出没有声音

本应用专注二维视觉镜头，不编辑声音。MP4、MOV、PNG 序列都无声；到视频剪辑工坊添加音乐、对白并完成成片。

## MOV 为什么看起来不透明

先检查播放器是否支持 Alpha，再检查工程内是否有覆盖画布的背景层。透明导出仍渲染所有可见图层，不会自动去掉背景素材。

## 动画突然停止

检查图层局部时间、持续时间和关键帧位置。裁短图层后，末尾关键帧可能超出有效范围；移动图层则动画随层一起移动。

## 遮罩跳动或翻转

先关闭动画检查静态轮廓，再核对关键帧之间的控制点和手柄。不要一次改变大量点后只验收单帧。

## 已发送镜头为什么没有更新

交接复制的是完成的媒体。源工程修改后需重新保存、导出并交接，目标工程不会被自动覆盖。

导出失败先处理范围、素材或资源问题；重复点击不能代替预检。可编辑工程与最终媒体应分别保留。
