# 特效制作工坊：保存与素材管理

当客户要求换一张背景图、但保留原来的标题运动时，应更新工程里的媒体与图层，而不是把上一次导出的 MP4 当成工程继续改。本节帮助你留下可恢复的编辑结构，并辨认“已保存工程”“已提交渲染”和“已交接镜头”三个不同结果。

## 保存一份可以继续修改的工程

编辑后观察保存反馈，等待“已自动保存”；也可使用手动保存。导出前再次核对画幅、帧率、总帧数和素材是否已经保存。若提示冲突，先保留当前草稿并核对服务器版本，不要连续提交同一份旧版本。

重大改动前导出工程包，特别是更换帧率、大量修改遮罩或替换媒体的时候。恢复检查应看图层、关键帧和素材能否继续编辑，不能只看一个预览缩略图。

> [!WARNING]
> MP4、MOV 和 PNG 序列只有渲染后的画面，不能恢复图层与关键帧。需要后续修改时，应同时保留工程包。

## 替换媒体时检查什么

1. 通过素材区上传或导入新媒体，先确认尺寸、时长和预览可用。
2. 将它用于对应图层，重新检查采样范围、位置、缩放和遮罩。新旧媒体即使文件名相同，尺寸与长度也可能不同。
3. 从图层进入到退出完整播放，确认视频没有提前结束，透明图片没有被背景覆盖。
4. 保存，再对照替换前的工程包确认其他图层与动画没有被误改。

删除一个图层不会让其他引用自动换成新素材。若多个图层使用同一来源，应逐层确认期望的替换范围。

## 渲染结果为什么不会跟着变化

导出任务使用提交时的固定文档快照。你可以继续编辑，但新修改不会改变已经排队或运行的任务。检查任务名称、格式与范围，避免下载旧任务后误以为保存没有生效。

向视频剪辑工坊发送镜头时，复制的是完成的媒体。原工程后续变化也不会自动覆盖剪辑工程中的那段镜头；需要重新导出，再明确交接并核对目标轨道。

> [!TIP]
> 给工程、图层和导出范围使用可区分名称，例如“片头_文字版”和“片头_透明版”。找任务时同时核对范围与版本，比只看名称可靠。
