# 特效制作工坊：保存与素材管理

## 保存状态

修改后等待“已自动保存”，也可手动保存。出现冲突先保留草稿并核对服务器版本，避免重复覆盖。导出前确认当前帧率、总帧数和素材已保存。

工程包保留可编辑结构；MP4、MOV 和 PNG 序列是渲染结果，不能恢复图层与关键帧。

## 素材使用

上传媒体后确认尺寸、时长与预览，再建立图层。删除图层不会让其他引用自动改用新素材。替换时检查采样范围、画幅和遮罩，避免旧参数作用到不同尺寸素材上。

透明区是否保留取决于整个合成。即使背景设置透明，覆盖画布的图形或媒体层仍会被渲染。

## 任务快照

导出采用提交时的固定文档快照，后续编辑不会改变运行任务。任务失败先查看原因和范围，修正后手动提交；任务完成后优先下载现有结果。

向剪辑工坊交接的是媒体副本。修改原特效工程不会自动替换剪辑里的镜头，需重新导出并明确交接。

## 整理建议

给图层、素材和导出范围使用可辨认名称。大幅修改遮罩或帧率前先导出工程包，再对比关键时刻，避免仅依赖本次编辑的撤销记录。
