# 特效制作工坊：主要操作流程

## 设置图层

选中图层后，在检查器确认名称、开始帧、持续时间和叠放顺序。媒体、文字和图形各有对应参数，修改的是该层表现，不改写原始文件。

先搭好静态构图，再添加动画。检查画布边缘和图层切入切出，图层时长不能超过工程范围。

## 属性关键帧

移动到目标帧，在“变换与关键帧”修改位置、缩放、旋转或透明度，使用属性旁的关键帧按钮记录。移到另一帧再记录数值，播放检查插值。

关键帧以图层开始位置为基准。移动或裁短图层后重新检查末尾动画；需要静态属性时确认没有遗留动画轨道。

## 路径遮罩

在“路径遮罩”启用遮罩，编辑控制点和贝塞尔手柄，检查闭合轮廓、边缘与反向裁切。需要动画时，在对应帧记录路径关键帧。

先做静态遮罩验证，再增加路径变化，留意控制点顺序造成的翻转或跳动。遮罩只影响选中图层，不删除源图像像素。

## 预览

浏览器画布用于交互，精确帧核对保存版本。检查关键帧两侧、透明边缘与不同叠层结果，再用相同时间点验证导出。
