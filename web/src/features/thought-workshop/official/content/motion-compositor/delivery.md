# 特效制作工坊：导入导出与交付

同一个标题镜头可以交给播放器直接播放，也可以作为透明叠层放进剪辑工程。交付前先决定接收方需要“继续改工程”还是“使用完成画面”，再选择文件；本节完成后应能在目标环境核对画幅、时长和透明边缘。

## 选对交付类型

| 接收方的目的               | 选择         | 需要留意                                         |
| -------------------------- | ------------ | ------------------------------------------------ |
| 继续调整图层和动画         | 特效工程 ZIP | 从项目列表“导入项目”恢复；不是其他软件的工程文件 |
| 常规播放或剪辑             | MP4          | 透明区合成到画布底色，无声                       |
| 与其他画面透明叠加         | MOV          | 保留 Alpha，无声；播放器需要支持透明通道         |
| 逐帧检查或交给其他合成流程 | PNG 序列     | 保留 Alpha，无声；需要保持帧顺序                 |

> [!NOTE]
> 透明导出仍会渲染可见图层。覆盖全画布的背景图或矩形不会因为选择 MOV 而自动消失。

## 提交一次导出

1. 保存工程，核对尺寸、帧率和总帧数；输出沿用工程设置。
2. 点击“导出镜头”，选择一种或多种格式，填写开始帧与结束帧。
3. 确认范围后点击“开始导出”，在最近导出中查看状态。结束帧不包含在范围内，例如 30 fps 下 `[0, 60)` 输出 60 帧、约两秒。
4. 等任务完成后下载结果。失败时先看原因，处理素材或范围问题后再手动提交。
5. 在能正确显示所选格式的播放器或合成工具中检查首尾、持续时间、遮罩和半透明边缘。

## 发送到视频剪辑工坊

在已完成任务选择“发送普通镜头”或“发送透明镜头”，选当前 Workspace 的已有剪辑工程，或填写名称创建目标，再点击“发送到剪辑”。目标会复制镜头媒体并追加画面轨道。

进入目标工程后，确认新增轨道、位置、持续时间和叠放关系，再添加音乐或对白。透明 MOV 使用保留 Alpha 的剪辑代理；PNG 序列不能直接通过这个交接入口发送。

> [!TIP]
> 对透明镜头，先在另一段有颜色的画面上叠放验收。播放器显示黑底不一定表示 Alpha 已丢失。
