# 特效制作工坊：导入导出与交付

## 工程包

项目列表的“导入项目”读取特效工程 ZIP；项目快照导出用于继续编辑。导入后检查素材、画幅、帧率与图层范围，不把外部软件工程文件直接当作本应用包。

## 选择格式

| 格式     | 用途           | 透明与声音                 |
| -------- | -------------- | -------------------------- |
| MP4      | 常规播放与剪辑 | 透明区合成到画布底色，无声 |
| MOV      | 透明叠加镜头   | 保留 Alpha，无声           |
| PNG 序列 | 逐帧检查与交付 | 保留 Alpha，无声           |

## 导出镜头

先保存，在“导出镜头”选一种或多种格式，设置起始与结束帧，点击开始导出。结束帧不包含在范围内；输出尺寸与帧率沿用工程设置。

在最近导出中查看状态，完成后下载。用透明背景检查边缘和遮罩，再核对持续时间及起止画面。

## 交给剪辑

已完成任务可“发送普通镜头”或“发送透明镜头”，选择当前空间已有剪辑工程或新建目标，再确认发送。目标工程复制媒体并追加画面轨道；PNG 序列不能用此入口直接交接。

透明 MOV 使用保留 Alpha 的剪辑代理。到目标工程核对叠放、时长并加入声音。后续源工程更新不会同步改变这段镜头。
