# 特效制作工坊：功能概览与快速开始

给短片加一段从画面左侧滑入的片名，可以先在特效制作工坊完成一个独立镜头，再交给视频剪辑工坊配乐。这里管理二维图层、属性动画和路径遮罩；完成本节后，你会得到一份可继续编辑的工程，以及可播放的无声标题镜头。

## 开始前准备

进入具有内容写权限的账号。文字和图形可以直接创建；需要照片或视频时准备对应媒体文件。制作与渲染不要求配置生成模型。先决定交付画幅和帧率，例如横屏画面、30 fps，避免动画完成后再改变时间基准。

> [!NOTE]
> 特效工坊当前不编辑声音。即使媒体来源包含音轨，导出的特效镜头仍为无声画面。

## 做出第一段标题动画

1. 从应用中心打开特效制作工坊，点击“新建项目”，填写名称、画幅和帧率，选择“空白项目”，再创建并打开。
2. 核对预览区的尺寸和时间轴总时长。从“快速添加”加入文字，输入片名；需要底图时先导入媒体并建立对应图层。
3. 选中文字图层，把播放头移到开始位置，在检查器设置标题的初始位置。使用位置属性旁的关键帧入口记录这一帧。
4. 把播放头移到稍后的位置，将标题放到画面中央，再记录位置关键帧。先保持缩放和旋转不变，便于观察单一变化。
5. 从动画起点播放，确认标题连续滑入并在预期位置停下。检查图层持续时间是否覆盖停留阶段。
6. 等待“已自动保存”，打开“导出镜头”，先选 MP4 和整段范围，再开始导出并下载完成结果。

## 判断是否完成

不要只查看中央那一帧。分别检查开始、中间和结束画面：标题不能提前出现、越过边界或在停留前被裁掉。下载的 MP4 应有正确尺寸与持续时间；回到工程仍能选中文字和修改关键帧。

> [!TIP]
> 先完成一个只有位置变化的图层，再添加透明度动画或遮罩。这样能区分“图层没显示”和“动画没记录”两类问题。
