# 特效制作工坊：功能概览与快速开始

特效制作工坊制作独立二维镜头，支持图层、属性动画、路径遮罩与透明输出。创建和编辑需要空间写权限，不要求配置模型。

## 制作一段标题动画

1. 点击“新建项目”，设置名称、画幅与帧率，选空白项目或特效模板。
2. 从快速添加加入文字或图形，或在素材区导入媒体。
3. 选中图层，调整位置、缩放与透明度。
4. 在起点和终点为需要变化的属性记录关键帧，播放检查。
5. 等待已自动保存，再打开“导出镜头”选择格式与范围。

例如让标题从左侧进入：先在起始帧记录左侧位置，再在稍后的帧记录中央位置；播放确认中间运动，而非只看终点。

## 时间与交付

图层有独立开始帧与持续时间，关键帧使用图层局部时间。移动图层时动画随层移动。

本应用不编辑声音，输出为无声镜头。需要音轨、字幕和多镜头成片时，将完成镜头交给视频剪辑工坊。
