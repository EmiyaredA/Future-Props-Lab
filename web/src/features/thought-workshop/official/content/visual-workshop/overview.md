# 视觉创作工坊：功能概览与快速开始

视觉创作工坊用项目和节点画布组织文本、图片、视频、音频及模型生成。节点表达素材与创作关系，连线不会直接把文件拼成视频。

## 第一次生成

1. 进入应用，创建并打开画布项目。
2. 在空白处右键添加文本和图片等节点，填写提示或上传素材。
3. 选中目标生成节点，检查相连的输入、模型和参数。
4. 确认后提交，观察任务状态，等待结果落盘并可预览。
5. 保存画布，再下载结果或继续建立后续节点。

例如根据产品图生成短视频，应选支持参考图的视频模型，核对图片节点与目标视频节点的引用，不仅修改标题。

## 权限与准备

编辑需要写权限，模型生成还需要模型使用权限和可用连接。普通素材整理不必提交模型任务。

图片和视频模型的参考输入、数量及参数不同，以所选模型的界面为准。先做最小样例验证，再批量处理。
