# 视觉创作工坊：功能概览与快速开始

想根据一张产品图生成短视频，或者把参考素材和提示组织在同一画布里？视觉创作工坊用节点表达文本、图片、视频、音频和生成关系。本篇先走通一次最小生成任务。

## 开始前

创建与编辑需要当前账号的写权限；模型生成还需要模型使用权限、可用连接和匹配能力。准备一张受支持参考图与一句清楚的提示，例如“保持主体外形，让镜头缓慢靠近”。

只整理素材不必调用模型。正式生成前，先在模型测试中确认对应媒体能力可用。

## 第一次生成

1. 进入视觉创作工坊，创建并打开画布项目。
2. 在空白处右键添加文本、图片等节点，填写提示或上传参考素材。
3. 准备目标生成节点，检查相连的文本、参考图及其他输入。
4. 选择具备对应能力的模型，核对参数和输出数量；本例应选择支持参考图的视频模型。
5. 明确提交后观察任务状态，等待结果生成、保存并可预览。
6. 检查真实媒体内容，等待画布保存完成，再下载结果或继续建立后续节点。

**完成标志：** 任务完成、结果可读取、节点关系已保存。占位节点出现、供应商开始处理或上传完成，都不等于完整闭环已经结束。

## 三种信息不要混在一起

| 内容           | 表示什么           | 不代表什么                     |
| -------------- | ------------------ | ------------------------------ |
| 节点标题和位置 | 画布上的组织与识别 | 不改变源文件内容               |
| 节点连线       | 生成输入关系       | 不把视频直接拼接成时间线       |
| 已完成任务结果 | 某次请求的输出     | 不会随提示或源素材变化自动重做 |

> [!TIP]
> 第一次只做一个目标节点、少量输入和一个易判断的结果。确认链路后再批量提交，既方便排查，也更容易控制费用。

## 生成失败后先查阶段

模型选不到时检查空间、权限和能力；任务已有远端结果但本地保存失败时优先恢复原结果；画布保存失败时先处理项目写入，不重复调用模型。

离开或刷新页面不等于取消远端任务。重新进入后先查询原记录，再决定是否发起新请求。

需要把多个镜头、字幕和声音组织成完整影片时，使用视频剪辑工坊。本应用负责素材创作与关系组织，不替代多轨剪辑。
