# 视觉创作工坊：主要操作流程

本篇以“参考图 → 生成视频 → 从视频提取一帧”为例，说明节点放置、一键整理、输入核对和派生素材的使用。开始前打开可编辑画布，确认需要生成时已有可用模型。

## 组织节点与输入

1. 在空白处右键添加文本、图片、视频或音频节点；位置被占用时，新节点会寻找附近空位，已有节点保持原位。
2. 填写提示或绑定媒体，拖动卡片整理位置；使用适应屏幕把现有节点纳入视口。
3. 建立目标生成节点的输入关系，核对每一条连线对应的文本和参考媒体。
   看板工作台的“输入素材”默认折叠，标题显示数量；点击标题展开并核对引用，点击“引用任务输出”会直接展开选择器。提示词框提供更大的默认编辑区域，也可继续展开编辑。
   也可把左侧“项目素材”中已有媒体文件的节点拖入生成器对应的参考框：图片生成只接收图片，图生视频与首尾帧接收图片，全能参考接收图片、视频和音频，拖到全能参考栏空白处会按类型添加。放下后核对参考缩略图和保存状态；重复、自身、超出数量或类型不符的素材不会添加；素材选择菜单也不显示当前节点自身的文件。拖入保存的是当前文件参考，后续切换来源节点的最终版本不会自动替换它；需要跟随任务输出时仍使用“引用任务输出”。没有媒体输出的节点与文本节点不可拖入参考框，点击素材框可通过菜单选择素材。
4. 要更换媒体时用节点的“替换素材”，不要只修改标题。
5. 提交前检查选区之外的来源，避免遗留连线把旧参考送入新任务。

**完成标志：** 目标节点引用的输入正是本次需要的素材，标题、缩略图和实际文件一致。

## 新增与整理布局

1. 通过画布的“添加内容”新增节点，观察节点出现在当前可见区域附近；右键新增、拖入素材和粘贴优先使用操作位置。节点之间预留间距，必要时画布平移让新节点可见，缩放比例保持不变。
2. 在看板“项目素材”中新建或批量上传，再切回画布，核对节点已经避开原卡片。看板分类、排序与视图切换不重新排列画布。
   每个节点行右侧都有三个点的操作按钮：选择“下载”可保存该节点当前绑定的媒体文件，文本节点下载为 TXT；无内容时下载不可用，下载不提交生成任务。选择“重命名”后输入名称并确认，核对列表标题已更新；选择“分类与标签”会打开该节点工作台中的整理区域，调整后核对节点所属分类和分组。选择“删除节点”后先核对确认框中的名称，再确认删除；节点及其输入连线会移除，项目素材原文件保留。若节点被下游引用，先解除引用再删除。工作台顶部的三个点提供相同操作。
3. 点击底部“一键整理”：有连线的流程从左到右排列，同一层上下排列；独立素材在旁边按网格排列。通过“画布整理方式”菜单选择“网格整理全部”，可以统一浏览所有卡片。
4. 框选至少两个节点，点击“整理选中节点”，或通过“选中节点整理方式”选择网格。仅选区位置变化，整理后的节点区域会避开未选中节点。
5. 按 Ctrl/Cmd+Z 撤销整次整理，按 Ctrl/Cmd+Shift+Z 重做；保存后刷新，检查位置和连线仍然保留。

**完成标志：** 新增卡片没有盖住原卡片，整理后的流程方向清楚，选区之外的节点保持原位。整理只改变位置，不提交生成任务；拖动、上传或保存冲突未解决时不能整理。展开的编辑面板属于临时界面，不决定卡片间距。

## 复制一组方案进行比较

框选或多选节点，通过选区工具栏、右键菜单或 Ctrl/Cmd+C 复制，Ctrl/Cmd+V 粘贴。副本保留内部连线与相对布局，舍弃外部连线；节点身份是新的，媒体素材仍可复用。

复制后先检查外围输入，再修改提示和参数。副本不继承原任务或批次关联，也不会自动提交生成。粘贴时整组平移避开已有卡片，保留组内相对位置；原组内的重叠可再用整理选中节点处理。整组插入参与一次保存和撤销。

> [!NOTE]
> 节点剪贴板只在当前画布会话保留，不能作为跨项目搬移方式。需要迁移项目时使用正式项目包或素材导入流程。

## 裁剪图片

1. 打开图片预览的裁剪入口。
2. 调整范围和比例，确认要保留的主体；未提交前可以取消。
3. 完成后检查新增 PNG 派生节点，透明度按结果保留。
4. 等待派生素材和画布结构保存，再用于后续生成。

裁剪不改写原图。若派生结果已经上传但节点保存失败，先恢复同一节点的保存，不重复创建相同结果。

## 从视频提取一帧

1. 在视频节点暂停，打开导出帧入口。
2. 在弹窗重新定位进度，确认当前画面与输出格式。
3. 执行导出，检查下载图片和画布中新建的未连线图片节点。
4. 需要作为新参考时，再明确连接目标节点并保存。

取帧是确定性派生，不会重新调用视频模型；新的图片节点也不会自动接入原生成链。

## 提交模型任务前最后检查

模型能力 → 输入类型与数量 → 参数 → 输出数量 → 成本预期。任务结束后检查真实结果再继续下游。批次失败时先判断具体失败阶段，不把整批任务全部盲目重做。
