# 视觉创作工坊：主要操作流程

本篇以“参考图 → 生成视频 → 从视频提取一帧”为例，说明节点放置、一键整理、输入核对和派生素材的使用。开始前打开可编辑画布，确认需要生成时已有可用模型。

## 组织节点与输入

1. 在空白处右键添加文本、图片、视频或音频节点；位置被占用时，新节点会寻找附近空位，已有节点保持原位。
2. 填写提示或绑定媒体，拖动卡片整理位置；使用适应屏幕把现有节点纳入视口。
3. 建立目标生成节点的输入关系，核对每一条连线对应的文本和参考媒体。
   看板工作台的“输入素材”默认折叠，标题显示数量；点击标题展开并核对引用，点击“引用任务输出”会直接展开选择器。提示词框提供更大的默认编辑区域，也可继续展开编辑。
   也可把左侧“项目素材”中已有媒体文件的节点拖入生成器对应的参考框：图片生成只接收图片，图生视频与首尾帧接收图片，全能参考接收图片、视频和音频，拖到全能参考栏空白处会按类型添加。放下后参考框会提示已添加，或说明未添加的原因；成功时再核对参考缩略图和保存状态。重复、自身、超出数量、类型不符或尚未导入当前项目的素材不会加入草稿，素材选择菜单也不显示当前节点自身的文件。拖入保存的是当前文件参考，后续切换来源节点的最终版本不会自动替换它；需要跟随任务输出时仍使用“引用任务输出”。没有媒体输出的节点与文本节点不可拖入参考框，点击素材框可通过菜单选择素材。
4. 要更换媒体时用节点的“替换素材”，不要只修改标题。
5. 提交前检查选区之外的来源，避免遗留连线把旧参考送入新任务。

**完成标志：** 目标节点引用的输入正是本次需要的素材，标题、缩略图和实际文件一致。

## 预览并下载参考素材

1. 点击生成器里已选的参考图片、视频或音频缩略图，核对预览弹窗标题与内容。
2. 点击弹窗右上角「下载」，等待下载完成；下载中按钮不可重复点击，预览仍可关闭。下载失败时弹窗显示原因，可再次点击重试。
3. 打开下载文件，核对内容与刚才预览的素材一致。文件保留原格式，名称使用当前素材名称；关闭弹窗后，参考选择仍保留。

**完成标志：** 本机取得当前参考素材的原文件，预览、参考选择和生成草稿没有变化。

## 确认节点已通过

1. 核对当前节点内容；右侧预览历史版本时，先将认可的版本「设为最终输出」。通过标记针对当前节点结果，单独预览历史不切换最终输出。
2. 打开工作台分类与标签行右侧的「通过」开关，应看到绿色「已通过」，左侧素材行也显示勾选图标。素材行的三个点菜单、状态卡和画布节点同样提供此操作。
3. 等待「已保存」后刷新，核对标记仍在；关闭「已通过」开关可取消，素材行勾选随之消失。

**完成标志：** 看板和画布显示同一通过状态。它表示人工认可，不改变生成任务状态或下游输入；生成／上传新输出、切换不同最终版本、删除最终版本或修改文本正文后需要重新确认。仅改标题、提示词或布局不会清除，复制节点从未通过开始，项目包保留原节点标记。

## 保存多个提示词方案

图片、视频与音频生成节点都可以保留多个提示词版本。在可编辑的看板工作台或画布生成面板中，提示词框上方显示当前版本。

1. 点击「复制」，创建包含当前文字的新版本；需要从空白开始时点击「新增」。核对版本选择器已选中新版本。
2. 修改文字，再从「提示词版本」切换回旧版；旧版文字保持原样，切回新版可看到刚才的修改。各版文字自动保存，模型、参考素材和生成参数共用；音频的主题和风格也共用。
3. 点击「重命名」，填写便于辨认的名称并确认；选择器应显示新名称。点击「删除」并核对确认框后，可删除当前版本；至少保留一版，每节点最多 20 版。
4. 选中要使用的版本后点击生成。提交会先等待草稿保存，保存冲突或失败时保留编辑并停止提交，先处理保存问题再生成。

**完成标志：** 保存状态显示已保存后刷新项目，版本名称、各版文字和当前选择仍保留；画布与看板显示同一组版本。复制节点与项目包导入导出也保留版本。提示词版本与右侧输出版本分别维护，切换文字不会更换已有输出；每版最多保存 6000 字符，生成时仍受当前模型的提示词长度限制。

参考图片排序会同步调整所有版本中的 `<Picture n>` 编号，保持已引用图片的含义。参考素材和参数始终共用，删除或替换参考素材后，应检查相关版本的文字再提交。

## 新增与整理布局

1. 通过画布的“添加内容”新增节点，观察节点出现在当前可见区域附近；右键新增、拖入素材和粘贴优先使用操作位置。节点之间预留间距，必要时画布平移让新节点可见，缩放比例保持不变。
2. 在看板“项目素材”中新建或批量上传，再切回画布，核对节点已经避开原卡片。看板分类、排序与视图切换不重新排列画布。
   每个节点行右侧都有三个点的操作按钮：选择“下载”可保存该节点当前绑定的媒体文件，文本节点下载为 TXT；无内容时下载不可用，下载不提交生成任务。选择“重命名”后输入名称并确认，核对列表标题已更新；选择“分类与标签”会打开该节点工作台中的整理区域，调整后核对节点所属分类和分组。选择“删除节点”后先核对确认框中的名称，再确认删除；节点及其输入连线会移除，项目素材原文件保留。若节点被下游引用，先解除引用再删除。工作台顶部的三个点提供相同操作。
3. 点击底部“一键整理”：有连线的流程从左到右排列，同一层上下排列；独立素材在旁边按网格排列。通过“画布整理方式”菜单选择“网格整理全部”，可以统一浏览所有卡片。
4. 框选至少两个节点，点击“整理选中节点”，或通过“选中节点整理方式”选择网格。仅选区位置变化，整理后的节点区域会避开未选中节点。
5. 按 Ctrl/Cmd+Z 撤销整次整理，按 Ctrl/Cmd+Shift+Z 重做；保存后刷新，检查位置和连线仍然保留。

**完成标志：** 新增卡片没有盖住原卡片，整理后的流程方向清楚，选区之外的节点保持原位。整理只改变位置，不提交生成任务；拖动、上传或保存冲突未解决时不能整理。展开的编辑面板属于临时界面，不决定卡片间距。

## 复制一组方案进行比较

框选或多选节点，通过选区工具栏、右键菜单或 Ctrl/Cmd+C 复制，Ctrl/Cmd+V 粘贴。副本保留内部连线与相对布局，舍弃外部连线；节点身份是新的，媒体素材仍可复用。

复制后先检查外围输入，再修改提示和参数。副本不继承原任务或批次关联，也不会自动提交生成。粘贴时整组平移避开已有卡片，保留组内相对位置；原组内的重叠可再用整理选中节点处理。整组插入参与一次保存和撤销。

> [!NOTE]
> 节点剪贴板只在当前画布会话保留，不能作为跨项目搬移方式。需要迁移项目时使用正式项目包或素材导入流程。

## 裁剪图片

1. 打开图片预览的裁剪入口。
2. 调整范围和比例，确认要保留的主体；未提交前可以取消。
3. 完成后检查新增 PNG 派生节点，透明度按结果保留。
4. 等待派生素材和画布结构保存，再用于后续生成。

裁剪不改写原图。若派生结果已经上传但节点保存失败，先恢复同一节点的保存，不重复创建相同结果。

## 从视频提取一帧

1. 在视频节点暂停，打开导出帧入口。
2. 在弹窗重新定位进度，确认当前画面与输出格式。
3. 执行导出，检查下载图片和画布中新建的未连线图片节点。
4. 需要作为新参考时，再明确连接目标节点并保存。

取帧是确定性派生，不会重新调用视频模型；新的图片节点也不会自动接入原生成链。

## 提交模型任务前最后检查

模型能力 → 输入类型与数量 → 参数 → 输出数量 → 成本预期。任务结束后检查真实结果再继续下游。批次失败时先判断具体失败阶段，不把整批任务全部盲目重做。

## 在看板查看生成状态

1. 在创作工作台提交图片、视频或音频后，检查生成按钮和节点状态显示转圈图标；当前任务运行时不能重复提交。
2. 右侧「输出预览」下方用紧凑状态栏显示任务阶段、已用时和「查看任务」入口。ZEALMAN 任务还会按接口实际返回显示上游排队位置、当前执行节点、采样步数和状态更新时间。采样百分比标注为「采样」，「上游报告」值单独显示，不代表整段视频完成度；尚无进度时显示等待动画。
3. 新提交的 ZEALMAN 任务使用独立实时连接；断线时显示重连状态并继续 HTTP 查询。采样信息超过一分钟未更新时恢复等待动画。旧任务仍可查询队列和上游状态，节点与采样信息取决于上游支持。
4. 生成期间仍可查看已有输出版本；预览徽标标明当前版本，旧结果不会标为本次生成的中间画面。当前接口尚未提供实时中间帧，没有输出时显示「等待生成画面」。
5. 完成后检查新的输出版本和可播放结果；失败时通过「查看任务」检查原因，再决定是否重新生成。

**完成标志：** 任务运行时状态持续更新，完成或失败后转圈状态结束；右侧保留输出版本，不显示阶段流程或过程缩略图列表。

## 使用 ZEALMAN 视频工作流

先在模型服务启用 ZEALMAN 连接及 U06、U17 视频模型。进入视频节点的看板工作台或画布生成面板，打开底部「生成模型」选择器；菜单会根据窗口空间展开，选项较多时可在列表内滚动，也可用方向键选择、Enter 确认、Escape 关闭。

1. 选择 `U06-9图3音频-V5` 或 `U17-9图1视频3音频V1-api`，核对底部模型名称已更新。使用「文生视频」填写提示词，或切到「全能参考」选择项目素材；切换自首尾帧模型时，原首尾帧转为普通参考图片，不提供首尾位置约束。
2. 两者均支持最多 9 张图片、3 段音频；U17 另支持 1 个视频，U06 不支持视频参考。音频需搭配图片或视频，素材合计最多 45 MB。按参考框顺序核对图片编号，未填写的位置不会使用远端示例素材。
3. 打开「视频参数」，时长选择 4–15 秒，默认 5 秒。U06 设置宽高（默认 1344 × 768，32 的倍数）及可选种子；留空时本次任务生成新种子。U17 设置画面比例、百万像素与放大倍率。工作流联合输出视频和音频。
4. 点击「生成」，等待草稿保存和任务完成；检查右侧输出预览能播放，输出版本已增加，节点管理菜单中的「下载」可以取得视频。失败时先检查任务提示；保存结果失败可重试保存原结果，提交中断不自动重新生成。

**完成标志：** 节点显示新的输出版本且视频可播放、可下载；刷新后模型、参数和参考素材仍保留。未填的随机种子保存在任务快照中，草稿保持空白以便下次生成使用新种子。
