# 视觉创作工坊：主要操作流程

## 画布与连线

从空白处右键添加文本、图片、视频或音频节点。拖动卡片改变位置，适应屏幕把现有节点框进视口。媒体节点绑定素材，替换应使用节点上的替换入口，不能靠改名改变源文件。

连线组织生成输入关系。提交前逐项检查文本、参考图、视频或音频，尤其检查选区之外的来源。

## 多选复制

框选或多选后，从选区工具栏、右键菜单或 Ctrl/Cmd+C 复制，Ctrl/Cmd+V 粘贴。副本保留内部连线和相对布局，舍弃外部连线，生成新的节点身份，但复用素材。

副本不继承原任务和批次关联，也不会自动提交生成。整组插入参与一次保存与撤销。剪贴板只在当前画布会话保留，不支持跨项目搬移。

## 图片与取帧

图片预览裁剪可选择范围和比例，完成后得到新的 PNG 派生节点，不修改原图。未提交裁剪可取消。

视频节点暂停后使用导出帧入口，在弹窗重新定位进度并确认格式。下载之外，还会创建未连线图片节点；检查节点是否保存后再继续使用。

## 模型任务

选择具备对应能力的模型，填写提示与参数，再提交目标节点。任务结束后检查原始结果，不把占位节点当作成片。批量生成前确认数量和费用，失败先定位阶段，不全批盲目重做。
