# 视觉创作工坊：导入导出与交付

只需要一张结果图，和需要别人继续调整节点、提示与连线，是两种交付。本篇帮你选对内容，并核对媒体与画布是否都已保存。

## 开始前

确认相关任务完成、原素材可读取、画布已保存。记录要交付的是某个生成结果、派生图片，还是整个可编辑项目，避免只发送一张截图。

## 按用途选择交付

| 需求               | 交付内容               | 接收方得到什么             |
| ------------------ | ---------------------- | -------------------------- |
| 直接使用图片或视频 | 下载真实媒体结果       | 最终文件，不包含节点关系   |
| 继续编辑画布       | 项目快照或正式项目包   | 可恢复的项目内容及包内资源 |
| 使用视频中的一帧   | 取帧图片               | 选定画面的静态结果         |
| 制作完整影片       | 把完成媒体导入剪辑工程 | 可继续编排的剪辑素材       |

## 使用项目验收

需要统一质量要求时，在画布或看板点击“项目验收”。需要写权限才能修改标准和记录结论；AI 辅助还需要模型使用权限，以及已启用的 chat + vision 模型。

1. 在“模板库”选择参考模板，点击“使用模板并配置”；也可以从空白开始。项目标准出现可编辑条目即表示复制完成。
2. 在“项目标准”增删或排序条目，填写要求、适用媒体、检查方式和必须／建议级别；绑定角色图等项目参考。应用节点不勾选时覆盖全部节点，条目按媒体类型生效。
3. 点击“保存草稿”只保存编辑；点击“发布并选择验收版本”生成新的生效版本。需要强制验收时，在发布前勾选对应开关。
4. 在“验收记录”选择输出版本和视觉模型，点击“开始验收”；也可在看板输出历史点击“验收当前版本”。完成后核对输出版本、标准版本、逐项结果与证据。
5. AI 建议始终需要人工确认。确认未通过、不适用或修改已有结论时填写说明；视频可设置问题起止秒数并“区间加密取样”，图片可填写归一化区域。
6. 处理所有待确认项后点击“确认整体验收结论”；必须项通过后形成通过记录。建议项的问题保留，不阻止通过。通过后再点击“设为最终输出”。

紧凑窗口中，在“验收清单／条目详情”之间切换编辑，在“输出预览／检查详情”之间切换审阅。切换面板会保留正在填写的内容。

**完成标志：** 验收记录显示通过，并在采用后由节点引用该输出版本。强制模式下，生成或上传仅增加候选，保留原最终输出；第一版也允许只有候选、尚无最终输出。

视频初检最多均匀抽取 12 帧，包含首尾附近画面；区间取样每次最多追加 12 帧。页面展示真实取样位置，不能据此宣称检查了整段连续动作、台词或音画同步。音频与文本首版仅人工验收。

## 返修与复验

先将问题确认为“需修改”，再生成“返修草稿”。编辑草稿并“保存为新提示词版本”后，返回工作台手动提交生成；此操作本身不调用生成模型。

新版本保存后，从原验收记录选择“选择返修版本复验”，选同一节点的另一个版本。复验重新检查全部适用条目，保留原问题、标准和历史结论；对比页可同步播放并定位问题时间段。

标准或参考修改需要重新发布。旧记录仍可查看，强制模式只认可当前标准版本的通过记录。项目快照携带标准、记录和证据，导入后作为历史保留，需要重新确认或复验，不直接继承通过授权。

修正已通过记录的单项结论或追加取样后，整体结论回到待确认。强制模式下，如果当前最终输出已没有有效通过记录，节点的通过标记会撤销，已采用的媒体仍保留。

| 现象                 | 处理方式                                                         |
| -------------------- | ---------------------------------------------------------------- |
| 缺少参考或模型不可用 | 补充项目参考、选择可用视觉模型，或明确改为人工检查后重新发布     |
| 检查失败或执行中断   | 查看错误与调用日志，确认状态后手动重新验收；不会自动重提模型请求 |
| 保存发生冲突         | 保留编辑内容，重新读取最新版本，再合并并保存，不能覆盖他人的结论 |
| 输出或证据不能删除   | 相关验收仍引用该内容，历史记录保留期间不直接删除                 |

## 下载结果并检查

1. 打开目标节点对应的完成结果，确认不是任务占位节点。
2. 下载实际图片或视频，使用容易辨认的名称保存。
3. 打开下载文件，检查尺寸、画面、透明度或时长等关键属性。
4. 批量交付时逐项核对，不把一条成功任务当作整批都成功。

**完成标志：** 下载文件可以独立打开，并且内容与目标节点一致。需要继续编辑时，还应另外保留工程。

## 导入与替换素材

通过节点或素材区上传、选择当前项目媒体；重新绑定时使用“替换素材”。跨项目复用走目标应用的素材导入或项目包流程，不粘贴旧节点 ID。

导入后的目标内容与来源不会自动同步。外部修改后的媒体需要正式上传并替换或新增节点；更换输入后，下游已经完成的生成结果不会自动重做。

## 派生结果怎样交付

视频节点取帧会下载图片并建立未连线派生节点；图片预览裁剪生成 PNG，保留原输入。确认派生节点已保存后，才把它当作工程的一部分使用。

> [!NOTE]
> 图片裁剪和视频取帧不会重新调用模型。已经得到结果时，优先修复保存或引用问题，而不是重新生成原视频。

## 与其他应用合作

需要字幕、混音和镜头顺序时，把完成媒体放进视频剪辑工坊。视频剪辑也提供向视觉工坊明确交接片段的用例；这不表示不同应用能互换完整工程格式。

交接后在目标工程核对素材副本与实际内容。来源后续变化不会自动替换已交付结果，需要明确重新导入并检查引用。
