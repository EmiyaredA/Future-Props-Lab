# 视觉创作工坊：导入导出与交付

只需要一张结果图，和需要别人继续调整节点、提示与连线，是两种交付。本篇帮你选对内容，并核对媒体与画布是否都已保存。

## 开始前

确认相关任务完成、原素材可读取、画布已保存。记录要交付的是某个生成结果、派生图片，还是整个可编辑项目，避免只发送一张截图。

## 按用途选择交付

| 需求               | 交付内容               | 接收方得到什么             |
| ------------------ | ---------------------- | -------------------------- |
| 直接使用图片或视频 | 下载真实媒体结果       | 最终文件，不包含节点关系   |
| 继续编辑画布       | 项目快照或正式项目包   | 可恢复的项目内容及包内资源 |
| 使用视频中的一帧   | 取帧图片               | 选定画面的静态结果         |
| 制作完整影片       | 把完成媒体导入剪辑工程 | 可继续编排的剪辑素材       |

## 使用节点验收

视频节点提供“动作迁移”验收。项目验收只有“验收模板”和“验收汇总”，模板与连接是固定只读项，不支持新增、复制、编辑或更换连接。管理员在部署配置中分别指定模型 API、Codex 和 Claude Code；未配置、未安装、未登录或账号未获准时，页面显示不可用，不会自动换连接。

1. 打开视频节点，在“生成设置”添加角色参考图片与原动作参考视频并保存。全部声明的图片作为角色参考、视频作为动作依据，不依赖文件名猜测。切换“节点验收”，选择已有方案；看到固定接入信息与自动资料列表即表示方案已绑定。
2. 核对资料来源。生成版本优先显示其实际提交的提示词、参考和预期规格；上传版本显示当前节点已保存的生成设置。缺少必要素材时，点击“返回生成设置”补齐后再检查，无需填写另一份验收配置。自适应尺寸或时长不会被猜成固定值。
3. 选择当前要检查的输出，点击“开始验收”。页面显示该输出版本和运行状态；模型方案返回逐项建议与证据，Agent 方案另有报告、问题区间与证据附件。检查只使用有界抽样，不能证明完整连续视频都已分析。
4. 在结果中查看证据并人工确认每个待确认项。需修改、不适用或改变已有结论时填写原因；连续动作、节奏和音画同步需要完整播放核对。处理完待确认项，点击“确认整体验收结论”，看到整体通过或需修改状态即表示本次人工结论已保存。
5. 回到“项目验收／验收汇总”，核对各节点当前版本、验收结果、最终输出和问题摘要。点击“打开节点”继续处理。验收只记录质量，不限制选择最终输出；验收完成或通过不会自动采用被检查的版本。

视频初检最多均匀抽取 12 帧；参考动作视频提供有界参考帧。Agent 每次最多追加 12 帧，每任务最多追加 24 帧，任务最长 15 分钟。取消、超时或进程中断后显示失败／取消，系统不自动重提付费请求。

**完成标志：** 节点保留输出版本对应的验收记录、证据和人工结论；项目汇总显示同一节点当前版本的状态，最终输出单独展示。

## 返修与复验

先将问题确认为“需修改”，再生成“返修草稿”。编辑后“保存为新提示词版本”，回到生成设置手动提交；保存草稿本身不调用生成模型。新版本出现后，在原记录选择“选择返修版本复验”，选同一节点的另一个输出再发起。复验创建新记录，保留原问题与结论，不能修改原检查依据。

输入变化后，旧记录仍可查看，页面会区分历史结果与当前依据。项目快照携带节点选择、执行依据、专属报告与证据；导入记录只读，固定连接在目标部署重新校验。旧项目标准和自存模板不自动转换成新模板，也不自动给节点绑定方案。

| 现象                   | 处理方式                                         |
| ---------------------- | ------------------------------------------------ |
| 缺少角色图或原动作视频 | 回到节点生成设置补齐并保存，再刷新依据           |
| 固定连接不可用         | 请部署管理员检查配置、CLI 安装登录或账号授权     |
| 检查失败或中断         | 查看原因，检查连接后手动重新验收                 |
| 上下文或 revision 冲突 | 重新读取并核对最新依据，再明确发起，不覆盖原记录 |
| 输出或证据不能删除     | 历史仍引用该内容，保留记录期间不能直接删除       |

## 下载结果并检查

1. 打开目标节点对应的完成结果，确认不是任务占位节点。
2. 下载实际图片或视频，使用容易辨认的名称保存。
3. 打开下载文件，检查尺寸、画面、透明度或时长等关键属性。
4. 批量交付时逐项核对，不把一条成功任务当作整批都成功。

**完成标志：** 下载文件可以独立打开，并且内容与目标节点一致。需要继续编辑时，还应另外保留工程。

## 导入与替换素材

通过节点或素材区上传、选择当前项目媒体；重新绑定时使用“替换素材”。跨项目复用走目标应用的素材导入或项目包流程，不粘贴旧节点 ID。

导入后的目标内容与来源不会自动同步。外部修改后的媒体需要正式上传并替换或新增节点；更换输入后，下游已经完成的生成结果不会自动重做。

## 派生结果怎样交付

视频节点取帧会下载图片并建立未连线派生节点；图片预览裁剪生成 PNG，保留原输入。确认派生节点已保存后，才把它当作工程的一部分使用。

> [!NOTE]
> 图片裁剪和视频取帧不会重新调用模型。已经得到结果时，优先修复保存或引用问题，而不是重新生成原视频。

## 与其他应用合作

需要字幕、混音和镜头顺序时，把完成媒体放进视频剪辑工坊。视频剪辑也提供向视觉工坊明确交接片段的用例；这不表示不同应用能互换完整工程格式。

交接后在目标工程核对素材副本与实际内容。来源后续变化不会自动替换已交付结果，需要明确重新导入并检查引用。
