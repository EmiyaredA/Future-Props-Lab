# 视觉创作工坊：导入导出与交付

## 原素材与工程

下载单个生成结果适合交付图片或视频；项目快照适合继续编辑。单张截图无法恢复节点、连线、提示草稿和媒体关系。

导出前先检查任务已完成、素材可读取和画布保存成功。需要批量交付时逐项确认结果，保留有意义的文件名称与来源说明。

## 素材导入

通过节点或素材区上传、选择当前项目的媒体。重新绑定应使用替换入口。要跨项目复用，走目标应用的素材导入或项目包流程，不粘贴旧节点 ID。

导入后的内容与来源不会自动同步；目标项目的调整属于目标作品。

## 视频帧和图片裁剪

视频节点取帧下载图片并建立派生节点。图片预览裁剪生成 PNG，保留透明度；结果仍需保存到画布才成为持久结构。

交付给剪辑时选择完成的真实媒体，不使用任务占位节点。视频剪辑向视觉工坊交接片段是明确用例，不代表所有应用之间都可以交换完整工程。

## 后续修改

外部修改后的媒体通过正式上传替换或增加节点。先保留原作品版本，再核对连线与引用；替换一个源素材后，下游已完成生成结果不会自动重做。
