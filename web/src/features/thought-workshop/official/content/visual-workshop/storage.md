# 视觉创作工坊：保存与素材管理

## 画布版本

修改画布后观察保存状态。发生版本冲突时保留当前草稿并读取最新快照，再选择界面提供的处理方式；不要连续提交旧 revision。

上传、生成结果落盘和画布保存是不同阶段。素材上传成功但节点保存失败时，先恢复画布写入，不再重复上传或调用模型。

## 任务恢复

任务列表记录提交、运行和结果状态。刷新或关闭页面后重新查询任务；离开不代表取消。提交阶段中断会安全失败，禁止自动重提，需先确认远端情况。

生成已有结果但本地保存失败时使用结果恢复入口。画布节点关联任务，但节点复制不会把任务再执行一遍。

## 素材与项目

项目素材用于节点引用。移除节点不表示删除原始媒体；先检查素材归属和引用，再使用正式清理入口。

裁剪与取帧产生派生素材，原输入保留。裁剪保存失败会保留已上传结果，可重试同一节点；冲突必须明确处理，不生成多个相同副本。

## 验收顺序

确认任务完成、原素材可预览、画布已保存，再离开或导出。发现预览失败时先排查素材是否落盘和鉴权，不靠重做模型请求恢复本地缺失文件。
