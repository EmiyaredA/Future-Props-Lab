# 视觉创作工坊：保存与素材管理

视觉任务有三个容易混淆的阶段：模型处理、结果保存、画布更新。本篇帮助你逐项确认、把上传素材放入指定分类与分组，并在中断后继续使用已有结果，避免重复生成。

## 每次任务后的验收顺序

1. 查看任务记录，确认生成是否已经结束。
2. 打开原始媒体，确认结果已落盘且能够预览或下载。
3. 核对目标节点绑定的素材、提示和连线。
4. 等待画布保存成功，再离开或导出项目。

**完成标志：** 任务、媒体和画布三个状态都符合预期。只有节点缩略图出现，不能代替保存检查。

## 画布保存与版本冲突

编辑画布后观察保存状态。网络失败或版本冲突时保留草稿，读取当前快照，再按界面提供的方式处理。重复提交旧 revision 不会把两个版本自动合并。

通过 SDK 保存整份画板时，必须显式提供 `nodes` 和当前 `expected_revision`，并携带完整 `edges`；即使只修改分类或分组，也先读取最新画板再提交原节点与连线。省略 `nodes` 返回 422，原画板不变；显式空列表表示删除全部节点。保存后重新读取，确认节点数量、连线和目标分组符合预期。

上传成功但节点保存失败时，先修复画布写入；已有素材不必再上传。生成结果存在但项目版本冲突时，同样先处理项目保存，不再请求模型。

## 中断后恢复任务

| 状态                       | 正确处理                                 |
| -------------------------- | ---------------------------------------- |
| 刷新或关闭页面             | 重新查询原任务，而不是直接新建同一任务   |
| 提交阶段中断               | 检查现有记录与远端情况；系统不会自动重提 |
| 远端已有结果、本地保存失败 | 使用结果恢复入口，优先保存现有输出       |
| 节点复制后没有原任务       | 属于预期，副本解除任务与批次关系         |
| 结果可读但画布未保存       | 保留结果，恢复或解决当前画布写入         |

> [!WARNING]
> 关闭页面不等于取消供应商任务。重新请求可能再次计费；先确认原任务状态，再明确发起新任务。

## 原素材与派生素材

### 上传到指定分类与分组

1. 在看板左侧「项目素材」点击「上传素材」，展开「上传到」区域；默认带入当前节点的分类与分组，可以改选或选「未分类」。也可以从目标分类的更多菜单选择「上传到此分类」。
2. 选择「上传分类」和可选的「上传分组」，再点「选择文件」，可一次选择多张图片或多个视频、音频文件。切换分类会清空先前的分组选择。
3. 等待上传完成，在目标分类或分组下查看新增节点，再重新打开项目确认归类仍然保留。

**完成标志：** 本批上传的节点均位于所选分类／分组，媒体可以预览，重新打开项目后位置不变。分类与分组用于项目内整理，不改变原文件在本机的目录。

目标分类或分组已变更时重新选择；出现版本冲突先处理当前画布保存。批量上传中途失败时，已完成的文件和节点保留，只重新选择未完成的文件。

### 保留原始媒体

媒体节点引用项目素材。移除节点不等于删除原文件；清理前检查素材归属及引用，再使用正式入口。

裁剪和取帧产生新的结果，原输入保留。裁剪保存失败会保留已上传结果，可重试同一节点保存；出现冲突需要明确处理，不应借机生成多个相同副本。

### 将 GIF 上传为视频输出版本

1. 在看板选中视频节点，点击右侧「输出版本」旁的「上传版本」，选择本地 GIF。
2. 等待上传完成。GIF 的完整一次动作会转换为无声 MP4，保留每帧停留时间；循环次数不写入视频。透明区域使用黑底，绿幕等不透明背景保留。
3. 播放输出预览，检查最后一帧和总时长，再刷新项目确认新版本仍为最终输出。后续引用和取帧使用这份视频。

**完成标志：** 输出版本增加且来源为「上传」，预览可以播放，下载得到 MP4。若要保留原始 GIF，请将它上传到图片节点。

文件损坏、超过上传大小或画布尺寸限制时不会新增版本；转换最长等待 120 秒。遇到版本冲突先处理画布保存，再由自己决定重新上传，系统不自动重试。

### 删除人工上传的输出版本

1. 在看板选中节点，在右侧「输出版本」中找到来源为「上传」的版本，点击该卡片下的「删除」。
2. 核对确认弹窗中的版本编号，再点击「删除版本」。删除最终输出时会切换到剩余的最新版本；删完最后一版则清空输出，节点、提示词和项目原文件仍保留。
3. 检查版本列表与「最终输出」标记，刷新后再次确认。后续上传沿用递增编号，不复用已删除编号。

**完成标志：** 已删除的版本从列表中消失，预览显示新的最终版或「暂无输出」，项目素材中的原文件仍可读取。

如果提示版本被固定引用，先到下游节点解除该固定引用，再重新删除；保存冲突时先处理画布保存，系统不自动重试删除。跟随最终输出的引用会在下次生成时使用新的最终版；清空输出后须先补充上游结果。已有生成任务和结果不受影响。

## 保存后检查什么

重新打开画布，确认节点仍在、输入连线正确、媒体能够读取。下载结果检查实际尺寸和时长，不能只用缩略图判断交付成功。

如果预览失败，依次检查素材是否落盘、原文件是否可读取、登录与网络状态。已存在的文件问题不应通过重复模型调用解决；需要定位具体调用阶段时查看调用日志。
