# 视觉创作工坊：常见问题与能力边界

画布问题先分成三类：节点组织不对、模型请求失败、结果或项目未保存。本篇按现象给出处理路径，避免通过重复生成来修复本地问题。

## 排查前记录

记下当前账号、画布项目、目标节点和任务状态。先确认问题发生在提交前、生成中、结果保存还是画布保存阶段，再查看对应反馈。

## 按现象处理

| 现象                       | 可能原因                         | 处理步骤                                   |
| -------------------------- | -------------------------------- | ------------------------------------------ |
| 模型选不到                 | 空间、启用状态、能力或权限不匹配 | 核对当前账号与任务类型，再检查可用模型     |
| 文字测试通过但媒体生成失败 | 测试的不是同一能力               | 用匹配图片或视频输入的最小请求验证         |
| 节点标题改了，素材没变     | 标题只用于识别                   | 使用“替换素材”，核对实际媒体与输入连线     |
| 新方案用了旧参考           | 外部输入连线仍指向旧来源         | 逐项检查目标节点所有输入，尤其是选区外来源 |
| 复制节点后没有原任务       | 副本主动解除任务和批次关联       | 确认新参数后明确提交，不把复制当作重新生成 |
| 刷新后无法粘贴节点组       | 剪贴板只在当前画布会话保留       | 跨会话或项目使用正式导入与项目包           |
| 远端已经生成，本地显示失败 | 结果保存或下载失败               | 查看任务详情，优先恢复原结果               |
| 取帧后节点没有连线         | 派生图片默认独立                 | 检查结果后手动连接需要的生成目标           |
| 删除节点后文件仍在         | 节点使用位置与源素材分开         | 检查引用后用正式素材清理入口               |

## 保存失败与提交中断

保存失败时保留当前草稿，查清素材是否已经存在，再处理画布写入。版本冲突先读取服务器快照，不连续重复旧版本提交。

> [!WARNING]
> 提交中断不表示供应商没有收到请求。系统不会自动重提；先查询原记录和费用相关反馈，再决定是否发起新任务。

## 修复后怎样确认

1. 打开目标节点，核对真实媒体与输入。
2. 查询原任务的最终状态。
3. 等待画布保存成功，重新进入后检查节点与连线。
4. 下载关键结果，检查实际画面与时长。

不以缩略图、占位节点或模型文字说明代替最终文件验收。

## 当前能力边界

单个画布最多保存 1000 个节点、2000 条连线。粘贴节点组前先核对粘贴后的总量；超限时整组不会加入，原节点、输入连线和输出版本仍保留。保存成功后重新进入项目，核对新增节点及其输入引用，确认修改已落盘。

视觉创作工坊用于素材创作与节点关系组织；连线不会直接把视频拼成成片。字幕、声音混合、镜头节奏和完整多轨输出在视频剪辑工坊完成。

裁剪与取帧是确定性派生，不是重新生成。素材或提示变化不会自动重做已完成结果，需要明确提交后续任务。
