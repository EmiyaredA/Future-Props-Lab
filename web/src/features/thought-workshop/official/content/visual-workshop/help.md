# 视觉创作工坊：常见问题与能力边界

## 模型选不到或提交失败

检查空间、模型启用状态、能力和使用权限。参考图或视频格式不支持时，修正输入；文字测试通过不能证明媒体生成也可用。

## 节点标题改了，素材没变

标题是识别信息。用“替换”重新绑定素材，再核对生成输入，连线和卡片位置不会改变源文件。

## 复制后为什么没有原任务

副本保留草稿和素材，解除任务及批次关系，避免复制触发模型调用。剪贴板只适用于当前画布会话，刷新或离开会清空；跨项目采用正式导入方式。

## 结果已经生成，却显示失败

查任务详情，区分供应商失败与本地结果保存失败。已有远端结果时优先恢复落盘。提交中断不自动重提，重复调用可能计费。

## 预览与最终文件

取帧和裁剪是确定性派生操作，不是重新生成。最终交付检查下载的真实文件与时长，不以缩略图或占位画面验收。

本应用用于视觉素材创作，不替代多轨剪辑工程。需要字幕、声音混合和完整成片时进入视频剪辑工坊。
