# Live2D 工坊：功能概览与快速开始

想让一张分层立绘能够微笑、点头，并继续用于桌面角色，可以先在 Live2D 工坊做一个参数和一段短动作。完成本节后，你会有一份保存过的原生角色工程，能重新打开检查绑定，也能导出透明画面用于交付。

## 准备角色原画

制作需要当前账号的内容写权限，不要求配置生成模型。准备分层 PSD 或透明 PNG，确认画布尺寸、部件名称与透明边缘。多张 PNG 不会自动知道彼此应放在哪里，导入后需要自行整理位置。

> [!TIP]
> 若还没有分层原画，可打开只读的内置 Amadeus 工程，选择“创建可编辑副本”，再回项目列表打开副本练习。不要把查看内置工程当作已经创建了自己的角色。

## 从部件做到一个短动作

1. 点击“新建角色”，命名并打开。在“模型”页通过“导入素材”加入 PSD 或 PNG；遇到不支持内容时先处理导入提示。
2. 在左侧对象树逐个选择部件，检查位置、叠放和可见性。用“适应窗口”看整体，用“定位选中对象”看细节。
3. 到“绑定”页选择一个参数，在默认值和极值下制作能辨认的变化，例如嘴部微笑。先拖动参数检查两端及中间值。
4. 到“动画”页新建短动作，在起点和终点记录参数关键帧。播放检查后清除手动预览值，再确认实际动作仍正确。
5. 点击“保存”，等待顶部“已保存”。在“交付”页下载工程包；需要逐帧画面时使用透明 PNG 序列。

## 检查你的成果

重新打开工程后，对象树、参数和动作都应仍在。默认姿态不能出现明显断缝；拖动参数应连续变化；动作循环首尾不应突然跳回另一种姿态。只有画面文件、但不能再调整网格和绑定，不算保留了完整工程。

> [!NOTE]
> 保存角色不会自动替换桌面助手。需要使用这个角色时，回项目卡片菜单明确选择“设为 Amadeus 形象”；桌宠则有单独的创建入口和固定来源快照。
