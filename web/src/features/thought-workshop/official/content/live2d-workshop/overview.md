# Live2D 工坊：功能概览与快速开始

Live2D 工坊把分层立绘制作成可编辑角色，管理网格、变形器、骨骼、参数和动作。浏览已有角色无需生成模型，制作需要空间编辑权限。

## 建立第一份角色

1. 点击“新建角色”并命名。
2. 在“模型”页导入分层 PSD 或 PNG，核对原画尺寸、透明区与图层名称。
3. 在对象树选部件，检查叠放、位置与可见性，用适应窗口查看整体。
4. 到“绑定”制作一个简单参数变化，再到“动画”记录短动作。
5. 保存后在“交付”检查当前版本，下载工程包或透明 PNG 序列。

首次可只制作一个微笑参数，检查默认值和两端，再增加点头动作。不要在错误分层上直接堆大量动画。

## 内置角色与个人工程

内置 Amadeus 工程只读，可创建可编辑副本。保存自己的角色后，可在卡片菜单明确“设为 Amadeus 形象”；编辑工程本身不会自动切换头像。

角色包 `.fpllive2d` 保存可编辑工程。透明序列是画面交付，不能恢复绑定。
