# Live2D 工坊：主要操作流程

## 部件与绑定

在对象树检查图层、父级、顺序和透明边缘。独显帮助查看遮挡内容，验收前恢复整体可见性。网格过粗会限制嘴角、发梢等细节，先调整网格再记录关键形。

旋转变形器处理整体转动，曲面变形器处理局部弯曲。把部件挂到正确父级，逐个试调，避免重复位移。

半身骨架模板只是起点。选中部件和目标骨骼，打开权重热图，用画笔调整影响范围，再试调旋转检查两端。重置试调姿态后保存，试调不自动成为正式动画。

## 参数关键形

在绑定页选参数与参数值，调整网格或变形器，确认关键形显示已记录。默认值和极值都应检查；改变参数范围后复查插值及多参数组合。

## 动作与表情

新建动作，设名称、帧率和时长。移到某帧调整参数，记录关键帧，再到另一帧记录新值。按需要设置保持、线性或缓入缓出插值，播放检查循环首尾。

静态参数组合可保存为表情。验收动作前清除手动预览值，避免预览覆盖动画结果。状态绑定选择动作、表情和播放方式后逐项预览，不因保存绑定就替换内置助手。
