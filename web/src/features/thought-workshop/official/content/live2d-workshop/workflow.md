# Live2D 工坊：主要操作流程

一个点头动作看起来不自然，问题可能在原画部件、参数关键形，也可能在动作时间轴。按本节顺序先让角色在静态参数下变形正确，再把参数变化组织成动作，能避免用更多关键帧掩盖绑定问题。

## 先检查部件和父级

在对象树选中部件，核对叠放顺序、位置、透明边缘和父级。使用独显检查被遮挡的部件，完成后恢复整体可见性。嘴角、发梢等细节需要合适的网格密度，先调网格再记录关键形。

旋转变形器适合整体转动，曲面变形器用于局部弯曲。把部件挂到正确父级后单独试调，检查是否发生重复位移。使用半身骨架模板时，仍需为具体角色检查绑定。

## 骨骼与权重试调

选中部件和目标骨骼，打开权重热图，再用画笔调整影响范围。试调旋转时同时观察关节附近和远端；只有热图颜色改变，不代表形变已经自然。检查完重置试调姿态，再继续正式参数和动作制作。

> [!NOTE]
> 试调姿态用于检查绑定，不会自动成为正式动画。要让变化随时间播放，仍需在动作中记录参数关键帧。

## 记录参数关键形

在“绑定”页选择“当前参数”和“参数值”，调整目标网格或变形器，检查关键形列表是否显示“已记录”。分别检查默认值、两端极值和中间插值，再组合多个参数观察轮廓。

修改参数范围后重新试拖，不要假设旧关键形仍覆盖新的范围。若多个参数一起改变时才出错，先分别验收每个参数，再缩小组合问题。

## 把参数变化变成动作

1. 在“动画”页新建动作，设置名称、帧率和时长。
2. 在起始帧调整参数预览值并“记录关键帧”，移动到另一帧后再次调整和记录。
3. 按需要选择保持、线性或缓入缓出插值，播放检查运动中段与循环首尾。
4. 验收前“清除手动预览值”，确认画面由动作本身决定。静态参数组合可另存为表情。
5. 配置执行状态绑定时，分别选择动作、表情和播放方式，并逐项预览，最后保存工程。

> [!TIP]
> 先做一个两端清晰的单参数动作。动作是时间轨道，表情是静态预设，两者配合前应分别验证。
