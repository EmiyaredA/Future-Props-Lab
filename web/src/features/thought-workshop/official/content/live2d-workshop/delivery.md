# Live2D 工坊：导入导出与交付

## 输入与工程交换

PSD 或 PNG 用于制作原生角色；`.fpllive2d` 用于完整工程交换。动作、表情 JSON 只携带可映射参数数据，需要目标角色已有对应参数。

Cubism 运行 ZIP 应包含 `.model3.json`、`.moc3`、贴图及引用资源。预检通过后挂载，可用 FPL、Cubism 或并排视图对照。

## 转换 Cubism

转换先读取可映射网格、UV、贴图和参数，展示报告，再明确创建新的原生工程。物理、姿势、复杂遮罩与多参数联动可能近似或无法转换；转换后检查默认姿态和极值。

## 三类输出

| 目标                      | 输出                                               |
| ------------------------- | -------------------------------------------------- |
| 继续编辑                  | `.fpllive2d` 工程包，含文档、素材及附件            |
| 透明画面                  | 按表情与动作组合导出 PNG 序列 ZIP                  |
| 在 Cubism Editor 重新绑定 | PSD、逐层 PNG 和可映射动作／表情 JSON 的素材交接包 |

素材交接包不生成 `.moc3` 或 `.cmo3`。

## 序列导出

先保存并更新预览，设置裁切、尺寸、帧率和范围，再做兼容与范围检查。结束帧不包含在输出中，静态输出一帧。提交后从记录下载并检查透明边缘、遮罩和时长。
