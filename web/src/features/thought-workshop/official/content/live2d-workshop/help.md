# Live2D 工坊：常见问题与能力边界

## 角色拉伸、断缝或重复移动

先检查分层、网格、父级与权重。重复位移常与不合适的父级或参数叠加有关。用默认姿态、两端极值和组合参数分别验收，再修动画。

## 动作与预期不符

清除手动参数预览值，核对动作范围、关键帧和插值方式。表情是静态预设，不等于动画；循环需检查首尾衔接。

## Cubism 对照加载失败

核对 ZIP 引用完整性及当前部署的运行 SDK。运行附件失败不代表原生工程丢失。转换只能尽力映射，无法恢复 Cubism Editor 的原始 `.cmo3`。

## 保存角色后头像没变化

回项目卡片明确选择“设为 Amadeus 形象”。该选择属于当前账号和 Workspace 的本机偏好，缺失角色会回退内置形象。

## 能直接编译 Cubism 模型或输出视频吗

当前不提供 Cubism 模型编译，也不把素材交接包变成 `.moc3`。原生交付使用工程包或透明 PNG 序列，视频、外部输入驱动及完整原生物理不作为已支持能力。

发生版本冲突先备份本地文档，再决定重新读取；不要连续覆盖提交。
