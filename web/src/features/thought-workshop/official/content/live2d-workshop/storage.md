# Live2D 工坊：保存与素材管理

角色已经绑定好之后换一版原画，最重要的是保留可恢复的旧工程，并逐项确认新素材与旧绑定仍兼容。本节区分工程保存、原画替换、运行附件和桌面角色选择，避免“看见新图”就误以为所有数据已经更新。

## 保存和冲突处理

编辑后查看顶部草稿状态，点击“保存”并等待“已保存”。离开编辑器时应处理未保存提示。发生版本冲突时先“下载本地文档备份”，再决定是否“重新读取服务器版本”。

> [!WARNING]
> 重新读取服务器版本会放弃当前未保存修改，并不自动合并。仅备份文档 JSON 也不等于已经备份全部素材；需要完整交接或恢复时应保存工程包。

## 安全更新原画

1. 在替换前导出当前 `.fpllive2d` 工程包，保留已验证的角色版本。
2. 通过“模型”页重新导入 PSD，阅读画布尺寸和素材替换提示，确认这是同一角色的原画更新。
3. 若使用多张 PNG，重新核对部件位置和尺寸。不要只依靠相同名称判断图像是否对应。
4. 检查父级、网格、遮罩和已有参数：默认姿态正确后，再看极值和多参数组合。
5. 播放已有动作，确认没有新增断缝或重复变形，保存并重新打开验证。

分层结构改变时，旧网格未必仍适用；角色外观相似也不代表可以省略绑定检查。

## 运行附件与可编辑工程

Cubism 运行 ZIP 作为角色附件保存，可用于与原生角色对照。转换时会创建新的原生工程，原工程与附件保留。`.moc3` 是运行资源，不是完整可编辑源工程，也不能由它恢复出原始 `.cmo3`。

## 助手与桌宠分别更新

“设为 Amadeus 形象”保存的是当前账号、账号的本机偏好。角色缺失或加载失败时会回退内置形象；保存绑定本身不会自动改变这个选择。

桌宠创建时复制角色文档与必需素材作为固定快照。后续改角色不会即时改变桌宠，应到桌宠的试玩与来源区域明确检查更新。

> [!TIP]
> 保留“已验收工程包”和“正在修改工程”两份材料，尤其是在重导入 PSD 或大量调整参数前。保存成功证明写入完成，视觉验收仍需自己播放确认。
