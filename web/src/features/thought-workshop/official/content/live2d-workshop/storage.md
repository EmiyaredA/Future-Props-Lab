# Live2D 工坊：保存与素材管理

## 保存角色

顶部显示草稿与保存状态。修改后点击保存，离开前处理未保存提示。冲突时先下载本地文档备份，再决定重新读取服务器版本；重新读取会放弃当前草稿，不是自动合并。

工程文档、素材、绑定与动作属于当前 Workspace。重大绑定调整前下载工程包；仅备份 JSON 未必包含素材。

## 原画更新

多张 PNG 导入后需自行整理位置。PSD 重导入会检查画布尺寸并提示替换；先备份工程，再确认是否为同一角色的更新。

重新分层、改画布或替换部件后，检查父级、网格、遮罩和已有参数。图片看起来相近不代表旧网格仍适用。

## Cubism 附件

运行 ZIP 作为角色附件保存，可用于对照。转换时创建新的原生工程，原工程和附件保留。不能将 `.moc3` 当作完整的可编辑源文件。

## 头像与桌宠

设为 Amadeus 形象是当前账号与空间的本机偏好，角色缺失时会回退内置形象。桌宠创建时复制固定角色快照，后续角色修改不会自动更新桌宠。

交付前在默认姿态、参数极值和组合姿态复查。保存成功只证明数据写入，不能替代视觉绑定验收。
