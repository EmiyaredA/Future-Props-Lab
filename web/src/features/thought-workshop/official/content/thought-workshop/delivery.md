# 思绪工坊：导入导出与交付

## 选择交付格式

| 格式     | 适合用途           | 内容                                               |
| -------- | ------------------ | -------------------------------------------------- |
| 完整备份 | 无损迁移、继续编辑 | 目录、首页、正文、标签、历史、回收站与引用文件     |
| Markdown | 文本交换           | 常用结构、LaTeX、Mermaid、画板源码；素材和附件随包 |
| HTML     | 离线阅读           | 排版、图片、公式、图表；有附件时随 ZIP             |

卡片列表的完整备份覆盖当前空间用户知识库；库内导出只覆盖当前库。官方指南随应用提供，不包含在备份中。

## 导入

通过导入入口选择工坊 ZIP、单篇 Markdown 或包含相对图片及附件的 Markdown ZIP。列表导入 Markdown 建新库，库内导入进入当前库。备份导入创建独立副本并重新分配 ID，不覆盖已有项目。

外部网页图片不会自动下载。检查缺失文件提示；ZIP 内引用应指向包内的相对路径。Markdown 内容包上限 128 MiB，完整备份由服务器校验。

## 导出前检查

等待保存成功，再选择格式。Markdown 无法完整表达颜色、字号、对齐和复杂表格等格式，阅读转换提示；需要完整保留时用备份。

HTML 适合离线阅读而非恢复全部编辑历史。交接有附件的 HTML ZIP 时保留目录结构，不只发送 HTML 文件。

旧版本备份通过正式导入兼容处理，不手工改 schema 或数据库。历史作者名称用于展示，不会关联成接收空间的新账号。

## 交付 UML 与信息图

- 单幅图用于幻灯片或报告：在图表操作栏选择“导出 SVG”或“导出 PNG”。SVG 适合保留清晰线条，PNG 适合直接贴图；这两种成品不保留笔记历史，也不能作为原生画板重新编辑。
- 整篇笔记用于离线阅读：导出 HTML，图表与画板转成可显示的图形，画板图片一并包含。若结果是 ZIP，应解压并保留相对目录再打开。
- 需要继续改图：使用完整备份。它保留画板场景、Mermaid 源码、引用文件和历史；导入后图片引用会重新映射到接收空间。
- 用 Markdown 往返交换：Mermaid 使用 `mermaid` 代码块，画板使用 `fpl-canvas` JSON 代码块。带图片时发送整个 Markdown ZIP，不要只复制正文中的素材 ID。

通用 Markdown 阅读器通常不认识 `fpl-canvas`，会显示源码而非信息图；接收方只需阅读时选 HTML 或图片。导入本应用可恢复可编辑画板，未知场景版本、损坏连接或缺失图片应按提示修正来源文件。官方文章中的短图形标识是内置资源引用，个人笔记导出会写入完整场景，不能把这个短标识当作用户导入格式。
