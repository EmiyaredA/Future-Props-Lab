# 思绪工坊：导入导出与交付

给同事阅读一篇笔记和把整套资料迁到另一空间，需要不同交付物。本篇先帮你选格式，再检查图片、附件、图表与画板是否随包完整交付。

## 先选交付目标

| 格式           | 适合用途             | 保留范围与限制                                         |
| -------------- | -------------------- | ------------------------------------------------------ |
| 完整备份       | 迁移并继续编辑       | 目录、首页、正文、标签、历史、回收站与引用文件         |
| Markdown       | 文本交换和应用内往返 | 常用结构、LaTeX、Mermaid、画板源码；不完整表达所有排版 |
| HTML           | 离线阅读             | 排版与可读图形；有附件时随 ZIP 交付                    |
| 单幅 SVG / PNG | 放进报告或幻灯片     | 图的成品外观，不含笔记历史和原生编辑结构               |

列表的完整备份覆盖当前空间用户知识库；库内导出只覆盖当前库。官方指南随应用提供，不包含在用户备份中。

完整备份 version 6 保留全部历史、命名快照、引用素材，列表备份还包含 Workspace 共享模板；继续接收旧版包。导入重新映射文档、历史、模板和素材 ID，包外引用转为普通文字并给出警告。个人筛选、阅读状态和本机草稿不迁移，损坏导入整体回滚。

## 整库离线 HTML

1. 保存当前文档，点击“导出整库 HTML”；只读入口也可导出可访问内容。
2. 解压整个 ZIP，打开 `index.html`，通过目录、首页和文档内部相对链接导航。
3. 断网后检查画板、Mermaid、公式、图片和附件；未包含的引用目标有明确标记。

**完成标志：** 不连接应用也能导航和阅读资料。文档、目录及素材清单来自同一个数据库读快照。HTML 用于阅读，继续编辑应保留完整备份。

## 导出一份可交付的笔记

1. 完成图表编辑或返回笔记，等待保存成功。
2. 按接收方需要选择 Markdown、HTML 或完整备份。
3. 下载后检查文件类型。若是 ZIP，保留整个包；阅读时解压并保持相对目录结构。
4. 打开结果，核对标题、图片、附件、公式和至少一幅图。
5. 交付时说明用途：用于阅读，还是可以在本应用导入后继续编辑。

**完成标志：** 接收方拿到完整文件集合，而不只是一个缺图片的 HTML 或仅带素材 ID 的文本。

## 导入到目标位置

1. 先进入目标 Workspace。选择从列表导入，或进入目标个人库后使用库内导入。
2. 选择工坊备份 ZIP、单篇 Markdown，或含相对图片和附件的 Markdown ZIP。
3. 阅读转换及缺失文件提示；外部网页图片不会被自动下载。
4. 导入完成后核对目录、正文与素材预览，再继续编辑。

列表导入 Markdown 会建立新库，库内导入进入当前库。备份导入创建独立副本并重新分配 ID，不覆盖已有项目；历史作者展示不会变成接收空间的新账号关联。

> [!NOTE]
> Markdown 内容包上限为 128 MiB，完整备份由服务器校验。SDK 的服务端 Markdown 转换还保留 200,000 字符限制；大型资料和画板优先使用完整备份。

## 图表与画板怎么交接

Mermaid 使用 `mermaid` 代码块；画板使用 `fpl-canvas` JSON 代码块。带图片时发送整个 Markdown ZIP，导入本应用后可恢复可编辑场景。通用 Markdown 阅读器通常只显示画板源码，接收方只阅读时选择 HTML 或图片。

单图操作栏的“导出 SVG”保留清晰线条，“导出 PNG”方便直接贴图；两者不能恢复画板元素。需要修改连线、图标或分区时，保留完整备份或可往返的 Markdown 数据。

官方文章的短图形标识只是内置资源引用，不能当作用户导入格式；复制到个人笔记后，导出会写入完整场景。

## 导入失败时

缺少图片就补齐包内资源及相对路径；未知场景版本或损坏连线先核对原文件；复杂排版转换出现差异时改用完整备份。不要手工改数据库或伪造版本号绕过校验。
