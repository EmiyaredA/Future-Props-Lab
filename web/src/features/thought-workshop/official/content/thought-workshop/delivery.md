# 思绪工坊：导入导出与交付

给同事阅读一篇笔记和把整套资料迁到另一空间，需要不同交付物。本篇先帮你选格式，再检查图片、附件、图表与画板是否随包完整交付。

## 先选交付目标

| 格式           | 适合用途             | 保留范围与限制                                         |
| -------------- | -------------------- | ------------------------------------------------------ |
| 完整备份       | 迁移并继续编辑       | 目录、首页、正文、标签、历史、回收站与引用文件         |
| Markdown       | 文本交换和应用内往返 | 常用结构、LaTeX、Mermaid、画板源码；不完整表达所有排版 |
| HTML           | 离线阅读             | 排版与可读图形；有附件时随 ZIP 交付                    |
| 单幅 SVG / PNG | 放进报告或幻灯片     | 图的成品外观，不含笔记历史和原生编辑结构               |

列表“更多 → 完整备份”覆盖当前空间用户知识库；库内导出只覆盖当前库。官方指南随应用提供，不包含在用户备份中。

完整备份 version 9 保留全部历史、命名快照、引用素材，列表备份还包含 Workspace 共享模板；继续接收旧版包。导入重新映射文档、历史、模板和素材 ID，包外引用转为普通文字并给出警告。多维表格保留多表结构、字段（含显示格式、选项颜色、人员与编组）、记录、共享视图、填色条件、差量历史和附件；导入、复制与模板应用重映射内部标识。个人筛选、阅读状态和本机草稿不迁移，损坏导入整体回滚。

## 手动同步到飞书

当前 Workspace 的管理员与拥有者先在[集成中心配置飞书连接](/apps/thought-workshop/official-knowledge-bases/general/documents/integrations)。准备一份已经授权给应用的专用新版文档。可以粘贴 `/docx/` 链接，也可以粘贴知识库中的 `/wiki/` 链接；检查目标时会解析成对应的新版文档。表格、旧版文档和其他知识库节点不能同步。应用需要知识库节点读取权限，以及该文档的编辑权限。检查失败时，侧栏会给出打开这篇文档、开通权限和开启机器人的入口。

1. 打开普通文章，点顶部「同步到…」。文章保存成功后打开同步侧栏；手机端以弹层显示。
2. 选择飞书连接，粘贴目标链接，点「检查目标」。核对显示的文档标题与正文，编辑权限应为可编辑，再点「绑定文档」。一篇文章只绑定一个目标，同一目标只能由一个有效绑定维护。
3. 点「预览并同步」。左侧「写入快照」按飞书能接收的标题、段落、列表、引用、代码和表格排版，右侧是飞书当前正文。先处理红色阻断，再核对黄色样式提示。没有红色阻断时，「确认并同步」可以点击。
4. 点「确认并同步」，在弹层中明确「确认替换并同步」。首次同步同样替换整篇原正文；保留飞书文档标题，文章标题写入正文。
5. 等待「同步成功」，打开飞书文档检查正文、图片与普通表格。继续编辑本地文章后，会显示「有修改待同步」。本地保存与外部同步分别显示状态。

**完成标志：** 最近记录显示同步成功，飞书正文与预览一致。图片上传到飞书，不使用本地鉴权图片链接。同步中可能短暂同时显示新旧正文，只有新内容和图片核验完成后才移除旧正文。

嵌入的多维表格按当前视图写成飞书普通表格，预览里会提示这是一份快照：之后改表需要重新同步，筛选、填色和编组不会保留。画板、Mermaid、公式、附件和文档导航节点仍会阻止同步，预览显示位置。提示框转引用，折叠内容展开；字号、颜色、图片裁剪、表格列宽及列表展开等差异显示提示，这些提示不阻止同步。单篇转换超过 1,000 个飞书块时需拆分文章。

| 状态或提示                 | 下一步                                                                                                                                                                                             |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文章、绑定或目标已变化     | 重新预览，并针对当前飞书正文重新确认                                                                                                                                                               |
| 飞书正文与上次同步不同     | 比较双方内容后明确决定是否覆盖；目标再次变化会暂停                                                                                                                                                 |
| 需要核对                   | 打开飞书检查新旧内容，再点「核对远端并尝试继续」；只有已确认步骤且远端一致才继续                                                                                                                   |
| 存在未确认步骤或远端已变化 | 人工处理现场后点「我已核对，结束此任务」，随后重新预览；应用不会自动重放不确定写入                                                                                                                 |
| 目标被删除或失去权限       | 检查授权，或解除旧绑定后绑定另一份文档                                                                                                                                                             |
| 知识库链接无法读取         | 点「打开这篇文档」，在右上角「…」→「更多」→「添加文档应用」并设为可编辑。列表没有应用时，点「开通权限」开通「查看知识空间节点信息」，并点「开启机器人」，发布新版本后再检查目标                    |
| 错误码 1770032             | 应用还不是这篇文档的协作者。点「打开这篇文档」，用同样的「添加文档应用」设为可编辑。列表没有应用时，点「开通权限」开通「查看、评论、编辑和管理云文档」，并点「开启机器人」，发布新版本后再检查目标 |
| 嵌入了多维表格             | 预览会把它写成当前视图的普通表格。核对左侧「写入快照」里的表格后可以继续同步；源表以后的修改要重新预览并同步                                                                                       |

飞书多个请求之间没有原子替换保证。解除绑定与删除本地文章会保留飞书文档；完整备份、复制、模板和导入不会携带有效外部绑定，恢复后的文章须重新绑定。首版为整篇手动单向同步，不自动创建文档或读取飞书修改来更新本地文章。

运行中或需要核对的任务会阻止永久删除文章，避免丢失处理入口。文章可先进入回收站；若提示外部同步尚未结束，请恢复文章，在同步侧栏核对并结束任务，再永久删除。

## CSV 交换

1. 打开多维表格，在“多维表格更多操作 → 导入 CSV”选择文件，确认第一行是否为表头、追加当前表或创建新表。
2. 点“预览和字段映射”，检查前 20 行及总数。为每列选择目标字段；新表的名称列保持文本，其他列可以选择文本、数字、日期、复选框或链接。
3. 点“校验类型与映射”，修正提示中的行列错误；点“确认导入”，刷新核对记录数。校验失败整批不写入，追加后总数不能超过 5,000。
4. 在“多维表格更多操作 → 导出全部记录 / 导出当前筛选结果”选择全部记录或当前筛选结果，检查表头、日期和选择字段的标签。CSV 仅交换当前表的数据；保留视图、附件字节、历史和引用结构请选择完整备份。

**完成标志：** 含逗号、引号或换行的字段仍能正确往返，错误行不会留下部分记录。首版不提供 Excel、公式或自动化。

普通笔记单独导出时，嵌入表格只生成当前可读视图的静态内容，不自动包含整个源表或历史。附件以数量提示保留，请从原表下载；继续编辑完整表格应交付完整备份。

## 整库离线 HTML

1. 保存当前文档，在“更多 → 导出整库 HTML”；只读入口也可导出可访问内容。
2. 解压整个 ZIP，打开 `index.html`，通过目录、首页和文档内部相对链接导航。
3. 断网后检查画板、Mermaid、公式、图片和附件；未包含的引用目标有明确标记。

**完成标志：** 不连接应用也能导航和阅读资料。文档、目录及素材清单来自同一个数据库读快照。HTML 用于阅读，继续编辑应保留完整备份。

## 社区阅读如何交付

社区文章“更多 → 导出可读文章 HTML”只导出当前获授权的已发布正文和素材。隐藏的父文档不出现在目录，包外文档引用标为不可用；未发布首页使用社区简介，不开放历史。可编辑成员也不能借导出获取原 Workspace 的私人文件、回收站或旧版本。

原知识库的完整备份不自动恢复社区发布与成员授权；导入的新副本默认未发布，需要目标 Workspace 管理者重新选择文章并授权。收藏、社区阅读位置和本机草稿属于账号状态，不迁移。

## 导出一份可交付的笔记

1. 完成图表编辑或返回笔记，等待保存成功。
2. 按接收方需要选择 Markdown、HTML 或完整备份。
3. 下载后检查文件类型。若是 ZIP，保留整个包；阅读时解压并保持相对目录结构。
4. 打开结果，核对标题、图片、附件、公式和至少一幅图。
5. 交付时说明用途：用于阅读，还是可以在本应用导入后继续编辑。

**完成标志：** 接收方拿到完整文件集合，而不只是一个缺图片的 HTML 或仅带素材 ID 的文本。

## 导入到目标位置

1. 先进入目标 Workspace。选择从列表导入，或进入目标个人库后使用库内导入。
2. 选择工坊备份 ZIP、单篇 Markdown，或含相对图片和附件的 Markdown ZIP。
3. 阅读转换及缺失文件提示；外部网页图片不会被自动下载。
4. 导入完成后核对目录、正文与素材预览，再继续编辑。

列表导入 Markdown 会建立新库，库内导入进入当前库。备份导入创建独立副本并重新分配 ID，不覆盖已有项目；历史作者展示不会变成接收空间的新账号关联。

> [!NOTE]
> Markdown 内容包上限为 128 MiB，完整备份由服务器校验。SDK 的服务端 Markdown 转换还保留 200,000 字符限制；大型资料和画板优先使用完整备份。

## 图表与画板怎么交接

Mermaid 使用 `mermaid` 代码块；画板使用 `fpl-canvas` JSON 代码块。带图片时发送整个 Markdown ZIP，导入本应用后可恢复可编辑场景。通用 Markdown 阅读器通常只显示画板源码，接收方只阅读时选择 HTML 或图片。

单图操作栏的“导出 SVG”保留清晰线条，“导出 PNG”方便直接贴图；两者不能恢复画板元素。需要修改连线、图标或分区时，保留完整备份或可往返的 Markdown 数据。

官方文章的短图形标识只是内置资源引用，不能当作用户导入格式；复制到个人笔记后，导出会写入完整场景。

## 导入失败时

缺少图片就补齐包内资源及相对路径；未知场景版本或损坏连线先核对原文件；复杂排版转换出现差异时改用完整备份。不要手工改数据库或伪造版本号绕过校验。

## 导出卡片与动态目录

HTML 保留引导卡片、两列卡片组和响应式排版，动态目录在导出时冻结为当前可读文章列表。社区导出通过社区访问适配器解析，未发布、撤回或无权访问的目标不产生标题、简介和链接。

Markdown 导出前显示排版转换提示：卡片变成可访问目标的标题、简介和链接，动态目录变成链接列表。要继续编辑同样的卡片结构，请保存完整备份；导入完整备份会重映射包内引用，包外私人卡片成为不可访问卡片，动态父目录的包外引用清除。

**完成标志：** 打开导出的 HTML 核对标题与卡片；用窄屏检查单列；在社区中导出时不能读到源知识库的私人目录。完整备份导入后，卡片可以继续选择文档和排序。
