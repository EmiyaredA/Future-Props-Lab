# 思绪工坊：保存与素材管理

## 自动保存和离开保护

停止输入约一秒后保存，也可点保存或按 Ctrl/Cmd+S。中文输入法组合输入结束后才提交。站内切换文档、筛选、搜索或进入其他页面时，未保存内容继续受到保护。

保存失败会保留本地草稿，允许重试或继续编辑。版本冲突暂停自动保存；比较当前服务器内容，选择采用或另存副本，不静默覆盖其他人的更新。

## 历史记录

成功保存的标题、正文、排版和标签形成历史。收藏、置顶和目录移动不产生正文历史。打开历史后只读显示原排版，可关闭“显示更改”阅读干净版本，或定位上一处、下一处改动。

还原历史会生成新的还原记录，当前内容仍能在历史里找到。永久删除文档会删除其历史。旧数据升级前没有记录的过程不能被还原。

## 文件与回收站

图片和附件属于空间公共文件库。删除正文卡片只解除引用；历史或回收站仍引用时文件管理禁止删除。

整库移入回收站会隐藏内容；恢复整库保持原目录和原有文档回收站状态。首页不能单独移动或删除。

官方库没有持久项目记录，不进入个人备份和回收站。修改个人同名库不会改变官方指南。

## 画板如何保存

画板元素、连接线、分组和样式都保存在当前笔记中。每次拖动结束、调整尺寸或修改属性都会成为正文变化；选中元素、缩放视图、平移画面不产生正文历史。全屏编辑器的“返回笔记”结束画板操作，但不等于服务器已确认保存，请继续检查笔记保存状态。

Mermaid 保存源码，画板保存版本化场景。两者都随笔记历史恢复；恢复历史时图片仍通过托管素材引用读取。画板图片和普通正文图片适用相同的 Workspace 归属与文件删除规则，不能手工删掉磁盘文件来清除画板内容。

复制官方图得到的新笔记进入个人保存、备份与回收站流程，官方原图不进入这些流程。图中的标题、元素文字和连接线标签可参与笔记正文搜索。
