# 思绪工坊：保存与素材管理

笔记的正文、图表、画板和附件需要一起可靠保存。本篇帮助你判断修改是否落地，回到某个历史版本，并在清理文件时避免破坏旧内容。

## 保存并安全离开

1. 完成输入后暂停约一秒，观察自动保存；也可点击保存或按 Ctrl/Cmd+S。
2. 中文输入法先完成组合输入，系统再提交内容。
3. 等待“已保存”，再切换文档、筛选、搜索或其他页面。
4. 出现失败时保留草稿，按提示重试或继续编辑。本机 IndexedDB 保存标题、正文、标签和基准版本，刷新、崩溃、断网或冲突后可恢复。存储失败会显示提示，此时先保留页面完成保存。

**完成标志：** 保存状态成功，重新打开文档仍能看到当前内容。站内导航受到未保存保护，但保护提示不能代替你确认保存结果。

重开时可恢复草稿、查看服务端、另存副本或丢弃。基准版本变化进入冲突处理，不直接覆盖服务器。草稿按账号、账号、文档与标签页隔离，只保存在本机；清理浏览器存储也会清理草稿。保存成功仅清除服务器已确认的草稿，不影响其他标签页。

## 处理版本冲突

版本冲突会暂停自动保存。比较当前服务器内容后，明确选择采用它或另存副本；系统不会静默覆盖别人的更新。

> [!WARNING]
> 选择服务器版本前，确认自己的改动是否需要保留。连续提交旧 revision 不是合并方法，关闭页面也不会自动解决冲突。

## 用历史查看和还原

1. 保存当前内容后打开文档历史，选择记录，再选择另一条比较基准，可比较任意两个已加载版本。
2. 查看原排版与更改；需要干净阅读时关闭“显示更改”，也可定位上一处、下一处改动。
3. 核对标题、正文与标签后再执行还原。
4. 等待成功，重新检查当前文档和最新历史记录。

标题、正文、排版和标签成功保存后形成历史。收藏、置顶和目录移动不产生正文历史。还原会新增一条记录，之前的当前内容仍可在历史中找到；永久删除文档会删除其历史。

用“命名此快照”为选中历史添加阶段稿或交付版名称。名称可修改，标记可删除；删除标记不删除底层历史。创建前完成当前保存，还原继续校验当前修订号。

## 个人阅读状态

保存筛选、最近访问和阅读位置按账号同步，桌面与 Web 可共用。同一正文版本恢复上次的滚动进度，正文改变后优先找回原段落，找不到时按相对进度恢复。记录位置不改变正文修订号。阅读官方文章只更新个人阅读状态；授权编辑则使用同一笔记保存和历史用例。个人偏好和本机草稿不进入知识库备份，只读成员也可维护自己的偏好。

## 图表和画板保存在哪里

| 内容     | 持久保存                         | 不会产生正文变化     |
| -------- | -------------------------------- | -------------------- |
| Mermaid  | 源码                             | 仅放大查看           |
| 画板     | 元素、连线、分组、样式、图片引用 | 选择、平移与缩放视图 |
| 普通图片 | 素材引用与显示参数               | 仅查看原图           |

每次拖动结束、调整尺寸或修改画板属性会写回正文。“返回笔记”结束全屏编辑，不等于服务器已确认保存；返回后继续核对笔记状态。

## 文件与回收站

图片、画板图片和附件属于空间公共文件库。删除正文中的使用位置只解除相应引用；历史或回收站仍使用文件时，文件管理会阻止删除。

整库移入回收站会隐藏内容；恢复整库保持原目录，以及原先已在文档回收站里的状态。首页不能单独移动或删除。需要找旧文档时区分整库回收站与库内文档回收站。

官方库不写入持久项目记录，不进入个人备份或回收站；复制官方图得到的新笔记则参与正常保存、历史和备份。给个人库起同样的名字不会改变官方文档。
