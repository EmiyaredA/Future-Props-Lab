# 思绪工坊：常见问题与能力边界

笔记问题通常发生在定位、编辑、保存或交付其中一层。本篇按界面现象给出处理顺序，先保住草稿，再修复原因。

## 排查前先确认

核对当前 Workspace、知识库和文档；查看是否正在使用搜索、收藏或其他筛选。记录问题发生在正文、全屏画板、历史预览还是导出文件中。

## 按现象处理

| 现象                    | 可能原因                           | 处理步骤                                         |
| ----------------------- | ---------------------------------- | ------------------------------------------------ |
| 找不到文档              | 空间或知识库不对、筛选隐藏、已删除 | 核对归属，清空筛选，再查看库内或整库回收站       |
| 大纲没有条目            | 只有加粗或放大的普通段落           | 把章节改为真正的标题块，再打开大纲               |
| 文件无法删除            | 正文、画板、历史或回收站仍引用     | 查看引用详情，通过正式入口处理需要清理的内容     |
| 图片或附件粘贴失败      | 剪贴板限制、格式问题、素材迁移失败 | 核对权限与格式，改用带素材 Markdown 包或完整备份 |
| Mermaid 显示错误        | 节点文字、引号或连接语法有误       | 打开“编辑图表”，以模板验证，再逐项加回关系       |
| 画板内容看不见          | 视图平移或缩放偏离                 | 使用“适应窗口”，再确认元素是否存在               |
| 返回笔记后修改没保留    | 正文仍未保存或存在冲突             | 保留草稿，检查笔记状态并处理错误                 |
| 图中文字被截断          | 元素太小、文本或连线过密           | 增大元素，缩短文字，必要时拆成分区或多图         |
| Markdown 里只有画板源码 | 通用阅读器不认识 `fpl-canvas`      | 导入本应用继续编辑，或改交付 HTML/SVG/PNG        |
| 看不到“复制到个人笔记”  | 当前只读权限                       | 阅读、放大或导出图；需要副本时申请内容写权限     |

## 保存失败时保留什么

先保留本地正文和修改意图，不立刻刷新。版本冲突暂停自动保存，需要比较服务器内容后明确选择采用或另存副本。单独导出的一张 PNG 只能保留外观，不能恢复图形和连接线。

修复后等待“已保存”，重新打开文档核对，再检查一次历史或导出结果。只有视图看起来恢复，并不能证明正文已经落地。

> [!TIP]
> 复杂图先缩小问题范围：保留一个节点和一条关系验证，再逐步恢复内容。Mermaid 语法错误不会丢弃源码；画板误操作可在当前编辑会话中撤销。

## 当前能力边界

知识库是文档容器，不提供 RAG、附件全文解析或多人实时共同编辑。应用内没有 AI 写作按钮或侧栏；获准 Agent/SDK 可以通过正式接口读取并按版本修改内容。

画板用于技术制图，包含图形、文字、内置图标、图片、连接线和分区；不包含自由画笔、便签、实时协作，也不会与 Mermaid 自动互转。

官方文档由版本发布维护。管理员不能在线改写官方原文，个人同名库也不会替换官方内容。发现界面与说明不同，先核对版本、权限和所在入口。
