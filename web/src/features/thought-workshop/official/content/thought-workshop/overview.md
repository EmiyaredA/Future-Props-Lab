# 思绪工坊：功能概览与快速开始

思绪工坊组织知识库、嵌套文档与富文本正文。这里的知识库是文档容器，不是模型检索服务；普通记录与整理无需模型。

## 写下第一篇文档

1. 打开思绪工坊。在官方文档专区阅读指南，在“我的知识库”管理自己的内容。
2. 点击“创建知识库”并命名，例如“产品研究”。
3. 进入知识库，首页默认阅读；可编辑首页写简介与常用资料。
4. 用目录的“＋”创建文档，填写标题与正文，等待显示“已保存”。
5. 返回所有知识库，再打开确认内容和目录都保留。

## 目录与阅读

文档可以有子文档，用空正文的父文档也能组织层级。当前库的搜索、全部文档、最近编辑、收藏和回收站只查询当前库。

个人库支持名称、简介和封面。官方库由应用发布提供，支持阅读、目录、正文与图中文字搜索，不提供原文编辑、导入和删除。技术原理库通过 UML 与信息图说明实现；具有内容写权限的账号可将单幅图复制成个人笔记。

## 用图说明想法

笔记支持两种可编辑图：Mermaid 通过源码表达类图、时序图、状态图、ER 图和流程图；画板通过图形、图标、连接线与分区表达架构和对比。两种图都能放大阅读并导出 SVG 或 PNG。普通笔记里的图表随正文保存，导出的图片用于展示，不替代可编辑原稿。

## 权限

个人库内容在当前 Workspace 内按权限共享。只读成员浏览已有内容，具有写权限的成员编辑。私人账号切换和空间切换前，应处理当前草稿。
