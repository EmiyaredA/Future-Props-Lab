# 思绪工坊：功能概览与快速开始

想把研究资料整理成目录，或者写一篇带 UML 和信息图的说明？思绪工坊把知识库、嵌套文档、富文本、附件和历史放在一起。本篇先带你保存一篇可重新打开的文档。

## 开始前

确认当前账号与内容写权限。普通记录、整理和制图不需要模型。这里的知识库是**文档项目容器**，不提供模型检索服务。

“我的知识库”归当前账号私有。其他账号与管理员都不能直接读取，只有显式发布并授权的文章才向社区开放。

## 写下第一篇文档

1. 打开思绪工坊，在侧栏“我的知识库”管理当前账号的项目；“知识社区”集中提供官方指南与用户发布。
2. 点击“创建知识库”，命名为“产品研究”，进入该库。
3. 进入后直接编辑首页。它与普通文档使用同一编辑器，可写简介或常用资料；笔记标题可以单独修改，知识库名称仍在侧栏。
4. 在目录的“＋”入口创建文档，填写标题与正文，加入一个真正的标题块。
5. 等待“已保存”，返回我的知识库，再打开这篇文档。

**完成标志：** 文档出现在正确目录，重新打开后标题和正文都保留；右侧“本页目录”能够识别标题块，并按层级定位正文。

## 先认识目录，再扩展内容

左侧是知识库的多级文档树，右侧“本页目录”是当前文章的多级标题目录。窄窗口可从顶栏分别打开笔记目录与本页目录；目录定位和折叠不修改正文。

文档可以带子文档，空正文的父文档也能组织层级。当前库的搜索、全部文档、最近编辑、收藏和回收站围绕当前知识库工作。

在“我的知识库”点击卡片封面或底部的“打开”，进入该库首页。底部操作栏可导出、重命名或移入回收站。“更多操作”提供修改简介和更换封面，保存后可在卡片上核对更新。先建立少量有意义的目录，再添加标签；无需在写第一篇笔记前设计所有分类。

## 管理任务与创作资料

在“新建文档”中选择“多维表格”，得到带名称、状态、截止日期和备注的第一张表。一个文档可以包含多张表，各自配置字段与视图。文本、数字、单选、多选、日期、复选框、链接、附件和笔记引用适合整理任务与资料；名称字段始终保留在第一列。

在独立页面配置表格、看板或月历视图，再在普通笔记插入“多维表格视图”块。嵌入块展示最新记录，单元格修改独立保存；筛选和隐藏列只影响展示。刷新后记录保留且父笔记没有新增正文修订，即可确认两种保存互相独立。

## 用哪一种图表达想法

| 内容                           | 推荐形式     | 保存的是什么           |
| ------------------------------ | ------------ | ---------------------- |
| 类关系、调用时序、状态和流程   | Mermaid 图表 | 可编辑源码             |
| 架构分区、图标、图片与对比说明 | 信息图画板   | 图形、连线、位置和样式 |
| 数学表达式                     | 公式         | LaTeX 内容             |
| 外部文档或原始资料             | 附件         | 托管文件引用           |

两种图都可放大阅读、导出 SVG 或 PNG；导出的图片适合展示，继续修改应保留笔记原稿。

> [!TIP]
> 先用两三个节点讲清一个关系，再增加分区和连接线。技术文档中的图属于标准笔记块；获授权后可编辑原文，需要独立副本时使用普通笔记复制或备份导入。

## 社区中的官方库与用户发布

知识社区采用紧凑书架，按“全部”“官方文档”“用户发布”筛选，搜索知识库与可读文章。卡片显示作者、简介、可访问文章数和更新时间。“我的收藏”按账号保存社区知识库与官方库；“我的发布”用于管理自己负责的发布。

账号管理者可在知识库“更多 → 发布到知识社区”勾选文章，填写社区名称与简介，逐篇选择所有登录用户可读或仅指定成员可读。未勾选文章和以后新建文章默认不公开；未发布首页时，社区使用简介代替。发布的是同一份当前正文，保存后即更新社区，无须再次发布。

可读成员可以阅读、收藏和导出可读正文；可编辑成员还可修改标题、正文、标签及附件；可管理成员还可调整该文章的访问范围、成员角色和发布状态。这些授权不开放原账号、其他文档或历史。首次发布、增选文章、修改社区信息和整库撤回仍由源账号管理者执行。

**完成标志：** 用另一账号的账号打开社区，只看到已发布且获授权的文章，卡片计数与目录一致；普通笔记地址仍不可访问。撤回后社区立即关闭，原正文保留；回收站恢复不会自动重新发布。

## 官方库与原知识库的区别

官方文档是管理员维护并发布的普通知识库，使用相同的正文、图形、历史、搜索、收藏与导出能力。官方徽标属于整个发布库，只有平台管理员或管理员可设置；正文标签“官方”不能产生徽标。

新发布默认勾选“只读发布”。发布者与源账号管理者保留维护权限，其他读者需要逐篇编辑／管理授权，或匹配管理员设置的角色编辑授权。角色授权不增加可见文章，也不授予发布管理能力。私人入口继续使用账号权限。

平台管理员可在知识社区点击“导入现有官方文档”，先核对库、文章和图形数量，再确认导入。导入在当前账号新建私人笔记，不自动发布。进入普通编辑入口核对内容后，在“发布到知识社区”明确选择文章、官方标记、只读设置及管理员／管理员编辑角色。应用升级不覆盖这些笔记；再次主动导入创建新的独立副本。旧官方地址只定位已导入、已发布且当前可访问的官方文章，无匹配时显示提示。

接下来先掌握块插入和目录整理；需要长期保存与迁移时，再完成一次完整备份并验证导入。
