# 思绪工坊：功能概览与快速开始

想把研究资料整理成目录，或者写一篇带 UML 和信息图的说明？思绪工坊把知识库、嵌套文档、富文本、附件和历史放在一起。本篇先带你保存一篇可重新打开的文档。

## 开始前

确认当前 Workspace 与内容写权限。普通记录、整理和制图不需要模型。这里的知识库是**文档项目容器**，不提供模型检索服务。

“我的知识库”是工作空间中的业务内容，访问取决于当前空间权限，不应把这个名称理解成只有自己能看的私人文件夹。只读成员可以浏览，编辑需要写权限。

## 写下第一篇文档

1. 打开思绪工坊，上方“官方文档”阅读应用指南，下方“我的知识库”管理自己的项目。
2. 点击“创建知识库”，命名为“产品研究”，进入该库。
3. 首页默认用于阅读。需要说明研究范围时，用首页编辑入口写简介或常用资料。
4. 在目录的“＋”入口创建文档，填写标题与正文，加入一个真正的标题块。
5. 等待“已保存”，返回所有知识库，再打开这篇文档。

**完成标志：** 文档出现在正确目录，重新打开后标题和正文都保留；文档大纲能够识别标题块。

## 先认识目录，再扩展内容

文档可以带子文档，空正文的父文档也能组织层级。当前库的搜索、全部文档、最近编辑、收藏和回收站围绕当前知识库工作。

个人库可以维护名称、简介和封面。先建立少量有意义的目录，再添加标签；无需在写第一篇笔记前设计所有分类。

## 用哪一种图表达想法

| 内容                           | 推荐形式     | 保存的是什么           |
| ------------------------------ | ------------ | ---------------------- |
| 类关系、调用时序、状态和流程   | Mermaid 图表 | 可编辑源码             |
| 架构分区、图标、图片与对比说明 | 信息图画板   | 图形、连线、位置和样式 |
| 数学表达式                     | 公式         | LaTeX 内容             |
| 外部文档或原始资料             | 附件         | 托管文件引用           |

两种图都可放大阅读、导出 SVG 或 PNG；导出的图片适合展示，继续修改应保留笔记原稿。

> [!TIP]
> 先用两三个节点讲清一个关系，再增加分区和连接线。技术原理库中的图可以作为阅读示例；有写权限时可“复制到个人笔记”，得到独立可编辑副本。

## 官方库与个人库的区别

官方库随版本提供，支持目录、正文及图中文字搜索，不提供原文编辑、导入和删除。官方图复制后的个人笔记进入正常保存与备份流程，官方原图不会被修改。

接下来先掌握块插入和目录整理；需要长期保存与迁移时，再完成一次完整备份并验证导入。
