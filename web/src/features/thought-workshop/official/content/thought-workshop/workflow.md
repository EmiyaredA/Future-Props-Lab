# 思绪工坊：主要操作流程

本篇以一篇“方案说明”为例：先整理章节，再插入表格、图片和图表，最后保存一个可继续修改的信息图。开始前打开个人知识库中的可编辑文档。

## 写正文与建立结构

1. 填好文档标题，在空段落输入 `/`，或使用块旁“＋”，插入标题、列表、表格、图片、附件、公式或图表。
2. 用真正的标题块划分章节，检查文档大纲；只加粗或放大段落不会生成章节结构。
3. 选中文字使用排版浮层；移动、复制或删除整块内容时使用块手柄。
4. 桌面可以从留白框选连续块，手机使用块菜单中的等价操作。
5. 表格中按需增删行列、合并拆分和调整列宽；修改后检查长文本是否仍易读。

**完成标志：** 章节能从大纲定位，块顺序正确，保存状态没有错误。

## 整理目录与标签

首页和父文档正文下方自动展示子文档导航，不写入正文。搜索、收藏等列表每页加载 40 篇，用“加载更多”继续浏览；错误时可重试，切换筛选会重新载入。

文档菜单提供新建子文档、移动、排序或删除。拖到条目边缘做同级排序，拖到中部挂为子文档；键盘操作可使用上移、下移和“移动到”。

删除父文档时分清“只删当前并提升子项”和“删除整个子树”。标签输入用逗号分隔，Enter 或离开输入框提交，Escape 取消；Ctrl/Cmd+S 会先提交正在编辑的标签。

## 引用、查找和复用

1. 在正文输入 `@` 或点击“文档引用”，选择当前 Workspace 文档或官方文章；填写自定义文字可固定显示名称。
2. 点击引用打开目标，悬停或键盘聚焦查看摘要；在目标正文下方展开“反向链接”检查来源。
3. 按 Ctrl/Cmd+F 查找正文、Ctrl/Cmd+H 替换，按需开启大小写或整词匹配。上一处、下一处定位命中；全部替换一次撤销即可恢复。

**完成标志：** 目标改名或移动后引用仍有效，默认显示最新标题；失效目标显示不可用。替换只处理正文文字，不改公式源码、图形、引用 ID 和素材属性，输入法组合输入时暂停。只读入口仅查找。

打开“全局搜索与最近访问”，设置全文或仅标题、知识库、标签和收藏条件；Workspace 与官方内容分区展示，点击结果定位正文。保存筛选后可应用、改名或删除，最近访问最多 50 篇。

点击“文档模板”，将已保存正文存为独立模板，维护名称、说明、标签与正文，再创建新文档。点击“复制文档 / 子树”，选择目标知识库和父文档后确认。副本内部引用指向新 ID，外部引用及素材保留，不复制原历史、收藏和置顶；冲突时刷新信息后重新确认。

**完成标志：** 原文、模板和副本独立保存。用斜杠菜单插入“提示块”，可切换信息、备注、成功、警告和危险，块内正文可编辑、复制、搜索与导出。

## 图片和附件处理

图片可以上传、粘贴或拖入，再设置宽度、对齐、替代文字和图注；裁剪只改变显示范围。附件卡片显示文件名、类型、大小和下载入口，ZIP 不自动展开，也不提供附件全文解析。

富文本复制可以携带托管图片。同 Workspace 的知识库共用受校验素材；跨 Workspace 的普通文档引用降级为文字，图片仍需通过目标 Workspace 的素材校验，失败时不会插入半截正文。遇到剪贴板容量或权限问题，改用带素材的 Markdown 包或完整备份。

## 用 Mermaid 绘制关系图

1. 插入“图表”，点击“编辑图表”。
2. 在“UML 模板”中选择类图、时序图、状态图、ER 图或流程图。
3. 编辑“Mermaid 源码”，先改名称，再改关系。例如 `A[输入] --> B[处理]` 表示一条从输入到处理的箭头。
4. 等待预览更新，修复错误提示后收起源码，并使用“放大阅读”检查细节。

> [!NOTE]
> 模板会替换当前源码。需要保留原图时先复制图表块。语法错误会保留源码，不会自动转换成画板或静态图片。

## 建立信息图画板

1. 插入“画板”，点击预览中的“编辑画板”进入全屏编辑。
2. 从“画板模板”选择系统架构、请求流程、分层结构、数据流或对比说明。默认作为新分组插入并保留已有内容；需要清空重建时用“替换整板”并确认。
3. 在“添加图形”中选择矩形、圆角矩形、椭圆、菱形、文字、图标、图片或分区；图片由本机文件上传，图标使用内置集合。
4. 选中元素修改文字、字号、文字对齐、填充和边框，拖动调整位置，用尺寸手柄改变大小。文字溢出时按提示适配高度。
5. 从四侧连接点拖向另一图形；选中连线后设置标签、箭头及线型，重连保留这些属性。
6. Shift 多选或从空白处框选，使用对齐、分布、分组、层级、复制与删除整理画面。移动分组时成员一起移动。
7. 用撤销、重做检查结果，点击“返回笔记”，继续等待笔记保存成功。

平移、缩放和选择只改变视图；完成拖动、尺寸或属性修改才改变正文。画板不提供自由画笔、便签、实时共同编辑或与 Mermaid 自动互转。

## 复用官方图

在技术原理文章的图上点击“复制到个人笔记”，选择当前 Workspace 的个人知识库并提交。成功后新笔记保留源码或画板元素，并附原文链接。

副本独立于官方原图，官方更新不会覆盖你的批注。只读成员没有复制入口；目标库删除、权限变化或冲突时先检查目标，再决定是否重新提交。
