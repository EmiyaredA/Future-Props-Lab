# 思绪工坊：主要操作流程

## 组织文档

用文档菜单新建子文档、移动、排序或删除。拖到条目边缘同级排序，拖到中部挂为子文档；键盘可用菜单上移、下移和“移动到”。删除父文档时可只删当前文档并提升子项，或删除整个子树。

标签用于分类。点击添加或编辑标签，用逗号分隔，Enter 或离开输入框提交，Escape 取消。Ctrl/Cmd+S 会先提交正在编辑的标签。

## 富文本与块

空段落输入 `/`，或用块旁“＋”插入标题、列表、表格、图片、附件、公式与图表。选择文字使用排版浮层；块手柄负责移动、复制和删除。

桌面可从留白框选连续块，手机使用块菜单中的等价操作。标题样式生成文档大纲，不只是把普通文字改大。

表格可增删行列、合并拆分和调宽。图片可上传、粘贴或拖入，设置宽度、对齐、替代文字和图注，裁剪仅改变显示范围。公式保留 LaTeX，图表保留 Mermaid 源码，语法错误不会丢失源码。

## 附件与复制

附件卡片显示名称、类型、大小和下载入口；ZIP 不自动展开，不提供在线附件解析。上传失败按反馈重试，切换文档不会把结果插入另一篇。

富文本复制可携带托管图片；跨库粘贴先迁移图片，失败时不会插入半截正文。剪贴板容量或浏览器权限受限时改用 Markdown 包或完整备份。

## 绘制 UML 与流程图

1. 在空段落输入 `/`，选择“图表”，或从块插入菜单加入图表。
2. 点击“编辑图表”，从“UML 模板”选择类图、时序图、状态图、ER 图或流程图。模板会替换当前源码，已有图形需要保留时先复制图表块。
3. 在“Mermaid 源码”中改名称、参与者和关系。比如流程图的 `A[输入] --> B[处理]` 表示从输入到处理的箭头。
4. 等待预览更新。语法有误时修正源码；错误不会把源码替换成图片。收起源码后可用“放大阅读”查看细节。

## 建立信息图画板

1. 插入“画板”，点击预览的“编辑画板”，进入全屏编辑。
2. 从“画板模板”选择系统架构、请求流程、分层结构、数据流或对比说明；已有内容会被替换，确认“应用模板”后仍可撤销。
3. 在“添加图形”中选择矩形、圆角矩形、椭圆、菱形、文字、图标、图片或分区。图片选择本机文件上传；图标使用内置图标，不需要外部图标服务。
4. 选中元素，在属性栏修改文字、填充和边框。拖动图形改变位置，用选中后的尺寸手柄调宽高；从图形连接端点拖到另一图形，选中连接线可修改标签、箭头与线型。
5. Shift 多选或从空白处框选，再使用对齐、分布、分组、层级、复制或删除操作整理图。移动分组时，其成员一起移动；连接线随端点位置变化。
6. 用撤销、重做检查修改，点击“返回笔记”。移动结束或修改属性后已经写回正文，还要等笔记显示保存成功才关闭整个应用。

画板视图缩放与平移只改变观察位置，不修改正文。画板使用技术制图元素，不提供自由画笔、便签、实时共同编辑或 Mermaid 自动转换。

## 复用官方原理图

打开[技术原理知识库](/apps/thought-workshop/official-knowledge-bases/technical)，在需要的图上点击“复制到个人笔记”，选择当前 Workspace 的个人知识库并提交。成功后新笔记保留 Mermaid 源码或画板元素，并附原文章链接；副本与官方原图独立，版本更新不会覆盖你的批注。

只读成员可阅读、放大和导出官方图，但没有复制入口。目标库已删除、权限变化或版本冲突时按错误提示检查目标，不要连续重复提交创建请求。
