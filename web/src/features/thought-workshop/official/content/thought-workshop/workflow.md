# 思绪工坊：主要操作流程

本篇以一篇“方案说明”为例：先整理章节，再插入表格、图片和图表，最后保存一个可继续修改的信息图。开始前打开个人知识库中的可编辑文档。

## 写正文与建立结构

1. 填好文档标题，在空段落输入 `/`，或使用块旁“＋”，插入标题、列表、表格、图片、附件、公式或图表。
2. 用真正的标题块划分章节，检查右侧“本页目录”；支持一至六级标题，子章节按层级缩进。点击标题定位正文，点击父标题旁的箭头展开或收起子章节。只加粗或放大段落不会生成章节结构。
3. 选中文字使用排版浮层；移动、复制或删除整块内容时使用块手柄。
4. 桌面可以从留白框选连续块，手机使用块菜单中的等价操作。
5. 表格中按需增删行列、合并拆分和调整列宽；修改后检查长文本是否仍易读。

**完成标志：** 章节能从右侧目录定位，父级折叠只隐藏其子章节；滚动到子章节时祖先自动展开。窄窗口或收起目录后，可从顶栏“目录”重新打开，按 Escape 关闭弹层。目录导航不修改正文；块顺序正确，保存状态没有错误。

## 制作与官方文档相同的首页

1. 在知识库首页点“编辑首页”，在空段落输入 `/知识库首页`，选择“知识库首页”；也可从“新建文档 → 从模板新建”选择“知识库首页（内置）”建立独立文档。
2. 在引导卡片点“选择文档”，选择可访问的文章。使用“文档卡片样式”切换普通卡片或引导卡片，在“卡片引导文字”填写“从这里开始”等说明。
3. 编辑章节标题和介绍。在卡片组中“添加卡片”，用卡片的“上移”“下移”和“删除”调整文章顺序；整组仍可用块菜单复制和移动。
4. 在文档目录块中选择“当前知识库”或一个父文档，并切换列表或卡片。新建、移动或改名后，目录按当前可见条目更新。
5. 保存并刷新，检查引导卡片、卡片组和目录；在窄屏检查卡片自动变成单列。发布后用另一账号核对权限，失效卡片显示“文档不可访问”，不显示隐藏文章名称。

**完成标志：** 普通笔记、官方首页与社区正文使用相同的卡片和正文样式；引导卡片的“开始阅读”打开目标文章，卡片简介在页面内显示摘要，完整说明在目标正文中查看；标题和简介跟随目标更新，卡片排序在刷新后保持。默认的动态目录不包含知识库首页，只显示所选层级的子文档。隐藏的父文档不会通过目录块泄露名称。

## 整理目录与标签

首页和父文档正文下方自动展示子文档导航，不写入正文。搜索、收藏等列表每页加载 40 篇，用“加载更多”继续浏览；错误时可重试，切换筛选会重新载入。

文档菜单提供新建子文档、移动、排序或删除。拖到条目边缘做同级排序，拖到中部挂为子文档；键盘操作可使用上移、下移和“移动到”。

删除父文档时分清“只删当前并提升子项”和“删除整个子树”。标签输入用逗号分隔，Enter 或离开输入框提交，Escape 取消；Ctrl/Cmd+S 会先提交正在编辑的标签。

## 引用、查找和复用

1. 在正文输入 `@` 或点击“文档引用”，选择当前 Workspace 文档或官方文章；填写自定义文字可固定显示名称。
2. 点击引用打开目标，悬停或键盘聚焦查看摘要；在目标正文下方展开“反向链接”检查来源。
3. 点击顶栏“查找”或按 Ctrl/Cmd+F 查找正文；编辑时从顶栏“正文工具 → 查找替换”或 Ctrl/Cmd+H 替换，按需开启大小写或整词匹配。上一处、下一处定位命中；全部替换一次撤销即可恢复。

**完成标志：** 目标改名或移动后引用仍有效，默认显示最新标题；失效目标显示不可用。替换只处理正文文字，不改公式源码、图形、引用 ID 和素材属性，输入法组合输入时暂停。只读入口仅查找。

在知识库列表侧栏打开“搜索与最近访问”，设置全文或仅标题、知识库、标签和收藏条件；Workspace 与官方内容分区展示，点击结果定位正文。保存筛选后可应用、改名或删除，最近访问最多 50 篇。进入知识库后，侧栏只显示返回入口、库内搜索、视图与文档目录；先返回“我的知识库”或“知识社区”，再切换全局入口。

在“新建文档 → 从模板新建”进入模板管理，将已保存内容存为独立模板，维护名称、说明和标签，再创建新文档。多维表格模板保留当前表、字段、视图和记录，新实例重新分配 ID。在笔记“更多 → 复制文档 / 子树”，选择目标知识库和父文档后确认。副本内部引用指向新 ID，外部引用及素材保留；普通笔记不复制原历史，多维表格保留自己的表格历史。收藏和置顶不复制，冲突时刷新信息后重新确认。

**完成标志：** 原文、模板和副本独立保存。用斜杠菜单插入“提示块”，可切换信息、备注、提示、成功、警告和危险，并设置提示块标题，块内正文可编辑、复制、搜索与导出。

## 逐篇发布与授权

1. Workspace 管理者打开知识库“更多 → 发布到知识社区”，选择文章。首页需要单独勾选；新文档默认不发布。
2. 填写社区名称与简介，点击文章旁“权限”，选择“所有登录用户可读”或“仅指定成员可读”。用准确账号名添加可读、可编辑或可管理成员。
3. 需要批量授权时勾选“批量”，把当前文章权限应用到选中文章；检查预览后发布。公开正文、实际引用的素材和封面一起开放，历史不开放。
4. 用不同 Workspace 的账号在“知识社区”查看目录、搜索和导出；未发布的父文档不显示名称，可读子文档提升到可见目录顶层。
5. 可编辑成员点“编辑文档”，保存后在原知识库核对同一正文；阅读时格式工具栏隐藏。可管理成员在文章“更多 → 文章访问权限”调整角色、批量权限或取消该篇发布。
6. Workspace 管理者在“我的发布 → 更多 → 管理发布”增选文章或撤回整个库。

**完成标志：** 另一空间的访问者只能操作获授权文章；保存更新原正文，源 Workspace 仍记录编辑历史。撤回或移入回收站后社区立即不可访问，恢复原文不会自动发布。权限或版本变化时停止保存，保留本机草稿，先核对授权和当前版本；不自动覆盖或重试。保存失败后离开可选择保留本机草稿。

社区选择素材、上传、粘贴、引用与导出均经过发布接口，不查询源空间其他文件。当前正文之外的跨库链接显示不可用；导出仅包含当前可读文章，不能借此查看私人目录与历史。

## 图片和附件处理

图片可以上传、粘贴或拖入，再设置宽度、对齐、替代文字和图注；裁剪只改变显示范围。附件卡片显示文件名、类型、大小和下载入口，ZIP 不自动展开，也不提供附件全文解析。

富文本复制可以携带托管图片。同 Workspace 的知识库共用受校验素材；跨 Workspace 的普通文档引用降级为文字，图片仍需通过目标 Workspace 的素材校验，失败时不会插入半截正文。遇到剪贴板容量或权限问题，改用带素材的 Markdown 包或完整备份。

## 管理多维表格

1. 在个人知识库“新建文档”选择“多维表格”。新文档显示“数据表 1”和“表格”视图，包含名称、状态、截止日期、备注四个字段。
2. 点击“＋ 记录”，在“记录详情”逐项编辑；也可直接在单元格中编辑。文本编辑点“完成”，等待顶部显示“已保存”后刷新核对。点击行号打开全部字段，详情中可删除记录。
3. 点击“字段”增加文本、数字、单选、多选、日期、复选框、链接、附件或笔记引用，设置字段名称、选项颜色和顺序。名称字段不能删除或改变类型。修改后点“预览字段变更”，检查受影响记录及前后值，再点“确认保存字段”；有无效值时不能保存。
4. 用“＋ 数据表”建立第二张表；用“＋ 视图”建立新视图，在“视图设置”选择看板及单选分栏字段，或日历及日期字段。看板有“未分配”栏；拖动卡片更新状态，月历拖动更新日期，无日期记录在独立列表中打开详情。
5. 在“视图设置”配置全部/任一满足的筛选、多字段排序、一级分组、隐藏列和列顺序。表格表头的列宽滑块调整共享列宽。隐藏和筛选只改变展示；其他有权限的读者仍可查看全部字段和记录。
6. 表格单元格用方向键移动、Enter 编辑，Shift 扩展选择；复制得到 TSV，粘贴先校验整块数据，任何无效值都不会部分保存。长表虚拟滚动并分页读取，每表最多 5,000 条记录、50 个字段。
7. 普通笔记输入 `/多维表格`，插入“多维表格视图”，选择文档、数据表与视图。嵌入显示最新记录，可在目标可编辑时修改单元格或增删记录；字段与视图配置在源表完成。

**完成标志：** 三种视图显示同一批数据，刷新后字段、记录、配置仍在；嵌入编辑只更新源表，父笔记正文没有待保存变更。删除目标或视图时嵌入提示不可用，可重新加载或重新选择目标。

视图配置由文档共享；当前表/视图、滚动位置属于个人阅读状态。失败或冲突停止自动提交，并保留本机操作草稿。先核对最新源表，再明确重新提交或丢弃；重新打开时可选择恢复草稿。社区需要分别发布和授权父文章、目标表格；父文章可读不会授予表格权限，编辑记录还需目标可编辑，撤回后附件立即不可读。

## 用 Mermaid 绘制关系图

1. 插入“图表”，点击“编辑图表”。
2. 在“UML 模板”中选择类图、时序图、状态图、ER 图或流程图。
3. 编辑“Mermaid 源码”，先改名称，再改关系。例如 `A[输入] --> B[处理]` 表示一条从输入到处理的箭头。
4. 等待预览更新，修复错误提示后收起源码，并使用“放大阅读”检查细节。

> [!NOTE]
> 模板会替换当前源码。需要保留原图时先复制图表块。语法错误会保留源码，不会自动转换成画板或静态图片。

## 建立信息图画板

1. 插入“画板”，点击预览中的“编辑画板”进入全屏编辑。
2. 从“画板模板”选择系统架构、请求流程、分层结构、数据流或对比说明。默认作为新分组插入并保留已有内容；需要清空重建时用“替换整板”并确认。
3. 在“添加图形”中选择矩形、圆角矩形、椭圆、菱形、文字、图标、图片或分区；图片由本机文件上传，图标使用内置集合。
4. 选中元素修改文字、字号、文字对齐、填充和边框，拖动调整位置，用尺寸手柄改变大小。文字溢出时按提示适配高度。
5. 从四侧连接点拖向另一图形；选中连线后设置标签、箭头及线型，重连保留这些属性。
6. Shift 多选或从空白处框选，使用对齐、分布、分组、层级、复制与删除整理画面。移动分组时成员一起移动。
7. 用撤销、重做检查结果，点击“返回笔记”，继续等待笔记保存成功。

平移、缩放和选择只改变视图；完成拖动、尺寸或属性修改才改变正文。画板不提供自由画笔、便签、实时共同编辑或与 Mermaid 自动互转。

## 复用官方图

在技术文档文章的图上点击“复制到个人笔记”，选择当前 Workspace 的个人知识库并提交。成功后新笔记保留源码或画板元素，并附原文链接。

副本独立于官方原图，官方更新不会覆盖你的批注。只读成员没有复制入口；目标库删除、权限变化或冲突时先检查目标，再决定是否重新提交。
