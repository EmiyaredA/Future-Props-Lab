# 创意工坊与固定版本安装

创意工坊在同一部署内分享工具 API、MCP、Skill 和组合方案。公开条目是发布内容，不会向浏览者暴露作者空间里的私人凭证。

## 查找与安装

1. 打开创意广场，按类型或关键词筛选，阅读用途、作者与版本。
2. 在详情执行“检查安装依赖”，核对固定依赖版本、目标名称和待配置内容。
3. 遇到名称冲突时修改目标名称并重新检查，不覆盖已有资源。
4. 确认安装后，到集成中心检查产生的副本，补充当前环境配置、验证并启用。

安装需要集成管理权限。工具 API、HTTP MCP 与 Skill 默认禁用；API 和 HTTP MCP 不复制作者的凭证。stdio MCP 需要目标空间管理员配置本机命令。

## 固定版本的含义

安装的是独立副本，发布者更新不会自动修改你已经安装的配置。方案固定引用具体版本，也不会自动运行。依赖版本撤回可能阻止新的安装，但不会自动删除已有副本。

## 发布自己的内容

在“我的创作”建立草稿，整理名称、用途、输入输出说明和所需依赖。发布前检查是否含真实凭证、本机私人路径或未授权素材。发布与撤回通过正式界面完成；需要修改已发布内容时按版本流程处理。

## 验收安装结果

先测试单个能力，再测试组合方案。核对验证状态、工具输入和实际输出；“安装完成”只表示复制配置成功，不能代表外部服务可访问或所有任务已经可执行。
