# Workspace 与账号权限

登录身份与当前 Workspace 一起决定你能做什么。业务请求使用服务端识别的当前空间，不通过填写一个 Workspace ID 切换资源归属。

## 选择空间

打开账号或工作空间入口，核对当前空间名称，再选择自己已加入的空间。切换前处理编辑器中的未保存内容。切换完成后，重新确认项目和模型；其他空间的资源不会自动带过来。

需要加入新空间时，通过空间管理提供的邀请流程加入。邀请、成员和角色管理应由具有对应治理权限的账号执行。

## 阅读与编辑

只读成员可以浏览被授权的业务内容；编辑权限允许创建和修改作品。模型使用、配置管理、日志查看和账号治理是不同权限：能编辑笔记不代表能管理供应商凭证，也不代表能查看完整调用日志。

官方知识库对可阅读思绪工坊的账号提供相同内容，管理员也不能在应用内改写官方正文。遇到按钮缺失，先检查当前角色，而不是把文档中的每个按钮都理解为所有人可用。

## API Key 与登录安全

Management API Key 绑定指定 Workspace 和授权范围。创建后明文只展示一次，应保存在自己的秘密管理工具中；不要写进项目正文、截图或发布内容。需要替换时创建新的凭证并撤销旧凭证。

浏览器使用登录 Cookie；通过正式界面修改资料、密码或会话状态，不手工复制 Cookie。登录失效时重新登录，再查询项目状态，不自动重复之前的写入。

## 排查访问问题

找不到项目时依次检查：当前空间、项目是否在回收站、自己是否仍为成员。跨空间资源会按不存在处理。若权限刚变更，刷新账号状态后再尝试；不要靠另一个人的密钥绕过权限。
