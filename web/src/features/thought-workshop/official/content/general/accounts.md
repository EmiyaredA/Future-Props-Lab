# 账号与私人数据

每个账号直接拥有自己的项目、文件、模型目录、集成和任务。本篇帮助你确认资源归属，使用安全凭证，并了解社区文章分享的边界。

## 确认当前账号

1. 打开右上角账号菜单，核对展示名和用户名。
2. 打开项目与文件列表，确认是自己创建或导入的内容。
3. 如果需要其他账号的文章，让作者通过社区发布并逐篇授权。

**完成标志：** 列表只显示当前账号的私人资源。应用没有空间切换或成员邀请；管理员也不能浏览其他账号的私人项目。

| 能力                                             | 普通用户 | 管理员 |
| ------------------------------------------------ | -------- | ------ |
| 管理自己的项目、文件、模型配置与集成             | 支持     | 支持   |
| 管理自己的会话、密码与 API Key                   | 支持     | 支持   |
| 通过显式发布与逐篇授权共享文章                   | 支持     | 支持   |
| 管理平台账号、共享模型模板、Agent 分配及运行额度 | 不支持   | 支持   |
| 读取其他账号的私人项目与日志                     | 不支持   | 不支持 |

## 创建自动化凭证

1. 在账号菜单打开「账号设置 → API 密钥」。
2. 填写密钥名称和有效期；只有确实需要写入时才勾选写入范围。
3. 创建后点击「复制密钥」。稍后可以在列表中点击「查看并复制」，并按提示验证账号密码。
4. 用 SDK 进行一次只读查询，确认资源属于当前账号，再运行写操作。

**完成标志：** 列表只显示密钥前缀。打开「查看并复制」后，弹窗显示当前账号的完整密钥。标有「旧密钥不可找回」的密钥仍可在有效期内使用。只读密钥可以查询和下载已有内容，不能新建项目或提交模型任务。

## 分享与编辑社区文章

作者在思绪工坊主动发布知识库，并为文章设置可见范围或逐篇读取、编辑授权。接收者从知识社区打开授权文章；不能借此进入作者私人目录、历史或普通文件库。撤回发布后，社区入口停止开放，恢复笔记不会自动重新发布。

**完成标志：** 接收者能打开获授权文章，作者的其他私人笔记仍不可访问。

## 处理升级与访问异常

从旧版升级时，旧空间归唯一原拥有者，同一拥有者的内容合并，旧 Session 和 API Key 失效。管理员重新登录后在维护页输入密码，执行文件迁移与核验；页面确认全部完成后关闭并重启应用。核验失败可修复源文件或目标冲突后重试，原件保留。升级期间普通业务与后台任务暂停。

404 可能表示资源属于其他账号，也可能已被删除；先核对登录账号和资源 ID。401 需要重新登录；403 需要检查密钥范围或文章授权。遇到版本冲突先保留草稿，再核对服务器内容，不自动重复提交。
