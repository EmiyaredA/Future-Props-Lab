# 桌面、Amadeus 与本地 Agent

桌面版把本机启动、窗口和私有自动化连接放在同一个应用里。本篇帮助你使用 Amadeus 时确认上下文，并在需要外部 Agent 操作项目时走正确的配对流程。

## 开始前

确认当前账号，以及“模型与智能体 → 编程智能体”中已登录且获准用于 Amadeus 的 Codex、Claude Code、OpenCode、DeepSeek Harness 或 Pi CLI。左侧列表可查看所有连接状态并重新检测，选择后在右侧查看详情。外部工具还需要相应集成配置。桌面数据与仓库运行数据分开管理，日常操作通过应用完成，不手工改数据库或复制运行目录。

## 发起一次 Amadeus 对话

1. 打开“AI 能力 → 模型与智能体 → 编程智能体”，在左侧连接列表查看各智能体状态，选择后在右侧核对登录说明与连接详情；下方账号授权表用于确认当前账号的用途授权。确认后从顶栏打开 Amadeus，新建对话并选择 Agent 和模型；无法发现模型时使用 CLI 默认模型。
2. 发送前查看“当前上下文”，核对空间、项目、活动窗口以及未保存提示。
3. 在“能力”中选择本次需要的 Skill、工具 API 和 MCP，并应用更改。
4. 写清目标和验收方式，例如“读取当前项目，说明哪三处需要调整”，再逐步执行必要修改。
5. 出现提问或审批时，阅读具体动作后确认；操作完成后到目标作品核对实际结果。

**完成标志：** 工具结果和目标作品都符合请求。上下文描述或助手说“已保存”，不能替代应用中的保存状态与实际内容。

> [!TIP]
> 先让助手读取当前版本，再执行依赖该版本的修改。你在编辑器中的未保存内容不应被误认为已经写入服务器。

## 参考文件与会话文件

参考文件可能参与模型输入，发送前核对内容及模型能力。视频参考不保证覆盖每一秒或所有音轨，需要精确判断时明确时间范围并核对结果。

助手会话文件可查看和下载；写输出文件需要参数绑定审批。CLI 仅使用声明的 FPL 工具，不获得任意本机命令权限。会话目录不等于项目素材库，最终产物需要明确导入或保存到目标应用。

## 连接外部 Agent

1. 在“AI 能力 → 模型与智能体 → 编程智能体”页展开“外部客户端接入”的配置，再开启本地接入。该能力默认关闭；开启成功后显示“已开启”。浏览器中只能查看配置，开启接入需要桌面版。
2. 使用随 App 提供的 `fpl --profile codex connect --name Codex` 发起只读配对，在 App 核对配对码和账号后批准。Claude Code 使用独立 profile；编辑需显式申请读写授权。
3. 按页面复制客户端配置，以 `fpl --profile codex mcp serve` 提供 stdio MCP；先调用 operations 或打开项目，确认连接的是预期账号和项目，再执行编辑。
4. 使用场景工具前，确保对应编辑器已打开且加载完成。

例如 `fpl open director PROJECT_ID` 打开指定导演台工程；把占位值替换为当前账号的真实项目 ID。连接描述和客户端凭证属于私有文件，不应发送给他人。

旧内核对话保留为只读历史；复制所需上下文并新建 Code Agent 对话后继续。关闭或刷新 Amadeus 窗口不会结束后端任务，重新打开可读取最新状态；退出应用或运行中断后不自动重试。切换 Agent 创建新会话。

## 从头像菜单开启本地与公网访问

1. 在桌面 App 使用管理员登录，打开头像菜单「本地与公网访问」。确认本地 Web 和公网隧道均显示「已关闭」；每次启动 App 都需要手动开启。
2. 点击本地 Web 的「开启」，显示「正常」后复制地址到本机浏览器。登录同一账号，应能看到相同项目与素材；其他设备不能直接连接这个回环端口。
3. 需要公网时先停止访问，在「网关与连接凭据」填入管理员提前部署的 SSH 网关与 HTTPS 域名，通过文件选择器导入专用转发私钥及已核验的 known_hosts。页面只显示文件标识和 SSH 指纹，不展示密钥正文。
4. 输入管理员密码并「备份并保存配置」，等待停机备份和重启结束。云端必须已发布与 App 相同的程序构建；不匹配时开启会明确失败，先由管理员发布匹配版本再重试。
5. 点击公网隧道「开启」，等待状态为「正常」，再从其他设备打开 HTTPS 地址并登录。状态、检测时间和本次转发流量可在面板查看；断网重连可停止，不会自动重新提交业务任务。

已有旧隧道可选择「接管现有 LaunchAgent 隧道」：应用停用旧任务的自动启动，并在停机快照中保留恢复资料。停止本地 Web 会同时停止公网；关闭窗口仍可后台运行，明确退出 App 才停止全部访问。私人数据仍在 Mac；云端仅保存程序资源，Mac 离线时业务接口不可用。首页播放内置红莉栖待机动画；减少动态效果或动画加载失败时显示静态形象，页面隐藏时暂停播放。

文件列表与视觉画布先按可见区域读取小图，打开原图或播放视频时才读取完整媒体；缩略预览不改变原始素材。访问变慢时先检查隧道和版本状态，避免反复刷新编辑页或重复提交生成任务。

## 中断与平台边界

| 情况                   | 处理                                   |
| ---------------------- | -------------------------------------- |
| 对话断开或工具失败     | 先查目标作品和任务现状，再决定是否重做 |
| 工具找不到当前项目     | 核对账号、项目上下文和编辑器加载状态   |
| 会话产物未出现在项目中 | 完成明确的上传、导入或保存操作         |

官方知识库随应用提供，正常阅读不依赖外部文档网站。外部模型和服务调用仍需要连接；实时语音仍属于模型测试能力。
