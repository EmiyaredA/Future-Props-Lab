# 桌面、Amadeus 与本地 Agent

macOS 桌面版负责本机启动、窗口和私有自动化连接。桌面数据与仓库数据分开管理；日常操作通过正式应用完成，不手工改数据库或复制运行目录。

## 使用 Amadeus

在顶栏打开 Amadeus，新建对话并选择可用文本模型。发送前核对“当前上下文”里的空间、项目、活动窗口和未保存提示。上下文用于定位，重要修改仍应先读取最新版本。

在“能力”中选择当前对话需要的 Skill、工具 API 与 MCP，再应用更改。参考文件会参与模型输入，应检查内容和模型能力；视频参考不保证覆盖每一秒或所有音轨。

工具结果、提问和审批会按顺序显示。阅读具体动作后再作确认；失败或断开后先检查目标作品现状，不让助手盲目重复写入。

## 会话文件与项目文件

助手会话文件可查看和下载；写入工作文件或执行脚本需要对应确认与可用沙箱。会话目录不是项目素材库，最终作品应明确导入或保存到目标应用。

## 连接外部 Agent

桌面 CLI/SDK 接入默认关闭。在应用提供的本地 Agent 接入流程中开启连接并完成配对授权，再使用随 App 提供的 `fpl` 或独立 Python SDK。连接描述和客户端凭证是私有文件，不要发送给他人。

示例：`fpl open director PROJECT_ID` 打开指定导演台项目；将占位 ID 替换为当前空间的真实工程 ID。场景工具还要求编辑器已打开并加载完成。

## 窗口能力边界

桌宠透明窗口只由桌面 App 打开，普通浏览器提供编辑和模拟预览。实时语音用于模型测试。官方知识库可以离线阅读，但外部模型和服务调用仍需要连接。
