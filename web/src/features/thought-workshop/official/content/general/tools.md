# 工具导航、空间占用与视频帧导出

需要一个小工具而不想新建完整工程时，先在工具导航查找。本篇说明如何通过 GrandPerspective 定位占空间的目录，以及从视频选定画面、下载图片并放入作品。

## 开始前

准备可播放的视频文件，知道要找的大致时间。首次使用先用短视频检查格式与解码支持。工具导航也包含外部网站，打开外部服务不等于把本地文件自动上传过去。

## 找到需要的工具

1. 进入工具导航，按分类、标签或关键词搜索。
2. 阅读用途，确认是应用内工具还是外部链接。
3. 常用条目可收藏，之后从收藏快速返回。
4. 没找到时清空筛选，再按目标而非文件名查找。

收藏只是定位方式，不会安装外部程序。录音标注已归入应用中心；视频帧导出仍是内置工具。部分平台管理入口还受桌面环境和管理员权限限制。

## 查看电脑的空间占用

此工具仅供 macOS 桌面版的平台管理员使用。先安装 GrandPerspective；工具导航不会自动安装它。

1. 在工具导航搜索“空间占用”，打开工具，检查 GrandPerspective 的安装状态与版本。
2. 选择主目录、下载、应用程序或启动磁盘；也可以点击“选择其他目录”，选择外接磁盘中的目录。页面显示当前目录的完整路径及其所在磁盘容量，目录本身的大小由下一步分析。
3. 点击“可视化分析 · 打开 GrandPerspective”。看到打开请求已发送后，切换到 GrandPerspective 原生窗口，等待占用图出现；页面提示不代表扫描已经完成。
4. 点击大色块锁定文件，通过 Focus 调整到所在目录，再使用 Reveal（在 Finder 中显示）。确认 Finder 显示了目标文件或目录后，自行检查并整理。也可从工具页直接“在 Finder 中打开”当前目录。
5. 整理后在 GrandPerspective 中 Refresh 或 Rescan 更新占用图，返回工具页点击“刷新容量 / 重新检测”。

**完成标志：** GrandPerspective 展示了所选目录的占用图，Finder 能定位对应内容；整理后的变化可通过重新扫描及容量刷新核对。

> [!NOTE]
> 工坊只按需读取所在磁盘的容量，不保存扫描结果，也不持续扫描。容量统计与 macOS“储存空间”的分类、可清除空间可能不同。完整扫描所需权限由 GrandPerspective 提示；本工具不改变它的偏好。

未检测到安装时使用官网下载链接，安装到系统或当前用户的 Applications 目录后重新检测。目录失效或无权限时重新选择；打开超时可能已经启动原生窗口，检查后再手动重试。

## 导出一张视频帧

1. 打开视频帧导出，选择支持的视频，等待它能够正常播放。
2. 暂停视频，通过时间定位或进度条接近目标画面。
3. 仔细检查当前帧，确认没有停在转场、黑场或不需要的模糊画面。
4. 核对输出设置后下载图片。
5. 打开下载文件检查清晰度与画面。需要用于笔记、文稿或其他工程时，再从目标应用上传或选择它。

**完成标志：** 下载文件可正常打开，并且内容就是选中的画面。拖动播放头只是在定位，不等于已经导出。

> [!NOTE]
> 视觉创作工坊的视频节点也有取帧入口，它还可以在画布中创建派生图片节点。工具导航里的独立下载与画布取帧的保存行为不同。

## 内置工具与外部网站

| 类型           | 文件如何进入                 | 使用后检查                     |
| -------------- | ---------------------------- | ------------------------------ |
| 内置视频帧导出 | 在工具里选择视频             | 图片是否实际下载成功           |
| 外部网站       | 按外部网站自己的流程提供输入 | 账号、费用、数据使用及结果下载 |
| 应用内派生工具 | 使用工程已有素材             | 新节点或新素材是否已保存到工程 |

不要以外部网站能打开来判断其所有能力可用；该服务的账号和运行状态由它自己管理。

## 出现问题时

| 现象                     | 可能原因               | 处理                                   |
| ------------------------ | ---------------------- | -------------------------------------- |
| 视频无法预览             | 格式、解码或文件不完整 | 用短样本验证，并检查源视频能否正常播放 |
| 下载画面不对             | 播放未暂停或定位不准确 | 重新暂停并核对当前帧后导出             |
| 工程里找不到刚导出的图片 | 图片只下载到了本机     | 从目标应用上传并保存引用               |
| 想要字幕而不是图片       | 选错工具类型           | 进入录音标注或视频剪辑的对应流程       |
