# 工具导航与视频帧导出

工具导航把内置能力和外部网站集中展示。先按分类、标签或搜索找到用途，再确认工具究竟运行在本应用还是外部服务。

## 浏览与收藏

进入工具导航，选择开发调试、数据处理、文本、模型或效率类别。收藏可以加快再次定位，不会安装外部工具。清空筛选重新显示全部条目。

录音标注已归入应用中心，视频帧导出仍是内置工具。桌面平台管理员可使用 Codex 模型源入口，其他角色不应假设自己拥有该入口。

## 导出一张视频帧

1. 打开视频帧导出工具，选择支持的视频。
2. 等待可播放后暂停，用时间定位或进度条选择目标画面。
3. 确认当前帧和输出设置后下载图片。
4. 需要用于作品时，再从目标应用上传或选择该图片。

拖动播放头是在选择画面，下载图片才是交付。视频创作画布自己的取帧入口还可以产生新的图片节点；两种入口的保存行为不同。

## 数据位置与失败排查

外部网站有自己的账号、费用和数据政策。本应用中的文件不会因为打开网站就自动传过去，也不能保证外部网站的可用性。

遇到视频无法预览时检查格式、解码和文件完整性。长视频先选择短片验证，不连续导出大量帧而不检查结果。需要分段标注与字幕时转到[录音标注工坊](/apps/thought-workshop/official-knowledge-bases/audio-annotation)。
