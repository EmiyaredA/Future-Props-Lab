# 工具 API、MCP 与 Skill

集成中心保存空间的外部能力。配置管理与验证需要对应权限；启用资源后，仍需在模型或助手的能力选择中明确使用。

## 工具 API

创建条目，填写名称、说明、请求方法以及 HTTPS 或本机回环地址。按目标服务选择无认证、Bearer Token 或指定 API-Key 请求头，并用 JSON Schema 描述输入。查询和请求体模板决定这些输入怎样发送。

先修正所有 JSON 格式提示，再保存并验证。验证可能真实调用目标服务，首次应使用自己控制的安全测试输入。密钥不会回显，修改时区分保留、替换与清除。

## MCP

HTTP MCP 使用远端服务连接；stdio MCP 使用部署机器上配置的本机命令与参数。两者的运行环境不同，不能把浏览器里的路径当成本机服务路径。

保存连接后查看验证反馈与工具列表，再启用。启动失败先检查服务地址、认证或命令依赖。安装一个 MCP 条目不等于服务已成功运行。

## Skill

通过正式 ZIP 导入入口导入 Skill 包，核对名称、说明、文件结构及依赖。Skill 是任务指引和资源，不会因为启用就自动执行每个步骤。

在 Amadeus 的能力选择中勾选需要的 Skill、工具 API 和 MCP，再应用选择。仅当前对话使用这次范围；取消弹窗不保存更改。

## 排查顺序

先检查当前空间和权限，再检查启用状态、验证结果、服务依赖及凭证。普通成员不能用“文档说能验证”代替实际权限。公开能力安装后的配置方法见[创意工坊](/apps/thought-workshop/official-knowledge-bases/general/documents/creative)。
