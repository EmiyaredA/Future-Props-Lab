# 入门与基本概念

Future Props Lab 是单机部署的模型基础设施管理台。它把模型连接、测试、文件、集成和创作应用放在同一部署中；账号可以参与多个逻辑 Workspace，业务内容按当前空间隔离。

## 从一个小任务开始

1. 登录后检查当前 Workspace 的名称。切换空间会改变可见的模型、文件和项目。
2. 想整理文档，从应用中心进入思绪工坊；想做幻灯片，进入演示工坊。这些操作无需先配置模型。
3. 想调用模型，先请有配置管理权限的成员建立连接，测试通过后再开始创作。
4. 第一次保存后返回项目列表，再打开项目确认内容保留。要交接给别人时，选择应用自己的工程包或备份入口。

## 三个重要区别

| 概念      | 用途                   | 要注意的事                         |
| --------- | ---------------------- | ---------------------------------- |
| Workspace | 权限和业务资源的边界   | 同名项目可以属于不同空间           |
| 项目      | 某个应用的可编辑作品   | 视频、标注、文稿等采用不同工程格式 |
| 文件      | 图片、音频、视频或附件 | 删除引用不等于删除源文件           |

思绪工坊的知识库是文档项目容器。官方知识库是随应用提供的只读指南，个人知识库才用于编辑自己的内容。

## 保存、任务与交付

多数编辑器显示未保存、保存中和已保存状态。看到保存失败或版本冲突时，先保留本地草稿，阅读反馈再处理，不连续重复提交。

后台任务拥有独立记录。离开页面不等于取消任务；提交中断也不代表供应商没有收到请求。查明状态后再手动重试。
