# 入门与基本概念

想先整理一篇资料、做三页介绍，或者验证一个新模型？可以从一个不依赖复杂配置的小任务开始。本篇带你确认当前账号、选择应用，并完成一次“创建 → 保存 → 重新打开”的闭环。

## 开始前确认两件事

- 已登录，并确认当前账号。私人业务资源归该账号所有。
- 已选择一个具体目标，例如“保存一篇会议记录”，而不是同时配置所有应用。写笔记、手工排版幻灯片不需要先连接模型。

只读成员可以先浏览已有作品和官方文档；创建或编辑需要相应内容权限。按钮缺失时先核对权限，不必重复登录或重新安装应用。

## 第一次使用：保存一篇记录

1. 从应用中心进入 **思绪工坊**。上方“官方文档”用于查阅说明，下方“我的知识库”用于管理账号私有的文档项目。
2. 点击“创建知识库”，命名为“工作记录”，进入该库。
3. 在目录中创建文档，写上标题“第一次使用”，加入两三行正文。
4. 等待页面显示保存成功，再返回知识库列表。
5. 重新进入该库、打开文档，确认标题和正文都在。

**完成标志：** 重新打开后仍能阅读刚才的内容。只有输入完成、尚未收到保存成功反馈，还不能算这一步完成。

> [!TIP]
> 准备演示材料时，也可以改走“演示工坊 → 新建演示文稿 → 修改标题 → 放映 → 导出 PPTX”。先交付最小作品，之后再增加素材和模型调用。

## 分清三类数据

| 名称         | 你用它做什么               | 常见误解                         |
| ------------ | -------------------------- | -------------------------------- |
| 账号         | 直接拥有模型、文件与作品   | 社区共享需显式文章授权           |
| 项目或知识库 | 保存某个应用的可编辑内容   | 不同应用的工程 JSON 不能直接互换 |
| 文件或素材   | 提供图片、音频、视频及附件 | 从正文删除图片不一定删除源文件   |

思绪工坊的知识库是文档容器。官方库由应用发布提供，个人创建的库保存业务内容；这里的“知识库”不表示模型检索服务。

## 什么时候需要配置模型

需要文字推理、图像或视频生成、语音等能力时，再进入模型服务配置连接。确认模型支持目标输入后，用一条简短请求测试；随后在目标应用选择它。文字测试成功不能证明视频生成也成功。

## 遇到问题先看哪里

| 现象                   | 先检查                   | 下一步                                   |
| ---------------------- | ------------------------ | ---------------------------------------- |
| 找不到刚保存的项目     | 当前账号、应用、筛选条件 | 回到创建时的空间，清空搜索再找           |
| 页面提示未保存或冲突   | 保存状态与具体错误       | 保留当前草稿，按页面提供的处理方式解决   |
| 关闭页面后任务仍在运行 | 任务记录                 | 查询原任务，确认状态后再决定是否新建任务 |
| 有成片却无法继续编辑   | 手中是媒体还是工程包     | 向交付方索取可编辑工程或完整备份         |

> [!WARNING]
> 提交模型请求后，断网或关闭页面不代表供应商没有收到请求。先查原任务和日志，再手动重试，避免重复调用。
