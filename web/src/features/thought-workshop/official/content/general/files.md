# 文件管理与引用

文件管理拥有当前空间的公共文件及其引用关系。上传后的图片、音频、视频与附件可以被业务作品引用，不能把项目列表和文件列表当成同一份数据。

## 上传与整理

通过文件管理或应用提供的上传入口选择本地文件。检查上传完成后的名称、媒体类型和预览，再从目标应用选择素材。批量处理时先上传少量文件确认格式与限制。

重命名方便查找，不会改变媒体内容。筛选和搜索用于定位文件，应用的素材选择器还可能限定文件类型或归属；在文件库看到资源并不保证所有应用都接受它。

从本项目或跨项目选取文件时，可以进入子文件夹、沿路径返回或回到项目根目录。搜索只查找当前文件夹；切换文件夹或搜索条件不会清空已选文件。可通过“移除”取消选中，切换来源项目则会重置选择。

## 引用与删除

删除节点、图片框或附件卡片通常只解除该作品的引用。原始文件是否删除由文件管理决定。文档历史和回收站也可能引用文件，此时删除会被阻止。

需要清理时先查看引用详情，确认对应作品和历史用途。不要手工删除磁盘文件来绕开保护；这样会让已保存作品缺失素材。

## 下载与交接

下载源素材用于外部处理；保存应用工程包用于继续编辑。普通项目 JSON 可能只保存文件引用，不包含所有媒体字节。交接前检查应用的包格式说明，再验证接收方能打开。

素材派生操作例如图片裁剪或视频取帧会产生新的结果；确认是否已下载、已上传或已插入项目，这三个状态不能混用。

## 常见问题

预览失败先核对媒体是否上传完整和格式是否支持，再检查登录与网络。删除被拒绝时检查业务引用。跨空间复用应走正式导入或交接入口，不能靠复制旧文件 ID 建立引用。
