# 文件管理与引用

同一张图片可能出现在笔记、文稿或其他作品中。文件管理帮助你找到源文件和引用关系；应用工程则保存如何使用这些文件。本篇带你完成上传、选用、交接与清理，并避免误删仍在使用的素材。

## 开始前

确认当前账号，准备一份格式受目标应用支持的文件。文件库能展示的媒体范围，不等于每个应用都能导入。批量上传前，先用一两份代表性素材验证。

## 上传并在作品中使用

1. 在文件管理顶部点击“上传文件”，或从目标应用提供的上传入口选择本地文件。文件夹以紧凑卡片单独排列，文件可切换卡片或列表视图。
   文件库顶部的“更多操作”提供导入 ZIP、导入文件夹、导出当前目录和打开本地文件夹；选择后检查对应的进度、结果或错误提示。
2. 等待上传完成，检查名称、媒体类型、大小和可用预览。
3. 回目标作品，从素材选择器中选择刚上传的资源，或通过应用支持的导入流程建立副本。
4. 确认素材出现在正确位置，再等待作品保存成功。
5. 重新打开作品，验证资源仍可读取。

**完成标志：** 文件已上传，且目标作品已保存对它的引用。只看到上传成功不能证明正文、节点或时间线已经保存。

## 判断加载是否完成

上传或下载大文件时，操作旁会显示已传输大小、可获得的总量与传输速度。大小全部传完后若显示“服务端处理中…”，继续等待业务成功回执；页面模块或服务端未提供总量时，循环进度条只表示正在等待，不代表固定百分比。

图片列表和正文优先读取合适尺寸的预览，接近视口时才请求。原图预览、裁剪和正式导出仍使用原始资源。预览失败时先重试；支持“查看原图”的预览中，主动点击后才读取大图。

1. 上传一张图片，观察传输提示，等待成功回执后在列表中找到它。
2. 打开图片预览，确认图片完整；需要原始文件时使用下载原图或原图预览入口。
3. 回到作品检查引用，保存后重新打开。

**完成标志：** 图片可以预览，下载的原始文件保持原有尺寸，且重新打开作品仍能读取。等待提示不能代替成功回执。

## 直接预览内容

首页按图片、视频、音频与文档显示四组文件套，每组按最近更新时间展示最多三份真实文件；不足三份时使用空白背卡补齐层次，不代表额外文件。文件套上的分类标题进入对应文件库，最前方露出的封面打开最新文件预览，后面的卡片仅供辨认内容。没有文件时显示空态，上传后即可检查真实预览。文件库中的文件卡片同样可以点击查看；只读账号也可预览自己的文件。

| 类型                     | 卡片内容                            | 打开后可做什么                         |
| ------------------------ | ----------------------------------- | -------------------------------------- |
| 视频                     | 约第 1 秒的真实画面，短视频使用首帧 | 播放、暂停、拖动进度、调音量、全屏     |
| 音频                     | 前 60 秒真实波形，标明范围和全长    | 试听完整音频、调进度和音量             |
| PDF                      | 实际第一页，包括扫描页面            | 上下翻页、放大缩小、下载原文件         |
| TXT、Markdown、JSON、CSV | 实际正文摘要                        | 阅读最多前 64 KiB 的文本，下载完整文件 |
| Office、压缩包等         | 格式和文件大小                      | 下载后使用对应软件打开                 |

1. 上传一份视频、音频或 PDF，等待上传成功，确认卡片展示实际画面、波形或文档首页。
2. 点击内容打开预览；视频和音频需要主动点击播放，不会自动发声。
3. PDF 点击“下一页”检查第二页，或用放大、缩小查看细节；文本出现截断提示时下载完整内容。
4. 按 Esc 或点击“关闭预览”，确认焦点返回刚才的文件卡片。

**完成标志：** 能辨认实际文件内容，播放或翻页有效，关闭后能继续操作原卡片。预览失败可“重新加载预览”或下载；加密或损坏的 PDF 可能无法在线显示。Markdown 按安全文本显示，不执行其中的 HTML。

## 在素材选择器中定位文件

从本项目或跨项目选择文件时，可以进入子文件夹、沿路径返回或回到项目根目录。搜索只查找当前文件夹；切换文件夹或搜索条件不会清空已选文件。

选错文件可用“移除”取消选中。切换来源项目会重置选择，因此先完成一个来源的选取，再切换到其他来源。

## 引用、副本和删除

| 操作                     | 通常改变什么       | 操作后检查                   |
| ------------------------ | ------------------ | ---------------------------- |
| 重命名                   | 便于查找的名称     | 媒体内容是否仍是预期文件     |
| 删除正文图片或时间线片段 | 作品中的使用位置   | 原文件是否仍被其他位置引用   |
| 从其他项目导入副本       | 目标项目的独立资源 | 来源变化不会自动同步         |
| 删除源文件               | 文件本身           | 是否被作品、历史或回收站引用 |

文档历史和回收站也可能保留引用。删除被阻止时，先查看引用详情，再决定是否确实要清理对应作品或历史。

> [!WARNING]
> 不要手工删除磁盘文件来绕过引用保护。应用中的文档可能仍指向这些文件，后续阅读、历史还原或导出都会受影响。

## 交接时选择正确内容

下载源素材适合外部处理；应用工程包或完整备份适合继续编辑。仅复制项目 JSON 或旧素材 ID，可能缺少媒体字节，也不能让其他账号直接引用源账号资源。

裁剪、取帧等派生操作可能生成新文件。交付前明确它处于哪一步：已下载到本机、已上传到空间，还是已保存到项目。三个状态不能互相替代。

## 常见问题

| 现象                 | 排查顺序                                            |
| -------------------- | --------------------------------------------------- |
| 预览失败             | 上传完整性 → 媒体格式 → 登录与网络 → 原文件可下载性 |
| 素材选择器找不到文件 | 当前账号 → 来源项目 → 文件夹 → 类型筛选             |
| 删除失败             | 查看业务、历史和回收站引用，再通过正式入口处理      |
| 跨账号复制后图片缺失 | 使用带素材的导入包，重新建立目标账号引用            |
