# 文件管理与引用

同一张图片可能出现在笔记、文稿或其他作品中。文件管理帮助你找到源文件和引用关系；应用工程则保存如何使用这些文件。本篇带你完成上传、选用、交接与清理，并避免误删仍在使用的素材。

## 开始前

确认当前账号，准备一份格式受目标应用支持的文件。文件库能展示的媒体范围，不等于每个应用都能导入。批量上传前，先用一两份代表性素材验证。

## 上传并在作品中使用

1. 从文件管理或目标应用提供的上传入口选择本地文件。
2. 等待上传完成，检查名称、媒体类型、大小和可用预览。
3. 回目标作品，从素材选择器中选择刚上传的资源，或通过应用支持的导入流程建立副本。
4. 确认素材出现在正确位置，再等待作品保存成功。
5. 重新打开作品，验证资源仍可读取。

**完成标志：** 文件已上传，且目标作品已保存对它的引用。只看到上传成功不能证明正文、节点或时间线已经保存。

## 在素材选择器中定位文件

从本项目或跨项目选择文件时，可以进入子文件夹、沿路径返回或回到项目根目录。搜索只查找当前文件夹；切换文件夹或搜索条件不会清空已选文件。

选错文件可用“移除”取消选中。切换来源项目会重置选择，因此先完成一个来源的选取，再切换到其他来源。

## 引用、副本和删除

| 操作                     | 通常改变什么       | 操作后检查                   |
| ------------------------ | ------------------ | ---------------------------- |
| 重命名                   | 便于查找的名称     | 媒体内容是否仍是预期文件     |
| 删除正文图片或时间线片段 | 作品中的使用位置   | 原文件是否仍被其他位置引用   |
| 从其他项目导入副本       | 目标项目的独立资源 | 来源变化不会自动同步         |
| 删除源文件               | 文件本身           | 是否被作品、历史或回收站引用 |

文档历史和回收站也可能保留引用。删除被阻止时，先查看引用详情，再决定是否确实要清理对应作品或历史。

> [!WARNING]
> 不要手工删除磁盘文件来绕过引用保护。应用中的文档可能仍指向这些文件，后续阅读、历史还原或导出都会受影响。

## 交接时选择正确内容

下载源素材适合外部处理；应用工程包或完整备份适合继续编辑。仅复制项目 JSON 或旧素材 ID，可能缺少媒体字节，也不能让其他账号直接引用源账号资源。

裁剪、取帧等派生操作可能生成新文件。交付前明确它处于哪一步：已下载到本机、已上传到空间，还是已保存到项目。三个状态不能互相替代。

## 常见问题

| 现象                 | 排查顺序                                            |
| -------------------- | --------------------------------------------------- |
| 预览失败             | 上传完整性 → 媒体格式 → 登录与网络 → 原文件可下载性 |
| 素材选择器找不到文件 | 当前账号 → 来源项目 → 文件夹 → 类型筛选             |
| 删除失败             | 查看业务、历史和回收站引用，再通过正式入口处理      |
| 跨账号复制后图片缺失 | 使用带素材的导入包，重新建立目标账号引用            |
