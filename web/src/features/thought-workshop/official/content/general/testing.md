# 模型测试与后台任务

模型配置完成后，先验证一项明确能力：得到一句回答、一张图片、一段短视频或一段可校对的转写。本篇说明如何判断测试是否完成，以及断网、关页后应该检查哪条记录。

## 开始前

确认当前 Workspace、模型使用权限及所选模型能力。准备一份小样本；使用文件时核对格式与内容，避免把整套正式素材作为第一次连通性测试。

## 文字与工具测试

1. 在模型测试中选择文本模型，新建或打开测试会话。
2. 先输入简短、结果易于判断的问题，观察流式回复直至结束。
3. 需要工具时，选择已经配置的测试工具，检查工具说明和输入参数后再发送。
4. 分别查看模型回复与工具结果，确认工具是否真的被调用，以及返回了什么。
5. 有附件时再加入一份受支持文件，验证模型是否按预期使用它。

**完成标志：** 请求以成功状态结束，输出可用；工具测试还应有实际工具执行结果，不能只依据模型说“已完成”。

## 图片、视频与转写测试

1. 选择对应测试模式和模型，填写提示、参考素材与必要参数。
2. 核对输出数量后提交，记录或保留当前任务。
3. 在任务列表观察阶段与结果。生成结束后打开真实结果，不只看占位图。
4. 转写结果要试听对应音频、校对文字与时间信息；没有返回的说话人分段或句级时间戳不应自行当作准确结果。
5. 需要用于作品时，再确认结果已保存并由目标项目引用。

> [!NOTE]
> 供应商生成完成、结果下载到本地、作品保存引用可能是三个阶段。视频已生成但下载失败时，优先恢复原结果，不要立即再发一次生成请求。

## Seedance 视频测试

选择火山方舟的 Seedance 2.0 或 2.5 后，测试台按版本显示时长、比例、分辨率与参考数量。纯文本测试先使用 5 秒、720p；需要首帧或首尾帧时，在“视频输入方式”选择对应模式，按首帧、尾帧顺序添加 1–2 张图片，2.5 使用自适应比例。切换模型会保留提示词与素材，请调整不兼容参数后提交。

2.5 支持纯音频参考；2.0 仍需搭配图片或视频。图片与音频直接编码提交，视频参考需要部署管理员配置 `temp_media_upload_url`。成功标志是任务“已完成”且本地视频可播放，不是仅拿到任务编号。

## 实时语音测试

选择支持实时语音的模型，允许浏览器或系统使用麦克风后连接。先说一两句短话，检查输入采集与声音播放，再进行较长测试。结束时主动断开会话。

如果文字能力正常而麦克风无输入，检查系统与浏览器权限、输入设备和连接状态。实时语音是模型测试能力，不提供电话接入、自动接听或 Bot 部署。

## 中断后的处理顺序

| 当前情况         | 先做什么                           | 避免的操作                     |
| ---------------- | ---------------------------------- | ------------------------------ |
| 刷新或关闭了页面 | 重新打开任务列表并查询原记录       | 直接创建同一请求               |
| 已生成但保存失败 | 使用现有结果恢复或转存入口         | 为恢复本地文件再次调用模型     |
| 任务显示取消中   | 等待安全阶段结束并查询最终状态     | 把按钮点击理解为远端已立即停止 |
| 提交阶段中断     | 检查原任务与日志，再明确决定下一步 | 假设供应商从未收到请求         |

系统不会自动重复供应商提交。确需重新测试时，在弄清原任务状态后，由你明确发起新请求。
