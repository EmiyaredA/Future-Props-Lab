# 模型测试与后台任务

模型测试用于验证文字、媒体生成、转写和实时语音能力。测试内容属于当前 Workspace，实际可用模式由模型能力与当前权限决定。

## 文字与工具测试

选择模型，新建或打开测试会话，输入一段小而明确的问题，再检查流式回复。需要工具时，选择已登记的测试工具，先检查参数和可控输入。工具执行与模型回复是两个步骤，模型声称已完成不能替代实际工具结果。

附件会成为模型输入的一部分。发送前核对文件名、格式和模型支持；模型不能处理附件时，减少输入或改用具备对应能力的模型。

## 图片、视频与转写

先选模式与模型，再填写提示、参考素材及参数。提交后查看任务列表的状态和结果。转写还应核对语言、时间戳和文本，模型输出需要人工校对。

结果已生成但本地落盘失败时，优先使用结果恢复或转存入口，不立即重做模型请求。生成成功、素材保存成功和项目引用保存成功可能是不同阶段。

## 实时语音

使用支持实时语音的模型，在测试界面授予麦克风权限并连接。先用短句检查输入和播放；结束时明确断开会话。浏览器或系统麦克风权限关闭会阻止采集，文字能力正常不代表语音链路正常。

该能力用于模型测试，不是电话接入，也不提供自动接听或 Bot 部署。

## 中断和取消

刷新、关闭页面或网络断开后先重新查询任务。取消请求可能需要在安全阶段结束，页面消失不等于远端任务已取消。提交阶段中断不会自动重提；确认当前记录和费用风险后，再手动发起新任务。
