# 模型配置与连接

要让工坊使用新的模型，先把“如何连接服务”和“调用哪个模型”配置清楚。完成本篇后，你应能在模型测试或目标工坊选中模型，并完成一次与目标能力一致的测试。

## 开始前准备

准备供应商给出的接口类型、服务地址、认证方式和原始模型标识，并确认当前账号具有配置管理权限。显示名称可以方便辨认，但不能代替供应商要求的模型 ID。

| 配置对象     | 负责的内容                 | 示例含义                         |
| ------------ | -------------------------- | -------------------------------- |
| 供应商连接   | 接口地址、认证与适配方式   | 请求发往哪个服务、如何认证       |
| 模型条目     | 模型标识、能力及可配置参数 | 这次调用哪个模型、接受什么输入   |
| 默认模型用途 | 工作空间中的用途选择       | 常用能力默认选择哪一个已配置模型 |

## 建立并验证连接

1. 在模型服务的供应商管理中新增或打开连接，按实际接口类型填写地址与认证。
2. 保存后创建或维护模型条目，填写供应商的原始标识，再核对能力配置。
3. 使用测试入口发起最小请求。文字模型先问一句短问题；图像、视频或音频模型应测试它对应的媒体能力。
4. 阅读返回结果与错误状态。流式输出必须正常结束；只收到一部分文字不代表测试成功。
5. 在目标工坊确认该模型能被选择。需要默认用途时，再设置“工作区默认模型”。

**完成标志：** 测试正常完成，目标应用能选择模型，输入方式与任务匹配。

> [!WARNING]
> 测试可能真实调用供应商并计费。先使用小输入和少量结果，确认连接后再扩大任务规模。

## 按目标核对能力

例如“根据产品图生成视频”至少要确认：选择的是视频生成模型、支持参考图、参考图格式符合要求、生成参数在允许范围。不要只因为同一供应商的文字问答可用，就直接提交大批视频任务。

上传参考图片、音频或视频前，查看当前模型界面提供的字段、数量和尺寸限制。没有出现的能力不应靠改提示词绕过。

## 修改地址或凭证后

编辑表单不会回显已保存密钥。按提示区分保留、替换与清除；保存后重新执行最小测试，再回到业务应用继续使用。部署机器必须能够访问服务地址，浏览器本身能打开网站并不能证明后端连接可用。

## 失败时按错误类别处理

| 现象             | 可能原因                     | 处理                                   |
| ---------------- | ---------------------------- | -------------------------------------- |
| 认证失败         | 凭证错误、失效或服务权限不足 | 核对认证方式与凭证授权，再测试         |
| 模型不存在       | 模型标识或所选供应商不匹配   | 按供应商原始标识修正模型条目           |
| 输入或能力不支持 | 模式、媒体格式或参数不匹配   | 缩小到受支持的最小输入                 |
| 超时或连接失败   | 地址、网络或服务状态异常     | 检查部署机器到目标服务的连通性         |
| 流式回复中途结束 | 服务报错或连接中断           | 查看调用日志，保留已得到内容后决定重试 |
