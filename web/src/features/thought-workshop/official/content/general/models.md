# 模型配置与连接

要让工坊使用新的模型，先把“如何连接服务”和“调用哪个模型”配置清楚。完成本篇后，你应能在模型测试或目标工坊选中模型，并完成一次与目标能力一致的测试。

## 开始前准备

准备供应商给出的接口类型、服务地址、认证方式和原始模型标识，并确认当前账号具有配置管理权限。显示名称可以方便辨认，但不能代替供应商要求的模型 ID。

| 配置对象     | 负责的内容                 | 示例含义                         |
| ------------ | -------------------------- | -------------------------------- |
| 供应商连接   | 接口地址、认证与适配方式   | 请求发往哪个服务、如何认证       |
| 模型条目     | 模型标识、能力及可配置参数 | 这次调用哪个模型、接受什么输入   |
| 默认模型用途 | 账号的用途选择             | 常用能力默认选择哪一个已配置模型 |

## 建立并验证连接

1. 在模型服务的供应商管理中新增或打开连接，按实际接口类型填写地址与认证。
2. 保存后创建或维护模型条目，填写供应商的原始标识，再核对能力配置。
3. 使用测试入口发起最小请求。文字模型先问一句短问题；图像、视频或音频模型应测试它对应的媒体能力。
4. 阅读返回结果与错误状态。流式输出必须正常结束；只收到一部分文字不代表测试成功。
5. 在目标工坊确认该模型能被选择。需要默认用途时，再设置“工作区默认模型”。

**完成标志：** 测试正常完成，目标应用能选择模型，输入方式与任务匹配。

> [!WARNING]
> 测试可能真实调用供应商并计费。先使用小输入和少量结果，确认连接后再扩大任务规模。

## 按目标核对能力

例如“根据产品图生成视频”至少要确认：选择的是视频生成模型、支持参考图、参考图格式符合要求、生成参数在允许范围。不要只因为同一供应商的文字问答可用，就直接提交大批视频任务。

上传参考图片、音频或视频前，查看当前模型界面提供的字段、数量和尺寸限制。没有出现的能力不应靠改提示词绕过。

## 接入 DeepSeek 官方服务

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/)创建 API Key，确认账户有可用额度。
   在「模型服务」点击「添加接入连接」，名称填写「DeepSeek」，接入协议选择「DeepSeek 官方」。
2. 填写 API Key，服务地址可以留空。保存后，连接详情应显示 `https://api.deepseek.com`；
   使用代理时填写对应的兼容接口根地址，不要追加 `/chat/completions`。
3. 点击「添加模型」，选择刚创建的连接，从「DeepSeek 模型预设」选择 Flash 或 V4 Pro。
   Flash 使用 `deepseek-flash`，自动勾选对话、工具和图像理解；V4 Pro 使用 `deepseek-v4-pro`，
   自动勾选对话和工具。两者均归入文本生成，也可以手动填写其他模型 ID 和对应能力。
4. 保存并启用后点击「去测试」，输入一句简短问题。应看到逐步输出的回答及正常完成状态，
   并能在调用日志按「DeepSeek 官方」筛选到这次记录。要测试图片，请选择具备图像理解能力的 Flash。

配置管理权限控制连接修改，实际调用仍使用当前账号的模型与凭证。

**完成标志：** 连接显示官方地址，模型能在对话测试和相关应用中选择，回答正常完成且有对应日志。
本接入使用非思考模式，不提供思考开关或思考内容展示。现有 SenseAudio 网关中的同名模型继续使用原连接，
添加官方连接不会替换旧条目，也不会更改默认用途。模型与能力以 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/)为准。

认证失败时核对 Key；额度或限流错误需检查开放平台。流式输出中断时保留部分回答并查看日志，
由用户决定是否再次提交，不自动重试。编辑已有连接时 API Key 留空保留原密钥。

## 使用 ZEALMAN H3 工作流

1. 添加接入连接，选择“ZEALMAN · H3 工作流视频”，填写 ZEALMAN 面板的 HTTPS 根地址。页面链接中的查询参数会在保存时移除；未启用认证的服务可留空 API Key。
2. 添加模型，从已支持工作流中选择 `U17-9图1视频3音频V1-api` 或 `U06-9图3音频-V5`。保存后应在视频生成分类中看到对应模型，并能点击“去测试”。
3. 在测试台填写提示词、时长和参考素材。U17 最多支持 9 图、1 视频、3 音频，可设置比例、百万像素和放大倍率；U06 最多支持 9 图、3 音频，可设置宽高和种子，宽高须为 32 的倍数。音频需要搭配图片或视频。
4. 按提示词中的图序依次上传参考图；没有上传的槽位不会使用远端示例。提示词只作用于本次工作流副本，不修改服务端保存的工作流。U06 留空种子时会生成随机值，实际种子保存在任务记录中。
5. 点击“开始测试”，等待任务完成，播放或下载结果，并在调用日志中核对状态。只拿到任务编号不表示测试成功；这两个工作流联合输出视频和音频，界面不提供水印和独立音频开关。

**完成标志：** 对应模型的任务显示“已完成”，视频可播放、可下载，调用日志显示成功。

任务详情会按上游返回显示队列位置、当前节点、采样步数、上游报告进度与更新时间。采样步数只反映当前节点；上游报告值不代表整段视频完成度。新任务独立连接实时状态，断线后继续 HTTP 查询；旧控制台任务不抢占其连接，可能没有采样步数。

上游 ComfyUI 重启可能清空生成历史，应用会及时保存结果并尝试从任务账本恢复。等待超过 60 分钟会报告失败，提交中断不会自动重提；已有结果下载失败时使用“重试保存结果”。如果下载提示地址指向非公网网络，请检查部署机器的 DNS／代理解析，不能通过关闭下载安全校验处理。

## 使用 AutoDL 上的 zealman 工作流

这组预设连接 AutoDL 部署的服务，包含 11 款 H3 视频工作流和 1 款 Wan 动作迁移。

1. 在 AutoDL 令牌管理中准备 ComfyUI 分组令牌。在模型服务添加连接，协议选择“AutoDL · zealman 视频工作流”，服务地址留空时使用 `https://www.autodl.art`，API Key 填入令牌原文。
2. 在此连接下添加模型，从“AutoDL 工作流预设”选择需要的版本。预设自动填写 AutoDL 页面上的完整名称与工作流描述，模型标识保留官方工作流 ID。保存并启用后，应能在视频测试和视觉创作工坊中看到同名模型。
3. 使用最小输入测试：影视、超清、升级和高速版至少选一张图片；文生视频填写提示词；首尾帧必须同时选择两张图片。多图多音频旧版及其 15 秒版可只填写提示词，也可仅添加音频参考。
4. 对口型工作流选择一张图片和一段音频，设置“音频截取时长”；动作迁移选择一张人物图片和一段 MP4／WebM 动作视频，输出尺寸为 464×832 或 832×464，时长随输入视频。这两款无需提示词。
5. 点击“开始测试”。任务显示“已完成”后播放或下载视频，并在调用日志核对结果；再到工坊视频节点选择同一模型生成。素材直接编码提交，无需临时上传服务。

图片支持 JPG、PNG、WebP；音频支持 MP3、WAV，影视画质以外的音频工作流还支持 FLAC。参考素材总大小最多 45 MB，单图最多 30 MB、单音频最多 15 MB。工作流各自限制数量、时长与尺寸，以界面显示为准。有提示词的工作流支持最长 20000 字符；种子留空会生成随机值并记入本次任务。影视画质不支持种子，所有 AutoDL 工作流均不提供水印或独立生成音频开关。

默认 H3 输出为 768p 竖屏、5 秒。影视与超清版的 960p 目前只开放文档明确列出的竖屏。切换模型时保留原素材和提示词，并按当前模型提示调整不兼容项。提交中断不会自动再次扣费提交；已取得结果但保存失败时使用“重试保存结果”。

**完成标志：** 测试台与工坊均可选择模型，生成任务完成后有可播放、可下载的视频和对应调用日志。

## 接入 Seedance 2.0 / 2.5

先在[火山方舟模型开通页](https://ark.volcengine.com/region:cn-beijing/openManagement)开通对应版本，再到 [API Key 管理](https://ark.volcengine.com/region:cn-beijing/apiKey)创建有权调用模型的 Key。账户开通条件以[官方 Seedance 2.5 教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)和控制台提示为准。

1. 在模型服务新增连接，接入协议选择“火山方舟 · Seedance 2.0 / 2.5”，填写 API Key。服务地址使用 `https://ark.cn-beijing.volces.com/api/v3`；留空保存时会填入此默认地址。
2. 在此连接下添加模型，从“Seedance 模型预设”选择版本。2.0 使用 `doubao-seedance-2-0-260128`，2.5 使用 `doubao-seedance-2-5-260628`。预设自动填写名称、视频生成能力和分类；保存并启用后应能在视频测试中选中。
3. 点击“去测试”，输入简短提示词，先用纯文本、5 秒、720p 测试；默认开启声音与水印。点击“开始测试”，等待“已完成”，播放并下载视频，再检查调用日志。
4. 进入视觉创作工坊的视频节点，选择同一模型，再添加参考素材。2.0 支持 4–15 秒、9 图／3 视频／3 音频，音频必须搭配图片或视频；2.5 支持 4–30 秒、30 图／10 视频／10 音频，可单独参考音频。两者可选自动时长；2.5 首帧／首尾帧保持输入比例，界面使用“自适应”。
5. 切换模型后检查时长、分辨率、比例与参考数量。提示词和素材保留，不兼容的选项会在提交前提示调整。2.0 可选 4K，2.5 最高 1080p；本入口输出 MP4，不提供随机种子或样片专用流程。

**完成标志：** 模型服务的视频测试与工坊生成任务均显示“已完成”，本地结果可播放，工坊新增输出版本。

### 配置参考视频临时上传

文生视频、图片参考和音频参考可直接提交给方舟。参考视频必须先获得方舟能够访问的公网 HTTPS 地址；应用复用已有临时上传服务，不需要额外的 TOS 凭据。

在生效的 `backend/config.toml` 中配置：

```toml
[integrations]
temp_media_upload_url = "https://your-media-service.example/upload"
```

此地址来自你部署或已有的临时素材上传服务，不是方舟 API Key 管理页面提供的地址。服务须接受 multipart `file` 上传，返回纯文本、同域的公网 HTTPS 文件地址；链接在供应商读取期间必须有效。该协议不携带上传服务认证凭据。留空时不会外传素材到上传服务，视频参考提交前会提示缺少配置。

源码部署使用仓库根目录下的 `backend/config.toml`；macOS 桌面版使用 `~/Library/Application Support/Future Props Lab/backend/config.toml`，隔离开发版位于同级 `Future Props Lab Development/backend/config.toml`。更改后按当前部署方式重启后端；桌面开发应通过已有的后端更新流程应用配置。

单张图片不超过 30 MB、单段音频不超过 15 MB、单段视频不超过 200 MB。视频与音频单段至少 2 秒，同类参考总时长分别不能超过对应版本的 15／30 秒；图片与音频编码后的整个请求体不能超过 64 MB。应用还会检查实际尺寸、格式与视频编码。参考视频需 H.264／H.265、24–60 FPS。涉及真人参考时，以方舟当前的素材授权和内容限制为准。

任务提交中断不会自动再次生成；先在任务与方舟控制台核对原请求。供应商已成功但本地下载失败时，使用“重试保存结果”，不会再次调用生成接口。

## 修改地址或凭证后

编辑表单不会回显已保存密钥。按提示区分保留、替换与清除；保存后重新执行最小测试，再回到业务应用继续使用。部署机器必须能够访问服务地址，浏览器本身能打开网站并不能证明后端连接可用。

## 失败时按错误类别处理

| 现象             | 可能原因                     | 处理                                   |
| ---------------- | ---------------------------- | -------------------------------------- |
| 认证失败         | 凭证错误、失效或服务权限不足 | 核对认证方式与凭证授权，再测试         |
| 模型不存在       | 模型标识或所选供应商不匹配   | 按供应商原始标识修正模型条目           |
| 输入或能力不支持 | 模式、媒体格式或参数不匹配   | 缩小到受支持的最小输入                 |
| 超时或连接失败   | 地址、网络或服务状态异常     | 检查部署机器到目标服务的连通性         |
| 流式回复中途结束 | 服务报错或连接中断           | 查看调用日志，保留已得到内容后决定重试 |
