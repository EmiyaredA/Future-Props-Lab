# 模型配置与连接

模型服务管理当前 Workspace 可调用的供应商和模型。供应商连接负责地址与凭证，模型条目负责模型标识和能力；条目名称不保证供应商实际支持某项输入。

## 建立连接

1. 在模型服务打开供应商管理，按实际接口类型填写地址及认证。
2. 创建或维护模型条目，填写供应商要求的模型标识，选择相应能力。
3. 保存后执行连接测试，从最小请求开始，检查响应和错误详情。
4. 确认可用后，在模型测试或目标工坊选择该模型。需要默认用途时，再设置空间的默认模型。

配置与验证需要对应管理权限。编辑凭证时已保存密钥不会明文回显；保留、替换与清除是不同动作，应按表单提示选择。

## 按任务检查能力

文字、图像输入、图像生成、视频生成、语音合成、转写和实时语音各有要求。准备参考图片、音频或视频时，检查模型支持的格式、数量与尺寸。文字测试成功不能证明图片或视频生成也成功。

例如需要“根据参考图生成视频”，应选择支持该输入方式的视频模型，再检查参考图字段和生成参数；不要把图片简单粘到不支持图像输入的文字模型中。

## 失败时检查什么

认证失败先核对凭证及账号额度；模型不存在先核对原始模型标识；能力错误先检查输入形式；连接失败先检查地址和部署机器能否访问服务。

流式输出中途报错或在完成前断开也属于调用失败。已经收到的部分文本不表示任务完成，应查看错误状态和调用日志；系统不会自动重试供应商请求。

配置修改后重新测试最小请求。测试可能调用真实供应商并计费。需要排查具体调用时，用[日志指南](/apps/thought-workshop/official-knowledge-bases/general/documents/logs)定位记录，避免把密钥复制到讨论或报告中。
