# 桌宠工坊：主要操作流程

## 外观和事件

Live2D 来源可建立皮肤，为对应部件上传同尺寸替换 PNG，复用原网格与动作。分层资源包来源（鲸鱼娘或人物小人）选择包内已有配色，不使用相同部件编辑方式；界面显示实际配色数量。

在交互页选择待机、点击身体、摸头、拖起、放下或自主走动，配置动作、表情和提示音。台词页为对应事件编写句子，每个事件最多八句、每句 1–140 字；用播放事件检验。

摸头依靠头部热区，其他角色区域触发身体点击。事件台词是预先编写内容，不会每次触摸调用模型。

## 习惯与试玩

设置角色大小、走动频率、拖拽、气泡和声音，最多选四个悬停按钮。试玩时检查触摸、拖起放下、大小和声音，再保存默认设置。

## 人设与聊天

作者在聊天页编辑简介、性格、说话方式和开场白，保存到项目。使用者在桌面聊天小窗选文本模型，发送文字并查看流式回复，也可停止当前轮次。

聊天历史、模型和偏好按账号、Workspace 与桌宠隔离。同空间其他人不会共享私人消息。清空聊天不删除工程和人设，操作前确认范围。

聊天模型可能计费；预设主动台词不调用模型。关闭窗口或切换身份后先查结果，不自动重复发送中断消息。
