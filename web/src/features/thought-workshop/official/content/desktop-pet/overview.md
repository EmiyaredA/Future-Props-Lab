# 桌宠工坊：功能概览与快速开始

想把已完成的角色放到桌面，点击时做一个表情、拖起时说一句预设台词，可以从桌宠工坊建立独立配置。完成本节后，你会有一只保存过、可以试玩的桌宠；在 macOS 桌面 App 中还能启动透明角色窗口。

## 选择角色来源

制作需要当前账号的内容写权限。原生桌宠使用当前账号已保存的 Live2D 角色；若还没有角色，先到 Live2D 工坊创建或导入并保存。另一条入口是项目列表“导入角色资源包”，接受兼容的本地鲸鱼娘或人物小人 ZIP。

| 来源           | 外观调整方式                      | 开始前需要                         |
| -------------- | --------------------------------- | ---------------------------------- |
| Live2D 角色    | 用同尺寸 PNG 替换部件贴图形成皮肤 | 已保存的角色工程与绑定             |
| 分层角色资源包 | 选择包内已有配色与分件动画        | 本地兼容 ZIP；应用不会代为联网下载 |

## 从 Live2D 创建第一只桌宠

1. 在桌宠工坊创建桌宠，选择来源角色并输入名称。先确认角色已在当前账号保存。
2. 打开项目，检查角色预览和来源版本；创建会复制文档与必需素材，形成固定快照。
3. 在交互区域先设置一个简单事件，例如点击身体时的动作或表情；在台词区域写一句可辨认的短句。
4. 用试玩的事件播放检查结果，再调整大小、走动、气泡和声音等习惯。
5. 保存项目。在 macOS 桌面 App 中点击“放到桌面”，确认透明窗口、拖动和触摸区域均正常。

> [!NOTE]
> 浏览器可以编辑和模拟试玩；独立透明桌宠与聊天小窗由 macOS 桌面版提供。没有桌面窗口并不表示工程创建失败。

## 判断桌宠是否准备好

试玩中分别检查待机、点击、拖起和放下，确保事件没有引用错误动作。重开项目后配置应仍在；真正放到桌面后，还要核对屏幕位置、角色大小和声音是否合适。

事件台词来自你预先编写的句子，不要求模型。文字聊天才使用当前账号可用的文本模型；共享项目人设与每位账号的私人聊天记录分开保存。

> [!TIP]
> 先让一个事件可靠工作，再补其他交互。来源角色后续变化不会自动更新这只桌宠，避免制作角色时影响正在使用的配置。
