# 桌宠工坊：功能概览与快速开始

桌宠工坊从角色快照创建桌宠，配置皮肤、触摸反应、台词和人设。透明窗口与聊天小窗由 macOS 桌面版提供，浏览器可编辑和预览。

## 从角色创建

1. 在 Live2D 工坊制作或导入角色并保存。
2. 打开桌宠工坊，新建桌宠，选择来源角色并命名。
3. 检查角色预览，配置交互、台词、外观和习惯。
4. 保存后先试玩，再在桌面 App 中点击“放到桌面”。

创建会复制角色文档与必要素材，形成固定快照。来源之后修改或删除不会自动改变桌宠。

## 另一种来源

项目列表的「导入角色资源包」支持本机鲸鱼娘与人物小人 ZIP。它们使用分件动画和包内配色，区别于原生 Live2D 部件换肤；应用不会代替你联网下载资源。人物包读取角色名称，默认关闭主动台词，可之后在聊天设置中开启。

## 权限与模型

配置需要空间编辑权限。预设事件台词无需模型；文字聊天需要当前空间可用文本模型。私人聊天与项目人设分开保存。
