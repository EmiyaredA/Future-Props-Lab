# 桌宠工坊：常见问题与能力边界

## 浏览器里没有透明窗口

浏览器提供编辑和模拟试玩。独立透明桌宠与聊天小窗需要 macOS 桌面版，不是浏览器弹出一个普通网页窗口。

## 修改来源角色后桌宠没变化

桌宠保存固定快照。进入试玩明确检查并更新来源；兼容校验失败时修正动作、表情或贴图，不绕过提示覆盖现有快照。

## 换肤被拒绝

核对部件和 PNG 尺寸，替换图必须与目标部件一致。鲸鱼娘与人物小人的分层资源包采用包内已有配色，不接受原生角色部件式换肤。

## 台词与聊天有什么区别

事件及主动台词来自预设内容，不调用模型。聊天依据人设和最近对话调用文本模型，可能计费；历史按账号与空间隔离。

## 重开后临时设置恢复了

运行时选择不自动写回项目。想作为下次默认值，回编辑器设置并保存。只想暂时隐藏时使用运行按钮，不删除项目。

目前不提供语音对话、长期记忆、电脑操作或桌宠包发布安装。聊天中断先检查已有记录，再决定是否重新发送。
