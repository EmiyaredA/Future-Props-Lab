# 桌宠工坊：常见问题与能力边界

桌宠的来源、编辑器试玩和桌面运行是三个不同环节。遇到外观没更新或事件不符合预期，先按下表确认问题发生在哪一环，再修改对应配置；这样能保留已可用的角色快照。

## 常见现象

| 现象                         | 常见原因                                                           | 处理与成功标志                                                                                      |
| ---------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| 浏览器里没有独立透明窗口     | 独立桌宠需要 macOS 桌面版                                          | 浏览器中完成编辑和试玩，再在桌面 App 点击“放到桌面”                                                 |
| 来源角色改了，桌宠仍是旧样子 | 桌宠保存固定快照                                                   | 到“试玩与来源”检查并更新；兼容通过后再验证主要事件                                                  |
| 上传皮肤 PNG 被拒绝          | 图片尺寸与目标部件不同，或来源不支持部件式换肤                     | 核对原部件尺寸；分层资源包应选包内配色                                                              |
| 摸头时触发了身体点击         | 点击位置不在头部热区，或事件配置相同                               | 检查热区并用明显不同的动作、台词分别试玩                                                            |
| 重开后大小或走动设置恢复     | 修改的只是当前运行状态                                             | 回编辑器修改默认习惯并保存，再关闭重开验收                                                          |
| 等了很久仍不走动             | 当前运行档位为“不乱动”、聊天或编辑器联动打开，或旧人物动作包已停用 | 先看桌宠提示；旧包需经视觉验收的完整动作资源更新，其他情况关闭聊天和联动后切到“常走动”，等待约 7 秒 |
| 聊天没有继续回复             | 模型请求失败、取消，或窗口/身份发生变化                            | 查看轮次状态和模型可用性，再决定手动重发，不重复连点                                                |
| 想暂时隐藏却担心丢失配置     | 混淆关闭运行和删除项目                                             | 使用隐藏或关闭运行；删除会清理桌宠配置与素材快照                                                    |

> [!NOTE]
> 台词与聊天不同：事件及主动台词来自预设句子，不调用模型；文字聊天依据人设和最近对话调用文本模型，可能计费。

## 找不到列表或属性时

窄窗口默认显示“预览”。点击工作区上方“列表”查找服饰和事件，点击“属性”修改当前项；在“性格”输入一段草稿后切换面板再返回，内容应保持。可用区域较矮时，滚动当前面板查找后续控件。只读账号会看到只读提示，项目修改和上传入口不可用，但仍可调整预览。

菜单中勾选标记表示当前值，悬停或键盘高亮表示当前操作位置。用方向键移动、Enter 选择、Esc 关闭；关闭后焦点返回原按钮。资源包更新按钮下方显示禁用原因，先保存草稿或结束桌面联动后再上传。

未保存时返回会询问是否离开。“继续编辑”保留草稿；选择“放弃修改”应直接回到项目列表，不重复弹出确认，也不会保存草稿。再次打开同一项目，应看到此前已保存的配置。

## 预览没有变化时

换装时出现“人物桌宠贴图无法加载”，当前可用服饰会保留。检查素材是否可访问，再切回原服饰并重新选择目标服饰；加载成功后提示应消失，角色应显示目标服饰。暂时的加载失败不会永久锁住这套服饰；仍失败时核对资源包，不反复保存配置。

先看舞台上方的事件、动作、表情和状态，再看舞台下方的能力原因。菜单标记“暂不支持”的动作无法在当前资源中演示；已有选项保留显示，系统不替换你的配置。显示“无动作／无表情”时，当前事件保持自然站立；选择“开心”应立即看到表情，无需点击播放。红莉栖菜单中的眨单眼与难过标注尚未支持，不能选择。跳跃、走路演示结束后会停止，表情仍保持；想再次检查动作可以重选同一事件或点“播放事件”。

中间舞台变化而桌宠未变化时，检查“同步预览到桌宠”是否开启。开关不可用通常是该项目桌宠未打开或桌面桥版本不支持；浏览器只能使用中间预览。聊天打开时联动暂停，关闭后显示最新草稿。看到其他编辑窗口占用时，先在原窗口关闭联动；看到项目版本变化时，保留未保存内容并重新加载核对，不自动覆盖。刷新、编辑窗口关闭或崩溃、身份变化和通信断开会释放临时预览。

资源更新后，未选事件保留的旧动作和表情不会阻止当前可用效果联动。先选择“待机、无动作、无表情”开启联动，应看到“临时预览，尚未保存”；再选择缺少素材的效果时，界面显示对应原因。无需清空其他事件或重新保存。完整“播放事件”还需要返回待机的效果可用；运动试玩覆盖事件动作，表情仍按当前配置检查。

具有关节描述的人物资源包可提供侧向头部和分段动作；是否自然仍需逐一检查，格式合法或窗口能移动不能证明素材已合格。旧版本 1 人物包显示“已暂停旧分件动画”，保留完整站姿、坐姿、表情及换装，拖动窗口仍可使用。其攀爬、滑翔和动作演示显示需更新资源，修改走动档位或重新保存不会恢复被停用的拼接动画。替换前先核对三套服饰、主要表情及动作衔接，只有通过视觉验收的完整兼容包才可用于“更新资源包”。分层角色的迈腿步相由宿主确认的实际移动距离驱动；仅打开下拉菜单不会重播动作或重新加载贴图。

完整动作资源播放起步、转向或放下过渡时，先完成姿势再开始窗口移动和休息计时。反复选择同一试玩时，应从当前位置重新检查，不突然跳回舞台起点。看到“缺少可用的过渡或支撑”提示时，该段演示会停止；应核对资源，不通过反复保存来恢复。按住仍可立即拖动，腰部跟随当前绘制位置。

## 关闭或重启桌宠时

完整序列角色的鼠标交互按当前实际显示原帧的可见像素判定。将鼠标移到脸、外套或靴子上，再短点或按住，应该进入对应事件或拎起；移到角色周围或帧内透明空白，应恢复桌面点击；已显示的悬停按钮及从角色边缘通向按钮栏的短通路保留交互。将鼠标从靴子或头顶移到按钮栏，应能操作按钮；再移到远离按钮栏及短通路的透明空白，应收起按钮栏。切换动作和换装后，点击区域随成功显示的新画面更新。若显示“完整序列帧点击区域读取失败”，先检查素材访问与加载提示，再重新选择当前可用效果或配色重试；读取失败时不把透明空白当成角色，也不自动保存草稿。

完整帧角色弯腰或悬挂时，头部热区跟随当前头部姿态。先为“摸头”和“点击身体”配置不同的台词，在试玩及桌宠上分别短点脸和靴子：脸应触发摸头，靴子与长发尾应触发身体点击；点透明空白不播放事件。若脸仍触发身体点击，核对当前原帧的冠顶与下巴登记，调整窗口大小不能修正错误头部登记。试玩按钮仍可用 Tab 聚焦和 Enter 试听。

独立桌宠提示“动作资源未齐”时，展开状态查看缺少的动作片段或过渡姿势；短点也可能触发当前包未提供的反应。角色会保留最后正确画面并停止当前自主轨迹，缺失的点击或聊天动作也不会启动旧跳跃物理。这不表示窗口启动或移动通信失败；仍可手动移动，并选择当前包支持的效果重新检查。“播放事件”结束后仍按规则返回待机。更新通过视觉验收的完整资源后再检查该反应，重新保存不会补齐素材。支撑冲突、接触点登记不一致和运动通信失败仍按异常处理；看到“桌宠状态异常”时先展开查看具体原因。

“重启桌宠”只重开独立窗口，不保存当前草稿。关闭联动、收起或重开后先核对编辑器的“未保存修改”仍在；希望草稿成为默认值时使用“保存”。重开后出现旧外观通常是尚未保存的草稿与保存基线不同，可开启临时联动核对。独立窗口右上角的状态按钮可用键盘展开完整原因；不要把动作资源未就绪误认为窗口启动失败。

## 攀爬、拎起或滑翔不符合预期时

靠近底边拎起时，身体暂时伸出工作区属于预期行为，腰部应连续跟随鼠标；松手才收回边界。如果角色反复向上跳、抓点脱离鼠标，或松手后悬挂卡住，属于放置或运动通信异常。五官贴到刘海上、眼睛带着矩形皮肤块、袖口扭曲或分件断开也属于素材／绑定问题，不能用重新保存配置解决；候选资源应先经过放大抽帧检查。

先确认来源是分层角色，并在习惯中启用对应开关；Live2D 会显示暂不支持。关闭聊天与编辑器联动，切到“常走动”后等待约 7 秒；每次活动结束才开始下一段休息。可攀爬表面是屏幕桌面可用区域，避开菜单栏和 Dock，其他应用窗口不是攀爬表面。顶部和底部演示禁用时，表示资源包未提供四边姿势；打开开关不会补出缺失的素材。

松手后原地停留是预期行为：滑翔由下一次自主活动决定，高度不足也不会滑翔。支持四边动作且启用边缘攀爬时，正常拖动放下后才会判定贴边；短点、取消手势或捕获丢失不触发贴附。实际抓取和贴边距离使用角色的可见范围及接触点，透明窗口空白不算边缘。按住超过约 150 毫秒可检查持续拎起；出现腿折到头旁、颈部反向扭转或衣物断缝时，视为动作素材不合格，不应继续应用。关闭“高处滑翔”后不会强制把高处的角色拉到底部。

窗口靠边时以角色可见范围约束位置，透明空白可能越出工作区；气泡和悬停按钮会向内调整。拔除显示器或更改缩放会取消旧轨迹并按新工作区重新定位。看到运动通信失败提示时，角色停在宿主确认的位置；关闭桌宠后重新打开，确认提示消失后再检查运动，不会自动重试旧轨迹。

动作看起来像分件拼接时，在“试玩”分别检查左右走路、攀爬、滑翔和落地；关注手脚接触、袖口与裙摆接缝，不能只凭角色移动判断姿势正确。仅靠正面贴图或缺少关节补画的旧包，不能获得完整侧向关节动作。

切换动作后头、手脚或身体忽大忽小时，先保持同一尺寸、服饰和预览位置，对照待机、行走与拎起；屈膝和弯腰会改变整体高度，头部和骨段本身不应跟着缩放。眼睛偏离脸部、前后腿一起弯着快速换脚、靴子与小腿断开，也应按动作素材与绑定问题处理。调整桌宠大小或重新保存不能修复这些问题；保留有问题的动作名称和连续画面，先修正并验收资源再更新。

同一服饰在某个动作里只剩外套袖子、衣身或衣尾消失时，对照待机和该动作的完整原画，检查肩背到髋侧的衣片及独立条纹下摆。只有袖口条纹不能代表外套下摆已画完整。换装或保存不会补回原画遗漏；修正后应逐帧检查进入、持续动作和放下，再更新资源。

中央完整序列预览使用资源共用画布整体取景。缩小编辑窗口后，头部、手和靴子应仍在舞台内；透明边距会保留，改变姿势不会按图片轮廓重新放大。若同一尺寸下切换动作仍出现头身比例突变，应检查原帧标尺与登记。中央取景调整不会改变独立桌宠的尺寸或桌面位置。

完整序列帧仍可能在相邻画面中改变人物比例。对照同一画布的连续原帧，检查透明边距变化是否把头部或身体重新放大，分别核对三套服饰及动作首尾；整张图片没有分件，并不表示比例和过渡已经自然。导入提示头部标尺、统一帧尺寸或服饰图集范围不符时，应修正资源原帧与登记，不能靠调整桌宠大小绕过。当前新候选尚未完成视觉验收，已提供的合法片段也不代表完整行走、四边攀爬与滑翔均已可用。

序列帧走路时，检查承重脚是否停在桌面同一位置，再观察另一条腿摆动和落脚。只有窗口连续移动、身体却每隔几帧跳一次，也不算自然行走。支撑点登记、交接或确认位移不一致会停止动作并提示失败；重新打开窗口不会补齐错误原画。旧包不需要写回新字段，但缺少真实支点的完整帧不能用于物理行走或攀爬。

停止或转向失败时，分别在不同落脚阶段重复检查。资源需要提供与当时实际姿势对应的收步和转身画面；一条通用过渡不一定能覆盖所有步相。快速切换动作也应检查正在播放的入口能否直接接上新目标。缺少过渡时会保留当前画面并反馈，重新保存配置不会补出这些原画。若退出过渡已显示完全相同的待机首帧，可以立即点击“播放事件”重播；播放器会从该已显示姿势进入新动作，仍检查新动作资源是否齐全。

制作新动作时，先核对完整姿态的头、肩、腰、膝和靴子比例，再检查绑定后的实际画面。静态完整图正常，走路时却出现锯齿、腿间空洞或靴底长条，说明网格或关节绑定仍有问题。新版应使用重新制作的动作；不以已拒绝的旧动作填补缺项。循环、开始和结束都需检查连续画面，只有全套服饰和动作通过后才更新资源包。

拎腰姿态的双手应从放松的肩膀自然下垂，肘部轻微弯曲；静止按住后逐渐稳定。双手举过头顶属于顶部攀爬姿态，不能用来代替拎腰。若原画的手臂长度正常，绑定后却出现抬手、袖口白缝或裤腿断线，应检查原始关节角度与遮挡连接，不能靠放大手臂或强拉关节补齐。

使用带换支点阶段的完整爬行资源时，手脚回收期间窗口应短暂停住，建立新支点后身体再上移；休息间隔从本次活动结束后重新计算。若角色一直停住并显示资源或支撑错误，检查本包是否提供该方向的完整承重和发力原画，再重新选择有效动作或点击“播放事件”。反复重播不能补齐缺失姿势，关闭再打开菜单也不应导致窗口自行补走。

完整动作图集读取失败时，预览和独立桌宠会显示加载错误。首帧未加载成功时保留原站姿，后续失败则保留最后正确画面；取消运动或自动回待机不会再次发起同一失败请求。检查资源后，在编辑器点击“播放事件”或重新选择当前包支持的效果、配色进行重试，成功绘制后错误提示消失。重试不保存草稿，也不能补齐缺少的动作。

出现“完整动作图集超过解码预算”时，角色会保留最后正确画面。已经缓存或压缩后很小的 PNG 仍可能超额；资源作者需减少一次切换涉及的图集原图总像素，并保持全部原帧的共同画布和人物比例。修正资源后重新选择有效效果或点击“播放事件”，新画面成功显示后错误提示应消失，草稿不会自动保存。反复重播同一超额资源或调整桌宠大小不能解决预算问题。

重新加载后，等待角色的新画面出现，再查看桌宠顶部状态：读取错误应消失，仍缺少的动作会显示对应原因。恢复后重新等待走动间隔；若提示移动通信失败，按状态说明关闭并重新打开桌宠。拎起资源可用时，从非腰部按住也应保持首帧连续，再平滑转移到腰点；松手后仍等待最终放置确认，不突然清空画面偏移。

检查完整帧时，将鼠标在角色左右两侧各停留一秒，再按住角色：同一张原画应保持宽度，不被横向压窄或突然翻面。左右运动需要对应方向的完整原画；没有转身画面时保持当前视图并提示资源原因。旧版本 1 人物保留正面站姿、坐姿与表情，鼠标追随不会恢复被停用的侧向拼接动作。

## 来源更新失败时

先保存当前仍可用的桌宠。核对来源角色中动作、表情和部件是否已删除或改名，再检查替换贴图。兼容校验失败时保留当前快照是预期保护，不应通过手动改文件绕过。

## 资源包更新失败时

先确认修改已保存、桌面联动已结束，再上传同一骨架类型的完整 ZIP。新包必须包含当前默认服饰 ID；包损坏、尺寸不一致或包含脚本时会拒绝更新。版本冲突时保留旧素材，使用“载入最新版本”核对其他窗口的修改后再决定重试。若提示“资源包已更新，桌面刷新失败”，先重新显示桌宠，不要重复上传；聊天记录仍属于原项目。

完整序列包提示登记帧引用无效时，核对 `cels` 中是否有对应的完整帧，以及每套服饰是否提供声明的图集；未使用的声明也会检查。复用登记只能减少重复 JSON，不能绕过帧数、模型文件或图片预算。修正包后重新上传，应通过引用与裁切校验并保留原项目配置；不要通过提高桌宠尺寸或反复保存来解决导入失败。

## 当前不提供的能力

桌宠工坊目前不提供语音对话、长期记忆、电脑操作或独立桌宠包发布安装。配置人设不会让桌宠获得操作其他应用的权限；私人聊天也不会写进共享项目人设。

> [!WARNING]
> 切换账号、账号或退出 App 会关闭运行窗口并取消当前客户端请求。重新打开后先查看已有记录，避免把中断理解为从未发送。
