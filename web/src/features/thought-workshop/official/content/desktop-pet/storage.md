# 桌宠工坊：保存与素材管理

## 项目配置与运行状态

编辑器保存外观、事件、人设和习惯，作为下次启动的默认值。运行中换装或调整走动只作用于当前会话；需要长期保留时返回编辑器修改并保存。

离开或切换空间前处理未保存草稿。冲突时保留当前配置，核对服务器版本后再处理，不反复覆盖。

## 固定来源快照

创建时复制 Live2D 文档和必需素材。来源角色修改不自动生效；在试玩中明确检查并更新来源，系统核对动作、表情和皮肤兼容性，不兼容会保留现有快照。

部件换肤 PNG 必须与对应部件尺寸相同。换肤复用绑定，不是导入另一只角色。来源结构变化后重新检查贴图与动作。

## 私人聊天

项目人设与用户聊天分开保存。聊天模型、历史和偏好按账号、空间及桌宠分别记录，不进入共享角色配置。

关闭聊天、隐藏桌宠、切换身份或退出 App 会取消当前客户端请求；失败或取消的轮次标记中断，不自动重发。

## 删除

删除桌宠清理其配置和素材快照，来源角色不受影响。删除前确认不是仅想关闭桌面窗口；关闭运行与删除项目是不同操作。
