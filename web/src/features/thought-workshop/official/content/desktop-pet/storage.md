# 桌宠工坊：保存与素材管理

运行中临时把桌宠缩小，并不一定意味着下次启动也会保持这个大小。桌宠有项目默认配置、当前运行状态、固定来源快照和私人聊天四类数据；理解各自保存的位置，能避免错误更新或误删角色。

## 哪些修改需要回编辑器保存

外观、事件、人设和习惯由编辑器保存，作为下次启动的默认值。运行窗口里的临时换装或走动调整作用于当前会话；需要长期保留时，返回编辑器设置并保存。

“同步预览到桌宠”只把展示草稿保存在内存，不修改项目配置或私人聊天。关闭联动、离开或刷新编辑器、窗口崩溃、断线和身份变化后恢复已保存配置。联动期间保存仍走原有版本校验；成功后刷新运行基线，临时换装和走动档位仍属于当前会话。

“边缘攀爬”和“高处滑翔”属于项目习惯，默认开启，使用同一版本校验保存。旧配置读取时补齐默认值，读取本身不写回。窗口位置、运动轨迹、悬挂摆动和试玩姿态仅在内存中，重新打开不会恢复未完成的轨迹；本次能力不增加数据库 schema 或事件类型。

离开项目或切换 Workspace 前确认保存状态。发生版本冲突时保留当前配置并核对服务器版本，不要把重复点击保存当成合并。

## 明确更新来源快照

创建桌宠时会复制 Live2D 文档和必需素材。来源角色后来修改，不会即时改变桌宠；删除来源也不会自动移除已复制的角色。

1. 先在 Live2D 工坊保存并验收新角色版本。
2. 打开桌宠项目的“试玩与来源”，查看当前来源版本。
3. 点击“检查并更新来源”，阅读动作、表情和换肤贴图兼容检查。
4. 更新后逐个播放主要事件，再保存项目并重新启动检查。

> [!WARNING]
> 不兼容时系统保留现有快照。先修正缺失动作、表情或贴图关系，不要绕过提示手动替换运行目录。

## 皮肤文件与来源结构

部件换肤使用与目标部件相同尺寸的 PNG，复用已有网格与动作；它不是导入另一个角色。来源结构发生变化后，需重新检查皮肤贴图与绑定是否仍对应。分层资源包采用已有配色，其素材按独立来源保存。

## 更新本地分层角色资源

“更新角色资源包”替换完整模型和服饰素材；它保留项目 ID、标题、人设、交互配置及聊天。新包需保留当前默认服饰，全部素材准备并通过版本校验后才切换。失败或冲突时旧包继续有效；出现冲突先载入最新版本核对，再决定是否更新，不要自动覆盖其他窗口的修改。普通资源更新不需要数据库迁移。

## 私人聊天如何隔离

共享人设属于项目，聊天模型、历史、主动台词开关与气泡／对话展示偏好属于账号、空间和桌宠的组合。其他账号不会因为能编辑同一桌宠就共享你的私人消息。升级前已有聊天保留完整对话展示，新建个人聊天默认气泡；可以在完整面板选择并保存自己的偏好。

关闭聊天、隐藏桌宠、切换身份或退出 App 会取消当前客户端请求；失败或取消轮次标记为中断，不会自动重发。重新打开后先查记录，避免重复发送同一句话。

展开或收回回复只改变同一窗口的布局，不取消请求，也不改变历史。长回复的气泡摘要来自原文开头，完整内容保留在对话记录中。

> [!NOTE]
> 删除桌宠会清理其配置和素材快照，但不删除来源 Live2D 工程。只想结束当前运行时应关闭或隐藏窗口，不要删除项目。
