# 桌宠工坊：导入导出与交付

把本地角色变成可运行桌宠，需要先导入受支持的来源，再保存桌宠配置并在桌面 App 启动。当前没有独立桌宠安装包的发布流程；本节说明两条实际可用的输入路径，以及启动后的验收方式。

## 从已有角色工程开始

原生桌宠使用当前账号的 Live2D 角色快照。若角色来自另一环境，先在 Live2D 工坊导入 `.fpllive2d`，检查绑定与动作并保存，再回桌宠工坊创建。这样桌宠获得的是明确的已保存来源，而不是对外部文件夹的临时引用。

## 导入分层角色资源包

1. 在项目列表点击“导入角色资源包”，选择本地兼容 ZIP。
2. 阅读导入校验结果；包内模型与 PNG 必须符合支持的结构。应用不执行包内脚本。
3. 导入完成后检查角色名称、默认外观和可用配色。鲸鱼娘与人物小人的分层包使用包内配色，不等同于 Live2D 部件皮肤。
4. 用试玩检查动作与事件，按需要配置台词、人设和习惯，再保存。

导入资源保存到当前账号，之后不依赖原目录。人物包读取角色名称，默认关闭主动台词，需要时再到相应设置开启。

> [!NOTE]
> 应用只读取你选择的兼容本地包，不代为联网下载角色资源，也不将资源包脚本作为程序运行。

## 放到 macOS 桌面

保存项目并完成试玩后，在桌面 App 点击“放到桌面”。检查屏幕位置、拖动、触摸、悬停按钮与气泡；透明区域允许鼠标穿过，角色区域响应触摸和拖动。

同一时间运行一只桌宠。若使用聊天小窗，选择文本模型后先发一条短消息验证。切换账号或账号、退出 App 时，桌宠和聊天窗都会关闭。

## 对外交接什么

对外交付角色绑定时使用 Live2D 工程包；桌宠事件配置、运行设置和个人聊天不是同一种交付物。当前没有独立桌宠包发布、导出和安装入口，不要用复制私有数据目录代替正式交接。

> [!TIP]
> 验收时先关闭再重新启动桌宠，确认保存的默认外观与习惯能恢复；这比只看当前试玩窗口更能发现遗漏保存。
