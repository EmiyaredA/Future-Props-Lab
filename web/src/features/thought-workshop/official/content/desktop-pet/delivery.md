# 桌宠工坊：导入导出与交付

## 导入来源

原生桌宠从当前空间已保存的 Live2D 角色快照建立。要跨环境制作角色，先在 Live2D 工坊使用 `.fpllive2d` 导入，再在桌宠工坊创建。

分层角色使用项目列表的「导入角色资源包」入口，选择本地 ZIP。兼容 Coopanion 鲸鱼娘，也支持红莉栖这类人物小人的分层资源包。导入会校验模型与 PNG，不执行包内脚本；资源保存到当前空间，之后不依赖原目录。配色与原生部件皮肤不同。

## 放到桌面

1. 保存项目，先在试玩中检查事件与外观。
2. 在 macOS 桌面 App 点击“放到桌面”。
3. 检查屏幕位置、拖动、触摸、悬停按钮及气泡。
4. 需要聊天时选择文本模型，先发一条短消息验证。

同一时间运行一只桌宠。透明区域允许鼠标穿过，角色区域响应触摸和拖动。切换账号或 Workspace、退出 App 时关闭桌宠及聊天窗。

## 更新与交接边界

来源变化通过明确更新快照生效，先检查动作、表情和皮肤兼容性。桌宠配置不是公开发布包，当前没有独立桌宠包发布、导出安装流程；不要把手工复制私有目录当作交接方式。

对外交付角色绑定时使用 Live2D 工程包；桌面运行设置和个人聊天是不同层面的数据。
