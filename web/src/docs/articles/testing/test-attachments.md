# 多模态附件

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 选择支持附件的模型

先核对模型声明的输入能力，再在对话输入区添加受支持附件。文本模型可见不代表它能读取图片或音频。

当前文本对话上传的是图片：JPEG、PNG、WebP、GIF。每条消息最多 5 张，单张最大 8 MiB，图片任一边不能超过 8000 像素。它不是任意文件上传入口；音频识别请切换专门模式，视频参考请使用视频生成测试。

## 添加与检查

上传或选择附件后，检查输入区的缩略图、名称及错误提示；等待上传完成再发送。发送前删除不需要的附件，避免把无关信息一并提交。

## 结果与记录

成功轮次的图片可能随上下文进入后续请求。附件在当前空间的模型测试数据中管理，不自动变成工坊素材。带附件日志通常不满足纯文本复现包的导出条件。

语音文件转写应使用[语音识别模式](/docs.html?page=test-transcription)。
