# 测试入口与模式选择

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 选择测试模式

从 Studio 的“模型测试”进入。先选择需要验证的模式，再选择该模式下可用的模型。文本对话、图像、视频、语音识别和实时语音使用不同输入控件和结果视图。

## 准备输入

文本测试从简短提问开始；生成测试先确认参考素材与模型参数；语音识别上传受支持的音频；实时语音需要浏览器麦克风权限。

## 理解数据归属

测试记录属于当前工作空间的调试数据，不自动进入视觉工坊项目素材库。语音识别结果可通过明确入口创建录音标注任务。真实模型测试可能产生供应商费用，先使用小规模输入验证。
