# 图像生成测试

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 开始生成

切换顶部“图片生成”，选择已启用的 SenseAudio 图片类型模型。填写提示词后点击“开始测试”。只给 OpenAI 兼容模型增加图像能力标签不会启用此入口。

![图片测试配置，未提交外部请求](/docs/test-image.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 参数选择

当前测试面板提供提示词、尺寸和可选种子。提示词最多 6000 字符；尺寸从所选模型提供的列表选择；种子填写非负整数，留空交由服务处理。相同种子不保证不同模型或不同服务版本得到同一张图。

不要把视觉创作工坊中的参考图、批量拼图等操作误认为此测试页的相同按钮；需要画布上下文时进入[图像生成应用文档](/docs.html?page=visual-image)。

## 查看结果

提交后在任务列表查看状态。成功后预览并下载图片；失败时打开任务详情及日志检查规范化参数。离开页面不等于取消已提交任务。

生成结果是模型测试素材；要在项目中继续使用，请通过文件或素材导入入口明确加入项目。
