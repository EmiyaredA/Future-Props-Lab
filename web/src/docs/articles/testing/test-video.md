# 视频生成测试

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 选择输入

在模型测试顶部切换“视频生成”，选择可用的视频模型。输入提示词，可选上传参考图片、音频或视频。视觉创作工坊中的“四种输入方式”属于应用画布，不是此测试页的独立模式按钮。

![视频测试参考素材与参数](/docs/test-video.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 提交前

核对提示词、素材、时长、分辨率及比例。换模型后重新检查参数，不要默认不同供应商接受同一组选项。

| 当前参数       | 检查方式                                                       |
| -------------- | -------------------------------------------------------------- |
| 提示词         | 最多 6000 字符，描述主体、动作和镜头，不填 API 凭证            |
| 参考素材       | 本地素材合计不超过 45 MB，最多 9 张图、3 个音频、3 个视频      |
| 音频参考       | 必须搭配参考图片或视频，不能只上传音频                         |
| 时长与分辨率   | 从当前模型选项中选择；页面显示的分辨率可包含 480p、720p、1080p |
| 比例           | 按输出用途选择，提交前确认选中值                               |
| 生成音频与水印 | 明确检查两个开关；不等于后期编辑音轨或自动去水印               |

## 跟踪任务

视频生成通常异步完成。等待、提交、处理中和终态具有不同含义；查看任务详情了解当前进度。任务结束后预览下载结果，失败时保留任务 ID 与错误信息。

> 提交阶段中断不会自动重复提交。重新生成前先核对是否已在供应商侧产生任务，避免重复计费。
