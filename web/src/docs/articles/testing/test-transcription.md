# 语音识别与结果导出

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 开始前

适合把音频转换为可检索的文字，并继续进行逐段校对。先准备当前空间可用的语音识别模型和对应录音；支持参数取决于模型，切换模型后重新检查设置。

## 测试语音识别模型 {#model-test-speech}

1. 在模型服务中启用 SenseAudio ASR Pro 或 ASR API 专业语音识别；也可以为 OpenAI 兼容模型声明 speech_recognition 能力并配置 API Key。
2. 进入模型测试并切换到“语音识别”，上传本地音频或从当前 Workspace 的文件管理中选择。
3. 参数区会按当前模型显示真正生效的语言、翻译、字词时间戳、文本整理、说话人、最大人数、标点、热词和缩写设置；切换模型后会恢复该模型默认值。
4. 任务会在后台运行；完成后可试听、复制全文，并查看任务参数、译文、说话人、重叠候选、处理提示和默认收起的字词时间戳。
5. 完成后可以导出可移植的识别 JSON 1.1，或直接创建录音标注任务；录音标注的“导入项目”兼容识别 JSON 1.0/1.1，并要求选择对应音频。标注只使用原语言识别文本。
6. 在录音标注编辑器中也可以选择语音识别模型，并在模型下方明确设置原语言与目标语言；目标为原文时只转写，选择其他受支持语言时会创建或切换到对应版本并写入译文，模型不支持的目标语言不可选择，已有文字需要确认后才会替换。
7. 一个录音片段可以同时勾选多位说话人；列表、波形标签和 SRT 导出会按选择顺序显示全部说话人，旧项目的单人标注保持兼容。
8. 选中录音片段后，可用“紧接上一段”或“紧接下一段”把当前片段的一侧贴齐相邻片段，快速消除对应间隙；文字、说话人和另一侧时间保持不变。

> 支持 MP3、WAV、M4A、OGG 且不会自动切片；ASR API 专业语音识别最大 100 MB，其余当前模型最大 10 MB，超限文件会在选择器中禁用。
