# 测试工具与 Mock

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 工具测试的用途

测试工具用于验证模型是否选择合适工具、生成正确参数并使用返回值。它与集成中心的真实工具 API 目录不同，Mock 结果用于确定性调试。

## 配置与使用

1. 打开 Studio 的“测试工具”，创建工具定义。
2. 填写名称、说明、输入结构与 Mock 返回内容。
3. 在模型测试设置中选择该工具。
4. 提问触发工具调用，展开调用卡核对参数、结果及状态。

## 排查

未调用时检查模型是否支持工具、是否选择了工具及说明是否清楚。参数不正确时先改善 Schema 与说明。Mock 成功并不证明外部业务接口已经执行，也不应把模拟结果当作真实查询结果。
