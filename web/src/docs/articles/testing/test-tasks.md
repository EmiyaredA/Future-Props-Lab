# 任务状态与失败处理

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 阅读状态

| 状态阶段       | 含义                       |
| -------------- | -------------------------- |
| 等待           | 已登记任务，等待执行       |
| 提交           | 正在向供应商提交请求       |
| 待处理、处理中 | 已进入异步执行流程         |
| 完成           | 结果已处理并可查看         |
| 失败或取消     | 查看详情确认原因与已有结果 |

## 失败后怎么办

先检查模型、参考文件和参数，再查日志。网络恢复后是否能继续轮询取决于任务阶段；不能把所有失败都当成可自动重试。

## 保存与恢复

后台任务从持久化记录恢复所属空间。提交阶段中断会安全失败以避免重复外部提交。只有界面明确提供的取消或重试入口才适用于当前任务，离开页面不会自动撤销远端请求。
