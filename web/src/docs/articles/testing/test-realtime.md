# 实时语音

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 开始前与适用范围

用于验证模型的实时语音能力，不是电话接入或持久化语音助手。需要可用的实时语音供应商、麦克风和安全浏览器上下文（HTTPS 或 localhost）。建议佩戴耳机，避免扬声器回声影响自动断句。

## 测试实时语音模型 {#model-test-realtime-voice}

1. 在模型服务中为 SenseAudio 实时语音配置 API Key、保持 WSS 地址并启用 senseaudio-realtime-1.0。
2. 进入模型测试并切换到“实时语音”，可配置音色、开场白、系统提示词、测试工具、VAD 阈值与断句、播放缓冲、说话打断和麦克风处理，然后允许浏览器使用麦克风。
3. 开始通话后直接说话即可；页面会自动判断停顿、提交当前语句，并以聊天消息卡按轮次保留双方转写及语音。工具调用卡会嵌入对应模型回复，可展开查看参数、Mock 结果或失败原因。
4. 通话中可独立静音麦克风或扬声器；结束通话或离开实时语音页会关闭麦克风、音频上下文和连接，但最近一次测试的转写和双方语音可在切换页面后回来查看、回放。

> 固定音频协议为单声道 PCM16：输入 16 kHz、输出 24 kHz。转写和双方音频只保存在当前浏览器页面进程内，音频缓存上限为 64 MiB；开始新通话、刷新、关闭页面、登出或切换 Workspace 后清除。工具调用快照、参数、结果、状态和耗时会写入测试记录；调用日志只保存工具摘要，不保存转写正文或音频。VAD 初始化失败时需重试，不会降级为不可靠的免按键通话。
