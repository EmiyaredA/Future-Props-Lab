# 文本对话、提示词与参数

<!-- prerequisites -->

面向验证模型效果的用户。先在当前空间配置并启用适用模型；确认供应商支持当前测试模式。提交真实请求可能产生费用，页面中的演示不代表实际模型效果。

## 建立对话

进入模型测试的文本对话模式，选择文本模型。设置系统提示词，例如“请先给出结论，再用两句话解释”，输入问题后发送。

![文本对话与测试参数](/docs/test-chat.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 调整模型参数

设置面板按模型能力提供参数。系统提示词定义整体回答要求，用户消息描述当前任务；温度等采样参数影响生成行为，不保证输出完全确定。

| 设置        | 当前界面范围与用途                                    |
| ----------- | ----------------------------------------------------- |
| 系统提示词  | 可选，用于定义角色、语气和回答规则                    |
| Temperature | 0～2，步长 0.1；较低通常更稳定，实际行为取决于模型    |
| 最大输出    | 1～8192 Token；它是本次输出上限，不是模型总上下文窗口 |
| 测试工具    | 仅对支持工具能力的模型绑定本地 Mock 工具              |

更改参数后等保存完成再发送；使用“恢复默认参数”可以重置当前会话的测试设置。

## 上下文与停止

只有成功完成的轮次及其图片进入后续请求。失败或停止的回复保留展示，但不会被当成成功上下文继续提交。生成中可点击“停止生成”，之后应检查该轮状态。

## 对照结果

修改提示词或模型时保留清晰测试目的，结合调用日志比较耗时、响应内容与错误。不要将一次成功响应视为对所有输入的保证。
