# 导入识别及标注 JSON

<!-- prerequisites -->

面向录音标注工坊用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 两类输入

项目列表“导入项目”支持录音标注项目 JSON，以及模型测试导出的识别 JSON 1.0/1.1。前者保留标注结构，后者将识别分段转成可编辑任务。

## 导入流程

1. 选择 JSON 文件，检查界面识别出的类型。
2. 选择对应的原始音频，核对标题与时长。
3. 阅读导入提示，确认要忽略或保留的识别片段。
4. 点击“导入并打开”，试听多个切点检查音频与时间对齐。

## 校验失败

不要仅修改版本字段使文件通过检查。确认 JSON 来自支持的导出入口；识别文本与翻译有不同用途，标注导入默认使用原语言识别内容。
