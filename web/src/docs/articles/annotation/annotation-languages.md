# 语言版本与模型识别

<!-- prerequisites -->

面向录音分段标注用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 选择识别参数

在编辑器选择语音识别模型，并明确设置原语言与目标语言。目标选择原文时仅转写，选择其他受支持语言时创建或切换对应语言版本并写入译文。

## 替换已有文字

已有文字需要确认后才会替换。先核对当前版本和模型支持的目标语言，避免把译文覆盖到原文校对任务中。

## 查看多语言

使用“优先展示语言”和“筛选片段语言”检查不同版本及未标注语言片段。语音识别结果仍需人工校对，多人重叠与专名尤其需要试听核实。
