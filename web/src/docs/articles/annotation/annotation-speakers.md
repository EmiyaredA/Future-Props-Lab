# 说话人与多人标注

<!-- prerequisites -->

面向录音标注工坊用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 建立说话人

维护容易区分的说话人名称，再为片段选择对应人物。没有确认身份时可用明确的临时称呼，校对后统一修改。

## 多人同时发言

一个片段可以勾选多位说话人。列表、波形标签和 SRT 按所选顺序显示全部说话人。旧项目的单说话人标注仍兼容。

同片段的情绪也按人分别记录；先选定说话人，再在情绪区域勾选要修改的对象。移除片段说话人时，其对应情绪绑定也会移除。详见[文本、情绪与校对](/docs.html?page=annotation-text)。

## 导出检查

不要把“已写入文本”当成“已完成标注”。缺少说话人的片段会影响 SRT 导出。多人名单应与录音中实际出现的发言者相符，不要把围观角色也加入说话人。
