# 文本、情绪与校对

<!-- prerequisites -->

面向录音标注工坊用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 逐段编辑

选择片段并试听，填写逐段内容。整理口头语和标点时遵循自己的标注规则，避免擅自改变原话含义。

## 情绪与校对状态

情绪按片段中的说话人分别标注。先勾选绑定对象（可以全选），再选择预设或自定义情绪；同一时段可让不同说话人拥有不同情绪。没有选入该片段的说话人不能成为情绪绑定对象。

情绪与文本校对是不同信息；选择情绪不等于完成校对。旧项目的单一情绪会在读取时兼容到对应说话人，新导出会保留逐人标注。

## 项目情绪词库与颜色

情绪「管理」可预建自定义词条并选择颜色；内置预设只读。自定义名称最多 40 字符，项目最多 64 项，名称不区分大小写去重；快速输入「使用」时也会尝试加入词库，重复项会提示。

重命名自定义情绪同步更新片段中的对应文案；删除词条只移出词库，已有标注仍保留。修改颜色不改变片段情绪文字。项目 JSON 保留词库名称与颜色，SRT 不提供完整情绪备份。

## 检查遗漏

通过列表检查空文本、未指定说话人和未校对项。项目 JSON 保留片段与校对状态，适合中途交接；SRT 主要提供字幕内容，不替代完整项目文件。
