# 文本、情绪与校对

<!-- prerequisites -->

面向录音标注工坊用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 逐段编辑

选择片段并试听，填写逐段内容。整理口头语和标点时遵循自己的标注规则，避免擅自改变原话含义。

## 情绪与校对状态

按界面提供的情绪字段标注表达状态，并完成校对。情绪与说话人是独立信息；同一角色在不同片段可有不同情绪。

## 检查遗漏

通过列表检查空文本、未指定说话人和未校对项。项目 JSON 保留片段与校对状态，适合中途交接；SRT 主要提供字幕内容，不替代完整项目文件。
