# 导入文本 JSON

<!-- prerequisites -->

面向录音分段标注用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

用于把外部校对结果写回已有录音项目。先导出当前项目 JSON，保留音频和结构，不要在外部重新排序或切分片段。

## 必须保持的结构

schema_version 必须为 "1.0"；片段数量、每个片段的顺序、id、start_ms、end_ms 和说话人分配必须与当前项目一致。language 需要为语言代码字符串或 null，status 为 draft 或 reviewed；语言版本代码不可重复。

导入只更新文本、情绪、语言版本和校对状态，时间和说话人沿用当前项目。结构不一致时整次导入被拒绝，应先使用新导出的文件重新校对。

## 入口与用途

在标注编辑器点击“导入文本 JSON”。此入口用于给现有任务导入文本信息，区别于项目列表中创建新任务的“导入项目”。

## 导入前

先确认当前录音、片段结构和语言版本。导出当前项目 JSON 作为可回看副本，再选择文本文件，阅读匹配或覆盖提示。

## 处理错误

格式不受支持、缺少必要字段或无法匹配时，按提示修正文件。不要把任意聊天模型输出直接当成合格标注文档；需要正确 JSON 和工具认可的结构。

导入后逐段试听检查文字、时间和说话人是否仍对应。
