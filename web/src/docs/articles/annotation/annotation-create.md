# 创建项目与导入音频

<!-- prerequisites -->

面向录音分段标注用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 新建任务

在录音分段标注项目列表创建新任务，填写标题并选择当前空间可用音频。确认文件名称、时长和可播放状态后进入编辑器。

## 选择音频

本地上传和文件库选择按创建界面提供的入口操作。若还要执行语音识别，模型对大小与格式有额外限制；可以播放的文件未必可提交给任意识别模型。

## 删除任务

删除确认会说明标注、说话人和波形数据将被删除，原始录音继续保留在文件库。需要恢复编辑时提前导出项目 JSON，并保存对应音频。
