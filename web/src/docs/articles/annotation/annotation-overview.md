# 录音标注工坊快速开始

<!-- prerequisites -->

面向录音标注工坊用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 工坊用途

录音标注工坊用于在时间轴上整理录音片段，标注说话人、文本、情绪与语言，并输出可继续编辑的项目 JSON 或字幕。

## 完成一次标注

1. 从应用中心打开“录音标注工坊”，创建任务并选择音频。
2. 试听录音，在波形上切分片段。
3. 为片段指定说话人和文本，检查情绪及语言。
4. 校对起止时间与内容。
5. 点击“导出标注”，选择项目 JSON 或 SRT。

## 结果差异

项目 JSON 可以保留未完成草稿；SRT 要求片段具备必要说话人和内容。项目保存在当前工作空间，原录音与标注数据有各自归属。
