# 波形、切分与时间调整

<!-- prerequisites -->

面向录音标注工坊用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 定位与试听

在编辑器通过波形、播放头和片段列表定位。先试听完整句子，再调整起止时间；不要只根据波形高度判断说话边界。

![双人演示标注与波形](/docs/annotation-editor.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 切分与贴齐

选中片段后使用切分和时间编辑功能。“紧接上一段”调整当前片段开始边界，“紧接下一段”调整结束边界，用于消除对应间隙；另一侧时间和文字保持不变。

## 核对范围

片段必须处于录音有效范围，过短片段可能被限制。多说话人重叠需要结合真实录音标注，不能为消除视觉重叠而破坏原时间。保存后再次循环试听边界。
