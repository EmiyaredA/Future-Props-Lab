# 保存冲突与常见问题

<!-- prerequisites -->

面向录音分段标注用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 遇到冲突

编辑器提示服务器标注已被其他操作更新时，本地内容不会被自动覆盖。先点击“导出本地 JSON”保存自己的修改，再加载最新服务器内容并对照。

## 导出不可用

SRT 不可用先查缺失说话人和内容；项目 JSON 则可用于保存不完整草稿。下载后没有文件时检查浏览器下载设置。

## 播放与识别异常

先确认原始录音可访问且浏览器能解码，再检查识别模型与文件限制。删除任务不会删除文件库原录音；重新创建或导入前先找到正确音频。
