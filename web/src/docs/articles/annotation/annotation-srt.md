# 导出 SRT

<!-- prerequisites -->

面向录音分段标注用户。先准备有权使用的录音和当前空间的标注项目；修改需要写权限。保存、项目 JSON 与 SRT 的要求不同，按下文分别检查。

## 导出前检查

确认每个片段都有说话人与非空内容。“SRT 字幕”按钮被禁用时，导出弹窗会显示尚有多少片段缺少说话人或内容。

![完整项目与字幕两种输出格式](/docs/annotation-export.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 下载字幕

1. 在编辑器点击“导出标注”。
2. 选择“SRT 字幕”。
3. 在字幕播放器或剪辑器中与原音频一起检查。

输出使用“说话人：内容”格式，多说话人按选择顺序显示。时间来自片段起止时间，不会自动把所有片段重新排齐。

## 保留项目

SRT 不是完整项目备份，不保留全部情绪、版本与校对信息。需要之后继续编辑，同时导出[项目 JSON](/docs.html?page=annotation-json)。
