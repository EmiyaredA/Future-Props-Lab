# 场景、演员走位与运镜

打开已加载的导演台工程，在每次编辑前确认当前戏段、对象和时间。空间关系与镜头运动需要在实际 WebGL 画面中检查。

## 整理场景

白模资源可按分类、收藏和最近使用筛选，支持列表和宫格。对象列表可按类型、楼层筛选；为演员、摄影机和关键道具使用容易辨认的名称。

先用宽视野检查场景，再调整演员、道具与摄影机位置。对象隐藏会影响成片，暂时隐藏用于检查后应恢复需要参与拍摄的对象。

## 安排演员动作

选择演员，移动播放头到目标时间，编辑走位、朝向与可用动作并记录相应关键帧。播放检查从起点到终点的移动，避免只看某一帧的位置。

需要复用动作时使用动作库及用户动作入口。替换动作后重新检查持续时间、角色方向与地面关系；动作存在不代表它适合当前演员或镜头。

## 设置摄影机

从摄影机画面检查构图，调整摄影机位置、朝向和可用镜头参数，再为运镜设置关键帧。普通观察视图用于编辑场景，摄影机画面才用于核对拍摄结果。

检查起止帧、运动中点、切换时刻与遮挡。多对象同时运动时，用实际播放确认人物是否出画、穿过道具或被前景挡住。

## 表面媒体与预览精度

为对象表面使用工程内媒体时，分别检查映射、裁切、偏移、重复与播放范围。同一源素材可复用，各对象仍可独立裁切。

流畅预览可以降低视频纹理精度；导出仍使用完整精度。验收应同时检查工程保存和最终输出，不能只依赖降低精度的实时预览。
