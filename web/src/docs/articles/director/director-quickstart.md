# 导演台快速开始

从「应用 → 导演台」进入项目列表。导演台用于三维预演，场景编辑需要当前 Workspace 的写权限；搭场景与运镜不需要配置生成模型。

## 建立一段预演

1. 点击「新建预演」打开编辑器，先确认顶部当前戏段、时间轴时长和当前时间。
2. 默认场景带有演员、舞台和摄影机，可先用它熟悉操作。切到左侧「资产」加入自己的地面、建筑或道具，再加入演员；用「俯视」或布景视图检查空间关系。
3. 选择对象调整位置、旋转与尺寸，使用对象列表核对名称、分组和可见性。
4. 点击「添加摄影机」加入机位，或选择已有机位。「并排」同时显示布景与拍摄结果，下方机位监看按钮可切换摄影机画面。
5. 选中演员时，右侧「动作」「走位」用于安排表演；摄影机的「K 位置」记录运镜位置。通过时间轴播放检查，点击顶部「保存」，等待成功后再打开「导出」。

模型、贴图和视频是工程资源，保存时由应用管理；不要用手工修改资源文件代替编辑器操作。

## 戏段与场景对象

戏段用于组织不同预演片段。复制或切换后，先确认正在编辑的戏段和播放时间。演员、道具、摄影机等对象各有属性；选错对象会让参数改到另一处。

对象列表的可见性会影响拍摄与导出，不只是收起列表。用搜索、楼层或区域筛选定位对象后，导出前检查参与拍摄的完整集合。

## 保存和工程包

工程通过服务器版本检测保存。出现冲突时先保留本地内容并核对当前版本，不反复覆盖提交。`.director` 工程包用于导入、导出与继续编辑；预演视频不能恢复场景对象和镜头轨道。
