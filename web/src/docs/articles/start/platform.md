# 平台介绍与能力边界

从模型配置到视觉创作，了解研究所提供的能力。

## 平台提供什么

研究所在同一台主机上管理账号、工作空间、模型连接、公共文件与创作项目。需要调用模型时，先在模型服务配置供应商，再到模型测试验证能力；整理笔记、制作角色、搭建预演与剪辑本地素材可以直接从应用开始。

| 入口               | 适合的任务                                                                 |
| ------------------ | -------------------------------------------------------------------------- |
| 模型服务、模型测试 | 配置与验证文本、图片、视频、语音模型                                       |
| 文件管理           | 整理当前空间内可供项目使用的文件                                           |
| 集成中心           | 管理工具 API、MCP 和 Skill                                                 |
| 应用               | 文稿与笔记、视觉生成、分支故事、剪辑、特效、角色、桌宠、录音标注与三维预演 |
| 创意工坊           | 发布与安装工具 API、MCP、Skill 和能力方案                                  |
| 桌面 Amadeus       | 读取当前窗口上下文，规划并审批执行业务操作                                 |
| 工具导航           | 视频截帧、本机 Codex 模型源及第三方工具入口                                |

## 使用边界

这是单机部署、逻辑多工作空间的管理台。工作空间之间的数据隔离不意味着多实例部署或云端实时协作。实时语音用于测试模型；平台没有 Bot、模型检索知识库（RAG）、电话接入或浏览器扩展功能。

思绪工坊的「知识库」是文档项目容器，沿用 Workspace 权限，不提供 RAG。AI 写作通过 Agent/SDK 接入，思绪工坊内没有单独的 AI 写作入口。

多窗口、Amadeus、透明桌宠和本机 Codex 配置依赖桌面版；具体前提见[桌面 App](/docs.html?page=desktop-use)。创意工坊的公开版本可跨空间浏览，但安装得到的是独立副本，不会共享作者私有凭据。
