# 平台介绍与能力边界

从模型配置到视觉创作，了解研究所提供的能力。

## 平台提供什么

研究所在同一台主机上管理账号、工作空间、模型连接、公共文件与创作项目。先在模型服务配置供应商，再到模型测试验证能力；需要完成创作时，从应用进入对应工坊。

| 入口               | 适合的任务                           |
| ------------------ | ------------------------------------ |
| 模型服务、模型测试 | 配置与验证文本、图片、视频、语音模型 |
| 文件管理           | 整理当前空间内可供项目使用的文件     |
| 集成中心           | 管理工具 API、MCP 和 Skill           |
| 应用               | 视觉素材生成、分支故事、多轨剪辑     |
| 工具导航           | 录音标注、视频截帧及第三方工具入口   |

## 使用边界

这是单机部署、逻辑多工作空间的管理台。工作空间之间的数据隔离不意味着多实例部署。实时语音用于测试模型；平台没有 Bot、知识库、电话接入或浏览器扩展功能。

## 从哪里开始

已有账号可阅读[首次登录](/docs.html?page=quickstart)。安装和启动由部署人员完成，参见[部署说明](/docs.html?page=dev-production-deployment)。
