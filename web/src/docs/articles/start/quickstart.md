# 首次登录与快速上手

完成登录、空间确认和第一次模型测试。

## 准备

浏览器用户向管理员获取平台地址、用户名和临时密码；桌面版首次启动按初始化界面创建首个账号。首次登录如出现修改密码要求，先设置自己的密码；不要将临时密码放入提示词或截图。

## 完成第一次使用

1. 登录后通过侧栏当前空间或顶栏账号入口确认工作空间，避免在错误空间创建项目。
2. 打开[模型服务](/docs.html?page=models-overview)，检查是否已有可用模型。没有配置权限时请联系空间所有者。
3. 进入模型测试，选择已启用的文本模型，发送“请用一句话介绍你能完成的任务”。
4. 返回[调用日志](/docs.html?page=logs-overview)查看请求状态与耗时。
5. 打开应用，选择工坊并创建自己的项目。

如果只需要笔记记录、幻灯片编辑、角色绑定、三维预演或本地剪辑，可以先[选择应用](/docs.html?page=apps-overview)，不必为这些操作配置生成模型。桌面助手与本地接入见[桌面 App](/docs.html?page=desktop-use)。

## 登录或测试失败

密码被重置后需要使用新临时密码。账号禁用、空间无权限和供应商认证失败属于不同问题：登录页失败找平台管理员；模型响应失败先检查模型配置和调用日志。
