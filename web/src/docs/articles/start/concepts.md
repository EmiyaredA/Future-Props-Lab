# 工作空间、项目和素材的关系

理解文件归属，避免切换空间后误以为项目丢失。

## 三个层次

工作空间决定能看到哪些业务资源。项目是某个应用中的创作容器；不同工坊有不同项目类型。素材可以来自公共文件管理，也可以是项目私有上传或生成结果。

## 引用与副本

从文件管理引用素材时，项目使用的是源文件引用；移除引用不会删除公共源文件。跨应用导入或快照导入可能创建独立副本，副本之后不会自动跟随原项目修改。

## 切换空间后的变化

模型、项目、文件和任务列表会随空间变化。其他空间的资源链接不能用于当前空间。先切回原空间再查找项目，不要重复创建同名项目来“恢复”。
