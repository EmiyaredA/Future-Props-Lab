# 面试助手：先准备资料再练习

本篇说明面试助手的实际操作、可验证结果和数据边界，帮助你在当前账号中完成操作后确认保存状态。

## 操作与核验

在应用中心打开面试助手，填写岗位名称与 JD，粘贴简历或上传原件。确认页面的本机 Codex 连接已安装、登录且被管理员授权用于面试资料准备，再开始准备。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 保存与能力边界

材料、准备任务与资料版本归当前账号保存；普通账号不能读取别人的房间和材料。文字练习是基于结构化资料的模拟，音视频为示意，并非自动接入真实招聘面试。

> [!NOTE]
> 本机应用与公网浏览器访问同一部署时使用相同账号隔离规则。来源绑定等桌面私有能力只能在已验证的桌面传输中执行；公开地址不会扩大账号权限。

## 主要流程

提交材料后查看实际任务状态。Codex 读取本场 JD 与简历，检索来源并交付需求、经历、主题、题目与评分要点。离开页面不会取消后台准备；回来后重新读取任务状态，确认成功再开始练习。

完成后核对页面显示的账号、对象名称和最新状态；若状态仍为进行中或有错误提示，先保留当前内容并查看原因，不能把按钮点击本身视为操作成功。

## 保存与能力边界

资料中展示来源、检索时间、版本和限制。先检查是否引用了真实经历、岗位要求是否匹配；缺失信息保留不确定性，不能把自动归纳当成已核实事实。失败时先看任务原因和已有结果，再决定手动重试。

> [!NOTE]
> 本机应用与公网浏览器访问同一部署时使用相同账号隔离规则。来源绑定等桌面私有能力只能在已验证的桌面传输中执行；公开地址不会扩大账号权限。
