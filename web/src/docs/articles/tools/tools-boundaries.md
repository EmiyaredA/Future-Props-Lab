# 内置工具与外部网站的区别

## 内置能力

录音分段标注的项目属于当前空间；视频帧导出在浏览器本地读取视频与导出图片。两者的数据保存方式不同，不能把浏览器截帧当成已保存项目。

## 外部网站

JSON 格式化、接口调试等条目会打开第三方网站。它们的账号、隐私政策、收费和可用性由第三方负责，研究所不会把站外操作保存为自己的项目。

## 输入前检查

使用外部工具前确认粘贴的文本或文件可以提交给该网站。凭证、完整调用请求和个人数据应先去除。外部页面打不开时可更换网络或直接访问原站，不要把站外故障当作项目数据损坏。
