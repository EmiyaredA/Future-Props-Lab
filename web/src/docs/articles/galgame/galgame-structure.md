# 章节、片段与剧情块

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 内容层级

章节组织故事的大段顺序，Fragment 是可以被调用的剧情节点，Block 描述对白、旁白、舞台、媒体和流程操作。开始创作时先让一条最小线路可运行。

## 编辑顺序

1. 在剧本左侧选择章节和 Fragment。
2. 添加场景、对白或旁白卡片。
3. 在右侧检查器调整所选块的属性。
4. 添加分支或调用目标，再运行验证。

## 稳定引用

入口章不能按普通章节删除或禁用。角色、素材和流程目标被 Block 引用后，应使用界面提供的替换或删除校验。不要手工改 ID 来重排结构。

卡片与演出编辑同一组剧情块；JSON 检查视图用于核对内容，不是另一套剧本。
