# 交接视频剪辑工坊

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 何时需要交接

故事可直接导出视频；需要进一步拼接、多轨剪辑或在剪辑器中调整交付内容时才使用交接。交接与直接导出是两个明确工作流。

## 操作顺序

先完成故事保存和导出检查，在视频交接界面确认路线、范围及目标。检查通过后提交，等待素材准备与项目交接完成，再打开视频剪辑工坊。

## 核对结果

检查交接后的片段顺序、声音和时间范围。目标项目属于当前空间；跨空间 ID 不可使用。交接失败时先处理预检或任务错误，不要连续新建多个目标项目来尝试恢复。
