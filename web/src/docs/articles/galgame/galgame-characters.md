# 角色、外观与声音

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 创建与配置角色

打开资产中的角色页，维护角色名称、主题色、默认显示名、立绘、皮肤和表情。对白可以跟随角色默认配置，也可为单句指定覆盖。

## 表情与口型

支持静态图片、普通序列帧和配音音量驱动的三帧口型。Spine 与 Live2D 当前入口会显示暂未支持，不能把对应素材当成已可运行角色。

## 舞台位置

在角色资产的舞台设置中调整位置、尺寸和锚点，再在对白或登场块选择距离档位及位置预设。脚本预览中的角色不是自由拖拽位置编辑入口。

## 多人对白

一条对白可选择多个说话角色，姓名会并列显示；主角色仍承担本句表情、立绘和配音。预览时检查聚焦与口型，不要仅检查卡片上的名字。
