# 剧情时间轴

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

卡片视图负责写作顺序；演出视图负责精确切点、并行声音和独立舞台动作。

## 从卡片切换到演出 {#open-timeline}

1. 剧本默认打开 Block 卡片视图。对白和旁白可直接编辑正文；对白卡还提供主角色、表情、现有配音、立绘模式和句后保留快捷项。多说话人、上传或生成配音、变换与转场继续在右侧属性中设置。
2. 选中 Block 后按 Tab 可打开上下文插入面板：最左列提供当前卡片的高频快捷设置，其余四列完整列出角色、文本、演出和逻辑 Block；新 Block 会插到当前 Block 前。快捷设置会保持面板打开并自动保存，正文、素材、角色、变量、Fragment 引用和分支结构通过“在右侧属性中编辑”继续处理。空 Fragment 可聚焦空状态后按 Tab，或使用“添加第一个 Block”。对白中按 Enter 新建同角色下一句，Shift+Enter 换行；空白新句再次按 Enter 会删除空 Block，并把焦点送到相邻卡片。
3. 连续且说话人集合相同的对白显示为一组；附着到对白且没有 atMs 的角色事件会随对白组成稳定移动包，场景、声音、逻辑 Block 或独立 atMs 事件会结束分组。
4. 点击“演出”查看统一多轨时间轴。无 timeline 的 Fragment 只在界面中按文本长度估时，切换视图本身不会保存；第一次拖动、精确输入或在播放头新增内容时才物化精确时间轴。
5. 整轨录音应作为 backgroundMusic 素材，通过 BGM 播放 Block 放入时间轴；编辑试听与正式试玩使用同一条声音事件。
6. 左侧固定显示轨道名称，右侧按真实时间展示场景、CG、对白/角色/配音、BGM、环境音、SFX 和结构标记。对白块直接标出说话角色、表情、配音、立绘模式与句后状态；CG 持续区间可整体移动或拖动双端。
7. 没有 atMs 的角色登场或退场会跟随下一句对白，移动对白时一起移动；单独拖动角色事件后才会成为独立演出。工具栏“演出细节”可展开逐角色轨，精确设置仍可逐个隐藏或恢复。
8. 用缩放滑杆调整每分钟像素宽度；点击轨道空白处，或直接拖动红色播放头来跳转时间。

## 卡片重排与轨道编辑 {#direct-editing}

- 无精确时间的卡片按 Block 顺序直接插入、移动和删除，不会因为估算投影而写入时间字段。
- 已有精确时间的对白卡移动时会连同附着角色事件一起移动，并从最早受影响位置波纹重排；每句原时长和句后间隙保留，显式 atMs 的独立演出保持绝对时间。
- 在精确片段中从卡片插入对白，会按估算时长和默认 300ms 间隙打开空间；删除会关闭对应时间空间，同时保留固定事件和结尾留白所需的总长。
- 点击对白、场景、角色、CG 或声音内容项，右侧属性面板会直接显示对应设置。
- 点击无对白区间可以精确调整它的有效边界；这类区间由相邻对白和剧情总长推导，不会新增 Block。
- 分支和章节结局显示为时间轴末尾的独立结构标记，可像其他 Block 一样直接选择。

## 普通裁切与波纹编辑 {#normal-vs-ripple}

| 操作            | 普通模式                                      | 波纹编辑                             |
| --------------- | --------------------------------------------- | ------------------------------------ |
| 拖动对白块      | 移动所选并补偿连续相邻块                      | 所选及全部后续对白整体移动           |
| 拉伸 A 的右边界 | 调整 A/B 的共享切点                           | 改变 A 时长，B 及后续整体移动        |
| 缩短 A          | B 可扩展到新切点                              | B 时长不变并前移，尾部形成空白       |
| 向右拉伸        | 受相邻对白限制；末尾 Block 可自动扩展剧情长度 | 自动增长剧情长度，并保留原有结尾留白 |

> 波纹编辑只影响所选块的右边界和后续对白；开始边界与无对白区间仍按普通边界语义编辑。

## 精确时间工具 {#precision-tools}

- 默认拖动吸附到 100ms；拖动时按住 Alt 可精确到 1ms。
- 边界获得焦点后使用方向键每次移动 100ms，按住 Shift 每次移动 1 秒。
- 右侧属性面板接受 mm:ss.mmm 时间码，并共享当前波纹编辑模式。
- “预听所选”会提前 300ms 播放当前正式 BGM；可开启循环所选反复检查切点。
- 移动播放头后，可直接把它设为所选对白的开始或结束。
- 精确设置允许输入剧情长度；若短于最后一个 Block 会自动保留到该 Block 结束。
- 在播放头位置可以连续添加多个不同角色、声音或舞台事件；右侧检查器可精确修改 atMs。
- 编辑时间轴与正式试玩共用逐句配音、BGM、环境音和 SFX；正式 BGM 会精确跟随播放头。

## 保存校验 {#timeline-validation}

- 起止时间必须非负、开始早于结束，单句至少保留 100ms。
- 对白之间不能重叠，也不能超过剧情时间轴总长；向右编辑会自动扩展该总长。
- timeline 只保存 durationMs；声音素材必须由 audio Block 引用，并与 bgm、ambient 或 sfx 通道角色匹配。
- 同一时刻只允许一次场景切换、一个 CG 事件、同一角色一次调整，以及每个持续声音通道一次播放；多个角色和多个 SFX 可以并行。归约顺序为场景、角色退场、角色登场、CG、声音、对白。
- 所有合法修改仍通过整份 Story CAS 自动保存。
