# 表现与播放器设置

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 调整个性化

进入顶栏“个性化”，设置对话框底图、颜色、字体、舞台聚焦、口型同步和自定义 UI。使用入口章节实时预览，检查正文、姓名与按钮是否可读。

## 故事设置

“设置”维护项目名称、简介、入口章与画布分辨率等。项目名称独立保存；故事相关设置随故事保存，切换前确认状态。

## 验收

在实际试玩中检查背景明暗变化下的文字对比度、长名字、多行对白和多语言排版。编辑器辅助线及取景偏好不应被当成最终导出图像内容。
