# 背景、画面与素材

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 组织场景

在资产中管理背景、场景和 CG。场景使用按渲染顺序排列的图层，可调整距离和偏移；编辑器镜头预览不自动改写剧情中的 Camera 块。

## 使用 CG

通过显示与隐藏 CG 块控制演出。显示新 CG 会替换当前 CG；场景切换和分支跳转不自动关闭它。希望恢复背景与角色时显式插入隐藏操作。

## 构图与资源

全屏 cover 会裁切铺满，contain 保留完整图片并可能留边。叠加模式可调整位置、尺寸和透明度。资源总览帮助检查引用和游离素材，删除前确认剧情引用。
