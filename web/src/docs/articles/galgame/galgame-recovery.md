# 保存与常见问题

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 保存与版本

故事整体保存采用版本检查。冲突时查看服务器快照，保留本地必要内容后决定后续操作；如果界面提供覆盖确认，必须理解它会替换哪个版本。

## 画面与声音异常

角色位置异常先检查角色资产预设，再检查对白覆盖。CG 不消失检查是否缺少隐藏块。BGM 持续播放检查声音停止事件，场景切换不会暗中停止音乐。

## 线路与时间

顺序执行和精确演出使用不同时间表达。时间轴不能保存时检查非法范围、重叠与总时长；线路不通时回到目标 Fragment 与条件变量检查。

完成态再次编辑会恢复草稿，重新通过检查后再交付。
