# 分支、变量与叙事地图

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 建立分支

先创建目标 Fragment，再在分支、条件或调用块中选择目标。变量用于记录选择或条件，命名时区分用途与类型，避免同一变量承担多种状态。

## 理解返回

Branch、If 和 Call Fragment 执行目标后返回调用位置。需要设计结局或章节推进时使用相应流程块，不能把所有目标连接理解为不可返回的跳转。

## 用叙事地图核对

叙事地图由当前故事关系派生，可缩放、平移、高亮相邻链路并定位回剧本。地图用于理解结构，最终仍需[线路检查与试玩](/docs.html?page=galgame-preview-report)确认不可达节点、循环和真实选择结果。
