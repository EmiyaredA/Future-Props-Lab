# 配音与语音识别

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 管理语音

进入资产的语音模块，按角色、旁白和未知分组整理音频。检查试听结果，再绑定对白；不要仅凭文件名判断内容一致。

## 执行识别

选择已启用的语音识别模型和语言，按界面配置并发。先处理未识别语音，再使用手工修正和对白自动匹配。强制重识别会重新请求模型，已有校对内容应先确认。

## 校准配音

对于精确演出，在时间轴检查语音起止与对白时间。BGM、环境音与音效由声音块显式控制，切换场景不会自动替换持续播放的音乐。

识别选项与文件限制取决于模型，参见[语音识别测试](/docs.html?page=test-transcription)。
