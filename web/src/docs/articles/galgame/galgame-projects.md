# 项目与工程概览

<!-- prerequisites -->

面向 Galgame 工坊创作者。先打开当前空间中的故事工程，确认已加载最新保存版本。编辑需要写权限；模型配音或识别还需要对应模型连接。

## 工程入口

从应用进入 Galgame 工坊，新建工程后先打开概览。查看章节、角色、素材、Fragment 和线路相关信息，确认工程处于预期的草稿或完成状态。

## 继续编辑

进入编辑器选择入口章与入口 Fragment，再添加剧情。工程概览用于掌握规模和完整性，不代替逐条对白校对和实际试玩。

## 快照与状态

项目列表支持携带工程的快照操作。导入创建独立副本，模型绑定不可用时按提示重新配置。完成态工程继续修改故事后会恢复草稿，应重新检查线路与交付内容。
