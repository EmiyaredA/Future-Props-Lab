# 保存冲突与恢复

<!-- prerequisites -->

面向遇到操作问题的用户。先保留错误提示、发生时间和当前页面，避免在未确认原因前删除项目或反复提交任务。

## 为什么发生冲突

多个标签页或操作可能同时修改同一项目。版本冲突表示服务器已有更新，系统拒绝静默覆盖，并不意味着你的操作已保存。

## 恢复顺序

1. 暂停连续编辑，记录当前未保存内容。
2. 编辑器有“导出本地 JSON”时先保留本地草稿。
3. 查看或重新加载服务器最新状态。
4. 对照差异，重新应用仍需要的改动并等待保存成功。

## 避免扩大问题

不要反复点击保存，也不要手改数据库的版本号。快照导入会创建副本，不会覆盖原项目。需要协作编辑时协调同一份整体文档的修改时段。
