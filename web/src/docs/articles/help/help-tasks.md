# 任务失败与日志定位

<!-- prerequisites -->

面向遇到操作问题的用户。先保留错误提示、发生时间和当前页面，避免在未确认原因前删除项目或反复提交任务。

## 先确认是哪类任务

区分模型生成、语音识别、素材代理和视频渲染。不同任务使用不同输入与恢复方式；代理失败不一定影响原素材文件。

## 收集最小排障信息

记录工作空间、应用、项目或任务 ID、失败阶段、发生时间和脱敏错误。模型请求可继续查看调用日志；剪辑导出先查看预检结果。

## 重试前

确认素材仍可用、模型配置有效，并等待保存完成。提交阶段中断时不要无判断重复请求；修正原因后通过正式界面显式发起新任务。涉及供应商费用时先核对远端任务是否已经创建。
