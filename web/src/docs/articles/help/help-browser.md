# 上传、下载与浏览器权限

<!-- prerequisites -->

面向遇到操作问题的用户。先保留错误提示、发生时间和当前页面，避免在未确认原因前删除项目或反复提交任务。

## 上传与下载

上传失败先看文件格式、大小和当前用途。下载没有出现时检查浏览器下载列表及阻止提示；文件预览失效时重新打开页面获取当前访问链接。

## 音视频权限

实时语音需要麦克风权限和支持安全上下文的浏览器。开始通话后确认所选麦克风、系统静音和播放设备。被拒绝后从浏览器站点设置重新授权。

## 本地与服务端位置

浏览器下载文件保存在使用者电脑；“打开项目文件夹”在运行服务的主机上打开目录。远程访问部署时，两者可能不是同一台电脑。

[视频帧导出兼容问题](/docs.html?page=frames-help)介绍浏览器解码限制。
