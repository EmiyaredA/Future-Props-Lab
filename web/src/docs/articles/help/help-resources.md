# 找不到功能或资源

<!-- prerequisites -->

面向遇到操作问题的用户。先保留错误提示、发生时间和当前页面，避免在未确认原因前删除项目或反复提交任务。

## 检查顺序

1. 看左下角是否处于正确工作空间。
2. 清除搜索、类型筛选和文件夹限制。
3. 确认当前打开的是模型测试、公共文件管理还是某个工坊项目。
4. 检查身份：公开展台不会显示私有模型和任务，普通成员也不具备所有治理权限。

## 模型不见了

模型可能被禁用，或不具备当前测试模式所需能力。先到模型服务核对供应商与模型条目。

## 链接显示不存在

其他空间的资源按不存在处理；文件也可能已被移除。回到所属项目列表确认。不要通过更换资源 ID 尝试访问无权限空间。
