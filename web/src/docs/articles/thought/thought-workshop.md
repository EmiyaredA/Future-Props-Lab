# 思绪工坊：记录与写作

<!-- prerequisites -->

登录后，从「应用 → 效率协作」进入思绪工坊。笔记在当前 Workspace 内共享；写入需要编辑权限，其他空间看不到这些内容。

## 记录与整理

进入思绪工坊后先看到知识库项目卡片。点击「创建知识库」，填写名称即可开始；没有旧数据的空间不会自动创建空项目。知识库支持搜索、改名、简介、封面及回收站管理。封面可上传公共图片，默认使用暖色图形。

点击卡片进入知识库首页。首页默认阅读，点击「编辑首页」可以编辑整页富文本；首页初始为空，没有演示文字。可写说明、目标、资料索引，也可以使用现有表格、图片和附件能力。封面单独管理。首页不能单独移动或删除。

左侧沿用思绪工坊的头像、返回应用中心卡片、图标导航和底部主题切换。可切换知识库、搜索当前库文档，直接打开首页、全部文档、最近编辑、收藏文档和文档回收站；筛选结果显示在右侧，多级文档目录在左侧独立滚动。切换筛选或搜索前，未保存内容仍会触发离开保护。目录「＋」创建根级文档；每个文档菜单可新建子文档、移动、排序或删除。拖到条目上缘／下缘可同级排序，拖到条目中部可挂为子文档；「移动到」也可选择父文档。键盘用户可通过菜单「上移／下移」排序。删除带子文档的节点时，可选择仅删当前文档（子文档上移）或连同子树一起移入回收站。

「所有知识库」返回卡片列表。最近编辑、收藏和文档回收站只显示当前库内容。文档删除先进入回收站；整库删除会隐藏其全部内容，恢复知识库时保留原目录和已有文档回收站状态。

标题下方以标签胶囊展示分类线索。点击「添加标签」或「编辑标签」，用中文或英文逗号分隔；离开输入框或按 Enter 提交，Esc 取消。Ctrl/Cmd+S 会先提交正在编辑的标签再保存文档。

## 丰富排版

正文使用居中阅读列的块编辑器，平时保持干净的文档外观。将鼠标移到块左侧可使用「＋」插入内容，或拖动手柄调整段落、标题、媒体、表格和单个列表项；从正文左右留白拖动可以连续框选多个块，再复制或删除。空段落输入 `/` 也会打开相同的插入菜单。选中文字后显示排版浮层，支持标题、粗斜体、下划线、删除线、颜色、高亮、字号、链接和清除格式；表格与图片继续使用各自的上下文工具。保存状态、保存和历史记录入口固定在顶部，长文档滚动后仍可访问。

窄屏不会启动留白框选或触摸拖拽。点击当前块右侧的手柄，可通过上移、下移、复制、删除和在下方添加完成等价操作；目录和写作助手仍以抽屉展开，可按 Esc 关闭。

- 「表格」直接插入 3×3 表格。表格内可以增删行列、合并和拆分单元格，拖动列边缘调整宽度。
- 图片支持上传、粘贴和拖入；选中后可拖动手柄或输入宽度缩放，设置左／中／右对齐，编辑替代文字与自由文本图注，并通过自由、原图、1:1、4:3 或 16:9 比例裁剪显示区域（原图文件不变，可随时重置）。
- 公式使用 LaTeX，可选择行内公式或独立公式，点击公式再次编辑。
- 图表保留 Mermaid 源码，可在「编辑图表」中修改。语法错误时仍保留源码。

「附件」支持多文件选择、粘贴与拖入，按顺序上传。支持 PDF、Word（doc/docx）、Excel（xls/xlsx）、PPT（ppt/pptx）、TXT、Markdown、CSV、JSON 和 ZIP。单文件默认上限 200 MiB，以服务端配置为准；ZIP 不自动展开。

附件卡片显示文件名、类型、大小与下载入口，可拖动、删除、撤销和重做。上传状态显示在正文上方；失败时显示原因并可重试。成功后插入原选区随编辑变化的位置；切换笔记后不会把上传结果插入其他笔记。删除卡片只解除引用，文件仍由文件管理清理。不提供在线预览或内容解析。

正文保存为 v2 结构化富文本，旧备份 v1/v2 仅在导入时转换；Markdown 是导入导出的交换格式。

## 保存与冲突

停止输入约一秒后自动保存。顶部显示保存状态，也可以点击「保存」或使用 Ctrl/Cmd+S。中文输入法组合输入完成后才提交正文更新。

其他成员或标签页先保存时，当前页面会保留本地草稿并暂停自动保存。可查看服务器版本、明确采用该版本，或将本地内容另存为副本。站内离开时自动等待保存成功再导航；保存失败会留下草稿并提示原因，可重试保存并离开，或继续编辑。

图片与附件保存在当前空间的公共文件库。只要笔记或历史记录（包括回收站）仍引用文件，文件管理便禁止删除该文件。

## 编辑历史

点击顶部「历史记录」，按日期与时间查看每次成功的内容保存。标题、正文、排版与标签变化会留下记录；收藏、置顶和移动目录不产生正文历史。记录全部保留，永久删除文档时一并删除。

选择记录后仍显示原文档排版，进入只读状态。「显示更改」默认开启，对比所选记录与上一条内容记录：下划线表示新增，删除线表示删除，格式或复杂块变化展示前后内容。点击上一处／下一处可定位修改。关闭显示更改可阅读干净的历史原文。

「还原此记录」经确认后恢复标题、正文和标签，并生成一条新的还原记录；当前内容仍在历史中可找回。原有文档升级后只保留一个历史起点，无法显示升级前未曾记录的修改人或过程。

## AI 写作

打开「AI 写作」，选择当前空间中可用的文本模型，处理整篇笔记或选中的文字。支持摘要、润色、续写、提炼待办和自定义要求。

生成前先保存当前笔记。建议显示在侧栏，点击「追加到笔记」或「替换选区」才会修改正文，并可以撤销。生成期间若正文变化，原选区不再允许替换。可以停止生成或在失败后手动重试。

搜索及 AI 写作只使用附件文件名，不读取或发送附件内容。

没有可用模型时点击「配置模型」；不影响普通笔记记录。调用日志显示来源「思绪工坊写作」，不保存独立聊天历史。

## 导入与导出

卡片列表的「完整备份」导出当前空间全部知识库；库内「更多 → 导出知识库」只导出当前库。v5 备份包含名称、简介、封面、首页、嵌套文档目录、文档、标签、回收站、全部历史与引用文件。导入创建独立副本，重新分配 ID，不覆盖已有内容；兼容 v1–v4 备份。导入历史保留原作者展示名称，不将其关联为当前空间账号。

「导入」支持工坊 ZIP 备份、单个 Markdown 文件和含相对图片及附件的 Markdown ZIP。卡片列表导入 Markdown 会创建新库；库内导入进入当前库。Markdown 内容包上限为 128 MiB；完整备份直接由服务器校验，不在浏览器展开大附件。外部图片不会自动下载，缺失文件会给出提示，网页链接保持原样。

编辑页可以导出：

- **HTML 离线阅读**：保留文字排版、图片、公式和图表，无需登录或联网。有附件时下载 HTML 与附件目录组成的 ZIP；无附件时保持单 HTML 文件。
- **Markdown**：保留常用文本结构；图片与附件随 ZIP 导出，附件以相对文件链接表示，公式保留 LaTeX，图表保留 Mermaid 源码。颜色、字号、对齐等无法完整表达的格式会在导出前提示。

需要无损保留所有编辑格式时，使用完整备份。首版不提供灵感画布、实时共同编辑或 Word 分页排版。

## 旧数据迁移

升级后，每个已有笔记或笔记本的 Workspace 会出现「我的知识库」；原笔记本先成为顶层文件夹，再迁移为空正文文档，子文档通过 parent_id 挂接。原文档 ID、正文、附件、标签、收藏、回收站状态和修订号均保留。收藏的旧笔记链接自动跳到新的知识库地址。知识库只是文档项目名称，不提供 RAG 检索或文件内容解析。
