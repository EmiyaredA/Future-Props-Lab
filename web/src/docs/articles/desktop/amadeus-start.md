# Amadeus：上下文与能力选择

在 macOS 桌面版顶栏点击「Amadeus」。助手使用当前登录账号和 Workspace，调用模型需要模型使用权限，实际业务操作继续受各模块权限限制。

## 选择对话与模型

新建或打开已有对话，在输入区选择当前空间可用的文本模型。需要理解图片或视频参考时，模型还应具备相应输入能力。没有可用模型时先到模型服务配置并测试。

窗口可以置顶，数字人舞台可以收起，主题跟随 App。对话区按发生顺序展示回复、工具卡、提问和审批，展开卡片可查看详细结果。

Amadeus 使用随应用提供的内置红莉栖形象，状态变化映射到对应动作与表情。

## 核对当前上下文

「当前上下文」显示研究所窗口、项目、选中控件及未保存提示，多窗口时标识活动窗口；窗口较多可展开全部。

发送前核对项目和选中项。上下文是定位线索，不能代替实际读取；重要修改应让助手先读取当前版本。助手不会因为窗口列表包含某个项目就获得额外权限。

## 选择能力范围

点击「能力」，在 Skill、工具 API 和 MCP 分类中搜索或按标签筛选，勾选需要的资源后点击「应用更改」。取消或关闭弹窗不提交这次选择。

范围只作用于当前对话。集成中心的启用状态决定资源是否可选，但启用一个 Skill 不会自动把它加入每个对话。出现连接异常或依赖缺失时，先回集成中心检查。

## 参考与文件

添加有权使用的参考文件。视频参考会经取帧等处理进入可用模型上下文；摘要与参考画面不保证覆盖每一秒或全部音轨内容，提问时注明关注的时间段。

会话文件可在助手文件区查看、下载；写入工作文件或运行会话脚本需要相应确认，脚本还要求沙箱可用。不要把会话目录当作项目素材库，交付结果应明确保存或导入目标项目。
