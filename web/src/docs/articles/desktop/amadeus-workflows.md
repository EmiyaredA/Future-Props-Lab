# Agent、Plan 与审批恢复

先在[Amadeus](/docs.html?page=amadeus-start)选择模型并核对上下文。两种模式都可能调用外部模型，Plan 的只读限制不代表不产生模型费用。

## 选择工作模式

| 模式  | 适合用途                           | 操作边界                                               |
| ----- | ---------------------------------- | ------------------------------------------------------ |
| Plan  | 调查当前工程、解释问题、提出方案   | 只暴露读取工具，不执行写入                             |
| Agent | 按目标读取、提出修改并执行获批操作 | 写操作先展示参数摘要审批，继续受业务权限和版本检查限制 |

Plan 完成后可从计划卡片继续执行。执行阶段会重新读取状态和版本，计划本身不是对任意修改的永久授权。

## 回答提问与审批

助手需要信息时会在对话中显示问题卡，选择或填写答案后提交。写操作显示审批卡，先核对项目、参数与影响，再批准或拒绝；调整参数后重新确认摘要。

读取调查可能出现折叠的子任务事件，它们不获得独立写权限。审批某一项不会绕过其他操作的审批，也不会解除只读账号限制。

## 重开后继续

提问和待审批状态会持久保存。关闭窗口后重新打开对应对话，可以处理仍待回应的卡片。回应后由关联的新运行根据已保存消息、事件和结果继续，不重放已完成的旧写入。

执行结果不明时，先查看实际项目状态，不能直接把中断当成未执行。修订卡可帮助检查变更、调整建议或继续；撤销仍受当前项目状态及可用操作限制。

## 停止与故障处理

生成中点击「停止」终止当前流程。出现权限、校验或版本冲突时，阅读工具卡错误并保留项目草稿；先解决冲突再继续。

窗口重开可恢复历史与等待状态，不表示会自动重试所有外部调用。涉及模型提交、外部工具或结果不明的写操作时，先查询现状，确认后再发起新操作。
