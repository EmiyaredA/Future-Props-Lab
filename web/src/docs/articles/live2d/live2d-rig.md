# 图层、变形器与骨骼蒙皮

先在[角色项目](/docs.html?page=live2d-quickstart)导入有权使用的分层素材。绑定需要编辑权限；建议在大幅调整前下载可编辑工程包。

## 检查角色分层

在「模型」页使用对象树搜索和折叠分组。选中部件后核对透明边缘、叠放顺序、父级和位置；使用部件旁的独显按钮检查被其他图层遮挡的内容，再退出独显查看整体。

网格决定部件可以如何形变。网格过粗会让嘴部、发梢等细节难以调整；先确认素材边界与网格，再记录参数关键形。隐藏或独显是检查手段，验收前应恢复预期的可见性。

## 建立变形器和骨架

旋转变形器适合整体转动，曲面变形器适合局部弯曲。创建后通过「父变形器」把相关部件挂到正确父级，逐个试调，检查是否出现重复位移。

也可以使用「建立人形半身骨架」作为起点，再按角色结构检查骨骼位置和父子关系。骨架模板不会代替人工核对：头部、头发、身体及手臂的归属应与实际分层一致。

## 审阅和调整蒙皮

1. 切换到「绑定」，选中部件与目标骨骼。
2. 打开「权重热图」，检查每个顶点受哪些骨骼影响。
3. 使用「权重画笔」调整局部影响范围，留意轮廓和接缝，不要把整个部件无意绑定到错误骨骼。
4. 在骨骼属性中「试调旋转」，分别检查左右极值；试调姿态不会作为正式动画自动保存。
5. 点击「重置试调姿态」，回到原始状态后保存。

## 验收绑定

同时检查默认姿态、最大转动和多个参数组合。重点看穿帮、拉伸、断缝、遮罩和头身连接。发现问题先修部件、网格或权重，再制作动作；否则每段动画都会复现相同问题。
