# Live2D 工坊快速开始

从「应用 → Live2D 工坊」进入角色项目。制作角色需要当前 Workspace 的编辑权限；查看已有角色不要求先配置生成模型。

## 创建第一份角色

1. 点击「新建角色」，填写项目名称并创建项目。
2. 在「模型」页点击「导入素材」，选择分层 PSD 或 PNG。导入前检查图层命名、透明区域和原画尺寸；不支持的 PSD 内容会显示具体原因。
3. 在左侧对象树选择部件，检查顺序、位置和可见性；用「适应窗口」查看完整角色，用「定位选中对象」检查细节。
4. 到「绑定」页制作参数变化，再到「动画」页记录动作。首次制作可以先完成一个微笑参数和一段点头动作。
5. 点击「保存」，等待顶部显示「已保存」。在「交付」页核对保存后的版本，再导出工程包或透明 PNG 序列。

导入多张 PNG 时需自行整理部件位置。PSD 重导入会检查画布尺寸并提示素材替换；确认前先保存工程包，避免误把不同尺寸的原画当成同一角色更新。

## 内置角色与自己的工程

内置 Amadeus 工程供只读查看。点击「创建可编辑副本」后，回到项目列表打开副本再修改。编辑自己的工程不会自动替换桌面助手正在使用的形象；保存后回到项目卡片菜单，点击「设为 Amadeus 形象」才会切换。选择保存在当前账号、Workspace 的本机偏好中；角色缺失或无法加载时恢复内置形象。

角色工程、绑定和动画保存在当前 Workspace。与他人交接可使用 `.fpllive2d` 工程包；仅下载图片序列无法恢复完整绑定。

## 保存和恢复

顶部显示未保存状态；离开编辑器时会检查草稿。发生版本冲突时，本地修改会保留，先「下载本地文档备份」，再决定是否「重新读取服务器版本」。重新读取会放弃当前未保存修改，不能把它当作合并。
