# 参数、动作与状态绑定

角色已有部件和基本绑定后，先制作参数变化，再把参数随时间的变化保存为动作。制作和保存需要当前空间的编辑权限。

## 制作参数关键形

在「绑定」页选中部件或变形器，选择「当前参数」并输入「参数值」。在该值下调整网格或变形器，检查关键形列表是否显示「已记录」。

默认值和两端极值都应有可检查的姿态。拖动参数检查插值，尤其留意多个参数一起变化时的轮廓；修改参数范围后重新检查已有关键形。

## 记录动作和表情

1. 在「动画」页点击「新建动作」，填写名称、帧率和时长。
2. 调整参数预览值，在当前帧点击「记录关键帧」。移动到另一帧，再调整并记录。
3. 选择轨道上的关键帧，按需要使用保持、线性或缓入缓出插值；可以复制或删除关键帧。
4. 播放检查，确认循环起点与终点衔接自然。手动参数预览值会影响看到的姿态，验收动作前可「清除手动预览值」。
5. 需要静态表情时点击「保存为表情」，命名并保存工程。

动作是随时间变化的参数轨道；表情是参数预设。一个看起来正确的表情不代表动画循环已经正确。

## 交换 Cubism 参数数据

「导入动作／表情 JSON」接受对应的 Cubism 参数文件。先阅读参数及范围的转换提示，再确认「导入并保存到工程」。目标角色必须有可映射的参数；动作文件不携带模型网格或完整绑定。

「导出当前动作」与「导出当前表情」用于参数数据交接，完整模型交接见[Cubism 对照与交付](/docs.html?page=live2d-cubism-export)。

## 预览执行状态

展开「Amadeus 执行状态绑定」，分别选择各状态的表情、动作和播放方式，点击该状态的「预览」检查效果。七种状态覆盖待命、思考及执行流程，具体名称以列表为准。

绑定保存在当前角色工程中，供预览和使用该工程的运行入口读取；不会因为保存绑定就替换内置 Amadeus 头像。桌宠另有自己的[事件配置](/docs.html?page=pet-appearance-events)。
