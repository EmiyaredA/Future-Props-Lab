# 选择适合的应用

## 打开应用中心

从 Studio 侧栏点击“应用”。选择卡片后进入对应应用的项目列表，再新建项目或打开已有项目。只有执行生成任务才需要可用模型；整理本地素材与剪辑不要求先配置生成模型。

各工坊拥有自己的项目、编辑器和交付格式；先按最终目标选择，再准备对应素材。录音标注工坊已位于应用中心，视频帧导出仍位于工具导航。

## 选择创作工坊 {#choose-workshop}

完整应用目录覆盖文档、视觉创作、角色、音频和三维预演：

| 目标               | 推荐入口                                                 | 最终结果                         |
| ------------------ | -------------------------------------------------------- | -------------------------------- |
| 编辑幻灯片并放映   | [演示工坊](/docs.html?page=presentation-workshop)        | 可编辑文稿与 PPTX                |
| 记录与组织文档     | [思绪工坊](/docs.html?page=thought-workshop)             | 知识库、富文本、历史与内容备份   |
| 生成或整理视频素材 | 视觉创作工坊                                             | 项目素材、画布节点与生成任务     |
| 编写分支视觉小说   | Galgame 工坊                                             | 可试玩故事、时间轴与线路报告     |
| 组装多轨成片       | 视频剪辑工坊                                             | 时间线、代理预览与 MP4           |
| 切分录音并整理字幕 | 录音标注工坊                                             | 说话人、片段文本与 SRT           |
| 制作二维合成镜头   | [特效制作工坊](/docs.html?page=motion-quickstart)        | 关键帧、路径遮罩与透明镜头       |
| 制作分层动态角色   | [Live2D 工坊](/docs.html?page=live2d-quickstart)         | 原生工程、绑定、动作与 PNG 序列  |
| 制作桌面伙伴       | [桌宠工坊](/docs.html?page=pet-quickstart)               | 角色快照、事件与私人文字聊天     |
| 搭场景与排运镜     | [导演台](/docs.html?page=director-quickstart)            | 三维工程与预演参考               |
| 阅读本机编程会话   | [Agent 工作台](/docs.html?page=agent-workbench-overview) | 原生会话的账号阅读副本与同步状态 |
| 准备面试与文字练习 | [面试助手](/docs.html?page=interview-assistant-overview) | 可追溯资料、题目与练习报告       |
| 验证模型是否可用   | Studio 模型服务                                          | 独立的模型测试记录               |

下一步：[视觉创作快速开始](/docs.html?page=visual-quickstart)、[Galgame 快速开始](/docs.html?page=galgame-quickstart)、[视频剪辑快速开始](/docs.html?page=video-overview)、[录音标注工坊](/docs.html?page=annotation-overview)。

## 复用能力与助手

[创意工坊](/docs.html?page=creative-overview)从 Studio 进入，用于发布和安装工具能力，不是上述创作工程的格式转换器。[Amadeus](/docs.html?page=amadeus-start)从桌面顶栏打开，可读取上下文、先规划并在审批后执行业务操作；它仍遵守当前账号的固定权限。
