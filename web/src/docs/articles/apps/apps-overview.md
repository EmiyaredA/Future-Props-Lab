# 选择适合的应用

## 打开应用中心

从 Studio 侧栏点击“AI应用”。选择卡片后进入对应应用的项目列表，再新建项目或打开已有项目。只有执行生成任务才需要可用模型；整理本地素材与剪辑不要求先配置生成模型。

演示工坊用于创建幻灯片文稿，支持基础编辑、放映和可编辑 PPTX 导出。详见[演示工坊](/docs.html?page=presentation-workshop)。

## 选择创作工坊 {#choose-workshop}

视觉创作工坊适合组织文本、图片、视频和音频素材；Galgame 工坊适合维护可试玩分支故事；视频剪辑工坊适合多轨时间线与确定性成片。

| 目标               | 推荐入口        | 最终结果                     |
| ------------------ | --------------- | ---------------------------- |
| 生成或整理视频素材 | 视觉创作工坊    | 项目素材、画布节点与生成任务 |
| 编写分支视觉小说   | Galgame 工坊    | 可试玩故事、时间轴与线路报告 |
| 组装多轨成片       | 视频剪辑工坊    | 时间线、代理预览与 MP4       |
| 验证模型是否可用   | Studio 模型服务 | 独立的模型测试记录           |

下一步：[视觉创作快速开始](/docs.html?page=visual-quickstart)、[Galgame 快速开始](/docs.html?page=galgame-quickstart)、[视频剪辑快速开始](/docs.html?page=video-overview)。
