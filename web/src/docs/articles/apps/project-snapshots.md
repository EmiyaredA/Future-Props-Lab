# 项目快照导入导出与跨应用交接

## 适用场景与准备

用于备份当前可编辑项目，或创建同类应用的独立副本。先等待项目保存成功，并确认源素材可访问。项目快照不是跨应用格式转换；把 Galgame 交给剪辑工坊应使用专门的交接入口。

## 携带、复制和定位项目 {#project-snapshots}

1. 在视觉创作、Galgame 或视频剪辑的项目卡片上点击“导出项目快照”，下载当前可编辑状态与所需素材的 ZIP。
2. 在项目列表点击“导入快照”并选择 ZIP；校验通过后会创建名为“原名称（副本）”的全新项目并直接打开。
3. 共享素材会转为副本的私有文件；不可用的模型绑定会清空并显示提示，不会丢弃提示词与生成参数。
4. 点击“打开项目文件夹”会在运行 Future Props Lab 的电脑上打开对应目录。

> 快照不保存历史，不覆盖原项目，也不包含助手对话、任务历史、视频代理和派生缓存。打开目录只对有写权限的浏览器 Session 开放。
