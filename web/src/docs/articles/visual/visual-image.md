# 图像生成

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

## 准备节点

在画布创建或选中用于图像创作的节点，打开其生成设置，选择图像模型。没有模型可选时先检查模型服务的能力与启用状态。

## 填写提示与参考

描述主体、环境、构图和输出用途，再按模型支持添加参考图。尺寸、比例和参考数量以所选模型实际选项为准。生成草稿保存在节点中，可离开后继续调整。

## 提交与使用

确认后提交任务。等待结果进入当前项目素材库，再在画布中组织、比较和复用；失败时查看生成任务错误。重复提交可能产生多次外部调用，先确认已有任务状态。
