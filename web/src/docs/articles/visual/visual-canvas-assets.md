# 自由画布与节点连接

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

用节点组织提示词与媒体输入，连接素材和生成结果。

## 画布常用操作 {#canvas-actions}

| 操作       | 入口                       | 说明                                                                                 |
| ---------- | -------------------------- | ------------------------------------------------------------------------------------ |
| 添加节点   | 画布空白处右键             | 支持文本、图片、视频和音频                                                           |
| 移动节点   | 拖动节点卡片               | 只改变画布位置，不修改素材文件                                                       |
| 复制节点   | 选中节点后的复制按钮       | 复制节点配置，素材仍复用同一引用                                                     |
| 替换素材   | 媒体节点上的“替换”         | 从当前项目素材中重新绑定                                                             |
| 导出视频帧 | 选中视频节点后的导出帧按钮 | 暂停后可在弹窗内拖动进度条重新选帧；设置格式后下载图片，同时在右侧创建未连线图片节点 |
| 适应屏幕   | 右下角视图控制             | 把现有节点重新框入可视区域                                                           |

## 节点与素材的关系

文本节点存放提示内容，媒体节点绑定素材；连线用于表达创作输入关系，不是把源文件拼接成一个新文件。生成前先选中目标节点并检查其实际引用。需要更换源图时使用“替换”，不要只修改节点标题。

整理后等待保存完成，再离开画布。保存冲突时参考[保存与故障排查](/docs.html?page=visual-recovery)。
