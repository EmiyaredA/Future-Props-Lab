# 用 Amadeus 操作视觉项目

<!-- prerequisites -->

打开当前账号的视觉项目。修改画布需要项目写权限；手动生成图片或视频需要在节点中选择对应的生成模型。

## 在项目中使用 Amadeus {#assistant}

1. 在画布或看板顶部打开 **Amadeus**。输入区会显示当前项目。
2. 使用输入区的页面元素选择器引用画布节点，或从当前项目选择素材。先确认项目与引用，再发送消息。
3. Amadeus 提出画布修改时，检查待审批操作和参数，确认后执行。若画布版本有冲突，刷新并让 Amadeus 根据当前画布重新提出操作。

旧的项目「对话」已下线，旧历史不再展示。Amadeus 会话及其附件继续在 Amadeus 中查看。
