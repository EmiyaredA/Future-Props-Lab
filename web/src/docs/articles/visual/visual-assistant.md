# 创作助手与操作确认

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

## 开始前

适合希望通过对话理解画布和规划操作的创作者。打开已保存的画布，准备可用文本模型；只有需要生成图片或视频时才另外配置对应生成模型。助手读取当前项目上下文，不能据此访问其他空间的素材。

## 使用创作助手 {#assistant}

1. 在画布右上角打开“对话”，选择文本、图像和视频模型。
2. 让助手总结画布、检查素材或规划下一步；读取操作无需确认。
3. 助手准备修改画布或创建生成任务时，先查看工具步骤和影响范围。
4. 确认后执行；发生 revision 冲突时重新读取画布再继续。
