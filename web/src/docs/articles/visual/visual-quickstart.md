# 视觉创作工坊快速开始

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

用一个项目承载画布、私有素材、生成任务和 Amadeus 项目上下文。

## 创建并进入项目 {#create-project}

1. 从应用打开视觉创作工坊，点击“新建项目”。
2. 在项目卡片中打开画布；需要整理文件时进入“素材”。
3. 在画布空白处右键，添加文本、图片、视频或音频节点。
4. 拖动节点组织空间，使用右下角控制缩放或适应屏幕。

![视觉创作工坊画布，包含文本、图片和视频节点](/docs/visual-canvas.jpg "画布是项目的创作工作区；节点位置、标题、内容和生成草稿都会自动保存。")

## 看懂保存状态 {#save-state}

- “保存中”表示本次修改正在写入项目画布。
- “已保存”表示当前 revision 已落盘。
- “存在冲突”表示另一页面更新过画布，需要选择保留本地或载入服务器版本。
- “保存失败”通常是服务不可用或输入不符合校验规则。

## 完成第一个结果 {#first-result}

1. 添加图片或视频节点并选中它。
2. 在节点检查器切换到“生成”，选择模型并填写提示词。
3. 提交任务后可继续编辑画布，无需停留等待。
4. 在“生成任务”查看进度；完成的媒体会绑定到节点并进入素材库。
