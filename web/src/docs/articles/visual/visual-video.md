# 视频生成

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

根据镜头目标选择纯文本、图生视频、首尾帧或参考素材模式，再由当前模型能力决定可用参数。

## 打开视频生成器 {#open-generator}

1. 在画布空白处右键添加视频节点，或选中已有视频节点。
2. 打开节点检查器的“生成”页签，确认当前类型为视频。
3. 选择可用的视频生成模型；没有模型时先回到模型服务完成配置。
4. 描述镜头主体、动作、运镜、光线和氛围，再选择输入方式。

![视频节点的 AI 生成面板，展示提示词、参数和输入方式](/docs/visual-video-generation.jpg "生成草稿保存在节点中；刷新或离开画布后仍可继续编辑。")

## 四种输入方式 {#input-modes}

| 模式     | 需要的素材                | 适用场景                       |
| -------- | ------------------------- | ------------------------------ |
| 纯文本   | 无需参考素材              | 从描述直接生成新镜头           |
| 图生视频 | 一张起始画面              | 让静态构图产生动作             |
| 首尾帧   | 必选首帧，可选尾帧        | 控制镜头起点和目标画面         |
| 参考素材 | 最多 9 图、3 视频、3 音频 | 综合借鉴角色、运动、节奏或声音 |

## 参数与提交 {#video-options}

在画布视频节点的“全能参考”中，可拖动参考图片调整顺序，也可使用缩略图下方的前移、后移按钮（支持键盘操作）。缩略图角标就是图片引用编号；排序时会同步更新提示词中的 `<Picture N>`，保持每处引用仍指向原素材。通过画布连线引用的图片也可以排序，连线关系保持不变。

顺序与提示词一起保存在节点草稿中，提交生成时沿用该顺序；新连入且尚未排序的素材追加到末尾。若原提示词编号已经与素材错配，需要先校正对应关系再排序。

- 时长、比例和分辨率只显示当前模型支持的取值；切换模型后应重新核对。
- “保留水印”控制供应商输出中的水印选项。
- “生成音频”请求模型同时生成声音，是否生效取决于模型能力。
- 参考音频和视频在提交前会经过临时 HTTPS 托管；链接不会写入任务快照或调用日志。

> 提交前确认提示词和素材引用。任务创建后会固定模型与参数快照，修改节点草稿不会反向改变已提交任务。

## 镜头描述模板 {#prompt-pattern}

可以按“主体与环境 → 动作 → 镜头运动 → 光线与风格 → 节奏与限制”的顺序写提示词。例如：雨夜研究所走廊，调查员快步靠近闪烁的终端，镜头缓慢推进，冷蓝应急灯与浅景深，动作连贯，不改变人物服装。
