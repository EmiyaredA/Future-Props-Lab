# 素材库

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

## 来源、引用与副本 {#asset-sources}

- 项目私有素材：直接上传到当前项目，只在该项目内管理。
- 公共文件：从 Studio 文件管理导入引用，原文件仍由文件管理维护。
- 跨项目素材：从其他视觉项目复制独立副本，来源项目后续整理或删除不会影响当前项目。
- 生成结果：图片或视频任务完成后自动加入当前项目素材库。

> 引用中的公共文件或项目素材不能直接删除；先在画布、提示词引用或任务配置中解除关联。

## 在画布内浏览素材 {#asset-drawer}

点击左侧素材库按钮可以在不离开画布的情况下搜索、筛选、上传和导入项目素材。卡片视图适合看缩略图，列表视图更适合按名称快速定位。完整素材页面仍可从项目列表进入。

素材库按「本项目」「跨项目」「总文件」区分范围。跨项目复制与总文件引用的归属不同，操作前确认当前标签。可从素材库拖入画布创建媒体节点；添加节点和复制节点都不会自动调用生成模型。
