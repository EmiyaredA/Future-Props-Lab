# 导出与素材复用

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

## 选择交付内容

单个生成结果适合下载原素材；项目继续编辑使用项目快照；视频节点需要图片时可使用画布内帧导出能力。输出图片、视频和可编辑项目的入口用途不同。

## 导出前

确认对应任务已经完成，素材预览可用且画布保存成功。不要用尚未完成的占位节点作为最终结果。

## 跨应用复用

在目标工坊通过素材导入入口选择当前空间的源内容。导入副本后在目标项目继续编辑，原项目不会自动同步这些修改。完整项目搬移参见[快照说明](/docs.html?page=project-snapshots)。
