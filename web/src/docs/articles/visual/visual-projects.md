# 项目管理

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

## 建立项目

从应用进入视觉创作工坊，在项目工作台点击“新建项目”。填写项目名称后打开画布；需要管理原始文件时进入项目素材区。

## 整理项目

通过项目卡片重命名、导出项目快照或打开项目文件夹。名称修改不改变项目内容身份。打开文件夹发生在运行服务的主机，而非必然发生在当前浏览器所在电脑。

## 删除与复制

删除前导出需要保留的快照。导入快照会创建副本，不会覆盖同名工程；助手对话与任务历史不在快照恢复范围。详见[项目快照](/docs.html?page=project-snapshots)。
