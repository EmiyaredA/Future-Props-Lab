# 保存冲突与故障排查

<!-- prerequisites -->

面向视觉创作工坊用户。先打开当前空间中的画布项目；编辑需要写权限，涉及生成时还需启用相应能力的模型。

## 保存状态

观察画布的保存中、已保存或保存失败提示。关闭页面前等待保存完成。出现冲突时查看服务器版本，确认差异后再继续编辑。

## 节点与任务不一致

生成任务完成但未绑定预期节点时，检查任务所属项目和目标节点是否仍存在。先去素材库检查结果，再刷新画布；不要直接重新生成来替代查找。

## 助手中断

助手运行及待确认操作不是可跨服务重启恢复的执行队列。中断后检查已完成的工具步骤和项目状态，再明确发起剩余操作。批量写入和外部生成应逐次核对确认内容。
