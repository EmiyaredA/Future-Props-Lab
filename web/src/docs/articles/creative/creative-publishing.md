# 草稿、发布版本与撤回

发布和编辑需要当前空间的内容编辑权限。草稿按 Workspace 与作者隔离，公开版本供同一部署的登录用户浏览。

## 创建和编辑草稿

在「创意工坊」点击「发布创作」，选择能力类型，填写名称、简介、使用说明、标签和封面。按类型补全工具 API、MCP 或 Skill 内容；也可使用页面提供的集成导入入口作为起点。

Skill 上传经过 ZIP 校验。包中应包含说明和所需资源，发布前逐项检查自定义文件，不要携带凭据、账号授权或私有运行数据。

## 预览并发布

保存草稿后进入「预览并发布」，核对展示信息及能力内容，再确认发布。公开版本从允许发布的字段构造，不复制私有凭据；封面和包内容通过服务端校验。

发布版本不可变。需要修改时在「我的创作」编辑新版本，再预览发布；不要期待修改草稿会同步改变他人已安装的副本。

## 撤回与并发冲突

撤回使该公开版本不能被新安装，不会删除其他空间已经安装的副本。撤回被方案引用的能力还会使该方案不能新安装，操作前检查影响。

保存或发布遇到版本冲突时，先保留编辑内容并重新读取条目状态。不要反复提交旧版本；发布、撤回和安装都应检查界面返回结果。

组合能力的方法见[方案包](/docs.html?page=creative-bundles)，使用者安装流程见[发现与安装](/docs.html?page=creative-overview)。
