# 组合可复用的方案包

方案把多项可复用能力与使用建议放在一起。它是能力集合和操作说明，当前不会自动编排执行。

## 选择能力版本

创建创作时选择「方案」，进入能力选择页面，搜索已公开的独立能力，至少选择一项。方案不能嵌套其他方案。

方案固定引用所选发布版本，详情会显示各项能力的名称、作者和版本。原作者发布新版本后，需要你明确更新方案的引用并重新发布。

## 编写建议步骤

说明各项能力的作用、安装后的配置顺序、输入准备与预期结果。明确哪些步骤需要用户自行执行，哪些会访问外部服务；不要把方案说明写成已自动完成的流程。

预览时确认每个依赖仍可用，再发布。无需把被引用的 Skill 或集成内容重新嵌入方案包。

## 安装与依赖撤回

使用者在详情统一预检名称与依赖，再确认安装到当前 Workspace。依赖安装在同一次操作中完成，失败不会留下半套安装记录；各项能力仍需在集成中心配置并启用。

所引版本撤回后，方案可以展示但不能新安装；现有安装副本继续保留。处理时选择可用版本并发布新方案，而不是要求使用者覆盖或删除原有配置。
