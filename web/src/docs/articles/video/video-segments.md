# 片段导出与交接

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 选择交接范围

适合把较长时间线的一部分作为独立素材继续创作。先选择需要的片段并核对时间范围，再打开片段导出入口。交接生成独立结果，不会把剪辑工程的全部可编辑轨道带入视觉画布。

## 导出关联片段 {#segment-export}

- 片段导出用于把选定时间范围生成独立片段，并可交接到新的视觉项目；名称和范围在提交时固定。
- 跨项目交接只使用当前 Workspace 内已验证的目标工程；其他 Workspace 的项目或任务 ID 会按不存在处理。
- 列表会显示各片段准备、渲染、保存和失败状态；取消只影响当前任务，不修改时间线。

## 勾选片段与可选导入

打开“分段导出”后会列出全部视频片段。时间轴已选中视频时默认勾选这些片段，否则默认全选。
可逐项勾选、全选或清空；取消勾选不会丢失名称与输出参数。“应用到勾选片段”只修改已勾选项。

“导入画布项目”默认开启，可选择一个已有画布或新建画布。取消勾选后只导出文件，
无需选择目标项目。提交后配置锁定，任务在后台继续运行，关闭弹窗不会中断。

完成后可逐段下载 MP4，或使用“全部打包下载”获取按片段顺序编号的 ZIP。
关闭弹窗后，可在“渲染任务”列表找到分段任务并继续下载。输出只编码各视频 Clip 的源区间，
不合成字幕、转场或其他轨道叠层。全部成功后才保存整批结果，失败或取消不保留半批输出。
