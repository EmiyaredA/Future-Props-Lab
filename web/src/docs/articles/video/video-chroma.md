# 抠像、素材默认参数与烘焙

使用纯色背景图片或视频，在时间线上叠放到背景画面上方。编辑抠像和生成派生素材需要写权限；原始素材保持不变。

## 调整片段抠像

1. 选中时间线片段，在检查器「抠像」启用效果。
2. 选择绿、蓝或自定义颜色，也可用可用的吸色功能取样背景。
3. 调整相似度、柔化和溢色，观察主体轮廓、发丝与边缘颜色。
4. 切换原画和效果对比，并在多个时间点检查，避免只对一帧调好。

相似度过大会删掉主体近似颜色；柔化和溢色用于改善边缘，不会自动修复所有光照与压缩问题。「重置」恢复参数，不替代重新检查画面。

## 素材默认值与批量处理

素材库可对所选图片／视频设置「默认抠像」，新加入时间线的片段带入参数。它与已有片段的独立参数不同，不会自动重写所有旧片段。

素材监视器用于查看源素材并确定默认效果。时间线多选检查器可明确应用批量片段属性；操作前核对选择范围和提示。

## 烘焙与输出检查

需要把默认抠像变成可复用媒体时，使用素材提供的烘焙操作，等待派生任务完成。烘焙生成新结果，原素材仍保留；失败时先检查原因再手动重试。

浏览器代理用于流畅播放，精确停帧与正式渲染用于核对最终画面。导出前检查透明边缘在浅色和深色背景上的效果，并确认下层轨道、素材和保存版本正确。
