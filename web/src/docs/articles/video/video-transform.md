# 画面变换、叠放与文字

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 编辑画面

选择时间线片段后，在检查器调整位置、缩放、裁切或其他可用表现参数。先确认选中的是目标片段，避免修改同来源的另一段。

## 叠放与文字

画面由可见轨道及片段合成。文字卡与纯色黑幕可独立加入时间线；调整文字长度和持续时间后，在实际项目分辨率检查换行和可读性。

## 核对输出

浏览器代理用于快速预览，精确帧与正式渲染用于核对最终画面。导出当前帧会包含可见轨道、文字、变换和项目背景。辅助控件本身不进入成片。
