# 画面变换、叠放与文字

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 编辑画面

选择时间线片段后，在检查器调整位置、缩放、裁切或其他可用表现参数。先确认选中的是目标片段，避免修改同来源的另一段。

## 叠放与文字

画面由可见轨道及片段合成。在素材区选择“添加文字”，可使用底部字幕、居中标题、普通文字三个预设。
文字从播放头开始，默认持续 3 秒；会复用最上方可用的文字视觉轨，或新建最上层文字轨。
字幕默认 48px 白字黑边、1600px 最大宽度，底部留白 80px；标题默认居中、72px。

创建后在属性区输入多行文字，设置字号、颜色、描边、背景不透明度、对齐和最大宽度。
文字使用内置中文字体，支持中英文混排、手动换行和按字体宽度自动换行。内容与数值编辑失焦后保存；
空白文字不会提交，保存失败时草稿保留在当前片段的编辑面板，可重试。切换片段前请完成保存。

直接拖动预览文字可调整位置，靠近画布中心时出现吸附线；Esc 取消本次拖动。
选中文字移动框后可用方向键微调，Shift 每次移动 10px。属性区也提供快捷位置和文字 X/Y 坐标。
已有位置关键帧的文字会在播放头新增或更新位置关键帧；普通文字更新基础位置。

时间线片段可移动、裁剪、复制、分割和删除；开始时间和时长也可以直接输入。
文字和位置编辑支持撤销、重做。锁定轨道不能修改片段。文字会烧录到导出画面，支持从“添加文字”导入 SRT、VTT 和 ASS 字幕，详见[轨道与片段编辑](/docs.html?page=video-editor-timeline)。语音识别与录音校对可使用独立的录音标注工坊。

抠像操作见[抠像与素材默认参数](/docs.html?page=video-chroma)，片段头尾和片段间效果见[画面与音频转场](/docs.html?page=video-transitions)。

## 核对输出

文字播放预览、精确帧与正式渲染共用后端透明文字图层，字体、换行与样式保持一致。音视频浏览器代理用于快速预览，精确帧与正式渲染用于核对最终画面。导出当前帧会包含可见轨道、文字、变换和项目背景。辅助控件本身不进入成片。

## API 与兼容

时间线仍使用 `schemaVersion: "1.0"`；`text` 片段通过已有 `addClip` / `updateClip` 操作保存。
`textMaxWidth` 现在可更新；可选的 `textStyle` 包含 `align`、`strokeColor`、`strokeWidth`、
`backgroundColor` 和 `backgroundOpacity`。缺少 `textStyle` 的旧快照保留旧排版规则，不回填持久文档，
无需数据库表结构迁移。未指定字体时使用应用固定中文字体。

`GET /v1/video-editor/projects/{project_id}/text-clips/{clip_id}/layer?revision=…` 返回原始画布像素比例的
透明 PNG，包含样式和换行，不包含位置、缩放或时间变换。接口要求内容读取权限，按当前 Workspace
校验项目；版本冲突返回 409，跨空间或非文字片段返回 404。前端加载 URL 包含渲染版本，精确帧磁盘缓存也按渲染版本区分。
