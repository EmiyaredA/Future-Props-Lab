# 预检失败与恢复

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 保留诊断信息

不要立即删除失败任务。先记录工程名称、任务 ID、输出范围和错误阶段，再检查素材状态。只有错误原因已处理后才重新提交；连续点击导出不会修复缺失素材或编码环境。

## 失败恢复顺序 {#failure-recovery}

| 现象             | 先检查                            | 恢复动作                                       |
| ---------------- | --------------------------------- | ---------------------------------------------- |
| 素材或代理失败   | 原文件是否仍在、格式是否受支持    | 重试代理；原文件失效时重新导入并替换引用       |
| 预检版本过期     | 页面是否仍在保存                  | 等待保存完成，重新打开导出并再次预检           |
| 编码器不可用     | FFmpeg/FFprobe 与 H.264、AAC 能力 | 补齐系统编码能力后新建任务                     |
| 任务失败或被取消 | 任务阶段与错误摘要                | 修正原因后显式重建；系统不会静默覆盖或自动重提 |
