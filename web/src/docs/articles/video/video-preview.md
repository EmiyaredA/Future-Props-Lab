# 代理预览、精确帧与截图

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 开始检查

打开包含片段的剪辑工程，把播放头移到需要检查的时间点。快速连续播放用代理预览；确认切点、文字位置或叠放结果时，再检查精确帧。等待项目保存完成后导出截图，避免请求旧版本画面。

## 代理预览与精确帧的边界 {#exact-preview}

在节目监视器点击“导出当前帧”会暂停并锁定当前 revision，打开图片设置弹窗；可以在弹窗内拖动进度条重新选择时间点，不会改变主时间线播放头。导出的最终合成画面包含全部可见轨道、文字、变换和项目背景；图片会下载到本机并加入当前剪辑素材区，但不会自动插入时间线。

| 能力           | 适用场景                   | 结果                                   |
| -------------- | -------------------------- | -------------------------------------- |
| 浏览器代理预览 | 快速播放、拖动和粗剪       | 优先流畅，不作为成片验收真源           |
| 后端精确帧     | 检查切点、文字、缩放和叠放 | 按当前 revision 和时间点确定性输出 PNG |
| 完整渲染       | 交付成片                   | 固定快照、固定帧网格和音频 PTS 的 MP4  |

> 精确帧提示版本过期时，先等待保存完成并重新请求；不要用旧 revision 的图片判断当前时间线。
