# 视频剪辑工坊快速开始

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 准备工程

从应用进入视频剪辑工坊，点击“新建剪辑”。准备有使用权的视频、图片或音频；没有原素材时不能仅依靠代理文件交付。

## 第一条成片

1. 导入素材并等待代理准备。
2. 将素材加入兼容轨道。
3. 通过移动、裁切与分割组织片段。
4. 播放预览，在切点使用精确帧核对。
5. 打开“导出视频”，先预检再提交完整渲染。
6. 完成后从任务记录下载 MP4。
