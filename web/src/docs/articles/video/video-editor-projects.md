# 项目与快照

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

创建剪辑工程，导出可编辑快照，或导入独立副本。

## 开始前

从“AI应用”打开“视频剪辑工坊”。准备本地图片、音频或视频即可开始剪辑；不要把模型生成凭证当作创建剪辑工程的必需条件。远程访问时，打开项目目录指的是部署机器的目录，而非浏览器电脑。

## 创建、携带与恢复工程 {#project-lifecycle}

1. 从 AI 应用进入视频剪辑工坊，点击“新建剪辑”后直接打开时间线。
2. 项目卡片支持重命名、删除、打开运行主机上的项目目录，以及导出版本 1 的项目快照 ZIP。
3. 导入快照会先验证结构和素材，再创建独立副本；不会覆盖现有工程或沿用原工程 ID。
4. 快照包含可编辑时间线和所需原素材，不包含代理、波形、缩略图、任务历史或已经生成的成片。
