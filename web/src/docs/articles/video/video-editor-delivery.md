# 完整渲染与任务管理

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

完成输出预检后提交后台渲染，并从任务记录下载成片。

## 导出前确认

先试听并检查画面，再等待所有编辑保存成功。确定输出范围没有意外的空白，且需要参与输出的轨道没有被隐藏或静音。精确帧检查方法见[预览与截图](/docs.html?page=video-preview)。

![真实时间线导出预检通过](/docs/video-render-preflight.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 预检并开始完整渲染 {#render-preflight}

1. 点击“导出视频”，选择 720p30、1080p30 或 1080p60 预设，并确认起止范围。
2. 先运行预检，处理缺失原素材、非法范围、版本过期、磁盘空间或编码能力问题。
3. 预检通过后提交确定性渲染。任务从数据库记录恢复 Workspace 和冻结快照，离开页面不会改变租户归属。
4. 完成后从任务记录下载 MP4；取消中的任务会在安全边界停止，提交阶段中断不会自动重复提交。
