# 素材导入、整理与代理

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 整理素材

在剪辑编辑器左侧“素材”区点击“上传”选择本地文件，或通过“导入快照”复制其他应用素材。点击“新建素材文件夹”建立分类后拖入素材；删除文件夹会把其中素材移到未分类，不会删除源素材。

## 导入素材并确认代理状态 {#assets-and-proxies}

- 可以上传本地素材，也可以从当前 Workspace 的文件管理、视觉项目或 Galgame 项目导入独立副本。
- 图片、视频和音频会保留原素材；缩略图、视频代理、波形等仅是可重建的派生缓存。
- 素材卡显示类型和代理状态。代理失败时可重试；删除前必须先移除所有时间线引用。
- 正式精确预览、片段导出和完整渲染读取原素材与不可变时间线快照，不以浏览器录屏或代理文件作为最终真源。
