# 片段变速

<!-- prerequisites -->

面向视频剪辑工坊用户。先打开当前空间的剪辑工程；编辑需要写权限，预览或导出前应等待素材解析与项目保存完成。

## 调整速度

选中视频或音频片段，在检查器找到“播放速度”。输入 0.25～4 的速度倍率，点击“应用”或按 Enter。1× 为正常速度，2× 加速，0.5× 减速。

![选中视频片段后的速度倍率面板](/docs/video-editor-timeline.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 关联音频

同一关联组的音频会同步变速。变速会改变片段占用时间，保存后检查相邻片段、总时长与声音同步，不能只看预览播放速度。

## 恢复与错误

可把倍率重新设置为 1，或使用编辑器撤销操作恢复。非法倍率会显示“请输入 0.25～4 之间的速度”；保存失败时处理提示后重试。

正式导出前重新预检，确认冻结快照已包含最新速度。
