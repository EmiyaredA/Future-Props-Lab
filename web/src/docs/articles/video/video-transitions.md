# 画面与音频转场

打开剪辑工程，在转场面板选择效果与放置位置。编辑需要写权限；应用前先检查片段、锁定轨道和已保存版本。

## 选择效果与位置

画面效果包括交叉淡化、黑场过渡、白场过渡、擦除、镜头缩放、径向模糊、闪白与闭眼睁眼。效果与位置分开选择：可以应用到片段头、片段尾或符合条件的两个片段之间。

擦除方向表示空间方向；黑白场是完整画布颜色过渡，闪白是切点附近短脉冲。闭眼睁眼通过上下眼睑合拢、切换后睁开，可先在预览中检查节奏。

片段头尾效果属于该片段；片段间效果作为独立接缝显示。移动或裁切后重新检查接缝关系，不要把两个模型的时长当成同一个设置。

## 音频接缝效果

| 效果           | 试听重点                           |
| -------------- | ---------------------------------- |
| 交叉淡化       | 前后声音按线性增益交接             |
| 等功率交叉淡化 | 接点附近的听感响度是否更连贯       |
| 淡出再淡入     | 中间降到静音形成停顿               |
| 频率扫掠       | 淡化时前段收窄、后段展开的频率变化 |

1. 选择同一独立音频轨中相邻的两个片段，先把头尾对齐或形成重叠，再打开音频转场。有间隙时先移动片段；转场时长必须短于两段各自的时长。
2. 先暂存效果、时长与缓动，预听后再点击「应用到片段之间」。
3. 应用会把后一片段及同轨后续片段、相关关联组移到对应重叠位置；胶囊时长反映真实重叠。
4. 检查声音和后续画面位置，必要时撤销整次操作。

与画面关联的 A/B 音频需先分离。混合轨视频自带声音不直接提供独立音频接缝；锁轨、负时间或非法重叠会拒绝整批修改，不应拆成多个提交绕过检查。

## 裁切、删除与验收

音频接缝随实际重叠更新；重叠消失或片段关系失效时接缝会移除。片段头尾仍使用原有音频淡化，不承担四种接缝效果。

删除转场胶囊只移除接缝效果，不会自动恢复片段位置或解除重叠。需要还原本次应用造成的移动时使用「撤销」，它会一起恢复后一片段、同轨后续片段及被连带移动的关联片段。

预听不保存时间线。应用后用项目播放和最终渲染核对切点前后，尤其检查连续画面转场、后续片段跟随、音乐响度与静音间隙。查找音乐切点见[相似音频接点](/docs.html?page=video-audio)。
