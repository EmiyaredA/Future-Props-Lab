# 特效制作工坊快速开始

从「应用 → 特效制作工坊」进入项目。它适合二维合成、路径遮罩与透明镜头；创建和修改需要当前空间的编辑权限，不要求先配置模型。

## 制作第一段镜头

1. 点击「新建项目」，填写名称、选择画幅和帧率，选「空白项目」或「特效模板」，再「创建并打开项目」。进入编辑器后核对预览顶栏的尺寸与时间轴总时长。
2. 在素材区导入媒体，或从「快速添加」加入图形和文字。原创特效模板可作为起点。
3. 选择图层，在检查器调整位置、缩放、旋转和透明度。
4. 移动播放头，为需要变化的属性添加关键帧，再播放检查。
5. 等待「已自动保存」，点击「导出镜头」，选择输出格式及起止帧，再「开始导出」。

## 图层与时间

图层先后影响叠放结果，每层有自己的开始帧和持续时间。动画关键帧相对于图层开始帧记录；移动图层后，动画随图层一起移动。

合成工程负责镜头内部的效果与动画，成片的声音和多镜头排列在视频剪辑工坊完成。特效工坊当前不编辑声音，导出为无声镜头。

## 保存与交付

修改后观察自动保存状态，也可手动保存。冲突时保留当前草稿、核对服务器版本，避免反复覆盖。工程包用于继续编辑，MP4、MOV 与 PNG 序列用于交付画面。
