# 透明导出与剪辑交接

导出与交接需要写权限。先保存工程并核对输出范围，任务会使用提交时的固定文档快照；继续编辑不会改变已提交任务。

## 选择格式

| 格式     | 适合用途           | 透明与声音                   |
| -------- | ------------------ | ---------------------------- |
| MP4      | 常规播放或成片剪辑 | 透明区域合成到画布底色，无声 |
| MOV      | 透明镜头叠放       | 保留 Alpha，无声             |
| PNG 序列 | 逐帧交付或检查     | 保留 Alpha，无声             |

透明导出仍会渲染工程里的背景图层。需要真正透明的区域，应检查是否存在覆盖整个画布的图形或媒体层。

## 提交并下载

尺寸和帧率沿用工程设置。点击「导出镜头」，可同时选择一种或多种格式，设置起始帧和结束帧，再「开始导出」。结束帧不包含在输出范围内。在「最近导出」检查排队、运行、完成或失败状态，完成后下载结果。

验收时查看透明边缘、遮罩、起止帧和输出持续时间。任务失败先查看原因并修正素材或范围，再手动提交；已有运行任务可以按界面操作取消。

## 交给视频剪辑工坊

在已完成任务点击「发送普通镜头」或「发送透明镜头」，选择当前 Workspace 的已有剪辑工程，或填写名称新建剪辑工程，再「发送到剪辑」。应用复制镜头媒体到目标工程，并追加新的画面轨道；PNG 序列不能直接使用这个交接入口。

透明 MOV 的剪辑预览使用保留 Alpha 的代理。到剪辑工程核对图层叠放和透明度，再添加声音并完成成片。来源特效工程后续修改不会自动替换已交接镜头，需要重新导出并明确交接。
