# 图层、关键帧与路径遮罩

先打开特效项目并确认画布帧率。修改需要写权限；选择某个图层后，检查器调整的是该层，不是原始媒体。

## 设置图层范围和外观

给图层命名，核对开始帧、持续时间与叠放顺序。媒体层调整素材取样与显示尺寸，文字或图形层编辑内容和样式。修改大小时注意画布边缘与遮罩范围。

在图层切入和切出时刻检查实际画面。延长图层时先检查工程总帧数，图层范围不能超过工程时长。

## 添加属性关键帧

移动到目标帧，在「变换与关键帧」修改属性并使用旁边的关键帧按钮记录。再到另一帧改变数值，播放确认中间变化；需要静态属性时先确认没有遗留动画轨道。

关键帧属于图层局部时间。移动图层不会把它们变成工程绝对时间；裁短图层后，要重新检查末尾动画是否还处于有效范围。

## 制作路径遮罩

在「路径遮罩」中启用遮罩，编辑控制点与贝塞尔手柄，检查路径闭合、边缘和反向裁切。需要动画时在对应帧记录路径关键帧。

遮罩影响选中图层，不会修改原素材。复杂轮廓先做静态检查，再逐步添加路径动画；播放中留意控制点顺序变化造成的翻转或跳动。

## 预览与验收

浏览器画布用于交互，精确帧用于核对保存版本的实际像素。检查关键帧两侧、遮罩边缘及不同叠放顺序，最终再核对导出的相同时间点。
