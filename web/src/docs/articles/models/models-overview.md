# 模型服务概览

<!-- prerequisites -->

面向配置模型连接的用户。开始前确认目标工作空间及写权限，并准备供应商提供的服务地址、协议类型和模型标识；密钥仅填入认证字段。

## 工作方式

模型服务是所有模型连接的配置入口。供应商保存协议类型、服务地址与认证；模型条目保存供应商侧标识、显示名称、能力和启用状态。选择模型时，模型测试与应用会按能力过滤可用条目。

## 接入流程

1. 添加或选择供应商。
2. 为供应商添加模型，核对模型标识。
3. 选择模型具备的能力并启用。
4. 执行连接诊断，再进入相应模式进行实际测试。

供应商认证成功不代表所有模型和全部能力均可用。[连接测试](/docs.html?page=models-diagnostics)介绍排查顺序。
