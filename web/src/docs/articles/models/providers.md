# 协议类型与认证配置

<!-- prerequisites -->

面向配置模型连接的用户。开始前确认目标工作空间及写权限，并准备上游服务提供的服务地址、接入协议和模型标识；密钥仅填入认证字段。

## 协议类型与接入连接

进入“模型服务 → 接入管理”。左侧按“协议类型 → 接入连接”组织目录；协议类型把接入方式一致的连接归在一起，可以在其下配置图片、视频、语音等多个独立连接。

点击“添加协议类型”填写名称，或在“添加连接”窗口中新建协议类型。连接分别填写名称、所属协议类型、接入协议、服务地址和 API Key。OpenAI 兼容是接入协议，不表示服务由 OpenAI 提供。历史连接初始放在“未归类”；可用“按接入协议整理”按 `kind` 展示名自动建组并归类，也可编辑连接明确归属。

## 编辑连接配置

选择连接，右侧默认显示“已接入模型”；进入“连接配置”管理地址、密钥和启停。API Key 留空保留现有凭证；只有需要更换时才输入新值。目录版本可在高级信息查看。

平台模板管理的字段在工作区只读，可以调整允许的启停状态。“复制为自建连接”只复制连接配置，不复制密钥或模型；创建后另行添加或复制模型。

## 删除与错误处理

仅空协议类型分组可以删除；先将连接移至其他协议类型或“未归类”。删除连接会删除其下模型，确认前检查引用。认证失败检查凭证及地址；版本冲突时界面保留草稿并载入最新目录，核对后再保存，不自动覆盖。不要把密钥放进名称、说明或文档截图。
