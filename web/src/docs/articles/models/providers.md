# 供应商与认证配置

<!-- prerequisites -->

面向配置模型连接的用户。开始前确认目标工作空间及写权限，并准备供应商提供的服务地址、协议类型和模型标识；密钥仅填入认证字段。

## 添加供应商

进入“模型服务”，点击“添加供应商”。填写名称、供应商类型、服务地址与 API Key。服务地址必须匹配所选协议，不能只因为服务支持 HTTP 就选择 OpenAI 兼容类型。

![添加供应商与认证配置](/docs/provider-form.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 编辑已有供应商

选择供应商并打开编辑。API Key 输入框显示“留空不修改”时，留空会保留现有凭证；需要更换才输入新值。保存后重新验证依赖该供应商的模型。

## 删除与错误处理

删除前检查其下模型和应用绑定，阅读确认框说明。认证失败检查凭证及地址；配置发生版本冲突时使用最新目录重新编辑。不要把密钥放进供应商名称、说明或文档截图。
