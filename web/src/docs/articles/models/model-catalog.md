# 模型目录、能力与启停

<!-- prerequisites -->

面向配置模型连接的用户。开始前确认目标工作空间及写权限，并准备供应商提供的服务地址、协议类型和模型标识；密钥仅填入认证字段。

## 添加模型

“模型服务”默认打开模型目录。按全部、对话、图片、视频或音频筛选，再用模型名称/标识、供应商和能力缩小范围。同名模型来自不同连接时分别展示来源。

点击“添加模型”后选择接入连接，输入服务实际接受的模型标识。也可从“接入管理”的连接详情中添加，自动预选当前连接。显示名称和说明不替代模型标识；没有可编辑连接时先创建连接。

## 声明能力

按实际服务选择支持的能力。文本模型不自动具备图像生成、视频生成、语音识别或实时语音能力。声明错误会导致条目出现在不适用的测试入口中，但无法使远端服务凭空支持该操作。
用途可多选；图片理解是对话模型的能力，不会因此进入图片生成分类。

当前图片与视频测试入口分别需要 SenseAudio 图片、SenseAudio 视频类型的供应商，仅给 OpenAI 兼容条目勾选图像或视频能力不会启用这两个测试模式。语音识别支持 OpenAI 兼容与 SenseAudio 语音识别类型；实时语音还需要匹配的实时协议服务。

## 启用与验证

保存并启用后，点击模型行的“去测试”进入对应模式。对话模型会新建独立测试会话，原会话保持不变；尚无测试界面的能力显示“暂不支持测试”。连接或模型停用时不能发起测试，两种停用状态分别显示。禁用不会自动取消已提交的后台任务。

平台模板管理的条目带来源标记，受管理字段在工作区只读；允许调整启停状态。操作菜单可以复制模型到自建连接。只读成员使用相同目录和筛选，写操作按有效权限隐藏。

## 默认模型用途

点击页面右上方「默认模型用途」，为对话、图片、视频、实时语音、语音识别和音频生成选择默认模型。只有连接与模型都启用、且支持对应用途的模型可选。保存后用于新建测试；已有会话和手动选择保持不变。只读成员可以查看当前默认选择。

若保存时目录发生变化，输入会保留。点击「刷新核对」读取最新目录，再核对后保存。
