# 连接测试与常见错误

<!-- prerequisites -->

面向配置模型连接的用户。开始前确认目标工作空间及写权限，并准备供应商提供的服务地址、协议类型和模型标识；密钥仅填入认证字段。

## 诊断顺序

先检查供应商服务地址和认证，再检查模型标识与能力。使用模型服务提供的诊断入口查看结果；之后在模型测试中验证具体输入和输出。

| 现象             | 优先检查                               |
| ---------------- | -------------------------------------- |
| 认证失败         | 密钥是否属于当前供应商、是否失效       |
| 模型不存在       | 供应商模型标识是否正确、账号是否有权限 |
| 请求超时         | 运行主机网络、服务状态与输入规模       |
| 参数不支持       | 当前模型能力、所选模式及生成参数       |
| 模型未出现在列表 | 是否启用、是否在同一空间               |

## 提交问题

记录模型标识、测试模式、失败时间、日志 ID 和脱敏错误。快速诊断有独立调用来源，可在[调用日志](/docs.html?page=logs-overview)中筛选。网络诊断可能产生外部请求。
