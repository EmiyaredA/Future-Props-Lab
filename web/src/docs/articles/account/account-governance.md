# 平台管理员账号治理

<!-- prerequisites -->

面向登录用户。开始前确认当前账号和工作空间；成员管理与空间设置需要所有者或平台管理员权限，账号治理仅限平台管理员。

创建普通账号、管理状态和重置密码。

## 进入账号治理

只有平台管理员会在账号面板看到“账号治理”。普通空间所有者通过成员邀请管理自己的空间，不能因此创建平台账号。

## 创建账号

在“创建普通账号”表单填写界面要求的资料并提交。成功后安全转交用户名和临时密码；临时密码仅显示一次。用户首次使用按登录流程修改密码。

## 维护已有账号

在账号列表核对用户名后执行禁用、恢复或重置密码。密码重置影响登录凭证，不是新建项目或清空用户作品。系统会保护最后一个活动平台管理员，避免平台失去管理入口。

## 离线恢复

平台无法登录时，部署人员可使用正式账号恢复入口，详见[部署与恢复](/docs.html?page=dev-production-deployment)。不要直接编辑数据库或伪造会话。
