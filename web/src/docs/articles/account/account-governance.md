# 平台管理员账号治理

## 创建与维护账号

从头像菜单打开「管理中台 → 账号管理」。创建时核对用户名和显示名称，选择管理员或普通用户。系统在同一事务创建账号与模型目录；新账号首次登录须修改临时密码，不创建工作空间。

创建或重置成功后，临时密码只显示一次。核对账号后可禁用、恢复、重置密码或修改平台角色；敏感操作要求近期密码验证和最新 revision。身份或密码变化会撤销旧会话和密钥，遇到冲突应重新读取，不能静默覆盖。

## 平台边界

不能禁用或降级自己，不能移除最后一个启用管理员。账号治理不授予其他账号的私人资源读取权；删除或复制底层数据库记录不是账号恢复方式。可在管理中台核对平台资源分配与运行额度，通过正式账号用例完成恢复。

旧工作区管理、成员与空间权限入口已经移除。需要分享知识时使用文章发布与逐篇授权，普通项目和凭证继续按账号隔离。
