# 密码与会话管理

<!-- prerequisites -->

面向当前登录账号。个人资料和凭据归本人管理，平台账号治理仅限管理员；任何角色都不授予其他账号的私人资源读取权。

修改密码，撤销其他设备，并检查本人安全事件。

## 修改密码

从右上角账号菜单进入“账号设置 → 密码与会话”，填写当前密码、新密码以及再次输入的新密码，点击“修改密码”。忘记当前密码时请管理员重置，而不是尝试修改浏览器内登录状态。

![密码和活动会话](/docs/account-security.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 管理设备

“活动会话”标明当前设备、最近活动时间和其他设备。对单个其他会话点击“撤销”，或点击“撤销其他设备”集中处理。当前设备需要结束使用时，从右上角账号菜单点击“退出登录”。

## 安全事件

账号设置中“安全记录”下的“本人安全事件”显示近期事件类型、结果、来源和时间。发现未知设备时先撤销会话并修改密码，再核对是否还有不需要的管理密钥。

更多管理接口见[API 参考](/docs.html?page=api-reference)。
