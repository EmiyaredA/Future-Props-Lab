# 账号创建与注册邀请

## 创建账号

部署只保留管理员和普通用户两种平台角色，没有空间成员、Owner 或可调整的成员权限矩阵。管理员从「管理中台 → 账号管理」创建账号，普通用户不能创建或治理他人账号。

创建或重置密码后，临时密码只显示一次，首次登录必须修改。通过可信渠道交付临时密码，不能将它放进项目正文或聊天记录。管理员不能因此读取新账号的私人资料。

## 注册邀请与权限

注册邀请码由平台治理维护。具备有效邀请码时从支持注册的入口创建账号；邀请码不授予其他账号的私人资源，也不把使用者加入任何空间。公网浏览器入口关闭邀请码注册，桌面或既有受控注册入口按部署规则处理。

需要共享知识文章时使用思绪工坊的逐篇发布和授权。账号禁用、角色变更与凭据撤销后重新登录核对状态，不能继续依赖旧会话或旧密钥。
