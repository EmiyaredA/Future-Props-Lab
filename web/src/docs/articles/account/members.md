# 成员与邀请

<!-- prerequisites -->

面向登录用户。开始前确认当前账号和工作空间；成员管理与空间设置需要拥有者、工作区管理员或平台管理员权限，账号治理仅限平台管理员。

通过用户名邀请平台中已有账号加入空间。

## 发送邀请

前提是对当前空间有成员管理权限。在空间面板打开“成员与邀请”。

1. 在“邀请已有账号”中填写对方的**用户名**，不是邮箱或显示名称。
2. 点击“发送邀请”。
3. 在待处理邀请中查看状态与到期时间；不再需要的邀请可撤销。
4. 对方在自己的空间面板“待处理邀请”中点击“接受”或“拒绝”。

## 移除成员

“成员”列表为普通成员提供“移除”操作。移除后对方失去该成员关系带来的访问权限；该操作不是删除账号，也不是删除空间内项目。所有者不能通过普通成员移除按钮删除。

## 常见问题

对方尚无账号时，先由平台管理员创建账号。邀请过期或已被处理时重新核对状态，不要将已失效的邀请当作有效成员关系。
