# 空间信息与公开展台

<!-- prerequisites -->

面向登录用户。开始前确认当前账号和工作空间；成员管理与空间设置需要拥有者、工作区管理员或平台管理员权限，账号治理仅限平台管理员。

设置空间名称，并了解公开作品的可见范围。

## 修改空间信息

空间拥有者、工作区管理员或平台管理员在空间面板中找到“空间设置”。修改“空间名称”后点击“保存更改”。

## 开启或关闭公开展台

1. 确认准备展示的项目和素材适合对其他登录用户展示。
2. 在访问范围中选择“公开：展示允许公开的内容”，点击“保存更改”。
3. 用其他账号的只读视角检查展示结果。
4. 需要停止展示时返回空间设置，选择“私有：仅成员和平台管理员”，点击“保存更改”。

## 展示范围

公开展台是登录可见的作品展示，主要提供视觉作品与互动故事。它不公开模型、提示词、生成任务或调用日志，也不允许访客编辑。

> “公开”不等于匿名公开互联网链接。访问范围以平台当前登录和空间访问规则为准。
