# 私人资源与知识社区

## 资源可见性

普通项目、素材、模型凭证和会话归当前账号私有。旧的空间公开展台不再提供访问入口；知道账号名称或资源 ID 也不会得到读取权限。管理员角色不会自动扩展私人资源范围。

## 显式分享知识文章

思绪工坊通过知识社区发布文章，发布与逐篇阅读/编辑授权由文章入口维护。接收者需要登录同一部署，并且满足该文章当前的可见范围和角色。允许阅读一篇文章不会开放源账号的其他目录、历史、文件库或私人会话。

发布前核对正文、封面和被引用的素材；撤回或回收站操作会收回发布范围，恢复笔记不会自动重新发布。分享工程时仍应使用相应应用支持的导出格式。
