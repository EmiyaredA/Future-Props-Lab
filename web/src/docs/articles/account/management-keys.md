# 管理 API Key

<!-- prerequisites -->

面向登录用户。开始前确认当前账号和工作空间；成员管理与空间设置需要拥有者、工作区管理员或平台管理员权限，账号治理仅限平台管理员。

为自动化访问创建绑定当前空间的密钥。

## 创建密钥

从右上角账号菜单进入“账号设置 → API 密钥”。

1. 填写能说明用途的“密钥名称”。
2. 只在确实需要时勾选“允许写入当前工作区”。
3. 选择 30、90、180 或 365 天有效期，点击“创建密钥”。
4. 立即点击“复制密钥”，保存到受控的凭证存储。

## 使用范围

密钥绑定创建时的工作空间，之后切换浏览器空间不会改变该密钥归属。只读密钥不能用于写请求；密钥也不会绕过服务端权限校验。

## 续期、撤销与删除

列表展示前缀、权限、创建时间、到期时间和状态。有效密钥从原到期时间继续延长，已过期密钥从续期时刻重新计算；续期不会更换密钥明文。已撤销密钥不能续期。

密钥泄露或暂时不再使用时点击“撤销”，记录仍会留在列表；需要彻底清理列表时点击“删除”。删除会立即让密钥失效且无法恢复，但安全记录仍会保留操作历史。密钥明文仅显示一次，遗失后应创建新密钥并撤销或删除旧密钥。

> 不要把 Management API Key 填到模型供应商的 API Key 字段。
