# 管理 API Key

<!-- prerequisites -->

面向当前登录账号。个人资料和凭据归本人管理，平台账号治理仅限管理员；任何角色都不授予其他账号的私人资源读取权。

为自动化访问创建绑定当前账号的密钥。

## 创建密钥

从右上角账号菜单进入“账号设置 → API 密钥”。

1. 填写能说明用途的“密钥名称”。
2. 只在确实需要时勾选“允许写入当前账号”。
3. 选择 30、90、180 或 365 天有效期，点击“创建密钥”。
4. 点击“复制密钥”，保存到受控的凭证存储。

## 再次复制密钥

在有效密钥的对应行点击“查看并复制”，打开弹窗后点击“复制密钥”。距上次密码验证超过 10 分钟时，弹窗会先要求验证账号密码。列表中标有“旧密钥不可找回”的密钥只保存了哈希，仍可按原权限和有效期使用。需要以后复制时，可以创建新密钥并更新客户端配置。

## 使用范围

密钥绑定签发账号。只读密钥不能用于写请求，所有请求仍须通过服务端权限校验。

## 续期、撤销与删除

列表展示前缀、权限、创建时间、到期时间和状态。有效密钥从原到期时间继续延长，已过期密钥从续期时刻重新计算；续期不会更换密钥明文。已撤销密钥不能续期。

密钥泄露或暂时不再使用时点击“撤销”，记录仍会留在列表。需要清理列表时点击“删除”。撤销或删除会让密钥立即失效，安全记录仍会保留操作历史。

> 不要把 Management API Key 填到模型供应商的 API Key 字段。
