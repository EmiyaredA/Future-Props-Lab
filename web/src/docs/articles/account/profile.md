# 个人资料

<!-- prerequisites -->

面向当前登录账号。个人资料和凭据归本人管理，平台账号治理仅限管理员；任何角色都不授予其他账号的私人资源读取权。

更新显示名称、邮箱和头像。

## 修改资料

1. 从右上角账号菜单打开“账号设置”，选择“个人资料”。
2. 修改“显示名称”和“邮箱”。
3. 点击“保存资料”，确认成功提示。

用户名字段只读。显示名称用于界面展示，修改它不会更改用于登录的用户名。

![个人资料设置](/docs/account-profile.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 头像

点击“上传头像”选择 PNG、JPEG 或 WebP 图片；已有头像时可以“删除头像”。上传完成后确认账号入口显示新的头像。

## 保存失败

若资料被其他窗口修改，重新打开资料面板查看最新值后再保存。不要在错误提示仍显示时认为修改已经生效。
