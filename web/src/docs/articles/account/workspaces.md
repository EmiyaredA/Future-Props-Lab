# 浏览与切换工作空间

<!-- prerequisites -->

面向登录用户。开始前确认当前账号和工作空间；成员管理与空间设置需要所有者或平台管理员权限，账号治理仅限平台管理员。

在自己可访问的工作空间之间切换。

## 打开空间面板

在 Studio 左下方点击当前空间，进入“空间”。“可访问的空间”展示空间名称、所有者和公开或私有状态；当前空间标记为“当前”。

1. 找到目标空间。
2. 点击“切换”。
3. 关闭面板并核对当前空间名称，随后再打开项目或配置。

![工作空间设置与切换](/docs/account-workspace.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 切换前后

先等待编辑器保存完成。切换空间后业务列表重新加载，实时语音的浏览器内缓存也会清除。平台管理员访问其他空间并不自动成为其成员。

## 没有看到目标空间

检查是否已接受邀请；私有空间不能仅凭名称加入。公开空间可能只提供[公开展台](/docs.html?page=workspace-public)，并不授予文件和模型管理权限。
