# 账号与私人数据

## 当前账号就是私人数据归属

项目、文件、模型连接、会话和后台任务归当前登录账号。应用已移除工作空间、成员身份和空间切换，不再创建默认空间。管理员负责平台账号治理，不能读取其他账号的私人项目和素材。此页面保留旧链接，原有空间入口已由账号菜单替代。

## 核对和使用账号

1. 从头像菜单查看当前账号，打开「账号设置」核对个人资料。
2. 本机浏览器或公网使用同一账号登录，应能读取同一部署中相同的私人项目。
3. 需要更换身份时先保存编辑，退出登录，再用另一个账号登录；不能通过切换空间访问别人的资源。

项目 ID 或文件链接不授予额外权限。看不到资源时核对当前账号、部署地址和任务状态，不通过修改数据库归属、复制素材目录或手工合并历史数据恢复。
