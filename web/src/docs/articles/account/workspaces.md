# 浏览与切换工作空间

<!-- prerequisites -->

面向登录用户。开始前确认当前账号和工作空间；成员管理与空间设置需要拥有者、工作区管理员或平台管理员权限，账号治理仅限平台管理员。

在自己可访问的工作空间之间切换。

## 打开空间面板

在 Studio 左下方点击当前空间，进入“空间”。“可访问的空间”展示空间名称、所有者和公开或私有状态；当前空间标记为“当前”。

1. 搜索目标空间，必要时翻页。
2. 点击“切换”。
3. 关闭面板并核对当前空间名称，随后再打开项目或配置。

![工作空间设置与切换](/docs/account-workspace.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 切换前后

先等待编辑器保存完成。切换空间后业务列表重新加载，实时语音的浏览器内缓存也会清除。平台管理员访问其他空间并不自动成为其成员。

## 没有看到目标空间

检查是否已接受邀请；私有空间不能仅凭名称加入。公开空间可能只提供[公开展台](/docs.html?page=workspace-public)，并不授予文件和模型管理权限。

## 成员角色

- **拥有者**：管理空间、全部成员与权限。
- **工作区管理员**：配置模型和集成、查看完整日志和审计；管理协作者与只读成员，不能修改拥有者、其他管理员或自己。
- **协作者**：编辑内容、上传素材、调用模型和发起生成；不能配置模型服务或查看完整调用日志。
- **只读成员**：浏览内部项目、播放和下载已有内容；不能修改、上传、调用模型或提交任务。

邀请时选择目标角色，默认协作者；受邀者在本人空间面板接受或拒绝。成员角色改变后，其旧空间密钥会失效。所有角色都可以管理自己的资料、密码与会话，只读成员只能创建只读密钥。

升级前的普通成员继续显示为协作者，模型配置和完整日志权限会收紧。需要这些能力时，请拥有者或平台管理员授予工作区管理员。

## 双栏空间面板

从工作台左下角的工作区入口打开面板。左侧搜索和分页浏览可访问空间，卡片展示拥有者、可见性、角色与当前标记。点击另一张卡片切换空间；有未保存编辑时先处理草稿。

右侧显示当前空间信息。有管理权限时可修改名称和访问范围，统一点击“保存更改”提交；关闭或切换前可以返回继续编辑，也可以放弃草稿。成员与邀请、固定角色说明、空间审计通过独立入口打开，可返回空间设置。

“我收到的邀请”处理其他空间发给你的邀请；“成员与邀请”中的列表只显示当前空间发出的邀请。手机上通过“空间列表”和“当前空间”切换视图。
