# 请求、结果与耗时说明

<!-- prerequisites -->

面向排查模型调用的用户。先确认工作空间中已有调用记录，并记录需要检查的时间和模型；日志不能访问其他空间的数据。

## 查看请求与响应

日志详情用于核对调用的模型、参数与已保存的脱敏请求快照。不同调用类型保留的内容不同：实时语音不会把转写正文和音频存成日志正文。

![本机演示响应的调用详情](/docs/logs-detail.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 理解统计

耗时用于判断调用速度，usage 依赖供应商实际返回。缺失字段不应解读为零消耗。工具摘要与工具调用完整快照也不是同一种记录。

## 复现限制

只有满足完整纯文本输入条件的调用才能导出复现包。语音、图片、视频和带附件请求不能依赖不完整快照恢复原始输入。详情显示无法导出时，阅读原因并回到测试入口构造可控输入。
