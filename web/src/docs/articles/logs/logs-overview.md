# 筛选日志与查看详情

<!-- prerequisites -->

面向排查模型调用的用户。先确认工作空间中已有调用记录，并记录需要检查的时间和模型；日志不能访问其他空间的数据。

## 找到一条调用

进入“模型调用日志”。可搜索模型、日志 ID 或 Trace ID，并结合调用来源、模型和状态筛选。调用来源包括快速诊断、模型测试与视觉助手。

![来自本机确定性服务的连接测试日志](/docs/logs-list.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 查看详情

打开目标记录后对照发生时间、模型、状态与耗时。连续测试时优先使用日志 ID 或 Trace ID 区分请求，避免把上一次失败当成最新状态。

## 列表维护

分页可调整每页数量；删除单条或批量删除前确认选择范围。删除日志不等于撤销模型调用，也不会退回已产生的供应商费用。

下一步阅读[结果与耗时](/docs.html?page=logs-details)。
