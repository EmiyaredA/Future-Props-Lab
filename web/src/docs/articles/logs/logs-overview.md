# 筛选日志与查看详情

<!-- prerequisites -->

面向排查模型调用的用户。先确认工作空间中已有调用记录，并记录需要检查的时间和模型；默认查看当前工作区。具备跨工作区日志权限时，可从筛选栏选择其他工作区或全部工作区，只读浏览概况，不会切换当前工作区。

## 找到一条调用

进入“模型调用日志”。输入模型、日志 ID 或 Trace ID 后按 Enter 搜索；调用源、供应商、模型和状态选择后即时筛选。调用源包括快速诊断、模型测试、视觉助手、视觉生成、思绪工坊写作和录音标注。

点击“筛选”设置日期范围，再点击“应用筛选”。关闭抽屉会放弃未提交修改；“重置”清空条件并保留工作区与每页条数。窄屏下更多筛选放在同一抽屉内，表格可横向滚动。

顶部统计表示所选工作区的今日数据，按 UTC 日界线计算，不受关键词和日期等列表条件影响。

## 查看详情

当前工作区点击“查看”，打开目标记录后对照发生时间、模型、状态与耗时。连续测试时优先使用日志 ID 或 Trace ID 区分请求，避免把上一次失败当成最新状态。

## 列表维护

分页支持每页 25、50 或 100 条。具有配置管理权限时，可以从行内更多菜单删除单条日志，或勾选后批量删除；操作前会要求确认。其他工作区和全部工作区视图只展示概况，不提供详情、复现包或删除。删除日志不等于撤销模型调用，也不会退回已产生的供应商费用。
