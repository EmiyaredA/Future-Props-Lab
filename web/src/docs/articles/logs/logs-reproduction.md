# 导出调用复现包及适用限制

<!-- prerequisites -->

面向排查模型调用的用户。先确认工作空间中已有调用记录，并记录需要检查的时间和模型；日志不能访问其他空间的数据。

## 适用对象

复现包适合需要独立验证文本请求的开发与测试人员。普通使用者排查失败时，先查看日志错误摘要，不必运行包内脚本。下载包后先检查请求内容是否含敏感信息，再考虑与他人共享。

## 导出模型调用复现包 {#model-log-reproduction}

1. 进入“模型调用日志”，打开一条保存了完整纯文本消息的 OpenAI 或 Anthropic 调用详情，点击“导出复现包”。
2. 解压 ZIP 并先阅读 README；通过 REPRO_API_KEY 环境变量提供测试密钥，包内不会包含管理台保存的凭证。
3. 使用 sync 模式串行多次调用，或使用 async 模式设置调用次数和并发上限；每次响应和延迟汇总会写入 results 时间戳目录。
4. 需要切换到测试网关时设置 REPRO_BASE_URL。批量调用可能产生真实费用和限流，应先用小批量与测试凭证验证。

> 实时语音、语音识别、图片、视频及带附件的文本日志没有保存原始输入，详情页会说明无法导出的原因，不会生成内容不完整的复现包。
