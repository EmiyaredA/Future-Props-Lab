# 皮肤、事件台词与行为习惯

打开桌宠项目后，先核对顶部保存状态。配置修改需要编辑权限，切换 Workspace 或离开时应处理未保存草稿。

## 外观与皮肤

Live2D 来源角色可以添加皮肤，再为来源部件上传替换 PNG。替换图必须与对应部件尺寸一致；皮肤复用角色的网格与动作，不是重新导入另一份角色。

选中皮肤供预览，再明确设置默认外观并保存。鲸鱼娘项目选择已有配色，不支持以原生角色部件方式替换贴图。

## 触发事件和台词

在「交互」页选择待机、点击身体、摸头、拖起、放下或自主走动，配置对应动作、表情和内置提示音；切换「台词」为同一事件添加台词。每个事件最多八句台词，每句 1–140 字，可用「播放事件」检查反应。

摸头由头部热区触发，身体其他区域触发点击；拖动开始与结束分别触发拖起和放下。台词是你预先编写的内容，不会为每次触摸调用模型。

## 行为与试玩

在「习惯」中设置角色大小、走动频率、拖拽、气泡和声音开关。悬停按钮最多选四个，常用入口包括装扮、走动、隐藏和聊天。

「试玩」提供桌面效果模拟。用触摸试听反应，检查大小、气泡和声音，再保存。保存的值是下次启动的默认配置；运行中换肤或调整走动只影响当前会话。

## 保存失败和来源兼容

保存遇到版本冲突时保留草稿，先核对服务器配置再决定如何处理。来源更新可能使某个动作、表情或皮肤不再兼容；不要绕过提示，先修正配置，再明确更新来源快照。
