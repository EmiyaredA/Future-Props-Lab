# 桌面运行与账号私有聊天

先保存[桌宠项目](/docs.html?page=pet-quickstart)，再在 macOS 桌面 App 中「放到桌面」。同一时间运行一只桌宠；浏览器编辑器中的模拟桌面不是独立桌面窗口。

## 运行与关闭

桌宠透明区域可让鼠标穿过，角色区域用于触摸和拖动。悬停按钮可换装、调整走动、隐藏或打开聊天；位置限制在屏幕可用区域内。

切换账号或 Workspace、退出 App 时桌宠及聊天小窗会关闭。运行时调整外观和习惯不会自动写回项目；想保留下次启动设置，需要回编辑器修改并保存。

## 作者编辑人设

在「聊天」页填写角色简介、性格、说话方式和开场白，保存到项目。人设随角色配置保留；私人聊天模型与消息不写入角色工程。

## 使用者开始聊天

1. 点击桌宠的「聊天」按钮，打开跟随角色的小窗。
2. 选择当前空间可用的文本模型；没有可用模型时先在模型服务配置并测试。
3. 输入文字并发送。回复按当前人设及最近对话生成，可以查看流式输出并停止当前轮次。
4. 需要重新开始时使用清空记录操作，先确认范围。清空不会删除桌宠工程或人设。

模型选择、主动台词开关和历史按账号、Workspace 与桌宠分别保存，同空间其他账号不会共享你的私人消息。主动台词使用预设事件内容，待机随机触发，不调用模型。

## 中断与边界

关闭聊天小窗、隐藏桌宠、切换身份或退出应用会取消当前浏览器请求。失败或取消的轮次标记为中断，不会自动重新发送；重新发送前先检查结果。

文字聊天会调用所选外部模型并可能产生费用，调用日志标识桌宠聊天来源。当前不提供语音对话、长期记忆或电脑操作能力。
