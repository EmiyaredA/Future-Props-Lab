# 从角色快照创建桌宠

从「应用 → 桌宠工坊」进入项目列表。桌宠项目属于当前 Workspace，创建和修改需要编辑权限；透明桌面运行与聊天小窗仅在 macOS 桌面版提供。

## 从 Live2D 角色开始

1. 先在[Live2D 工坊](/docs.html?page=live2d-quickstart)制作或导入角色，并保存。
2. 回到桌宠工坊，新建桌宠，选择「来源角色」并填写名称。
3. 创建后检查角色预览，再配置皮肤、事件台词、人设与行为习惯。
4. 保存后使用「放到桌面」运行；浏览器中可以编辑和预览，但不能打开透明桌宠窗口。

创建时复制角色文档和必需素材，形成固定快照。后续编辑或删除来源角色不会自动改动这只桌宠。

## 本地导入鲸鱼娘

项目列表提供「导入鲸鱼娘资源包」，选择本机 Coopanion ZIP 并阅读校验结果。资源通过导入保存到当前空间，不再依赖原始目录；应用不会替你联网下载资源。

鲸鱼娘使用原版分件动画与配色，不通过 FPL 原生骨骼重新绑定。在「形象」页选配色，设为默认值并保存；它与 Live2D 来源桌宠的部件皮肤编辑方式不同。

## 更新来源与删除

Live2D 来源桌宠在「试玩」中可「检查并更新来源」。更新前会检查动作、表情与换肤贴图兼容性；不兼容时保留当前快照。更新需要明确提交，不会自动跟随来源。

删除桌宠会删除其配置和素材快照，来源角色工程不受影响。桌宠配置不是公开发布包，目前没有桌宠包发布与安装入口。
