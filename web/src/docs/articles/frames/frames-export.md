# 图片格式与导出

<!-- prerequisites -->

面向需要从本地视频取图的用户。准备浏览器可以解码的视频文件；视频在浏览器中处理，不需要生成模型或上传到模型供应商。

## 设置输出

选择 PNG、JPEG 或 WebP。PNG 适合无损画面；JPEG/WebP 可按界面调整质量。填写导出文件基础名称，并决定是否包含时间戳。

![合成视频帧的导出预览](/docs/frames-export.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 下载

重新生成预览并确认它未过期后下载。文件名根据基础名称、时间戳设置和输出格式生成；输出扩展名对应实际图片类型。

## 保存位置

图片由浏览器下载到本机，不会自动进入文件管理或某个工坊。继续用于项目时，从项目的上传入口显式导入。
