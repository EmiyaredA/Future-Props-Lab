# 定位时间点与预览

<!-- prerequisites -->

面向需要从本地视频取图的用户。准备浏览器可以解码的视频文件；视频在浏览器中处理，不需要生成模型或上传到模型供应商。

## 选取画面

使用播放、暂停、时间进度控件定位。工具的前后步进按 1/30 秒调整，用于细调时间点，不等价于识别每个源视频的真实帧率。

## 生成预览

定位后生成当前画面的预览，检查尺寸与内容。拖动时间点、修改参数后旧预览可能标记为过期，需要重新生成。

## 验收

确认截图没有运动模糊或错误切点，再执行下载。浏览器定位与解码行为可能因视频编码而异；要求剪辑成片像素一致时使用剪辑工坊的精确帧导出。
