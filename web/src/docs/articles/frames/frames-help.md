# 格式兼容及常见问题

<!-- prerequisites -->

面向需要从本地视频取图的用户。准备浏览器可以解码的视频文件；视频在浏览器中处理，不需要生成模型或上传到模型供应商。

## 文件能选但不能播放

容器扩展名相同不保证内部编码受支持。MOV、MP4 等文件可能使用浏览器无法解码的编码。保留原文件，使用受支持编码转换后重试。

## 预览与时间不一致

查看预览是否过期。先等待定位完成，再生成预览；改时间、格式或质量后重复该步骤。

## 刷新后内容丢失

这是浏览器本地工具，刷新或关闭会释放已选择的视频与预览。重新选择源文件即可继续；已经下载的图片不受影响。
