# 视频帧导出：导入视频

<!-- prerequisites -->

面向需要从本地视频取图的用户。准备浏览器可以解码的视频文件；视频在浏览器中处理，不需要生成模型或上传到模型供应商。

## 适用场景

从单个视频中选取一个时间点并导出图片，例如封面或参考画面。工具在浏览器中读取本地文件，不上传视频，也不创建服务端项目。

## 导入

从工具导航进入“视频帧导出”，选择或拖入视频。可选择 MP4、MOV、WebM 或 OGG 等常见文件，但实际播放取决于浏览器解码能力。

## 检查

等待视频准备完成，核对时长与画面尺寸。换文件会重置之前的时间和预览；需要保留的图片应先下载。
