# 项目引用与素材复用

<!-- prerequisites -->

面向需要整理与复用素材的空间用户。先确认工作空间；上传、移动与删除需要写权限，公开只读访问不能执行这些操作。

识别引用和独立副本，理解删除操作的影响。

## 在项目中选择已有文件

打开项目素材区的文件选择入口，从当前空间的文件管理中选择素材。项目引用让多个项目复用一个源文件；另一些跨应用导入操作会创建独立副本。

## 移除引用

素材菜单显示“移除引用”时，只从当前项目解除关系，文件管理中的源文件保持不变。菜单显示“删除”时，应按该素材真实归属检查影响。

## 快照与跨应用导入

项目快照会把必要素材打包，导入时创建新项目和独立素材。模型绑定不可用时可能清空绑定并提示，但提示词与参数会保留。详见[项目快照](/docs.html?page=project-snapshots)。

## 使用前检查

确认文件类型符合目标工具，且原文件可访问。其他工作空间的文件不能通过复制资源 ID 绕过隔离。
