# 上传与预览文件

<!-- prerequisites -->

面向需要整理与复用素材的空间用户。先确认工作空间；上传、移动与删除需要写权限，公开只读访问不能执行这些操作。

检查每个上传结果，并确认文件能正确预览。

## 上传

1. 打开目标文件夹，点击“上传文件”。
2. 选择本地文件。
3. 在上传状态中区分等待上传、上传中、上传成功和上传失败。
4. 等成功项目出现在列表后，再把它用于模型测试或创作。

![公共文件列表中的合成演示素材](/docs/files-library.jpg "真实界面 · 隔离演示数据；合成素材或本机确定性响应，不代表外部模型效果。")

## 预览

普通文件上传默认单文件不超过 **200 MiB**，部署管理员可以调整此上限。文件扩展名、MIME 和实际文件头需要一致，改后缀不能让不支持的内容变成合法文件。

| 类型 | 当前公共文件接口支持            |
| ---- | ------------------------------- |
| 图片 | JPG、JPEG、PNG、WebP、GIF、AVIF |
| 视频 | MP4、WebM、MOV、MKV             |
| 音频 | MP3、WAV、M4A、OGG、AAC、FLAC   |
| 文档 | PDF、TXT、Markdown、JSON        |

字体由支持字体的应用入口管理。能上传不代表浏览器具备对应解码器；模型附件和项目导入还会进一步限制格式。

点击素材预览入口检查图片、视频或音频。文档是否可直接预览取决于其格式；不能预览不一定代表上传失败，应结合文件状态与下载结果判断。

## 排查上传失败

查看具体失败条目和错误原因，再单独重试。上传限制由当前上传用例决定；语音识别、项目快照与普通文件上传的限制不能互相套用。

> 上传过程中不要切换空间或关闭页面。模型输入选择器还会额外校验模型支持的格式与大小。
