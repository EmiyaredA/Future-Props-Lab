# 删除限制与常见问题

<!-- prerequisites -->

面向需要整理与复用素材的空间用户。先确认工作空间；上传、移动与删除需要写权限，公开只读访问不能执行这些操作。

先处理引用，再删除不再需要的文件。

## 删除前

核对文件名称、所在目录与引用情况。删除文件夹可能连同下级文件和子文件夹一起删除；确认框中的影响范围应完整阅读。

## 文件仍被引用

若删除被阻止，进入相关项目移除素材引用或替换时间线、画布中的使用位置，然后重新尝试。删除按钮不可用不代表需要直接删除磁盘文件。

## 文件消失或预览失败

先确认工作空间和筛选条件；如果文件仍列出但预览失败，尝试重新打开预览并查看错误。不要手工移动运行目录中的原文件，这会让项目记录与文件失去对应。

[找不到资源](/docs.html?page=help-resources)说明了更完整的排查顺序。
