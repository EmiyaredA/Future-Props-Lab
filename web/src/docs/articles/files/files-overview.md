# 文件管理概览

<!-- prerequisites -->

面向需要整理与复用素材的空间用户。先确认工作空间；上传、移动与删除需要写权限，公开只读访问不能执行这些操作。

集中组织当前空间中的图片、视频、音频和文档。

## 打开文件管理

从 Studio 主导航进入“文件管理”。这里管理供不同项目复用的公共文件，区别于某个工坊的项目私有素材区。

## 选择操作方式

按类型筛选图片、视频、音频或文档；通过名称搜索目标文件。需要整理层级时进入文件夹，准备内容时选择“上传文件”。

## 从文件到项目

上传成功不表示文件已被加入所有项目。进入目标项目的素材选择器，显式选择需要引用或导入的文件。

下一步：[上传与预览](/docs.html?page=files-upload)、[引用与复用](/docs.html?page=files-references)。
