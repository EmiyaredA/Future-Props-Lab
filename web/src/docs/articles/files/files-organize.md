# 文件夹、搜索与整理

<!-- prerequisites -->

面向需要整理与复用素材的空间用户。先确认工作空间；上传、移动与删除需要写权限，公开只读访问不能执行这些操作。

通过目录、类型和名称找到素材。

## 文件夹整理

在文件管理中创建文件夹，进入目标层级后上传。通过文件夹或文件菜单重命名、移动或删除，操作前核对当前目录和目标名称。

文件夹最多五层；移动文件夹也会检查整个子树是否超过上限。不能把文件夹移入自身或自己的子文件夹。

## 搜索与排序

搜索文件或文件夹名称，并结合类型筛选缩小范围。排序可在“最近更新”和“按名称”间切换。搜索未找到时先清除筛选，再检查是否处于正确空间与文件夹。

## 命名建议

用用途、内容与版本命名，例如“片头背景-v2”。重命名用于整理显示名称，不应依靠它改变文件类型。删除父文件夹涉及子文件夹和文件，确认对话框会说明范围。
