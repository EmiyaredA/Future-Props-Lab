# Provider brand artwork

`qwen-logo.svg` and `deepseek-logo.svg` are the purple Qwen symbol and blue
DeepSeek whale from [LobeHub Icons](https://github.com/lobehub/lobe-icons),
retrieved on 2026-10-23:

- [Qwen color SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/qwen-color.svg)
- [DeepSeek color SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/deepseek-color.svg)

The Qwen mark uses the purple brand color `#615CED` instead of the upstream
file's blue fill; its geometry is unchanged.

These SVG files are distributed under the upstream MIT license, reproduced in
`lobe-icons-LICENSE`. Brand names and marks belong to their respective owners;
they identify the configured provider and do not imply endorsement.

Brand references: [Qwen](https://qwen.ai/), [DeepSeek](https://www.deepseek.com/).
The application serves these assets locally; displaying a provider does not
contact the brand sites or the icon library.

`codex-logo.svg` and `claudecode-logo.svg` identify the fixed native software
connections in node acceptance. Retrieved on 2026-10-23 from the same MIT-licensed
LobeHub Icons project (geometry unchanged, rendered as a theme-aware mask):

- [Codex SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/codex.svg)
- [Claude Code SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claudecode.svg)

identify the selected software; they do not imply affiliation or endorsement.
