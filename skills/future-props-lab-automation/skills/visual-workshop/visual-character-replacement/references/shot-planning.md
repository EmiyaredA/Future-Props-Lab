# 镜头规划与参考职责

在拆镜、准备参考或改变场景时读取。

## 从原片得到制作说明

记录源时间区间、镜头类型、在场人物、景别/机位、站位/视线、动作先后、空间接触、道具、镜头运动和节奏。切镜边界需要核对邻近原帧，场景检测和稀疏抽样只作为候选。角色映射使用稳定 ID，不只依赖会随镜头变化的“左边/右边”。

将用户要求写成“保留”和“替换”。只换人物时，沿用场景、构图和表演；服装是否跟随目标人物依用户要求明确记录。换场景时区分外观替换和空间重构，保留动作成立所需的接触面、人物路径、遮挡顺序和镜头视线。更改空间结构需要重新审查相应动作，不能假设换一张背景就成立。

## 分离参考职责

| role | 约束 | 避免 |
| --- | --- | --- |
| identity | 指定角色的脸、发型、体型、服饰 | 无关角色混入；原片身份回流 |
| space | 起始构图、站位、接触、光照、场景/道具 | 只看风格而忽略动作所需结构 |
| action | 动作顺序、视线、表情、运镜 | 以原片人物外观替代目标身份 |
| timing | 动作关键时刻、短句、节奏 | 只控制总时长，不检查内部时序 |

完整人设板用于统一身份，实际输入按镜头选择独立脸部、全身或侧面参考。单人镜头不塞入无关人物；多人参考明确映射。起始画面应先检查构图与身份，再用于动态任务。

选择执行方式时服从上层能力：直接编辑、关键帧驱动、参考驱动或确定性合成都可以。没有某种输入能力时保留制作要求，说明能验证的范围，不能假装该能力存在。

## 长镜头与特殊镜头

- `segments` 使用源片绝对秒，连续覆盖原镜头。按动作起落、停顿、机位阶段规划，保留姿态/速度/视线衔接；不要把固定秒数写为通用规律。
- 生成时可以准备衔接余量，但记录实际采用区间；避免重复动作、遗漏收尾或通过未授权变速掩盖错拍。
- 无需替换的镜头标为 `preserve`。文字/重复头像等图形镜头标为 `graphic`，保持版式、图层、重复规律与切换时序，按能力选择素材替换或合成。
- 代表镜头根据实际共同风险选择，并在记录中将对应镜头 `representative` 设为 true。共同参考变化后需重新检查受影响镜头。
